  히트판 ERP 설치 안내서
  (HitPan Enterprise Resource Planning v1.0)
═══════════════════════════════════════════════════════════════════

■ 준비물
  • Windows 10 이상 (64비트)
  • 공간: 약 1GB
  • 관리자 권한


■ 설치 방법 (초간단 3단계)

  1) "히트판_ERP_설치.exe" 파일 더블 클릭

  2) "이 앱이 장치를 변경할 수 있도록 허용" → [예] 클릭
     (관리자 권한 요청)

  3) 설치 마법사에서 [설치] 버튼 클릭
     → 2~3분 대기 (MariaDB + 히트판 자동 설치)
     → 설치 완료 시 자동으로 히트판 실행


■ 첫 로그인

  아이디:   tenant@hitpan.kr
  비밀번호: Admin1234!

  로그인 후 [설정] → [사용자정보 설정]에서
  회사 정보를 변경해주세요.


■ 실행 / 종료

  [실행]
    바탕화면의 "히트판 ERP" 아이콘 더블클릭
    (브라우저가 자동으로 http://localhost:5234 열림)

  [종료]
    시작 메뉴 → 히트판 ERP → "히트판 ERP 중지"
    또는 PC 재시작 시 자동 종료


■ 설치 경로

  히트판 본체:     C:\HitPan\hitpan
  데이터베이스:    C:\Program Files\MariaDB 11.4
  바탕화면 바로가기: 히트판 ERP (자동 생성)


■ 자주 묻는 질문

  Q. 설치 중 Windows Defender가 차단합니다.
  A. "추가 정보" 클릭 → "실행" 클릭하면 됩니다.
     (히트판은 검증된 프로그램입니다)

  Q. 설치 후 브라우저가 안 열려요.
  A. 크롬/엣지에서 직접 접속: http://localhost:5234

  Q. 기존 MariaDB가 설치되어 있어요.
  A. 기존 MariaDB를 사용하거나, 설치 전 제거해주세요.
     제거 방법: 제어판 → 프로그램 제거 → MariaDB

  Q. 포트 충돌 에러가 납니다.
  A. 다른 프로그램이 5234, 5257 포트를 사용 중입니다.
     해당 프로그램을 종료 후 재시도하세요.

  Q. 제거는 어떻게 하나요?
  A. 제어판 → 프로그램 제거 → 히트판 ERP → 제거
