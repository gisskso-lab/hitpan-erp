## 2. 테스트 환경 (VM 한정)

**절대 원칙**
- 사장님 PC·고객사 PC·본사 운영 서버 **테스트 금지**
- 모든 테스트는 Hyper-V / VMware Workstation **격리 VM**에서만
- VM 스냅샷 필수 (각 백신 설치 직전 1회)

| 항목 | 사양 |
|---|---|
| OS | Windows 11 Pro 23H2 (clean install) |
| RAM | 8GB 이상 |
| Disk | 80GB 이상 (백신마다 별도 VM 권장) |
| 네트워크 | NAT (인터넷 가능, 격리 서브넷) |
| 사전 설치 | 없음 (.NET Runtime은 EXE가 자동 설치) |

## 3. 테스트 시나리오 (T-1 ~ T-8)

| ID | 시나리오 | 측정 |
|---|---|---|
| T-1 | 백신 설치 후 → 히트판 EXE 다운로드 | 다운로드 차단 여부 |
| T-2 | EXE 실행 (관리자 권한) | 실행 차단·격리 여부 |
| T-3 | 설치 진행 (MariaDB / .NET / cloudflared) | 컴포넌트별 격리 여부 |
| T-4 | 설치 완료 후 첫 실행 | 프로세스 종료·메모리 스캔 알림 |
| T-5 | 자동시작 등록 (Windows 서비스 3종) | 서비스 등록 차단 여부 |
| T-6 | 터널 통신 (UDP 7844 cloudflared) | 방화벽·네트워크 차단 여부 |
| T-7 | 24시간 가동 상시 스캔 | 실시간 보호 오탐 여부 |
| T-8 | Windows Update 강제 재부팅 후 자가 복구 | 워치독 동작 + 백신 간섭 여부 |

상세 절차·기대값은 `antivirus-matrix-template.md` 참조.

---

## 4. 실행 순서 (1 VM 기준)

1. **스냅샷 0** — Windows 11 clean (백신 미설치)
2. 백신 설치 + 최신 시그니처 업데이트
3. **스냅샷 1** — 백신 설치 직후
4. T-1 → T-8 순차 실행, 각 단계 결과 매트릭스 기재
5. 격리 발생 시 → **강제 우회 금지**. `docs/installer/1CLICK_QUARANTINE_RECOVERY.md` 절차로 정상 봉합 후 재현 가능 여부 기록
6. VM 폐기 또는 스냅샷 0으로 복귀 → 다음 백신으로

> 6개 백신 × 8 시나리오 = **48 셀** 완성이 라운드 1 종료 조건.

---

## 5. 절대 금지

- 격리된 파일을 강제 실행하거나 백신 탐지 회피 코드 작성 (= 악성코드 패턴, 헌법 #23 위반)
- Defender 예외·방화벽 규칙을 테스트 절차서 또는 별도 PowerShell로 등록 (인프라 조작 = 헌법 #29 위반)
  - 예외 등록은 **설치 EXE 내부 관리자 권한 흐름**에서만. 테스트는 그 동작을 **관찰**할 뿐.
- 실측 결과 미기재 상태로 매트릭스 PASS 마킹 (받아쓰기 = 헌법 #32 위반)

## 6. 산출물 제출

- 매트릭스 48셀 완성본 → 보안 매니저 2 → PM → 사장님 결재
- 격리 발생 백신·시나리오 → 1클릭 봉합 매뉴얼 보강 안건으로 회부
- 라운드 1 통과 기준: **48/48 PASS 또는 1클릭 봉합 100% 성공**
