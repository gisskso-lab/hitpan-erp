## 3. 시나리오 상세

### T-1 EXE 다운로드
- 절차: 브라우저에서 `hitpan-installer.exe` 다운로드
- 기대값: 다운로드 완료, SmartScreen 신호 없음
- 실패 시 기록: 차단 메시지 원문, 백신 로그 경로

### T-2 EXE 실행 (UAC)
- 절차: 다운로드 EXE 우클릭 → 관리자 권한 실행
- 기대값: UAC 동의 후 인스톨러 UI 표시
- 실패 시 기록: 격리 파일 경로, 백신 탐지명

### T-3 컴포넌트 설치
- 절차: 설치 진행 (MariaDB 11.4 / .NET 8 / cloudflared)
- 기대값: 3개 컴포넌트 모두 정상 설치
- 실패 시 기록: 어느 컴포넌트에서 격리, 백신 탐지명

### T-4 첫 실행
- 절차: 설치 완료 후 바탕화면 아이콘 → 히트판 ERP 첫 실행
- 기대값: 로그인 화면 표시, 메모리 스캔 알림 없음
- 실패 시 기록: 프로세스 종료 여부, 알림 원문

### T-5 서비스 등록
- 절차: 자동 등록되는 Windows 서비스 3종 확인 (`HitpanAPI`, `HitpanWatchdog`, `cloudflared`)
- 기대값: 3종 모두 `Running`
- 실패 시 기록: 등록 실패 서비스, Defender ASR 알림 여부

### T-6 터널 통신
- 절차: cloudflared UDP 7844 outbound 연결 시도
- 기대값: 정상 connect → 외부 헬스체크 200 OK
- 실패 시 기록: 방화벽 차단 알림, netstat 결과

### T-7 24h 상시 스캔
- 절차: VM 24시간 가동, 백신 실시간 보호 ON
- 기대값: 오탐 0건
- 실패 시 기록: 시각·탐지명·조치 결과

### T-8 Windows Update 후 자가 복구
- 절차: Windows Update 강제 적용 → 재부팅 → 워치독 자가 복구 관찰
- 기대값: 재부팅 5분 이내 cloudflared·API·DB 정상 (헌법 #28)
- 실패 시 기록: 복구 단계 멈춘 위치, 백신 간섭 여부

## 4. 격리 발생 시 1클릭 봉합 절차

> 강제 우회·예외 자동 등록·탐지 회피 코드 작성 절대 금지.
> 격리 발생 시 **고객 손 1번 안에 끝나는 정상 경로**만 허용.

상세 절차: `docs/installer/1CLICK_QUARANTINE_RECOVERY.md`

요약 (백신별):
1. **Defender** — 보호 기록 → 항목 선택 → 작업 → 허용
2. **V3 Lite** — 검사 기록 → 격리소 → 복원 → 예외 추가
3. **알약** — 격리소 → 복원 → 신뢰 항목 추가
4. **네이버 백신** — 격리실 → 복원 → 예외 등록
5. **Norton** — 보안 기록 → 격리 → 복원 → 신뢰
6. **McAfee** — 격리된 항목 → 복원 → 예외 처리

봉합 후 재현 테스트 → PASS 여부를 매트릭스 셀에 `QUAR→PASS` 형태로 기록.
