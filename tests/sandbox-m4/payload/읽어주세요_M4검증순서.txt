이 샌드박스는 demo 운영 PC(호스트)와 완벽히 분리돼 있습니다.
여기서 무슨 일이 나도 호스트(진짜 demo)는 절대 안 다칩니다.
끄면 안의 모든 것이 사라집니다 — 그게 테스트용으로 쓰는 이유입니다.

문제가 보이면 그 화면을 그대로 캡처해서 PM에게 주십시오.

------------------------------------------------------------------
[순서 ②-먼저] 종단 빌드테스트 — 설치 EXE 깔기
------------------------------------------------------------------
1) 파일 탐색기에서  C:\dist  로 갑니다.
2) HitPan-ERP-Setup-1.2.15.exe  를 더블클릭해 설치합니다.
   - 이 EXE 안에 MariaDB·.NET·ERP가 다 들어 있습니다.
3) 설치 마법사를 따라갑니다. 각 화면을 캡처하십시오.
   - 가입(랜딩) → 시리얼 입력 → 설치 완료까지.
   - ★ 막히는 화면이 나오면 거기서 멈추고 캡처 → PM 호출.
     (그 막힌 지점이 바로 "진짜 끊김"입니다 — 추측이 아니라 실측.)
4) 설치가 끝나면 ERP 로그인 화면까지 가서 로그인해 봅니다.
   - 로그인 되면 종단 흐름 골격 OK.

------------------------------------------------------------------
[순서 ①-다음] 고리4 P1 멱등 검증 — 자동 스크립트
------------------------------------------------------------------
위 EXE 설치로 MariaDB가 깔렸으면, 멱등 검증을 자동으로 돌립니다.

1) 시작 → "PowerShell" 우클릭 → 관리자 권한으로 실행
2) 아래 한 줄을 붙여넣고 Enter:

   powershell -ExecutionPolicy Bypass -File C:\m4\setup-m4.ps1

3) 화면을 봅니다:
   - 초록색  "① 고리4 P1 멱등 = PASS"  → 성공.
   - 빨간색  [FAIL]  →  그 줄 전체를 캡처해 PM에게.

------------------------------------------------------------------
[순서 끝] 결과 정리
------------------------------------------------------------------
- ② 종단: 어디까지 갔는지 + 막힌 화면 캡처
- ① 멱등: PASS / FAIL 캡처
이 둘을 PM에게 주시면 종합 보고를 만듭니다.

* MariaDB를 못 찾는다고 나오면 = EXE 설치(②)가 아직 안 끝난 것입니다.
  ② 먼저 끝내고 ①을 돌리십시오.
