========================================
 히트판 ERP 종단 설치 테스트 (v1.2.28)
 목표: 설치마법사에서 부모계정(아이디+비번) 등록 → 로그인 종단
========================================

이 창은 Windows 샌드박스(깨끗한 백지 가상 PC) = 실고객 PC입니다.

※ 이번 구조(1.2.28, 헌법 #40 재조정):
  - 백오피스↔ERP 연결 = 시리얼·테넌트넘버로만 (고객계정 아님)
  - 시리얼 검증 = 설치마법사가 백오피스에 "서버간" 1회 조회 (브라우저 아님 → CORS 없음)
  - 부모계정(아이디+비번) = 설치마법사 안에서 직접 등록 → 고객 PC 로컬 DB에 저장
  - 부모계정 비번은 본사에 절대 안 감. 부모계정 생성은 통신 0 (본사 개인키 서명을 오프라인 검증)

※ 개발 PC 정상은 의미 없음. 반드시 이 백지 샌드박스에서 검증.

────────────────────────────────────────
[1] 설치 EXE 실행
────────────────────────────────────────
  C:\hitpan-test\HitPan-ERP-Setup-1.2.28.exe
  → 우클릭 → 관리자 권한으로 실행

────────────────────────────────────────
[2] 설치마법사 안에서 (★이번 핵심★)
────────────────────────────────────────
  ① 시리얼 키 입력 (HITP-XXXX-XXXX-XXXX-XXXX) + 사업자번호
     → 백오피스 서버간 조회로 회사정보·서명증표 받아옴
  ② 회사정보 확인
  ③ ★부모계정 = 아이디 + 비밀번호(8자+) 직접 입력★
     → 아이디는 이메일 형식 아니어도 됨 (예: hitpan_admin)
  ④ 자동 설치 (DB·통신·부모계정 로컬 생성까지 설치마법사가 완료)

  ※ 이제 설치가 끝나면 부모계정이 이미 만들어져 있음. 웹에서 따로 안 만듦.

────────────────────────────────────────
[3] 로그인 (설치 후)
────────────────────────────────────────
  브라우저 → https://test1.hitpan.kr (또는 설치 후 자동 열림)
  → 로그인 화면에서 방금 설치마법사에서 만든 아이디 + 비번 입력
  → 로그인 200 되나? 6단계 메뉴(설정/마스터/매입/판매/현황/재무) 뜨나?

  막히면 그 자리에서 멈추고 화면·F12 콘솔 캡처해서 PM에게.

────────────────────────────────────────
[부모계정 실제 저장 확인 — 관리자 cmd]
────────────────────────────────────────
  "C:\Program Files\MariaDB 11.4\bin\mysql.exe" -u root hitpan_erp_t001 -e "SELECT email,is_parent,is_active FROM users;"
  → 설치마법사에서 만든 아이디가 email 컬럼에, is_parent=1 로 나오면 성공.

  [1]~[3] 다 통과 = 설치마법사 로컬 완결 온보딩 첫 종단 통과 = 진짜 검증 완료!
