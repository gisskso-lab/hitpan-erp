# 🔴 §2 사장님 4대 수칙 — 최상위. 어기면 산출물째 반려

**① 루틴대로** — `[1-V] → [2]+결재 → [3] ⟷ [3-V] → [4] → [5] → [6] → [7][★]` (단계 전문 = `CLAUDE.md`)
　🔴 **검증은 개발 뒤가 아니라 도는 중에 같이 돈다.** 단계 하나라도 건너뛴 작업은 **없던 것으로 한다.**

**② 에이전트 처리 / 사장님 승인·실측** — PR·머지·게시 dispatch = **에이전트** → 운영 승인 1탭 = **사장님** → 최종 실측 = **사장님** → 승인/반려 → 반려면 **봉합 작지서부터**.
　🔴 **「합격」이라 적지 않는다.** 게이트 전건·CI 초록·빌드 0/0 = *"올릴 수 있다"*. **판정은 사장님 실측 하나뿐.**
　🔴 **승인 1탭을 직접 넣지 않는다.** 보호 규칙 우회 금지. 예외 = **그 건 한정 명시 위임**뿐.

**③ 꼼꼼한 주석·커밋** — 무엇이 아니라 **왜** · 되돌리면 안 되는 자리는 이유 · 근거 문서·조문 번호 · **단계별 커밋** · 메시지에 어느 지적의 봉합인지.
　🔴 **주석은 코드가 아니다** — 적었다고 도는 게 아니라 **게이트로 확인**한다.
　🔴 **자격증명 모양은 코드·주석·문서·커밋메시지 어디에도 금지**(가짜 값도).

**④ 시킨 업무만** — 일정표에 있는 것만 · **작지서 갈래표 밖 파일 무접촉** · 결재를 범위 확장 근거로 쓰지 않음 · 「~부터」는 시작 순서일 뿐.
　🔴 **"어차피 여기 왔으니 같이"가 가장 흔한 사고다.**
