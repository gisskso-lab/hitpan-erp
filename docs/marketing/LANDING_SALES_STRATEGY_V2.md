## 0. 한 줄 영업 명제

> **"본사도 못 보는 ERP. 사장님 데이터는 사장님 PC에만."**

- 더존·이카운트: 본사 클라우드 = 사고 시 전 고객사 노출

## 2. 이탈률 방지 전략 (사등 업로드 30~50% → 15% 이하)

### 2-1. 메시지 프레임 전환
- **금지 카피**: "사업자등록증 업로드 (필수)" → 차갑고 위협적
- **권장 카피**: "1분 검증, 평생 안전. 본사도 사장님 사등을 못 봅니다 (암호화 보관)"

### 2-2. 가입 5단계 진행률 표시
1. 사업자번호 입력 (10초) → "1/5 완료"
2. 사등 업로드 + KYC 동의 (1분) → "2/5"
3. 대표자 정보 + 휴대폰 인증 (1분) → "3/5"
4. 결제 수단 등록 (1분) → "4/5"
5. 시리얼 발급 (영업시간 1시간 / 야간 자동 5분) → "5/5 완료"

### 2-3. 사등 업로드 직전 인터스티셜
> "딱 1분 걸립니다.
> 본사도 사장님 사업자등록증 사진을 평문으로 보관하지 않습니다.
> AES-256 암호화 후 KYC 통과 자동 파기.
> 검증된 사업자만 가입 가능 = 도용·사칭으로부터 사장님 보호."

### 2-4. 가입 도중 이탈 자동 봉합
- 사등 업로드 페이지 진입 후 5분 무동작 → 챗봇 안내 "어디서 막히셨어요?"
- 결제 페이지 진입 후 미완료 → 1시간 후 이메일 "30초만 더 하시면 시작합니다"
- 24시간 후 미결제 → 영업팀장 직접 전화 (베타 100곳 한정)
- 7일 후 → 자동 폐기 (개인정보 최소주의 헌법 #22)

### 2-5. SLA 공약 가입 페이지 노출
- "시리얼 발급 영업시간(09~18) 1시간 이내"
- "1시간 초과 시 다음 달 10,000원 자동 할인"
- "야간/주말 = 24/7 자동 발급 폴백 (자동 KYC 통과 시 5분 이내)"

### 2-6. FAQ 인포그래픽 (사등 페이지 우측)
- "왜 사업자등록증이 필요한가요?" (30초 영상)
- "본사가 제 사등을 볼 수 있나요?" → NO
- "이미지 어디에 저장되나요?" → KYC 통과 후 자동 파기
- "법인이 아닌 개인사업자도 되나요?" → 됨

## 3. 신뢰 자산 영업 응대 시나리오

### Q1. "왜 본사가 시리얼을 발급하나요? 셀프 발급 안 되나요?"
A. "셀프 발급은 도용 1건 발생 시 형사 책임이 사장님께 옵니다.
저희가 본사 KYC를 통과시켜 발급하면, 도용 사고 발생 시 본사가 우선 면책 라인이 됩니다.
시리얼 1개 = 사장님 면책 1개 = 1시간 투자."

### Q2. "본사가 시리얼 발급하면 본사가 내 데이터 다 보는 것 아닌가요?"
A. "정반대입니다. 시리얼은 '본사 KYC를 통과한 사업자' 표식일 뿐, 사장님의 매출·매입·거래처 데이터는 사장님 PC에만 있습니다.
저희가 시리얼 발급 후 보유하는 것: 사업자번호·상호·결제 메타정보뿐.
저희가 절대 보유하지 않는 것: 매출·매입·거래처·직원·세금계산서·재고."

### Q3. "본사 직원이 마음먹으면 내 데이터 볼 수 있지 않나요?"
A. "기술적으로 불가능합니다.
사장님 PC ↔ 본사 사이 = Cloudflare 터널.
백오피스에는 사장님 매출 한 줄도 표시되지 않게 설계.
CS 응대 필요 시 = 사장님이 '1시간 임시 열람' 토큰을 발급해주셔야만 본사가 볼 수 있음 (JIT CS 토큰)."

### Q4. "그럼 백업은요? 본사가 백업 안 가져가면 PC 고장 시 어떡하나요?"
A. "백업은 사장님 PC + 사장님 외장하드 + (선택) E2E 암호화 본사 보관.
E2E = 본사가 받지만 본사 키로는 못 열고, 사장님 비번 없으면 평문 못 봄.
쿠팡·SKT·KT 사고 시대에 '본사가 내 데이터 다 들고 있다'가 가장 위험."

## 4. 대리점 영업 동기 박제 (사장님 명제 6 정합)

### 우려 진단
- 대리점이 자기 영업 고객사의 평문(매출·거래처)을 못 봄 → 영업 동기 약화 우려

### 봉합안 A: 메타 대시보드 (대리점 백오피스 화면)
| 표시 | 표시 안 함 |
|---|---|
| 고객사명·업종·규모(소/중/대) | 매출 금액 |
| 가입일·갱신예정일·결제 상태 | 거래처명·상품명 |
| 이상징후(7일 미접속·결제 실패·CS 폭주) | 직원명·내부 데이터 |
| 월 매출 구간(추정 5단계: A/B/C/D/E) | 정확 매출액 |
| 갱신 가능성 점수(0~100) | 회계 내역 |

### 봉합안 B: 갱신 수수료 인상
- 신규 가입 수수료: 30% (업계 표준 20%)
- 1년 갱신 수수료: 15% (업계 0~5%)
- 2년 연속 갱신: 20%
- → 대리점이 "팔고 끝"이 아닌 "갱신 챙기기"로 동기 전환

### 봉합안 C: JIT CS 토큰
- 고객사가 CS 요청 시 → 대리점이 "1시간 데이터 열람 요청" 발송 → 고객사 승인 시 1시간만 열람
- 모든 열람 로그는 고객사·본사·대리점 3자에 박제

### 대리점 랜딩 가입 흐름 (/reseller/signup)
1. "지역 독점 대리점 모집 — 월 평균 30곳 가입 시 1,500만원 수입"
2. 사업자등록증 + 영업 경력 증빙
3. 본사 면접 (전화 30분)
4. 표준 계약서 (지역·갱신 수수료·SLA)
5. 대리점 백오피스 계정 발급

## 5. 베타 100곳 영업 시나리오

### Phase 1: 1~5번째 (사장님 직접)
- 채널: 사장님 지인 도소매·서비스업
- 시연: 사장님 직접 방문, 30분 시연 + 무료 1년 + 사고 시 사장님 보상
- 카피: "히트판 1호 고객으로 기록됩니다"
- KPI: 가입 5/5, 이탈 0

### Phase 2: 6~50번째 (대리점 영업)
- 채널: 대리점 5개사 × 9곳
- 시연: 대리점 영업사원 방문, 1시간 시연 + 무료 6개월
- 카피: "베타 50곳 한정 — 평생 30% 할인 락인"
- KPI: 가입 45/45, 이탈 5 이내

### Phase 3: 51~100번째 (마케팅 인바운드)
- 채널: 네이버 검색·블로그·유튜브
- 시연: 셀프 가입 + AI 챗봇 + 화상 가이드
- 카피: "더존·이카운트 쓰다 답답하신가요? 30분 무료 컨설팅"
- KPI: 가입 50/50, 이탈 10 이내

### 시연 표준 시나리오 (30분)
1. (5분) 첫 화면 — "본사도 못 봅니다" 카피 설명
2. (5분) 사등 업로드 시연 — KYC 1분 통과
3. (10분) ERP 메인 시연 — 매입→재고→판매→세금계산서 3분 완주
4. (5분) 인터넷 끊고 시연 — 로컬 동작 확인
5. (5분) Q&A + 결제

## 6. 3티어 영업 응대 시나리오

### Tier 1: Basic 29,000원/월 (1인, 5GB)
**고객**: "29,000원도 비싸요. 무료 ERP 많은데?"
**응대 A (안전 프레임)**:
"무료 ERP는 본사가 데이터 다 가져갑니다. 광고·재판매가 비즈니스 모델이에요.
29,000원은 사장님 데이터를 사장님이 갖는 비용입니다.
하루 1,000원, 커피 한 잔 안 마시면 됩니다."

**응대 B (시간 프레임)**:
"엑셀로 30분 걸리던 세금계산서를 30초에 만듭니다.
하루 30분 × 22일 = 11시간 절약.
시급 1만원만 잡아도 11만원 절약. 29,000원이 비싸다는 건 사장님 시간이 시급 2,500원이라는 말입니다."

### Tier 2: Pro 59,000원/월 (5인, 20GB)
**고객**: "Basic으로 시작하고 나중에 올려도 되나요?"
**응대**: "됩니다. 첫 달 Basic으로 가입 후 3개월 차에 Pro 업셀이 가장 흔합니다.
직원 2명 추가하거나 BOM 쓰시려는 순간이 트리거입니다."

### Tier 3: Enterprise 100,000원/월 (무제한, 100GB, 우선 SLA 30분)
**고객**: "100,000원 받을 만한가요?"
**응대**: "Enterprise는 SLA 30분(Pro·Basic은 1시간), 우선 CS, 무제한 사용자, 멀티 사업장 통합입니다.
더존 Smart A Enterprise는 월 200,000원+이고 데이터는 본사 클라우드입니다.
100,000원에 데이터 주권까지 가져가시는 거예요."

### 업셀 트리거
- Basic → Pro: 직원 2명 추가 / BOM 필요 / 거래처 100개 돌파
- Pro → Enterprise: 직원 5명 돌파 / 멀티 사업장 / SLA 30분 필요
