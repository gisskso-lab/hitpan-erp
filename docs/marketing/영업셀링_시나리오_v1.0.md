## 1. 면담 시나리오 5단계

### 1.1. 단계 1 — 인사 + 사장님 페인 파악 (3분)
**질문 박제:**
- "현재 ERP 쓰시나요? 어떤 거?"
- "가장 불편한 점이 뭐세요?"
- "보안에 대해서 걱정하시는 부분 있으세요?"
- "직원분들 ERP 교육에 시간 많이 쓰시나요?"

**페인 5종 박제:**
1. 비싸다 (더존·이카운트 월 10만 원+)
2. 어렵다 (직원 교육 1주~1개월)
3. 본사 클라우드 = 데이터 유출 우려
4. 통신 끊기면 업무 중단
5. 기능 제한 (저가 티어 = 핵심 기능 잠금)

### 1.2. 단계 2 — 페인 vs 히트판 (5분)
| 페인 | 더존·이카운트 | 히트판 |
|---|---|---|
| 가격 | 월 10만~30만 | 월 2.9만~10만 |
| 교육 | 1주~1개월 | 첫날부터 사용 |
| 데이터 | 본사 클라우드 | 사장님 PC만 |
| 통신 | 본사 다운 = 업무 중단 | 사장님 PC가 자가 복구 |
| 기능 | 저가 티어 기능 제한 | 모든 티어 기능 동일 |

### 1.3. 단계 3 — 데모 시연 (10분)
**시연 5종:**
1. **첫 등록 (3분)**: 거래처 등록 → 매출 등록 → 세금계산서 발행
2. **자가 복구 (2분)**: 인터넷 끊고 → 5분 안 자동 봉합 시연
3. **데이터 주권 (2분)**: 본사 백오피스 = 사장님 데이터 0건 화면
4. **모바일 (2분)**: 사장님 폰에서 매출 즉시 확인
5. **워치독 대시보드 (1분)**: 사장님 PC 상태 실시간

### 1.4. 단계 4 — Q&A (5분)
**자주 묻는 질문 6종 (FAQ 양식):**

#### Q1. 본사가 사장님 데이터 가져가지 않으면 사장님 데이터 잃어버리면 어떻게 해요?
A: 백업 매뉴얼 + AI 챗봇으로 사장님이 안전하게 보관할 수 있도록 가이드합니다. 본사가 가져가는 게 더 위험합니다. 쿠팡·SKT 사고 보셨죠? (헌법 #24 책임 분산)

#### Q2. 99.99%는 어떻게 지키나요?
A: 본사 책임 영역 한정입니다. 사장님 PC·통신사·전기는 별도. 본사 클라우드 + 워치독 자가 복구 + 백업 = 99.99% 박제. 약관에 명시.

#### Q3. 더존·이카운트 안 쓰면 세무사가 데이터 못 받아요?
A: 세무사 자동 전송 기능 있습니다. 더존·이카운트 양식으로 변환 박제. 세무사 변경 필요 없습니다.

#### Q4. 직원이 ERP 안 써본 사람인데 쓸 수 있나요?
A: 30년 도소매 노하우 + UI 단순화 = 첫날부터 사용. 데모 시 5분 안 매출 등록 가능 박제.

#### Q5. 베타 끝나면 가격 오르나요?
A: 베타 가입 사장님은 6개월 베타 가격 유지. 정식 출시 후 가격 인상해도 베타 가입자 6개월 면제.

#### Q6. 사장님 PC 사고 나면 어떻게?
A: 백업 매뉴얼 + AI 챗봇. 본사 CS 콜센터 (월 1회 무료). 백업이 있으면 30분 안 복구 박제.

### 1.5. 단계 5 — 베타 1주차 무료 체험 클로징 (2분)
**제안:**
> "베타 1주차 무료 체험하세요. 사장님 PC에 설치해드리고, 1주일 써보시고 결정하시면 됩니다. 만족 안 하시면 0원입니다."

## 2. 차별화 포인트 7종 (경쟁사 비교)

### 2.1. 데이터 주권 (✨ 핵심 차별화)

|---|---|---|---|
| 데이터 보관 | 본사 클라우드 | 본사 클라우드 | **사장님 PC** |

| 본사 털리면 | 데이터 유출 | 데이터 유출 | **0건 영향** |

### 2.2. 자가 복구 (✨ 핵심 차별화)
| 항목 | 더존 | 이카운트 | 히트판 |
|---|---|---|---|
| 통신 끊김 시 | 업무 중단 | 업무 중단 | **5분 안 자동 봉합** |
| Windows Update | 영향 없음 | 영향 없음 | **자동 봉합 (5/27 사고 후 박제)** |
| 백신 격리 | 영향 없음 | 영향 없음 | **사전 화이트리스트 5종** |

### 2.3. 가격 (✨ 차별화)

| 중간 | 월 20만 | 월 15만 | **월 5.9만** |
