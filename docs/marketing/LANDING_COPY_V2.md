- **사장님 말투**: 군더더기 없는 단정. "~합니다"보다 "~한다" 톤 허용.
- **30년 검증된 손맛**: 정통 ERP 회사 포지셔닝 (애플 vs 삼성처럼 — 우리는 정통).
- **금지 단어**: AI, Claude, Cursor, 바이브코딩, 생성형, ChatGPT, LLM, 머신러닝 (헌법 #23).
- **권장 단어**: 사장님 손맛, 본사도 못 본다, 데이터 주권, 30년, 검증된, 정직한.

## 1. 메인 헤드라인 후보 5종 (H1 48px)

> 5초 안에 "쓰고 싶다"를 만드는 첫 문장. 사장님 1개 선택.

### H1-A. 데이터 주권형
> **"본사도 못 보는 ERP, 히트판"**

- 셀링 포인트: 로컬 PC + 터널 아키텍처 차별화 직격
- 리스크: 과대광고 — **법무팀장 검토 필수** (E2E 암호화·헌법 #22 근거 명시 필요)
- 권장 서브카피: "사장님 데이터는 사장님 PC에. 본사는 결제만 압니다."

### H1-B. 사장님 손맛형
> **"30년 손맛 그대로, 더 쉽게."**

- 셀링 포인트: 레거시 히트판 계승 + 신규 사용자 진입장벽 0
- 리스크: 신규 고객엔 "30년"이 부담 — 보완 카피 필요
- 권장 서브카피: "히트판을 쓰던 그 손, 새 히트판에서 그대로."

### H1-C. 정직한 가치형
> **"사업을 한 곳에서. 히트판."**

- 셀링 포인트: 매입·매출·재고·세금계산서·경리 통합
- 리스크: 무난하나 차별화 약함
- 권장 서브카피: "발주부터 세금계산서까지, 끊김 없이."

### H1-D. 시대 정신형
> **"내 데이터는 내 PC에. 사장님의 ERP."**

- 셀링 포인트: 쿠팡·SKT·KT 사고 시대 정합 (헌법 #22)
- 리스크: "쿠팡·SKT" 직접 거명은 광고법 리스크 — **법무팀장 검토 필수**
- 권장 서브카피: "데이터 사고 시대, 가장 안전한 ERP."

### H1-E. 간결 단정형
> **"쓰기 겁나 쉬운 ERP."**

- 셀링 포인트: 사장님 격언 직인용 (CLAUDE.md "쉬움으로 이겼다")
- 리스크: "겁나"가 격식 부족 — B2B 결재자(대표·세무사) 거부감 가능
- 권장 서브카피: "처음 앉아서도 그냥 됩니다."

## 7. 신뢰 뱃지 3종 (후보 5개 중 사장님 선택)

| 뱃지 | 의미 | 사용 가능 시점 | 법무 리스크 |
|---|---|---|---|
| **KISA 정합** | 정보보호 기준 | 자체 점검 통과 시 즉시 | 낮음 (사실 기재) |

| 카피 표현 | 리스크 | 법무팀장 검토 의무 |

```

├─────────────────────────────┤
│                              │
│   H1 메인 헤드라인 (32px)    │ ← 모바일은 48→32px

│                              │

│                              │
│   (신뢰 뱃지 3종 가로)        │
└─────────────────────────────┘
```

- **CTA 모바일판**: "오늘 시작" (4자, 엄지 닿는 위치)

### 모바일 후순위 (스크롤 시 노출)
1. 3대 셀링 포인트 (세로 카드)

## 10. 박제 마무리 — 사장님 결재 동선

### 사장님이 선택해야 할 결재 항목 (총 10개)

1. ☐ **H1 메인 헤드라인** A/B/C/D/E 중 1개
2. ☐ **서브 헤드라인** SH-1/2/3 중 1개
3. ☐ **Card 1~3 본문** 각 a/b/c 중 1개씩 (총 3개)
4. ☐ **Testimonial 노출 여부** (정식 출시 후 교체 동의 포함)
5. ☐ **요금제 한 줄 카피** a/b 중 1개씩 (3개 티어)
6. ☐ **"왜 이 가격" 설명** A/B/C 중 1개
7. ☐ **CTA-Header / Hero / Footer** 각 a/b/c 중 1개씩
8. ☐ **신뢰 뱃지 3종 조합** (5개 중 3개 선택)
9. ☐ **법무 검토 필요 카피 사용 여부** (각 항목 GO/홀드)
10. ☐ **모바일 H1 단축형** 사용 승인

### PM 운영 원칙 (헌법 #32 정합)
- PM이 임의로 1개 단정 금지. **반드시 사장님 결재 카드로 올림**.
- 사장님 반응에 즉석 카피 수정 금지. 결재 카드 형태로 박제 후 일괄 처리.
- 후보 추가 요청 시에만 PM이 추가 후보 박제.
