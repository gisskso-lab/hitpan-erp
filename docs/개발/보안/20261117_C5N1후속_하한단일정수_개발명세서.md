## 3. 1층 · 2층 · 판정 줄

**1층(`scan.sh:182~184`)** — 셋 중 하나라도 아니면 `scan_error "훑은 양 기록 모양 이상(기록 줄 R개 · 조각 값 N개 · 범위 커밋 C개)"` (R · N · C 숫자만 · 셈 실패면 `?`)

| | 조건 | 방법 |
|---|---|---|
| ⓐ | `records` 가 글자 그대로 `1` | `[ "${records:-}" != "1" ]` 글자 비교 — 빈 값 · 깨진 값도 닫힘 쪽. `records` = 엔진 기록 파일에서 `LC_ALL=C grep -ac 'finished scanning'` |
| ⓑ | `chunks` 전체가 `0` 또는 1~9 로 시작하는 1~9자리 ASCII 숫자 하나 | bash `[[ =~ ]]` 정규식 `^(0` 또는 `[123456789][0123456789]{0,8})$` — **숫자를 범위(`0-9`)가 아니라 하나씩 나열**해 지역 설정이 숫자 범위를 넓히지 못하게 함(4-3 「방법은 구현 갈래 판단」). bash 정규식은 줄 단위 고정이 없어 `^ $` = 값 전체 → 여러 줄 · 빈 값 · 앞자리 0 · 10자리 이상 · 부호 · 공백 · 글자 전부 아님 |
| ⓒ | `chunks` 숫자 바로 뒤 글자가 §1 집합 밖인 자리 개수 = 0 | `tailbad` = 기록 줄만 골라 `LC_ALL=C grep -aoE` 로 「`chunks` 숫자 + 집합 밖 한 글자」 자리를 셈(괄호식 `[^0-9,} 탭 CR]` · 탭 · CR 은 `$'…'` 로 실제 글자를 넣음 — 괄호 안 역슬래시 글자 그대로 오해 방지) · 줄 끝은 뒤 글자가 없어 안 걸림 = 허용 · 비교는 글자 `0` |

**2층(`scan.sh:185`)** — `[ "$chunks" -gt 0 ] 2>/dev/null || scan_error "범위 커밋 C개인데 훑은 조각 0(또는 비교 불가)"` : 참일 때만 통과 · 거짓 · 비교 실패(상태 2) 모두 검사 오류. `2>/dev/null` = 비교 실패 때 셸이 값을 찍는 길 차단(옛 `:174~175` 는 여러 줄 값을 문구 · 오류 출력에 그대로 찍었다).

- 문구 구분(정적): 1층 문구에는 `훑은 조각 0` 이 없고, 2층 문구에는 `훑은 양 기록 모양 이상` 이 없다 → S11 「모양」 · 「조각0」 단언이 어느 층이 닫았는지 가른다.
- `commits = 0` 길 무변(1층 · 2층 모두 `commits > 0` 안).

**판정 줄(`scan.sh:187`)** — 깨끗 판정 줄에만 ` · records=R`. 예: `판정: 깨끗 — 결과 0건 · 훑은 양: chunks:22 bytes:120 commits=3 · records=1`. 찾음 길 · 오류 길 무영향 · S9c 단언(`^판정: 깨끗 — ` 접두 · 1줄 · `^::` 0) 무영향(정적).
