## 4. 못 잰 것 (CI 전)

- 이 PC 에 jq · shellcheck 없음 · docker 실행 금지 → **자체시험 전체 미실행**. 잰 것 = `bash -n` 3파일 · `map_detector_names` 를 떼어 낸 단독 실행(허용 3 + 대소문자 다름 · 줄바꿈 이스케이프 · 빈 값 · 41자 · 공백 끼움 · 뒤 공백 6 → `CustomRegex(2) SQLServer(1) 기타(6)`).
- jq 식 두 개(`test("^[ \t\n\r\f\u000b]*$")` · `try (fromjson …) catch false`)는 러너 jq(1.7 계열)에서 처음 돈다.
- `local LC_ALL=C` 의 지역 전환이 러너 bash 에서 정규식에 먹는지 — 안 먹어도 목록 대조가 글자 그대로라 허용 밖은 `기타`(안전 쪽).
- 「이름 줄 수 불일치」 단언(scan.sh:165)은 정상 입력으로는 닿지 않는 방어 줄 — 시험 없음.
- 엔진 실물 출력이 엄격 해석에 걸리지 않는지는 S1·S2·S7·S8(진짜 엔진) 무후퇴로만 잰다.
