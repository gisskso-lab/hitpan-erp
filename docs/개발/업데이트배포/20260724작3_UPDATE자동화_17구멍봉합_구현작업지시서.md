## §1. 17구멍 봉합 명세 (설계 §2 → 구현)

### 🔴 CRITICAL
**B-1 — SSH 자격증명 분리 (웹CD 관통)**
- 트랙2(NCP): `hitpan-deployer` 전용계정 신설. 웹CD도 래퍼(`deploy-web.sh`) 경유로 리팩터 → 광역 sudo 제거.
- 트랙1: `deploy-web.sh` 래퍼 작성(아래 §2). GitHub Secret `NCP_USER`/`NCP_SSH_PRIVATE_KEY` = deployer 전용으로 분리.
- 산출물: deploy-web.sh, deploy-ncp.yml 리팩터, deploy-update.yml.

**B-2 — publish-update.sh in-script 가드** ✅ **완료**
- sudo 컨텍스트 오버라이드 인자 die. sudoers(외부)+가드(내부) 다층. 커밋만 남음.

### 🔴 HIGH
**B-3 — packages write-time sha + append-only**
- publish-update.sh: packages 배치 **전** `sha256(zip)==manifest.sha256` 강제(이미 입력검증 있으나 배치 직전 재확인) + 기존 packages 파일 덮어쓰기 금지(존재 시 die, `--allow-republish`는 sudo에서 이미 B-2로 차단).

**B-4 — NCP 독립 재조회 (관통결함 급소)**
- deploy-update.yml deploy잡 또는 NCP 래퍼: 서명 직전 (a) commit이 main 조상인지 `git`으로 직접확인 (b) run_id·아티팩트 digest를 **GitHub API 직접조회** (c) deployment approval status GitHub API 조회. "메타 값 ≠ 독립조회 값"이면 abort.
- 산출물: deploy-update.yml + publish-run.sh 내 검증 훅.

**B-5 — self-check 결정적/비결정적 구분**
- publish-update.sh 자기검증: 서명검증 실패(결정적)=즉시 롤백 / 네트워크 5xx(비결정적)=N회 폴링 후만 롤백. (전파지연을 실패 오판→전고객 중단 방지, #27)

**B-6 — zip 200 캐시버스터**
- publish-update.sh:285 zip 확인에 캐시버스터+no-cache 추가. downloadUrl 실제 GET→sha256==manifest.sha256 재확인(반쪽 게시 검출).

**B-7 — 액션 SHA 핀**
- deploy-update.yml(신규)·deploy-ncp.yml·trufflehog.yml 전 액션 40자 SHA 핀(`@<sha> # v5.x`). `trufflehog@main` → SHA 핀. Dependabot(github-actions) 설정 + CODEOWNERS 갱신루프.
- 산출물: 워크플로 YAML들, `.github/dependabot.yml`.

**B-8 — SSH 페이로드 안전 + version 재검증**
- deploy-update.yml: 힙독 변수보간 금지, deploy잡 진입 시 `VER` `^[0-9]+\.[0-9]+\.[0-9]+$` 재검증(fail-closed), 원격 인자 `printf %q`/stdin.

**B-9 — deploy-web.sh 롤백 exclude**
- deploy-web.sh 롤백 rsync에도 `--exclude appsettings.Production.json`·`.Development.json` 적용(시크릿 회귀 차단). 최초배포 실패 시 시크릿 복구 경로 명시.

**B-10 — branch protection (→BLOCKING)**
- 트랙2(GitHub): protection rule(Require CODEOWNER review + 셀프머지 금지)을 dispatch 활성화 **전** 강제.
- **단 gisskso-lab=단일User라 SoD 구조 미성립**(방아쇠=승인=사장님1인) 명문화. Org 전환 전 2인서명 불가 → 정식숙제-2와 연결.

### 🟡 MEDIUM
**B-11 — Secret 전환 concurrency**
- 트랙2: 교체 직전 대상 워크플로 큐정지→교체→재활성. deploy-update.yml에 `concurrency:{group,cancel-in-progress:false}` 상시 배선(트랙1).

**B-12 — 운영시크릿 아티팩트 미포함 게이트**
- deploy-update.yml deploy잡 시작(다운로드 후): update zip에 `appsettings.Production/Development.json`·`.pem`·`.pfx`·`db.conf`·`hitpan-keys.conf` 스캔→발견 시 fail. appsettings.json 실 커넥션스트링/비번 스캔.

**B-13 — kid 도달불가 fail-closed**

**B-14 — 불변 staging**

**B-15 — 원자성 2파일 경계**

**B-16 — 백업 retention + free-space (→BLOCKING)**
- 트랙2(NCP): 디스크 96.8% 실측. 백업 세대 N개 보관 + 배포 전 free-space 프리플라이트 게이트. **곧 닥칠 상시사고라 착수 전 필수.**
- 트랙1: publish-update.sh·deploy-web.sh에 free-space 체크 + `.bak` 세대정리.

### 🟢 LOW
