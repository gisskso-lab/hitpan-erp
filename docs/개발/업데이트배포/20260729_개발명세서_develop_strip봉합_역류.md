## 2. 어떻게 했나 (헌법 #1 준수 방법)

**main 활성본을 통째 복사하지 않았다.** 작업지시서 §7 리스크 1번 방어:

```
① main blob(d80d249) 추출 → CRLF/LF 정규화
② develop .disabled 와 diff  →  추가 29줄 / 삭제 0줄 확인
③ 삭제 0줄임을 확인한 뒤에만 착수   ← develop 고유 내용 덮어쓰기 없음 보증
④ 누락분 29줄만 Edit 으로 삽입
```

> 정규화를 안 했다면 diff 가 **392줄 전체 교체**로 보였다(CRLF/LF 차이).
> 그대로 갔으면 develop 고유 헤더 주석을 통째 덮어썼을 것 — **헌법 #1 위반.**
