## 1. 실제 착수·커밋된 범위 (커밋 a2c249f, 8파일 1016+/37-)

### W4-2 · 파일 교체 스왑 (`UpdateOrchestrator.cs`)

- **B안 마이그게이트**(스왑 前): `RequiresMigration=false`인데 `extract\api\Migrations\SQL\*.sql` 존재 → 강제 중단. `.sql`에 `local_update_` 있으면 중단(구버전 워치독 보호).
- 부분성공 즉시 역복원(헌법 #20). 열린핸들 진단(HRESULT 32/5 + tasklist, 헌법 #15).
- `{app}` = `AppContext.BaseDirectory\..`(워치독 EXE는 `{app}\watchdog\` 설치 — .iss:105·DbConfReader.cs:119 실측).

### W4-4 · 재시작 (`UpdateOrchestrator.cs`)
- `WS28I_FourProcess.TryRestartTask`(`schtasks /Run`) **그대로 재사용**. **api→web** 기동(스왑과 비대칭 — "API가 서야 ERP가 산다"). keepalive 복원.
- DI: `WS28I_FourProcess` 생성자 맨 뒤 주입(이미 싱글턴 등록, 순환 없음).

### W4-5 · 검증·롤백 (`UpdateOrchestrator.cs`, `UpdateClient.cs`)
- **2중 판정**: `/health` 200 AND `checks.version`==신버전(2초×60초 폴링) **AND** 교체된 `{app}\api\HitPan.API.dll` FileVersion==신버전. **200만으론 불통과**(구버전도 200). Web은 판정 안 함.
- 롤백: 신버전 정지 → `api.old→api`·`web.old→web` 복원 → keepalive ENABLE+재기동 → 구버전 생존확인. 신버전은 `.failed`로 치움(.old 안 날림).
- **DB 자동복원 안 함**(대표 결재 #3). `IsSameVersion`(3자리 정규화 재사용, `UpdateClient.cs`).

### W4-6 · 상태기록·통지 (`WatchdogStatusWriter.cs`·`WatchdogConsentReader.cs`·`WatchdogBackupRunner.cs`·`Worker.cs`·`UpdateClient.cs`)
- `local_update_apply_status` UPSERT(멱등키=버전, 자가생성 `CREATE IF NOT EXISTS`). result=success|rolled_back|rollback_failed|blocked.
- 롤백실패 → `MetaPingClient.NotifyEmergencyAsync("update_rollback_failed")` (본사 가시성, 헌법 #30 통지만).
- 펜딩 인메모리 소실 복원(하루게이트 개방만, 부분manifest 안 만듦 = 서명우회 없음).

- mysqldump PATH 봉합(고정경로 우선→PATH 폴백, SYSTEM 권한상승 차단) 3파일 통일.

### DDL (`installer/hitpan_db_clean.sql`·`scripts/ddl-smoke-test.sh`)
