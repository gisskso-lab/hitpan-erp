> 이걸 모르고 했으면 "수신 실패"로 오판하고 없는 진범을 쫓았을 것이다.
> (§6-4 위험이 여기서 **해소**됐다 — 기다림 부족 오판 방지)

### 1-5. PR #13 이 이 게시를 막는가 — **막지 않는다** (검사함)

PR #13 = `deploy-update.yml` 의 strip regex 를 게이트와 동형화(백업접미사 `.bak/.old/.orig/.save`).
게시에 쓰는 그 파일이라 **의존성을 의심했고, 가정하지 않고 실측했다**:

```
find installer/payload -type f -name "appsettings*"
→ installer/payload/HitPan.Watchdog/appsettings.json   (1건)
```

| 판정 | 근거 |
|---|---|
| ✅ **PR #13 없이도 1.2.41 게시 가능** | payload 에 백업접미사(`.bak` 등) 파일이 **0건**. 비대칭이 발현할 입력 자체가 없음 |
| 단 PR #13 은 여전히 필요 | 잠복 결함이다. 언젠가 `.bak` 이 생기면 그날 게시가 깨진다 |

> **"막힌다"고 지레짐작했으면 사장님께 없는 선행조건을 보고할 뻔했다.** 실측으로 뒤집었다.
