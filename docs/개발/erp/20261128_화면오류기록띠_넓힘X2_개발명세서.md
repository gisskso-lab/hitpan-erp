## 4. ⚠ 남은 점(합칠 때 PM 판단)

1. **`null` 판정 3자리(계산서 상세 · 휴직 사원 · Users 부서)는 401 · 403 을 못 뺀다** — 서비스가 상태 번호를 버리므로. 403 이면 처리기 알림 「이 기능에 접근할 권한이 없습니다」 와 이 글이 같이 뜰 수 있음(글이 달라 겹침 막음이 안 걸림). 세 자리 다 그 화면 목록을 이미 본 사람이 부르는 조회라 403 가능성은 낮음 · 401 은 처리기가 로그인으로 보냄.
2. **`DeliveryService.GetAsync`(갈래 S 파일)에 기록 없는 `catch (Exception) { return null; }`**(`:392`) — #15 꼴(기록 0). 이 가지 손 0 · X1 · S 쪽에 보고.
3. **반품사유 그리드 2개 기존 결함(이번 고침과 무관 · 손 0)**: 검색이 취소되면(칸에 빨리 쓸 때 MudAutocomplete 가 앞 조회를 취소) catch 가 `_reasonCache = new()` 를 넣어 **그 그리드가 닫힐 때까지 사유 목록이 영영 빈 채**. 이번 알림은 취소엔 안 뜸(`ShouldNotify`) · 고치려면 취소 갈래를 따로 두어야 함 → 별도 보고.
4. 장면 스크립트의 바닥 셈 문제(아래 §5-2) — 바닥 `d54b6e9f` 의 자체시험 B10 이 이미 거짓이었다(CI S9b 가 `rc=1` 로 끝났을 것).
