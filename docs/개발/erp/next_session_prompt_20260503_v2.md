## 검증 테스트 시나리오 (사장님이 직접 처음부터 해보실 것)

**순서대로 해야 워크플로우 무결성 검증 가능:**

1. **설정** → 사원 등록 → 권한 설정
2. **마스터** → 거래처 등록 → 상품 등록 (BOM 선택)
3. **매입** → 발주서 작성 → 매입처리 → 재고 확인
4. **판매** → 견적서 → 수주 → 거래명세서 → 세금계산서
5. **현황** → 재고현황 / 매출현황 / 거래처원장 확인
