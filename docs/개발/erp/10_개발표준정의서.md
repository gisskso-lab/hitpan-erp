## 5. Dapper 사용 표준

### 5.1 EnsureOpen 패턴 (BomService 정합)
```csharp
public async Task<IEnumerable<ItemSpecDto>> GetByItemIdAsync(Guid itemId)
{
    await _uow.EnsureOpenAsync();      // ← 필수 (헌법 #16 정합)
    const string sql = @"
        SELECT
            CAST(spec_id AS CHAR) AS SpecId,    -- ← 진범 #99 봉합
            CAST(item_id AS CHAR) AS ItemId,
            spec_value AS SpecValue
        FROM item_specs
        WHERE item_id = @ItemId AND is_active = 1";
    return await _uow.GetDbConnection().QueryAsync<ItemSpecDto>(sql, new { ItemId = itemId });
}
```

### 5.2 트랜잭션 패턴
```csharp
using var tx = await _uow.BeginTransactionAsync();
try {
    await _uow.GetDbConnection().ExecuteAsync(sql1, p1, tx);
    await _uow.GetDbConnection().ExecuteAsync(sql2, p2, tx);
    tx.Commit();
} catch (Exception ex) {
    tx.Rollback();
    _logger.LogError(ex, "...");
    throw;
}
```

### 5.3 금지 패턴
- ❌ `MySqlConnection` + `Task.WhenAll` (헌법 #16)
