## 5. 안 한 것 / 못 한 것 — 🔴 계약·API 쪽 문제(고치지 않음 · I-API/PM 판정 요)

1. **수동 업데이트 끝 결과가 수동 업데이트 화면에 안 온다** — 계약 §7 은 「GET 이 다음 로그인 뒤 알린다」인데 `ManualUpdateCheckResult` 에 `last` 칸이 없다(되돌리기 GET 에만 있음 · 두 모드 공통 `ReadLast`). 화면 DTO 에 `Last` 칸을 미리 두었다(서버가 `last` 로 실으면 그대로 뜬다). 지금은 수동 업데이트 실패(`reverted`) 안내가 **되돌리기 화면에서만** 보인다. 되돌리기 GET 을 업데이트 화면에서 부르는 우회는 하지 않았다(그 GET 은 확인 번호를 발급하는 부수효과가 있다).
