## 1. 무엇을 고쳤나 — **한 줄 추가**

`src/HitPan.API/Program.cs` CSP 에 `frame-src` 지시문 추가.

```
frame-src 'self' https://t1.daumcdn.net https://postcode.map.daum.net;
```

🟢 **헌법 #1 정합** — 기존 지시문은 **한 글자도 안 고쳤다.** 줄 하나를 **더했다.**
🟢 DDL 0 · 화면 0 · API 0 · 패키지 0.

### 왜 도메인이 둘인가
스크립트는 `t1.daumcdn.net` 에서 오지만 **iframe 문서는 `postcode.map.daum.net`** 에서 온다.
하나만 적으면 여전히 안 뜬다.

### 왜 넓게 안 여나
`frame-src https:` 같은 전체 허용은 **보안 후퇴**다. 필요한 두 곳만 연다(G-47 이 지킨다).

## 2. 검증 — 🔴 **봉합을 실제로 빼서 FAIL 을 봤다**

가짜 게이트 누적 9번 교훈([[feedback_gate_must_test_behavior]]) — *"짜면 곧바로 봉합 빼고 FAIL 확인"*.

| 상태 | 결과 |
|---|---|
| 봉합 있음 | 🟢 **4/4 통과** |
| 🔴 **봉합 제거** (`frame-src` 줄만 삭제, **주석은 남김**) | 🔴 **G-45·46·47 FAIL** |
| 봉합 복구 | 🟢 4/4 통과 |

🔴 **주석을 일부러 남긴 채로 뺐다.** 글자검사 게이트였다면 주석의 `frame-src` 글자에 걸려
   **통과했을 것**이다. FAIL 이 났다는 것은 이 게이트가 **글자가 아니라 동작을 본다**는 증거다.

🟢 **G-48(`frame-ancestors 'none'`) 은 봉합 제거 상태에서도 통과했다** — 정상이다.
   그 줄은 이번에 안 건드렸으므로 **여전히 초록불인 게 맞다.** (초록불이 어디서 오는지 확인함)

### 초록불이 어디서 오나
글자검사가 **아니다.** `Program.cs` 에서 CSP 문자열을 **실제로 조립**해
지시문 사전으로 **파싱**하고, **브라우저와 같은 판정**(지시문 없으면 `default-src` 폴백)을 돌린다.
⇒ 이 폴백이 이번 사고의 원인 그 자체다.

### 짜다가 잡은 내 버그
처음 판정기가 `IndexOf(';')` 로 대입문을 끊었다 — **CSP 문자열 안에 세미콜론이 많아** 첫 지시문에서 잘렸다.
⇒ 4개 전부 FAIL. **봉합이 아니라 시험이 틀린 것**이었다. 다음 대입문(`h["`)까지로 고쳤다.
⚠️ 이걸 *"게이트가 원래 그런가 보다"* 하고 넘겼으면 **가짜 게이트 10번째**가 됐다.
