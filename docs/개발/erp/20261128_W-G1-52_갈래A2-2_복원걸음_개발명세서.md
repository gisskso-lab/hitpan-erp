## §3 붓기 꼴 — (ㄴ) 앱 연결 직접 실행을 고른 까닭
- 변환기가 이미 문장을 나누므로 `mysql` 클라이언트가 할 일이 없다 → `source` · `tee` · `\!` 같은 클라이언트 명령 면 · 실행 파일 찾기 · `MYSQL_PWD` 길이 **통째로 0**(설계 §15-3 ③-3 검토 권고 · R4).
- 바이트 보존: 문장 바이트를 **엄격 UTF-8**(잘못된 바이트면 예외 → 멈춤)로만 글자로 바꿔 보냄 — 올바른 UTF-8 은 왕복 손실 0 · 바이너리 칸은 `--hex-blob` 로 16진(ASCII)이라 따옴표 안 원시 바이너리가 없다(R2 덧 벽).
- 세션: 붓기 전 `sql_mode='NO_AUTO_VALUE_ON_ZERO' · time_zone='+00:00' · foreign_key_checks=0 · unique_checks=0`(덤프 머리와 같은 값) · 끝에 전역 값으로 되돌림(실패면 연결 닫음).
- 두 바퀴: 첫 바퀴 = 끝까지 변환 + 2차 검사(붓기 0) · 둘째 바퀴 = 같은 손잡이 되감아 문장마다 2차 검사 다시 → 실행.
