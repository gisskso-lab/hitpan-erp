  - `FindOnPath` 는 상대 경로 PATH 항목을 건너뛴다 — 설치 PC 에 상대 PATH 로만 MariaDB 가 잡힌 경우가 있는지.
- **회귀 우려**
  - 기본 폴더가 사용자 계정 API 에서는 여전히 문서 폴더(종전 동일), SYSTEM 에서는 `%ProgramData%\HitPan\Backup` 으로 **바뀐다** — 기존 `C:\Windows\System32\HitpanBackup` 의 옛 백업은 옮기지 않는다(교정 후 목록의 옛 파일 경로는 그대로 이력에 남음).
