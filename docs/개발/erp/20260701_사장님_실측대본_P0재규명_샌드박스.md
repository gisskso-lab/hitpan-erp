# 사장님 실측 대본 — 2026-07-01 P0 설치 DOA 진짜 원인 규명

> PM 브라운킴 / 어제 인수인계서 "내일 0초 첫 행동" 실행분
> 한 줄: **샌드박스에서 1.2.16 시리얼 없이 재설치 → 에러로그 3개를 캡처해 붙여주시면, PM이 코드로 좁혀둔 4개 후보(A~D) 중 어느 것인지 한 번에 판정합니다.**

---

## 왜 랜딩페이지가 필요 없는가 (사장님 질문 답)
- 오늘 P0 = **시리얼 없이 설치** 경로 버그. 이 경로는 코드상 「예」 누르는 순간 `TenantCode=LOCAL` 세팅하고 **즉시 Exit** — 백오피스 API(`CallBootstrapApi`)도 랜딩도 **아예 안 탑니다**(HitPan-Universal.iss L559-566).
- 즉 인터넷·랜딩·백오피스 없이 **샌드박스 안에서 EXE만 실행하면 그대로 재현**됩니다.
- 랜딩을 타는 **정상 동선(가입→시리얼 발급→시리얼 설치)** 종단 실측은 이 P0를 살린 **다음** 순서. (사장님 결재: P0부터.)

## 왜 사장님 손이 필요한가
- Windows Sandbox 설치 마법사는 **GUI 클릭**(시리얼 없이 → 「예」 → 완료)이 필요 — 자동화 불가.
- 에러로그가 **유일한 진실원**. PM이 오늘 아침 코드를 다시 정독해 후보를 4개로 좁혔지만, 어느 것인지는 로그만이 확정.
- 그래서 사장님이 **아래 5단계**만 따라 주시고, 마지막 3개 캡처를 채팅에 붙여주시면 됩니다.

---

## 5단계 (그대로 따라가기)

### 1단계 — 샌드박스 띄우기 (반드시 .wsb 더블클릭)
탐색기에서 아래 파일 **더블클릭**:
```
C:\Users\소순근\Desktop\hitpan-erp\tests\sandbox-m4\HitPan-M4.wsb
```
⚠️ 그냥 "Windows Sandbox" 앱으로 띄우면 `C:\dist` 매핑이 안 됩니다. **반드시 .wsb 더블클릭.**
→ 뜨면 안내문 메모장이 자동으로 열립니다(정상).

### 2단계 — 1.2.16 설치 실행
샌드박스 안에서:
```
C:\dist\HitPan-ERP-Setup-1.2.16.exe
```
더블클릭 → 설치 마법사 진행.

### 3단계 — 시리얼 없이 설치
- 시리얼 입력 화면에서 **입력란을 비운 채** 「다음」.
- "시리얼 키를 입력하지 않고 설치하시겠습니까?" → **「예」**.
- 계속 진행 → **"데이터베이스 초기화 실패(코드 1)"** 에러가 뜨면 → **「확인」**.
  (에러가 안 뜨고 설치가 끝나면 → 봉합 적중! 그것도 알려주세요.)

### 4단계 — 에러로그 3개 캡처 (핵심)
샌드박스 안에서 **PowerShell**을 열어(시작 → powershell) 아래를 순서대로 복사·실행하고, **출력 전체를 캡처**:

```powershell
# ① import 에러로그 (진짜 원인 — 유저명·에러코드가 여기 나옴)
Get-Content "$env:TEMP\hitpan_import_err.log" -Tail 40

# ② 실제 기록된 DB 접속정보 (유저명이 hitpan으로 채워졌는지 확인)
Get-Content "$env:LOCALAPPDATA\HitPan\db.conf" -ErrorAction SilentlyContinue
# 위가 비면 아래 경로도 시도:
Get-ChildItem "C:\Program Files\HitPan*" -Recurse -Filter db.conf -ErrorAction SilentlyContinue | ForEach-Object { "=== $($_.FullName) ==="; Get-Content $_.FullName }

# ③ db-setup.bat 실행 흔적 (남아있으면)
Get-Content "$env:TEMP\db-setup.bat" -ErrorAction SilentlyContinue | Select-Object -First 20
```

### 5단계 — 채팅에 붙여주기
①②③ 출력을 **그대로 복사해 채팅에 붙여**주세요. PM이 즉시 판정합니다.

## PM이 볼 신호 = 4개 후보 (사장님은 참고만)

| 후보 | ①에러로그 신호 | 뜻 | PM 봉합 방향 |
|---|---|---|---|
| **A 봉합 미실행** | 유저명이 여전히 `-p...`로 깨짐 (`using password: NO`) | L859-860 가드가 실행 안 됨 | 실행경로 재검(예외로 EXE에 반영 안 된 것) |
| **B 비번 불일치** | `Access denied for user 'hitpan'@'localhost' (using password: YES)` | CREATE USER 비번 ≠ 접속 비번 | 비번 변수 흐름 봉합 |
| **C import SQL 오류** | `ERROR 1064/1146/1419...` + 특정 라인 | clean DDL 구문 자체가 hitpan 권한으로 실패 | 해당 DDL 봉합(권한/트리거) |
| **D sandbox mode 제약** | sandbox·권한 거부 문구 | 덤프 첫 줄 `/*M!999999...sandbox mode*/` 제약 | 덤프 스트립 |

> ②의 유저명이 `hitpan`이면 → 후보 A 탈락(봉합은 됐고 그 다음이 문제) → B/C/D로 압축.
> ②의 유저명이 비었거나 이상하면 → 후보 A 확정.
