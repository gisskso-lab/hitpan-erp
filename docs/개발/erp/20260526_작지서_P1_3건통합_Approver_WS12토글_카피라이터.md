## 🔒 P1-① Approver Policy 분리 옵션화 (보안 매니저 1)

### 가도 영역
- **현재**: TenantApprover 별도 역할 (Admin·User·Viewer·Approver 4분할)
- **변경**: 테넌트 설정에서 옵션 ON/OFF
  - **ON (대형)**: 4분할 — User 입력 → Approver 결재 (분리)
  - **OFF (소형 도소매)**: 3분할 — User가 입력·결재 겸함

### DDL (DB 매니저 가도)
```sql
ALTER TABLE tenants
ADD COLUMN approver_separation TINYINT(1) NOT NULL DEFAULT 0
  COMMENT '결재자 분리 (1=대형/4분할 / 0=소형/User 겸함)'
AFTER allow_negative_stock;
```

### Authorization Policy 분기
```csharp
// TenantUserPolicy
.RequireAssertion(ctx => {
    var tenant = ctx.User.GetTenant();
    if (!tenant.ApproverSeparation)
    {
        // OFF: User도 confirmed 전환 권한 보유
        return true;
    }
    // ON: User는 draft까지만, confirmed는 Approver
    return ctx.Resource is DraftOnlyResource;
})
```
