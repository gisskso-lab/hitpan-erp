## 6. 🔴 전제 교정 (병렬검증 [3-V] 수용)

- **「`system_admin` 이라 403 이어서 작은 글씨만 보였다」는 주 경로가 아니다** — 메뉴로 들어온 사람은 403 을 안 받는다(403 은 주소 직접 입력뿐).
- **안내는 두 화면에 다 있었고, 약했던 것은 갈래다**(`FormTemplateEditorDialog.razor:213` 당시 · `PrintSettingsPage.razor:105~110`) — **없던 것이 아니다.**
- 이 PC 실측으로 `company-images` 가 **빈 폴더** ⇒ 사장님 상태는 **`missing`** 이었을 가능성이 가장 크다. 그래서 이번 봉합의 중심은 **`missing` 이 눈에 들어오는 모양인가**다.

### 6-1 상태 네 칸 — **전 / 후** (🔴 [4] 검증의 입력)

| 상태 | 전 — UI · 자리 · 조건 | 후 — UI · 자리 · 조건 |
|---|---|---|
| `present` | 아무것도 안 그린다 · — · — | **그대로**(아무것도 안 그린다) — 재료가 있으니 말할 것이 없다 |
| `missing` | `MudAlert Warning` **`Dense`(한 줄 작은 알림)** · 라디오 바로 아래(펼침 없음) · `_wmMode != off` | 🔴 **`MudAlert Error` + `Variant.Filled` + 제목(`subtitle1`) + 본문(`body2`)** · 자리 같음 · 조건 같음 |
| `unusable`(화면 enum `Outside`) | `MudAlert Warning` **`Dense`** · 같은 자리 · `_wmMode != off` | 🔴 **`Error` + `Filled` + 제목 + 본문** · 자리·조건 같음 |
| `unknown` | 🔴 **`MudText Typo.caption` 회색 작은 글씨**(알림 아님) · 같은 자리 · `_wmMode != off` | 🔴 **`MudAlert Warning` + `Filled` + 제목 + 본문**(큰 경고) · 자리·조건 같음 |

**조건 가림 여부(좁은검증 W-4 미판정 건)** — 측정 결과:
- 네 갈래는 **서로 배타적**이다(`_logoState` 한 값) ⇒ 앞 조건이 뒤를 가리지 않는다.
- 공통 가림막은 **`_wmMode != WmModeOff` 하나**다 ⇒ 기본값 `common`(공통 따름)에서 **켜기 전에 보인다.** 고객이 「이 양식만 끄기」를 고른 경우에만 안 보이고, 그때는 안 깔리는 것이 고객 뜻이다.
- 또 하나의 가림막은 **세금계산서**(`_isTaxInvoiceForm`) — 워터마크 절 자체가 안 열린다(결재 결-K 대로 · 합격선 5).
- 🔴 **접힌 절 안이 아니다** — 워터마크 라디오 바로 아래, 펼치는 동작 없이 보인다.
- ⚠️ **안 바꾼 것**: 경고가 뜨는 조건 자체(`_wmMode != off`)와 `_logoState` 를 읽는 통로는 손대지 않았다(#1 · W-C 소관).

## 7. 🔴 W-D 가 재야 할 축 (시험 파일은 W-D 소관 · 본 갈래 `tests/` 0건)

작업지시서 §5-3 의 6축 중 **W-B 가 받치는 축 4개**와, 그 축을 **음성 대조군으로 빨개지게 만드는 방법**:

| 축 | 재는 것 | 🔴 음성 대조군(버그를 되살려 빨개지는지) |
|---|---|---|
| ⓐ `plain`+그림 좌표 | 빈 A4 + 그림 + 좌표 1줄 ⇒ 화면에 **좌표 표가 열리고** 서버 PDF 에 그 칸이 찍힌다 | `_plainCoordsOpen` 조건을 다시 `preprint` 전용으로 좁히면 표가 사라져 **빨개져야** 한다 |
| ⓑ `preprint` 이중 인쇄 음성 | `preprint` 새 양식에 그림을 올려도 `print_background` 가 **`false` 그대로** · 저장 본문에 `PrintBackground=true` 가 **안 간다** | 제안 조건에서 `PaperMode != "preprint"` 를 빼면 **빨개져야** 한다(이것이 B-2 사고의 모양) |
| ⓒ 로고 없음 경고 | `missing`·`unusable`·`unknown` 세 값 각각에 **큰 경고가 그려진다** — 🔴 **글자 유무가 아니라 「큰 경고 요소인가」**(`MudAlert` + `Filled` + 제목)를 못으로 박는다. `present` 는 **0건**(대조군 축) | `unknown` 을 다시 `MudText caption` 으로 되돌리면 **빨개져야** 한다. 🔴 「문구가 있다」만 세면 **이번 반려를 그대로 통과한다** |
| ⓔ 저장 전 상태 | ① 업로드 후 양식 행이 **안 바뀐다**(DB/API 조회로) ② 꼬리표가 **그려진다** ③ 닫기에서 **되묻는다** ④ 저장 성공 후 꼬리표가 **사라진다** | 업로드 핸들러에서 `_bgUnsaved = true` 를 지우면 ②③ 이 **빨개져야** 한다 |

- **이미 저장된 양식**(`TemplateId` 있음)을 열어 그림만 다시 올려도 `PrintBackground` 가 **안 바뀐다** ⇒ 바뀌면 반려.
