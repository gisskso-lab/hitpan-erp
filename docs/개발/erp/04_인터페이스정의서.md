> **작성일**: 2026-06-01 / PM 브라운킴

> **Base URL**: `https://api-demo.hitpan.kr` (베타) / `http://localhost:5257` (개발)

---

## 1. 공통 규약

### 1.1 인증
- **JWT Bearer 토큰** (Authorization 헤더)
- Access Token 만료: 15분
- Refresh Token: 7일 (회전)
- 토큰 클레임: `tenant_id`, `user_id`, `role`, `email`

### 1.2 role 매핑 (헌법 #7)
| DB Role | JWT claim role | 의미 |
|---|---|---|
| `TenantAdmin` | `system_admin` | 테넌트 어드민 (사장) |
| `tenant_admin` | `system_admin` | 동일 |
| `Employee` | `employee` | 일반 사원 |

### 1.3 응답 형식
```json
// 성공
{ "items": [...], "totalCount": 137 }   // 페이징
[...]                                    // 단순 리스트
{ ... }                                  // 단일 객체

// 실패
{ "error": "...", "details": "..." }
```

### 1.4 상태 코드
- 200 OK
- 201 Created
- 204 No Content
- 400 Bad Request (validation)
- 401 Unauthorized (토큰 없음/만료)
- 403 Forbidden (역할 부족)
- 404 Not Found
- 409 Conflict (멱등성 충돌)
- 500 Internal Server Error

### 1.5 Idempotency
- POST 요청: `Idempotency-Key` 헤더 권장
- `IdempotencyMiddleware`가 중복 차단

### 1.6 약관 동의 차단
- `TermsConsentMiddleware`가 미동의 사용자 `/terms` 강제

## 3. 주요 endpoint 상세

### 3.1 인증
```
POST /api/auth/login
Body: { email, password }
Response: { accessToken, refreshToken, userName, requiresTermsConsent }

POST /api/auth/refresh
Body: { refreshToken }
Response: { accessToken, refreshToken }

POST /api/auth/logout
Header: Authorization: Bearer ...
Response: 204
```

### 3.2 약관 동의
```
GET /api/auth/terms/required
Response: { items: [{ type, version, mandatory }] }

POST /api/auth/terms/consent
Body: { consents: [{ type, version, agreed }] }
Response: 201
```

### 3.3 상품 + 규격
```
GET /api/items?pageSize=20&page=1
Response: [...] (배열 직접 반환)

GET /api/items/{itemId}/specs?activeOnly=true
Response: [{ specId, itemId, specValue, isDefault, sortOrder }]

POST /api/items/{itemId}/specs
Body: { specValue, isDefault, sortOrder }
Response: 201
```

### 3.4 견적·수주·매입 (워크플로우)
```
POST /api/quotations
Body: { partnerId, items: [{ itemId, specValue, quantity, unitPrice }], memo }
Response: 201 { quotationId }

POST /api/sales/orders/from-quotation/{quotationId}
Response: 201 { salesOrderId }

POST /api/delivery
Body: { salesOrderId, items: [...] }
Response: 201 { deliveryId } + stock_ledger -N + journal_lines INSERT
```

### 3.5 BOM 생산
```
POST /api/bom/{bomId}/produce
Body: { quantity }
Response: 201
  → 동일 트랜잭션:
  → stock_ledger +N (완제품)
  → stock_ledger -각각 (자재)
```

### 3.6 결재
```
POST /api/approval/request
Body: { documentType, documentId, lineId, comment }
Response: 201

POST /api/approval/{approvalId}/approve
Body: { comment }
Response: 200

POST /api/approval/{approvalId}/reject
Body: { reason }
Response: 200
```

### 3.7 마이그 (SignalR)
```
POST /api/migration/start
Body: { mdbPath, options }
Response: 202 { jobId }

SignalR Hub: /hubs/migration
Event: ProgressUpdated { jobId, percent, currentTable, processed, total }
Event: Completed { jobId, summary }
Event: Failed { jobId, error }
```

## 4. 외부 시스템 인터페이스

### 4.1 Cloudflare 터널
- 프로토콜: cloudflared (UDP 7844)
- 도메인: `https://{tenant}.hitpan.kr` (베타: `hitpan-{tenant}.workers.dev`)
- 인증: TunnelSecret (DPAPI 보호, 헌법 #28 자동 복구)

### 4.2 토스페이먼츠 (SaaS 결제)
- BillingController가 호출
- 본사 서버 측 결제만 (고객 PC에서 호출 금지, 헌법 #18)

### 4.3 카카오/토스/금융/PASS (간편인증)
- ESignController가 통합
- 헌법: 공인인증서 미사용

### 4.4 메이크빌 ASP (전자세금계산서)
- TaxInvoiceController L2 계층
- 3차 외부 베타 자문 협력사

### 4.5 홈택스 API (선택, 외주 검토)
