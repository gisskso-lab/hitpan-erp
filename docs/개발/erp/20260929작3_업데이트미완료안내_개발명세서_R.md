## §2 설계에서 한 발 더 간 곳 (사실만 · 검증 대상)
- **`AlreadyUsed` 구분**: 설계는 「in_progress 기록 실패 → Z-1」만 적었다. UNIQUE 위반(1062)은 「그 [예]는 이미 시도했다」는 **확정 신호**라 Z-1(3루프 뒤 적용)에 태우면 G-R7(적용 1회)과 충돌한다 ⇒ 1062 는 적용 안 함·펜딩 해제, 그 밖의 실패만 Z-1. 판정 = stderr 에 `ERROR 1062`/`Duplicate entry`.
- **값 해석 실패도 Z-1**: 판독 줄 해석 실패 시 동의 표만 다시 읽어 `AttemptsUnknown=true` 로 돌린다. `ParseLatestWithUsage` 자체는 무변경(기존 시험 그대로).
- Z-1 내려앉음 뒤 같은 동의 id 는 다시 3루프 보류 후 인메모리 집합으로 「이미 씀」 처리(재적용 0 — G-R5 확인).
