## 5. 안 바꾼 것 · 남은 위험

- 브라우저 장면은 이 PC 에서 안 돌림(실물 DB) → 새 장면 3 · 알림 칸은 CI 첫 런이 처음 잼. 위험: ① 상주 · 짝 장면(quiet)은 「그 밖 알림 0」 이라 CI 환경에서 대시보드 등이 다른 알림을 띄우면 빨강(이전 런 로그상 G-R1a/b 다른 알림은 기록만이라 0 확인 못 함) ② once 「정확히 1」 은 MudBlazor 중복 막음에 기댐 — 같은 글이 첫 알림이 사라진 뒤 다시 오면 2(진짜 두 번이면 맞는 빨강) ③ G-X1o 는 백업 설정 조회가 CI 에서 2xx 여야(아니면 장면 무효 빨강) ④ 알림 맞춤을 앞머리 고정으로 좁힘 — 알림 부품이 글 앞에 다른 글자를 붙이면 0.
- HR 3화면 403 · 취소 = 빈 목록(알림 0 · 처리기 「권한 없음」 은 뜸) — 넓힘 X2 의 다른 OrNull(부서 등)은 403 도 null(알림)이라 꼴이 조금 다름(이 고침은 §8-5 #6 「같은 403 거름」 쪽을 따름).
- 넘김 그대로(§8-5 #9 대장): 기록 양(`ex.ToString()`) · 기존 `ex.Message` 알림(백업) · 기록 없는 catch · 인쇄 공통 설정 저장 안 막힘 · 백업 [설정 저장] 막힘 뒤 [다시 불러오기] 없음([3-V] P3-6) · `BackupPage` 설정 실패 `Show` 뒤 같은 글 `Add`([4] P3-2 · 중복 막음에 기댐).
