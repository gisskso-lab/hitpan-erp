## ⚠️ 박제 영역 3가지 (레거시 자체 결함 — 봉합 불가)

### 1. 회계 분개 라인 13.3% 누락
- **현상**: 일부 전표의 분개 상세 라인이 조회되지 않을 수 있음
- **원인**: 레거시 30년 누적된 source_id 중복 3,667건 (원본 결함, 봉합 5종 시도 모두 효과 0)
- **영향**: ❌ **일별·월별·연간 합계 보고서는 100% 정확** (전표 헤더 기준)
- **봉합 시도 5종**: 옵션 A (BulkCopy 재시도), B (row-by-row), C (staging INDEX 캐시), D (SHOW CREATE TABLE 파싱), E (DISTINCT 원본 중복 제거) — 모두 실패
- **권장 조치**: 베타 기간 신규 분개는 100% 정상 입력. 과거 분개 누락이 운영에 영향이 있으면 본사 CS 문의

### 2. 세금계산서 21쌍 누락 (-0.03%)
- **현상**: 1996~2025년 발행된 세금계산서 66,631건 중 21쌍 누락 (66,610 적재)
- **원인**: 레거시 원본 21쌍이 (TX_NO + TX_SEQ + TX_PDT + TX_REM) 컬럼까지 100% 동일 — 사실상 같은 거래
- **봉합 시도 2종**: 옵션 A (invoice_no suffix), F (TX_REM hash 추가) — 모두 효과 0
- **영향**: ❌ 매출 합계·세무 신고는 100% 정확
- **권장 조치**: 신규 세금계산서 발행은 100% 정상. 과거 21쌍은 원본 결함으로 박제

### 3. 카드 사용 이력 2,262건 별도 보존
- **현상**: 레거시 카드 결제 헤더 106건은 100% 적재. 카드 사용 이력 2,262건은 신ERP 모델에 매핑 불가
- **원인**: 레거시 DOCCD(카드 결제) ↔ DOCCD1(카드 사용 이력) 두 테이블 간 외래 키 관계 없음. 단 3장의 카드(국민·외환·카드)에 사용 내역 2,262건 모두 묶임
- **영향**: ❌ 카드 결제 자체는 100% 적재. 사용 이력은 별도 archive 저장 (운영 무관)
- **권장 조치**: 신규 카드 결제는 100% 정상. 과거 카드 사용 이력은 별도 백업 보존
