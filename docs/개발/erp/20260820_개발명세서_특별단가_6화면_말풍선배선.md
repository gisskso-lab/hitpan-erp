## 2. 🔴 지켜야 할 축 3개 (다음 사람 필독)

### 2-1. 자동 적용에 끼는 축은 **업체특별단가 하나뿐**
상품특별단가는 **말풍선에 보여주기만** 한다(사장님: *"상품 특별단가는 존재 자체가 큰 의미가 없네"*).
🔴 여기 끼워 넣으면 **우선순위 다툼**이 되살아나고, 그것이 **초안이 폐기된 이유**다. → **G-53** 이 지킨다.

### 2-2. 판 값과 산 값은 **다른 금액**이다
`IsPurchase` 가 최종단가 출처를 가른다 — 매입계열 `purchase_receipt_items` / 판매계열 `sales_delivery_items`.
🔴 섞이면 **매입 화면에 판 가격이 뜬다.** → **G-51** 이 지킨다.

### 2-3. 값이 없으면 **`null`. 0 아니다**
0 으로 그리면 **진짜 0원과 구별이 안 된다.** 경리가 0원을 실제 단가로 믿고 확정하면 매출이 0 으로 잡힌다.
`RenderRow` 가 `null` 이면 **줄 자체를 안 그린다.** → **G-54** 가 지킨다.

### 2-4. 기존 동작을 **없애지 않았다** (헌법 #1)
업체특별단가가 **없으면** 종전대로 표준단가(판매)·매입단가(발주)로 채운다.
채운 값을 **잠그지 않는다** — 사람이 지우고 다시 칠 수 있다.
