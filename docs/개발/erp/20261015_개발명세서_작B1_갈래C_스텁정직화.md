  호출자 입장에서 맞는지 **내 판단이라 의심해 주시기 바란다.**
- **특히 봐줬으면 하는 곳 2** — `:74`(열쇠 있고 provider 가 `ses`/`sendgrid`)를 `stub_mode` 로 적었다.

  더 정직하다고 보실 수도 있다 — 다만 §5 G4 숫자가 **사유코드 2종**이라 2종에 맞췄다. **판정 부탁한다.**

  이 전제가 틀리면 — 즉 어딘가 `IEmailSender` 를 주입해 `Success` 를 보고 분기하는 코드가 있으면 —
