## 1. 꼴(전 줄 공통 · 설계 §2)

- 화면 · 부품마다 `@inject ILogger<자기 이름> Logger` 1줄(파일 머리 `@inject` 무리 끝). 예외 2:
  - `EmployeePage.razor.cs` = 같은 파일 기존 꼴로 `[Inject] private ILogger<EmployeePage> Logger { get; set; } = default!;`
  - `MobileDocList.razor` = `@typeparam TItem` 부품이라 `ILogger<MobileDocList<TItem>>`(빌드가 잡음 · CS0305)
- 바꾼 줄 = 바로 위에 `// ⬛ [낡은 줄 · 화면오류기록띠] Console.Error.WriteLine(…);` 로 옛 줄 그대로 남김(#1 · E3) → 그 아래 `Logger.LogWarning(ex, "[표지] 무엇을 못 했나")`.
  - 표지 `[…]` 는 옛 줄 글자 그대로(게이트가 `console.warn` 에서 그 글자로 찾음) · `{ex.Message}` · `GetType().Name` 은 글에서 빼고 `ex` 를 첫 인자로(설계 §2-2).
  - 옛 줄이 `[HP15]` 표지만 있던 자리(현황 화면들)는 `[HP15] {화면 이름} 조회 실패` 꼴로 무엇을 못 했는지만 덧붙임.
  - 서버 거절(ⓑ) 1줄 = 틀 + 값: `LogWarning("[FormBackground] 저장 뒤 그림 파일 지우기 거절 ({Status})", (int)resp.StatusCode)`.
  - 값이 글에 있던 2줄 = 틀 + 값: `PrintSettings` 그림 올리기 · 지우기 실패 `({Kind})`, `kind`.
  - 예외 없는 1줄(`FormTemplateEditorDialog` 양식 번호 못 읽음) = `LogWarning("[FormYTemplate] …")`.
  - 한 줄 catch 2자리(`FormPreview` · `DocPreview` 주소 거두기) = ⬛ 주석 줄 + 같은 한 줄 catch 를 `LogWarning` 으로.
- `LogError` · `LogCritical` · `Console.SetError` 0(E1). `@using Microsoft.Extensions.Logging` 더하지 않음 — `.razor` 는 빌드 0/0 으로 불요 확인(설계 §10 #4 닫음). `.cs` 서비스 1개(`PartnerMasterService.cs`)만 같은 폴더 선례(`AbsenceService.cs`)대로 `using` 1줄.
