### 2-2. 🔴 P0 — 로고·인장·헤더를 등록해도 저장되지 않는다

**화면은 "등록되었습니다"라고 말한다. 실제로는 새로고침하면 사라진다.**

#### 무엇을 확인했나

| 확인 | 위치 | 결과 |
|---|---|---|
| 업로드 → 미리보기 | `UserInfoPage.razor.cs:314-336` | ✅ base64 로 화면에 표시됨 |
| 성공 메시지 | `:319` `"로고가 등록되었습니다."` | ✅ **뜬다** |
| 저장 시 서버 전송 | `:382-398` `ApplyAsync` | 🔴 **Logo/Seal/Header 필드 없음** |
| 코드 자백 | `:381` 주석 | *"이미지 미리보기 등은 별도 저장 대상 아님"* |

즉 **미리보기용 base64 가 메모리에만 있다가 화면을 떠나면 소멸**한다.

#### 🔴 더 중요한 사실 — 저장할 곳이 이미 만들어져 있다

이건 "아직 안 만든 기능"이 아니다. **만들어 놓고 연결을 안 한 것**이다.

| 계층 | 상태 | 근거 |
|---|---|---|
| DB 컬럼 | ✅ **있다** | `installer/hitpan_db_clean.sql:3585` `tenants.logo_url varchar(200)` |
| 서비스 SELECT | ✅ **있다** | `CompanyService.cs:39` `logo_url AS LogoUrl` |
| 서비스 UPDATE | ✅ **있다** | `CompanyService.cs:84`, `:134` `logo_url = @LogoUrl` |
| DTO | ✅ **있다** | `CompanyDtos.cs:16`, `:42` `LogoUrl` |
| API 라우트 | ✅ **있다** | `CompanyController.cs` — `Route("api/company")` |
| **프론트 호출** | 🔴 **0건** | `grep '"api/company'` → **검색 결과 없음** |

화면은 로고 필드가 **없는** 쪽(`api/settings/company`)만 부른다.
**백엔드까지 다 깔아놓은 길을 프론트가 안 쓰고 있다.**

#### 사용자가 실제로 겪는 것

```
1. 회사 정보 → [인장 등록] → 파일 선택
2. "인장이 등록되었습니다" ← 성공했다고 믿는다
3. 미리보기에 인장이 보인다  ← 더 확신한다
4. [적용] 누른다 → "사용자정보설정이 적용되었습니다"
5. 다른 메뉴 갔다 돌아온다 → 인장이 사라져 있다
```

**심각도 P0 근거**: 성공했다고 말하고 실패한다.
아무 말 없이 안 되는 것보다 나쁘다 — 고객은 등록됐다고 믿고 넘어간다.

> 💡 다만 **어디에 쓰이는지는 아직 미확인**이다.
> 인쇄 양식(견적서·거래명세서)이 인장을 실제로 참조하는 코드는 **찾지 못했다**(`grep "인장"` → 0건).
> 저장이 안 되니 쓰는 쪽도 안 만들어졌을 가능성이 있다. **수정 범위 결정 전에 확인 필요**(§5).

## 5. 🔴 사장님께 여쭐 것 — 로고·인장 수정 범위

**어디까지 고칠지에 따라 작업량이 크게 다르다.** PM 이 임의로 정하지 않는다.

| 안 | 범위 | 결과 |
|---|---|---|
| **(가)** | 버튼→파일선택 연결 + `api/company` 로 로고 저장 | 로고가 저장·유지된다. **인장·헤더는 DB 컬럼이 없어 그대로 안 됨** |
| **(나)** | (가) + `tenants` 에 인장·헤더 컬럼 추가(ALTER) | 3종 다 저장된다. DDL 변경 → 헌법 #36·#9 결재 필요 |
| **(다)** | 지금은 **버튼을 감춘다** | 안 되는 걸 "된다"고 말하지 않게 된다. 기능은 나중에 |

**PM 의견은 (나)입니다.** 이유는 —
인장은 **거래명세서·견적서에 찍혀야 하는 것**이라 ERP 에서 빠질 수 없고,
지금 DB·서비스·API 가 로고 기준으로 **이미 절반 이상 깔려 있어** 인장·헤더 2컬럼만 붙이면 됩니다.
(다)는 가장 싸지만, 베타에서 고객이 *"인장 넣는 데가 없네"* 를 먼저 겪습니다.

⚠️ **단, (나) 전에 확인이 하나 필요합니다** — 인쇄 양식이 인장을 실제로 참조하는 코드를
아직 못 찾았습니다. 저장만 되고 **찍히지 않으면 반쪽**이라, 인쇄 쪽까지 같이 봐야 완결입니다.
