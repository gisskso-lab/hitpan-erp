**원인 가설 — 탐침이 스스로 캐시를 얼린다**
- `information_schema.INNODB_TRX` 는 서버 중간 캐시를 읽고, 그 캐시는 **마지막으로 읽힌 지 0.1초가 넘어야만** 새로 채워진다. 출처: MariaDB 11.4 `storage/innobase/trx/trx0i_s.cc` — `CACHE_MIN_IDLE_TIME_NS 100000000` · `can_cache_be_updated()` = `now - last_read > 0.1s` · **`trx_i_s_cache_end_read()` 가 읽을 때마다 `last_read` 를 갱신**(MySQL 매뉴얼 「refreshed only if more than 0.1 seconds has elapsed since the last time the buffer was read」와 같은 동작). ⚠️외부 출처 판독 — 이 PC `hitpan` 계정은 `PROCESS` 권한이 없어(`SHOW GRANTS` 확인) 직접 못 쟀다.
