## ③ 서버 접속 → 서명·원자게시·자기검증 (publish-update.sh 가 다 함)

```powershell
ssh -i hitpan-key.pem root@211.188.58.140
```
접속되면 서버에서:
```bash
sudo bash /root/publish-update.sh \
  --zip      /root/hitpan-1.2.34.zip \
  --manifest /root/manifest-1.2.34-unsigned.json \
  --webroot  /var/www/updates
```
> ⚠️ **`--webroot /var/www/updates` 꼭 붙일 것** — 스크립트 기본값(`/var/www/updates.hitpan.kr`)은 이 서버 실제 웹루트(`/var/www/updates`)와 다름. 안 붙이면 엉뚱한 폴더에 게시됨.

publish-update.sh 가 자동으로: 다운그레이드 게이트(1.2.34 > 1.2.30 통과) → 개인키 서명 → 원자 교체(tmp→mv, 백업) → 자기검증(공개키 verify + zip 200) → "배포 완료" 출력.
