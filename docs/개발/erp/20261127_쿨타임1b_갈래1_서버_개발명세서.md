## §5 못 한 것 · 결재 필요 (🔴 PM)

1. 🔴 **규칙 ④(설정 시각 뒤 로그인 = 로그인 1시간 뒤부터 묻기 · C-4 (나)) 보류 — 설계 문장 그대로면 모든 낮 로그인이 1시간 뒤 팝업을 받는다.** `C` = 「가장 최근에 지난 설정 시각」 이라, 22:00 설정 회사에서 오늘 09:00 로그인은 `C`(어제 22:00) **뒤** 로그인이 되고 10:00 에 물음이 뜬다(02:00 같은 새벽 설정이면 낮 로그인 전부). 설계 예(22시 뒤 23시 로그인)만 걸러낼 경계가 문서에 없어 임의로 정하지 않았다(#33). 지금 동작 = (가)(그날은 안 묻고 다음 설정 시각에 ③) — 23시에 들어와 잊은 PC 는 종전처럼 마지막 사용 + 8시간까지 남는다(회귀 없음). 경계(예: 「`C` 뒤 n시간 안 로그인만」 · 「정시 퇴근 시각 뒤 로그인만」)를 정해 주시면 `askWhere` 에 OR 한 갈래로 붙인다. ④ 를 재는 게이트는 원래 없다(G-C1~17).
2. API 끝내기 삭제 조건에 `cooltime_asked_at IS NOT NULL` 을 걸었다 — 물음을 받은 로그인만 이 주소로 끝낼 수 있게(낮에 아무 때나 불러 18:00 퇴근을 적는 길을 닫음). 설계는 API 경로 조건을 따로 안 적었다 → PM 확인. `[계속]`·상태·API 끝내기에 `user_id` 를 덧건 것도 같은 결(작2 절K 모양).
3. `TermsConsentMiddleware` 면제에 세 주소를 넣지 않았다 — 약관 미동의 상태로 팝업을 받으면 [계속]이 403 이고 서버 ① 이 끝낸다(안전 쪽). 손 로그아웃은 면제돼 있다 — 맞출지 PM 판단.
