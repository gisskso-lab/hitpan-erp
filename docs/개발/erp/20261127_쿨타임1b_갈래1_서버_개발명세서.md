## §1 계약 — 갈래 ② · ③ 이 붙는 자리 (고정)

> 🔴 이름·주소·값을 바꾸면 화면·게이트가 같이 깨진다. 바꿀 일이 생기면 이 절부터 고치고 PM 결재.

### 1-1 API 3개 — `src/HitPan.API/Controllers/CooltimeController.cs`

모두 `[Authorize]` · 테넌트 = `HttpContext.Items["TenantId"]` · 사용자 = `Items["UserId"]` · 세션 = JWT `sid` 클레임. **요청 본문·주소로 받는 식별자 0**(#2). `TenantMiddleware`·`TermsConsentMiddleware` 면제 목록에 **넣지 않았다**(토큰 필수).

| 주소 | 요청 | 응답 |
|---|---|---|
| `POST /api/auth/cooltime/continue` | 본문 없음 | 200 `{ "snoozeMinutes": 60 }` · 409 `{ "message": "이미 로그아웃되었습니다", "code": "cooltime_already_ended" }`(0행 · `sid` 없는 토큰) · 401(테넌트·사용자 없음) |
| `POST /api/auth/cooltime/logout` | 본문 선택 `{ "trigger": "button" \| "countdown" }`(없으면 button) | 200 `{ "ended": true \| false }`(false = 이미 끝남 — 화면은 어느 쪽이든 저장소 비우고 로그인 화면) · 503 `{ "message": "로그아웃이 완료되지 않았습니다", "code": "cooltime_retry" }`(교착) · 500 `{ "message": "로그아웃이 완료되지 않았습니다" }` |
| `GET /api/auth/cooltime/state` | — | 200 `{ "asked": bool, "secondsLeft": 0~60, "snoozeUntilUtc": "…" \| null }`(세션 행 없음·`sid` 없음 = `asked:false`) |
| 🆕 11/27 E-5 · 세 주소 공통 | 서버가 세션 행을 지운 뒤 | **401** — `SessionValidityMiddleware` 에서 막힘(캐시 최대 10초 뒤) · 컨트롤러까지 안 감 |

🆕 **11/27 E-5 계약 문장**(설계 §E · 갈래 ② · ③ 이 받음): 「서버가 세션 행을 지운 뒤 세 주소는 `SessionValidityMiddleware` 에서 **401**(캐시 최대 10초 뒤) — 컨트롤러의 409 · `ended:false` 는 행이 남은 좁은 틈에서만 나온다. 화면은 셋을 같게 끝남으로 처리한다.」 — 팝업이 떠 있는 동안(또는 `CooltimeEnded` 뒤) 받은 401 · 409 · `ended:false` = 저장소 비움 · 로그인 화면 · 401 본문 문구(「다른 컴퓨터에서…」)는 보여 주지 않는다. G-C14 기대값은 상태별 고정(행 있음 = 200/409/`ended:false` · 행 지움 = 401). ⚠️ E-3 과 맞물림 — 관리자가 팝업 60초 안에 끄면 물음 칸이 비워져 [계속] 409 · 0초 `ended:false` → 화면은 로그인 화면 · 서버 세션은 남는다(같은 PC 다시 로그인이 작2 「두 번째 PC 불가」 에 걸리는지 = 갈래 ③ 확인 거리 · 설계 §E E-5 ⚠️).
