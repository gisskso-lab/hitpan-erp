# 19. 사용자 매뉴얼 — 일반 사용자용 (경리·구매·창고·영업)

> **작성일**: 2026-06-01 / PM 브라운킴 + ERP 매니저
> **대상**: 처음 히트판을 쓰는 직원 (사장님 헌법: 3분 안에 쓸 수 있어야)

---

## 0. 처음 사용하기 (3분 가이드)

### 1단계 — 로그인
1. 사장님께 받은 이메일·비밀번호로 로그인
2. 처음 로그인이면 약관 4개 동의

### 2단계 — 메뉴 찾기
- 왼쪽 사이드바 = 카테고리 (마스터·매입·판매·재고·재무 등)
- 각 카테고리 = 작업 단계 순서대로

### 3단계 — 첫 작업
- 구매담당: 사이드바 [매입] → [발주서] → 신규
- 영업담당: 사이드바 [판매] → [견적서] → 신규
- 창고담당: 사이드바 [재고] → [재고현황]
- 경리: 사이드바 [재무] → [회계]

**모르겠으면**: 우측 하단 "히트판에게 물어보세요" 챗봇 클릭

---

## 1. 매입 업무 (구매담당)

### 1.1 발주서 작성
1. 사이드바 → [매입] → [발주서]
2. "신규" 버튼 클릭
3. 거래처 선택 (검색 또는 ▼ 클릭)
4. 납기일 입력
5. "+ 라인 추가" → 품명 검색 → 선택
6. 규격 콤보에서 선택 (없으면 직접 입력)
7. 수량·단가 입력 (금액 자동 계산)
8. "임시저장" 또는 "확정"

### 1.2 매입 입고
1. 발주서 → "매입 발행" 버튼
2. 입고 창고 선택
3. 실제 입고 수량 확인·수정
4. "확정" → 재고 자동 증가

### 1.3 반품
1. 매입명세서 → "반품" 버튼
2. 반품 사유 선택 (6종 + 메모)
3. 수량 확인
4. "확정" → 재고 자동 차감

---

## 2. 판매 업무 (영업담당)

### 2.1 견적서
1. [판매] → [견적서] → 신규
2. 거래처 선택, 유효기간 입력
3. 라인 추가 → 품명·규격·수량·단가
4. 부가세 자동 계산
5. "PDF" 또는 "메일 발송"

### 2.2 견적 → 수주 → 거래명세서
1. 견적서 → "수주로 변환"
2. 수주서 → "거래명세서 발행"
3. 거래명세서 "확정" → 재고 차감

### 2.3 세금계산서
1. 거래명세서 → "세금계산서 발행"
2. 메이크빌로 자동 전송

---

## 3. 재고 업무 (창고담당)

### 3.1 재고현황 확인
- [재고] → [재고현황]
- 창고별·상품별 필터

### 3.2 재고조정 (실사)
1. [재고] → [재고조정]
2. 상품 검색 → 실제 수량 입력
3. 사유 필수 입력
4. 확정

### 3.3 창고 이동
1. [재고] → [재고이동]
2. 출고 창고 / 입고 창고 선택
3. 상품·수량 입력
4. 확정 (출/입 동시)

---

## 4. 경리·회계

### 4.1 일일 점검
- 출납장 입력
- 카드결제 내역 입력
- 은행 거래 내역 확인

### 4.2 월마감
1. [재무] → [월마감]
2. 모든 거래 확정 확인
3. "마감 실행" → 이후 수정 차단

### 4.3 부가세 신고
- [재무] → [부가세]
- 자동 집계 → 세무사 자동 전송

---

## 5. 결재

### 5.1 결재 요청
- 모든 문서에서 "결재 요청" 버튼
- 결재 라인 자동 선택
- 상태 확인: [결재] → [결재발신]

### 5.2 결재 처리 (결재자)
1. [결재] → [결재대기]
2. 문서 클릭 → 내용 확인
3. "승인" 또는 "반려" (사유 필수)

---

## 6. 인사 (직원 본인)

### 6.1 출퇴근
- 모바일 앱 또는 PC에서 출근 체크
- 외근·재택 옵션

### 6.2 연차 신청
1. [인사] → [연차신청]
2. 일자·사유 입력
3. 결재 라인 자동
4. 승인 후 잔여 자동 차감

### 6.3 근로계약 서명
- 회사에서 보낸 알림 클릭
- 카카오/토스/금융/PASS 간편인증
- 전자서명 완료

---

## 7. 모바일 사용

### 7.1 아이폰 홈 스타일
- 자주 쓰는 메뉴 큰 아이콘
- 꾹 누름 → 재정렬

### 7.2 현장 즉시 발행
- 견적·발주·매입 즉시 작성
- 카메라로 사업자등록증 인식 (Phase 6)

## 8. 자주 묻는 질문 (FAQ)

| Q | A |
|---|---|
| 비밀번호 잊었어요 | 로그인 화면 "비밀번호 찾기" |
| 잘못 입력했어요 | "draft" 상태면 수정 가능, "확정" 후는 반품/조정 |
| 거래처가 없어요 | [마스터] → [업체관리]에서 등록 |
| 상품이 없어요 | [마스터] → [상품관리]에서 등록 |
| 마감했는데 수정해야 해요 | 어드민에게 요청 (마감 해제) |
| 백업은 어디에? | 사장님 PC에 자동 저장 (본사 모름) |
| 다른 사람 데이터가 보여요? | 절대 없음. 회사별 완전 격리 (헌법 #2) |
