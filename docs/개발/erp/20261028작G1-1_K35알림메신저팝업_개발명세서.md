1. **함수 이름·인자**: §4-2 는 `TryGetRoomId(string? link, out string roomId)` 하나였다. §0-4 대표 답이 「종류 **그리고** 링크」를 요구하므로 `TryGetRoomId` 는 링크 모양 판정으로 남기고, 화면이 부르는 것은 **`TryGetPopupRoomId(type, link, out roomId)`** 로 따로 두었다. 링크만 보는 함수를 화면이 부르지 않는다(grep §6).
2. **방 번호 범위**: §4-2 예시보다 좁힘(§0-1).
3. **개발명세서 위치**: 작업지시서 §0 「산출」은 `docs/개발/그룹웨어/` 였으나 그 폴더가 없다(`docs/개발/` 하위 = erp·랜딩·백오피스·브랜치정렬·설치배포·업데이트배포 · `INDEX.md` 에 「그룹웨어·메신저」 0건). 새 폴더를 독단으로 만들지 않고(#41) 메신저가 ERP 본체 안 기능이므로 **`docs/개발/erp/`** 에 두었다. 폴더 신설이 맞으면 PM 이 옮긴다.
4. **토스트 길 처리 함수 하나 더**: [3-V] C3 반영으로 `OpenChatPopupFromToastAsync` 를 더했다(§7).
