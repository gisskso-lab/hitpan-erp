## 3. 시나리오 상세

### 3.1 로그인 → 87 화면 전수
```
1. POST /api/auth/login → JWT 발급
2. localStorage 박제 (3 keys)
3. /dashboard 진입 → 4.5초 대기 (WASM 부팅)
4. for 87 routes:
   - goto(route)
   - waitForNetworkIdle
   - 본문 텍스트 추출
   - 키워드 매칭 + FAIL_KW 차단
   - 콘솔 에러 수집
5. 카테고리별 점수 + 총점
```

### 3.2 워크플로우 3흐름 E2E (계획)
```
[매입]
1. POST /api/partners → 신규 거래처
2. POST /api/items → 신규 상품
3. POST /api/purchase-orders → 발주
4. POST /api/purchases → 매입 입고
5. GET /api/stock → 재고 +N 확인
6. POST /api/returns → 반품
7. GET /api/stock → 재고 -N 확인

[BOM]
1. POST /api/bom → BOM 등록
2. POST /api/bom/{id}/produce → 생산
3. GET /api/stock → 완제품 +N + 자재 -각각 확인

[판매]
1. POST /api/quotations → 견적
2. POST /api/sales/orders/from-quotation → 수주
3. POST /api/delivery → 거래명세서
4. GET /api/stock → 재고 -N 확인
5. POST /api/sales/tax-invoices → 세금계산서
```
