## §1 중단 사유 (실측)

작업지시서 §4-2 G3 참고 「표식 = ASCII `.net core bundle` 의 SHA-256 32바이트를 시험이 **계산**해 exe 에서 찾음」 이 **실측과 다르다.**

| 잰 것 | 값 | exe 안 개수 |
|---|---|---|
| SHA-256(ASCII `.net core bundle`) | `db2a6c16fec7fbeb…` | **0** |
| SHA-256(ASCII + NUL) | `df19cf0cd196b102…` | 0 |
| SHA-256(UTF-16LE) | `4750150ac5cf64b4…` | 0 |
| 실제 표식(apphost 고정 32바이트) | `8b1202b96a612038727b930214d7a03213f5b9e6efae3318ee3b2dce24b36aae` | **1**(위치 7,953,960) |

- 실제 표식은 「SHA-256 이라고 주석이 붙은」 **고정 바이트**다. 계산으로는 나오지 않는다 ⇒ 「바이트를 손으로 적지 않음」 과 「표식을 찾음」 을 함께 지킬 수 없다.
- 계산 꼴로 짠 G3 를 돌린 결과: G3 만 빨강 「번들 표식이 0 개다」(G1 · G2 · G4 · ①②③ 6 초록).
- 설계가 고를 거리(개발이 정하지 않음): ㉠ 표식 32바이트를 상수로 적음(출처 주석) ㉡ 다른 방법(새 꾸러미는 지시서상 금지 · 회송 대상) ㉢ 그 밖.
