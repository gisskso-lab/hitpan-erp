## 0. 한 줄

**경비는 결재가 정상으로 보이는데, 승인해도 원본이 `pending` 그대로였다.** 그 배선을 넣었다.

---

## 1. 무엇이 문제였나

`ProcessAsync` 의 원본 동기화는 `if (doc.DocType == ...)` **손코딩 블록**이고,
`expense` 만 통째로 빠져 있었다.

| doc_type | 상신 | 원본 반영 | 위치 |
|---|---|---|---|
| `leave` | ✅ | ✅ | `ApprovalService.cs:676` |
| `absence` | ✅ | ✅ | `:718` |
| `overtime` | ✅ | ✅ | `:775` |
| `report_*` | ✅ | ✅ | `:793` |
| **`expense`** | ✅ | 🔴 **없음** | **← 이번에 넣음** |

🔴 **빌드 0/0 · 시험 619개 전부 통과 상태에서 이 결함이 살아 있었다.**
기존 가드시험 8개가 전부 *"상신을 부르는가"* 라는 **글자**만 보고
*"승인이 원본에 갔는가"* 라는 **동작**을 안 봤다.

---

## 2. 어떻게 고쳤나

### 2-1. 위치

`ApprovalService.cs` — 보고서 블록 뒤, `tx.Commit()` 앞.
**같은 트랜잭션**에서 처리한다(`leave`·`absence` 와 같은 원칙, 헌법 #20).

### 2-2. 🔴 두 표 모두 시도한다 — 정본을 고르지 않는다

작업지시서 초안은 *"정본 판정 결재 필요"* 였으나 **PM 결재에서 뒤집혔다.**
코드가 이미 답하고 있었다 — 두 경로가 **서로 다른 `refId`** 로 같은 `'expense'` 를 상신한다:

| 경로 | refId |
|---|---|
| 직원 신청 `HrService.cs:251` | `hr_expense_requests.request_id` |
| 경리 등록 `FinanceService.cs:265` | `expenses.expense_id` |

⇒ **정본을 하나 고르는 문제가 아니다.** 어느 표를 가리키는지 승인 시점에 알 수 없다.

> 사장님(2026-08-21): *"경리없이 **대표가 직접 경리업무 보는 소규모 회사**도 있고,
> **경리팀이나 회계팀 조직을 빌딩할 정도로 큰 회사**도 있고 **이건 케바케라**"*
>
> ⇒ 정본을 고르면 **한쪽 회사 유형이 죽는다.**

**기존 `FinanceService.ApproveExpenseAsync` 패턴 재사용** — `updated == 0` 이면 다른 표 시도.

### 2-3. ⚠️ 두 표는 컬럼이 다르다

한쪽 SQL 을 복사해 쓰면 런타임 500 이 난다(헌법 #13 — DESCRIBE 선행으로 확인).

| 표 | 상태 칸 | 승인자·사유 |
|---|---|---|
| `hr_expense_requests` | `status` | `approved_by`·`approved_at`·`reject_reason` **있음** |
| `expenses` | `approval_status` | **없음** (대신 `approval_id`) |

### 2-4. 헌법 준수

- **#6** — 중간 단계 승인은 원본 무접촉. `doc.CurrentSeq >= doc.TotalLines` 일 때만
- **#20** — 같은 트랜잭션. 결재만 되고 원본이 안 바뀌는 창이 없다
- 멱등 — `status='pending'` 가드. 화면이 먼저 처리했으면 0행이라 무해

**화면에서 실제로 도는지 확인하지 않았다.**

> 이 결함 자체가 *"빌드도 시험도 통과하는데 화면에서 아무 일도 안 일어나는"* 종류였다.

**실측 항목** (⚠️ 헌법 #39 — **테스트 환경만**):
- [ ] 직원 경비신청 → 결재함 승인 → `hr_expense_requests.status` 가 `approved`
- [ ] 경리 경비등록 → 결재함 승인 → `expenses.approval_status` 가 `approved`
- [ ] 반려 → 양쪽 `rejected` + 사유 표시
- [ ] 중간 단계 승인(2단 결재선) → 원본 **아직 안 바뀜**(헌법 #6)
