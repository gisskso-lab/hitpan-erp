## §5 첫 CI 런 전에 PM 이 알 것
1. 🔴 **trace 와 S10 충돌 예상** — 로그인 뒤 trace 에는 인증 헤더·SignalR 주소의 접속 토큰이 들어간다(⚠️미측정). 그러면 실패 런마다 S10 이 trace/ 를 잡아 지우고 빨강 → S11 규칙상 **main/(결과표·스크린샷)까지 업로드 0**. 실패 증거가 런 로그(판정표)에만 남는다. 정리(trace 끄기 · 토큰 가린 사본 · 규칙 유지)는 PM·보안상무 판정.
2. 첫 PR 런이 곧 첫 기동이다 — 장치 빨강 여러 번 예상(publish·기기 승인·방 만들기). H 상한 6 · 재실행 규칙 §5 그대로.
3. 측정 런 = `plant.flags`(`red` 또는 `leak`) 를 더한 측정 커밋 · 런 뒤 버린다(머지 금지).
4. ⑫ⓓ 가림 측정은 사람이 S0 로그의 `가림 측정:` 줄을 읽어 기록한다.
5. 「CI 초록 = 실제 크롬에서 안 막힘」 아님 — 터널·실제 크롬 팝업 차단 강도는 HQA 실측팀(§0-10).
