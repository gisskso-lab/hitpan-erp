### 2-1. 인증서 「없음」 은 실패가 아니다 — 서비스 한 자리 고침(필수 · 거짓 알림 방지)
- 서버 `TaxInvoiceCertController.GetInfo` 는 인증서가 없으면 `Ok((object?)null)` = **204 빈 본문**. 종전 꼴 `GetFromJsonAsync` 는 빈 본문을 못 읽어 예외 → catch(기록 줄)로 갔다 — 그대로 두면 **인증서 없는 회사에 매번 실패 알림**이 뜬다.
- 고침: `GetAsync` → 204 면 `null`(실패 신호 0 · 기록 0) → 그 밖은 `EnsureSuccessStatusCode` 뒤 `ReadFromJsonAsync`. 200 = 같은 값 · 실패 = 같은 예외 → catch(종전과 같은 결과). 옛 줄 ⬛ 로 남김.
- 같은 꼴 확인(나머지): 백업 · 구독 설정 · 메일 · 팩스 설정 · 안전재고 · 로그 · 결재선 서버 응답은 늘 값(비-null DTO · 목록) — 204 갈래 없음. 구독(`GetSubscriptionAsync`)은 원래 `GetAsync` + 204 가름이라 그대로.
