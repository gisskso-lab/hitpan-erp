## 0. 결론

1. 🔴 **「양쪽 막힘」은 코드 경로 두 줄로 설명된다** (🟢 코드 · 어느 갈래였는지 운영 DB 확인은 ⬜):
   - **도메인** — `MainPcOnlyAttribute.IsMainPc` = *터널 헤더 없음 AND loopback*. 도메인은 cloudflared 를 거쳐 `CF-Connecting-IP` 가 붙으므로 **설계상 항상 거짓**이다.
   - **localhost:5234 첫 로그인** — 새 주소라 기기번호·기계비밀이 비어 있다 → 서버가 **새 줄을 `approved` 로 넣지만 `is_main_pc` 는 안 붙이고 인증키도 없다** → `DeviceAuthMiddleware` 세 축 전부 불통 → 업무 API 403 `forbidden_device_auth` → 화면 `_blocked` 관문 *"인증된 기기가 아닙니다"*. **이 관문에는 대표용 [이 컴퓨터 승인]·[회사서버] 버튼이 그려지지 않는다** ⇒ 인계3 H4 는 코드로 반증.
2. 「이 요청이 메인PC냐」 판정식이 **4벌 복제**(요청 기준) + 기동 기준 1벌 + `is_main_pc` 표식 쓰기·읽기 10여 곳. 판정 서비스 메서드(`IsDeviceAllowedAsync`)는 **운영 호출처 0**(시험만) — 미들웨어가 같은 SQL 을 인라인으로 복제하고 있다.
3. **설치본이 사장님을 도메인으로 보낸다** — 바탕화면 바로가기(`hitpan-start.bat`)와 설치마법사 마지막 단계가 `https://{도메인}` 을 연다. 그리고 `web-server.ps1`·`hitpan-start.bat` 은 **자동업데이트로 바뀌지 않는다**(업데이트 zip = `api`·`web`·`watchdog` 3폴더).
4. 🔴 새로 드러난 잠재 결함 4건(§2-4): **출하 DDL 에 DB-89 방어선(UNIQUE·트리거)이 없는데 적용 완료로 표시**돼 신규 설치엔 영영 안 깔린다 · 로컬 재로그인 뒤 API 재기동 시 서버 줄 재표식 충돌 · LOCAL 모드는 사내 전 PC 가 메인PC · Host 헤더 조작 시 사내 PC 가 로컬 판정.
5. **개발팀 권고**: ① [1-V] 운영 DB 한 번 읽기 → ② **(f) 당장 봉합 S**(로컬 첫 로그인 덫 + `_blocked` 대표 버튼 + 안내) → ③ **(b) 확인코드 페어링 + (d) 판정 단일화(바인딩 절 가산) M**. 셋 다 **DDL 0 · 업데이트로 전달 가능**. 단 (d) 를 증명 수단 없이 열면 원격 초기화 문이 열린다 🔴.
6. **마이그 실측 당장 경로**: localhost 에서 **로그아웃→재로그인(P2)** 하면 코드상 자료관리 전부 통과 🟡. 「도메인에서 로컬 줄 승인→키 입력(P1)」은 **화면으로는 불가** 🟢. **「없는 것만 보태기」는 도메인에서 경로를 타이핑하면 된다** 🟢(코드) — 막힌 버튼은 **찾아보기 · 모두 지우고 새로 가져오기 · 백업 · 초기화** 넷이다.
