## 3. 🔴 기존 시험 3건의 기대값을 바꿨다 — **규칙이 뒤집혔기 때문**

**코드에 맞춰 시험을 고친 것이 아니다.** 셋 다 옛 규칙을 글자로 검사하고 있었고, 그 규칙이 결재로 뒤집혔다.

| 시험 | 옛 기대 | 지금 | 왜 |
|---|---|---|---|
| `G27_QR등록도_승인제를_따른다` | `qrStatus = _approvalEnabled ? …` | `qrStatus = "pending"` **고정** | 2-4 로 **더 엄해졌다.** 옛 정규식을 두면 **되돌아간 코드가 초록불**이 된다 |
| `G27b_대기중인_QR기기는_승인자가_비어있다` | `By = _approvalEnabled ? null : issuedBy` | `approved_by` **항상 NULL** | QR 을 띄운 사람은 **승인한 적이 없다** |
| `D5_기존기기_갱신경로는_한도검사를_하지_않는다` | 계수 호출 **0건** | **거부(`denied_limit`) 0건** | D-5 의 목적은 *"계수를 부르지 마라"* 가 아니라 **"쓰던 사람을 막지 마라"** 다 |

## 4. 오해하기 쉬운 자리 — 설계 의도 확인

### 4-1. 🔴 2-1 은 **"막는다" 가 아니라 "안 바꾼다"**

```
mobile → pc 승격 · 컴퓨터 칸이 꽉 참
   ⇒ normalizedType = null  (COALESCE 가 기존 값 보존)
   ⇒ return 하지 않는다 ← 🔴 return 하면 그것이 곧 "막는다" = 8/10 사고
   ⇒ 그 사람은 계속 mobile 칸으로 쓴다 (불편 0 · 요금 구멍 0)
```
G-13b 가 **두 가지를 동시에** 본다: `device_type != "pc"` **그리고** `allowed == true`.

### 4-2. 🔴 V-05 — 진짜 구멍은 승격이 아니라 **최초 등록**이었다

공격자는 **승격할 이유가 없다.** 처음부터 `mobile` 로 등록하고 안 바꾸면 그만이다.
⇒ **2-1 만 했으면 게이트는 초록, 구멍은 잔존 = 거짓봉합.**

⚠️ **완벽을 약속하지 않는다.** UserAgent 도 위조할 수 있다.
이 봉합이 하는 일은 **"신고값을 그대로 믿지 않는 것"** 하나 —
화면 조작만으로 칸을 고르던 것을 **헤더까지 함께 위조해야** 되게 바꾼다.
🔴 *"위조를 막았다"* 고 적으면 거짓봉합이다.

**남은 구멍을 명시한다**: 서버는 **터치 여부를 못 본다.**
아이패드와 책상 위 Mac 을 가를 수 없어 **Mac 계열은 판정하지 않고 비켜선다.**
⇒ **Mac 을 사칭하면 이 검사를 빠져나간다.** 막는 것은 다음 차수의 장비넘버(`hardware_id`) 몫이다.
(비켜서지 않으면 **아이패드가 컴퓨터 칸을 먹던 8/10 사고가 재발**한다 — G-V05-짝 이 그것을 지킨다)

### 4-3. 2-6 — 칸은 여전히 **둘**이다

`tablet` 은 저장만 갈렸고 **과금 계수(`MobileUsedFrom`)는 한 글자도 안 건드렸다.**
G-13+ 가 숫자로 확인: `MobileUsed == 2`(mobile 1 + tablet 1) · `PcUsed == 0`.

### 4-4. DP-2 — **막는 것과 빠져나오는 것은 다른 역할**

- ① 막는 자리(`RejectAsync` 가드)만 있으면 → **이미 `rejected` 인 기존 행**이 영영 못 나온다.
- ② 빠져나오는 자리만 있으면 → 표가 계속 더러워진다.
- 🔴 ② 를 **`pending` 으로 되돌리면 아무것도 안 고친 것**이다 —
  승인해 줄 유일한 사람이 **자기가 승인 대기에 갇힌다**(8/16 P0 커밋 `30e3873` 그 자체).
  ⇒ 메인PC 는 **`approved` 로 되돌려 세운다.**

### 4-5. 🔴 문자열 검사 자리 전수조사 (헌법 #12)

PM 지시대로 **두 방향 다** 훑었다.

```
grep -rn '"revoked"'   → 구제책이 revoked 하나만 덮고 있었다 = DP-2 ② 의 진범
grep -rn "== \"mobile\"" → 계수 자리 4곳 전부 이미 mobile+tablet 쌍으로 검사 중 (샐 자리 0)
```
`tablet` 을 되살리며 새는 자리가 있는지 확인한 결과 —
`:505` · `:640` · `MobileUsedFrom` · 백오피스 `IN ('mobile','tablet')` **전부 안전**.
