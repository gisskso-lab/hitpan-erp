## 3. P3 실세션 확인

| 단계 | 명령 | 실제 출력 |
|---|---|---|
| ① 탐침 | `claude -p "Agent … description 'p3-probe' … reply ok" --model haiku --allowedTools Agent --output-format json` | `"result":"spawned"` · 세션 `102130a0-3a77-4ed0-8dac-50dab65643e2` · 기록 `subagents/agent-ae7117507007bb6f8.jsonl` |
| ② 대기 | 5분 30초 (백그라운드) | — |
| ③ 쉰 에이전트 재개 | `claude --resume 102130a0-… -p "SendMessage to 'ae7117507007bb6f8' 'ping - reply ok'"` | **`DENIED: [토큰규칙 P3] 에이전트 ae7117507007bb6f8 (p3-probe) 가 10분 쉬었다 — 캐시 5분 만료. 이어 부르면 대화 전체를 다시 쓴다.`** |
| ④ 대조 — `#재개승인` | 같은 세션 · 메시지 `#재개승인 control - reply ok` | **`Agent p3-probe completed with result: ok`** — 거부 없이 전달돼 재개됨 |

> 사용자 설정 훅은 **새로 뜨는 세션**(`-p` · `--resume` 포함)이 읽는다 — 설정을 바꾸기 전에 뜬 창에는 안 걸려 있을 수 있다. 새 창에서는 걸린다.
