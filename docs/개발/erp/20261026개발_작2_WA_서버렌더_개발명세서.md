## 4. 🔴 `plain` 좌표 경로에서 **배경이 깔리는 조건** (= `preprint` 이중 인쇄를 어떻게 막았나)

판정 자리는 **한 곳**이다 — `PdfRenderService.cs:1980` (`ResolveFormBackground`). 🔴 **이 줄은 한 글자도 안 고쳤다.**

```
overrides?.IsFormDesignPreview != true && template?.PrintBackground != true  ⇒  배경 없음
```

| 경우 | 「종이에도 인쇄」(`print_background`) | 전표 미리보기·실인쇄에 배경 | 비고 |

| `plain` + 그림 | **켬(1)** | 🟢 **깔린다** ← 오더 ① 이 서는 자리 | 켜는 것은 고객 · 제안은 화면(B-3) |
| `plain` + 그림 | 끔(0 · **DB 기본값**) | 안 깔린다 | 종전과 같다 |
| `preprint` | 끔(0 · **DB 기본값**) | 🟢 **안 깔린다 — 종전 그대로** | 🔴 **이중 인쇄 0건** |
| `preprint` | 켬(1) | 깔린다 (**종전과 동일 · 내가 바꾼 것 아님**) | 🔴 아래 미결 참조 |
| 양식 설계 미리보기 | 무관 | 깔린다 | `FormTemplateController.cs:148` · 종전 그대로 |

**어떻게 막았나 — 한 줄**: 🔴 **`DocumentController` 에 `IsFormDesignPreview = true` 를 넣지 않았다.** 그것이 설계 §3 **B-2** 이고, 넣는 순간 `preprint` 고객 **전원**이 이중 인쇄가 된다(미리보기 PDF **가 곧 종이**다 · `:1925` 주석). 울타리는 **고객 설정 한 축**으로만 열린다. DB 기본값이 0 이므로 **오늘 쓰는 모든 `preprint` 고객의 종이는 글자 하나 안 바뀐다.**

> ⚠️ **미결로 올린다(내가 혼자 정하지 않았다)** — `preprint` + 「종이에도 인쇄」를 **고객이 직접 켠** 조합은 종전처럼 깔린다. 작업지시서는 「`preprint` 는 배경 안 깔림」이라 적었고 **기본값(0) 기준으로는 참**이다. 이것을 서버가 **몰래 끄도록** 좁히는 것은 ⒜작1 결-D(「고객이 고른 대로 그린다 · 우리가 몰래 끄는 길은 안 만든다」)를 되돌리는 것이고 ⒝#1 위반이며 ⒞그 자리를 글자로 못박은 게이트(`FormPaperSizeAndBackgroundUploadGateTests.cs:1680~1689`)를 깬다. ⇒ **PM·[4] 판정 요청.** 화면은 이미 그 조합을 말리고 있다(`FormTemplateEditorDialog.razor:353~366` 캡션).

## 9. 검증팀·PM 에 요청 (내 판단 아님)

1. 🔴 **판정 요청** — `preprint` + 「종이에도 인쇄」를 **고객이 켠** 조합(§4 미결). 좁히면 작1 결-D 를 되돌리고 #1·글자 게이트를 깬다. 좁힐지 말지는 PM·[4] 몫.
2. 🔴 **W-C 에 한 줄** — `Program.cs` CORS `.WithExposedHeaders("X-HitPan-Print-Gate")`. 없으면 꼬리표는 영영 `unknown` 이다(사고는 아니지만 ⑤ 가 안 선다).
3. **W-B 에 넘기는 값** — §3 표의 **글자 6개**만 쓰면 된다. 🔴 `PrintGateReasons` 는 `HitPan.Application` 에 있어 Web(WASM)이 참조하지 못할 수 있다 ⇒ 화면은 **표의 글자**를 쓰고, 공용 자리(`HitPan.Contracts`)로 옮기는 것은 **등재**(내가 안 했다 — 3번째 파일이 된다).
4. 🔴 **A-1 의 대가 안내는 화면 몫** — 「좌표로 찍으면 표준 표는 안 나옵니다」 + 비어 있는 필수 칸 목록(설계 §2 A-1 완화). **서버는 아무 안내도 안 한다.**
5. §5-1 종단 한 줄기는 **구현자 아닌 손**으로.
