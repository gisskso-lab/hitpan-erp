namespace HitPan.Application.Interfaces;

public interface ILocalAuditFile
{
    string FilePath { get; }
    Task<LocalAuditEntry> AppendAsync(LocalAuditRecord record, CancellationToken ct = default);
    Task<IReadOnlyList<LocalAuditEntry>> ReadUnfinishedSwapsAsync(string? tenantId = null, CancellationToken ct = default);
    Task<LocalAuditChainReport> VerifyChainAsync(CancellationToken ct = default);
}

public enum LocalAuditAction
{
    RestoreStarted = 1, PreBackupCreated = 2, VerifyFailed = 3, SwapStarted = 4, SwapCompleted = 5,
    SwapFailed = 6, RestoreAborted = 7, RecoveryResolved = 8, ParentPasswordReset = 9,

}
public enum LocalAuditResult { Started = 1, Succeeded = 2, Failed = 3, Noted = 4 }

public sealed record LocalAuditRecord(string TenantId, string ParentUserId, LocalAuditAction Action,
    LocalAuditResult Result, string OpId, string? Detail = null);
public sealed record LocalAuditEntry(long Seq, DateTime AtUtc, LocalAuditRecord Record, string PrevHash, string Hash);
public sealed record LocalAuditChainReport(bool Ok, int ValidLines, int? FirstBadLineNumber, string? Reason, bool TailTorn);

## 3. 파일 자리 · 줄 꼴 · 지문

- **자리** = `%ProgramData%\HitPan\audit\restore-audit.log` (`LocalAuditFileWriter.DefaultFilePath`). 앱 로컬 자료 관례(`CompanyImagePaths.Root` · `FormBackgroundPaths` · `BackupService` 기본 백업 = 모두 `%ProgramData%\HitPan\…`)와 같은 뿌리 · 복원 대상 DB 밖. 한 PC 한 파일(회사는 줄의 칸으로 가름). 폴더는 첫 쓰기 때 만든다(생성자 부작용 0).
- **줄 꼴**(탭 구분 · UTF-8 BOM 없음 · 끝 `\n` · 11칸):
  `v1 ⇥ 순번 ⇥ 시각(UTC "yyyy-MM-ddTHH:mm:ss.fffffffZ") ⇥ 회사 ⇥ 대표 user_id ⇥ 동작 ⇥ 결과 ⇥ OpId ⇥ 덧말(없으면 빈칸) ⇥ 앞 줄 지문 ⇥ 이 줄 지문`
- **지문** = SHA-256(마지막 탭 앞 글자 전부의 UTF-8) 소문자 16진 64자. 첫 줄 앞 줄 지문 = `0` × 64. 순번 1부터(깨진 조각은 안 셈).
- **글자 규칙**(개인정보 · 줄 깨뜨리기 막기): id 3칸 = 영문 · 숫자 · `-` `_` 64자 이하. 덧말 = 글자 · 숫자 · `. _ - : + =` 200자 이하 → 빈칸 · 줄바꿈 · 탭 · `@` 거절 = 문장 · 이메일 · 비번 문장이 들어갈 자리가 없다. 비번 · 토큰 · 주민번호를 넣지 않는 것은 호출자 책임(주석 명시).
- **동시 쓰기** 2겹: ① 경로별 `SemaphoreSlim`(정적 사전 · 인스턴스가 여럿이어도 같은 자물쇠) ② `FileShare.Read` 로 열어 다른 프로세스 쓰기 막음(공유 위반 32 · 33 이면 50ms × 최대 100회 다시 · 끝내 못 열면 `IOException` — 호출자는 삼키지 말 것).
- **내려쓰기** = `FileOptions.WriteThrough` + 줄 묶음 끝 `Flush(flushToDisk: true)`.
- **깨진 끝 줄** — 다음 쓰기가 ① 줄바꿈 없는 끝이면 `\n` 으로 닫고 ② 표시 없는 깨진 줄이면 `TornTailNoted`(회사 · user · OpId = `-` · 덧말 `torn-sha256:` + 조각 SHA-256 앞 16자) 줄을 먼저 남긴 뒤 새 줄. 검사는 「깨진 조각 바로 뒤 그 조각 지문을 적은 표시 줄」 일 때만 통과.
- **네트워크 의존성 0** — 쓰는 형식 = `System.IO` · `System.Security.Cryptography` · `System.Text` · `System.Threading` · `ILogger`. 본사 주소 · HttpClient · 소켓 0(시험 G0_9).

## 6. A · C 에 넘길 말

- **주입**: `ILocalAuditFile`(Singleton) 을 생성자로 받는다. 새 인스턴스를 직접 만들지 않는다(자리 · 자물쇠 한 벌).
- **#2**: `TenantId` · `ParentUserId` 는 JWT 클레임(또는 서버 안에서 확정한 값)만. 비번 되찾기(C)는 로그인 전이라 서버가 찾아 낸 부모 user_id · 못 찾으면 `"unknown"` 같은 고정 낱말(입력값 그대로 적지 말 것).
- **OpId**: 한 번의 복원 · 되찾기마다 `Guid.NewGuid().ToString("N")` 하나 → 시작 줄과 끝 줄이 같은 값.
- **A 복원 순서(설계 §6 · §7 대로)**: `RestoreStarted/Started` → `PreBackupCreated/Succeeded`(덧말 = 파일 이름만 · 경로 아님 — 경로 `\` 는 덧말 규칙 밖이라 거절됨) → 대조 실패면 `VerifyFailed/Failed`(덧말 = 칸 이름) · 교체 전 멈춤이면 `RestoreAborted/Failed` → `SwapStarted/Started` → 커밋 + 갱신 줄 수 확인 뒤 `SwapCompleted/Succeeded` · 되돌려지면 `SwapFailed/Failed`.
- **A 다음 기동 복구**: `ReadUnfinishedSwapsAsync()` 결과마다 `restore_history` 로 커밋 여부 판정 → 기록 채움 + 모두 끊기 + 캐시 비움(설계 §7 R17) → `RecoveryResolved`(같은 OpId · 덧말 `committed` 또는 `rolledback`). 이 줄이 남아야 다음 기동이 같은 일을 또 하지 않는다.
- **C**: 성공 `ParentPasswordReset/Succeeded` · 거절 `ParentPasswordResetFailed/Failed`(덧말 = 까닭 코드 · 비번 · 1회용 표 값 금지).

### G1-5. A · C 에 넘길 말(§6 에 더함 · 지우지 않음)

- **§A 인계 — DB 맞대기(X6 · 3-V F4 = 갈래 A 몫)**: 파일만으로는 끝 줄 잘라내기 · 앞부분만 남기고 자르기 · 옛 사본 되돌리기 · 지문 다시 계산 · 통째 지우고 다시 쓰기를 못 알아본다. A 설계에서 정할 것: 줄마다(또는 묶음 끝마다) `seq` · 지문을 `restore_history`/`audit_logs` 에도 적고, 기동 · 복원 때 「DB 가 아는 마지막 seq ≤ 파일 마지막 seq」 · 지문 같음을 대 본다. `ExplainedTornLines`(끊김 수) · 순번 재사용도 대 볼 값. `State = Missing/Empty` 인데 DB 에 복원 기록이 있으면 = 통째 지움 의심.
- **회사 열쇠**: `ReadUnfinishedSwapsAsync` · `ReadOpenOperationsAsync` 둘 다 회사 id 필수. 기동 때(JWT 없음) 넘길 「서버 확정 회사 값」 = 그 슬롯 API 가 붙은 DB 의 회사(A 설계에서 못박음 · 5 슬롯이 한 파일을 같이 씀 · 3-V F2).
- **못 믿는 줄**: `UntrustedLines > 0` 이면 자동 회복(모두 끊기 · 기록 채움) 금지 → 「확인 필요」(A 지시서에서 화면 · 로그 정함).
- **기동 복구 순서(설계 §7)**: `ReadUnfinishedSwapsAsync` → 묶음마다 `RecoveryResolved`(committed/rolledback) · `ReadOpenOperationsAsync` 중 교체 미완이 아닌 것 → `RestoreInterrupted`(결과 `Noted` · 덧말 = 까닭 코드).
- **쓰기 실패**: `LocalAuditWriteException` 만 잡는다. `LineWritten = true` 면 다시 쓰지 말 것(같은 OpId 줄 두 개). 멈출지 · 지날지 = A · C 지시서(PM 추천 = 둘 다 멈춤 + 쉬운 안내).
- **덧말**: 고정 낱말(까닭 코드 · committed/rolledback · 사전 백업 파일 이름 꼴)에서만 고른다 — 글자 규칙 · 모양 거절은 다 막지 못한다. 사용자 못 찾음 = `LocalAuditWords.UnknownUser`.
- **G11**: 같은 훑개(`NetworkTypeScanner.Scan`)가 이제 부르는 `HitPan*` 형식까지 전이로 훑는다 — A · C 경로 형식도 그대로 넣으면 그 너머까지 잰다(DB 를 쓰는 형식은 `MySqlConnector` · `System.Data` 로 잡히므로 대상 고를 때 주의).
