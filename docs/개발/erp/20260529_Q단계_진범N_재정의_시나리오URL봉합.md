## 2. 진범 정체

### 잘못된 시나리오
```powershell
# S20.ps1 (수정 전)
$baseUrl = ([Uri]$HealthUrl).GetLeftPart([UriPartial]::Authority)
# → https://demo.hitpan.kr (Web hostname)
$loginUrl = "$baseUrl/api/auth/login"
# → https://demo.hitpan.kr/api/auth/login  ← Blazor WASM은 API 아님 → HTTP 405
```

### 봉합
```powershell
# S20.ps1 (수정 후)
$webHost = ([Uri]$HealthUrl).Host
$apiHost = if ($webHost -like 'api-*') { $webHost } else { "api-$webHost" }
$loginUrl = "https://$apiHost/api/auth/login"
# → https://api-demo.hitpan.kr/api/auth/login  ← API endpoint → HTTP 401 정상
```

동일 패턴 S18·S19도 봉합.
