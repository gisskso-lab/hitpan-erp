## 4. 공통 컴포넌트

### 4.1 WorkflowBreadcrumb
- 워크플로우 단계 표시 (매입: 발주→매입→반품 / 판매: 견적→수주→거래명세→세금계산서)
- 현재 단계 강조

### 4.2 ItemSpecAutocomplete ⭐ (2026-05-31)
- 품명 선택 → 규격 콤보 동적 로드
- CoerceValue=true (직접 입력 허용)
- 6개 그리드 적용 (QuotationGrid, SalesOrderGrid, DeliveryGrid, PurchaseOrderGrid, PurchaseReceiptGrid, PurchaseReturnGrid)

### 4.3 UnifiedCalendar ⭐
- 통합 일정 표시
- 견적·수주·발주·연차·근태 색상별
- OnAfterRenderAsync 패턴 (진범 #100 봉합)

### 4.4 DailyBriefingModal
- 오늘 일정 요약 다이얼로그

### 4.5 TermsConsentBanner
- 미동의 사용자 상단 배너 → /terms 유도

### 4.6 FormTemplateEditorDialog ⭐
- 양식 설정 (preprint/blank 분기)

### 4.7 ItemSpecManager
- 상품마스터에서 규격 다건 관리

### 4.8 그리드 패턴 (MudDataGrid)
- 정렬·필터·페이징 표준
- 라인 추가/삭제 인라인
- 셀 인라인 편집 (Ctrl+Enter 저장)

## 6. 입력 검증 표준

| 항목 | 검증 |
|---|---|
| 사업자번호 | 10자리 + 체크섬 |
| 이메일 | RFC 5322 |
| 전화번호 | 정규식 (`01[016789]-?\d{3,4}-?\d{4}`) |
| 금액 | decimal, 음수 금지 (조정 제외) |
| 수량 | 양수, 소수점 3자리 |
| 날짜 | YYYY-MM-DD, 미래일 제한 (필요 시) |

## 10. PDF 출력 (QuestPDF)

### 10.1 paper_mode 분기
| 모드 | 용도 | 컴포넌트 |
|---|---|---|
| `preprint` | 양식용지 | ComposeBodyPreprint (좌표 박제) |
| `blank` | 순백지 | ComposeBodyBlank |

### 10.2 출력 대상
- 견적서, 수주서, 거래명세서, 세금계산서
- 발주서, 매입명세서, 반품명세서
- 근로계약서
