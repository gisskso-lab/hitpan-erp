# 0번 🚪 **서버 들어가기** — 1번·2번을 하려면 여기부터 (5분, 한 번만)

> 🔴 **제가 사장님 NCP 화면을 직접 볼 수 없습니다.** 아래 메뉴 이름이 화면과 다르면 **보이는 대로 말씀만 주십시오.** 바로 고쳐 드립니다.
> **길이 두 개입니다. A 가 빠르면 A 만 하시면 됩니다.**

## 🅰 길 A — 평소 쓰시던 방법이 있으면 그게 제일 빠릅니다
평소 백오피스 서버(`back.hitpan.kr` 가 도는 서버)에 들어가시던 **터미널 프로그램**(PuTTY · MobaXterm · Windows 터미널 등)이 있으면 **그걸로 들어가신 뒤 → 아래 「3) 들어간 뒤」 로 바로 가십시오.**

## 🅱 길 B — 처음부터 (NCP 콘솔 → 주소 확인 → 내 PC 에서 접속)

### 1) NCP 콘솔에서 **서버 주소(공인 IP)** 확인
1. 인터넷 주소창에 **`console.ncloud.com`** 입력 → 로그인.
2. 왼쪽 위 **`Services`**(서비스) 클릭.
3. **`Compute`** → **`Server`** 클릭. *(VPC 환경을 쓰시면 `VPC` 쪽 `Server`)*
4. 서버 목록이 뜹니다. **백오피스 서버** 줄을 클릭합니다.
   - 이름을 모르시면 — 아래쪽 상세에서 **공인 IP** 가 있는 서버가 보통 그 서버입니다. 🔴 **헷갈리면 서버 이름 목록을 저에게 그대로 주십시오.** 제가 짚어 드립니다.
5. 상세 화면에서 **`공인 IP`** (예: `000.000.000.000` 모양 숫자)를 **복사**합니다. 📋

### 2) 내 PC 에서 접속 (Windows 11 이면 프로그램 설치 필요 없습니다)
1. 키보드 **`윈도우키`** 누르고 **`powershell`** 이라고 치고 Enter.
2. 파란 창이 뜨면 아래를 치십시오. **`계정이름`** 과 **`복사한IP`** 두 군데만 바꿉니다.

```powershell
ssh 계정이름@복사한IP
```

3. 처음 접속이면 **`Are you sure you want to continue connecting (yes/no)?`** 가 뜹니다 → **`yes`** 치고 Enter.
4. 비밀번호 또는 인증키를 물어보면 넣으십시오. 🔴 **그 값은 저에게 보내지 마십시오.**
5. 글씨가 `사용자@서버이름:~$` 모양으로 바뀌면 **들어가신 겁니다.** 🎉

> 🔴 **계정 이름을 모르시면**: NCP 콘솔 → 그 서버 → **`서버 관리 및 설정 변경`** → **`관리자 비밀번호 확인`** 에서 확인하실 수 있습니다(인증키 `.pem` 파일이 필요합니다). 리눅스 서버는 보통 **`root`** 또는 **`ncloud`** 입니다.
> 🔴 **`ssh: connect to host ... port 22: Connection timed out`** 이 뜨면 → **방화벽(ACG)에서 내 IP 의 22번이 막힌 것**입니다. 그 문장을 그대로 저에게 주시면 다음 길을 안내해 드립니다. **ACG 는 제가 손대면 안 되는 영역(#29)이라 사장님 승인 없이는 제안만 드립니다.**

### 3) 들어간 뒤 — **이제 1번을 하시면 됩니다**
검은 화면에 아래 한 줄을 **그대로 붙여넣고 Enter**. (붙여넣기는 **마우스 오른쪽 클릭** 입니다.)

```bash
sudo cat /etc/systemd/system/hitpan-backoffice-api.service.d/*.conf 2>/dev/null | cut -d'"' -f2 | cut -d= -f1
```

- 🔴 `sudo` 때문에 **비밀번호를 한 번 더** 물어볼 수 있습니다. 치셔도 **화면에 아무 글자도 안 보이는 게 정상**입니다. 그냥 치고 Enter.
- 나온 **이름 목록을 복사해서** 저에게 주십시오. **값은 안 나옵니다.**
- **아무것도 안 나와도** 그대로 *"아무것도 안 나왔다"* 고만 주십시오 — 그것도 답입니다.

### 4) 나올 때
```bash
exit
```

# 1번 ☁️ NCP 서버 환경변수 **이름만** 보기 (3분)

**왜 하나요**: 서버에 들어 있는 **이름이 맞는지**만 보면 됩니다. 이름이 틀려 있으면 고객이 설치할 때 **무조건 실패**합니다. 🔴 **값은 안 봐도 되고, 안 보입니다.**

### 이렇게 하세요

```bash
sudo cat /etc/systemd/system/hitpan-backoffice-api.service.d/*.conf 2>/dev/null | cut -d'"' -f2 | cut -d= -f1
```

3. 화면에 **이름 목록**이 쭉 나옵니다. 🔴 **값은 안 나옵니다**(위 명령이 `=` 뒤를 잘라 버립니다).
4. 그 **목록을 그대로** 저에게 주십시오. (아무것도 안 나오면 *"아무것도 안 나왔다"* 라고만 주십시오 — 그것도 답입니다.)

### 🔴 하면 안 되는 것
- 값을 보여주시거나 적으시는 것 — **필요 없습니다.**
- 이름을 **고치는 것** — 1번은 **보기만** 입니다. 고치는 건 제가 교정안을 만든 뒤 2번째 순서로 합니다.

### ✅ 통과 판정 (제가 합니다)
목록에 **`License__Pepper`** 라는 이름이 **있으면 🟢 통과!!!** / **없고 `BACKOFFICE_License__Pepper` 만 있으면 🔴 아직!!!** (이름이 코드에 닿지 않습니다)
🔴 **제가 방금 발견한 것**: 값을 넣는 스크립트(`scripts/deploy-ncp-secrets.sh:42`)가 **대문자 이름만 받아들입니다.** `BACKOFFICE_License__Pepper` 는 소문자가 섞여 있어 **아무 말 없이 건너뛰어집니다.** 그래서 1번 결과가 「아무것도 없다」일 가능성이 큽니다. 그래도 **보셔야** 확정됩니다.

# 2번 📧 SMTP 값 넣기 (10분)

**왜 하나요**: 이 값이 없으면 가입 신청 화면이 *"이메일로 발송됩니다"* 라고 **거짓말**을 합니다. 메일 1통이 O트랙(온보딩 자료) **전체**를 세우고 있습니다.

### 준비물
메일 서버 4가지 — **주소 · 아이디 · 비밀번호 · 보내는 사람 주소**. (사장님만 아시는 값입니다.)

### 이렇게 하세요
1. 1번과 같은 방법으로 서버 **터미널**을 엽니다.
2. 아래 한 줄을 붙여넣고 Enter (편집기가 열립니다):

```bash
sudo nano /etc/systemd/system/hitpan-backoffice-api.service.d/smtp.conf
```

3. 열린 화면에 **아래 6줄을 그대로** 적습니다. `여기에_값` 부분만 사장님 값으로 바꿔 주십시오.

```
[Service]
Environment="Smtp__Host=여기에_메일서버주소"
Environment="Smtp__Port=587"
Environment="Smtp__User=여기에_아이디"
Environment="Smtp__Password=여기에_비밀번호"
Environment="Smtp__From=여기에_보내는사람주소"
```

4. **저장**: `Ctrl` + `O` → `Enter` → `Ctrl` + `X`
5. 아래 두 줄을 차례로 붙여넣고 Enter:

```bash
sudo chmod 600 /etc/systemd/system/hitpan-backoffice-api.service.d/smtp.conf
sudo systemctl daemon-reload && sudo systemctl restart hitpan-backoffice-api
```

6. 마지막으로 이 한 줄 — `active` 라고 나오면 성공입니다:

```bash
sudo systemctl is-active hitpan-backoffice-api
```

### 🔴 하면 안 되는 것 3개
- **포트 465 쓰기** — 안 됩니다. **587** 입니다(우리 발송기가 STARTTLS 방식).
- **파일 이름을 `release-version.conf` 로 하기** — 배포가 그 파일을 덮어써서 값이 날아갑니다. 반드시 **`smtp.conf`**.
- **이름을 `HITPAN_SMTP_...` 로 적기** — 그 이름은 **폐기**됐습니다. 넣어도 **0통**입니다. 반드시 **`Smtp__`** (밑줄 **2개**).

### ✅ 통과 판정 (제가 합니다)
백오피스에서 **테스트 메일 1회** → ⓐ **받은편지함에 진짜 1통** + ⓑ **발송기록 표에 `result='sent'` 1행**.
둘 다 차면 **🟢 통과!!!** — 이 한 건으로 **B1①2단 · [5] 조건-6 · O트랙**이 같이 열립니다.
