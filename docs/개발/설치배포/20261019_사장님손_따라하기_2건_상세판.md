# 🔴 A. 운영 서버에 「빈 열쇠」가 있나 보기 (약 5분)

## A-1. 왜 이걸 하시나요 — 그림으로

히트판 백오피스 서버에는 **열쇠(비밀값)가 여러 개** 들어 있습니다. 그런데 지금 이런 상태일 수 있습니다.

```
   열쇠 자리        들어 있는 것        서버가 하는 말
 ┌──────────────┬─────────────────┬──────────────────┐
 │ 열쇠 A       │  진짜 값 ✅      │  "정상입니다"     │
 │ 열쇠 B       │  🔴 빈 칸        │  "정상입니다"  ← 거짓말!
 └──────────────┴─────────────────┴──────────────────┘
```

🔴 **지금 서버는 열쇠가 비어 있어도 "정상"이라고 말합니다.** 빈 열쇠로도 그냥 돌아가기 때문입니다.

제가 이번에 **"비어 있으면 멈춰라"** 로 고치려 합니다. 그런데 —

> 🔴 **지금 빈 열쇠로 돌고 있는데 제가 그걸 고쳐 버리면, 서버를 다시 켤 때 안 켜집니다.**

그래서 **고치기 전에** 사장님이 **"비어 있는 게 있나 없나"** 만 봐 주셔야 합니다.
**사장님이 못 보시면 제가 그 봉합을 못 넣습니다.** (운영 서버는 제가 직접 못 만집니다 — 헌법 #39)

## A-2. 0단계 — 서버에 들어가기 (처음이시면 여기부터)

> 🟢 **평소 NCP 서버에 들어가시던 방법이 있으면 그걸 쓰십시오. 그게 제일 빠릅니다.** → 바로 [A-3](#a-3-1단계--명령-한-줄-붙여넣기) 으로 가십시오.
> 처음이시면 [10건 매뉴얼의 0번](20261018_사장님손_따라하기매뉴얼_10건.md) 에 **그림 단위로** 적어 뒀습니다. 요약하면:

1. **윈도우 키**를 누르고 `terminal` 또는 `powershell` 이라고 치고 **Enter**.
2. 검은 화면이 뜹니다. 거기에 아래를 치고 Enter (`아이디`·`서버주소` 는 사장님이 쓰시는 것):

```
ssh 아이디@서버주소
```

3. 비밀번호를 물으면 치십시오. 🔴 **치는 동안 화면에 아무것도 안 보이는 게 정상입니다** (별표도 안 나옵니다). 다 치고 Enter.
4. 글자 앞부분이 바뀌면 들어가신 겁니다.

## A-3. 1단계 — 명령 한 줄 붙여넣기

검은 화면에 **아래 네모 안을 통째로 복사**해서 붙여넣고 **Enter** 를 누르십시오.

```bash
sudo cat /etc/systemd/system/hitpan-backoffice-api.service.d/*.conf 2>/dev/null | grep '^Environment=' | sed 's/^Environment="//; s/"$//' | awk -F'=' '{n=$1; v=substr($0,length(n)+2); gsub(/[ \t]/,"",v); printf "%-34s %s\n", n, (length(v)==0 ? "<<< 비었음 — 위험 >>>" : "값있음 ("length(v)"자)")}'
```

> 💡 **붙여넣기가 안 될 때**: 검은 화면에서는 `Ctrl+V` 가 아니라 **마우스 오른쪽 버튼 클릭** 이 붙여넣기인 경우가 많습니다.
> 💡 **비밀번호를 또 물어보면** 사장님 서버 비밀번호를 치시면 됩니다 (`sudo` 때문입니다).

## A-4. 2단계 — 화면에 나온 것을 그대로 주십시오

이렇게 생긴 목록이 나옵니다. **왼쪽은 열쇠 이름, 오른쪽이 답**입니다.

```
HITPAN_BO_JWT_SECRET               값있음 (64자)
HITPAN_BOOTSTRAP_TOKEN_KEY         값있음 (64자)
License__Pepper                    <<< 비었음 — 위험 >>>
```

🔴 **값은 한 글자도 안 나옵니다.** 글자 **개수**만 나옵니다. 그래서 **화면을 통째로 복사해서 저에게 주셔도 안전합니다.**

### 세 가지 경우뿐입니다

| 화면에 나온 것 | 사장님이 하실 말 |
|---|---|
| 목록이 쭉 나왔다 | **그 목록을 통째로 복사해서 주십시오** |
| 아무것도 안 나왔다 | *"아무것도 안 나왔다"* 🟢 **이것도 정답입니다** (열쇠가 다른 곳에 있다는 뜻 — 제가 그 다음을 봅니다) |
| 빨간 글씨 / 영어 오류가 났다 | **그 줄을 그대로 주십시오** — 제가 읽습니다 |

# 💻 B. 시험용 PC(또는 VM) 1대 정하기

## B-1. 왜 이걸 하시나요

고객 사무실에서 **인터넷이 끊기거나 컴퓨터가 꺼졌을 때** 히트판이 스스로 살아나는지를 재야 합니다. 그러려면 —

> 🔴 **일부러 망가뜨려도 되는 컴퓨터**가 한 대 있어야 합니다.

**이 PC 로는 못 합니다.** 지금 이 PC 에는 진짜 터널이 돌고 있어서, 시험 프로그램이 **스스로 "안 하겠다"며 멈춥니다**(제가 실행해서 확인했습니다). 억지로 끄면 **운영 수술 금지(헌법 #39) 위반**입니다.

### 못 재면 생기는 일

| 시험 | 내용 | 지금 |
|---|---|---|
| S-A | 터널 프로그램을 강제로 죽였을 때 스스로 살아나나 | ⛔ 못 잼 |
| S-B | 데이터베이스를 강제로 멈췄을 때 살아나나 | ⛔ 못 잼 |
