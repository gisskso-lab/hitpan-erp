# 5. 사원번호 칸 빼기 — **시험도 같이 고친다** (10초)

**무슨 상황인가요**
오늘 사장님이 *"코드를 설계에 맞춘다"* 로 결재해 주셨습니다(**본사가 받는 칸을 줄이는 쪽**). 그런데 막혔습니다 —

```
   설계 문서      : 직원 4칸만 받는다   (이름·메일·직급·재직여부)
   실제 코드      : 직원 5칸을 보낸다   (+ 사원번호)
   🔴 시험(ST-01) : "5칸이어야 맞다"고 이미 고정해 뒀다
```

🔴 **칸을 빼면 그 시험이 빨강이 됩니다** = 빌드 오류 0·경고 0 이 깨집니다(#19).
그래서 **칸 제거 + 그 시험의 판정까지 함께 고치는 것**을 한 묶음으로 승인해 주셔야 합니다.

🟢 **안전한 쪽입니다** — 백오피스가 그 칸을 **저장하는 코드 0건**, 당기는 코드도 **0건**이라, 빼도 본사 기능 손실이 없어 보입니다(받는 쪽 전수는 다음 차수에 다시 잽니다).

### 〈이렇게만 답해 주십시오〉
```
사원번호 칸 빼기 + 시험 같이 고치기 승인
```
또는
```
보류 — 설계를 코드에 맞춰라
```
(뒤쪽을 고르시면 코드는 안 건드리고 **설계 문서에 한 줄 더하는 쪽**으로 갑니다)

# 7. 운영 서버에 「빈 열쇠」가 있나 보기 (약 5분)

> 🔴 **이 1건만 사장님 손이 실제로 움직입니다.** 나머지 6건은 한마디로 끝납니다.
> 🔴 제가 못 하는 이유: **운영 서버는 읽기만**이고 직접 수술 금지입니다(#39).

**무슨 상황인가요**
서버에 **열쇠(비밀값)가 여러 개** 들어 있는데, 지금은 **비어 있어도 "정상"이라고 말합니다.** 제가 *"비어 있으면 멈춰라"* 로 고치려는데 —
🔴 **지금 빈 열쇠로 돌고 있다면, 고친 뒤 서버가 다시 안 켜집니다.** 그래서 **고치기 전에** 사장님이 봐 주셔야 합니다.

## 7-1. 서버에 들어가기
평소 들어가시던 방법이 있으면 **그게 제일 빠릅니다.** 처음이시면:
1. **윈도우 키** → `powershell` 치고 **Enter**
2. 검은 화면에 아래를 치고 Enter (아이디·서버주소는 사장님이 쓰시는 것)
```
ssh 아이디@서버주소
```
3. 비밀번호를 물으면 치십시오. 🔴 **치는 동안 화면에 아무것도 안 보이는 게 정상입니다**(별표도 안 나옵니다). 다 치고 Enter.

## 7-2. 명령 한 줄 — 네모 안을 통째로 복사해서 붙여넣고 Enter
```bash
sudo cat /etc/systemd/system/hitpan-backoffice-api.service.d/*.conf 2>/dev/null | grep '^Environment=' | sed 's/^Environment="//; s/"$//' | awk -F'=' '{n=$1; v=substr($0,length(n)+2); gsub(/[ \t]/,"",v); printf "%-34s %s\n", n, (length(v)==0 ? "<<< 비었음 — 위험 >>>" : "값있음 ("length(v)"자)")}'
```
> 💡 검은 화면에서는 `Ctrl+V` 가 안 먹고 **마우스 오른쪽 클릭**이 붙여넣기인 경우가 많습니다.
> 💡 비밀번호를 또 물으면 서버 비밀번호를 치시면 됩니다(`sudo` 때문입니다).

## 7-3. 화면에 나온 것을 그대로 주십시오
왼쪽은 **열쇠 이름**, 오른쪽은 **「값있음 (몇 자)」 또는 「비었음」** 만 나옵니다.
🟢 **값은 한 글자도 안 나옵니다.** 글자 **개수**만 나옵니다 — 그래서 **화면을 통째로 복사해 주셔도 안전합니다.**
🟢 이 명령은 제가 **가짜 파일로 6가지 미리 시험**했습니다(값 노출 0건 · 빈칸·스페이스·탭 3종 전부 포착).

# ✅ 복사용 — **전부 한 번에** 답하실 때

아래를 통째로 복사해서, 각 줄 뒤에 답만 바꿔 주시면 됩니다.

```
1 조임 일수        : 7/14/30
2 시험용 기계      : 남는 PC 있다        (+ 끊는 조작도 승인)
3 가짜 자료 환경   : 승인
4 꾸러미 갱신      : 승인 · 게시는 따로
5 사원번호 칸      : 빼기 + 시험 같이 고치기 승인
6 수수료 결함      : 베타 뒤에
7 빈 열쇠          : (서버 화면 붙여넣기 / 또는 "나중에")
```

🟢 **7번만 시간이 걸립니다(5분).** 1~6 은 **한 줄씩 지우고 고르기**만 하시면 됩니다.
🔴 **급한 순서**: 2번(기계) → 1번(일수) → 5번(칸 빼기). 2번이 **통신 시험 전부**를 혼자 막고 있습니다.
