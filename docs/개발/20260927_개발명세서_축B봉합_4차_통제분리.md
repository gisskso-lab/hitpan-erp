비상으로 끈 고객을 다음 업데이트에서 소리 없이 다시 켠다. (DB-128 은 값 1 이 의도된 적 없어 `UPDATE` 가 맞았다 — 다른 경우다.)
⚠️ 남은 구멍: 컬럼이 **이미 있고 값이 0** 이던 DB 는 이 마이그 뒤에도 0 이다. 고객이 껐는지·손으로 만든 표인지 SQL 로 못 가른다. 정당한 쪽을 지키는 편을 골랐다.
