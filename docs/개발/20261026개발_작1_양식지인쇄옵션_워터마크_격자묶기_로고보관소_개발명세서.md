## §4 갈래 C·D — 렌더와 화면

### C-1 3겹 레이어

`page.Background().Layers(…)` — ①양식지 그림 ②`PrimaryLayer().Extend()` ③워터마크. 본문은 그 위(배경 자리라 글자가 워터마크 위에 보인다 — 사장님 *"내용을 해치지 않을정도"*).
🔴 둘 다 없으면 **Layers 를 아예 만들지 않는다** — 끈 고객의 종이는 종전과 동일.

### C-2 워터마크 SVG

```
<svg …><defs><filter id='hpwm'><feColorMatrix type='saturate' values='{채도}'/></filter></defs>
  <g opacity='{명도}' filter='url(#hpwm)'>
    <image … preserveAspectRatio='xMidYMid meet' xlink:href='data:{mime};base64,{로고}'/>
  </g></svg>
```
🔴 `opacity` 는 **`<g>` 에.** · 숫자는 범위로 조인 뒤 **`InvariantCulture`** · 고객 문자열은 **base64 말고 0건** · mime 은 **허용목록에서 바꿔 적는다**.

### C-3 `print_background` 개방

`ResolveFormBackground` — **인자 0개 추가**, 안의 조건만 넓혔다:
`overrides?.IsFormDesignPreview != true && template?.PrintBackground != true` → `return null`
🔴 경고 주석을 **지우지 않고 고쳐 적었다** — *"끈 고객의 종이에 그림이 새면 그게 사고다"* 는 여전히 참이다.

### C-4 격자 묶기 (결-G)

`CellHead`/`CellBody` 의 `static` 을 떼고 같은 메서드에 **이미 있던** `borderWidth` 를 쓴다. 본은 `PayslipCell`.
🔴 머리칸 **회색 바탕도 끈다** — 양식지 그림 위에 겹칠 때 그 회색이 양식지 칸을 가린다.
🔴 패딩 4→5 보정은 **끌 때만**. `showBorder=1` 종이는 그대로다.

### C-6 미리보기 즉시 반영 (결-J)

`PdfPreviewOverrides` + 5칸 · `ApplyPrintOptions` 의 **조기 반환 조건을 같이 넓혔다**.
🔴 **구멍을 하나 찾아 막았다** — 화면이 만지는 수치는 따로 둔 변수(`_wmOpacity` …)인데 `_form` 에 담는 일을 **저장 때만** 했다면 미리보기는 **옛 값**으로 그려진다. 칸은 있고 숫자를 고쳐도 종이가 안 바뀐다 ⇒ 저장과 미리보기가 **같은 한 벌**(`ApplyWatermarkToForm`)을 쓴다.

### D 화면

양식 편집기: 켬/끔 + 「**공통값 그대로 / 이 양식만 따로**」(결-I) · 수치 3개는 따로 정할 때만 열림 · 열 때 수치가 있으면 「따로」로 열어 준다(안 그러면 저장만 해도 지워진다).
🔴 **세금계산서는 칸을 그리지 않고 까닭을 적는다**(결-K) · 서버도 한 번 더 막는다.
🔴 그림 묶음을 **두 모드 모두** 열고, 안내를 **모드 × 켬/끔 네 갈래 + 법정서식**으로 갈라 각각 참을 말한다.
공통 설정: 양식정보설정 화면에 묶음 + 저장 단추를 **따로** 뒀다(그 화면의 다른 묶음은 아직 저장되지 않는다 — 하나를 눌러 둘 다 저장된 것처럼 보이면 거짓).
