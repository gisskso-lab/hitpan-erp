## 5. 🔴 하단 띠 `?stage=` 를 어떻게 걸었나

- **받는 쪽만** 고쳤다. `CsStatusBar.razor:57`(`Nav.NavigateTo($"/admin/cs?stage={stage}")`)·counts 서버식은 **한 글자도** 안 건드렸다.
- `AdminCsListPage.razor:212-213` — `[SupplyParameterFromQuery(Name = "stage")] public string? StageFromQuery`
- `:220-226` `NormalizeStage` — 허용 4종(`unread`·`open`·`done`·`rated`) **밖이거나 비어 있으면 `"all"`**(= 지금처럼 전체). 모르는 값을 아는 척하지 않는다.
- `:228-241` `OnParametersSetAsync` — 첫 적재와 「쿼리가 바뀐 때」만 `_stageFilter` 에 걸고 다시 조회한다. `OnInitializedAsync` 의 최초 조회를 여기로 옮겼다(두 번 조회 방지).
- **사람이 콤보로 고른 단계를 쿼리가 덮지 않는다** — `_appliedStageQuery` 와 같으면 조회하지 않는다(`:231-234`).
- 서버 쪽은 이미 `stage` 를 받고 있었다(`CsAdminController.cs:115`·`:150-155`) ⇒ **쿼리 0줄 수정**.

## 9. 🔴 [4] 검증에 넘기는 과녁

1. **브라우저 실물** — 2단·접힘·폭별 거동·`?stage=` 클릭 왕복·다이얼로그 5칸. 나는 **0회** 띄웠다.
2. **게이트 DB 공유 함정** — `HITPAN_BO_GATE_DB` 를 **한 DB 로 여러 게이트 클래스에 쓰면 애먼 게이트가 빨간불**이 된다. 내가 실측했다: `test_w7_bo` 를 네 클래스에 돌려쓰자 `CsKbGate` 가 `Table 'test_w7_bo.bo_kb_docs' doesn't exist` 로 **2건→5건 사이에서 들쭉날쭉 FAIL**(같은 코드·같은 명령에 다른 실패집합 ⇒ 재현적 초록/빨강이 아니다), **각자 DB** 로 가르자 **9/9 초록**. ⇒ 재측정 때는 게이트 클래스마다 다른 DB 를 쓸 것. 🔴 **원인은 확정하지 못했다**(표를 지운 주체를 눈으로 못 봤다 — 가설은 「앞 실행이 남긴 상태 + 적용기 재적재 타이밍」이고 **실측 전엔 가설이다**).
3. **합류 전 도달 불가 기능**(§4) — 갈래③ 합류 없이 게시하면 선발신·보관기한·「지금 준비하기」가 UI 에서 사라진 상태로 나간다.
4. **G-W7-2 가 못 무는 자리**(§6-4) — `.razor` 에 옛 인라인 식을 다시 적어 넣는 경로.
5. 내가 만든 시험 DB: `test_w7_b2`·`test_w7_adm`·`test_w7_kb`(+ 기존 `test_w7_bo`·`test_w3_regress`). 재측정 뒤 지워도 된다.
