## §2 [1-V] 원인 확정 — 「고쳤다 ≠ 갔다」

### 2-1 증상 모양부터 갈랐다

`DocumentPrintPreviewDialog.razor:175~185` 에는 갈래가 **둘**이다.

| 갈래 | 문구 | 뜻 |
|---|---|---|
| `!ok` | 「브라우저가 **인쇄창을 막았습니다**」 | JS 가 돌았고 `false` 를 돌려줬다(팝업 차단) |
| `catch` | 「**인쇄창을 띄우지 못했습니다**」 | 🔴 **JS 호출 자체가 예외** |

사장님 화면은 **catch 문구**다 ⇒ **팝업 차단이 아니다.**
`storage.js:308~329` 의 `hitpanPrintPreviewFrame` 은 안에서 전부 `try/catch` 하고 `bool` 만 돌려준다 — **던지는 경로가 없다.**
⇒ 남는 경우는 하나: **그 함수가 브라우저에 없다.**

### 2-2 측정 (git)

| 사실 | 값 |
|---|---|
| `hitpanPrintPreviewFrame` 을 `storage.js` 에 넣은 커밋 | `15a26869` (이번 릴리스) · **+33줄** |
| 이번 게시 범위(`33d2057d..4f98aa27`)의 `index.html` 변경 | 🔴 **0건** |
| `index.html:81` 꼬리표 | 🔴 `js/storage.js?v=`**`20260928c`** — 9/28 값 그대로 |
| 그 규칙 | `index.html:78~80` 에 **N-4 로 명문화** — *"storage.js 가 바뀌었다 ⇒ 꼬리표를 올린다"* |
| 그 규칙을 지키는 **게이트** | 🔴 **0건** (주석만 있었다) |

⇒ 브라우저가 **9/28 판 `storage.js`** 를 캐시에서 꺼내 쓴다 → 함수 없음 → JS interop 예외 → catch 문구.

### 2-3 🔴 왜 2,687건이 전부 초록이었나

**주석은 코드가 아니다.** 규칙에 게이트가 없으면 규칙이 아니다.
고친 것이 **브라우저에 도달조차 못 했는데** 모든 시험이 초록이었다 — 「고쳤다 ≠ 갔다」 **8차 재발**.

### 2-4 미리보기는 왜 멀쩡했나 (증상 정합)

미리보기는 서버가 그린 PDF 를 **iframe `src`** 로 받는다 — **JS 를 안 탄다.**
JS 를 타는 것은 **「인쇄」 단추 하나뿐**이다. ⇒ 7/7 통과 + 인쇄만 죽음이 **정확히 같은 뿌리에서 설명된다.**

| 꼬리표 | 내용은 그대로인데 **꼬리표만 되돌렸다**(봉합 무음 되돌림 차단) |
