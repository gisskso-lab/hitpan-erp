## 11-1 🔴🔴 S-1 — 검증팀이 **실제로 뚫었다**

| | |

| 내가 넣은 것 | `PassesThroughLink(경로, **테넌트 폴더**)` |
| 🔴 그 함수의 성질 | `dir.FullName.Length > rootNoSep.Length` — **뿌리 자신을 검사에서 뺀다.** 뿌리는 관리자가 정한 자리라는 뜻이었다 |
| 🔴 그래서 무엇이 열렸나 | **테넌트 폴더가 junction 이면 아무도 안 봤다.** 읽는 쪽은 뿌리를 `FormBackgroundPaths.Root` 로 넘겨 그걸 잡는데 **내 쪽만 한 칸 안**이었다 |
