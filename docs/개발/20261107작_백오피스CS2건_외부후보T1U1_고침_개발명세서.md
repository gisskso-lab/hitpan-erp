- 영향: 둘 다 고객사 상세 화면 · 표시줄은 `"%2F"` 로 서버에 물어 found=false(「고객사를 찾지 못했습니다」). 상세 화면도 `"/"` 고객사는 없음. 혼입 0 · 노출 0(서버 `=` · 인자 · PlatformAdmin). 손으로 친 주소에서만.
- 길 찾기 꼴에 맞추려면 「풀린 값 안 `%2F`(대소문자 무시)를 `/` 로 한 번 더」 같은 예외 규칙이 필요 → C-8 「이중 풀기 금지」 와 부딪힘 · 범위 밖 → 칸에 넣지 않았다. 고칠지 · 기록만 할지는 PM 결정.
