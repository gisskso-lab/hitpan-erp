## 5. PM 확인 ① — K4 에 스타일 먹음 ↔ 대표 §49 「기본 폼 유지」

- §49 글자: 「칸 모양 인쇄는 그림 있는 빈 A4(Y 템플릿)에만 · 옛 좌표만 남은 빈 A4 = **main 처럼 기본 폼**」. 물음이 가른 축 = **칸 모양(좌표) ↔ 기본 폼(표준 머리 · 표)** 이다. 스타일 4종은 시안 §0 「칸 위치 · 순서 · 열 너비 안 바뀜 · 바뀌는 것 = 글꼴 · 크기 · 선 · 회색」 = 기본 폼 안의 그리는 꼴 ⇒ 다른 축.
- 먹지 않게 하면 K4 만 「고객이 고른 스타일을 조용히 버리는 순백지」 가 되고, 같은 순백지 좌표 0 양식과 다르게 그려진다 — §49 가 바란 「main 과 같은 기본 폼」 을 오히려 K4 에서만 특례로 만든다.
- 「main 처럼」 글자: main 은 스타일 칸을 안 읽어 늘 basic. 지금 K4 행의 `style_key` 는 화면 고르는 칸이 생긴 적 없고 DDL 기본값이 `basic` ⇒ **지금 고객 K4 종이 = main 과 같음**(관찰 가능한 차이 0 · 정적). 차이가 생기는 때 = Q-D 화면이 생겨 고객이 K4 양식에 스타일을 고른 뒤 — 그건 고객의 선택이다.
- **판정: 어긋남 없음(조건부)** — 조건: PM 기록에 「§49 기본 폼 = 칸 모양이 아닌 표준 머리 · 표 경로 · 스타일 축은 별개」 유권해석 1줄을 남기고, Q-D 화면 설계 때 같은 줄을 따른다. 대표 재질문은 불요로 보나(지금 차이 0), PM 이 「main 처럼」 을 「basic 고정」 으로 읽는다면 그때는 대표 몫.

## 6. 멈춤 ⑵ (가) 지금 꼴 — 검증 의견

- (가) = 품명 3 : 규격 2 그대로 + 기본 줄바꿈 · 줄 수 제한 0. 품명 **잘림 0** 은 지켜진다(제한 · 높이 고정 0 확인 :835).
- 그러나 F1 대로 숫자 칸이 이미 M4 를 못 넘을 계산이고, F3 대로 품명 2자 · 규격 1자/줄이라 큰글씨의 목적(멀리서 읽기)과 어긋난다. 「너비 그대로」 와 「넓힘」 둘 다 대표가 허용했으므로(§11 #3) **수치 산정 1건(설계팀장)** 으로 숫자 칸 안쪽 · 글자 크기 · 품명 비율을 함께 다시 정하는 것이 R1 런 낭비를 막는다. 수치는 검증이 정하지 않는다.
