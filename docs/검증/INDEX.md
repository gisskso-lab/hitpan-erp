```
      ↓
[5] 작업리뷰서 + 병렬이슈 참조 → CTO 래리 → 사장님 결재 (→ 운영기록/)
      ↓
[6] 🔴 결재 + 검증 통과 = 무조건 커밋   ← 1파츠 완성
```

> ## 🔴 SoD — 만든 사람 ≠ 검증하는 사람
> **구현한 사람은 여기 못 들어온다.** 자기검증은 거짓봉합을 통과시킨다.
> 검증은 "됐다"를 확인하는 게 아니라 **"안 되는 경우를 찾는 것"**이다.
