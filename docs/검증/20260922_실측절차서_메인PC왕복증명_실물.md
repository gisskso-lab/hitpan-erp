## 0. 왜 사람이 해야 하나 — PM 이 혼자 못 하는 세 가지

| 막힌 것 | 이유 |
|---|---|
| **UAC 창** | 이 PC 의 API 를 갈아끼우려면 `C:\Program Files\HitPan` 을 건드려야 한다. **읽기조차 거부**된다. UAC 는 사장님이 직접 누르셔야 한다 |
| **실제 브라우저 창** | 🔴 **헤드리스로 재면 결과가 정반대로 나온다** — `headless:true` 는 loopback 을 거부하고, 실제 창은 200 이다. 자동화로 재면 그 초록·빨강 **둘 다 거짓**이다 |
| **모바일·다른 PC** | G-2(클라이언트 판정)·G-8(브라우저 교체)은 **다른 기계**가 있어야 성립한다 |

## 2. 🔴 시작 전 — 되돌릴 자리를 먼저 만든다

**관리자 권한 PowerShell** 에서:

```powershell
# ① 지금 것을 통째로 옆에 복사한다. 이것이 되돌릴 자리다.
$stamp = Get-Date -Format "yyyyMMdd_HHmmss"
Copy-Item "C:\Program Files\HitPan\api" "C:\Program Files\HitPan\api.bak_$stamp" -Recurse
Write-Output "되돌릴 자리: C:\Program Files\HitPan\api.bak_$stamp"
```

⚠️ **이 줄을 건너뛰지 마신다.** 실측이 잘못돼도 이것만 있으면 5분 안에 원래대로 돌아온다.
⚠️ 히트판을 쓰는 다른 분이 있으면 **미리 알리신다** — 실측 중에는 잠깐 멈춘다.

## 3. 새 코드를 올린다

**일반 PowerShell** (관리자 아님) — 레포에서 만든다:

```powershell
cd C:\Users\소순근\Desktop\hitpan-erp
git log -1 --format="%H %s"      # 047885a9 … 인지 확인
dotnet publish src\HitPan.API\HitPan.API.csproj -c Release -o C:\Users\소순근\Desktop\hitpan-api-new --nologo
```

**관리자 권한 PowerShell** — 갈아끼운다:

```powershell
# ② 멈춘다
Stop-Process -Name "HitPan.API" -Force

# ③ 바꿔 넣는다
Copy-Item "C:\Users\소순근\Desktop\hitpan-api-new\*" "C:\Program Files\HitPan\api\" -Recurse -Force

# ④ 다시 띄운다
& "C:\Program Files\HitPan\hitpan-start.bat"
```

**확인 — 새 코드가 올라갔는가** (일반 PowerShell):

```powershell
# 왕복의 ② 는 토큰 없이 통과해야 한다. 200 이면 새 코드다. 401 이면 아직 옛 코드다.
Invoke-WebRequest -Uri "http://127.0.0.1:5257/api/devices/mainpc-proof" -Method POST `
  -Body '{"challenge":"없는표"}' -ContentType "application/json" -UseBasicParsing
```

| 결과 | 뜻 |
|---|---|
| **HTTP 200** + `{"confirmed":false}` | 🟢 새 코드가 올라갔다. **다음으로 간다** |
| **HTTP 401** | 🔴 아직 옛 코드다. ③이 안 들어갔거나 기동이 안 됐다 |
| 연결 거부 | 🔴 API 가 안 떴다. `hitpan-start.bat` 을 다시 실행 |

🟢 `confirmed:false` 가 맞다 — 없는 표를 냈으니 거절이 정상이다. **우리가 보려는 것은 200 이라는 사실**이다.

## 4. 실측 — 게이트별로 무엇을 보나

### 🔴 공통 규칙
- **반드시 실제 브라우저 창**으로 한다. 자동화·헤드리스 금지(§0)
- 브라우저 **개발자도구 → 콘솔·네트워크**를 열어 둔다. `mainpc-proof` 요청이 보인다
- 접속은 **도메인**으로 한다 (`localhost` 로 열면 옛 경로라 이번 봉합을 안 지난다)
- 계정: 실측 기준 계정 · 도메인은 [실측 기준 메모](../../CLAUDE.md) 의 테스트 계정을 쓰신다

### G-1b — 🔴 이번 봉합의 수문장
1. **메인PC(이 PC)** 에서 **도메인**으로 히트판을 연다
2. 로그인한다
3. 네트워크 탭에서 순서를 본다: `mainpc-challenge` → `mainpc-proof`(127.0.0.1) → `mainpc-verify`

| 통과 | 실패 |
|---|---|
| `mainpc-verify` 응답이 `isMainPc: true` (또는 `outcome: NotRegisteredYet` → 등록 팝업) | `mainpc-proof` 가 **401/차단**이면 봉합이 안 올라갔다 · `confirmed:false` 로 끝나면 브라우저가 loopback 을 막은 것이다 |

### G-18 · 등록 팝업 (첫 회)
4. 미등록이면 **[메인PC 등록]** 팝업이 뜬다 → 누른다
5. 등록 직후 **자료가 비어 있으면** 「자료 복구」 안내가 떠야 한다

⚠️ 팝업은 **대표(부모계정)에게만** 뜬다(결재 D-8). 자식계정으로 로그인하면 안 뜨는 것이 정상이다.

### G-1 · G-11b — 자료관리가 열리고, 팝업은 다시 안 뜬다
6. **설정 → 자료관리** 로 들어간다 → 🟢 **열려야 한다**(종전에는 403)
7. 로그아웃 → 다시 로그인 → 🟢 **팝업이 안 떠야 한다**(결재 D-7). 바로 들어간다

### G-2b · G-12 — 클라이언트 PC 는 반대여야 한다
8. **다른 PC 또는 휴대폰**에서 같은 도메인으로 로그인한다
9. 🟢 자료관리가 **안 열려야** 한다 · 🟢 등록 팝업도 **안 떠야** 한다
10. 🔴 **여기서 열리면 그것이 사장님이 잡으신 결함 ④ 의 재발**이다 — 즉시 멈추고 알려 주신다

### G-8 — 브라우저를 바꿔도 같다
11. 메인PC 에서 **Edge → Chrome**(또는 반대)로 바꿔 3~7 을 반복한다 → 🟢 같은 결과

### G-9 — 종전 경로가 여전히 된다 (무회귀)
12. 메인PC 에서 `http://localhost:5234` (또는 종전에 쓰던 로컬 주소)로 열어 자료관리 → 🟢 **열려야 한다**

### G-13b · G-14 — 컴퓨터가 바뀌면 안다 (⚠️ 예비 PC 가 있을 때만)
13. 예비 PC 에 히트판을 깔고 **자료관리 → 백업 복원**으로 이 PC 의 자료를 넣는다
14. 예비 PC 에서 로그인 → 🟢 **[메인PC 변경]** 팝업이 떠야 한다(봉인이 안 풀린다)
15. 변경을 누른다 → 🟢 기기 목록에서 **메인PC 표식이 1줄**이어야 한다

⚠️ 13~15 는 **예비 PC 가 없으면 하지 않는다.** 이 PC 하나로는 못 잰다.

## 5. 🔴 다 끝나면 — 되돌릴지 결정한다

실측이 끝나면 **이 PC 를 어떤 상태로 둘지** 사장님이 정하신다.

| 선택 | 방법 |
|---|---|
| **원래대로 되돌린다** (권합니다 — 이 코드는 [4] 검증 전이다) | 관리자 PS: `Stop-Process -Name "HitPan.API" -Force` → `api.bak_<시각>` 을 `api` 로 되돌림 → `hitpan-start.bat` |
| **새 코드로 둔다** | 아무것도 안 한다. ⚠️ 단 **[4] 검증 전 코드가 사장님 실사용 PC 에 남는다** |

⚠️ 어느 쪽이든 **다음 자동업데이트가 오면 그것으로 덮인다.** 자동업데이트가 정식 교체 경로다.

## 6. 실측 결과를 어디에 적나

게이트별로 **🟢통과 / 🔴실패 / ⬛미실시** 와 **본 것 그대로**를 적는다.
추정은 적지 않는다 — 「안 열렸다」와 「왜 안 열렸다고 생각한다」를 섞지 않는다.

| 게이트 | 결과 | 본 것 (화면·응답·콘솔) |
|---|---|---|
| G-1b 메인PC + 도메인 | | |
| G-18 빈 DB 복구 안내 | | |
| G-1 자료관리 열림 | | |
| G-11b 팝업 1회만 | | |
| G-2b 클라이언트 차단 | | |
| G-12 클라이언트 팝업 없음 | | |
| G-8 브라우저 교체 | | |
| G-9 localhost 무회귀 | | |
| G-13b·G-14 다른 PC | | |

🔴 **한 건이라도 🔴 면 거기서 멈춘다.** 뒤 게이트를 이어서 재면 원인이 섞인다.

## 7. 이 절차서가 못 하는 것

- **자동으로 돌려 주지 않는다.** §0 의 세 가지 때문이다
- 🔴 **되돌리기(§5)를 안 하면 [4] 검증 전 코드가 사장님 PC 에 남는다**
- G-13b·G-14 는 **예비 PC 가 없으면 못 잰다** — 그때는 ⬛미실시로 남긴다. 「됐을 것」로 적지 않는다
- 이 절차는 **운영 DB 를 수술하지 않는다.** 등록·변경은 화면으로만 한다(#39)
