## §2 ⑦ 채택 조건 (이것 없으면 ⑦ 읽기 = 반려로 바뀜)
- ⓐ **실행된 자체시험**: `font-rename.selftest.py` 가 이 PC 에서 실제로 돌아 ① 손질 켬 → 역대응 0x20 초록 ② 손질 끔(대조군) → 0x01 + 사유 빨강 ③ D14-6 ID 0 바이트 대조 초록 · 변이(다른 글자) 빨강 — 넷 다 출력 원문을 개발명세서에. 문법 검사 통과는 「자체시험 0건」 으로 센다.
- ⓑ **자기 확인 막기**: 시험은 `fix()` 가 적은 `reverseSpace` 를 그대로 믿지 않는다 — 저장된 글꼴을 **다시 열어** 시험 쪽 규칙(코드 오름차순 · 칸이 0 일 때만 · U+0000 빈칸 취급 = [1-V] ① 렌더 원문 규칙)으로 따로 셈 → 사실 칸과 같아야 초록. 대조군 0x01 이 R6 실측(U+0001 3,636 · [1-V] ①)과 같은 꼴이라는 한 줄을 명세에 이어 적음 = 시험 규칙의 닻.
- ⓒ **남은 위험 그대로 알림**: 리눅스 실렌더 = R1 T8 띄어쓰기 견본이 첫 실측 · 못 읽으면 판정 0 = 1번 잃음(앞 판정 §6 ①) — 대표 push 직전 보고에 한 줄. 판정기 쪽 T-D14-1(`print.selftest.js`)은 이 PC 에서 그대로 실행 대상(도구 차이 없음).
