## §0 읽는 법

- **이 갈래의 등급 해석(한 줄)** — 「P0」 = 판정식 ⓐ(출하 차단 결함 5종)·ⓑ(업무 불능 실측)에 들고, **베타 첫 고객(차수 1) 투입 전**에 닫혀야 하는 것 · 「베타 필수(P1)」 = 판정식에 들지만 **10개사 도달 전**에 닫으면 되는 것. ① 범위표의 3분류(베타 필수 / 서버 비활성 후 정식 이후 / 제안 보류)와는 다른 축이다 — P0 는 「베타 필수」 안의 우선순위다. 정의 결재 없음 ⇒ 합본 쟁점.
- **재현 증거 상태** — 「실측」 = 사장님 또는 승인된 실측 기록이 있다 · 「정적 코드뿐」 = 조사서·임원·GPT 가 코드를 읽었을 뿐 돌려 보지 않았다(몇 명이 독립으로 읽었는지 적는다) · 「재현 필요」 = 정적 근거도 갈리거나 동작 여부가 결과를 가른다.

- **막는 결재** — 🟢 = 결재문에 사장님 원문이 있다 · ⬜ = 아직 없다.
