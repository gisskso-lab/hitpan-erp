## §0 읽는 법

- **판정 순서**(메모리 10/20 · #18·#22) — ① 운영(과금·CS·설치·장애)에 **필요한가** → ② 필요하면 받는다 · **왜 필요한지 글로 남긴다** → ③ 불필요하면 받지 않는다 → ④ 🔴 **업무 자료(장부·거래처·단가·매출·재고·계산서)는 별 축** — 필요성과 무관하게 본사는 받지 않는다.
- **결재 안 3값(제안)** — **받는다**(운영에 필요 · 이유 글 있음) / **안 받는다**(이유 글이 서지 않음 또는 업무 자료) / **동의 후**(고객의 명시 동의 기록이 있어야 나간다). §2 「회사 밖(본사 아님)」 행은 같은 3값을 「이 길로 나가는 것을 허용 / 막음 / 동의 후」로 읽는다.
- **3분류 해석(합본 쟁점 대응 한 줄)** — 이 조각은 ①-1 의 3분류(베타 필수 / 서버 비활성 후 정식 이후 / 제안 보류)를 쓰지 않는다. ⑤ 의 분류 축은 **결재 안 3값**이고, 베타 범위 연결은 「G4 연결」 칸에만 적는다.
- **업무 자료 칸** — 「구조상 칸 없음」(전송 자료에 업무 자료 자리가 없다) / 「자유글 유입 가능」(칸은 없으나 사람이 적어 넣으면 간다) / 「예」 / 「미측정」.
- **근거** — 10/20 실측 절 번호(A-n · B-n · 6-1 본사n 등) 또는 조사서 행ID(02-A7 · 04-S6 · 06-24 형식). 🔴 공개 레포 — 소스 경로·줄 번호는 새로 적지 않는다(근거 문서에 이미 있다).
- **법무 후보** ○ = 법무팀장 확인 후보(개인정보 수집·처리위탁·국외 이전·보관·파기·고지 문구). 판정이 아니다.
