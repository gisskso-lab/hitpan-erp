## §5 대조 — 명령과 결과

```bash
# 레포 루트에서 · S = 진실원 사본(git show origin/main:docs/베타배포_진실원.md > $S/d2_truth.md) · F = 이 파일
# ① 이 파일 행 수
grep -c '^| C-0[0-9] |' $F                 # → 8
grep -c '^| D-[0-9][0-9] |' $F             # → 77
grep -c '^| T-[0-9] |' $F                  # → 4      (합 89)
# ② 진실원 항목 표 데이터 행(L190~L494 · 머리줄 8개 · 제외표 L277~281·L420~428·L458~474 뺌)
awk 'NR>=190&&NR<=494 && /^\| / && !/^\|---/ && !(NR>=277&&NR<=281) && !(NR>=420&&NR<=428) && !(NR>=458&&NR<=474) {print NR}' $S/d2_truth.md \
 | grep -v -x -e 190 -e 215 -e 235 -e 247 -e 289 -e 315 -e 353 -e 385 > $S/d2_tbl.txt   # → 43
# ③ 이 파일이 가리키는 진실원 줄(고유) · 빠진 표 행
grep -o '^| [CD]-[0-9]* | [^|]*L[0-9]*' $F | grep -o 'L[0-9]*$' | tr -d L | sort -u > $S/d2_mine.txt   # → 70
comm -23 <(sort -u $S/d2_tbl.txt) $S/d2_mine.txt                                                     # → (빈 출력 = 표 항목 43줄 전부 대조됨)
# ④ D행 짝 칸
grep '^| D-[0-9][0-9] |' $F | awk -F'|' '{g=$7; gsub(/ /,"",g); if(NF==9 && g!="") n++} END{print n}'  # → 77
```

|---|---|---|
| **진실원 항목 수 = 대조 행 수** | 진실원 항목 = 표 항목 행 **43** + 표 밖 항목 줄 **27**(§0 ⓑ 규칙 · 고유 줄 70 − 43) + 한 줄 쪼갬 **+15**(L200 +1 · L268 +6 · L485 +8) + §7 **4** = **89** / 대조 행 = 8 + 77 + 4 = **89** | 🟢 일치 · 표 항목 43줄 누락 0(③ 빈 출력) · 🔴 표 밖 27줄은 **이 갈래의 판단으로 고른 것**(§0 제외 목록 공개) — 명령이 고른 것이 아니다 |
