### 3분류 — 이 갈래가 읽은 뜻 (PM 합본 때 다른 갈래와 맞출 것)

- **베타 필수** = 베타 사용 경로에 남긴다. 판정식 ⓐ·ⓑ 에 걸리는 결함이 있으면 그 결함만 G1 에서 봉합한다. 결함이 없으면 「동결(손대지 않음)」.
- **서버 비활성 후 정식 이후** = 베타에서 뺀다. 화면 숨김이 아니라 **서버 API · 권한 · 상태표시**까지 막고, 고치는 일은 정식 이후로 미룬다(작업지시서 §1 「비노출은 화면 숨김이 아니라 …」).
- **제안 보류** = 분류가 아직 내려지지 않은 사장님 결재(K) 또는 원문 근거에 달려 있어, 이 갈래가 분류를 제안하지 못한다.
