**표기**
- 7영역 방향 칸: `ERP·정합` = 흐름 정합성 · `ERP·손실` = 데이터 손실 방지 · `ERP·외곽` = 핵심 흐름 밖(관리·보조).
- 판정식 근거 칸: ⓐ 5종 = 업무중단 / 불일치(원장·재고·데이터) / 손실 / 권한침범 / 법적오인 · ⓑ = 대표·승인된 실측으로 입증된 누락. 「후보」 = 코드 근거만 있고 재현 증거 없음.
- 경로 칸: ERP 화면은 전부 고객 PC 로컬 + 터널 도메인 · **로그인 뒤**. 익명 외부 노출 행은 이 조각에 없다.
- 재현 칸: `코드` = 조사서의 파일:줄 근거만 · `원문` = 사장님 원문 인용 있음 · `없음` = 실측·재현 0.
- 독립검증 칸: 조사서를 쓴 갈래(만든 쪽) ≠ 이 조각(분류 쪽). [4]·[3-V] 는 아직 0.
- 분류가 「서버에서 실행 가능한 경로인가」에 달린 행(25·33·36)만 코드를 다시 열었다(§11 미결2) — §2 에 적었다.
