## §1 [읽는 법]

- **한 표 체계** — §2 는 17행 · 칸 10개를 같이 쓴다. 「구분」 = P0(31 출처) / N(32 출처).
- **제안 분류 어휘** — P0 행: P0 유지 · 승격 · 조건부 승격 · 승격 보류(P1 유지) · 이관. N 행: 필수 수정 · 안전한 비노출 · 고객 고지(뜻은 32 §0 한 줄 정의 그대로).
- **P0 의 뜻(31 §0 해석 · 결재 없음)** — 판정식 ⓐ·ⓑ 에 들고 **베타 첫 고객(차수 1) 투입 전**에 닫혀야 하는 것. 범위표 3분류와 다른 축이다(P0 = 「베타 필수」 안의 우선순위) → ⬛낡음: ~~경계 정의는 K55 에 달림~~ → 🆕 K55 는 **등급 채택만** 묻는다(10_ 2단계 K55 · ⓪-3 상신본 묶음 3) — 경계 정의를 묻는 결재 칸은 없다 · 따로 물을지는 PM(§4 2번 · §5 2)).
- **재현 증거** — 실측 / 정적 코드뿐(독립으로 읽은 수) / 재현 필요(31 §0 정의).
- **임원 반증** — [90](../전수조사_20261027/90_임원반증_CTO_보안상무.md)·[91](../전수조사_20261027/91_임원반증_2_CTO_보안상무.md) 행 번호 · 「반증 전」 = 90·91 이 판정하지 않았다(N 7행은 90·91 에 N 번호 0 — §6 셈).
- **소관** — G0-S / G1(W 묶음 = 종합 §3). N 행의 G1 은 32 §0 처우 정의(필수 수정 = 베타 전 G1)를 따른 것이고 W 번호는 32 가 적은 행만 옮겼다.
- **출처** — 조각 파일 절 + 범위표 행ID. 세부 근거·G2 부딪힘 전문은 출처 칸을 연다.
