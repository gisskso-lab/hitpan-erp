## §0 읽는 법

- **7영역 방향**(ERP 온보딩 줄 원문 — 오더접수:58) = 「설치 성공뿐 아니라 첫 업무 완료까지 검증」 — 칸에는 그 행이 닿는 축(**설치 성공 / 첫 접속 / 첫 업무**)만 적는다.
- 🔴 **3분류 해석(이 갈래 · 한 줄)**: **베타 필수** = 베타 고객의 「설치 → 첫 로그인 → 첫 업무」 동선 위에 있어 빼면 동선이 끊기는 행(그 행의 일 = ⓐ 결함 닫기, 결함이 없으면 **G2 실측 증거 확보만** · 새 기능 0) · **서버 비활성 후 정식 이후** = 빼도 동선이 안 끊기고, 뺄 때 화면 + 서버 입구·권한·상태표시를 같이 닫는 행 · **제안 보류** = 분류가 아직 없는 결재(K 또는 새 K 후보)에 달린 행. ⚠️ 16 랜딩 조각은 「베타 필수 = 결함 닫기」만 셌다 — 이 조각은 **무결함 동선 행도 베타 필수(일 = 실측뿐)** 로 센다 ⇒ 합본 때 맞출 것(§4).
- **판정식**(§1) — ⓐ 베타 사용·외부 노출 경로의 출하 차단 결함 5종(업무 중단 · 원장/재고·데이터 불일치 · 손실 · 권한 침범 · 법적 오인) · ⓑ 대표·승인된 실측으로 업무 불능이 입증된 누락. 이 영역은 **ⓑ 근거 0행**(사장님 실측 원문이 붙은 S22~S25 는 「통과」라 누락 입증이 아니다).
- **재현** — 04·보충3 모두 새 실측 0. 증거 = 조사서 행(정적 코드). 사장님 실측은 S22~S25 의 1.3.53 G-8 뿐이고, 그 원문 대조는 ②(B2) 몫.
- **코드 재열람**(§11-2) — 분류가 「서버에서 실행 가능한 경로인가」에 달린 행 **S16·S18·S19** 만 기준판 `b9f34ccd` 를 다시 열었다(결과는 그 행에 「🔎재열람」). 나머지는 조사서 행 열람으로 근거를 인정.

## §4 한계 · 반증 · 합본 쟁점

**독립 반증 (만든 사람 아닌 눈 · 「안 되는 경우」)**
1. 🔴 **「베타 필수 아님」 쪽에 숨은 출하 차단 결함** — S14 는 비노출로 둘 수 없다. 설치기가 두 번째 회사를 막지 않으므로 **아무 결정도 안 하면 결함이 베타 경로에 그대로 열린다**(S9 와 합쳐 첫 회사 업무 중단). 「제안 보류」가 「안 해도 된다」로 읽히면 안 된다.
2. 🔴 **「서버 비활성」이 실제로 닫히나** — S19 를 비활성으로 고르면 화면은 숨어도 익명 설치 입구 둘은 터널로 열린 채다. 설치기가 같은 입구를 쓰는지 호출처 전수 전에는 「닫을 수 있다」고 말할 수 없다(코드 확인 필요).
3. 🆕 **조사서에 없던 것** — S16 약관 동의 기록의 IP 칸이 터널 경유면 전원 같은 루프백 값일 수 있다(가설 · 실측 0). 3시스템 헌법 「동의 일시·IP·약관 버전 DB 기록」 이 글자로는 지켜지고 증거로는 무력일 수 있다 ⇒ G2 실측 회차에서 DB 한 줄 확인 + 법무팀장.
4. **「통과」 4행의 근거 강도** — S22~S25 는 PM 인계서 2차 기록이고 원문 미열람(04 §E). 같은 판 01a 표본이 임원 판정 「약함 · 성립」 이라 성립 쪽으로 보이나, ② B2 원문 대조 전에는 「대표 실측」 표로 못 옮긴다.
5. **K2 가 덮는 것은 S4 하나** — 설치 행 수선(S1·S7·S10·S13 · 필요해지면 S12)은 10/8 무접촉 그대로라 **아직 없는 결재**에 막혀 있다 ⇒ WBS 에서 G1 설치 갈래가 결재 대기로 멈출 위험.

**한계** — 새 실측 0 · 운영 읽기 0 · 재열람은 S16·S18·S19 세 행의 분류 근거만(전체 재조사 아님) · 메모리 인용(S2·S14·S16 일부)은 PM 기록이라 원 대화 미열람 · 보충3 가 「결재 원문 미열람」이라 적은 S20(10/5 결재)도 이 갈래가 다시 열지 않았다.

**합본 쟁점 (①-2 로 올림)**
- 🔴 3분류 해석 차이 — 이 조각은 무결함 동선 행 13개(실측만 9 + 통과 4)를 「베타 필수」로 셌다. 16 랜딩 식(결함 닫기만)으로 세면 이 영역 베타 필수는 9 로 줄고 13 행은 분류 칸이 빈다 ⇒ 합본 첫 작업(3분류 정의 하나로)에서 「무결함 동선 행」 칸을 따로 둘지 결정.
- **새 K 후보 3** — ⓐ 다중 사업자(한 PC 두 회사)를 베타에 넣나(S9·S14 · 6/9 구현 결재와 별개) ⓑ 설치기 수선의 10/8 무접촉 **별도 부분 해제**(S1·S7·S10·S13 · K2 범위 밖) ⓒ 약관 동의 IP 기록 기준(S16 · 법무).
