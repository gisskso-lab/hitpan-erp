## §0 이 파일이 쓴 해석 (합본 때 갈래 간 통일 대상)

- **3처우의 뜻(한 줄)**: **필수 수정** = 베타 전(G1) 동작을 고친다 → 범위표 「베타 필수」 · **안전한 비노출** = 메뉴·모바일 입구·서버 API 문·권한·상태표시까지 닫아 고객이 못 닿게 하고 정식 이후로 미룬다 → 범위표 「서버 비활성 후 정식 이후」 · **고객 고지** = 동작은 두고 화면·내보내기에 한계를 사실대로 적는다(문구 수정은 G1) → 범위표 「베타 필수(고지 한정)」.
- 판정식 ⓐ 5종 = 업무 중단 · 원장/재고·데이터 불일치 · 손실 · 권한 침범 · 법적 오인(작업지시서 §1).
- 🔴 비노출을 고르려면 「화면 숨김 ≠ 차단」 — 서버 API 문·권한·상태표시를 함께 본다. 이관(G2)이 쓰는 표면은 비노출 금지(14 조각 쟁점).
- 코드 재열람 = 분류가 갈리는 4곳만(N-1 기간 조건 위치 · N-5 등록/삭제 검사 위치 · N-7 요청 검사 · 이관의 출납장 쓰기 여부) — HEAD 에서 조사서와 같은지 grep 만. 결과는 각 행 「재현 상태」 칸.
- G0-S 소관 행: 없음(N-1~N-7 은 익명 입구 2곳과 무관).
