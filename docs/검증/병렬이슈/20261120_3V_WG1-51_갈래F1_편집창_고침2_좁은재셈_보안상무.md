- **앞 재셈의 근거(「서버가 늘 엄격한 쪽이라 거짓 유지 0」)는 이제 성립하지 않는다.** 대신 근거가 바뀐다: 같은 식 · 같은 입력(열 때 경로 = DB 현재 경로)이면 서버 「유지」 ⇔ 화면 「같음」 → **확인창과 「유지」 가 정확히 여집합**. 둘 다(이중) · 둘 다 아님(조용한 Y 사라짐) 모두 0. 앞 P3-B 는 닫힘.
- **거짓 「유지」(다른 그림인데 같다고 봄) = 0.** 대소문자 · 앞뒤 공백만 다른 두 경로가 서로 다른 파일이려면 대소문자를 가리는 폴더가 있어야 한다. 올리기 이름 = 시각 + 소문자 GUID + 소문자 확장자(`FormBackgroundStore.cs:90`) → 올리기로는 만들 수 없음. 손으로 적은 경로도 회사 울타리 대조가 대소문자 무시(`FormTemplateService.cs:1111`)이고 Windows 기본 폴더는 같은 파일을 연다. 히트판이 대소문자 가리는 폴더를 만드는 길 0.
