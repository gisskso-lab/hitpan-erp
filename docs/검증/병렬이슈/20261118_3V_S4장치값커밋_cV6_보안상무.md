## 반증 3 — 4회차 잔여 위험(바깥 환경 · git 설정 훅)에 새로 더해진 면

**P3-2 (기록 · 사람 실행 도구)** — 새 시험의 격리는 **쓰기**만 막고 저장소 **훅**은 막지 않는다. 버리는 임시 저장소에서 같은 꼴(임시 색인 · 임시 개체 폴더 · 대체 경로)로 `git read-tree HEAD` 를 돌리니 `post-index-change` 훅이 1회 실행됐다(git 2.53.0). 새 시험은 `read-tree` · `update-index` 를 여러 번 부르므로, 사람 · 검증자가 훅이 걸린 사본에서 돌리면 그 훅이 돈다. 설계가 경계를 「측정 런 밖 · 돌리는 사람의 환경을 믿는다」(결-18 R11 · 머리 주석 6행)로 명시했으므로 막지 않음. 원하면 다음 손질 때 시험 안 git 호출에 훅 끄기(`-c core.hooksPath=` 빈 폴더)를 더하는 정도 — 결재 밖 제안.
