## 2. 2층 `[ "$chunks" -gt 0 ] 2>/dev/null ||` 와 셸 옵션 (반증 축 2)

- `scan.sh` 머리는 `set -uo pipefail` — `-e` 없음. `||` 오른쪽 `scan_error` 는 `exit 2` 로 끝남.
- `2>/dev/null` 은 그 `[` 한 명령에만 걸린다. 삼킬 수 있는 건 그 비교의 오류 문구뿐이고, 비교 실패는 상태 ≠ 0 → `scan_error` 로 간다(참일 때만 통과).
- `set -u`: `chunks` 는 :136 에서 늘 대입 · 새 셈은 `${records:-}` 꼴 — 미설정 중단 길 0.

## 3. 새 셈이 엔진 글자를 내보내는 길 (반증 축 3 · ⑨) — 0

- `records` = `grep -c` · `nvals` = `grep -c ''` · `tailbad` = `grep -c ''` — 세 값 모두 개수(숫자) 또는 빈 값. 엔진 글자는 파이프 안에서만 흐르고 변수에 남지 않는다.
- 새 오류 문구 · 판정 줄의 칸은 `records` · `nvals` · `commits`(앞에서 `^[0-9]+$` 확인) 뿐 — 숫자 또는 `?`.
- PR 런 · push 런 잡 로그에서 `finished scanning` 글자 0줄(엔진 기록 파일이 잡 로그로 안 나감).
