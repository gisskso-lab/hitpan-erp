## 재현 경로 (코드 읽기 · 실행 안 함)

1. 같은 PC · 같은 브라우저에서 ERP 탭 2개(토큰 = localStorage 공유 · 같은 sid · 같은 허브 그룹).
2. 설정 시각 → 서버가 sid 그룹에 `CooltimePrompt` → 두 탭 모두 60초 팝업.
3. 탭 A [예 — 계속 작업] → `POST api/auth/cooltime/continue` 200 → 서버 `asked_at = NULL` · snooze 1시간.
4. 서버는 「계속됨」 을 푸시하지 않는다(`CooltimePusher` = Prompt · Ended 둘뿐) · 탭 사이 알림도 없다.
5. 탭 B 카운트다운 0 → `POST api/auth/cooltime/logout {trigger:"countdown"}` → 엔진 WHERE `asked_at IS NOT NULL` 0행 → 200 `ended:false`.
6. `CooltimeScreenRules.LogoutOutcome` → Ended → `EndLocallyAsync` → **공유 저장소 토큰 3칸 삭제** → 탭 B 로그인 화면 · 탭 A 도 다음 요청에서 401 → 로그인 화면.

## 결과

- 사용자가 고른 「계속」 이 뒤집힌다 · 저장 안 한 내용 손실.
- 서버 세션은 살아 있고 퇴근은 안 적힌다 → 설계 §E-5 ⚠️ 「같은 PC 다시 로그인이 두 번째 PC 불가에 걸리나」 와 같은 위험이 탭 경로로도 열린다.
- 숨은 탭은 타이머가 늦어도 결국 0에 닿는다.

## 고침 안 (결정 = PM · 코드는 안 고침)

- ⓐ [계속] 성공 시 서버가 sid 그룹에 「계속됨」 이벤트 푸시 → 다른 탭 팝업 닫기 (서버 + 화면).
- ⓑ 탭 사이 표식(storage 이벤트 · BroadcastChannel)으로 「계속됨」 전달 (화면만).
- ⓒ 수용 — 설계 §E-5 ⚠️ 에 탭 경로 한 줄 덧 · 실물 실측 항목에 「탭 2개」 추가.
- 어느 안이든 게이트에 음성 대조군 「탭 2개 · 한 탭 계속 → 다른 탭 0초 뒤 로그인 유지」.
