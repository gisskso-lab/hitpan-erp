## 네 곳

**(1) 요청 본문으로 판·경로를 받는가** — §2 「화면 값 불신(재판정)」은 되돌리기에만 적혀 있다. 수동 업데이트는 「현재 판」을 어디서 읽는지 설계에 없다. `UpdateClient.IsNewerVersion(feed, current)` 는 **current 를 호출자가 준다** ⇒ 본문·쿼리·DB 값으로 current 를 받으면 다운그레이드 방어가 무너진다(G-U2 는 「피드 판 ≤ 현재 → 거부」만 잰다 — 그 「현재」가 어디서 왔는지는 안 잰다). 되돌리기도 `to`·재료 경로를 본문에서 받으면 §3-3 을 우회한다.
- ⇒ POST 본문은 **확인 표시 외 값 0**(판·경로·주소·해시 필드 없음). current = API 자기 어셈블리 FileVersion. to·재료·sha256 = 서버가 서명 매니페스트·재료 판정에서만 만든다.

**(2) 작업 명령줄** — `schtasks /Create /TR "…"` 에 들어가는 글자가 설계에 없다. `cmd /C` 로 문자열을 이어 붙이면 따옴표·`&` 주입 자리가 생긴다(설치본 `.iss:2888` 은 `cmd /C` 문자열 방식이다 — 그 모양을 그대로 따르면 안 된다).
- ⇒ `/TR` = **고정 경로**(`%SystemRoot%\System32\WindowsPowerShell\v1.0\powershell.exe` 절대경로 · `-NoProfile -NonInteractive -ExecutionPolicy Bypass -File <보호 폴더 고정 경로>`) + **GUID 형식 번호** + **모드 열거값** 만. `Process.Start` 는 `ArgumentList` 로(셸 경유 0). 본문 값 0.

**(3) 새 주소가 이미 열린 접두사 밑에 가는가** — `TenantMiddleware` 화이트리스트는 `StartsWithSegments` 라 **하위 경로까지** 연다. 예) `/api/auth/update-consent-local/…` · `/api/install/…` · `/api/internal/…` · `/api/setup/…` · `/api/landing/…`. 새 컨트롤러가 이 밑에 붙으면 미들웨어가 테넌트·인증 검사를 건너뛴다(`[Authorize]` 는 남지만 `Items["TenantId"]` 가 비어 `MainPcOnly` 의 출입증 대조 `IsPassValid(pass, null)` 로 간다). 설계 §2 는 「화이트리스트 추가 0」만 말하고 **기존 접두사 밑**은 말하지 않는다.
- ⇒ 두 컨트롤러 경로는 `/api/manual-update` · `/api/local-rollback` 처럼 **화이트리스트 어느 항목과도 앞머리가 안 겹친다**. 이 판정 게이트 + G-U1 에 「미들웨어를 실제로 지나가는」 익명 401 호출(9/22 `mainpc-proof` 사고 — 속성만 보는 게이트가 미들웨어를 못 잡았다).
- ⇒ 클래스 단위 `[Authorize(Policy="TenantAdminOnly")]` + `[MainPcOnly]` · 액션 `[AllowAnonymous]` 0(조회 GET 포함 — 조회도 피드로 나가는 요청을 만든다).

**(4) 로그인 뒤 `/data/update` 로 가는 방법** — 지금 `Login.razor` 에는 로그인 뒤 목적지 인자가 없다(`/terms`·`/welcome`·`/` 고정). F 가 `?returnUrl=` 식 **주소 인자**로 만들면 ① 바깥 주소로 보내는 열린 이동(피싱) ② 첫 로그인 약관 `/terms` 를 건너뛰는 이동이 생긴다.
- ⇒ 목적지는 **고정값 하나**(버튼이 세운 표식 → 로그인 성공 뒤 약관·기존 분기를 **다 지난 다음** `/data/update`). 주소 인자 0. `UpdateConsentGate`(#43 팝업)가 그 화면에서도 그대로 뜨는지 확인.
- 병렬이슈 03(작3) 조건과의 관계: 버튼이 `update-consent-local` 을 안 부르면 **새 익명 입구 0** ✅. 단 그 익명 주소는 화이트리스트에 **남는다**(§13-4 잠복) ⇒ 이 트랙 보고에 「N-UPD7 흡수 = 익명 입구 닫힘」이라고 쓰면 거짓 — 「버튼만 옮겼다 · 주소는 N-UPD7 잔여」로 적는다.
