> ### 🔴 봉합 중 드러난 추가 사실 (regex만으로는 안 됐다)
>
> `-Filter 'appsettings.*.json'` 이 `.bak` 을 **열거조차 하지 않는다.**
> 즉 regex 만 고쳤다면 **봉합이 성립하지 않은 채 "고쳤다"고 기록될 뻔했다.**
> 실측(임시폴더 파일 생성 후 Get-ChildItem 대조)으로 잡아 `-Filter 'appsettings.*'` 로 함께 수정.
>
> **교훈**: regex 를 눈으로 읽고 "맞다"로 끝냈으면 거짓봉합이었다. 실행해서 확인해야 한다.

## 1. 적발 시점

작2 [3] 개발에서 main 의 Strip 스텝을 develop `.disabled` 로 이식한 **직후**,
작업지시서 §5 "게이트 regex 와 **동형** 확인" 판정을 위해 두 regex 를 실측 대조하던 중.

> ⚠️ **작업이 끝난 뒤가 아니라 도는 중에 나왔다.** 끝나고 했으면 "동형 확인 ✅"로 통과됐을 건이다.

---

## 2. 무엇이

| regex | 값 |
|---|---|
| **strip** (제거) | `^appsettings\.[A-Za-z]+\.json$` |
| **게이트** (차단) | `appsettings\.[A-Za-z]+\.json(\.(bak\|old\|orig\|save))?$` |

**게이트에는 `(\.(bak|old|orig|save))?` 백업 접미사 절이 있는데 strip 에는 없다.**

### 실측 대조 (PowerShell 7종 입력)

| 파일명 | strip | gate | 판정 |
|---|---|---|---|
| `appsettings.Production.json` | ✅ | ✅ | 정합 |
| `appsettings.Development.json` | ✅ | ✅ | 정합 |
| `appsettings.Local.json` | ✅ | ✅ | 정합 |
| `appsettings.Staging.json` | ✅ | ✅ | 정합 (SoD 과제2 확장 목적 달성) |
| `appsettings.json` | ❌ | ❌ | 정합 (일반본 보존 — 의도대로) |
| **`appsettings.Production.json.bak`** | **❌** | **✅** | 🔴 **비대칭** |
| `appsettings.Prod2.json` | ❌ | ❌ | ⚠️ 아래 §3-2 |

---

## 3. 왜 위험한가

### 3-1. 백업 접미사 (주 발현)
`appsettings.Production.json.bak` 이 payload 에 섞이면
→ strip 이 **안 지운다** → 게이트가 **차단한다** → **배포 중단(fail)**.

**7/28 첫 실측 실패와 정확히 같은 실패 모양이다.** 그때 진범은 Production·Local 2종이었고,
이번엔 `.bak` 이 같은 자리에서 같은 방식으로 배포를 막는다.

> 다만 **안전측 실패**다(시크릿이 나가는 게 아니라 배포가 멈춤). 그래서 P0 가 아니라 P2.

### 3-2. 숫자 포함 접미사 (부수)
`[A-Za-z]+` 라 `appsettings.Prod2.json` 은 **양쪽 다 안 잡는다.**
strip·게이트가 **함께** 못 잡으므로 비대칭은 아니나, **환경파일이 그대로 zip 에 실린다.**
현재 리포에 그런 파일은 없다(실측). 명명 규칙이 바뀌면 발현.

---

## 4. 재현 방법

```powershell
$rx   = '^appsettings\.[A-Za-z]+\.json$'
$gate = 'appsettings\.[A-Za-z]+\.json(\.(bak|old|orig|save))?$'
'appsettings.Production.json.bak' -match $rx    # False  ← 안 지움
'appsettings.Production.json.bak' -match $gate  # True   ← 차단
```

## 5. 현재 리포 상태 (발현 조건 실측)

```
$ find . -name "appsettings.*.json.bak" -o -name "appsettings.*.json.old" → 0건
```

**지금은 발현하지 않는다.** 개발자가 수동 백업본을 남기거나 도구가 생성할 때 발현.
