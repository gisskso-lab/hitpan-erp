## C5 판단 — N4 등록값 범위
- **줄이지 않는다.** 화면에 원래 보이는 값(로그인 아이디 · 표시 이름 · 방 이름 · 회사 코드)은 처음부터 등록값이 아니다(읽기 확인). 늘 걸릴 수 있는 등록값은 **비밀번호 입력 칸의 값 하나**다.
- 그 칸은 값을 글자 대조에서 빼고 **칸이 가림형인지**를 본다(보이기 단추로 꼴이 바뀐 칸 = 걸림). 뺀 등록값 목록 = 없음.
- **넓힌다**(7): 모든 프레임 · 본 창과 열린 팝업 전부 · 입력 값(가림형 제외)과 자리표시 글자 · 대소문자 무시 · 찍기 직전과 직후 두 번(토스트 경쟁) · K 자기 토큰 등록 뒤 대조 · K 의 모든 그림이 한 도우미를 지남.
- 그려져도 되는 것: 시험 계정 표시 이름 · 방 이름 · 고정 글자 메시지 · 로그인 아이디 = **허용**.
- 대조가 못 보는 것 = **미측정**으로 적는다: 캔버스·그림 픽셀 · 닫힌 그림자 문서 · CSS 생성 글자 · 부분 노출. 그림에 안 그려져 대조가 필요 없는 것: 창 제목 · 기본 말풍선 · 브라우저 기본 대화상자(대신 콘솔·로그 소독 대상).
- 「DOM 대조 통과 = 그림 무누출」 이라 쓰지 않는다(지시서 그대로).
