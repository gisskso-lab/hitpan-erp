## B. 문제없던 것 (반증 시도했으나 안 뚫림)

1. **db.conf 화이트리스트 밖 줄** — 비밀 표지를 `DB_PASSWORD=` · 키 없는 줄 · `API_PORT_X=` · 주석 · `=값` 줄에 넣고 `-Verbose` · 경고 · 출력 · `$Error` · 반환 객체를 모두 훑음 → **표지 0**(측정). 오류 · 자세히 출력엔 줄 번호만. `KEY_X=` 접두 키 안 걸림 · 같은 키 두 번 = 그 키 `$null`(대소문자 다른 중복 포함). 실패 매치는 빈 매치 객체라 줄 글자를 붙들지 않음(정적). 단, 화이트리스트 키 **값**은 검증 없이 원문 그대로 담음 → A7.
2. `hitpan-tunnel.conf` · `bootstrap.conf` · `tenant.conf` 를 여는 코드 0(정적).
3. 공급자 하나 빠짐 · 빈 해시 = 예외로 멈춤(실물로 메우지 않음 · 측정). git 없음 = G4a 거절(측정). 스냅숏 `$null` = 7칸 전부 거절 · `Allowed` = 거절 0 **그리고** 7칸(측정).
4. 빈 값 · 공백뿐 → 해시 안 만듦 · 허용목록 빈 `entries` = 전부 거절 · 항목 한 개라도 형식 틀림 = 목록 전체 무효 · 마커 키 중복 = 무효 · `MACHINE` · 해시 비교는 `[0-9a-fA-F]` 명시(유니코드 숫자 안 받음).
5. 시간 초과 = 실패로 셈: S-A 외부 `$null` · Status 0 → `fail` · S-D 목표 `$null` → 실패 · 대조 `$null` → 관측자 연결 불명(정적 + 측정).
6. S-D 창 경계: 첫 실패 T=296(5번째 = 300초) → 완료 · T=297(5번째 = 301초) → 실패(끊김 미반영) — 개발명세서 §9 「엄격 쪽」 그대로(측정).
7. §7 해석 3(`other` = R2 위반)은 fail-closed 로 동의. 해석 1(목표 끝 → 대조 시작)은 방향은 동의하나 아래쪽 경계가 없음 → A3. 해석 2(S-C 복구 주체 = 불명 고정)는 판정 미반영 칸이라 이견 없음.
8. 헌법 #15: catch 8곳 전부 `Write-Warning` / `Write-Verbose` 한 줄 · 예외 종류만(메시지 0). #23 금지어 0 · 자격증명 모양 0(`TunnelSecret` = 워치독 쿨다운 키 이름). UTF-8 BOM 있음.
