## 무엇이 문제인가

`GET …?mdbPassword=…` 는 비밀번호가 **URL 에 실린다** — Kestrel·cloudflared·브라우저 이력에 남을 수 있다.
반면 실행 API(`POST legacy-mdb/start`)는 **본문**으로 받는다. 같은 화면에서 같은 비번이 두 방식으로 오간다.

| 엔드포인트 | 방식 | 비번 위치 |
|---|---|---|
| `GET legacy-mdb/preview` (5/13) | 쿼리 | URL 🔴 |
| `GET legacy-mdb/reconcile` (작21 B2) | 쿼리 | URL 🔴 |
| `POST legacy-mdb/start` | 본문 | body 🟢 |

## 왜 이번에 안 고치나

- 작지서가 GET 으로 정했고(PM 오기), 갈래 C 화면도 그 계약으로 이미 짜였다 — 세 파일이 함께 바뀌어야 한다.
- 미리보기(기존)와 짝을 맞춰 **둘 다** POST 로 옮겨야 의미가 있다 → **작22(W3 편의성 · 찾아보기·업로드)** 에서 화면·API 를 함께 손대는 자리에 얹는다.
- 로컬 PC + 터널 경로(HTTPS)라 전송 구간 노출은 없다. 남는 건 **로그·이력**.

## 작22 에 넘기는 것

- `preview` · `reconcile` 둘 다 `POST` + `[FromBody] MdbMigrationRequest` 로 통일(컨트롤러 2 · razor 2)
- 서버 요청 로그에 `mdbPassword` 마스킹 여부 확인
