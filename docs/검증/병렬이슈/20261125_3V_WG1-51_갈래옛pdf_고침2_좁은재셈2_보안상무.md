### P4-E · 대역 `UiLog` 가정 — 실제 동작과 다른 곳(지금은 결과 같음 · 정보)
1. `ConfirmAnswer` 는 `bool` — 실제 `ShowMessageBoxAsync` 는 `bool?` 이고 Esc · 바깥 눌러 닫으면 null. null → 「취소」 대응은 화면 람다의 `== true` 글자(O12 ⓐ)만 지킨다 · 동작 증거는 갈래 D 실측 몫(시험 주석의 「보조」 표시와 일치).
2. `ConfirmThrows` · `SaveThrows` 는 **동기로 던짐** — 실제 async 람다 · `InvokeVoidAsync` 는 실패한 Task 를 돌려줌. 제품이 두 손잡이 모두 `try` 안에서 `await` 하므로 지금은 결과가 같다. 다만 호출과 await 를 갈라 `try` 밖에서 부르는 변경에는 두 꼴이 다르게 반응할 수 있다(대역이 실제보다 빨리 터짐 · 헛빨강 쪽).
