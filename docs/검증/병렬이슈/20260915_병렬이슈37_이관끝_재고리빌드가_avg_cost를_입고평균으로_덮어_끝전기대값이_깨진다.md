## 근거
- 리빌드는 이관 **마지막 단계**에서 stock_ledger 전체로 item_stock 을 다시 쓴다. D 가 avg_cost 를 레거시 값(CAMT/CQTY 6자리)으로 넣어도 리빌드가 그 뒤면 입고평균으로 덮이고, 앞이면 맞춤 줄 unit_cost 로 섞인다.
- 독립 계산(`r62check.ps1` · DOCFC 창고별 마지막 행 · 품목·규격 Trim+소문자 1,192품목): 2자리 avg Σ = −0.11 · 6자리 품목별 ROUND(q×avg,2) Σ = 차 0 · **반올림 없는 Σ q×avg6 = 54,753,974.399974**. `StockService.cs:486` 은 `SUM(current_qty*avg_cost)` 반올림 없음 → 화면 표시 자리수에 따라 .40 / .399974 갈림.
- `item_stock.current_qty` 는 `decimal(10,2)`(`hitpan_db_clean.sql:1790` 절) — 품목 수량 최대치가 들어가는지 [4] 확인.
