## 무엇이 문제인가
- API Serilog 기본 경로 = `AppContext.BaseDirectory\logs` = `{app}\api\logs`(`Program.cs:29-30`).
- 운반 목록은 `chat-files`·`HitpanBackup` 둘뿐(`local-swap.ps1:270`). `logs` 는 교체 단위 `api` 폴더와 함께 움직인다:
  - 되돌리기 성공: `api.rbk`(새 판·실패한 판의 로그 포함)를 문지기로 지움(`:783`) ⇒ 실패 원인 로그 소실.
  - S7 되돌림(`staging_zip`): 새 `api` 를 `Remove-AppDirSafe`(`:556`) ⇒ S5~S6 동안 새 판이 남긴 기동 실패 로그 소실.
  - 업데이트 성공: 옛 로그는 `rollback\prev\api\logs` 로 갔다가 다음 교체의 `Remove-AppDirSafe(prev)`(`:750`) 에서 소실.
- 일꾼 자기 로그(`{app}\rollback\logs`)는 남으므로 「무엇을 했나」는 남고, 「새 판이 왜 안 떴나」는 안 남는다.
