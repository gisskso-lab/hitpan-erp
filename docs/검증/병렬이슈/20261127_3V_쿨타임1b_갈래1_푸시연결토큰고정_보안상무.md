## 사실 (코드 읽기)

- `src/HitPan.Web/Services/NotificationClient.cs:59-62` — `_hub` 가 있으면 다시 안 만든다.
- 같은 파일 `:66-81` — 시작할 때 저장소에서 읽은 `token` 을 `AccessTokenProvider = () => Task.FromResult(token)` 로 **붙잡는다**. 갱신된 토큰을 다시 읽지 않는다. `Closed` 처리 0.
