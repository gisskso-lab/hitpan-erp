## §1 판정 — 🟢 통과 (P1 0 · P2 0 · P3 5)

P3-2 고침은 **Node 안 TCP 길은 실제로 막는다**: net.connect · createConnection · Socket.connect(포트를 글자로) · http.get · tls.connect · fetch · worker_threads 7길 모두 연결 전에 던지고, 열린 포트가 받은 연결 0이다. 던지기 전에 연결이 나가는 틈은 없다(`con.apply` 앞에서 던지므로 DNS 조회와 소켓 생성 둘 다 0). 허용 주소를 꺼내지 못하면 `''` 가 되어 전부 막는다(닫힌 쪽으로 실패). 변이 3개(되돌림 · 던짐을 기록 앞으로 · 허용을 넓힘)는 전부 T-C1d 에서 빨강이다.
남는 길은 2개다. ⑴ NODE_OPTIONS 를 비운 자식 프로세스 ⑵ `path` 옵션 위장. 둘 다 실측으로 뚫렸지만 capture.js 가 일부러 그렇게 짜야만 열리는 길이다. 우연한 퇴행으로는 열리지 않고, ⑴ 은 T-C1a/b 의 `child === 0` 이 사후에 빨강을 낸다. 그래서 P3 으로 둔다. 명세서 §1-9 (2)에 적힌 「연결 자체를 막음 · 연결 0」 은 이 범위를 넘어 말한다.
