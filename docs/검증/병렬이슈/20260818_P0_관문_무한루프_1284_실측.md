# 🔴 P0 — 1.2.84 관문 무한 루프 (사장님 실측)

| 항목 | 내용 |
|---|---|
| 적발 | **사장님 실측** (2026-08-18, 1.2.84 수신 직후) |
| 증상 | *"로그인 → 로딩 → 히트판 메인화면(일정팝업) → 인증화면"* 이 **매우 빠르게 무한 반복** |
| 등급 | 🔴 **P0** — 로그인 자체가 불가능하다 |
| 원인 | `DeviceAuthGate.razor` — 승인된 기기도 화면이 뜰 때마다 `location.reload` |
| 상태 | 🟢 봉합 (PR 대기) |

---

## 1. 무엇이 났나

```
앱 시작 → 정적 상태(DeviceAuthState) 초기화 → _awaitingApproval = false
  → OnInitializedAsync 가 CheckGateAsync(initialProbe: true)
  → 서버 "Approved = true"
  → 🔴 location.reload            ← 조건이 없었다
  → 앱 시작 → 정적 상태 초기화 → …  ← 끝나지 않는다
```

🔴 **이미 승인된 기기가 가장 먼저 걸린다** — 메인PC 가 정확히 그 경우다.
사장님 PC 는 `is_main_pc=1, status='approved'` 라 **매번 즉시 "승인됨"** 을 받고, 그때마다 새로고침을 당했다.

## 2. 왜 그 코드가 있었나 (없앨 게 아니라 조건을 다는 이유)

관문에 **막혀 있는 동안**에는 화면 뒤 자료 요청이 막힌다.
대표가 [예] 를 누른 그 순간 **못 받은 자료를 받아 오려고** 한 번 새로 읽는 것이다 — **필요한 동작이다.**

🔴 **다만 그것은 "기다리다 풀린" 경우에만 필요하다.**
처음부터 승인돼 있었다면 **막힌 적이 없으므로 받아 올 것도 없다.**

## 3. 봉합

`initialProbe`(화면이 처음 뜰 때의 물음)에서는 **상태만 표시하고 조용히 지나간다.**
폴링으로 풀린 경우(`initialProbe == false`)에만 새로 읽는다.

```csharp
StopPolling();
DeviceAuthState.MarkAllowed();

if (!initialProbe)          // 🔴 기다리다 풀린 경우에만
{
    Snackbar.Add("기기 등록이 허락되었습니다.", Severity.Success);
    await JS.InvokeVoidAsync("location.reload");
}
```

⚠️ **`:351`(사람이 인증키를 넣고 버튼을 누른 뒤)의 `location.reload` 는 그대로 둔다** — 사람 행동이 방아쇠라 루프가 생기지 않는다.

## 4. 🔴 왜 게이트 27개가 못 잡았나 — 이것이 핵심이다

| | |
|---|---|
| 게이트가 본 것 | **서버가 뭐라고 답하나** (`approved` 판정이 옳은가) |
| 실제 결함 | **그 답을 받은 브라우저가 무엇을 하나** |

🔴 **`location.reload` 는 브라우저 동작이라 xUnit 에 재현할 수단이 없다.**
서버 판정은 27개 게이트 전부 통과했고 **실제로 옳았다** — 사장님 기기는 승인된 기기가 맞다.
**틀린 것은 그 다음이었다.**

> ⇒ 🔴 **[[project_fixed_vs_delivered_gap]] 과 같은 계통이다.**
> *"판정이 맞나"* 는 전부 검사했는데 *"판정을 받고 무엇을 하나"* 는 아무도 안 봤다.

### 이미 알고 있었다 — 그런데 안 했다
개발명세서 §못한 것에 **"Playwright 4항목 미실시"** 를 적었고,
PM 도 게시 보고에 *"관문 뒤에서 API 가 안 도나 는 xUnit 이 못 잡는다 — **구조상 맞지만 실측 전엔 논증**"* 이라 적었다.

🔴 **논증이라고 적어 두고 게시했다. 그 논증이 틀렸다.**

## 5. 무엇을 바꾸나 — 규칙

🔴 **브라우저 동작(reload·navigate·localStorage)이 얽힌 봉합은 게시 전 Playwright 1회를 게이트로 둔다.**
xUnit 이 못 잡는 자리를 *"못 잡는다"* 고 적는 것만으로는 **아무것도 막지 못한다.**
**적는 것과 막는 것은 다른 일이다** — 오늘 가짜 게이트에서 배운 것과 같은 교훈이다.
