## 6. 게이트 요구 (갈래 G)

- J 불충족 감사 게이트는 **실제 감사 서비스 + 비어 있는 테넌트 문맥**(로그인과 같은 상태)으로 불러 `audit_trail` **+1** 을 값으로 단언한다.
- 무력화: 안 A 입구를 기존 `LogAsync` 로 되돌리면 0행 → FAIL · **왜 FAIL 인지** = 「문맥이 비어 `AuditService.cs:37` 에서 반환」까지 기록.
- `NoOpAudit` 로 돈 게이트는 이 조건의 판정 근거로 인정하지 않는다.
