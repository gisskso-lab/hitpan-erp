## 2. 언제 생기나 (히트판 실사용 경로)
- 히트판은 LAN 길이 없고 늘 터널로 들어온다(인터넷 필수 · 10/20 결정). 문서 요청 머리가 15초 넘게 늦는 때 = 터널 다시 붙는 중(#27 · 5분 안 자동 회복 구간) · Windows Update 직후(#28) · 첫 설치 날 웹 호스트 첫 기동(콜드 스타트).
- 즉 **첫 설치 날 직원 첫 로그인**(약관 미동의 = `/terms` 가 꼭 필요한 사람)과 겹친다.

## 4. 권고 (고침은 PM 결재 · 구현 담당 몫)
- 앞 화면이 이동을 **낸 순간** 정적 칸 하나(예: 「이동 냄」)를 켜고, 안전망은 그 칸이 켜져 있으면 아무것도 하지 않는다. `navigated = true`(지역 변수 · `:469` · `:534`) 를 정적 쪽에도 한 줄 같이 — 갈 곳 식 손 0 은 그대로 지켜진다.
- §8-2 A-① 의 「시계 멈춤」 칸과 한 칸으로 묶어도 된다(상태: 진행 중 / 사용자 입력 대기 / 이동 냄). 「이동 냄」 이면 안전망 영구 해제.
- 시험(갈래 T · 동작으로): Playwright `page.route` 로 로그인 뒤 **문서 요청만** 20초 늦춤 → 약관 미동의 계정 → 끝 주소 `/terms` · 문서 이동 1건 단언. 변이 = 새 칸 확인 줄을 빼면 빨강.
