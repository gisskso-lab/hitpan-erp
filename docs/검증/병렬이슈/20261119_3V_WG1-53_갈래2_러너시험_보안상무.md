## B. 문제없던 것(찾아봤으나 안 되는 경우 없음)

- **훅 「전부-아니면-멈춤」**: 14개 이름 중 하나라도 없거나 scriptblock 아님 → 모듈 불러오기 전 throw · `-Hooks $null` 도 throw · 실물로 메우는 길 0(`:621~630`). 섞인 조합(가짜 스냅숏 + 실물 끊기)은 호출자가 직접 실물 코드를 쓰지 않는 한 불가. `ModulePath` 는 훅 모드에서만 읽음.
- **가드 거절** → 외부 GET 0 · 끊기 0 · 파일 0(`:650~652`). **`-Confirm` 없음** → 끊기 0 · 폴더 만들기 0(만들기는 `-Confirm` 갈래 안에서만 · `:667~675`) · 외부 GET 은 가드 허용 뒤에만.
- **실물 끊기 함수에 닿는 길**: `Stop-Service` · `Stop-Process` 는 실물 훅 두 함수 안 1곳씩 · 첫 줄 계수(시험 정적 검사와 grep 일치). 시작 · 재시작 명령 0 · `sc.exe` 는 `qfailure`(조회)만.
- **`Stop-Service`**: `-Force` 없음 → 종속 서비스 같이 안 끊음(종속 있으면 실패 → 측정불가 + 인계) · 오류 안 삼킴. `-Confirm:$false` 는 내부 명령에만.
- **`Stop-Process` 대상**: 이름 `HitPan.API` 고정 · 경로 못 읽으면 「하위 아님」(안 죽임 · 안전 쪽) · 8.3 · 대소문자 차이도 안전 쪽(V3 은 「너무 넓은」 쪽만).
