## 무엇이 문제인가

작지 **§13** 에서 PM 은 개정 2판을 승인하며 근거 하나를 이렇게 적었다:

> 처방 (나)의 부수 이득 — 잠금 범위가 회사 전체 → 거래처 1건으로 좁아진다 = **3판 1차안 교착 원인 제거**. **[4] 에서 G-RC5(다른 거래처 동시)로 확인.**

[4] 가 확인한 결과는 **반대**다. 교착은 제거되지 않았다. **매번 나고 있고, 재시도 껍질이 되돌리고 있다.**

## 실측

### ① 게이트 본문 — 단언이 「교착 0」을 재지 않는다

`src/HitPan.Tests/Integrity/RcSafePathGateTests.cs` G-RC5 (가):

```
Assert.True(ea is null && eb is null, $"다른 거래처 동시 등록 실패(교착 등): A={ea?.Message} · B={eb?.Message}");
```

단언은 **「예외가 안 샜다」뿐**이다. 바로 위 주석은 「둘 다 성공 · **교착 0**」이라고 쓰여 있으나, **교착 횟수를 읽는 코드가 없다**.
(나) 절은 `재시도 attempt=1` · `재시도 소진 attempts=3` 을 로그에서 찾지만, 이는 **1205 대기** 시나리오이지 (가) 의 1213 이 아니다.

### ② 봉합(재시도 껍질)만 빼면 (가) 가 교착으로 죽는다 — 내 손으로 재현 (R4)

치환 1건(선확인) · `sed` · CRLF 보존 · 원복 뒤 `git diff` **0바이트** 확인:

`CollectionService.cs:38` `private static readonly int[] MatchTxRetryableErrors = { 1213, 1205, 1665 };` → `Array.Empty<int>()`

```
Failed!  - Failed: 1, Passed: 10, Skipped: 0, Total: 11   (RcSafePathGate)
  Failed G-RC5 …
  다른 거래처 동시 등록 실패(교착 등): A= · B=Deadlock found when trying to get lock; try restarting transaction
```

→ **정상 상태에서도 서로 다른 거래처(PA · PC) 두 건이 동시 수금하면 1213 이 난다.** 초록은 「교착이 없다」가 아니라 **「교착을 3번까지 되돌린다」**이다.

### ③ 개발팀도 같은 것을 먼저 봤다 (자인)

S2 개발명세서 **§4-1**:

> 껍질을 빼니 G-RC5 (가) 다른 거래처 동시 등록이 교착(1213)으로 터졌다. 즉 RR 경로에서 재시도는 드문 예외를 곱게 포장하는 장치가 아니라 **정상 동시 등록이 성립하는 조건**이다.

**같은 사실이 개발명세서에는 「게이트가 진짜 잰다는 증거」로, PM 결재문에는 「교착 원인 제거」로 적혀 있다.** 둘은 양립하지 않는다.

## 고객에게 무엇이 되나

`binlog_format=STATEMENT` 고객사에서:

1. 서로 **상관없는 거래처** 두 건이 동시에 수금·지급되면 **매번** 교착 → 재시도.
2. 재시도 3회가 소진되면 `MsgMatchBusyCollection` — **「지금 다른 사용자가 같은 거래처의 수금을 처리하고 있습니다」** 로 거절된다. **다른 거래처인데 같은 거래처라고 말한다**(#25 · 병렬이슈53 §증상 3 과 동일).
3. 두 사람이 동시에 일하는 경리·영업 창구에서 저장이 끊긴다 — **#20**.

✅ **돈은 안 틀어진다.** 부분 반영 0 은 G-RC5 (나) 가 실제로 잰다. 정합성 사고가 아니라 **가용성·문구** 사고다.

## 요구 (판단은 PM·설계)

> **이 이슈의 몫은 「감시」 하나다.** 잠금 범위(원인)는 [3-V] **병렬이슈53** 으로 이미 열려 있고 **설계 3판 · PM 결재 §16·§17 로 봉합 진행 중**이다 — 여기서 중복해서 요구하지 않는다.

## 내가 안 잰 것

- 교착 **빈도**(동시 2건이 아니라 실사용 동시성에서 몇 %가 3회 소진까지 가는지) — 안 쟀다.
- 지급(`CreatePaymentAsync`) 축의 다른 거래처 동시 — G-RC5 는 **수금 축만** 잰다. 지급 축은 게이트에도 없고 나도 안 쟀다. ⚠️미실측.
