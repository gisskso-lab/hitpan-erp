## C. 문제없던 것

1. **`ls-tree -r -z` 파싱**: 첫 탭에서 앞(모드 · 종류 · blob)과 경로를 나눔 — 앞부분엔 탭이 없어 경로 안 탭 · 공백 · 따옴표는 경로에 그대로 남음. 경로 안 줄바꿈이면 `grep -F` 가 여러 패턴이 되지만, 건너뛰는 건 `tree.txt` 가 이미 비어 있지 않을 때뿐이라 거짓 초록은 생기지 않음(코드 읽기 · NTFS 에서 탭 · 줄바꿈 · `"` 이름은 못 만듦). 공백 · 홑따옴표 · 비ASCII · `-` 시작 = W0~W2 측정.
2. **링크 판정 순서**: `[ ! -L ] && [ -f ]` 다음에만 `hash-object` — 마지막 이름이 링크면 해시 안 함 → 빨강. 상위 폴더가 링크인 꼴은 원 바이트 쪽이 따라가 읽지만, 임시 색인 diff 가 「링크 너머」 로 보고 지운 파일 + 링크 자체를 새 파일로 잡는 쪽(둘 다 초록이어야 초록) — 코드 읽기만 · 개발 PC 링크 생성 불가.
3. **빈 목록 · 못 읽음** = `t1=1` 빨강. 장치 커밋의 다른 모드(`120000` · `160000`) = 해시 안 함 → 빨강(닫힌 쪽). 지금 G 범위 모드 = `100644` 20 · `100755` 3.
4. **실행 비트**: 원 바이트 쪽은 안 보고 임시 색인 diff 가 실행기 `core.filemode` 로 봄 — 그 값 바뀜은 G2. 장치 파일은 전부 `bash` · `node` 로 불려 실행 비트가 동작을 안 바꿈. 미측정(리허설).
5. **대소문자만 다른 경로**: 실행기 = 대소문자 구분 → 새 파일로 `ls-files --others` 에 잡힘(코드 읽기).
6. **`hash-object --no-filters`**: 줄 끝 · 부호 · 필터 변환 안 탐(R1~R3). 남는 `core.*`(객체 형식 · 대소문자 등)는 설정이라 G2. 외부 명령 = `git` · `grep` 만(새 이름 0 · `read` · `case` · `[` · `printf` · `local` = 셸 내장 · `local` 은 `guard()` 함수 안) → 11개 그대로. `GIT_*` = K2⁗ 명령 앞 접두 세 줄뿐 · `export` 0.
7. **M1 판정 해시(`--path`)가 작업 나무 속성을 탐 — 바꿔치기 길 없음**: 순서 = 내려받기 → `expected-sums.txt` · 릴리스 `SHA256SUMS` · 실제 sha256 세 값 대조(L86~91) → **같은 파일**을 풀기(L94) → 해시. 묶음 바이트는 sha256 으로 고정이라 속성이 바꿀 수 있는 건 고정된 한 쌍(묶음 ↔ 장치 커밋 나무)의 **판정 칸**뿐 — 원 바이트 칸(`--no-filters`)이 `m1-src-hashes.json` 에 함께 남아 설치 없는 다른 환경에서 다시 셀 수 있음. 설정 없이 도는 속성(`text` · `eol` · `working-tree-encoding` · `ident`)만 가능 · `filter=` 는 설정이 필요해 G2. 둘 사이 풀린 파일을 바꾸는 건 같은 실행기 악의 단계 = 「한계(v5)」. → 지적 아님 · A #3 ⓒ 는 공개 문구 거리만.
8. **MAPPING 바뀐 줄 ↔ 코드**: L374 K2⁵ 문장(ls-tree `--no-replace-objects` · `hash-object --no-filters` · 일반 파일인데 링크 · 폴더 · 없음 = 빨강 · 다른 모드 빨강 · 둘 다 같아야 초록 · `tree_changed` 이름만 · 범위 두 경로) = 코드와 맞음 — 단 「새 파일」 은 A #1 예외. L371 「(guard 시점)」 · `m1-compare.js` L4 주석 = 동작 무관.
9. **한계 단락 바이트(A10-3)**: L320 안에 「옛 글자」 · 취소선 0 · 「저장소 내부(개체 저장소 · 손으로 만든 팩 위조 = 미측정)」. 옛 글자는 빈 줄 + 「덧말」 줄 뒤 따로 선 인용 줄 L325 — 단락 밖이라 공개 단락 바이트에 안 섞임. 장치 커밋 안에 「한계(v5)」 글자 = MAPPING 한 파일뿐(공개 문서 K7 은 아직 나무에 없음) → 두 곳 대조는 push 전 PM 몫 그대로. L325 「위조하면 빨강 쪽」 = Z11(표시 `H` 로 위조해도 G5 빨강)과 맞음.
