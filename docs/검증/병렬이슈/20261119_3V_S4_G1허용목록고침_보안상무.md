## §1 위협이 열리나 — `GITHUB_ARTIFACTS` · `GITHUB_ARTIFACTS_LIST` (반증 1)

### 1-1. 이 두 이름이 무엇인가 (실행기 공개 소스 실측)

- 실행기 공개 저장소 `actions/runner` (main `838820efc31b05c51e1e13f047b12f4206f1951a` · 2026-11-18 · 릴리스 `v2.338.2` 에도 있음):
  - `src/Runner.Worker/CreateArtifactsFileCommand.cs` — `GITHUB_ARTIFACTS` = 「per-step environment file」. 단계마다 빈 파일을 새로 만들고 단계 끝에 실행기가 **자기가 만든 파일**을 읽어 (이름, 다이제스트) 짝을 잡 단위 목록에 모은다. 기능 깃발이 꺼져 있어도 환경 변수는 노출되고 쓰기만 무시된다.
  - `src/Runner.Worker/ArtifactsListFileCommand.cs` — `GITHUB_ARTIFACTS_LIST` = 같은 단계별 수명주기 · 읽기 전용 JSON(앞 단계들이 선언한 목록). 단계가 되써도 무시.
  - `src/Runner.Worker/FileCommandManager.cs` — 단계별 파일 명령 = `path` · `env` · `step_summary` · `state` · `output` (+ 위 둘 `artifacts` · `artifacts_list`) = **7개**. `InitializeFiles` 가 단계마다 새 경로를 GitHub 문맥으로 노출.
