## 1. #4404 — `cs/cleartext-storage-of-sensitive-information` · error · high

자리: `src/HitPan.Application/Services/ParentPasswordResetService.cs:189` (blame `cfb80fde` · 갈래 C 고침 1)

```csharp
_logger.LogError(ex, "[ParentReset] 감사 끝 줄을 못 씀 op={OpId} · 동작 {Action} · 까닭 {Reason} · 줄 남음 {LineWritten}", opId, action, ex.Reason, ex.LineWritten);
```

### 데이터 흐름 — 그 줄에 실리는 값 넷

| 자리표 | 값의 출처 | 비밀인가 |
|---|---|---|
| `{OpId}` | `NewOpId()` = `Guid.NewGuid().ToString("N")` (:164) | 아님 — 무작위 묶음 번호 |
| `{Action}` | `LocalAuditAction` enum — 호출 3곳(:137 · :144 · :149)이 넘기는 값은 상수 `ParentPasswordResetFailed`(=10) · `ParentPasswordReset`(=9) 뿐 | **아님 — enum 이름에 「Password」 글자가 들어 있을 뿐** |
| `{Reason}` | `LocalAuditWriteException.Reason` — 기록기 · 폴더 지킴이가 던지는 고정 코드(`io` · `access_denied` · `busy` · `write_failed` · `flush_failed_line_present` · `folder_acl` · `file_owner` · `file_reparse_point` …) | 아님 — 고정 문자열 |
| `{LineWritten}` | bool | 아님 |

- 새 비번 · 표(토큰) 값 · 비번 해시 · 자격증명은 이 줄에 **0건**. 같은 파일 로그 줄 전수 grep 에서도 비번 변수는 어떤 `_logger.Log*` 에도 들어가지 않는다(`Password` 가 걸리는 줄은 enum 상수 · `Reasons.PasswordMismatch/PasswordRule` 코드 이름 · 로거 형식 이름뿐).
- CodeQL 메시지 자체가 출처를 「**access to constant** ParentPasswordResetFailed」 라고 적는다 — 이름 휴리스틱(이름에 password 가 든 멤버 접근 = 민감)으로 뜬 전형적 오탐. 선례 `20261018_보안경보_high5건_오탐4_진짜1_판정서.md` 의 #3926(같은 규칙) 과 같은 결.

### 판정: **오탐** (내용상 평문 비밀 저장 없음)

### 권고 — dismiss 보다 **1줄 고침**(A안)

- 까닭: (1) error/high 라 머지 check 를 막는다 — dismiss 는 대표 손이 들고 줄 번호가 밀리면 번호가 바뀌어(선례 §0) 다시 뜬다. (2) 그 자리표가 주는 정보는 다른 값으로 **잃지 않고** 대신할 수 있다.
- **A안(권고)**: 로그에서 `{Action}`(enum) 을 빼고 `{Result}`(`LocalAuditResult` · Succeeded/Failed) 로 바꾼다. 이 서비스에서 동작은 둘뿐이고 결과와 1:1(`ParentPasswordReset`↔`Succeeded` · `ParentPasswordResetFailed`↔`Failed`)이며, 로그 머리 `[ParentReset]` 이 이미 무슨 일인지 말한다 → 정보 손실 0.
  꼴: `"[ParentReset] 감사 끝 줄을 못 씀 op={OpId} · 결과 {Result} · 까닭 {Reason} · 줄 남음 {LineWritten}", opId, result, ex.Reason, ex.LineWritten`
  - 주의: `(int)action` 이나 `action.ToString()` 로 감싸는 꼴은 오염이 형변환을 타고 흐를 수 있어 경보가 안 꺼질 수 있다 — 권하지 않음.
  - 고친 뒤 확인 = #1021 다음 스캔에서 `#4404` closed(fixed) · check pass. 감사 **파일**(LocalAuditRecord)에 동작을 적는 것은 그대로 둔다(감사 기록의 본분 · 이번 경보 자리 아님).
- **B안(대안)**: 코드 그대로 두고 오탐 사유서 + dismiss(사유 "False positive" · 본 문서 §1 표 인용). 대표 손 1번 · 번호 바뀜 위험 있음.
