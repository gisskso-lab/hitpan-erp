## 무엇이
- `AuthService.cs:415-418` `EnforceSinglePcLoginAsync` — `deviceKind != "pc"` 이면 그냥 통과(모바일 FREE).
- `DeviceTypeResolver.cs:144-160` 판정 = UA 글자(`Android`·`iPhone`·`iPad`). **UA 없음 + 신고 없음 = `"mobile"`**(:147).
- `tenant_settings.enforce_one_pc_login` 이 0 이면 끔(:422-425).
- 작3 이 `SessionLimitMiddleware` 파이프라인을 걷었고(`Program.cs:688` ⬛) 작4 가 기기 한도를 걷어 **다른 상한 없음**.

## 재현(시험 환경)
- PC 크롬 F12 → 기기 툴바(모바일 에뮬레이션, UA 에 `Android`) → 같은 계정으로 PC 2·3대 로그인 → 셋 다 200, 앞 PC 안 끊김.
- 대조군: 에뮬레이션 끄고 두 번째 PC 로그인 → 다른 PC 확인/끊기 흐름.
