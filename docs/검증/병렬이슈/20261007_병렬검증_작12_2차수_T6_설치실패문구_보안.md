### 전수 결과 — 서버 글자 자체에는 흘릴 것이 없다

- **예외가 실리는 자리 0건.** `:389` 는 **고정 문장**이다. `ex.Message`·`ex.ToString()`·`StackTrace` 가 응답에 들어가는 자리는 **전수 0건**(`grep "message\|Exception\|ex\." ` 전수 확인). 예외는 `_logger.LogError` 로만 간다(`:388`).
- **존재 oracle 0건.** `:198` 이 「키 불일치」와 「미승인 계정」을 **한 문장으로 묶는다**. 키가 실존하는지 고객/공격자가 가를 수 없다.
- **테넌트 식별 정보 0건.** 실패 응답에 회사명·테넌트코드·이메일이 들어가는 자리 없다(그건 성공 응답 `:356-363` 전용).
- **DB 오류·컬럼명·SQL 0건.**

### 🔴 그러면 봉합이 새로 흘리는 게 없다는 뜻인가 — **아니다. 서버 글자가 아닌 글자가 있다.**

봉합안(설계 §2-1)의 `$human` 결정 순서는 **ⓐ → ⓑ → ⓒ** 다:

- ⓐ `$_.ErrorDetails.Message` 를 `ConvertFrom-Json` 해서 `.message` 가 **있으면** 그 값 → 위 표 6종. 🟢 안전.
- **ⓑ 실패하면 `$_.ErrorDetails.Message` 원문** ← 🔴 **여기가 P1.** 응답 본문이 위 표가 아닐 때(= 히트판 컨트롤러가 만든 본문이 아닐 때) **본문 전체**가 고객 대화상자 글자가 된다.
- ⓒ 그것도 없으면 `$_.Exception.Message` → .NET/WinHTTP 예외 문구(영문 혼재 가능).

**ⓑ 로 들어오는 본문은 무엇인가** (히트판이 #23 심의를 한 적 없는 글자다):

| 경로 | 본문 모양 | 고객 화면에 뜨는 것 |
|---|---|---|
| 프록시·LB 장애 (502/503/504) | HTML 오류 페이지 | 영문 전문 + 제품명·호스트명·추적 ID |
| Cloudflare 류 오류 페이지 | HTML | `cloudflared`·오류번호·Ray ID·원본 힌트 |
| 경로 오타·배포 직후 404(본문 빈 경우) | 본문 없음 → ⓒ | .NET 예외 문구 |
| ASP.NET 자동 400 ProblemDetails | `type`/`title`/`status`/`traceId`/`errors` — **`message` 키가 없다** ⇒ ⓐ 통과 못 하고 **ⓑ 로 떨어진다** | 영문 + `traceId` + DTO 속성 이름 |

**실측 1건 (이 PC · 운영 무접촉)** — PowerShell **5.1.26100.9444** 에서 봉합안의 쓰기 방식(`[pscustomobject][ordered]@{…} | ConvertTo-Json -Compress`)을 그대로 돌렸다:

- 한글 `message` → **그대로 보존**된다. 🟢 봉합의 의도(423 문구 도달)는 실제로 선다.
- HTML 본문 → `<`·`>`·`&` 만 `<`·`>`·`&` 로 바뀐다. **호스트명·IP 모양 글자·제품명·추적 ID 는 escape 없이 그대로 통과한다.**
  ⇒ **이스케이프가 가려 주지 않는다.** 고객은 「읽을 수 없는 영문 뭉치 + 내부 정보」를 본다(#23 위반 + 「처음 보는 사람이 혼자 쓸 수 있냐」 정면 위반).

### P1-A3 — 처방 제안 (내가 정하지 않는다 · 결재 사항)

## §4 D — 고객에게 보이는 문구 자체의 안전성

### 🟢 D-1 판정 — **잠금 문구를 고객에게 보여도 공격자에게 새 정보는 0이다. 보여라.**

근거(추측 아님):
- 이 엔드포인트는 `[AllowAnonymous]` 다 — `InstallerBootstrapController.cs:28`. **공격자는 설치 EXE 없이**, `curl` 한 줄로 `POST /api/installer/bootstrap` 을 치고 **423 + 같은 본문을 직접 받는다.**

### 가름표 요지 — 한 문장

> **봉합이 새로 흘리는 것은 「히트판 컨트롤러가 만들지 않은 응답 본문」 하나뿐이다.** 서버 `message` 6종은 **원래 공개돼 있었고**(익명 엔드포인트), 봉합은 그 수신자에 **고객**을 더한 것이다. 흘리는 쪽은 `message` 가 **아닌** 본문을 그대로 통과시키는 **폴백 ⓑ** 다. ⓑ 를 빼면 봉합의 보안 지적은 **A1·A2 두 건의 결재 사항만** 남는다.

### 🔴 봉합의 지지대 2개 — 건드리면 반려

1. **`.iss:823` `IsValidSerialFormat`**(HITP + 영숫자 16자)가 요청 JSON 주입을 막고 있다. `Program.cs` 에 `SuppressModelStateInvalidFilter` 가 **0건**이므로 요청 JSON 이 깨지는 날 ASP.NET 자동 400 ProblemDetails(영문·`traceId`·DTO 이름)가 **고객 대화상자로 간다.** 지금은 **막혀 있다** — 이 게이트를 느슨하게 하면 열린다.
2. **`.iss:865` `G_CompanyName := '(미인증 — 시리얼 인증 실패)'`** 가 오류 글자의 디스크 저장을 막는다(§2 B-3).
