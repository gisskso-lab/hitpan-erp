## §3 임무 3 — 개정 게이트가 합격선을 낮췄는가 → **분리는 정당 · 🔴 게이트 집합은 사실상 낮췄다**

### 3-1 🟢 「전체 ↔ 주장」 분리 자체는 **정당한 정밀화다**

| 근거 | 실측 |
|---|---|
| ① 합격선이 그대로다 | 「주장 0」이고, **내가 독립으로 재서 주장 0** 이다(§1-1) |
| ② **G-K0-5′ 는 분리해도 숫자가 안 바뀐다** | 느슨한 「주장만」도 0, **엄격한 「전체 출현」도 0**. ⇒ 이 게이트에서 분리는 **얻은 것이 없다** = 통과를 위한 장치가 아니다 |
| ③ 남은 2건이 실제로 기록 줄이다 | K0-1:12 · K0-2:94 를 눈으로 확인. 둘 다 *"1판은 … 거짓이었다"* 꼴 |
| ④ 세면 기록을 지우게 된다 | 기록 줄을 위반으로 세면 **#42(작업 루틴은 문서로 남긴다)와 정면 충돌**한다. PM 근거는 성립한다 |

🟢 **판정: 완화 아님.** 「통과시키려 바꿨다」고 볼 근거를 못 찾았다 — 특히 ②가 결정적이다. 자기 산출물을 통과시키려면 **0이 아닌 숫자를 0으로 만들어야** 하는데, 엄격히 세도 0 이다.

### 3-2 🔴 그러나 **집합 차원에서는 합격선이 내려갔다**

1차 반려의 P0 는 **두 모양**이었다: ⓐ 숫자(「○칸뿐」) · ⓑ 경로부재 단정(「길이 아예 없습니다」).

| 모양 | 개정 후 게이트 | 측정되나 |
|---|---|---|
| ⓐ 숫자 | 🆕 G-V6′ | 🟢 센다 (전체 2 / 주장 0) |
| ⓑ **경로부재 단정** | **없음** | 🔴 **하나도 안 센다** |
