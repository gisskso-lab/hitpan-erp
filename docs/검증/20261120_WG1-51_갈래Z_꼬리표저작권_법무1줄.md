## 근거
1. **두 원문**: 파일 ID 0 = `Copyright © 2011 NHN Corporation. All rights reserved. Font designed by Sandoll Communicat…`([1-V] ③ §2) · 꾸러미 저작권 글 = `Copyright: 2010, NAVER Corporation (http://www.nhncorp.com)` → 옛 꼬리표는 꾸러미 글(배포자 기록)에서 온 것이라 근거 없는 귀속은 아님. 다만 1차 원문은 파일 쪽 → 파일 원문 인용이 가장 정확.
2. **조항 2**: "Original or Modified Versions of the Font Software may be bundled, redistributed and/or sold with any software, provided that each copy contains the above copyright notice and this license." → 고지 의무는 **글꼴 사본을 재배포할 때 그 사본**에 걸림. R6 산출물 글꼴 파일 0 · PDF 0 · 수정본 ID 0 보존 같음(`preserveSame true` = ㉢ · 리뷰서 §1) → 이 의무가 생긴 일 0 · 지켜야 할 고지는 파일 안에 그대로.
3. **조항 5 후단**: "The requirement for fonts to remain under this license does not apply to any document created using the Font Software." → 결과표 = 문서 · 꼬리표 = 우리가 스스로 건 표시(㉣) → 꼬리표 글자 차이 = OFL 위반 아님.
4. **조항 4**: 저작권자 이름은 "except to acknowledge the contribution(s)" 범위로만 → 원문 인용 = 감사 표기 그대로. 「지금 권리자 = ○○」 덧붙임은 이 범위를 넘는 주장이 될 수 있어 뺌.
5. **같은 권리자인가 = 확인 필요(등기 · 공시 대조)**: 일반 지식으로는 2013 NHN 주식회사가 게임 사업을 인적분할로 떼고 존속 회사가 네이버 주식회사로 상호 변경 · 2019 떼어 나간 회사가 NHN 주식회사로 상호 변경 → 지금 「NHN Corporation」 은 다른 회사를 가리킬 수 있음. 그래서 「원문」 이라는 말로 파일 기록 인용임을 밝힘. 귀속 확정은 이 결론에 필요 없음.
6. **정정으로 충분 · 앞 판단 무변**: 지우기 금지 · 고칠 위반 0 · R6 산출물 보존 기한 = 확인 필요(기한 뒤 사라져도 이 문서 · 정정 줄이 기록). ㉠ 반출 0 · ㉡ 낱말 0 · ㉢ 보존 같음 · ㉤ 두 칸 = R6 🟢 그대로 · ㉣ 「있음」 은 지켜졌고 글자만 고침 · 앞 판단의 근거(조항 2 · 3 · 5 · FAQ)는 꼬리표 글자에 기대지 않음.
