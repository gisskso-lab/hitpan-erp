## 1. 무엇을 고쳤나

### 축 ① — 창고결정 3단이 BOM 에만 없었다

매출(작19)·매입은 **① 사용자지정 → ② 상품마스터 기본창고 → ③ 테넌트 MAIN** 3단을 쓰는데,
BOM 생산·해체는 **③ 하나뿐**이었다. 상품마스터에 A창고를 지정해도 MAIN 에서 빼려 했다.

⇒ `WarehouseResolver.Resolve` 를 BOM 도 부르게 했다. **자재별·완제품별로 각각** 결정한다.

🔴 **해체(`DisassembleAsync`)도 같이 고쳤다.** 생산만 고치면 완제품은 A창고에 쌓이는데
해체는 MAIN 을 뒤져 "재고 부족" 이 난다 — **한쪽만 고쳐 비대칭을 만드는 사고**를 히트판은 여러 번 겪었다.

### 축 ② — 자재 목록이 창고 수만큼 부풀었다 (과차감)

`GetAsync` 의 `LEFT JOIN item_stock` 에 창고 필터도 합산도 없어, 자재가 2창고면 BOM 자재 1건이 2행이 됐다.
`AssembleAsync` 가 그 목록을 그대로 돌며 차감하므로 **10개 생산에 자재 20개**가 빠졌다.

⇒ 창고합산 서브쿼리로 바꿨다. **같은 파일의 `GetListAsync`(:73-76) 가 이미 쓰던 방식**을 그대로 따랐다.

### 곁가지 — `stock_adjust_logs` 의 before/after 오염

before/after 를 읽는 SELECT 에 `warehouse_id` 필터가 없어, 기록된 창고와 다른 창고의 수량을 적고 있었다.
다창고면 여러 행이 INSERT 됐다. 생산·해체 4곳 모두 필터를 넣었다.

## 2. 사본을 늘리지 않았다

`LoadItemDefaultWarehousesAsync` 와 테넌트 폴백 SQL 이 **매출·매입에 따로 두 벌** 있었다.
BOM 에 세 번째 사본을 만들면 다음에 또 한쪽만 고쳐진다.

⇒ `WarehouseLookup` (신설, `src/HitPan.Application/Services/WarehouseLookup.cs`) 에 공용으로 두었다.

- `WarehouseResolver` = **판정** (순수 함수, DB 접근 없음 — 시험이 DB 없이 돌 수 있다)
- `WarehouseLookup` = **조회** (판정에 필요한 값을 DB 에서 읽는다)

⚠️ **복붙이 아니다.** 공유하는 것은 "어느 창고를 쓰느냐" 하나뿐이고,
입고냐 출고냐·차감이냐 증가냐는 부르는 쪽이 정한다.

## 3. 게이트 — `BomWarehouseResolutionGateTests` 신설 4건

진짜 `BomService` 를 진짜 DB 에 물려 돌린다. 알고리즘을 베껴 적지 않았다.

| 게이트 | 재는 것 |
|---|---|
| G-B1 | 자재가 상품마스터 기본창고(A)에 있으면 생산이 된다 |
| G-B2 | 자재가 **어느 창고에서** 빠졌나 (A 90 · MAIN 100 을 함께 판정) |
| G-B4 | 창고 수가 늘어도 빠지는 자재 **총량은 같다** (과차감 차단) |
| G-B3 | **대조군** — 마스터 기본창고가 없어도 흐름이 안 끊긴다 (헌법 #20) |

🔴 **G-B3 대조군이 없으면** "무조건 마스터 창고" 로 굳혀도 통과한다. 그러면 기본창고를 안 쓰는 고객(대다수)의 생산이 죽는다.

🔴 **G-B2 는 두 값을 한 Assert 로 판정한다.** 앞 Assert 에서 멈추면 "어디서 뺐는지" 가 안 보인다.

## 4. 무력화 시험 — 게이트가 진짜인지 확인

초록불만 보고 끝내지 않았다. **두 축을 각각 죽여** 정확히 그 게이트만 빨간불이 되는지 봤다.

| 무엇을 죽였나 | 결과 |
|---|---|
| 자재 창고결정 (`WarehouseResolver.Resolve` → `defaultWarehouseId`) | **G-B1·G-B2 FAIL**, G-B4 통과 |
| 창고합산 서브쿼리 (→ 단순 `LEFT JOIN`) | **G-B4 FAIL**, G-B1 통과 |
| 둘 다 복구 | **4건 전부 통과** |

🟢 **두 축이 독립적으로 걸린다는 것까지 확인했다.** 하나가 다른 하나를 가리지 않는다.

🔴 창고결정만 죽였을 때 MAIN 이 **90**(과차감 시절엔 80)이었다 — 과차감이 이미 별도로 고쳐졌다는 증거다.
