## 근거 1 — ID 7 보존
- 조항 3: 예약 이름 제한은 "the primary font name as presented to the users" 에만. FAQ 5.3: 그 범위 = "the font menu name and other mechanisms that specify a font in a document". FAQ 3.1: 수정본은 "internal names of the font" 를 바꿔야 함.
- ID 7 = 상표 고지 글(`NanumGothic Regular is a registered trademark of NHN Corporation.`) — 글꼴 메뉴 이름도, 문서에서 글꼴을 지정하는 장치도 아님. 이 길에서 family 는 ID 21→16→1 차례, PDF 글꼴 이름은 ID 6 에서 나옴([1-V] ③ E4-6 · E5-2) → ID 7 은 어느 이름 길에도 안 쓰임 = 조항 3 의 「사용」 아님.
- FAQ 3.7: "Any trademark notices must remain in any derivative fonts to respect trademark laws" → 지우는 쪽이 오히려 FAQ 에 어긋남. 조항 4 단서 "except to acknowledge the contribution(s)" 와도 맞음.
- ㉡ 읽기: 앞 1줄 ㉡ 대상 = 이름 기록(ID 1 · 3 · 4 · 6 · 16 · 18 · 다른 언어) · ㉢ = ID 7 보존 → 처음부터 ID 7 은 ㉡ 밖. **읽기 맞음.** 단 ID 20(`NanumGothic-KSCpc-EUC-H`)은 글꼴을 찾는 이름 기록 = ㉡ 안 = 지워야 함 — [3-V] 11차 ㉡ 🟢(보존 밖 기록의 금지 낱말 지움 · 판정기 다시 셈)로 확인. ID 7 바이트 같음 = ㉢ 🟢(저장 뒤 바이트 비교).

## 근거 2 — 내장 부분집합
- 내장본에 남는 것 = ID 0(저작권 · NHN · 산돌) · ID 1 「Malgun Gothic」 · ID 2~6(중립) → 예약 이름 낱말 **0**(ID 7 이 빠지므로). PDF 글꼴 칸(BaseFont · FontName) = 중립 ID 6 → FAQ 5.3 「문서에서 글꼴을 지정하는 장치」 에 보이는 이름은 중립. ID 1 은 내장 프로그램 안쪽이라 둘째 줄의 「family 칸」 보다 덜 드러남 → 둘째 줄(낮음 · ㉠~㉤ 전부)을 **상한**으로 보는 분류 = 보수적으로 맞음.
- ID 7 · 13 · 14 빠짐 = 부분집합기 기본 동작([1-V] ③ E5-7 · E5-8) — 원본(길 ②)을 내장해도 똑같이 빠짐 → 길 ① 탓 아님. 조항 5 후단("does not apply to any document created using the Font Software") · FAQ 1.12 "Yes, either in full or a subset. The restrictions regarding font modification and redistribution do not apply" → 허용.
- FAQ 1.15 "should not lose its authorship information and licensing" = 권고(본문 조항 아님). 이 파일 ID 13 · 14 값(요지) = `NHN Corporation` · `http://www.nhncorp.com`([1-V] ③ §2) → OFL 글 · 주소가 원래 파일 안에 없음 · 빠져서 잃는 라이선스 글 0 · 저작자 정보는 ID 0 으로 남음. 라이선스 표시는 ㉣(「SIL OFL 1.1, © NAVER Corp.」)가 맡음 → **㉣ 가 공개물에 함께 붙을 때 충분**.

## 근거 3 — PDF 업로드
- 공개 저장소 CI 산출물 = 로그인한 누구나 내려받음 → 앞 1줄의 「공개 산출물」. ㉣ = 「공개 산출물이면 필수」 인데 PDF 파일 자체엔 없음 · PDF 만 따로 돌면 꼬리표가 떨어짐 → **㉣ 미충족(PDF)**.
- ㉤ = 「FontName · FontFamily 실측값」. FontFamily 는 원문상 Type3 에서만 씀([1-V] ③ E5-5 · E5-6)이나 판 고정 원문 아님 · 런 실측 0([1-V] ③ §4 한계 · §7) → **㉤ 반쪽**([3-V] 11차 🔴 와 같음). 내장본 ID 1 은 원문상 남음 → PDF 에선 둘째 줄 조건(㉠~㉤ 전부)이 다 서지 않음. 7일 보존은 노출을 줄일 뿐 0 아님 · 앞 1줄 둘째 줄 권고도 「공개 대상을 PDF 대신 측정 표로」.
- **결과표만 올리면**: 내장본이 든 파일이 러너 밖 0 → 상표 경우 표 첫째 줄(최저) 수준 · ㉠ 더 단단 · ㉣ 결과표 🟢 · ㉤ = 결과표에 「FontName = 실측 · FontFamily = 원문상 이 경로 미기록 · 미측정 · 내장본 ID 1 = Malgun Gothic 남음(원문 기본값)」 을 그대로 적으면 공개 표시가 사실과 같음 = **충족**(㉤ 목적 = 공개 표의 정확성 · 못 잰 칸을 「미측정」 으로 적는 것도 정확한 표시). S11-1 (가) 판독기 FontFamily 칸 추가는 법무상 필요 없어짐.
- 러너 안에서 PDF 를 만들고 판정에 쓰는 것은 그대로 됨(배포 아님 · 앞 1줄 근거 5).
- PDF 를 꼭 공개해야 할 사정이 생기면 = 대표 · 법무 결재 거리(S11-2). 그때 조건 = FontFamily 실측 · ㉣ 글을 같은 묶음 맨 위 글 파일로 · 보존 7일 이하.
