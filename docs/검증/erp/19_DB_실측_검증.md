## 2. INFORMATION_SCHEMA.TABLES vs COUNT(*) 차이 사유

- TABLE_ROWS는 옵티마이저용 통계치, 실제 행수와 다름
- ANALYZE TABLE 후 갱신
- 정확한 행수는 `SELECT COUNT(*)` 필수
