## §3 [D4] (가) — ⑤ 안 UPDATE 를 받는 조건 (PM 이 (가′) 대신 (가) 를 고를 때만)

1. 문장 = **백업 값 결재 표**(`approval_doc_lines` · 결재 문서 표 등 이름을 다 적음)의 UPDATE 만. 지금 값 표(알림 · `audit_trail` 등) 쓰기 0 · INSERT 0 · DDL 0.

3. 자리 = 모든 INSERT … SELECT **뒤**, `restore_history` 쓰기 · 커밋 **앞**. 퇴사자 집합은 덧씌운 뒤의 `employees`(= 지금 값)에서 정한다.

5. 정리 건수는 커밋 뒤 감사 2벌에만 적는다(트랜잭션 안 감사 쓰기 0).
6. `delegate_id` 를 퇴사 뒤처리와 같게 다룬다(K-b 결과).
7. 결재 표에 트리거가 0 임을 G13 ⓔ 가 이미 못 박는다 — 트리거가 생기면 다시 판정.
