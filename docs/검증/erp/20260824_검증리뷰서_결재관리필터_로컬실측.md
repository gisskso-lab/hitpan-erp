## 1. 🔴 게이트를 먼저 실패시켰다

**초록불이 어디서 오는지 밝히는 것**이 규율이다. 봉합 전 상태를 먼저 재현했다.

### 옛 SQL (봉합 전) — 부장이 본 「완료된 결재」

```
A-APPROVED   휴가 신청(승인됨)      approved    ← 진짜 완료
A-INFLIGHT   일일보고서(진행중)     pending     🔴 아직 도는 중인데 완료
A-REJ-1ST    초과근무(1차 반려)     rejected    🔴 반려인데 완료
A-REJECTED   경비 신청(반려됨)      rejected    🔴 반려인데 완료
```

⇒ **4건 중 3건이 거짓말이었다.** 결함을 **눈으로 보고** 봉합했다.

### 새 SQL (봉합 후)

```
[completed]  A-APPROVED                          ← 1건. approved 만
[rejected]   A-REJ-1ST · A-REJECTED              ← 2건. 제 자리로 갔다
```

🔴 **초록불의 출처 = `ad.status` 조건.** 화면 글자가 아니라 SQL 조건이 걸렀다.
