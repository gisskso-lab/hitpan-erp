# §1. 🔴 P0 — 저장은 되는데 **아무도 안 읽는다**

## 실측

```
설정 20개  →  화면에서 켜고 끔  →  DB 에 저장됨  →  ❌ 읽는 코드 0건
```

`tenant_settings` 를 SELECT 하는 곳은 **`SettingsService` 자기 자신 3곳**뿐이다.
그 밖에는 [`DataResetService.cs:54`](../../src/HitPan.Application/Services/DataResetService.cs)(삭제 목록)와
백오피스 주석 한 줄이 전부다.

**소비처 전수 집계** (DTO·저장·조회 코드를 뺀 실제 사용처):

| 설정 | 소비처 | 설정 | 소비처 |
|---|---|---|---|
| 마이너스 재고 허용 | 🔴 **0** | 미수금 출고정지 | 🔴 **0** |
| 재고부족 경고 | 🔴 **0** | 매입가 표시 | 🔴 **0** |
| 다중창고 사용 | 🔴 **0** | 0원 단가 허용 | 🔴 **0** |
| 단가 허용 편차 | 🔴 **0** | 이전자료 수정 허용 | 🔴 **0** |
| 개인정보 보호 | 🔴 **0** | 담당자별 매출관리 | 🔴 **0** |

## 이게 왜 P0 인가

고객이 **"마이너스 재고 허용"을 꺼도 출고가 그대로 된다.**
**"미수금 출고정지"를 켜도 미수금 넘은 거래처에 계속 나간다.**
화면은 켜졌다 꺼졌다 하는데 **실제 동작이 안 바뀐다.**

🔴 **이건 안 되는 기능이 아니라 되는 척하는 기능이다.**
고객은 설정했다고 믿고 일한다. 사고가 나야 안 걸려 있었다는 걸 안다.

⚠️ 화면에 **거짓말이 적혀 있다** — `Settings.razor:232-236`:
> *"모든 강제 수정은 **이력이 기록됩니다**"*

`LogForceEditAsync` 호출처 **0건**. `force_edit_logs` 에 아무것도 안 쌓인다.

# §3. 🟡 P1 — [초기화]가 다른 화면 설정을 지운다

[`Settings.razor:478`](../../src/HitPan.Web/Pages/Settings.razor) `Reset()` 이 `new TenantSettingsModel()` 로 만든 뒤 **바로 저장**한다.

그런데 **업종(`IndustryType`)은 이 화면에 입력칸이 없다.** `/company` 에서 설정한다
([`UserInfoPage.razor.cs:333`](../../src/HitPan.Web/Pages/Settings/UserInfoPage.razor.cs)).

⇒ 사용환경설정에서 [초기화]를 누르면 **회사정보에서 고른 업종이 `retail` 로 덮어써진다.**
고객은 여기서 그걸 건드린 적이 없다.

⚠️ 확인 대화창이 *"모든 설정을 기본값으로 되돌린 뒤 바로 저장합니다"* 라고만 한다.
**다른 화면 값이 함께 바뀐다는 말이 없다.**

# §4. 🟡 P1 — DB 기본값이 코드가 모르는 값이다

clean DDL 의 DEFAULT 와 코드 허용목록이 어긋난다.

| 컬럼 | clean DDL DEFAULT | 코드 허용목록 | 판정 |
|---|---|---|---|
| `price_input_type` | **`'vat_in'`** | `net` / `inclusive` | 🔴 **허용목록에 없는 값** |
| `industry_type` | **`'general'`** | `retail`/`metal`/`elec`/… | 🔴 **허용목록에 없는 값** |
| `stock_eval_method` | `'fifo'` | (코드 기본값 `moving_avg`) | 🟡 불일치 |
| `use_credit_limit` | `0` | (코드 기본값 `true`) | 🟡 불일치 |

⇒ 신규 고객이 이 화면을 **한 번도 안 열면** DB 기본값이 그대로 남는데,
그 값을 코드는 모른다. 나중에 §1 을 고쳐 실제로 읽기 시작하면 **그때 터진다.**

⚠️ 유래: [`DB-28_tenant_settings_missing_columns.sql`](../../src/HitPan.API/Migrations/SQL/DB-28_tenant_settings_missing_columns.sql)
에서 18컬럼을 추가할 때 들어간 DEFAULT 다.
