## 4. 도구 실행 (재현)
```
HITPAN_DB_CONF=<db.conf 경로: DB_NAME=hitpan_e2e>   (옆에 hitpan-keys.conf: ERP_ENCRYPTION_KEY)
HITPAN_MDB_PASSWORD=<비번>  HITPAN_TENANT_ID=e2e-mig-baseline-tenant  HITPAN_BASELINE_OUT=<md 경로>
dotnet tools/MdbMigrationBaselineRun/bin/Release/net8.0/MdbMigrationBaselineRun.dll --apply-schema
```
- 도구는 `DB_NAME` 이 `hitpan_e2e`/`hitpan_trgtest` 가 아니면 즉시 중단한다(#39).
- 테넌트 시드: `tenants`(e2e-mig-baseline-tenant) + `warehouses`(MAIN) 2행 — 도구가 만들지 않는다.
- ⚠️ 콘솔 로그는 코드페이지 탓에 한글이 깨진다 — 결과는 `HITPAN_BASELINE_OUT` markdown(UTF-8)으로 본다.
