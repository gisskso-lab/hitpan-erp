| 같은 파일에 생길 꼴 | 걸리나 | 까닭 |
|---|---|---|
| `"SELECT … FROM device_slot_policy_settings"` (한 문자열 안) | 걸림 | 표 이름 바로 앞이 공백 — `"device_…"` 조각 아님 |
| `JOIN device_slot_policy_settings` · `$"… FROM device_slot_policy_settings WHERE …"` | 걸림 | 같음 |
| 여러 줄 SQL(`@"…"` · `"""…"""`) 속 표 이름 줄 | 걸림 | 따옴표 없음 |
| 다른 파일에 같은 배열 꼴 | 걸림 | 파일 경로 같음 조건 |
| ⓐ `"SELECT * FROM " + "device_slot_policy_settings"` (이어 붙이기) | **안 걸림** | 조각 포함 |
| ⓑ `const string T = "device_slot_policy_settings";` 뒤 `$"SELECT … FROM {T}"` | **안 걸림** | 첫 줄 = 조각 포함 · 둘째 줄 = 정규식 자체가 안 맞음 |
