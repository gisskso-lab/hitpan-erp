### 새로 본 것 (P3 · 막지 않음 · PM 기록용)

- **P3-a** 다시 확인이 연결 실패일 때 팝업을 닫으며 「계속 작업할 수 있습니다.」(성공 색)를 띄운다 — 실제로는 「모름」. 그리고 끊긴 동안 `CooltimeEnded` 를 놓치면, 재연결 때 `NotificationClient.CheckCooltimeStateAsync` 는 `asked` 만 보고 `active:false` 는 버린다 → 화면 종료는 다음 요청의 401 까지 늦는다(서버 판정과 어긋나지는 않음).
- **P3-b** 팝업 중 끔(또는 다른 탭 계속) 뒤 사용자가 **[아니요 — 지금 로그아웃]** 을 눌러도 `ended:false` → 팝업만 닫히고 「계속 작업할 수 있습니다」 — §275 결정대로지만 누른 뜻(나가기)과 반대 문구. 화면 실측 때 문구 판단 거리.
- **P3-c** `[E-5 확인]` 계측(`CooltimeDbGateTests` :1035)은 「화면은 로그인 화면」 을 전제로 서버 로그인만 다시 해 본다 → 고친 뒤에도 같은 줄이 나온다. 이번 E-5 고침의 증거는 규칙 시험(`AfterRecheck(200,true,false,0)=ClosePopup`)과 [4] 화면 실측뿐 — §275 「계측 줄로 다시 확인」 을 증거로 읽지 말 것.
