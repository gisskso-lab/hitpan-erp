## 7. 🔴 PM 미측정 3건에 대한 검증팀 판정

### 7-1 사람 눈으로 종이 **0회** · 미리보기 ↔ 인쇄 **글자 완전 일치**(합격선 ①)
🔴 **둘 다 여전히 미측정이고, 검증팀도 못 쟀다.** 🔴 **합격선 ① 은 결재 ㉯ 조건 3 의 본문**이다 ⇒ **상신 조건으로 유지**한다. 「닫혔다」로 적을 수 없다.

### 7-2 🔴 `RenderDocumentAsync` 를 **실제로 부르는** 축 — 1차 기각을 **유지한다 (단, 내 1차 표현을 교정한다)**

🔴 **1차에 내가 적은 것**: *"DB 없이 메울 수 있다 ⇒ PM 의 「DB 있는 환경에서만」 기각."*
🟡 **교정**: **「시험만 더 쓰면 된다」는 뜻이었다면 그건 과했다.** 정확히 적는다 — **막는 것은 「DB」가 아니라 메서드 하나다.**

미리보기 경로가 DB 에 닿는 자리는 **넷**이고, 그중 **둘은 이미 `overrides` 가 비켜 간다**:

| 자리 | 미리보기에서 |
|---|---|
| `LoadDocumentAsync` | 🟢 **안 탄다** — `overrides.UseSampleData == true` ⇒ `BuildSampleSnapshot` |
| `TryLoadTemplateAsync` | 🟢 **안 탄다** — `overrides.Template is not null` ⇒ `ToTemplateInfo` |
| `EnsureOpenAsync` | 🔴 **탄다** |
| `LoadCompanyAsync` | 🔴 **탄다** ← **이 하나가 유일한 실질 차단막** |

🟢 **그래서 남는 길은 둘이다 — 둘 다 「DB 필요」가 아니다**:

**길 ⓐ — 제품 코드 0줄, 연결 대역(代役).** `PdfRenderService` 생성자가 받는 연결에 **SQLite in-memory** 를 꽂고 회사정보 표 한 벌만 만들어 Dapper 가 그것을 읽게 한다. 🔴 **조건**: `LoadCompanyAsync` 의 SQL 이 MariaDB 전용 문법(역따옴표·전용 함수)을 안 써야 한다. 🔴 **검증팀은 그 SQL 을 이번 라운드에 안 읽었다 ⇒ 길 ⓐ 의 성립 여부는 「미검증」.**

**길 ⓑ — 한 줄 이음새(설계 결재 필요).** 이미 있는 `PdfPreviewOverrides` 에 회사정보를 **얹는다** — 미리보기는 이미 **저장 전 값**을 넘기는 통로이므로 결이 같다:

```csharp
// PdfPreviewOverrides 에 한 칸 추가 (설계 결재 사항)
public CompanyInfo? Company { get; set; }

// PdfRenderService 안 — 지금 한 줄을 삼항으로
var company = overrides?.Company ?? await LoadCompanyAsync(tenantId, ct).ConfigureAwait(false);
```

이것이 서면 게이트가 **같은 자료를 두 길에 먹여** 이렇게 잴 수 있다 — **결재 ㉯ 조건 3 이 요구한 측정법 그대로**:
1. `RenderDocumentAsync(t, "delivery", "", overrides, ct)` 로 **미리보기 PDF 바이트**를 받고
2. 같은 스냅숏으로 **4인자**를 불러 **인쇄 PDF 바이트**를 받고
3. 두 PDF 의 **글자를 뽑아 대조**(합격선 ① ) + **배경 포함 여부가 ②에서만 0** 인지(R-1 종단) 단언.

🔴 **판정**: PM 의 *"DB 필요라 못 세웠다"* 는 **반쯤 참이다.** 🔴 **「DB」가 아니라 `LoadCompanyAsync` 한 자리**이고, PM 은 **그것이 무엇인지 적지 않았다** — 「DB 필요」로 뭉개면 다음 사람이 **다시 똑같이 포기한다.** 🟢 **기각을 유지하되**, 집행에는 **[2] 설계 결재(길 ⓑ)** 또는 **길 ⓐ 의 성립 확인**이 선행한다고 적는다. **검증팀이 「시험만 쓰면 된다」고 읽히게 쓴 것은 내 잘못이고 여기서 교정한다.**

### 7-3 반려 ③ 전표 6화면 화면인쇄
🔴 **이번 범위 밖 — 재검증 안 했다.** 🟡 다만 §0 의 결-2 코드(`DocumentPrintPreviewDialog.razor` · `DocumentPrintPreview.cs` · `DocumentController` 수정)가 **그 자리를 건드리는 중**으로 보인다 ⇒ **별 차수에서 [1-V] 부터**.
