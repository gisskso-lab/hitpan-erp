## 볼 곳 ② — G-S3-2 시험 꼴 판정 (개발자 확인 요청)

**판정: 회송 해당 아님 · P3-1 로 적발.**

- 설계 :111 「#1022 꼴을 쓰기 어려우면 = 멈추고 회송(우회 시험 임의 대체 금지)」 은 **꼴을 버리고 다른 시험으로 바꾸는 것**을 막는 줄이다. 이번 것은 #1022 꼴(TestHost · MVC 만 · 시험 인증 · Strict 가짜 — `BetaClosedChatHttpGateTests.cs:78` · :85 와 같음)을 그대로 쓰고 **실물 부품 하나(`TenantMiddleware`)를 더 얹었다**. 대체가 아니라 실물에 더 가까워진 쪽이다. 자리도 맞다 — 실물 `Program.cs:800` 인증 · :801 권한 · :805 `TenantMiddleware`(사이 :804 `RateLimitMiddleware` 는 시험에 없음 · 영향 없음).
- 더 얹은 까닭이 맞다: `#1022` 의 `ChatController` 는 `[Authorize]` 만(`ChatController.cs:30`)이라 정책이 필요 없었지만 `DeviceController` 는 클래스에 `[Authorize(Policy = "TenantOnly")]`(`DeviceController.cs:19`)라 정책이 없으면 시험 집이 뜨지 않는다. 처리기가 `HttpContext.Items` 를 읽으니 미들웨어 없이는 M1 · M2 가 빨강이 되지 않는다(명세서 §5 :89).
- 옮겨 적은 정책(`BetaClosedDeviceHttpGateTests.cs` `AddPolicy("TenantOnly", …)`)은 지금 `Program.cs:396` ~ :399 와 **글자로 같다**(확인). 정책이 바뀌어도 시험이 따라가지 않는 것은 사실이나 **닫힘 판정은 정책과 무관**하다 — `[NonAction]` 이면 끝점이 없어 권한 판정이 돌지 않고 404 가 난다. 정책 사본이 어긋나면 흔들리는 곳은 대조군 G-S3-2-4(200)와 M1 · M2 의 HTTP 빨강뿐이고, 같은 변이는 반사 목록 G-A1-1 이 정책과 따로 잡는다. 거짓 초록 길 = 없음(두 겹).
- **P3-1**: 사본이 실물과 같은지 지키는 줄이 없다 — `Program.cs` 에 같은 판정 글자가 있는지 단언하는 한 줄을 권함(다음 손댈 때 · 이번 머지 막지 않음).
