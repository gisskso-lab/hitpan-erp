## 3. 미확인(이번에 못 본 것)

- 로그아웃 뒤 같은 출입증이 정말 401 이 되는가(JWT 무효화 · `SessionValidityMiddleware`) — 서버 코드 안 봄. 안 되면 M9 가 모든 대상에서 D 거짓 → main 런에서 드러남.
- 자식 만들기 `POST api/users` 의 `email` 칸에 `ci-wc…`(메일 꼴 아님)가 받아지는가 — 시드(`seed-children.js` :101)와 같은 꼴이라 될 것으로 보이나 실측 아님. 실패 시 시드 자식 가로 대체(결과 칸 기록).
- MudBlazor 고르개 실물 일치(`.mud-radio` 부모 구조 · `.hp-menu-item` 글 · `button.hp-mha-btn:has(.hp-mha-avatar)` · 인쇄 설정 첫 쓰기 칸) — main 대조 런이 첫 실물.
- 자체시험을 `git archive` 사본에서 돌리면 옛 · 새 둘 다 `C15 시험 자체 예외` 로 멈춤(이 PC 환경 몫으로 보임 · 나무 안에서는 134/134). 명세서 §5 의 「옛 123/123(사본)」 은 다시 재지 못함 — 대신 §1 ① 의 판정기 38벌 대조로 갈음.
