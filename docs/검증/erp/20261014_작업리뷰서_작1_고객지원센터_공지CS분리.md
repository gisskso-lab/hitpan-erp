### 🔴 V-1 에서 적발한 것 2건

**(1) `G-W9-4` 의 음성 대조군 문구가 실행 불가다.** 작지서 §7 은 「쪽별 LIMIT 를 **단일 `LIMIT 200` 으로 되돌린다**」고 적었다. 구현에는 **되돌릴 쪽별 LIMIT 라는 장치가 없다** — SQL 은 `LIMIT 200` 한 줄이고, 쪽별 집계는 **WHERE 의 쪽 조건**에서 나온다(주석도 「쪽별 LIMIT」라고 말하지만 실제 수단은 WHERE 다). 실행 가능한 유일한 형태가 `{sideWhere}` 제거이고, 그러면 **1·2·4·15 네 건이 함께** 빨개진다. ⇒ 게이트가 동작을 재는 것은 맞지만, **작지서 §7 의 그 줄은 사실과 다르다**(문서 교정 대상 · 코드 문제 아님).

**(2) CRLF 함정을 독립적으로 재현했다.** `G-W9-9` 를 여러 줄 패턴으로 깨뜨린 **첫 시도가 치환 0건 = 무효**였다(`Sidebar.razor` 는 CRLF 597·700줄 전부 · 패턴을 LF 로 적었다). 개발명세서가 기록한 것과 **같은 함정이 같은 파일에서 다시 재현됐다.** 슬러프 모드 + `\r?\n` 로 다시 깨뜨려 치환 1건을 확인한 뒤 단독 FAIL 을 봤다. ⇒ 🔴 **판정 전에 치환 줄 수를 세지 않으면 「대조군 돌렸다」가 거짓이 되는 자리다.**

## §10 [5] 로 올릴 때 붙일 말

1. **코드 축은 섰다** — 범위·회귀·보안·칸 없는 DB 축에서 **반려 사유 0건**. 음성 대조군은 13건을 내가 다시 깨뜨려 **13/13 빨개졌고**, 그중 **8건은 그 게이트만** 빨개졌다.
