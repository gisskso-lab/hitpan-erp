## 4. 🔴 신규 결함 — 업데이트 후 502 (사장님 발견)

### 무엇을 겪었나

```
"업데이트 완료" → F5 누르라는 안내 → F5 → 🔴 502
→ 다시 새로고침 → 정상
```

### 사장님 지적 (원문)

> *"완벽하게 업데이트 되고 F5 누르라고 해야겠다. 고객들 헷갈리겠어."*

### 실측

| 항목 | 결과 |
|---|---|
| PM 외부 실측 (18:12~18:13) | **HTTP 200 · 3회 연속** — 정상 복구 |
| 원인 | 재기동 중 API 가 뜨기 전 요청 → 터널이 빈 곳을 가리킴 |
| 지속성 | 일시적 (수 초~수십 초) |

### 왜 P0 인가

**시스템은 정상인데 고객 눈에는 고장으로 보인다.**

- 사장님은 다시 눌러보셨지만, **현장 직원은 502 를 보는 순간 전화한다**
- 대리점 10곳 · 고객사 5만 규모에서 **CS 폭증** 경로
- 8/02 *"안 받아짐"* 신고와 **같은 계열**(정상인데 고장으로 보임)
- 히트판 존재 이유 정면 위배 — *"처음 보는 사람이 혼자 쓸 수 있냐?"*
  **502 화면 앞에서 혼자 해결할 수 있는 사람은 없다**

### 봉합 방향 (챕터2에서)

| 지금 | 고칠 방향 |
|---|---|
| "완료됐으니 F5 누르세요" | **서버가 살아난 것을 확인한 뒤** 자동 새로고침 |
| 눌렀는데 502 | 아직이면 *"마무리 중입니다"* 표시하고 **대기** |
| 고객이 판단 | **시스템이 판단** |

⭐ **핵심: 준비되기 전에는 새로고침 자체를 권하지 않는다.**
