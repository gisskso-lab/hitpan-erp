## 1. 화면 ↔ DB 정합 영역 (마이그 데이터 기준)

### 1.1 거래처 관리 (/partners, 13,542건) — `Pages/Partners.razor`
- 컴포넌트: `PartnerMasterService.LoadServerDataAsync`
- API 호출: `GET /api/partners?search&type&page&pageSize` (PartnerController)
- 화면 컬럼: 코드 / 업체명 / 유형 / 등급 / 여신한도 / 잔액 / 미수금 / 연체 / 사용
- 페이지네이션: `MudTable ServerData` + `RowsPerPage=50` (13,542건 → 271 페이지)
- 검색·필터: `_search` (코드·업체명), `_type` (customer/supplier/both)
- 정합 영역: PartnerController.cs `[HttpGet]` 15개 — 잔액·미수금·연체 컬럼이 마이그 직후 partners 테이블에 채워졌는지 실측 필요 ⚠️
- 사고 영역 박제: 마이그 직후 잔액 0 표시 가능성 → collections 614,212건 집계 누락 의심

### 1.2 상품 관리 (/items, 337건) — `Pages/Items.razor`
- 컴포넌트: `ItemMasterService` + `BomService` + `DeliveryService`
- API: `GET /api/items?search&type` (ItemController, 9개)
- 화면 컬럼: 상품명·코드·유형(product/material/semi_finished/finished)·안전재고·현재고
- 안전재고 미달 배너: `stock_alerts pending` 조회 → 자동발주 사슬
- 정합 영역: 337건 → 1 페이지 OK. 현재고는 stock_ledger 115,460건 SUM(qty) 영역 — `Task.WhenAll + MySqlConnection` 금지 정합 필요 (헌법 #16)
- 사고 영역 박제: 안전재고 미달 배너가 마이그 직후 동작하는지 미검증

### 1.3 견적 (/quotation-status, 0건) — `Pages/Sales/QuotationStatusPage.razor`
- 마이그 데이터 0건 — **사장님 박제 사고 영역 (레거시 MDB에 견적 미존재)**
