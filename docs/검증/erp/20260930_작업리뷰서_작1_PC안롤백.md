## 2. 발견

### F-1 🔴 P1 — 원위치(S7) 중 예외가 나면 다시 켜지 않고 끝난다 · 고객 PC 가 꺼진 채 남는다 (실측)
- 위치: `src/HitPan.API/Rollback/local-swap.ps1:640-645`
  ```
  try {
      try { Stop-All } catch { ... }
      Invoke-Revert
      [void](Start-All)
      $back = Test-Running ([string]$script:Req.from) 'S7'
  } catch { Write-Log ('S7 failed: ' + $_.Exception.Message) }
  ```
  `Invoke-Revert`(`Move-Part` → `Remove-Item`/`Move-Item`, `$ErrorActionPreference='Stop'`)가 던지면 **`Start-All` 을 건너뛴 채** 안쪽 catch 가 삼킨다 → `broken` 기록 → finally 는 잠금·작업만 지운다. 바깥 catch(`:658-663`, `$stopped` 면 `Start-All`)는 안쪽이 삼켜서 안 탄다.
- 재현(스크래치 사본 · `-TestRoot` · 레포 무접촉): `Invoke-Revert` 첫 줄에 `if (Test-FailAt 'S7R') { throw }` 주입.
  | 경우 | 끝 상태 | 마지막 keepalive | Guardian | 워치독 서비스 | api 판 |
  |---|---|---|---|---|---|
  | 대조: 원본 `S6` | reverted | ENABLE | ENABLE | Running | 1.3.48 |
  | 원본 `S6,S7`(기존 게이트 `LocalSwapOnStartGateTests:90` 모양) | broken | **ENABLE** | ENABLE | Running | 1.3.48 |
  | 주입 `S6,S7R` | broken | **DISABLE** | **DISABLE** | **Stopped** | **1.3.47(반쯤 교체)** |
  | 주입 `S3,S7R` | broken | **DISABLE** | **DISABLE** | **Stopped** | 1.3.48 |
- 남는 것 = ONSTART 안전망 하나(`:651` 주석) — **재부팅해야** keepalive 만 켠다(Guardian·워치독 서비스는 안 켠다). 사장님 원칙 「고객 손 0번」(#28·#30)과 어긋난다. 워치독 `UpdateProcessGate.RestoreKeepalive` 는 「try/finally 에서 무조건」인데 이 일꾼은 그 규칙을 안 옮겼다.
- 🔴 기존 게이트가 못 잡는 이유: `S7` 주입점은 `Test-Running`(= `Start-All` **뒤**)에 있다 ⇒ 「broken 이어도 켜져 있다」만 잰다. 원위치 자체가 던지는 경로는 게이트 0.
- 실물 유발 가능성: 교체 대상 폴더의 파일 잠금(백신 검사·잔존 핸들)으로 `Move-Item`/`Remove-Item` 실패 — Windows 에서 드문 일 아님(⚠️빈도 미측정).
- 봉합 조건(구현 아님 · 권고): S7 의 `Start-All` 을 `finally` 로(원위치 성패와 무관) · 바깥 catch 도 `$stopped` 면 무조건 · 게이트 = `Invoke-Revert` 예외 주입점 + 「broken 뒤 keepalive ENABLE·서비스 Running」 + 대조군(`finally` 뺀 사본 FAIL).
