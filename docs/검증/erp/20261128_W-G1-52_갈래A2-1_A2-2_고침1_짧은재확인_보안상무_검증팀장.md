## 줄 끝 의견 (PM 판단 칸 ④)

동의 — 「변환기 손 0 · `\r\n` 덤프면 멈춤(fail-closed)」 로 닫는 것이 맞다. 근거: ① `--help` 도 덤프와 같은 stdout 으로 나가므로 파이프에서 LF 만 나왔다 = 이 실행 파일의 stdout 은 줄 끝을 안 바꿈(텍스트 모드 변환 없음) ② 옛 실물 덤프 1개 CRLF 0 ③ 만약 CRLF 가 와도 ` VALUES\r\n` 은 두 꼴 어디에도 안 맞아 자료 있는 첫 INSERT 에서 멈춤(자료는 그대로 · 가용성 문제일 뿐 안전 문제 아님). 단서 한 줄: 「멈춤」 은 자료 있는 표가 하나라도 있는 덤프 기준이며, 빈 표만 든 CRLF 덤프의 CREATE 경로는 실측 0 — 실사용 덤프에선 해당 없음으로 보고 기록만.
