- **덧붙여**: 워커는 **HTTP 2xx 만 보고** 「도착확인 완료」를 적는다 — `acked=0` 이어도 같다(`CsOutboxSenderWorker.cs:508-512`). 응답의 `acked` 를 안 읽는다.
- **내가 쟀나**: ⚠️ 코드 직독 · 재현 미실측(경주 창을 로컬에서 만들 수 없다).

## §4 오더 3 「최종 도는지」 — 어디까지 증명됐고 무엇이 안 됐나

🔴 **섞지 않는다.**

1. 끊긴 한 자리가 **실제로 이어졌다** — `bo_cs_outbound` → Pull 응답 `outbound` 배열 → ERP `cs_requests`/`cs_replies` → ack → `delivered_at`. 경로의 모든 고리가 코드에 있다.

## §8 PM 봉합기록 (2026-10-12 · 5차수 `작성중`) — 🔴 §7 의 「로컬에서 못 돈다」는 **틀렸다**

### ⓐ 「로컬 실행 불가」가 틀린 기록이었다 — 두 번째 재발

§7 과 작지서 §6-4, CI 주석 세 곳에 「`CREATE DATABASE` 거부 ⇒ CI `db-gate` 가 **유일한** 계측 경로」라고 적혀 있었다.
근거를 실제로 재 보니 개발 계정은 **`test_` 접두 이름이면 DB 를 만들 수 있다**(MariaDB 기본 허용 · `SHOW GRANTS` 로 확인 후 `CREATE`/`DROP` 왕복 실측).

- 게이트에 `HITPAN_W3_ERP_DB`·`HITPAN_W3_BO_DB` 지정을 뚫었다. 🔴 이 게이트는 **DB 를 DROP** 하므로 이름에 `test`·`gate` 가 없으면 **지정을 거부**하고 무작위 이름으로 돈다(실물 DB 를 지울 길을 아예 없앴다).
- **실측: 6/6 통과 · 54초** (1초대면 조용한 SKIP 이다 — 소요시간이 판별이라는 누적 교훈 그대로)
