**4-1 각 사실이 단언하는 것**

**4-2 조건이 빠지면 G-2 가 빨강인 까닭(코드)**
- 줄 SQL WHERE 는 `pri.tenant_id = (JWT 회사)` 로 회사 A 줄만 남김. 조건이 없으면 조인이 `i.item_id = pri.item_id` 하나라, `items` 는 `item_id` 단일 PK(TEMPORARY 도 DDL 대로)이므로 B1 줄이 **회사 B 품목 행**을 찾음 → `ItemName = 「나회사비밀품」` · `Spec = 「B-규격99」` → 표준 표가 그대로 그림(`PdfRenderService.cs:997-998`) → `:133 Assert.DoesNotContain(NameB1, …)` 빨강.
- 조건이 있으면 B1 줄은 짝 없음 → NULL → 품명 칸 빈 칸 · 금액 칸은 상세행 COALESCE 값 그대로(`:1006-1009` 가 `line.Total` 을 찍음) → 53,790 남음.
- G-1 · G-0 은 모든 줄의 품목 회사 = 줄 회사라 조건 유무와 결과가 같음 → 변이에도 초록 = 변이가 재는 것은 조각 하나.
