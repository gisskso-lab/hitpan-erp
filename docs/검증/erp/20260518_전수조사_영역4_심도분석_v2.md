## 🚨 진범 #46 (NEW) — itemKey 패턴 불일치 발견

### `BuildItemKey` 헬퍼 (line 5376~5381)
```csharp
private static string BuildItemKey(string pumName, string spec)
{
    return string.IsNullOrWhiteSpace(spec)
        ? pumName.Trim()                 // spec 비면 pumName만
        : $"{pumName.Trim()}|{spec.Trim()}";  // 둘 다 Trim
}
```

### `MigrateItemsAsync` (마스터, line 1056)
