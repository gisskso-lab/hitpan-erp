## §0. 사장님이 못박은 2대 검증게이트 (기본 중 기본)

> **"기본 중에 기본인 이 두 가지가 반드시 선행되어야 함."**

```
【시나리오 1 — 신규 진입 (백지)】
랜딩 가입 → 도메인 생성 → 백오피스 시리얼넘버 생성 → 설치파일 설치
→ 설치 후 정상 연결·가동 → UPDATE 정상가동 → 워치독 정상가동

【시나리오 2 — 재설치 (포맷·PC교체)】
설치파일 재설치 → 설치 후 정상 연결·가동 → UPDATE 정상가동 → 워치독 정상가동
```

두 시나리오 모두 **"UPDATE·워치독 정상가동"으로 닫힘** = UPDATE 통로 확보가 두 시나리오의 종착. 사장님 우선순위(UPDATE 최우선)와 정합.

### 결재란
- **CTO 결재**: **부분수정후승인 → 3건 반영 완료(N-3·N-5 승격/추가, G-1 kid·G-2 DNS PATCH, 도메인규칙 BLOCKING) → 승인** (2026-07-24)
- **사장님 최종 결재**: **OK — "작지서대로 진행해" (2026-07-24)**

## §2. 🔴 NCP 실측 확인 목록 (사장님 결재 후 최우선 — 코드보다 먼저)

> **이게 급소다.** NCP 백오피스에 아래 환경변수가 실제 설정됐는지 열어봐야 확정. 미설정이면 "설치는 되는데 접속·로그인 안 됨"이 재현.
> **CTO 결재 수정 반영(2026-07-24):** N-2 격하·N-3 승격·N-5 추가 (코드 실측 근거).

| # | 환경변수 | 없으면 | 급소등급 | 근거(CTO 실측) |
|---|---|---|---|---|
| **N-1** | `CLOUDFLARE_API_TOKEN`·`ZONE_ID`·`ACCOUNT_ID` | 도메인·터널 자동발급 skip → 접속 불가 (그런데 성공 응답) | 🔴 **BLOCKING** | `CloudflareDomainService.cs:60-63`, `InstallerBootstrapController.cs:102`·186(skip돼도 success=true) |
| **N-3** | `HITPAN_BOOTSTRAP_TOKEN_KEY` | 미설정 시 **예외→500** = 부트스트랩 자체 불가 | 🔴 **BLOCKING(진짜 급소)** | `InstallerBootstrapController.cs:163-166`. (작 v1이 약하게 표현한 것 승격) |
| **N-4** | `License:Pepper`·`Backoffice:BizNoPepper`·`NTS_API_KEY` | 시리얼 해시·사업자검증 (Pepper 미설정 시 500) | 🔴 BLOCKING | `InstallerBootstrapController.cs:57` |
| **N-5** | `ConnectionStrings:BackofficeDb` + 백오피스 서비스 가동·TLS(back.hitpan.kr) | 미설정 시 부트스트랩 500 = **모든 시나리오 시작조차 안 됨** | 🔴 **BLOCKING(v1 누락)** | `InstallerBootstrapController.cs:228-230`·214(HTTPS 전제) |
| **N-2** | `HITPAN_SERIAL_SIGN_PRIVATE_KEY(_FILE)` | 공개키 서명 증표만 생략 → **HMAC 폴백으로 부모계정 생성은 뚫림** | 🟡 **정식 전 숙제(#40)** | `LandingPublicController.cs:256-259`(발급지), `SeedParentCommand.cs:136` allowExpired·HMAC 이행기 수용. **BLOCKING 아님** |

**확인 방법(읽기 전용):** NCP 백오피스 systemd 환경/설정에서 위 키 설정 유무만 확인(값 노출 금지). 미설정분은 사장님 결재 후 설정(#29).
**CTO 정정 요지:** N-2를 "없으면 로그인 불가"로 단정한 v1은 과장 — HMAC 폴백으로 우회됨. 진짜 BLOCKING은 N-3·N-5(부트스트랩 자체 500).

## §3. 검증 게이트 (각 단계 통과 기준 — "코드상 된다" ≠ "된다")

> 헌법 feedback_dev_pc_proves_nothing: **백지 Sandbox 실측만 인정.** 개발PC·정적진단 불인정.

### G-1 시나리오1 백지 종단 (BLOCKING)
1. 백지 Sandbox → 랜딩 가입(사업자검증 통과) → 승인 → **도메인·터널 실발급 확인**(N-1 전제)
2. 시리얼 수신 → HitPan-Universal.iss 설치 완주(clean DDL 124테이블)
3. **부모계정 생성 성공**(HMAC 폴백으로 가능, N-2 공개키 불필요) → 로그인 200 → `/me` 200(복호화)
4. 터널 도메인으로 외부 접속 200 (**응답코드 아닌 실제 접속**으로 판정, §5)
5. 워치독 서비스 Running + 1분 자가진단
6. **[CTO 추가] 워치독 내장 공개키 kid ↔ NCP 서명 kid 일치 실측** — G-3(UPDATE 서명검증)의 숨은 전제. 불일치면 G-3에서 "서명검증 실패" 두더지잡기(7/16 DER≠P1363 전례). G-1에서 미리 못박음.

### G-2 시나리오2 재설치 종단 (BLOCKING)
1. G-1 완료 PC를 포맷/백지 리셋 → 같은 시리얼(또는 재발급)로 재설치
2. 재설치 완주 → 터널 재연결 → 로그인 200
3. 잠금게이트가 재설치 안 막음 확인(is_locked 백지=0)
4. **[CTO 추가] 재설치 시 DNS record가 새 터널 ID로 PATCH됐는지 실측** — 재설치는 DNS 81053(already exists) 경로(`CloudflareDomainService.cs:103`)를 타는데 실패도 삼켜짐. 1033(옛 터널ID 잔존) 재발점. 외부 접속 200으로만 확정.

### G-3 UPDATE 종단 (핵심 BLOCKING — 두 시나리오 공통 종착)
1. G-1으로 깐 EXE(예 1.2.40)에서 → **상위버전 신규 게시**(1.2.41, 같은버전 감지0)
2. NCP webroot `/var/www/updates` 정정 전제(안 하면 100% 실패)
3. 워치독 감지 → 서명검증 → **교체 완주** → 재시작 후 FileVersion 상승
4. 판정 3지표만: `local_update_apply_status`=성공 + `/health` 버전 + FileVersion. (MetaPing400·로컬watchdog500 = 정상노이즈, 실패 아님)
5. **롤백 리허설**: 일부러 실패 주입 → 자동 롤백 → 구버전 정상복귀(#39)

**SoD**: G-1~G-3 만든사람≠검증자. 손으로 API 띄우기 금지(Session1 유령·순간판정 오염). 오염 시 백지 리셋 후 재실측.

## §4. 착수 순서 (사장님 NCP 결재가 병목)

```
[0] ★CTO 추가★ 비특권화 v2 §3-G1 webroot 레포정정 커밋 (publish-update.sh:41 → /var/www/updates)
      — G-3 실측의 전제(상주본은 정정 완료·레포 원본은 미정정=거짓봉합 적발). 이 1건만 검증 前 선행.
   ↓
[선결] 사장님 NCP 결재 (#29) — 2시나리오 전체 병목
   ↓
[1] NCP 실측 확인 §2 (N-1·N-3·N-4·N-5 설정 유무, 읽기전용) → 미설정분 설정
[2] UPDATE 게시다리: webroot 정정(✅상주본 완료) + deploy-update 활성화(A-3~A-6)
[3] G-1 백지 신규진입 종단 실측 (워치독 kid 일치 포함)
[4] G-2 백지 재설치 종단 실측 (DNS PATCH 실측 포함)
[5] G-3 UPDATE 종단 실측 (1.2.41 게시 + 롤백 리허설)
   ↓
2시나리오 통과 = PHASE 0 완료 = 이후 모든 수정 "딸깍" 전환
   ↓
[검증 통과 후] 배포계정 비특권화 v2 본체 = PHASE 3(과금 전) — 검증을 인질로 잡지 않게 나중
```

**CTO 순서 판정:** 완전 비특권화(계정·sudoers·Secret 교체)를 검증 前에 하면 배포 파이프가 흔들려 **검증 게이트가 인질**. 검증 먼저(root 파이프 유지)·강화 나중(#39). 단 webroot 레포정정 1건만 [0]으로 선행.
**병렬 무관:** clean DDL CF-1·2(신규설치 무결성)는 G-1 로그인 안 막음 → 트랙 뒤/병행.
