### 새 발견 (모두 🔵 P3 · PR 막지 않음)

- **N1 알림은 「그 계정으로 처음 로그인한 사람」 이 가져간다** — `ParentResetStore.cs:170-188`. 몰래 다시 정한 사람이 먼저 로그인하면 알림을 그 사람이 보고 끝(`notified_at` 찍힘). 진짜 대표는 옛 비번이 안 먹어 어차피 알아채고, DB 감사 줄 · 로컬 감사 파일은 남으니 설계 R16 ⑤ 의 뜻은 「본인이 다시 정한 확인」 쪽으로 읽는 게 맞음. 설계 1줄(PM)로 기대를 사실대로.
- **N2 끊기 회사 조건은 동작 시험이 없음** — DB `X6` 끊기 시험은 자식 행이 안 끊기는 것(user_id 구분)만 잼. `JOIN users … tenant_id` 를 빼도 초록(한 DB 한 회사 · GUID). 지금 결과 같아 위험 0 · 「한 DB 여러 회사」 가 되면 그때 시험 덧.
- **N3 DB-151 제자리 칸 덧** — 1차 판을 적용한 DB(시험 PC · CI 캐시)가 있으면 칸 없음. 합류 때 「DB-151 을 돌린 곳이 있나」 PM 확인 1줄(없으면 그대로).
- **N4 윈도우 11 시작 메뉴** — 기본 화면은 「고정됨」 이라 「HitPan ERP」 묶음은 「모든 앱」 을 눌러야 보임. 괄호 속 검색 길(「대표 비밀번호」 입력)이 있어 막히진 않음 — 시험 PC 실측에서 첫 걸음 문구를 같이 볼 것.
- **N5 약관 동의로 돌아가는 로그인** — `Login.razor:448-452` 약관 이동이 알림보다 앞이라 그 로그인엔 알림 안 뜸 · 표시도 안 찍혀 다음 로그인에 뜸(잃지 않음) ✅ 참고만.
