# W-G1-51 갈래 Z · 측정 장치 글꼴 길 — 법무 1줄 의견

> 법무팀장(김앤장 관점) · 2026-11-19 · 범위 = 시험 러너 안 측정 장치의 글꼴 길 ①·② 만 (제품·설치본 0줄) · 코드·실행·커밋 0
> 근거 = 공개 원문만. 확실하지 않은 칸은 「확인 필요」 — 추정은 단정하지 않는다.

## 법무 1줄

**길 ① = 조건부 가** — 필수 ㉠ 수정한 글꼴 파일·사본을 러너 밖으로 내보내지 않음(산출물·캐시·저장소 업로드 0) ㉡ 모든 이름 기록(ID 1·3·4·6·16·18 · 다른 언어 기록 포함)에 「Nanum」「Naver」 낱말 0, ID 4·6 은 「Malgun」 도 없는 중립 이름 ㉢ 저작권·라이선스 기록(ID 0·13·14)과 상표 고지(ID 7, 있으면) 보존 · 공개 산출물이면 필수 ㉣ 「대체 글꼴 기준 측정 · 맑은 고딕(Microsoft) 아님 · 글리프 = 나눔고딕(SIL OFL 1.1, © NAVER Corp.)」 꼬리표 ㉤ 산출 PDF 글꼴 칸(FontName · FontFamily) 실측값을 표에 그대로 적음.
**길 ② = 가** — 파일 수정 0 = 수정본 아님으로 봄. 권고 ㉣·㉤ (PDF 안에 별명이 적히는 경우만 필수). **법무 위험은 ② < ① — 법무 관점 추천 = 길 ②.**

## 상표 쟁점 — 경우 나눔 · 위험 줄이는 조건

| 경우 | 위험 | 조건 |
|---|---|---|
| 길 ① · PDF 글꼴 칸에 중립 PostScript 이름만 남음 | 최저 | ㉠~㉢ · 공개면 ㉣ |
| 길 ① · PDF family 칸에 「Malgun Gothic」 남음 | 낮음 | ㉠~㉤ 전부. 공개 표의 글꼴 칸은 「요청 이름 Malgun Gothic → 실제 렌더 = 대체 글꼴(나눔고딕 기반 수정본, 중립 이름)」 처럼 두 칸으로 적음. 공개 대상을 PDF 대신 측정 표로 줄이고 PDF 보존 기간을 짧게 두는 것도 권고 |
| 길 ② · PDF 에 원본 이름(나눔 계열)만 박힘 | 최저 | 원본을 그대로 내장 = 예약 이름 문제 없음(조항 3 은 수정본에만). ㉣ 권고 |
| 길 ② · PDF 에 별명 「Malgun Gothic」 이 적힘 | 낮음 | 길 ① 의 둘째 줄과 같은 ㉣·㉤ |
| 시험 코드(공개 저장소 가능) 안 「Malgun Gothic」 조회 키 | 사실상 없음 | 제품이 요청하는 글꼴 이름을 가리키기만 하는 지시적 사용. 저장소에 글꼴 바이트 0 이면 배포도 아님 |

- 조항 4: 저작권자 이름으로 수정본을 홍보하면 안 되지만 "except to acknowledge the contribution(s)" — ㉣ 꼬리표의 출처 표기는 감사 표기 범위로만 쓴다.
- PDF 에 실제 적히는 글꼴 칸(길 ①·② 각각) = **확인 필요** — 첫 측정 런 뒤 ㉤ 실측값으로 채운다. 남은 확인 필요 3칸(상표 등록 · 파일 ID 0·7 · PDF 글꼴 칸)이 위 판단을 뒤집는 결과면 이 의견을 다시 낸다.
