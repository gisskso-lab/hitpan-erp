🔴🔴 **더 큰 것 — N-2 에서 `G-RC16` 은 초록이었다.** §4-5.

### 3-3. N-3 (C2 제거) — 🔴 **반쪽만 울었고, 그 반쪽도 0.0004 차다**

**2회 실행 · 두 번 다 같은 값**:

| 채움 | 봉합 후 잠금 | 비 | 건강할 때(V1) | 판정 |
|---|---|---|---|---|
| 0% | 1 | 0.0000 | 0.0000 | 동일 — **못 잡음** |
| **2%** | **2522** | **0.4522** | **0.4522** | 🔴 **완전히 동일 — 못 잡음** |
| 4% | 4464 | **0.8004** | 0.6009 | 🔴 울었다 — **상한 0.80 대비 여유 0.0004** |

🔴 **지시서는 「2~4%」를 예측했으나 2% 는 값이 건강할 때와 소수점까지 똑같다.** C2 에 **눈이 없는 칸**이다.
🔴 **4% 의 여유는 `4464/5577 = 0.800430`** — 상한을 **0.00043** 넘겼다. 잠금 행 수로 환산하면 **약 2.4행**이다.
**C2 를 지켜주는 것이 판정 구간 한 칸의 2~3행 차이뿐**이다.

⚠️ 이 픽스처에서는 값이 **2회 재현**됐으므로 「동전 던지기」라고 말하지는 않는다.
🔴 **그러나 데이터 분포·통계·MariaDB 버전이 조금만 달라지면 C2 는 감시 밖으로 나간다.** 계수 0.80 (P-20) 의 **여유가 사실상 없다**.

### 4-2. 🔴 G-RC16 보고표가 **재현되지 않는다** — PM §10-2 와 다른 값

독립 실측(33306 · `hitpan_a_base_*` / `hitpan_a_seal_*` · 1회):

|---|---|---|
| 0% | **막힘 3,005ms** | 막힘 3,010ms 🟢 일치 |
| **2%** | 🔴 **막힘 3,019ms** | ❌ **「①~⑤ 전부 기준선 통과(2ms)」** |

🔴 **2% 칸에서 PM 은 「통과」를, 독립검증은 「3초 막힘」을 봤다.**
판정(FAIL/PASS)은 안 뒤집힌다 — W-3 은 *기준선 통과 → 봉합 막힘* 일 때만 운다. **막힘이 늘어난 건 살아있음에 유리하다.**
🔴 **그러나 뜻하는 바는 크다**: **G-RC16 의 보고표는 회차마다 달라진다.** PM 은 **1회만** 재고 그 표를 §10-2 에 「실측」으로 올렸다.
⇒ **「살아있음 1건」이라는 수치도 회차 의존이다.** 살아있음이 **0 으로 떨어지는 회차**가 있는지 **PM 은 안 쟀고 나도 아직 못 쟀다**(§7).

### 4-3. 🔴 G-RC17 **0% 칸은 측정 실패(-1)를 그대로 통과시킨다** — 거짓 초록 구멍

V-2 에서 PM 이 한 주장(*「끝내 못 잡으면 `-1` 을 그대로 둔다 — 거짓 초록을 안 만든다」*)의 **반쪽만 맞다.**
`-1` 은 확실히 **반환**된다. 🔴 **그런데 `G_RC17_PairInequality` 의 0% 칸은 그 `-1` 을 잡지 못한다.**

코드(`RcSafePathGateTests.cs` `G_RC17_PairInequality`):

```csharp
if (s.Sum != 0 && s.Locked <= 0)     // ← A-1′ 가드
    failures.Add("A-1′ 위반 …");
```

* 0% 칸은 **정의상 `s.Sum == 0`** 이다 (PM 자신이 「0% 칸은 맞은 전표가 하나도 없다가 정의라서 구조적으로 0」이라고 적었다).
* ⇒ **가드의 첫 조건이 거짓** ⇒ A-1′ 를 **건너뛴다.**
* 이어서 `ratio = (double)s.Locked / b.Locked = -1 / 110661 = -0.000009`
* 판정식은 `if (ratio > 0.80)` 뿐이다 ⇒ **음수는 언제나 통과.**

🔴 **결론: 0% 칸에서 `innodb_trx` 재조회가 12회 모두 실패하면, G-RC17 쌍 부등식은 「비 -0.0000 · 통과」로 초록을 낸다.**
이것은 가설이 아니다 — **PM 의 `run1` 로그(§9-1)가 정확히 그 모양이다**:
`채움 0% … 봉합후 -1 · 비 -0.0000 · 판정`. 그때 빨간불을 낸 것은 **별개 시험인 A-3** 이었지 이 게이트가 아니었다.
⇒ **A-3 시험이 없었거나 그 회차에 A-3 이 우연히 잡혔다면, 0% 칸의 측정 실패는 아무도 못 봤다.**

⚠️ **덧붙임**: `fill > 0` 칸은 `s.Sum != 0` 이라 가드가 산다. **구멍은 0% 한 칸이다.**
🔴 **그리고 0% 는 작2 가 「이관 직후」로 가장 중요하게 본 칸이다.**

### 4-4. ⚠️ 살아있음 단언이 **다른 실패에 가려진다**

`G_RC16_NeighborProbes_W3` 의 살아있음 검사:

```csharp
if (failures.Count == 0 && baselineBlockedTotal == 0)
    failures.Add("🔴 살아있음 위반 …");
```

🔴 **다른 실패가 하나라도 있으면 살아있음 검사를 아예 안 한다.**
「W-3 위반 1건 + 살아있음 0건」인 회차에서 보고에는 **W-3 만** 뜬다 — *게이트가 아무것도 안 재고 있다* 는 더 중요한 사실이 가려진다.
⚠️ 초록 회차에는 영향이 없다(그때 `failures.Count == 0`). **우선순위 낮음 · 별건 권고.**

### 4-5. 🔴 **G-RC16 은 「봉합이 되돌려진 것」을 못 잡는다** — N-2 가 드러냈다

N-2(제품에서 ㉪ 제거 = **봉합 되돌림**)를 돌렸을 때 `G-RC16` 은 **통과**했다. 그 회차 보고표:

```
[G-RC16] 채움 0% · 보유자 잠금 기준선 110661 · 봉합 110258
    ① 무관 거래처 collections INSERT   기준선 막힘(3017ms) → 봉합 막힘(3017ms)
```

🔴 **봉합 쪽 보유자의 잠금이 1행에서 110,258행으로 돌아갔고, 이웃의 수금 등록이 다시 3초를 꽉 막혔다.**
**PM 이 §10-2 에서 「#20 이 실제로 끊겼다가 이어진 자리」라고 부른 바로 그 개선이 통째로 사라졌는데 게이트는 초록이었다.**

원인은 코드에 그대로 있다. `G_RC16_NeighborProbes_W3` 가 실패를 세는 자리는 네 곳뿐이다 —
대조군 막힘 · 보유자 미성립 · 1205/1213 아닌 오류 · **`!b.Blocked && s.Blocked`**.
🔴 **「봉합 쪽이 좋아졌는지」를 단언하는 줄이 한 줄도 없다.** 개선은 **보고표에 인쇄될 뿐 판정되지 않는다.**

### 4-6. 🔴🔴 **W-3 판정은 0% 칸에서 구조적으로 발화 불가** — 5회 실측

`W-3` 는 **`기준선 통과 && 봉합 막힘`** 일 때만 운다. 그런데 **기준선 ① 은 0% 에서 늘 막힌다.**

🔴 **결론: G-RC16 은 「W-3 을 증명하는 게이트」가 아니라 「1/3 확률로만 판정할 수 있는 게이트」다.**
N-8 이 안 운 것(§3-4)은 사고가 아니라 **이 구조의 당연한 귀결**이다.

### 4-7. 🔴 `trx_rows_locked` 가 **막힘과 일치하지 않는다** — G-RC17 의 척도 자체 문제

N-8 회차의 한 줄이 이것을 못 박는다:

```
[G-RC16] 채움 0% · 보유자 잠금 기준선 1(조회 1) · …
    ① 무관 거래처 collections INSERT   기준선 막힘(3011ms)
```

🔴 **보유자가 `trx_rows_locked = 1` 을 보고하는데 이웃의 INSERT 를 3초 꽉 채워 막았다.**
(대조군은 보유자 없이 5/5 통과했으므로 **막은 주체가 그 보유자임은 확정**이다.)

🔴 **G-RC17 의 판정은 전부 `trx_rows_locked` 의 비 하나로 이루어진다.** 그런데 그 수치는 **간극 잠금을 세지 않아** 「1행」을 보고하면서도 실제로는 이웃을 막는다.
⇒ **비가 0.0000 이라고 해서 「이웃이 안 막힌다」가 따라 나오지 않는다.** 계수 **0.80 (P-20)** 은 **피해(#20 워크플로우 끊김)와 단조 관계가 증명되지 않은 척도** 위에 얹혀 있다.

⚠️ **이것이 봉합이 무효라는 뜻은 아니다.** V1 실측에서 봉합 쪽 ① 은 **3~11ms 에 통과**했다 — **실제 개선은 있었다.**
🔴 **뜻하는 바는 「증거의 종류」다**: 개선을 보여 준 것은 **G-RC16 의 보고표**이고, **판정하는 것은 G-RC17 의 비**인데 **둘이 같은 것을 재고 있지 않다.**
