## 0. 판정 요지 — **일곱 번째 모양이 나왔고, 그중 하나는 내 과장이다**

3판은 축을 제대로 넓혔다. R-3(상시 왕복)·R-4(두 글 불일치)는 **코드로 받친다.** §4 사내망 줄 삭제, AI 「아직 쓸 수 없습니다」, C-3 「뿐」 제거도 전부 맞다.

그런데 **삭제한 자리에 넣은 대체 문장 세 개가 다시 단정**이 됐고, 재어 보니 **그 단정을 깨는 시작 경로가 하나 더 있다.**

> 🔴 **`installer/hitpan-start.bat:79` — `HitPan.API.exe --urls http://0.0.0.0:%API_PORT%`**
> 바탕화면 아이콘이 쓰는 그 경로는 API 를 **모든 랜카드에 연다.** API 는 Blazor 앱을 **직접 서빙**하고(`src/HitPan.API/Program.cs:680`·`:681`·`:740`), 301 캐노니컬 리다이렉트는 **5234 의 `web-server.ps1` 에만** 있다 ⇒ **사내망 직접 접속이 코드상 성립한다.**

⇒ 2차에 내가 「사내 주소로 접속하는 경로가 **없다**」고 단정한 것은 **시작 경로 하나(schtasks)만 재고 전체로 말한 과장**이다. 내가 1·2·3판을 반려한 바로 그 모양을 내가 했고(§4 S-6), 그 과장이 **K0-1 5판 §1 내부 지침에 그대로 전파**됐다.
⇒ 그리고 AI 쪽은 **제품 화면이 공개 문서보다 정확하다** — 화면은 「**회사 자료가** 밖으로 나가지 않습니다」로 축을 좁혔는데, 공개 문서는 「**나가는 것은 없습니다**」로 넓혀 **거짓**이 됐다(T-1).
