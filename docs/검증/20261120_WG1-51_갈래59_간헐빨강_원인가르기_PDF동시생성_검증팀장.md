**같은 프로세스 안에서 PDF 를 동시에 만들면(QuestPDF 2026.2.4 `GeneratePdf`) 일부 PDF 의 글자층(글리프→유니코드 대응)이 통째로 빠진다.**

- 운영 영향: ERP API 는 요청을 동시에 처리하므로 **두 직원이 동시에 인쇄 · 메일 · 팩스로 PDF 를 만들면 그중 일부 PDF 의 글자층이 비는 꼴이 운영에도 남는다**(글자 복사 · 검색 · 받는 쪽 글자 추출이 깨짐). 화면 · 종이 모양이 깨지는지는 **미확인**(글리프 자리 · 폭이 같으니 모양은 같을 것으로 추정 · 래스터 대조 안 함).
