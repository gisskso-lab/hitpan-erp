## §C [제안]

**C-1 수정보완 (🔵 전부 · 채택은 사장님)**
- 🔵 ERP 매니저 「3분 안에 쓰나」 — 가입 폼의 필수 칸 중 본사로 안 가는 칸(사업자등록증)은 고객에게 일만 시킨다. 받을지 말지부터 정하자(A-3).
- 🔵 김삼성 상무 — 이 영역은 인사 흐름과 겹치지 않음(해당 없음).
- 🔵 기술영업 「가입에서 설치까지 고객이 혼자 되나」 — 지금은 가입 후 화면이 「다운로드」로 보내지만 시리얼은 승인 뒤에 온다. 화면에 「승인 대기 · 메일을 기다리세요 · 그동안 설치파일은 받아 두셔도 됩니다」 한 줄이면 혼자 간다(A-10).
- 🔵 CS팀장 강지원 「문의가 줄어드나」 — 「결제 완료」「메일 발송했습니다」 문구가 그대로면 무결제 베타 고객의 첫 문의는 「결제한 적 없는데요」·「메일이 안 와요」다. 문구 정정이 문의를 가장 많이 줄인다(B-3).
- 🔵 개발팀(보안) — 시리얼을 URL 쿼리로 넘기지 말고 화면 상태로만 넘기기(`WelcomePage.razor:51` · `DownloadPage.razor:113` · `PaymentPage.razor:191`) — 주소창 기록·리퍼러에 남는다(S-5).
- 🔵 개발팀(보안) — 부르는 곳 없는 `serial/verify`(A-22)를 닫을지 결재.

**C-2 추가기능**
- 🔵 기술영업 — 가입자에게 「승인 완료」 상태를 스스로 볼 수 있는 조회(메일 재요청 포함). CS 전화를 대신한다.
- 🔵 개발팀(보안) — 랜딩 익명 끝점 전체에 요청 빈도 제한(백오피스 API `Program.cs` grep 0). 잠금 키가 클라이언트가 보내는 지문 하나라 지문만 바꾸면 잠금이 안 걸린다(`SerialVerifyController.cs:63` · `InstallerBootstrapController.cs:86`).
