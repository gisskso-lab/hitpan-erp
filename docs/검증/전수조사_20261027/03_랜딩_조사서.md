- 🔵 마케팅팀장 「30초 안에 설명되나」: 히어로·특징 카드가 「3분」을 세 번 쓴다(`HeroSection.razor:12` · `FeatureSection.razor:19` · `CtaSection.razor:10`) — 숫자 약속은 줄이고 「설치 파일 하나·키 하나」 같은 행동으로. 신뢰 뱃지 「메이크빌 기술협력·바른 법무자문·KISA ISMS 준비」 `HeroSection.razor:32-43` 은 실제 계약·진행 증빙이 있을 때만(법무 확인).
- 🔵 기술영업 「이게 팔리냐」: 요금표 자리를 「요금은 상담 후 안내 · 베타 무료」 한 칸으로 — 숫자 없이도 가입 버튼은 산다.
- 🔵 CS팀장 강지원 「문의가 줄어드나」: 문의처가 넷으로 갈렸다 — help@ `LandingFooter.razor:29` · cs@ `DownloadPage.razor:68` · partners@ `RecoveryPage.razor:32` · privacy@ `privacy.html:24`. 하나로 모으고 깨진 CS 링크(F3)를 같이.
- 🔵 법무팀장: 환불 조건 「거래 데이터 100건 이상 입력」 `subscription.html:47` — 본사는 업무 데이터를 안 본다(#18)고 같은 약관 묶음이 말하므로 **회사가 확인할 수 없는 조건**이다.
- 🔵 법무팀장: 동의 사슬의 `postMessage` 가 출처 확인 없이 받는다 `hitpan-signup.js:7-12` · 보내는 쪽도 `'*'` `service.html:121` 등 — 다른 창이 「동의」를 대신 찍을 수 있다(동의 증빙 약함).
