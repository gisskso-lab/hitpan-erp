## §1 원칙 4개 — 받는다 · 다만 「잴 수 있게」 정의한다

| # | 사장님 원칙 | Claude 팀 | 운용 정의 (🔵 제안) |
|---|---|---|---|
| 1 | 실제 업무 처리 + **책임지고 복구** | 수용 | 「복구했다」는 세 가지가 모두 맞을 때만 쓴다. ⓐ 고객이 입력한 자료 손실 0 ⓑ 정해진 시간 안에 업무 재개 ⓒ 고객 손 0번(#28·#30). ⓑ 의 숫자는 G0 에서 사장님이 정한다 (§2 G3) |
| 2 | 기능 동결 · 예외 = 베타 필수 결함 + 실측으로 입증된 누락 | 수용 + 판정 기준 | **베타 필수 결함** = P0 전부 + P1 중 넷: 흐름 끊김(#20) · 원장·회계 정합(#3·#6) · 자료 손실 · 테넌트·권한 침범. **실측으로 입증된 누락** = 사장님 실측 또는 G4·G5 고객 실사용에서 「이게 없어서 업무를 못 했다」고 기록된 것만. 🔴 판정자는 사장님이다. PM 이나 두 AI 팀이 「필수」로 올려 동결을 풀지 않는다 |
| 3 | 만드는 조직 → 책임지는 조직 | 수용 | 지금 루틴에 빠진 칸은 **운영 칸**이다. 장애 연락망 · 고객별 담당 · 배포 중단권 · 롤백 집행자를 G4 종료 조건으로 둔다 |
