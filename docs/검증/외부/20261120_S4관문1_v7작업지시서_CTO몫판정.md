## §8 반증 — 이 판정이 틀릴 수 있는 곳

- **R1** 안 A 는 S3 판정을 HQA 로 넘긴다. HQA 가 결과 전에 답하지 않으면 S3 칸은 결과 뒤 해석이 된다 → 「판정 HQA」 의 사전 공개 사실 행 + HQA 재대조를 대표 v7 런 결재 전 조건으로 둔다(갈래 1 §7 표 그대로). 회신 없이 런 = 반려.
- **R2** S2 가 S3 보다 앞이다(M-1 `errors` ≥ 1 → 장치 무효). 제품이 문맥을 닫게 만든 경우 제품 결함이 장치 실패 글자로 갈 수 있다. 초록은 아니므로 거짓 초록 0 · 원인 글자 오분류만 남는다 → 표본 줄에 `errors` 원문(공개 금지 축 통과분)이 남아 HQA 가 대조할 수 있어야 한다.
- **R3** ② 는 (i-b) 를 「제품 측정값 0」 으로 봤다. 조각이 9.3 마크업을 옮긴 것이면 제품 화면 복제에 가깝다 — 그래도 입력 0 · 항목 0 이라 고르기 방지 약속과 부딪히지 않고, K2 · K4 로 띄우는 자리와 닫는 범위를 묶었다.
- **R4** ④-1 을 (나) 로 두면 v7 이 같은 까닭으로 또 멈출 위험이 커진다 → 그래서 X-4 를 갈래 2 결재 전 조건으로 둔다.
- **R5** §5 줄 번호와 장치 경로는 갈래 2 의 A1 대조를 믿은 것이다. 나는 A1 을 보지 않았다 → [4] 한 줄 대조 뒤 확정.
