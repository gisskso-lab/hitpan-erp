## 재발 방지 (이번 라운드에서 실제로 밟은 것)
- 의뢰 **전에** 3인 대상 확인 → CTO → 대표 (§8-1 #1). 대표 범위 승인이 3인 단계를 대신하지 않는다.
- GPT 감시 목록 = **그 트랙의 모든 PR**(코드 PR 포함). 새 창은 직전 창 목록을 그대로 쓰지 말고 다시 센다.
- 보고에 「CI 초록」을 쓸 때는 **기계 시각**(`gh`)을 붙인다. 손 시각(「20:3x」)은 근거로 쓰지 않는다.
- 파일 개수 셀 때 `git grep`(추적 파일만) — 작업 트리 `grep -r` 은 `bin/` 사본까지 센다.
