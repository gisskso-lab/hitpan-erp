## §3 `run.json` long-token 칸 (CTO 확인 요청)

### 규칙 (장치 A1 `7329cf25` 원문 읽음)
- 누출 검사기는 가림기와 **같은 판정 함수**로 긴 덩어리를 찾고, 하나라도 나오면 꼴 종류 `long-token` 을 붙인다. 하위 꼴 3가지(표준 base64 · 16진 40/64 · 영숫자 22자 이상)가 모두 `long-token` 이름으로 나온다.
- 16진 40/64자는 「알려진 칸」에서만 남긴다: 장치 고정값 · 기대 해시 목록 · 환경 `GITHUB_SHA` · 판독 규칙 · 판독기 파일 지문 / 장치 파일(`run.json` 등) 안에서는 정해진 칸 이름 목록(`sha` · `sha256` · `commit` 등) 뒤에 올 때만.
- **`verdict_sha256` 은 그 칸 이름 목록에 없다** → 값이 공개 해시여도 걸린다.
