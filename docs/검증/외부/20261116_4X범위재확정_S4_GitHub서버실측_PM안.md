### 1-2. PM 안 — 대상 문구

**[4-X] = HQA 관문 ①(A′ 판 · GitHub Linux 러너 위 개발팀 장치 실측 + HQA 원자료 대조 판정) + 코드 원문 대조 4줄 · 관문 ② 규칙은 11/13 그대로**

1. **관문 ① 실행**: 장치 가지(시험 앱 `01161edb` 을 부모로 워크플로 · 측정 폴더만 더함)의 push 로 GitHub 호스트 러너(ubuntu-24.04)가 잰다. 장치 첫 단계 = 시험 앱 나무 `0b31f869…` 단언(다르면 측정 0). 앱 = 릴리스 linux-x64 묶음(지문 대조) · 브라우저 = 릴리스 Chrome for Testing 151.0.7922.34 · Playwright 1.62.1.
2. **항목 · 조건 · 기대값**: 11/7 §5 · 11/13 정본 §6 **글자 그대로 승계**(아래 §6). 장치는 정본 글자 밖의 기대값을 만들지 않는다 — 기대값 글자가 없는 항목은 「판독값 기록 · 판정 = HQA」. T3 는 정의 확인 전 「미측정」. WebKit · Firefox 「미측정」.
3. **HQA 가 대조하는 것**: ① 장치 원문(발행 링크 = 장치 커밋 SHA 고정) ② 원자료(측정 잡이 원자료 가지에 직접 커밋한 파일 · SHA 고정 blob · 각 파일 SHA-256 목록) ③ 원자료 ↔ 런 연결(런 ID · 장전 커밋 · 나무 해시 · 지문 대조 줄) ④ `/before` 대조군 결과. **장치 원문도 의심 제기 대상**이다.
4. **HQA 의심 제기의 효과**: HQA 가 장치가 기대값 글자와 다른 것을 잰다고 지적한 항목은 그 회차에서 「대조 불가」(통과로 안 셈) → 개발팀이 장치를 고쳐 **새 회차**(재발행 → 장전). 조건 변경 요구(표본 수 · 지연 · 창)도 같은 길. HQA 는 직접 다시 돌릴 수 없으므로 이 길이 재실행 요구권이다.
5. **회차 규칙**: 장치 원문 · 판독 규칙 · 기대값 대응표는 **첫 장전 런 전에 커밋하고 링크 발행**. 결과 본 뒤 1글자라도 바뀌면 새 회차 · 새 원자료 가지 · 옛 원자료 보존. 발행 댓글 시각 < 장전 런 생성 시각.
6. **실행 실패**: Linux 기동 · 브라우저 실패는 실패 단계 · 오류 글자를 원자료로 커밋(초록으로 덮지 않음). 시험 앱 자체를 고쳐야 하면 11/7 C5(시험 앱만 고쳐 1회 재발행) 적용 여부 = **3인 판단 요청**(1-3).
7. **쓰기 권한**: 원자료 커밋 잡 하나 · 원자료 가지 하나에만. 기능 · 시험 앱 · main 쓰기 0 · main 으로 PR 0 · 태그 push 0.
8. **공개 규칙**: 원자료는 공개 전 가림(러너 경로 · 회로 ID 후보 · 자격증명 꼴 · 금지어) · 누출 검사 통과분만 커밋 · 걸린 파일은 이름 · 꼴 종류만 목록. HQA 회신 원문 보존 · 재게시 사본 가림(11/13 그대로).
9. **대상 밖**: 서버 · 인가 · 데이터 길(변경 0) · 분석기(11/13 C-2 사본 · 내부 판독 도구 — 이 경로에서 안 씀) · 운영 상세 오류 설정(별건) · 이전 내부 측정 스크립트 · 결과.
10. **그대로**: blob 4개 = A′ 판 머리 대조 · 새 코드 커밋 시 관문 ① 무효 · `/before` 가 실패를 재현 못 한 항목 「대조 무효」 · 코드 원문 대조 4줄(HQA 읽기 몫 · 장치 밖) · 관문 ② 규칙.

### 1-3. PM 이 스스로 반증한 것 (3인 판단 요청)
- **독립성**: 장치 · 판독기 · 가림을 같은 개발팀이 만든다. 막는 것 = 발행 전 고정 · 장치 원문 공개 · 원자료 공개 · 대조군 · 「잰 표본 0 = 빨강」 · 심은 빨강. 그래도 「무엇을 재지 않았는가」 는 HQA 가 장치 원문으로만 볼 수 있다 → 3인 반증 요청.
- **가림이 증거를 지우는 길**: 22자 이상 토큰 가림이 판독에 필요한 값을 지울 수 있다(설계 §10). 가린 수는 기록되지만 원문은 공개 안 됨.
- **11/7 C5 의 대상**: C5 는 「HQA 가 시험 앱을 못 띄우면」 이다. 이번엔 장치가 띄운다. 장치 쪽 기동 실패를 C5 로 볼지(시험 앱 1회 재발행 허용) 아니면 대표 결정으로 바로 갈지.
- **HQA 회신 대기**: S1~S4 대응이 정본 항목과 다르면 대상 문구 2 를 다시 3인에 돌린다(범위 확대 금지 · 11/13 X-2 꼴).
- **분석기 대상 밖 유지**: 이 경로의 판독기(장치 안 `judge.js`)는 장치 원문이라 대상 안 · 옛 분석기는 안 쓰므로 대상 밖 — 둘을 섞지 않았나.
