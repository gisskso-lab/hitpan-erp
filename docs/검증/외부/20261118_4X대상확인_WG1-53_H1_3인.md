### 1-3 H1 질문 최종안 (①~⑤ = 설계 §9 · 보강 표시 「+」)

1. 두 독립 증거(기기 묶인 마커 + 저장소 허용목록 해시)와 G3 만료 조합이 대표 정식설치 PC · 실고객 PC 를 빠짐없이 거절하나 — 우회 경로가 있나. **+ 실행 순간 둘 다 같은 PC 의 로컬 파일이라는 점(F4)에서 「독립」 이라 부를 수 있나 · 위협 모형을 「실수 방지」 로 한정한 것이 충분한가**

3. 「멈춤 관측 → 5분 대기」 · 판정 6칸 · 「전부 PASS 일 때만 합격」 이 거짓 PASS · 숨은 SKIP 을 남기지 않나 **+ PASS 를 「워치독이 살림」 으로 읽게 되는 길(F6)이 남는가**
4. 다루는 4 ID · 안 다루는 목록 · 「17 중 n」 미기재가 부풀림 없이 정직한가 · 결-3 두 안 비교에 빠진 축이 있나
