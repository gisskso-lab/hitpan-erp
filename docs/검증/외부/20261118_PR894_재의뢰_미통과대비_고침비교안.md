## §2 [ⓑ 고침 두 갈래 비교]

**(1) 꼴 추가** — ⓗ1 줄 UTF-8 올바름(바이트 열 검사 1회) · ⓗ2 줄 앞 BOM 0 · ⓔ′ 최상위 수 필드 3개(`bytes` · `verified_secrets` · `unverified_secrets`)마다 맨 글자 1 + 경계 조각 1(`"k":(0|[1-9][0-9]{0,19})[,}]`).
**(2) 줄 전체 허용 문법** — §1 꼴을 C 지역 바이트 문법 하나로 고정, 맞는 줄 수 `gram` = 1 이어야 통과 · 그 밖 = 검사 오류. 조각(초안 · 결재 대상):
- `U=(0|[1-9][0-9]{0,19})` · `C=(0|[1-9][0-9]{0,8})`(chunks · 지금 범위 그대로) · `I=(0|-?[1-9][0-9]{0,18})`(부호 허용은 확인 필요 3)
- `TS=[0-9]{4}-[0-9]{2}-[0-9]{2}T[0-9]{2}:[0-9]{2}:[0-9]{2}(Z|[+-][0-9]{2}:[0-9]{2})`
- `DUR=(0s|([0-9]+h)?([0-9]+m)?[0-9]+(\.[0-9]+)?s|[0-9]+(\.[0-9]+)?(ms|µs|ns))`(µ = 바이트 C2 B5 · 부호 불허)
- `VER=[0-9A-Za-z.+-]{1,32}`(글자 집합만 · 정확값 고정은 digest 관문 몫 — 확인 필요 1)
- 줄 = `^\{"level":"info-0","ts":"TS","logger":"trufflehog","msg":"finished scanning","chunks":C,"bytes":U,"verified_secrets":U,"unverified_secrets":U,"scan_duration":"DUR","trufflehog_version":"VER","verification_caching":\{"Hits":I,"Misses":I,"HitsWasted":I,"AttemptsSaved":I,"VerificationTimeSpentMS":I\}\}\r?$`
- 끝 `\r?` = S11 t(줄 끝 CR = 깨끗) 기대 무변 유지(확인 필요 4). 기존 ⓐ~ⓖ 는 지우지 않고 둔다(#1 추가만 · 해석/글자 칸 이중).
