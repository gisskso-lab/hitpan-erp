- **S1 🟡 필수 · :263 셈 「누락」 정의** — 누락 = 「E 행 중 **허용** 수」 뿐이다. 8차에서 ㉡ 가 들어오면서, h4 가 E4 를 놓쳐도 네이티브가 해석한 뒤 ㉡ 가 거절하면 화면은 「거절」 이고 누락 = 0 → 초록이 된다. E1~E3 도 네이티브 열기 실패로 거절되면 똑같다. 「전 거절」 이 깨졌는데 셈은 초록이 된다. 행 판정 칸(:247 「해석 시작 0」)과 심은 결함 ⓐ 의 빨강 근거(:263)가 셈 정의와 어긋난다.
