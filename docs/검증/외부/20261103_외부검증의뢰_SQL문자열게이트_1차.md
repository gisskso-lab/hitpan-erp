## 질문 — 범주별로 있다 / 없다

| # | 범주 | 묻는 것 |
|---|---|---|
| 1 | 어휘 분석 경계 | C# 소스의 어휘 경계를 잘못 읽어 판정 대상을 놓치는 **범주**가 있는가 |
| 2 | 줄끝 처리 | LF · CRLF 체크아웃에서 판정이 갈리는 **범주**가 있는가 |
| 3 | 대조군의 눈먼 곳 | 도구의 자체 단계가 재지 않는 판정 경로의 **범주**가 있는가 |
| 4 | 필수 검사로 쓸 때의 잡 구성 · 권한 · 로그 | 위반 없이 빨강이 되거나 위반이 있는데 초록이 되는 **구성**이 있는가 · 공개 로그에 남으면 안 되는 것이 나가는가 |

- 답은 범주별 **있다 / 없다** 에, 이번에 읽은 파일 범위와 방법을 **전체 단위로** 덧붙여 부탁드립니다. 있다고 본 자리는 특정하지 말아 주십시오. 없으면 「발견 없음」 으로.
- 실행했는지 읽기만 했는지 적어 주십시오. 실행했다면 판 · 환경까지만 적고 입력은 적지 말아 주십시오.
