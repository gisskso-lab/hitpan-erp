## HQA ARGOS — #6902200730 / #6896955850 질의 회신 (설계 검토 의견, 합격 판정 아님)

기준: 대표가 확정한 GitHub Linux 호스트 러너 실측·개발팀 장치·HQA 원자료/장치 원문 대조 구조, 11/13 §6 고정 기대값. **이 댓글은 기대값 변경 결재가 아니며 관문 ① 합격 판정도 아닙니다.**

### 선행 Q-A / Q-B
- **Q-A:** 과거 HQA가 쓴 `S1~S4`는 정본에 없는 비공식 묶음 명칭입니다. 이를 4개 항목으로 축소 해석하지 마십시오. **11/7·11/13 정본의 전체 항목과 N-1·N-2가 유일한 범위**입니다. 장치의 I-1~I-6 및 N-1·N-2를 정본 원문 항목·§6 기대값에 1:1 매핑한 표를 발행 전 제출하십시오. 매핑되지 않는 칸은 합격 처리 불가.
- **Q-B:** GitHub Actions 로그·artifact 익명 접근 401/403이 확인되었으므로, 공개 가능한 **SHA 고정 raw 링크**를 기본 전달 경로로 수용합니다. JSON/CSV 원자료와 판독 규칙·환경·실행 식별 메타데이터, 필요 시 PNG를 함께 두고 파일별 SHA-256·누락/제외 표본 수·전체 분모를 기록하십시오. 공개 저장소에 비밀·실사용자 데이터·개인 PC 경로·민감 오류 원문을 올리지 마십시오. 가림 때문에 판정 필수 칸을 읽을 수 없다면 그 회차는 판정 불가/미통과로 기록하십시오.

### Q1~Q4
- **Q1:** V0 M6/M7은 I-1/I-2 `/before` 기대값의 **후보 근거**로 인정합니다. 단, I-1/I-2의 정확한 자극·대상·기대가 M6/M7과 동일하다는 1:1 대응표와 정본 인용을 먼저 제시하십시오. 일치가 확인되기 전에는 자동 채택/기대값 변경 불가.
- **Q2:** `/before` 키보드 접근 불가가 원래 결함 D1의 **재현**인 것은 관찰 사실로 기록할 수 있습니다. 그러나 해당 자극을 실행할 수 없어 후속 동작 비교가 성립하지 않는 I-4/I-5/I-6 칸은 **대조 무효**로 별도 표시하십시오. **미측정**은 실제 시도·원자료 자체가 없는 경우에만 쓰십시오. 재현과 대조 무효를 같은 필드에 덮어쓰지 마십시오.
- **Q3:** `/after` 키보드 도달 0 표본을 유효 표본에서 제외하고, 사전 고정 최소 표본 수가 부족하면 **장치 실패/측정 불충분(합격 불가)** 로 처리하는 보수적 규칙에 이견 없습니다. 단 원시 분모·제외 건수·제외 이유를 보존하고, 제외 표본이 실제 제품 결함을 은폐하지 않는지 별도 판독하십시오.
- **Q4-ⓐ:** 대조 무효 항목을 **제외하고 전체 합격으로 선언하는 것은 불가**합니다. 필수 대조가 성립하지 않으면 그 항목 미판정, 관문 ① 전체는 **미통과(검증 불충분)** 로 유지합니다. 단 정본이 명시적으로 독립 판정 가능한 항목은 개별 결과를 보존합니다.
- **Q4-ⓑ:** A2(`2a6a0ee1`)는 N-1에 한정한 **조건부 대조판 후보**로 수용합니다. 다만 기능 HEAD/시험 앱과 A2의 출처·blob·실행 조건 동등성, 기존 `/before` 결과 및 N-1 기대값을 모두 사전 공개하고 **대표의 조건부 결재 범위를 넘지 않을 것**. A2가 서지 않으면 원래 결재 경로(대조 무효)로 돌아가며 임의 대체 금지. **A2 사용 승인 ≠ N-1 합격.**
- **Q4-ⓒ:** 리허설 2에서 이미 공개된 지연 0 칸은 사후 노출 사실을 명시하고 **사전 고정된 기준대로 원자료를 남기되, 독립적인 미노출 재현 증거 없이 그 칸만으로 합격을 확정하지 마십시오.** 표본·기대값을 노출 결과에 맞춰 조정해서는 안 됩니다. 노출로 인한 독립성 제약을 최종 판정에 명시하고, 보완이 필요한 경우 변경안과 근거를 대표에게 별도 결재 요청하십시오.

**장전 전 요구:** 정본↔I/N 대응표, 대조판/표본 분모/실패·대조 무효 처리 규칙, A2 SHA/동등성 근거, 노출된 칸 목록과 독립성 대책을 **첫 장전 실행 전에** 고정해 제시하십시오. HQA가 장치를 직접 실행한 사실은 없으며, 최초 장전 1회 원자료가 공개되기 전 관문 ① 판정은 미통과(검증 미완료)입니다.
