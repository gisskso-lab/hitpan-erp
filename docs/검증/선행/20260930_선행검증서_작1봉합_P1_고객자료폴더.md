## 🔴 사장님 결재가 필요한 것 (PM 이 정하지 않는다)
- **F-2(P4~P8) 를 어디서 고치나** — ① 작1 봉합 차수에 넣는다(첨부 폴더를 데이터 폴더로 옮김 + 기존 파일 옮겨 싣기 · 자동 업데이트·되돌리기 둘 다 해결) ② 별건 트랙으로 뗀다(작1 은 되돌리기에서만 첨부 폴더를 옮겨 싣고 넘어감)
- ✅ **결재(사장님 9/30 22:2x) = ② 별건 트랙** — 저장 위치를 데이터 폴더로 옮기는 일은 별건 트랙([1-V] 부터). **작1 은 되돌리기에서 첨부 폴더를 옮겨 실어 지우지 않는 것만** 한다.
- **실물 확인 1회** — 사장님 PC 에서 관리자 권한으로 `C:\Program Files\HitPan\api\chat-files` 가 있는지 · 파일이 몇 개인지(오늘 업데이트 뒤 비었는지). 읽기만.

## 설계로 넘기는 사실목록 (작1 안 · 결재 무관)
- F-1: 원위치 실패에서도 `Start-All`(keepalive·Guardian·워치독 다시 켜기)이 **반드시** 돈다 — 게이트 주입점은 `Invoke-Revert` 예외(기존 broken 게이트는 `Start-All` 뒤라 못 잡음 · 리뷰서 F-1).
- 05: 재료 ② 채택 조건에 「바로 앞 판 증거」 — 증거 없으면 `no_previous_version`.
- 06: 조기 종료·미기동에도 `HitPan-LocalSwap` 작업이 정리되거나, 묵은 작업을 바쁨에서 빼는 만료가 있다.
- P2(07·08·F-3 등)는 설계가 이번 차수 포함 여부를 제안 → PM 결재.
- 불변: `installer/**` · `src/HitPan.Watchdog/**` · 작3 자동 경로 무변경(작1 작업지시서 §9·§6).
