## 1. ① 이웃 프로브 — 누구를 막는가

**방법**: 세션 A 가 L5(`LOCK IN SHARE MODE` · 거래처 `1f8dad70…` 793건)를 **25초 쥔 채로**,
세션 B 가 `innodb_lock_wait_timeout=3` 으로 등록을 시도한다. 1205(Lock wait timeout)면 **막힘**.
세션 A 가 실제로 쥔 잠금 = **`trx_rows_locked` 3,124** (T1-2 값과 일치 · 값 3,666,200.00).

| # | 시도한 등록 | 결과 |
|---|---|---|
| **B1** | **같은 거래처(PA)** 매입반품 INSERT | 🔴 **막힘** |
| **B2** | **다른 거래처(PB)** 매입반품 INSERT | 🔴 **막힘** |
| **B3** | **다른 거래처(PB)** 매입반품을 `status='confirmed'` 로 INSERT | 🔴 **막힘** |
| **B4** | **무관한 표** `payments` INSERT | 🟢 통과 |

### 1-1. 음성 대조군 (함정 §5-2 — 차이가 나올 수 없는 실험을 하지 않았다는 증거)

**보유 세션 없이** B2 와 같은 INSERT 를 **2회** 시도 → **2/2 🟢 통과.**
⇒ B1~B3 의 막힘은 **L5 보유 때문**이다. 표 자체나 제약(`return_no` 유니크 등) 때문이 아니다.
**B4 통과**가 「전부 막히는 시험이 아니다」를 함께 보인다 — 양성·음성 양쪽이 다 있다.

### 1-2. 🔴 무엇을 뜻하는가

- L5 의 구동표는 `rt`(`purchase_returns`) **`ALL` / key NULL / rows 997** 이다(T1-2 §5-3: **술어가 없어 구조적**).
- 전체 스캔 + RR 넥스트키 ⇒ **`purchase_returns` 의 인덱스 구간 전체 + 간극**을 잠근다.
- ⇒ **지급 등록 한 건이 도는 동안, 그 회사의 매입반품 등록이 거래처와 무관하게 전부 막힌다.**
- 이것은 **워크플로우가 끊기는 모양(#20)** 이다. 「잠금 행 수가 3,124」보다 이 문장이 실제 피해를 말한다.

⚠️ **다만 막힘 지속시간은 안 쟀다** — 실제 등록 경로에서 L5 가 얼마나 오래 잠금을 쥐는지는 별개 측정이다. 여기서는 **인위적으로 25초 쥐었다.**

## 2. ② 안전 후보 `rt.receipt_id IS NOT NULL` — **이득 0**

`t1_ret` 실측: `purchase_returns.receipt_id IS NOT NULL` = **998 / 998 = 100%**.

| | 값 | **trx_rows_locked** | EXPLAIN (`rt`) |
|---|---|---|---|
| 기준선 | 3,666,200.00 | **3,124** | `ALL` / NULL / 997 |
| **+ `rt.receipt_id IS NOT NULL`** | 3,666,200.00 | **3,124** | `ALL` / NULL / 997 |

🔴 **완전히 동일하다.** 계획도 잠금도 한 칸도 안 움직인다.
**이유**: 그 칸이 **전부 채워져 있어** `IS NOT NULL` 이 아무 행도 걸러내지 않는다 — 옵티마이저에게 **정보가 되지 않는다.**

### 2-1. 🔴 L2·L4 와 정확히 **거울상**이다

| 문장 | 대상 칸 | NULL 비율 | ㉪ 계열이 듣는가 |
|---|---|---|---|
| **L2** | `collections.ref_doc_id` | **100% NULL** | 0~1% 에서만 (그 뒤 역효과 — 처방민감도 문서 §4) |
| **L4** | `payments.ref_order_id` | **100% NULL** | 🟢 듣는다 (무해) |
| **L5** | `purchase_returns.receipt_id` | **0% NULL** | 🔴 **못 듣는다 — 원리적으로** |

⇒ **㉪ 계열 처방(「`IS NOT NULL` 한 줄」)은 「그 칸이 대부분 NULL 이다」는 데이터 사실에 얹혀 있다.**
L5 는 그 사실이 성립하지 않으므로 **같은 모양의 처방을 아예 시도할 수 없다.**
T1-2 §5-3 이 「`rt` 를 좁힐 술어 자체가 없다」고 적은 것과 같은 결론에 **다른 길로 도달했다.**

## 4. 내가 **못 잰 것** (정직하게)

1. **실제 등록 경로에서 L5 가 잠금을 쥐는 시간** — 25초는 **내가 인위적으로 만든 것**이다. 현장 체감 피해 크기는 이 값으로 말할 수 없다.
2. **반품 외의 등록** — `purchase_receipts`·`sales_deliveries`·`collections` INSERT 는 안 해 봤다. B4(`payments`)만 음성으로 확인했다.
3. **다른 회사 축** — 한 DB 한 회사(§3 결정)이므로 안 했다. 시험 DB 에 회사가 하나뿐이기도 하다.
4. **규모 민감도** — 998건에서만 쟀다. T1-2 는 98건에서 1,292, 998건에서 3,124 로 **선형**임을 보였으나 **막힘 여부가 규모에 따라 달라지는지는 안 쟀다**(구동표가 `ALL` 인 한 달라질 이유는 없어 보이나 **추론이다**).
5. **다른 후보 처방** — ② 하나만 쟀다. 대안(예: 구동표를 `pr` 로 고정)은 T1-4 가 **잠금이 늘어난다**(3,124 → 3,295)고 이미 실측했다.
