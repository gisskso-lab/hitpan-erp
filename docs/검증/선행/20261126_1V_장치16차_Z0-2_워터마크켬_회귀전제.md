## §1 물음 1 — §84 글자
- §84 :877 원문(결과 칸): 「**H-C0 확정 — 그때 안 나온 것 = 정답 동작** … ⇒ **C = 결함 0 · C 닫음** · 장치 15차 Z15-3 칸 짓기 0 … · **WM-가-on 은 회귀 칸 그대로**」.
- §84 글자만으로는 「main 기대 = 초록」 이라는 낱말이 없다. 「회귀 칸」 의 뜻은 CTO 판정 §1-4 표 :41 이 정했다: `WM-가-on | 고친 판 기대 ⓐⓑⓒ | main 기대 = 같으면 「회귀 칸(무변)」 | ① 고침 근거로 안 셈`. 검증팀장 가름 `docs/검증/20261120_WG1-51_갈래C_워터마크원인_가름_검증팀장.md` :127 도 「WM-가-on 은 회귀 칸 그대로(CTO §1-4)」 로 같은 표를 가리킨다.
- 같은 표 :42 의 「WM-가-대표조건」 줄만이 「main 빨강 기대 · main 초록이면 C 멈춤」 이었다. §84 「Z15-3 칸 짓기 0」 으로 이 줄은 지어지지 않았다 → main 초록을 멈춤으로 보던 유일한 근거가 닫힘.
