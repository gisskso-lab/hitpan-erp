## C. 덤으로 본 것 (설계 참고)
- TruffleHog 액션이 `@main`(움직이는 판)이다. 비밀 검사 도구가 공급망 쪽 구멍이 될 수 있다 — 판 고정 권고.
- UI Browser 워크플로 「건너뜀」 10회의 원인은 이번에 안 봤다(필수 판단에는 영향 적음).
- 이 PC 이력 검색은 `.doc` 변환기 설정 때문에 `git log -G/-S` 가 조용히 멈춘다 — 이력 기반 게이트·조사 때 `--no-textconv` 필수.
