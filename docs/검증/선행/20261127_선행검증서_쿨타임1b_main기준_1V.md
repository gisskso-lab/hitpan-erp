## 4. 그대로 유효한 것 (재확인)

- C-1~C-5 · 15초 주기 결정(설계 §9-1) — 결정 기록 남아 있음. C-2 는 사장님 재확인 끝.
- 마이그 번호 DB-132~134 — 비어 있고 예약 흔적 있음 · 번호 빈칸 적용 가능(§2-3 MigrationRunner). 단 [3] 착수 때 다른 가지가 그 번호를 쓰는지 다시 확인(지시서 §4 「번호 겹침 사전 확인」 그대로).

## 5. 오늘 겪은 일(§255)과의 관계 — 기대 범위 적어 둠

- 쿨타임은 **회사가 켠 경우(기본 꺼짐 · Q4)**, **설정 시각에** 남은 PC 세션을 푼다. 오늘처럼 낮에 자동 로그인 도구가 세션을 안 놓은 경우는 **설정 시각이 올 때까지** 잠김이 남는다 — 쿨타임이 그 사고를 즉시 풀지는 않는다.
- 즉시 풀기(관리자가 남의 PC 세션을 끊는 화면 등)는 9/28 지시서 「하지 않는 것」 의 등록기기관리(작3) 쪽이며 이번 범위 밖. 범위를 넓히려면 대표 결재 필요(#33). 여기서는 사실만 적는다.

## 6. 미확인

- `SessionAccessTrail.WriteAsync` 를 반사(reflection)로 부르는 게이트가 있는지 — D-4 (가) 를 고르면 [2] 에서 grep.
- 작3(등록기기관리)이 `user_sessions` 를 `SELECT *` 로 읽는지(설계 §10 마지막 줄) — 이번에 안 잼.
