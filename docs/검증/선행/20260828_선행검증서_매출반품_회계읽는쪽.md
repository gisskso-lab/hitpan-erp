## 2. 실측 — 무엇을 직접 봤나

### 2-1. 매출반품 확정은 분개를 만든다 🟢

`SalesService.cs:2487` — 반품 확정 트랜잭션 안에서 기표한다.

```
// 5) 회계 역분개 — 매출취소 역분개 재사용 (차변 매출+부가세예수금 / 대변 외상매출금)
await AutoJournalHelper.RecordSalesDeliveryCancelAsync(...)
```

**분개는 실제로 쌓인다.** 인계6 의 정정은 이 부분에서 옳았다.

### 2-2. 🔴 그런데 «자기 이름표»가 없다 — 진짜 원인

`AutoJournalHelper.cs` 가 쓰는 `source_type` 키 전수:

| 매입 | 매출 |
|---|---|
| `purchase_return` | 🔴 **없음** |
| `purchase_return_cancel` | `sales_return_cancel` |

**매입은 「반품」 키가 있는데, 매출은 「반품취소」 키만 있고 「반품」 키가 없다.**

매출반품 확정은 자기 키를 안 쓰고 **`sales_delivery_cancel`(명세서 취소) 키를 빌려 쓴다.**
즉 장부에 **매출반품이 「명세서 취소」로 적힌다.** 반품인지 취소인지 구분이 안 된다.

### 2-3. 그래서 읽는 쪽이 못 센다

`FinanceService.cs` (정합성 검사·회계 집계) 실측:

| 낱말 | 건수 |
|---|---|
| `purchase_return` | **17** |
| `sales_return` | 🔴 **0** |
| `sales_delivery_cancel` | 🔴 **0** |

`FinanceService.cs:644` — 「확정전표 기표 누락」 검사:

```
+ (SELECT COUNT(*) FROM purchase_returns r
    WHERE r.status='confirmed' ... AND NOT EXISTS (
      SELECT 1 FROM journal_entries j WHERE j.source_type='purchase_return' ...))
```

**매입반품만 검사한다. 매출반품(`sales_returns`)은 아예 안 본다.**

🔴 **어제(8/27) 내가 만든 정합성 검사 화면이 이 사각을 그대로 물려받았다.**
매입은 양쪽을 다 보는데 매출반품은 검사 항목 자체가 없다.

## 3. 🔴 내가 두 번 틀렸다 — 기록

| 회차 | 내가 쓴 것 | 실제 |
|---|---|---|
| 인계5 | *"매출반품이 회계에 아예 없다"* | ❌ 틀림 — 분개는 만든다 |
| 인계6 | *"구멍은 읽는 쪽이다"* | 🟡 절반 — **쓰는 쪽 키가 원인**, 읽는 쪽은 결과 |

**공통 원인**: 두 번 다 **낱말을 세어서 판단**했다.
「회계 서비스에 참조 0회」 → 인계5 는 *"안 만든다"*, 인계6 은 *"못 읽는다"* 로 읽었다.
**둘 다 코드를 안 읽고 숫자만 봤다.** 낱말이 0인 진짜 이유는 **이름을 빌려 썼기 때문**이었다.

⇒ 헌법 #32(점수·숫자 받아쓰기 금지) 위반. **낱말 세기는 단서지 근거가 아니다.**

---

## 4. 부가세 결론은 살아있나

🟢 **살아있다. 다만 이유가 다르다.**

- 분개 자체는 역분개로 들어가므로 **`journal_lines` 원장 수준에서는 부가세예수금이 차감된다**
- 🔴 그러나 **반품으로 식별이 안 되므로**, 반품을 구분해 집계·신고하는 화면·리포트는 이걸 **명세서 취소로 센다**
- 🔴 그리고 **기표 누락 검사가 매출반품에 없으므로**, 기표가 실패해도 **아무도 못 잡는다** (매입은 잡힌다)

⇒ **과대계상 리스크는 유효**하되, 고칠 자리는 *"읽는 쪽에 매출반품을 더한다"* 가 아니라
**"쓰는 쪽에 `sales_return` 키를 세우고 읽는 쪽을 거기 맞춘다"** 이다.

### 🔴 [2] 설계 착수 전 사장님 결재가 필요한 이유

`sales_return` 키를 새로 세우면 **이미 쌓인 기존 분개**는 여전히 `sales_delivery_cancel` 로 남는다.
**과거 데이터를 어떻게 할지는 사업 판단**이라 PM 이 정할 수 없다 (헌법 #33).
