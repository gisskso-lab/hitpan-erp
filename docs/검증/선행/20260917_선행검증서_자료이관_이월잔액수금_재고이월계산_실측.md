### A-2. 「이월잔액 한 줄」 매칭 대상 — 기존 모양 vs DDL

- 수금: `ref_doc_type='legacy_balance'`(가칭) + `ref_doc_id` = 이월잔액 키 — **DDL 불필요**.
- 지급: `payments` 에 유형 칸이 없어 `ref_order_id` 에 이월잔액 키를 넣고 `partner_legacy_balances` JOIN 으로 가른다(UUID 충돌 사실상 0) — DDL 불필요하나 식이 암묵적. 명시 칸을 원하면 DDL.
- 🔴 **키 선택**: `balance_id` 는 덮어쓰기 재이관(삭제 후 재적재) 때 새 UUID → 사람이 넣은 수금이 고아가 된다. UPSERT(병합)는 유지. `partner_id` 를 키로 쓰면(거래처당 1행 UNIQUE) 재이관에도 안정 — 설계 판단.
- 화면 목록 표시: `CollectionPage.razor:122` 는 `sales_delivery` 가 아니면 **원문 값을 그대로 표시** → `legacy_balance` 영문 노출(고객 노출 개발용어 금지) → 라벨 필수.
- 번호: DB-123 main 미머지(`git show origin/main` 없음) → 같은 번호에 추가 가능. 이미 적용된 시험 DB 는 id skip → 재생성.

## B. R-C2 이월 계산 역검증 (공영정보 MDB · `PANDATA.mdb` DOCFC 52,664행 · DOCFB 124,152행 · `PYOJUN.mdb` DOCFS 309행)

### B-0. 표 구조 실측
- DOCFC 한 행 = 품목(품명·규격·창고)×달 요약. 달마다 **움직인 품목만** 행이 있다(202512 73행). 품목별 최종 = 그 품목의 MAX(IM_YM) 행(갈래 D 규칙과 같음).
- 수량: `C = B + I − O` 52,664 중 51,811 일치 · 어긋난 행은 `IM_ISQTY/IM_OSQTY`(특수입출 · 창고이동 `가산세1 00→02` · 2025-08 `거래명세서` 5품목 특수입고 149개) 와 P/L 줄.
- 금액: `C_AMT = CQTY × IM_DAN` 52,175행 일치 · `IM_DAN ≈ (B_AMT+I_AMT)/(B_QTY+I_QTY)` = **월 총평균**.
- DOCFB 202602 I/O 수량 = DOCFC 202602 74행 전부 일치(20260220 까지 포함).
- 🔴 P/L 줄: 키 (`''`,`P/L`,`00`) · 수량 0 · 금액 24,885,456(202511) → 23,096,686(202512) → 18,642,076(202601) → 0(202602). 상품 아님.
- DOCFB 에만 있고 DOCFC 에 한 번도 없는 키 203개(설명 줄 `- 배차일정표` 등) · 순수량≠0 은 8개 · 2025년 뒤 움직임 11개 전부 순수량 0.

### B-2. 금액 이월 규칙 — 재현하는 것
- **규칙 ③** : 달마다 `입고수량 = Σ IO1 수량(음수 포함)` · `입고금액 = Σ IO1 IJ_AMT` · `출고수량 = Σ IO2 수량(음수=반품이 출고를 줄임)` · 입고수량≠0 이고 (기초+입고)≠0 이면 `DAN=(기초금액+입고금액)/(기초수량+입고수량)` · 아니면 `DAN = 상품마스터 S_IDAN`(마스터 없으면 직전 DAN) · `기말금액 = ROUND(기말수량×DAN, 0)`.
- 이동평균(건별)·IM_DAN 고정(마지막 DAN × 수량 = 54,633,075 · 3키 차이)은 ③보다 못함. `LedgerMove` 의 「반품 = 입고칸 절대값」을 **금액**에 그대로 쓰면 틀린다(`전자결제용 충전` 반품 1개를 판매가 87,818 원 입고로 셈).
- ⚠️ `S_IDAN=0` 이면 `S_IDANB` 폴백을 넣어도 결과 같음(수수료는 움직임 없는 달이라 계산에 안 들어옴) — 폴백 규칙 미확정.

### B-3. 기준일 규칙 ↔ 미래 오타 배제(갈래 I) 충돌
- `LastValidLegacyDate`(`MdbLegacyFinalStock.cs:202-215`) 는 **이관일 뒤 날짜만** 뺀다 → 「마지막 유효 날짜 달 말일」은 이관일보다 뒤가 될 수 있다(이관 9/17 · 마지막 거래 9/10 → 기준일 9/30). 🔴 사장님 재결재 대상(카드).
- 이관일 **이전** 오타(2025 를 2026 으로)는 둘 다 못 가린다(갈래 I §5 한계와 같음) — 기준일도 따라 밀린다.
