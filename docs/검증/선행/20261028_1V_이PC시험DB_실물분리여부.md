## §1 사실
| 사실 | 근거 |
|---|---|
| 이 PC 의 DB 서버 2개 | 서비스 `MariaDB`(11.4 실행파일 · 설정 `C:/MariaDB/mariadb-10.0.17-win32/my.ini` · 포트 **3306**) · `MariaDBssk`(11.7 · `C:/Program Files/MariaDB 11.7/data/my.ini` · 포트 **3307**) — 둘 다 자동 시작·실행 중 |
| 실물 히트판이 쓰는 쪽 | `HitPan.API` 프로세스가 **3306 에 연결 4개**(실행 경로는 권한 밖이라 안 보임 = 다른 계정으로 도는 서비스로 보임 · `C:/Program Files/HitPan` 설치본) — ⚠️ `db.conf` 는 읽기 권한 없음(우회 안 함) ⇒ **추정** |
| 시험의 기본 접속 | DB 시험 클래스 다수가 `HITPAN_DB_HOST` 없으면 `localhost` · `HITPAN_DB_PORT` 없으면 **3306** · `HITPAN_TEST_DB` 없으면 `hitpan_e2e`(예: `src/HitPan.Tests/Integrity/AccountSeatGateSeal1Tests.cs:53-56` · `AutoChainPolicyGateTests.cs:232`) |
| 이 PC 환경변수 | `HITPAN_DB_HOST`·`HITPAN_DB_PORT`·`HITPAN_TEST_DB` **없음**(이름만 확인) |
| 3307 의 용도 | ⚠️ 미확인 — 이름(`ssk`)만으로 시험용이라 단정하지 않는다 |

## §2 판정
- 🔴 지금 상태로 이 PC 에서 DB 시험을 돌리면 **실물 히트판이 쓰는 3306 서버** 안에 시험 DB 를 만들고 지운다(클래스별 DB · `hitpan_e2e`). 업무 DB 를 직접 건드리지 않더라도 같은 서버의 자원·계정·잠금을 함께 쓴다 ⇒ #39 「운영 직접 수술 금지」의 위험 쪽.
- 오늘 이 창의 시험은 전부 DB 없는 시험만 골라 돌렸다(필터) — 3306 접속 0.
