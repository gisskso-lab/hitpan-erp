**[2] 가 먼저 정할 것 (C-1~C-4)**
- C-1 한도 값의 집 — `local_subscription.max_users` 를 「총 계정(대표 포함)」으로 쓸지 「자식 수」로 쓸지. 지금 기본 3 이라 **그대로 켜면 오늘부터 3 에서 막힌다.**
- C-2 「null 로 비워둔다」의 실체 — 지금은 email(아이디)이 남아 `UNIQUE(tenant_id,email)` 이 **같은 아이디 재등록을 막는다**(중복검사는 통과 → INSERT 에서 터짐 ⚠️미실측). 퇴사 경로(`EmployeeService:709`)는 email 에 `resigned+` 표식을 붙여 비우는데 계정관리 경로는 안 비운다.
- C-3 기기 한도를 이번에 어떻게 할지 — 놔두면 계정 한도와 기기 한도 **2중**(별건 결재 대상 · 범위 밖이면 적어만 둔다).
- C-4 셈 대상 — `is_deleted=0` 인가 `is_active=1` 인가. API `PUT /api/users/{id}` 로 `is_active=0,is_deleted=0` 상태가 만들어진다(화면엔 없음).
