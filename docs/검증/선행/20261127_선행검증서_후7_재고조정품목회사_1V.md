## 1. 결론 먼저

- 대장 문장 그대로 맞다: `StockService.AdjustStockAsync` 는 요청 `ItemId` 를 **검사 없이** `stock_ledger`(INSERT ONLY)와 `item_stock` 에 쓴다(§2-2).
- 회사 값은 JWT 에서만 온다(🟢 #2 지킴) — 문제는 회사 값이 아니라 **요청 id 의 소속**을 안 본다는 것.
- 대장에 없던 것: **창고 id 도 같은 꼴로 안 본다.** 이관 **도착** 창고는 「출발 재고 ≥ 수량」 간접 차단의 바깥이라 X1 이 닫혀도 열려 있다(§3 F-2).
- 순서 의존: 공용 검사 `ItemTenantGuard` 가 main 에 들어간 뒤(PR #1005 머지) 후7 을 붙이는 것이 자연스럽다. 창고용 공용 검사는 main · PR 어디에도 **없다** — 새로 만들지, 후7 안에서 한 줄 조회로 할지 [2] 가 정할 것(§5).
