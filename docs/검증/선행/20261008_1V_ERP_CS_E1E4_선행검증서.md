## ③ ⛔ 설계 전 사장님·PM 이 알아야 할 막힘

1. **「기존 큐 재사용」 전제가 성립하지 않는다**(❌). `cs_outbox` 는 종류 열 0(`DB-140_cs_outbox.sql:20-33`), 보낼 주소는 코드 1줄 고정(`CsOutboxSenderWorker.cs:129`), `UNIQUE uq_cs_outbox_req`(`:32`) 때문에 **같은 쪽지에 2번째 큐 행이 못 들어간다**. ⇒ E-1 은 「화면만 붙이면 되는 일」이 아니다.
2. **`ratings` 는 티켓이 본사에 없어도 200 을 준다**(`CsInboundController.cs:231-232`). 아직 전송 안 된 쪽지(화면 글자 「아직 본사에 안 갔음」)나 거부된 쪽지에 평가를 보내면 **조용히 사라진다**. 평가 가능 시점 제한은 결재가 필요한 자리.
3. **E-2 가 쓸 통로가 없다**(❌). ERP 가 본사에서 받아오는 것은 답 Pull 하나뿐이고, 수락 사실(`read_at`·`read_by`·`handler_id`)은 **ERP 로 나가는 길이 없다**. 화면의 「접수됨」은 **2xx 수신**이라 수락과 다른 사건이다.
4. **E-3·E-4 는 수신 문이 먼저 닫혀 있다**. `messages` data 화이트리스트 6개 고정(`CsInboundController.cs:67-81`)이라 7번째 키를 실으면 **쪽지 전체가 400 → `rejected` 종결**(`CsOutboxSenderWorker.cs:138-142`). ERP 만 고치면 쪽지가 오히려 **거부**된다.
5. **E-3 의 스레드 키는 양쪽 다 없다**. ERP `cs_requests` parent 열 0 · 백오피스 `rework_of_id` 는 축이 다르고 수신이 채우지 않으며 읽는 쿼리도 0건.
6. **E-1 왕복 실측은 지금 어디서도 불가**: 운영 500 + 접속 금지 / 로컬 `hitpan_erp` DB 없음 / 로컬 `bo_cs%` 표 없음 / 게이트는 `CREATE DATABASE` 권한 없어 SKIP. ⇒ **PR 의 `db-gate` 잡만 증거**다. 「개발 PC 에서 돌려 봤다」는 증거가 아니다.
7. **E-4 의 숨은 꼬리**: 대리점 CS 접근은 현재 0건이 맞지만 수신 시점에 `reseller_id` 가 티켓에 **이미 적혀 있다**(`CsInboundController.cs:115-121`) ⇒ 대리점 조회를 켜는 날 과거 쪽지까지 소급 노출.
8. **별건(이 오더 밖)**: `/reseller/v2/cs` 는 링크 0 · 백엔드 API 0 인 **죽은 화면**. 제거·복구 어느 쪽도 이 트랙에서 손대지 않는다 — 보고만 한다.

2. **운영 백오피스에 40·41·42 SQL 이 적용됐는지** — 운영 접속 금지로 확인 불가. 인계3 §3 의 500 보고를 **인용**한 것이고 내가 직접 재지 않았다.
3. **G-CS-1~7 게이트의 현재 통과 여부** — 로컬 SKIP 구조라 돌리지 않았다. CI `db-gate` 결과 미확인.
4. **`License:Pepper` 운영 설정값 존재 여부** — `CsInboundController.cs:286` 에서 미설정 시 예외로 터지는 구조인데 운영 설정 확인 불가.
5. **ERP `TENANT_CODE`·`LICENSE_KEY`(TenantConfigReader)가 실물 고객 PC 에서 채워져 있는지** — 비면 3중 일치가 401. 읽지 못했다.
6. **S-2 부모계정 첫 보고(`owner-report`)가 실물에서 성공했는지** — 실패 상태면 `ratings` 도 `owner_not_registered` 401(`CsInboundController.cs:296-301`). 미확인.
7. **백오피스 `tenants` 에 실물 테넌트 행·`license_key_hash`·`owner_account_id` 가 채워졌는지** — 운영 DB 미열람.
