## §3 적발 A 상세 — 옛 가지 push = 옛 래퍼

1. push 사건은 **push 된 커밋 안의** 워크플로 파일을 돌린다. #859 앞에서 갈라진 가지는 옛 `trufflehog.yml`(래퍼 `@main` · 판 고정 없음 · `--github-actions` 주석 꼴)을 그대로 쓴다.
2. 옛 래퍼는 찾은 후보마다 **파일 경로 · 줄 번호**를 단 경고 주석을 남긴다. 저장소가 공개라 누구나 읽는다.
3. 후보 값 자체는 이미 공개 저장소 파일 안에 있다 — 주석은 **값을 새로 내보내지는 않지만 「어디를 보면 되는지」 색인**을 공개한다. 그중 진탐(갈래 ㄴ 기준선 대상)이 섞여 있으면 찾는 비용이 0 이 된다.
4. 판 고정 없는 `@main` 을 돌리는 것도 #859 가 막으려던 공급망 위험 그대로다.
5. **S4 일정과 맞물린다**: 장치 가지 · 공개 검토 가지 · 시험 앱 가지 모두 #859 앞 바닥. 인계19 §9-4 의 「장치 가지 push → 리허설 6」 이 그대로면 같은 주석이 또 생긴다.
