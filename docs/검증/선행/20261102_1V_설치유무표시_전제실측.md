## §0. 판정

⚠️ **조건부 — 백오피스만으로 고칠 수 있다. 단 투입 카드 1순위 후보(`installer-bootstrap`)를 「설치 완료」로 쓰면 거짓 완료가 된다.**

- 🟢 전제 유효: 화면이 설치 성공에도 「미설치」로 나온다. 쓰는 코드 0곳 재확인(§1).

- ⚠️ 어떤 재료로도 **삭제(언인스톨)는 못 잡는다**(§2-3 S7). 이건 ERP·설치 변경 없이는 못 고친다.

3. 양성 — `owner_collected_at` 만 있는 고객 = 완료 · `update_state` 만 있는 고객 = 완료.
4. N행 — 같은 `tenant_id` 2행(`update_state`) · 복구 다행(`attempts`)에서 목록 행 수 불변.
5. 재료 전무 + `IsLocked=1` 옛 값 고객의 표시(§8 안건 결과대로).

## §8. 결재가 필요한 것 (PM → 대표)
