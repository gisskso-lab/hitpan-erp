## §1. 깨질 수 있는 자리 → 설계 반영

- **훅 반영 시점** — 설정의 훅은 세션 시작 때 읽히는 것으로 본다 → P2 · P3 실동작 확인은 **새 창**에서 한다. 이 세션에서는 표준입력 모의 시험으로 동작을 잰다.
- **1시간 캐시** — `experimental.cacheTtl: 1h` 는 쓰기 단가가 높다 → hp-verifier · hp-judge 에만 준다.
- **INDEX 한 줄 200바이트** — 한글 파일명 주소만으로 넘는다 → 규격을 *"설명 60자 이내"* 로 고쳤다 (매뉴얼 §3-1).
- **워크스페이스 신뢰** — 프로젝트 설정 훅은 신뢰 여부에 좌우될 수 있다 → 훅은 **사용자 설정**에 건다.
