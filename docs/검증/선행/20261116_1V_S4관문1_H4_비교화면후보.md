## §2 질문 2 — A2 가 I-4 Esc 실패를 낼 근거 · 「4줄」 의 뜻

1. **A2 = Esc 고침 뒤 판.** 시험 앱 A2 blob `49d7502d` = `2a6a0ee1` 의 결과물. A2 커밋 자체가 Esc 고침이다: `git diff 5c17aa78 2a6a0ee1` = `if (e.Key != "Escape" || _menu is null) return;` → `… || !_open) return;`(A2 L149) · 옛 줄 주석 「닫힌 때도 아래 CloseAllMenusAsync 를 불러 단추 초점이 1 왕복 늦게 와 Tab 으로 옮긴 초점을 되끌었다」. 시험 앱 A2 `_Imports.razor` 도 「고침 직전 중간판」 = **F14 직전**이라는 뜻.
2. **작업지시서 초안 §12 P3 의 오독.** P3 「A2 ↔ After 차이 = 1파일 +4/-1(Esc 닫힘 조건) → A2 몫 = Esc 계열(I-4)」 의 출처 `git show 2a6a0ee1 --stat`(+4/-1)는 **A2 ↔ 그 부모 `5c17aa78`** 의 차이다. A2 ↔ After 가 아니다.
3. **실제 A2 ↔ After** = razor **+32/−4**(`git diff --stat` 시험 앱 A2 · After) + After 전용 `CsStatusMenu.cs`. 지워진 4줄 = `</MudMenu>` 1 + `await _menu.CloseAllMenusAsync();` 3곳(Esc A2 L156 · 다시 누름 L179 · Tab L187) → After L164 · L189 · L199 `CloseAllMenusLoggedAsync` 로 감쌈. 감쌈이 잡는 것 = `JSDisconnectedException` · `OperationCanceledException` 둘뿐(After L212) = **회로 끊김 · JS 시한 때만 다름**. 여는 태그 `MudMenu` → `CsStatusMenu`(그린 뒤 초점 JSException · ↑↓ 키 JSException 기록 = N-1 몫).
4. 결론: **살아 있는 회로 · HQA I-4 조건에서 A2 의 Esc 길 = After 의 Esc 길(코드 글자상).** A2 가 I-4 Esc 실패를 낼 원문 근거 = **없음**. 늦은 첫 항목 초점이 Esc 뒤 나가는 길도 A2 주석(9.3 L510 Clear → L1023 Count > 0 차단 · 11/8 근본원인 L76)상 막힘. → 대표 결정 ⓐ 의 「A2 를 I-4 비교에도」 는 **대조 무효가 거의 확실(정적 · 강함 · 미측정)**. 「못 서면 대조 무효」 되돌림이 미리 적혀 있어 결과는 안전하나, 결정 근거 문장 P3 은 정정해야 한다(설계 · PM 몫).
