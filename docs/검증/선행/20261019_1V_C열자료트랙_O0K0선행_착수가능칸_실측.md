## §1 🔴 실측 1 — O1·K1 12칸은 **한 칸도** 지금 못 쓴다

일정표 자신이 각 칸에 「🔴 기다리는 것」을 적어 두었다. 그 칸을 그대로 옮긴다 (추정 0).

| 칸 | 기다리는 것 | 지금 상태 |
|---|---|---|
| O1-1 설치 안내서 | 개발 **1-2**(백지설치 실측) | 🔴 합격선이 **「실측 소요시간 기재」** — 실측 전 기재는 **O-4·#32 위반** |
| O1-2 7일 가이드 | **K1-2 캡처** | 🔴 캡처 = 결재 4(가상데이터 테넌트) + 기계 |
| O1-3 CS 1차 응답 대본 | 개발 **1-3**(CS 왕복) | 🔴 **절 ③ 결재 대기**(인계2 §9) |
| O1-4 장애 안내문 확정 | 화면 문구 | 🔴 §2 — 5종 중 **2종만** 화면 문구 실재 · 초안(O0-6)도 미착수 |
| O1-5 "안 내면" 안내 | **결재 6·7** | 🔴 일정표 조건 1 = *"결재 전에 쓰지 않는다"* |

| K1-1 시연 시나리오 | 개발 **1-5**(시연 테넌트) | 🔴 미완 |
| K1-2 화면 캡처 | 결재 4 · 개발 0-7·1-5 | 🔴 **K·O 두 트랙 공동 목**(K 트랙 반-1) |

즉 **O0·K0 를 건너뛰면 O1·K1 은 영영 열리지 않는다.**

## 🟢 실측 2 — 지금 가능한 칸 = O0·K0 **12칸** (의존 0 · 코드 0줄)

두 일정표가 각각 *"산출물 6건. 전부 글. 코드 0줄."* 이라고 적은 칸이다.

기한은 **10/14(수)~10/17(토)** — **이미 지났고 증거 칸이 전부 비어 있다.**

## §2 🔴 실측 3 — 장애 안내문 5종: **화면 문구가 있는 것은 2종뿐**

O0-6·O1-4 의 합격선은 **「화면 문구와 같은 말」**이다. 그 화면 문구를 전수로 찾았다.

| 종류 | 화면 문구 | 실측 |
|---|---|---|
| 업데이트 중 | 🟢 **실재** | `UpdateProgressOverlay.razor:39` *"히트판 업데이트 중"* · `:32` *"히트판은 계속 업데이트를 진행하고 있습니다."* |
| 통신 끊김 | 🟢 **실재** | `CommsRecoveryBanner.razor:17` *"서버 통신이 불안정합니다."* |
| 디스크 부족 | 🔴 **0건** | `src/**/*.razor` 전역 「디스크」 **0 hit**. 걸린 것은 `.cs` **주석뿐**(`CsRequestController.cs:93-94` 등) ⇒ **고객 화면에 이 안내가 없다** |
| 백업 실패 | ⚠️ **있으나 부적격** | `BackupPage.razor:203` `"백업 실패: {result.Error}"` — 🔴 **내부 오류 문자열을 고객 화면에 그대로 흘린다**(O-2 · #23 소지) |
| 점검 | 🔴 **ERP 0건** | 걸린 것은 랜딩 `PaymentPage.razor:55` *"결제 시스템 점검 중입니다…"* 하나 — **ERP 화면에는 없다** |

🔴 **그래서 합격선이 지금은 못 닫힌다.** 2종은 화면 문구를 그대로 받아쓰면 되지만,
**3종은 글이 먼저 생기고 화면이 그 글을 따라와야 한다 = 코드 변경 = C열 밖**(결재 필요).
⇒ **처분**: O0-6 초안은 **5종 전부 쓰되**, 3종에 **「화면 문구 없음 — 신설 결재 필요」**를 글자로 박아 둔다.
**O1-4(확정)은 그 결재 뒤에만.** 지금 「확정」으로 올리면 **화면에 없는 말을 고객 안내서가 약속**한다.

## §3 🔴 실측 4 — K0-6 가격표: **숫자 두 판이 충돌한다**

| 출처 | 값 |
|---|---|
| 레포 `scripts/pricing_plans_seed.sql:54` | **29,000** (월) / `:62` **100,000** |
| 10/6 결재 요금(인계·기억) | 5유저 **29,000** / 10유저 **59,000** / 추가 **10,000** |

🔴 **10유저 값이 100,000 과 59,000 으로 갈린다.** 어느 쪽이 정본인지 **문서로 확인되지 않는다.**
⇒ #32 · K-3(측정 안 한 숫자 금지)에 따라 **PM 이 고르지 않는다. 사장님 확인 1줄이 필요하다.**
🟢 `pricing_plans_seed.sql` 은 **결재 전 실행 금지** 파일 — **읽기만 했다**(실행 0).
