### 1-1. 🔴 [3-V] 가 못 본 조건 — 정식 도메인 301 (가설을 좁히지만 닫지는 않음)

- `installer/web-server.ps1:66-86`(판정 `:75-85`) — `PRIMARY_DOMAIN` 이 db.conf 에 있으면(`HitPan-Universal.iss:2038 · 2467` 이 씀) **프록시보다 먼저** 「Host 가 루프백도 정식 도메인도 아니면 301 → `https://{정식도메인}`」.
- 그래서 [3-V] 가 적은 그대로의 꼴 `http://메인PC주소:5234/api/...` 는 **정식 설치본에서는 301 로 튕김**(브라우저는 터널로 다시 가서 CF 머리글이 붙음 → 막힘). **이 문장 그대로는 반증.**
- 그러나 Host 는 보내는 쪽이 정한다. `HttpListener` 의 `+` 접두는 Host 를 가리지 않고, `Url.Host` 는 요청 Host 머리글에서 나옴 → `curl -H "Host: localhost" http://메인PC주소:5234/api/...` 또는 `Host: {정식도메인}` 이면 301 을 건너 프록시로 감. **도구 하나면 우회 = 가설 본체는 살아 있음(코드상).**
- `PRIMARY_DOMAIN` 이 빈 설치(LOCAL 모드 · 도메인 없음)는 301 자체가 없음 → 평범한 브라우저로도 뚫림(코드상).
- 직원 PC 가 자기 PC 관리자라면 hosts 파일(정식도메인 → 메인PC 주소) · 포트 중계로 브라우저째 우회 가능 — 미확인(실측 대상 아님 · 기록만).

| S8 Host 2 | B → `A:5234` + `Host: {정식도메인}` | S5 요청 | `true` | 정식 도메인 Host 로도 우회되는가 |

### 3-3. 판정 규칙

- S1 · S2 대조군이 기대와 다르면 **측정 전체 무효** — 결과를 가설 판정에 안 씀.
- 가설 확인 = S5 true **그리고** S6 200 **그리고** S6 대조 403.
- 응답 코드만 보지 말고 본문(`error: main_pc_only` 유무)까지 적음 — 400(본문 검증) · 401(토큰) 은 「필터 통과 여부 판정 불가」 로 따로 셈.
- 「재현 안 됨」 은 S4 · S5 · S8 셋 다 시도한 뒤에만 쓸 수 있음.

### 3-4. 되돌림

- S1 ~ S8: 상태 변경 0(읽기 · 로그아웃) — 되돌릴 것 없음.
- S9 · S10: 위 표의 되돌림 · 끝나면 A 의 시험 설치본은 대표 결재로 제거 또는 보존(시험 PC 라 고객 영향 0).
