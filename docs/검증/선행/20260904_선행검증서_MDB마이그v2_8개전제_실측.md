### 3-5. *"ERP에는 있고 레거시에 없는 기능은 NULL"* — 🟡 대체로 맞음 · 예외 1건은 정면 충돌
- nullable → NULL ✅ (`default_warehouse_id` · `category_id` · `supplier_default_id` …)
- NOT NULL DEFAULT → 기본값(`purchase_price 0` 등 — DDL 상 NULL 불가)
- 🔴 **창고**: 이관 전용창고 `wh-migration` 을 만들어 전 원장에 박는다(:824). 9/4 사장님 정의 *"미지정 = MAIN"* · *"메인창고 하나 = 미사용과 같다"* 와 **충돌** — 이관 재고는 「이관창고」, 신규 거래는 MAIN ⇒ 재고가 두 창고로 갈린다(Q9).

### 3-6. *"옵션 2개 — 1 덮어쓰기 · 2 병합"* — 🔴 현행 1개(사실상 병합)
- 현행 = source_id UPSERT/IGNORE. 단 마스터(업체·상품·사원)는 `ON DUPLICATE KEY UPDATE` 로 **레거시가 ERP 값을 덮는다**(:894, :1065, :1307) ⇒ ERP 에서 고친 단가가 재이관 때 되돌아간다.
- 🟢 덮어쓰기 기반 **실재**: `DataResetService`(6/23 사장님 결재 화이트리스트 — 회사정보·계정·약관·라이선스·로그 보존 · 백업 선행 · 비번 확인 · tenant 범위 DELETE) + `DataResetPage.razor`. **덮어쓰기 = 초기화 → 이관** 한 흐름으로 잇는다.

### 3-7. *"편리 — 경로 붙여넣기 · 직접 찾기"* — 🟡 절반
- 있음: 경로 텍스트(기본 `C:\HITWIN`) · 비번 · 미리보기(총 건수) · 시작 · SignalR 진행카드 16 · 10/30/60분 Y/n
- 없음: **찾아보기**. 🔴 구조 제약 — 브라우저(WASM)는 PC 경로를 못 읽는다. 길은 둘: ① API 가 고객 PC 의 드라이브·폴더를 나열하는 **서버측 탐색기**(MDB 3개 있는 폴더 자동 표시) ② **브라우저 업로드**(다른 PC 에서 터널로 접속 시 유일한 길 · 300MB+)
- 미리보기가 "총 N건"뿐 — 표별·기간·마지막 사용일·**대사 예고** 없음

### 3-8. *"BOM = 레거시 셋트조립"* — 🟢 이미 그렇게 돼 있다 (+빈칸 2)
- `DOCRT`(RT_PUM/RT_KU 완제품 · RT_RPUM/RT_RKU 자재 · RT_UNIT 수량 · RT_ABS 로스 · RT_SON/RT_KUM 원가·금액) 31행 / 완제품 19 → `bom_headers` 19 · `bom_items` 31 (30차 100%, :1162)
- 미이관: `DOCFS.S_SET` 분포 **0:287 · 1:4 · 2:2 · 3:10 · 공백:6** — 뜻 미확인(Q12) · `RT_SON/RT_KUM` 은 ERP `bom_items` 에 자리 없음
