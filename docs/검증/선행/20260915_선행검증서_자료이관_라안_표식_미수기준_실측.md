## §0 카드 (≤40줄)

**판정: 조건부.** (라)안 자체는 성립하나 전제 3개가 틀렸거나 비어 있다.

1. 🔴 **DOCF5 S_GU 0 의 50만 행 중 326,194행은 거래가 아니라 「월초 이월잔액」 행**이다 (S_YMD 끝 `00` · S_SUN 0 · S_BAL = 그 시점 누적잔액). 종전 식 30.3억 미수는 이 행을 더해서 부풀었다 — 9/9 기각 원인.
2. 🔴 **레거시 거래처원장은 거래처당 잔액 한 줄**(매출·수금·매입·지급 전부 한 칸)이다. 월초 이월행 1,788개 중 1,784개가 「전 코드 S_BAL−S_SUK 누적」과 원 단위 일치. 9/9 식(매출−수금 / 매입−지급 따로)은 레거시가 쓴 적 없는 모양 — 거래처별로 풀면 초과수금 1,112곳 −1.35억 · 매입 없는 지급 −1.07억이 섞인다(용지·잔액정리 상계).
3. 레거시 최종 잔액 후보: **F3 이월행 기준 미수 142,062,113(1,059곳) · 미지급 51,577,479(530곳)** / F1 재계산 141,931,113 · 51,522,479 / 9/9 식 5,565,664 · −82,606,946. 차이 규모 = 억 단위.
4. 🔴 **표식을 status 값으로 담으면 깨진다** — 합계 SQL 이 `status IN ('confirmed','invoiced')`(포함형)와 `status <> 'cancelled'`(제외형 83곳)로 섞여 있어 새 값이 한쪽에선 빠지고 한쪽에선 들어간다. source_type='migration' 은 멱등 키·대사가 물고 있고 memo 는 IJ_REM 이 쓴다 → **DDL(신규 칸) 필요** · purchase_receipts 는 is_deleted·tax_invoice_id 칸도 없음.
5. 조회 영향: FROM/JOIN 운영 SQL **약 110곳 · 12파일 + 뷰 2개**(v_partner_aging_buckets · v_partner_balance_calc). ReportService 만 52곳.
6. 🔴 **세금계산서 잠금은 353건 문제가 아니다** — 이관 명세서 **115,150건 전부** status='confirmed' · tax_invoice_id NULL · 이관 계산서는 delivery_id 미연결(주석 「추후 연결 UPDATE」 미구현) → `TaxInvoiceService.IssueAsync:76-109` 가드 통과 = **레거시에서 이미 발행된 명세서도 재발행 가능**.
7. 날짜 없는 줄 4행: `00000000` 2행은 명세서 이관에서 **통째 skip**(`MdbMigrationService.cs:4948`) — (라) 「전 줄 등록」과 충돌. `00000001` 2행은 `?? now` → **이관한 날 매출·매입**으로 들어감(부가세 1원·−5원). 재고원장(:2306)은 4행 모두 `?? now`.
8. 머리 있는데 원장 없는 2건: ① 2015-05-12 SEQ13 330,000원 — 원장에는 **다른 거래처(2147441292)** 로 같은 날·S_SSUN 13 으로 있음(명세서 거래처 변경 후 원장 미갱신 ⚠️추정) ② 2025-03-10 SEQ27 「가산세1」 0원 — 원장 없음(0원 머리 3,612건 중 원장 없는 건 이것뿐 · 원인 ⚠️미확인).
9. 🔴 판정 키 주의: 원장↔명세서 연결은 「같은 거래처·같은 날」이 아니라 **S_YMD + S_SSUN(=IJA_SEQ)** 이다. 거래처로 묶으면 ①이 「미반영」으로 오판정된다.

### §0-3 사장님 재결재 안건
- **R-A** 미수·미지급 기준: 9/9 식 폐기하고 레거시 방식(거래처당 한 잔액 · 양수=미수 · 음수=미지급)으로 갈지. 간다면 F3(레거시 저장 이월값) vs F1(원장 줄 재계산) 중 무엇을 정본으로 할지 — 차 131,000 / 55,000 (5곳).
- **R-B** 세금계산서 잠금 범위: 미반영 353건만 vs **이관 명세서 전체**(레거시에서 발행된 계산서 재발행 사고 방지).
- **R-C** `00000000`/`00000001` 4행: 등록한다면 날짜를 무엇으로(이관일 금지 시 → 표식+날짜 칸 NULL 불가(DDL NOT NULL) → 최초 거래일/1900-01-01 등) · 금액 합계 영향 부가세 −4원.

### 산출·검증 불변식(다른 MDB 에도 같은 식)
① 이월행(`RIGHT(S_YMD,2)='00'`) 제외 ② 원장↔머리 키 = (S_YMD, S_SSUN) ③ 이월행 = 직전 누적 대조군(불일치 4곳 · 누락 1곳이 기대값).
