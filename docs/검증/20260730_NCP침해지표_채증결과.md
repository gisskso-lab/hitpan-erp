### 8-1. 디스크 — 배포 게이트 복구가 진짜 목적이었다

> 매니저2 지적: `deploy-web.sh:44` **`MIN_FREE_MB=2048`** 게이트 존재.
> **여유 1.3G(1331MB) < 2048MB → 지금 배포하면 거부된다.**
> 즉 로그 정리는 보안 위생이 아니라 **가동 복구 작업**이었다. PM 이 순위를 잘못 봤다.

- **증거 보존 후** 정리: `/root/btmp-evidence-20260730.bak` (355MB 원본)
- `/tmp` 잔재 1.2.40 은 **sha 대조 후** 삭제(packages 사본과 일치 확인). 1.2.41 은 오늘 작업분이라 보존
- 결과 **2.2G** — 게이트(2.0G) 통과

### 8-2. fail2ban — `is-active` 가 아니라 실차단으로 증명

> 검증팀 요구: *"`systemctl is-active` 는 증명이 아니다. 밴 IP 실재 + 커널 룰 + 카운터 증가 셋 다."*

```
Currently banned: 4
Banned IP list: 45.148.10.152  198.98.62.211  185.166.25.150  159.65.1.75

nft list set inet f2b-table addr-set-sshd
→ elements = { 45.148.10.152, 159.65.1.75, 185.166.25.150, 198.98.62.211 }
```

**커널 nftables 에 실재 확인.** `185.166.25.150`·`198.98.62.211` 은 채증에서 확인한 상위 공격 IP.
**활성 20초 만에 4건** = 공격 밀도가 그만큼 높았다는 뜻이기도 하다.

설정 근거(매니저2):
- `maxretry=5` — 3은 위험. 사장님이 키 여러 개라 SSH 가 자동 순차 시도하며 실패 2~3회 소모
- **`ignoreip` 에 사장님 IP 미포함** — `124.194.59.154` 는 동적 IP 가능성. 넣으면 나중에 그 IP 를
  물려받은 **남을 무기한 면제**하는 규칙이 된다. 사장님은 키 접속이라 실패가 안 쌓인다
- `bantime=1h` + 누진(최대 7일) — 영구밴은 자기차단 시 자력 복구 불가

### 8-3. 비밀번호 인증 차단 — 🔴 진범은 cloud-init 드롭인이었다

**1차 시도 실패.** 드롭인 `60-hitpan-hardening.conf` 를 넣었는데 값이 안 먹었다.

| 항목 | 1차 결과 |
|---|---|
| `permitrootlogin` | ✅ `without-password` (먹음) |
| **`passwordauthentication`** | 🔴 **`yes` 그대로** (안 먹음) |

**원인**: `/etc/ssh/sshd_config.d/50-cloud-init.conf` 에 `PasswordAuthentication yes` 한 줄.
**드롭인은 파일명 순으로 읽히고 SSH 는 먼저 나온 값이 이긴다** → `50-` 이 `60-` 을 이겼다.
(`sshd_config` 본문엔 `PasswordAuthentication` 자체가 없어 `permitrootlogin` 만 먹은 것)

**봉합**: 파일명을 **`49-`** 로 당겨 cloud-init 보다 먼저 읽히게 함.
> cloud-init 파일을 직접 고치지 않은 이유 — 재부팅·재프로비저닝 시 **다시 덮어쓸 수 있다.**
> 번호로 이기는 쪽이 영속적이다.

**최종 검증 (사장님 PC 에서 외부 실측)**:
```

→ OK / root                                    ✅ 키 접속 정상

ssh -o PreferredAuthentications=password -o PubkeyAuthentication=no root@...

```

> 따라서 *"유출되지 않았다"* 를 직접 증명할 수는 없고,
> **"유출됐다면 반드시 남았을 흔적이 없다"** 는 간접 증명만 가능하다.
>
> 본 채증은 그 간접 증명 4종을 통과했다. **판정은 "침해 정황 없음(높은 신뢰)"이지
> "침해 없음 확정"이 아니다.** 이 구분을 흐리면 PM 이 처음에 한 오독("증거 부재 = 부재 증거")을 반복하게 된다.
