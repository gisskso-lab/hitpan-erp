### 🚨 이 폴더에서 다음 사람이 먼저 알아야 할 것

- 🔴 **워치독은 `/api/installer/bootstrap` 을 60분에 최대 10회 부른다** — `CoolDownMaxPerHour=5` 가 **키별 독립 큐**이고 호출 키가 2개(`ServiceReinstall` · `PostReboot:ServiceReinstall`)다. 「시도 제한 5회/60분」을 설계할 때 **반드시 이 숫자부터 본다.**
- 🔴 **`machineFingerprint` 는 요청 본문의 자유 문자열이다** — 공격자가 자유롭게 바꾼다. **지문 단위 잠금은 공격자를 못 막고 정직한 클라이언트만 막는다.**
- 🔴 **`POST api/landing/serial/verify` 는 호출자 0건** — `serial_verify_locks` 는 오늘 아무도 안 쓴다. 「기존 검증된 기계 재사용」으로 읽지 마라.
- 🔴 **백오피스 API 에 전역 rate limit 은 0건이다**(실측 2026-10-07).
- 🔴 **백오피스 Blazor 호스트의 화면 잠금은 집행 지점이 확인되지 않았다** — `Components/Routes.razor:8` 이 `AuthorizeRouteView` 가 아니라 맨 `RouteView` 다(ERP `src/HitPan.Web/App.razor:13` 은 쓴다 · `FallbackPolicy`·`RequireAuthorization()` 둘 다 0건). 화면 `@attribute [Authorize(Policy=...)]` 를 **더하는 작업은 2단 대조(주소창 재적재 / 회로 안 이동)로 재야 한다** — 1단만 재면 통과가 거짓이 된다.
- 🔴 **「사이드바에서 지웠다」는 「잠갔다」가 아니다** — `@page` 라우트는 전부 살아 있고 `Platform*.razor:10` 리다이렉트 shim 6개가 미노출 화면으로 되돌려 보낸다.
