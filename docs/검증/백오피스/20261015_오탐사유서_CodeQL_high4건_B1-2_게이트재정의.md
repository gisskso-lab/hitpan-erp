## §3 오탐 4건 — 사유

### 1999 `cs/user-controlled-bypass` — `TelemetryController.cs:72`

규칙이 분기 조건으로 본 자리는 **형식 검사**다(`:71-73` — `TenantIdHash` 가 `sha256:` 으로 시작하는지). 틀리면 `400`.
**실제 인증은 `:104-118`** 에 있다 — `License:Pepper` 로 HMAC-SHA256 한 값을 `tenants.license_key_hash` 와 대조하고, 없으면 적재 거부(위조 행 방지) + 경고 로그는 **해시만**.
⇒ 사용자 입력으로 **우회되는 인증 관문이 아니다.** 형식 게이트와 인증 게이트가 **다른 줄**이다. **오탐.**

### 1426 `cs/web/missing-function-level-access-control` — `:280`

경보가 가리키는 파일은 `PromotionsAdminController.cs` 지만, **그 줄의 클래스는 `PricingPublicController`** 다(`:265-268` — `[ApiController]` `[Route("api/landing/pricing")]` **`[AllowAnonymous]`**). 액션은 `:279` `[HttpGet("plans")] GetPublicPlans`.
같은 파일의 **관리자 컨트롤러 2개는 제대로 잠겨 있다** — `:20` `PromotionsAdminV2Controller` 와 `:173` `RewardsAdminController` 둘 다 `[Authorize(Policy = "PlatformAdmin")]`(2026-06-11 P0 봉합 주석).
⇒ **랜딩이 비로그인 상태로 읽어야 하는 공개 요금표**다. 권한을 붙이면 랜딩 가격 화면이 죽는다. **의도된 공개 · 오탐.**
🟡 **단, 한 파일에 공개 컨트롤러와 관리자 컨트롤러가 섞여 있는 것은 사람이 오독하기 쉽다** — 파일 분리는 **B1 범위 밖**(별건 후보로 기록).

⇒ 숫자 10자리 외의 문자가 **구조적으로 통과 불가.** **오탐.**

## §4 🔴 B1② 게이트 재정의안 (전결 판정)

**종전**(진실원 §4 B1②) — *"보안 high 5건 봉합 → 열린 high 0"*
🔴 **이 합격선은 코드로 도달 불가다.** 오탐 4건은 고칠 코드가 없다(고치면 기능이 죽는다). dismissed 0 인 상태에서 「열린 high 0」은 **영구 미달**이고, 미달인 게이트는 **차수를 영원히 안 닫는다.**

**신규 합격선 — 3항 전부 만족**
1. 🔴 **진짜 취약 0** — 1665 봉합 완료 (증거 = 그 자리에 원문이 안 남는 게이트 1건 + 음성 대조군)
2. **오탐은 사유서 있는 dismiss 만** — dismiss 건수 = 사유서 §3 항목 수와 **일치**(현재 4). 사유서 없는 dismiss 가 1건이라도 있으면 **미달**
3. **critical 0 유지** (현재 0) + **새 high 유입 0** — 측정 시점·명령을 숫자로 남긴다

🟢 **「덮기」와 다른 점**: ① 규칙 전체를 제외목록에 넣지 않는다 — **경보 단위 dismiss** ② 각 건에 코드 근거 한 줄 ③ **진짜 1건은 dismiss 하지 않고 봉합** ④ dismiss 는 되돌릴 수 있고 이 문서가 되돌릴 근거가 된다.
