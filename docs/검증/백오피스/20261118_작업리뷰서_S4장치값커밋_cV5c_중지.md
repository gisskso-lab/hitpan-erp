## 2. 발견

### P2-V5c-1 (새 · P2) — 검사 시점 ≠ 실행 시점: getter · Proxy 로 env · 호출 모양 검사를 통째로 지나감

`shGuard` 는 `opt` · `args` 를 **읽어서 검사**하고, `sh` 는 같은 객체를 `spawnSync(cmd, args, Object.assign({ cwd: root, env: env0 }, opt || {}))` 로 **다시 읽어** 넘긴다. 읽을 때마다 값이 바뀌는 객체를 넘기면 검사는 허용값을, 실행은 다른 값을 본다. 실측(블록 안 `shTry` 다음 자리에 실험 코드 삽입 · 사본 되돌림):

| 실험 | 넘긴 것 | 결과(원문) |
|---|---|---|
| E3 env getter(git) | `opt.env` getter: 첫 읽기 = `env0`(=== 통과) · 둘째 읽기 = env0 + `GIT_TRACE=<파일>` · 모양 `cat-file -e SB4[0]` | `threw:false · status:0` · getter 읽힘 2회 · **추적 파일 생김 `true`** — 검사 밖 env 가 자식에 닿음 |
| E4 Proxy(bash) | `new Proxy({encoding, env: env0 + BASH_ENV=<스크립트>}, { has: k==='env' ? false : … })` · 허용 bash 꼴 | `threw:false · status:1` · **표지 파일 생김 `true`**(BASH_ENV 스크립트 실행 = 임의 명령) — `'env' in opt` 만 속이면 `Object.keys` 는 열쇠 허용 목록 통과 · `Object.assign` 은 env 를 복사 |
| E5 args getter(git) | `args[1]` getter: 2회까지 `'-e'` · 그 뒤 `'-p'` | `threw:false · status:0` · 출력 = `# P0 #2 (2026-05-14): TruffleHog 시크릿 스캔 …` — **모양 8 밖 `cat-file -p` 실행**(결-17 ② 의 핵심 검사 우회) |
