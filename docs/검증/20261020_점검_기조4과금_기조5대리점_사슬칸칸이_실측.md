## 7. 「내가 측정하지 못한 것」 (⚠️ — 통과로 쓰지 않는다)

1. **DB 실측 0회.** 운영 접촉 금지 + #39 로 **쿼리를 한 건도 돌리지 않았다.** 위 판정은 전부 **코드·DDL 정적 실측**이다. 특히 ⓔ 가 「실제로 전 고객사 `reseller_id` 가 `NULL` 인가」는 코드로는 **「채우는 경로가 없다」까지만** 말할 수 있다 — 사람이 SQL 로 넣은 행이 있을 수 있다. **백오피스 DB 1회 조회가 필요하다**(진실원 §6-10 「PM 이 백오피스 DB 한 번도 조회 안 함」과 같은 구멍).
2. **화면 실행 0회.** 대리점 계정으로 `/reseller/v2/*` 를 열어 어떤 모양으로 깨지는지(빈 화면인가 오류인가) 재지 않았다. 코드는 경고 + 빈 모델을 가리킨다(`ResellerDashboardPage.razor:103-106`).
3. **ⓖ 음성 대조군 불가.** 조임 코드가 0건이라 「미납인데 통과한다」를 보일 대상이 없다. 「내보내기 개방」은 **미측정**으로 남긴다.
4. **ⓑ 플랜 연결**은 `pricing_plans` 를 **칸 목록까지만** 봤다(`00_backoffice_core.sql:400`). 플랜 코드가 `subscription_tier` 문자열과 규약으로 맞춰져 있을 가능성은 **확인하지 못했다**.
5. **`AdminResellerIssuePage.razor:41` 의 「수수료율 %」 열**이 어디서 값을 받는지 끝까지 못 쫓았다(그 화면에 API 호출 문자열이 보이지 않았다) — **미측정**.
6. **사장님 실측과 코드가 어긋나 보이는 자리는 나오지 않았다.** 이번 범위(과금·대리점)에서 터널·인터넷·VM 전제에 닿는 판정은 하지 않았다.
7. **A열 CS · 설치 · 업데이트 사슬의 결함은 찾지 않았다** — 범위 밖. §6 의 「닿았다」가 전부다.
