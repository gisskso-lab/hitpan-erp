## 판단 1줄
**조건부 가** — 손질하지 않은 원본 파일 1개를 ERP 와 함께 묶어 고객 PC 에 까는 것은 OFL 1.1 조항 2 가 허락하는 「소프트웨어와 함께 묶어 재배포」이고, PDF 임베드 · 부분집합은 조항 5 후단으로 문제없다. **조건** = 아래 ①~⑥. 그중 막는 것 셋: **고지 파일을 설치본과 업데이트 판 둘 다에 실음 · 공식 출처 · 판 · SHA-256 고정 · 손질 0**.

## 근거
1. **묶어 배포 허용** — 조항 2: "Original or Modified Versions of the Font Software may be bundled, redistributed and/or sold with any software, provided that each copy contains the above copyright notice and this license." · FAQ 1.4(상용 소프트웨어에 포함): "Yes, you can do this with both the Original Version and a Modified Version of the fonts." → 유료 ERP 에 넣어도 가 · 의무 = **사본마다** 저작권 고지 + 라이선스 전문.
2. **원본이면 이름 제한 없음** — 조항 3(예약 이름) · 조항 4(권리자 이름 홍보 금지)는 수정본에만 걸림. 공식 저장소의 지역 부분집합 파일(`SubsetOTF/KR`)은 권리자가 직접 낸 파일이라 「Font Software」(정의: "the set of files released by the Copyright Holder(s)") 그대로 = 원본. 조항 1(단독 판매 금지)은 ERP 안에 묶여 나가므로 해당 0.
3. **PDF 는 라이선스 밖** — 조항 5 후단: "The requirement for fonts to remain under this license does not apply to any document created using the Font Software." · FAQ 1.12: "Yes, either in full or a subset. The restrictions regarding font modification and redistribution do not apply, as the font is not intended for use outside the document."
4. **고지는 따로 읽히는 글로** — 조항 2 는 고지를 "stand-alone text files, human-readable headers or in the appropriate machine-readable metadata fields … as long as those fields can be easily viewed by the user" 로 허락. DLL 안 내장 리소스 속 글꼴 이름 기록은 사용자가 쉽게 볼 수 없음 → 그것만으로 채웠다고 보기 어려움. FAQ 1.10 은 「프로그램 안에 묶인 경우」를 예외처럼 적지만 FAQ 1.20 은 "At a minimum you must include the copyright statement, the license notice and the license text." → **원문 조항 2 와 FAQ 1.20 쪽(엄한 쪽)을 따라 독립 텍스트 파일로 둔다.**
