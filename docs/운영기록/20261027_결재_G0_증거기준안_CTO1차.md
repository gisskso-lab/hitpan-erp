- 고친 글(:53 끝): 「R6 의 「다음 차수」 = 테스트 PC 스케줄표 차수(판 ⑫). G5 의 「차수」(실고객을 늘리는 단위)와 다르다 — 수정 건은 고객을 늘려서 재확인하지 않는다(G5 에서 난 수정 건도 테스트 PC 차수 측정표 **또는** 처음 합격 등급으로 닫는다).」
- 들어간 것: 뜻 구분 · 확대가 재검증을 대신하지 않음 · 🔵. 출처를 Q8 대신 판 ⑫ 로 단 것은 문제없다(R6 앞부분이 이미 Q8·Q1 에 달림).

- 빠진 것: 「닫은 뒤에만」. P0 는 「P0 1건 = 신규 투입 중단」(:157) · 업무 중단 P1 은 G5 차수 종료 칸(:155)이 이미 막는다 → 남는 것은 그 밖 등급의 수정 건을 연 채 확대하는 경우뿐. 사장님 원문 밖 새 규칙이 되므로 CTO 가 넣으라 하지 않는다 → C5.
