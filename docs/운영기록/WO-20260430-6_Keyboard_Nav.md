# 작20260430-6 — 키보드 네비게이션 + 그리드 동작 (P1)

## 🟡 우선순위
P1 (ERP 매니저 격상 권고: 더존 vs 히트판 결정 지점)

## 사장님 격언
> "자재상·유통상가 등 도소매 업자들은 바빠서 마우스 잘 안 씀.
> 그렇다고 마우스가 안 되면 안 됨."

## 적용 범위 (3개 화면 공통)
- 견적서
- 수주서
- 거래명세서
- **+ 매입관리 대메뉴 전체 그리드** (발주·매입·반품 등)

## 담당
- 메인: 프론트 매니저 (직접 처리, 어려운 영역 = 키보드 이벤트 + 포커스 관리)
- 보조: UX/UI 매니저
- 검증: ERP 매니저 (현장 시선) + 검증팀

## 작업 범위

### A. 헤더 입력란 키보드 네비게이션
- 일자 → 유효기한 → 거래처 → 메모 → 그리드 첫 셀
- 엔터·Tab·방향키로 이동
- Shift+Tab·역방향키로 역이동
- 마우스 클릭도 정상 동작 (병행)

### B. 그리드 품명 동작 (자재상 사용 시나리오 핵심)
- 품명 셀 진입 → 검색 자동 포커스
- 검색어 입력 → 드롭다운 표시 → 방향키로 선택
- **엔터 1회: 선택 항목 반영 (단가·규격·단위 자동 채움)**
- **엔터 2회: 다음 행 1번 셀로 이동**
- 마우스 클릭도 동일 동작

### C. 매입관리 그리드 (발주·매입·반품 등 전체)
- B와 동일 패턴 일괄 적용

## 검증 보고서 양식 (헌법 4조)
- DB 계층: 견적·수주·거래명세서 INSERT 정상
- 백엔드 계층: API 200 OK
- 프론트 계층: **키보드만으로 견적 1장 완성 → 저장까지 가능**
- 연결 끊김 0: 견적 → 수주 → 거래명세서 → 세금계산서 흐름 데이터 인계 (절대원칙 #20)
- 고객 시선:
  - "마우스 안 잡고 50장 칠 수 있나?" (ERP 매니저 시연)
  - "처음 보는 직원이 키보드만으로 쓸 수 있나?"
