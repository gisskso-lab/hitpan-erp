## 📋 인증서 등록 UX (수석 웹디자이너 정합)

### Step 1: 사용자가 자기 인증서 등록
```
[설정] → [전자세금계산서] → [공인인증서 등록]
  ↓
.pfx 파일 업로드 + 비밀번호 입력
  ↓
DPAPI 암호화 후 %APPDATA%\HitPan\Cert\ 저장
  ↓
"등록 완료. 만료일: 2027-05-25"
```

### Step 2: 세금계산서 발급
```
거래명세서 → [세금계산서 발급] 버튼 클릭
  ↓
히트판 ERP가 자동으로:
  1. DPAPI로 인증서 로딩
  2. XML 생성 (LINQ to XML)
  3. SignedXml 서명
  4. 홈택스 API POST
  5. 승인번호 수신·저장
  ↓
"발급 완료. 승인번호: XXXX-XXXX-XXXX"
```

### Step 3: 인증서 만료 자동 알림
```
D-30: "공인인증서가 30일 후 만료됩니다."
D-7: "공인인증서가 7일 후 만료됩니다. 갱신 필요."
D-0: "공인인증서 만료. 갱신 필수."
```
