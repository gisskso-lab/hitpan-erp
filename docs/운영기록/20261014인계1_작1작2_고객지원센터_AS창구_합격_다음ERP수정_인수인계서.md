## §6 🔴 함정 — 다음 세션이 밟을 지뢰

1. 🔴 **이웃 회귀를 안 돌리면 CI 가 잡는다.** [4] 작업리뷰서 §8-7 에 「이웃 회귀 미실시」가 **적혀 있는데 읽고도 안 메워** CI 가 `G-W3-10`·`G-C-12`·`G-B8-2` 3건을 잡았다. **CS 묶음만 돌리지 말고 전체를 돌려라.**
2. 🔴 **게이트를 코드에 맞춰 느슨하게 만들지 마라.** 규칙이 갈리면 **음성 대조군을 옮긴다**(쪽지건 → 수기건). 이번에 `G-C-12` 는 단언 **2→5개**로 늘었다. 지우면 조용한 초록이 된다.
3. 🔴 **FAIL 대조군은 「깨뜨린 줄 수」를 세고 나서 판정하라.** 이 세션에 같은 뿌리로 **3번** 틀렸다 — ⓐ CRLF 때문에 perl 다중행 치환이 **0건**인데 초록 ⓑ 주석을 끼워 줄번호가 밀려 `sed '331s'` 가 엉뚱한 줄을 쳤다 ⓒ `from==to` 검사가 **두 개** 생겨 동작이 안 바뀌었다. 치환 건수를 **찍어서** 봐라.
4. 🔴 **새 칸을 화면에 꺼낼 때 폐기 가림을 같이 봐라.** S-5 가 `rating_comment` 를 꺼내자 **폐기된 건의 고객 말**이 다시 보였다(내가 만든 개인정보 구멍). 2겹으로 막았다(폐기가 비움 + 상세가 가림 · `G-W8-8`).
5. 🔴 **칸은 바꿔 끼우지 말고 더하라.** 작2 첫 판이 작1 의 「접수 경로」를 「응대유형」으로 **교체**했다. 렌더 하네스가 0건이라 **어떤 게이트도 못 잡는다** — 사람이 봐야 한다.
6. 🔴 **로컬 게이트 DB**: `hitpan` 은 **`test_%` 이름만** CREATE 가능하고, `HITPAN_BO_GATE_DB` 는 **DB 하나를 고정**하는데 xUnit 은 클래스를 **병렬**로 돈다 ⇒ **묶음 하나씩, 각자 다른 `test_` DB 로** 돌려라.
7. 🔴 **`G-W3-10` 은 DB 둘(ERP+본사)이 필요해 CI 가 유일한 계측 자리다.** 로컬 초록은 증거가 아니다.
8. 🔴 **`Scan secrets` 빨강의 정체 — 이번에 증명됐다.** 같은 갈래 같은 워크플로인데 갈렸다: 갈래 **첫 밀기**는 `base` 가 없어 **이력 전체**(20,168 조각 · 미검증 **116**) → 빨강, **두 번째부터**는 delta(**5 조각 · 0/0**) → 초록. ⇒ ① 내 커밋에 자격증명 모양 **0건** ② 116건은 **레포 이력**. 🚫 `exclude-paths` 로 덮지 마라. 이력 재작성은 **사장님 결재** 사안.
9. MudBlazor 9 는 `MudExpansionPanel.IsInitiallyExpanded` 가 **없다**(MUD0002) → `@bind-Expanded` + 필드.
10. `bo_cs_tickets.client_ticket_uid` 는 **varchar(36)** — `manual-{Guid:N}`(39자) 가 터졌다.
11. 🔴 **[3-V] 를 움직이는 표적에 띄우지 마라.** 미커밋 + FAIL 대조가 파일을 흔드는 중에 띄워 검증자가 `if (false) /* FAIL대조 */` 가 든 판을 읽었다. [4] 는 커밋 뒤 SHA 에 못 박아 띄웠다.
