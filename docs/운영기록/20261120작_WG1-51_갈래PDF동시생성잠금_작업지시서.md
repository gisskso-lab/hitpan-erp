## §1 [오더] 대표 결재 원문 · 이해

> §99 첫 행(대표 직접 답 · 질문창 1문항): **「W-G1-51 안 새 갈래 (Recommended)」** — 인쇄 작3 합류본 전에 ERP 인쇄 서비스(`PdfRenderService` · `PdfExportService`) `GeneratePdf` 공용 잠금 + 동시 생성 회귀 게이트(병렬 60장 · 글자 빠진 장 0). 먼저 [1-V] = 종이 모양(그림 대조)까지 깨지는지 실측 · 14곳 목록. 백오피스 계약서 PDF · QuestPDF 판올림 = 별건(W-G1-51 뒤)

- 대표가 고른 것은 선택지 라벨이고, 내용 글은 PM 이 쓴 질문 본문이다(PM 기록 ≠ 대표 원문 — 해석이 갈리면 PM 이 대표께 다시 여쭘).
- 「14곳」 은 1V 가 **틀림**으로 판정(주석 4 + 메서드 이름 1 포함) → 이 지시서는 「제품 호출 8곳(ERP)」 만 쓴다(C1).
- 안 하면: 직원 둘이 동시에 인쇄 · 메일 · 팩스를 누르면 일부 PDF 의 글자 복사 · 검색 · 받는 쪽 추출이 깨진다(1V §1 · 이 PC 무잠금 병렬 18~45%). 시험에서는 §59 간헐 빨강으로 나타남(§97).
- §101 셋째 행: 1V 🟡 **받아들임** → 「설계팀장 작업지시서(C1~C7 그대로)」.

## §4 [설계] 잠금 꼴 · 범위 · 중첩

### §4-1 객체
- 두 서비스 등록: `PdfRenderService` `AddScoped`(`src/HitPan.API/Program.cs:165`) · `PdfExportService` `AddScoped`(`:315`) → 요청마다 새 인스턴스 → 인스턴스 필드 잠금 = 무효(C2). **정적 클래스의 정적 필드 1개**를 둘 다 부른다.
- 프로세스: ERP API 한 프로세스(고객 PC). 워치독 · 런처는 QuestPDF 를 안 씀 — 프로세스 둘 이상 잠금(이름 있는 뮤텍스 등) 불필요 · 쓰지 않음.
- `lock`(Monitor) 추천 — C# 컴파일러가 `lock` 안 `await` 를 막아 C2 「`await` 를 잠금 안에 두지 말 것」 을 **구조로** 지킴 · 같은 스레드 재진입 허용이라 혹시 모를 중첩에도 교착 0. `SemaphoreSlim.Wait` 는 재진입 시 교착 · `await` 를 막지 못함 → 쓰지 않음.

### §4-2 범위 = `GeneratePdf()` 호출 한 줄 (고른 까닭)
1. **실측 근거**: 1V A2 — 문서 구성은 밖 · `doc.GeneratePdf()` 한 줄만 `lock` → 순수 QuestPDF 60장 ×3 = **0 · 0 · 0**(D1 · D2 · D3) · 대조 무잠금 15~27(1V §3). 앞 탐침 P6 「생성만 잠금 0」 은 렌더 통째였고, 한 줄 잠금도 0 임이 따로 섰다.
2. QuestPDF 는 `Document.Create` 람다를 `GeneratePdf` **안에서** 실행 → 한 줄 잠금이어도 구성(레이아웃 · 글꼴 부분집합)은 잠금 안(1V §3 주의). 그래서 「문서 구성 포함」 을 따로 고를 까닭이 없다.
3. 잠금 밖으로 빠지는 것: DB 조회(`RenderPayslipAsync` `:3490 · 3491 · 3496` 의 `await` 등) · 그림 미리 열기(`:3132` 주석 자리) · 측정 전 준비. 렌더 통째 잠금은 DB 대기까지 줄 세워 직원 동시 인쇄를 DB 시간만큼 더 늦춘다.
4. 세금계산서 한 요청 = 측정(1860 · 2079 반복) + 본판(1737) — 호출마다 따로 잡고 놓음 → 다른 요청이 사이에 끼어도 각 생성은 혼자 돈다(1V §5(나): 측정 호출도 남의 본판을 깨므로 잠금 대상).
5. 1V §7: 「제품 코드에서 호출만 잠금의 0 · 시간」 은 미측정 → G2 가 그 실측이다.

### §4-3 중첩 없음 확인
- 측정 호출은 모두 `Document.Create` **밖**(구성 전)에서 끝남(1V §2 `:1655-1664` 확인) · 제품 `GeneratePdf` 는 위 8줄뿐(`git grep -n "GeneratePdf" d8900021` · 주석 · 메서드 이름 제외) → 생성 안에서 생성 0.
- 개발 확인 거리: `TaxInvoiceFitProbe`(Dynamic 구성요소) · `page.Background()` 람다 안에서 통로를 부르는 줄 0 — `git grep -n "GeneratePdfSerialized\|GeneratePdf(" ` 로 셈해 명세에 적음.
- 예외: `lock` 은 try/finally — `:1862` · `:2081` catch(측정 실패 → 두 쪽) 길도 잠금이 풀린 뒤 기존 그대로.
