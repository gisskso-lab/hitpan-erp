## 1분 달성 5축 정공법

### 1축. MySqlBulkCopy (LOAD DATA LOCAL INFILE)

**현재:** row-by-row INSERT + 1000행 청크 INSERT IGNORE
- 1000만 행 ≈ 10~17분

**정공법:**
- `OleDbDataReader` → CSV 임시 파일 stream 작성
- `LOAD DATA LOCAL INFILE` 한 번에 적재
- 1000만 행 ≈ **30초** (50~100배 가속)

### 2축. OLEDB 병렬 SELECT (3 MDB 동시)

**현재:** PYOJUN → PANDATA → POTHER 순차 (POTHER 미구현)
**정공법:**
- 3개 OleDbConnection 별도 open → Task.WhenAll
- 동시 읽기로 I/O 대기 1/3
- POTHER 4개 테이블 (DOCNM 명함 / DOCAS AS / DELIVERY 배송 / CALENDAR 달력) 신규 마이그 메서드 4개 작성

### 3축. Stream 처리 (DataTable 폐기)

**현재:** `ReadMdbTable` → 전체 DataTable 메모리 → foreach 변환
- 1000만 행 = 메모리 60MB~수GB

**정공법:**
- `OleDbCommand.ExecuteReader()` → `OleDbDataReader` 직접 stream
- 변환 후 CSV stream 직접 작성
- 메모리 사용량 일정 (수 MB) — 1000만 행도 OOM 0

### 4축. 인덱스 비활성화 → 마이그 → 재활성화

**대상 테이블:** partners, items, employees, collections, stock_ledger, sales_orders, purchase_orders, tax_invoices, bills, card_payments, bank_transactions (11종)

```
ALTER TABLE collections DISABLE KEYS;
-- 마이그 LOAD DATA INFILE
ALTER TABLE collections ENABLE KEYS;  -- 한 번에 인덱스 재구축
```

DB매니저 02번 보고서 권고. 60만 행 인덱스 매번 갱신 → 1회 일괄 재구축으로 단축.

### 5축. 테이블별 병렬 마이그 (Task.WhenAll)

**제약:** 헌법 #16 (MySqlConnection thread-safe 아님)
**정공법:**
- 각 테이블별 **독립 connection** (connection pool에서 발급)
- partners·items 완료 후 (FK 매핑 in-memory 채움)
- PANDATA 11개 테이블 병렬 LOAD DATA INFILE
- Task.WhenAll로 동시 실행
