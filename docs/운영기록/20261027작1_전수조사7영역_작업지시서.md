## §6 [받아쓰기] 받아쓰기 금지 규칙

1. ②·③ 의 🟢 = **조사자가 그 파일:줄을 이번에 직접 읽은 것만.** 읽지 않았으면 🟡 + 출처 🟡.
2. 문서의 「완료·통과·머지」 = 🟡. 머지 여부는 `git show b9f34ccd:<파일>` 로 확인한다(P-2 사례).
3. ① 🟢통과 = **사장님 원문 또는 원문을 인용한 문서 주소**가 있을 때만. PM·에이전트가 쓴 「통과」는 ⬜. 원천은 1-V §3 표(반려대장 · 운영기록 · 사장님 손 따라하기 · 진실원) — 🔴 진실원은 10/25 이후 갱신 0, 10/26 반려 3건은 반려대장에만.
4. 통과 판 뒤 코드 변경 여부는 §4 의 `git log` 로 확인하고 「통과 · 이후 변경 있음」으로 적는다.
5. 「전부」·「N건뿐」은 세지 않고 쓰지 않는다 — 분모는 목록으로.
