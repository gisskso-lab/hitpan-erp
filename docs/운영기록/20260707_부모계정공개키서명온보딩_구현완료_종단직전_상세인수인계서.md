## 4. 키 인프라 (NCP) — 중요, 정확히 기록

- **ECDSA P-256 키쌍은 NCP 안에서 openssl로 생성.** 개인키는 채팅·개발PC 어디에도 안 나옴(공개키만 화면 출력).
- **개인키 위치**: `/var/hitpan/serial-keys/serial_private.pem` (chmod 600, root). **밖으로 유출 금지.**
- **공개키**: `/var/hitpan/serial-keys/serial_public.pem` (노출 무해). 이 값이 EXE `SerialProofVerifier.EmbeddedPublicKeys["v1"]`에 내장됨.
- **백오피스 주입**: `/etc/systemd/system/hitpan-backoffice-api.service.d/secrets.conf`에
  `HITPAN_SERIAL_SIGN_PRIVATE_KEY_FILE=/var/hitpan/serial-keys/serial_private.pem` + `HITPAN_SERIAL_SIGN_KID=v1` (경로만, 값 아님).
- **짝 정합 실측 확인 완료**: `GET https://back.hitpan.kr/api/landing/license/public-key` → `{"configured":true,"algorithm":"ECDSA-P256-SHA256","kid":"v1",...}` 공개키가 EXE 내장값과 일치.
- ⚠️ **이 v1 키쌍은 베타 검증용.** 정식 배포 전 사장님이 새 키쌍 발급·교체(헌법 #23·#29). 개인키는 NCP만.
