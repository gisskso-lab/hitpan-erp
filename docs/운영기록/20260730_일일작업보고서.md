#### 검증팀이 잡은 것 — 내 코드가 침묵을 '거짓 성공'으로 바꿨다

```
ExecLogged('6-1-stopdel', 'sc stop X & timeout /t 3 & sc delete X & timeout /t 2')
```

cmd 는 이것을 `A & B & C & (D > file 2>&1)` 로 파싱한다:

| 결함 | 실측 채증 |
|---|---|
| **P0-1** 리다이렉트가 마지막 명령에만 → `sc stop`·`sc delete` 출력 **100% 유실** | 파일에 `timeout` 카운트다운만 남음 |
| **P0-2** 종료코드가 `timeout` 것이라 **항상 0** | `sc delete NoSuchSvcXyz & timeout /t 1 > f 2>&1` → **EXITCODE=0** (실제 sc 는 1060) |
| **P0-3** 좀비 없는 정상 경로에서 파일 미생성 → `(명령 자체가 실행되지 않았을 수 있다)` **거짓 진단이 백지 설치 전건에 찍힘** | `sc query NoSuch && echo X > f` → 파일 미생성 |

> **P0-2 는 침묵보다 나쁘다.** `sc delete` 가 실패해도 로그에 `종료코드 0 (성공)` 을 찍는다.
> 다음 세션 PM 이 이걸 보고 "6-1 은 성공했다"고 판단하면 **10번째 오답**이 된다.

### 3-2. 그 원인 — 관측성 부재 + 혼자 검증

**① 로그가 침묵했다**
```pascal
Exec(..., SW_HIDE, ewWaitUntilTerminated, ResultCode);
Sleep(3000);   // ResultCode 미검사 · 로그 0줄
```
`SW_HIDE`(안 보임) + 미검사(무시) + 로그 0줄 = **세 겹 은폐**. 헌법 #15 위반.

**② SoD 를 지키지 않았다**
P0-1·P0-2·P0-3·P0-4·P0-5 전부 **PM 이 만들고 PM 이 검증**했다. 병렬검증 0건.

**만약 [3-V] 가 돌았다면 잡혔을 것들**:
- P0-1 을 `6-3`(시작)에 넣을 때 → *"`6-2`(등록)는 검증했나?"*
- `ResultCode` 미검사 코드 → 헌법 #15 로 **반려**
- `STOPPED`(등록됨) vs `1060`(미등록) 구분 → 근거 오류 지적

**혼자 만들고 혼자 검증해서 잘못된 지점을 고쳤다.** 사장님이 *"서로 받아쓰기 금지"*,
*"견제하며 완성도를 높여라"* 하신 이유가 정확히 이것이었다.

### 3-3. 작9 오판 — "지워진다"를 확인 없이 믿었다
