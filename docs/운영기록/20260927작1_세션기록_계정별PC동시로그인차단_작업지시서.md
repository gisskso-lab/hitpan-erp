## 3. 🚫 금지 — 어기면 즉시 반려

| # | 금지 |
|---|---|
| 1 | **`SessionLimitMiddleware` 수정 금지** — 축이 다르다. 한 줄도 손대지 않는다 |
| 2 | **`user_agent` 문자열로 모바일 판정 금지** — 위장하면 FREE 로 과금이 뚫린다 (설계 §3-1) |
| 3 | **`device_kind` 기본값을 `'mobile'` 로 두지 마라** — 모르면 과금되는 쪽(`'pc'`)으로 |
| 4 | **`appsettings.json`·`appsettings.Development.json` 무접촉** (#21) |
| 5 | **계정 수 상한(5/8) 강제 구현 금지** — 숫자 결재 4건 미결. 이번 범위 아님 |
| 6 | **빈 `catch` 금지** (#15) · **금액 아님이므로 decimal 무관** |
| 7 | **세션 INSERT 를 로그인 성공 판정 앞에 두지 마라** — 실패한 로그인이 행을 남긴다 |
