### B-1 구현 형태 — 이대로만 만든다

```
2번째 PC 로그인 시도
  → 거절 + "이미 다른 PC에서 사용 중입니다 (마지막 사용: HH:mm)"
  → [그 PC 접속을 끊고 여기서 사용하기] 버튼
  → 사용자가 누르면 → 기존 세션 끊고 로그인
```

🔴 **밀어내기 버튼은 선택이 아니라 필수다.** PC 가 꺼지거나 브라우저를 그냥 닫으면 로그아웃 `DELETE` 가 안 돌아 **죽은 세션이 본인 계정을 스스로 잠근다.** 버튼과 `expires_at` 만료, **두 경로 다** 있어야 한다.

### B-2 — 축 A 는 끈 채로 출하한다

⚠️ **PM 은 실물 DB 를 못 잰다** — `hitpan` GRANT 가 `hitpan_backoffice`·`hitpan_e2e`·`hitpan_trgtest`·`test` 4개에만 걸려 있다. 아래는 **축 A 를 켜는 날** 사장님이 1회 돌린다 (읽기만 · #39):

```sql
SELECT tenant_id, COUNT(*) AS active_users
  FROM users WHERE is_active = 1 GROUP BY tenant_id ORDER BY 2 DESC LIMIT 20;

SELECT 'user_sessions' t, COUNT(*) c FROM user_sessions
UNION ALL SELECT 'refresh_tokens', COUNT(*) FROM refresh_tokens;
```

🔴 **「살리되 꺼둔다」를 코드 주석에도 남긴다.** 다음 사람이 「살린다」만 읽고 켜져 있다고 믿으면,
이번 트랙을 만든 바로 그 사고(넣는 곳 없는데 돈다고 믿음)를 되풀이한다.
