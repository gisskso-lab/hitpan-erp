## §3 🔴 배운 것 8건 — 여덟 중 여섯이 내 실수에서 나왔다

### ① 🔴 내가 적은 경고를 바로 옆에서 어겼다 (다섯 번째)

G-W12 에 **「이 트랙에서 네 번 밟았다 — 글자를 세는 게이트는 주석을 먼저 벗긴다」**고 직접 적어 두고, **본체 게이트 G-W10-8 에는 안 걸었다.** 낱말 몸통을 공백 한 칸으로 깨고 정본 글자를 `//` 주석에 넣으니 **5건 전건 초록**이었다.

🔴 **교훈: 함정 주석을 적을 때, 그 함정이 걸리는 자리를 그 자리에서 전수로 센다.** 「여기는 걸었다」가 아니라 「**글자를 세는 함수가 몇 개이고 그중 몇 개가 벗기나**」를 세야 했다.

### ② 🔴 「닫았다」를 돌려 보지 않고 결재 문서에 적었다

①의 더 나쁜 쪽. 예외 목록을 규칙으로 바꾼 것은 **옳은 설계**였는데, **그 규칙이 실제로 막는지는 안 재고** 코드 주석·설계·개발명세서에 「예외 0건으로 길을 닫았다」고 썼다.

🔴 **교훈: 「닫았다」는 그 길로 들어가 보고 적는다.** 설계가 옳다는 것과 코드가 막는다는 것은 다른 사실이다.

### ③ 🔴 내 음성 대조군이 내 게이트를 뚫었다 (NC-9) — 🟢 그게 대조군의 값이다

G-W13-5 를 **한 바퀴만** 돌리고 「새 마이그는 한 건도 못 들어온다」고 적었는데 초록이었다. 새 칸은 출하본에 아직 없으니 **1회차가 성공**한다 — 멱등이 깨지는 자리는 **2회차**다.

🟢 **그 봉합이 `DB-35` 를 새로 찾아냈다**(1회차 성공·2회차 1061) ⇒ 🔴 **분개 중복 방지 UNIQUE 키가 신규 설치본에 없다**는 사실로 이어졌다. **대조군이 게이트를 고치고, 고친 게이트가 사실을 하나 더 찾았다.**

🔴 **교훈: 동작으로 쟀다고 끝이 아니다 — 「몇 바퀴」가 맞아야 한다.**

### ④ 🔴 바퀴 수는 돌았다는 증거가 아니다 ([4] 지적)

[3-V] 가 「몇 바퀴 돌았나를 안 단언한다」고 올려서 `measured` 를 넣었더니, [4] 가 **「`measured` 는 바퀴 수이고 적용 건수가 아니다」**라고 다시 뚫었다. 러너 폴더가 비면 110 바퀴를 다 돌면서 SQL 은 **한 줄도 안 돈다.**

🔴 **교훈: 「돌았다」를 세려면 「무엇이 바뀌었나」를 세라.** 반복 횟수는 부작용의 증거가 아니다.

### ⑤ 🔴 주석은 코드가 아니다 — 정렬 규칙을 글로 적고 그 글을 믿었다

G-W13-3 의 통제 마이그를 「같은 번호 + 접미사면 **바로 앞**에 선다」고 주석까지 적어 심었는데, 러너 정렬은 같은 번호에서 **접미사 없는 쪽이 먼저**다 ⇒ 통제가 과녁 **뒤**에 서서 「뒤가 안 돈다」를 못 쟀다. **실측이 잡았다**(그 판은 빨강이었다).

### ⑥ 🔴 음성 대조군의 `git checkout` 이 **커밋 안 한 봉합을 되돌렸다**

NC-8·NC-10 복원이 두 바퀴 봉합·`DB-35`·사전 시드를 **전부 지웠다.** `grep -c` 로 표식을 세어 알아내고 다시 넣었다.

🔴 **교훈: 「대조군은 커밋 뒤에」는 **대조군 도중에 생긴 봉합**에도 적용된다.** 2차(C-1~C-7)에서는 커밋 뒤에 돌렸다.

### ⑦ 🟢 INDEX `numstat` 확인이 이번엔 잡았다

운영기록 INDEX 의 결3 줄을 **덮어썼다.** 작2 때 같은 사고(awk `next`)를 내고 적어 둔 **「손댄 뒤 `numstat` 으로 삭제 0 확인」**이 바로 잡았다 — 되돌리고(차이 0) 표 머리만 앵커로 잡아 다시 넣었다. 6건 전부 1/0.

🟢 **배운 것을 적어 두면 다음 번에 잡는다.** 이번 차수에서 **유일하게 적어 둔 교훈이 작동한 자리**다.

### ⑧ 🔴 소요시간만으로는 조용한 SKIP 을 못 가른다 — 게이트 안에 증거를 넣어야 한다
