## 1. 도메인 A1 — 가격 구조 (3티어 29k/59k/100k)

### 사장님 영역 (질문)
> "LITE 29k, STANDARD 59k, PRO 100k 확정인가? 베타 1개월 무료 + 6개월 50% 할인 헌장은?"

### PM 정직 권고
- **함정**: 59k는 이카운트(33k) 대비 +79% → 5% 시장점유 한계 위험
- **대안**: STANDARD 49k로 낮추면 BEP 6개월 늦어지지만 점유율 +12%p 예상
- **전제 의심**: "디바이스 3대=STANDARD" 매핑이 도소매 현장 정합인지 ERP 매니저 30년 경험 재검증 필요

### 매니저 정직 의견
- 마케팅팀장 **(찬성)**: 100k PRO는 더존(SPP-Pro 120k) 대비 -17% 매력 충분
- ERP 매니저 **(신중)**: 도소매 현장 STANDARD 3대는 빠듯, 5대로 늘리거나 49k 인하 둘 중 하나 권장
- 보안 매니저1 **(반대)**: 베타 6개월 50% 할인은 보안 SaaS 헌법 위반 우려 — 무료 영역은 보안 SLA 95% 제공 명시 필요

### 결재 옵션
- A. 29k/59k/100k 확정 유지 + 베타 1개월 무료 + 6개월 50% (사장님 원안)
- B. 29k/49k/89k 조정 + 베타 3개월 무료 + 6개월 30% (점유율 우선)
- C. 29k/59k/100k 유지 + 베타 1개월 무료만 (수익성 우선)

## 2. 도메인 A2 — 결제 수단 1순위

### 사장님 영역
> "토스페이먼츠 주력, KCP 예비. 우선순위·전환 기준은?"

### PM 정직 권고
- 함정: 토스 단일 의존 시 토스 장애=전체 결제 0
- 대안: KCP 자동 페일오버(5초 timeout) 옵션 H 검토
- 전제 의심: 법인 세금계산서 결제는 토스 위젯 불가 → 메이크빌 별도 라우팅 필요

### 매니저 의견
- 백엔드 매니저 **(찬성)**: 토스 주력 + KCP 페일오버 = 99.99% SLA 정합
- 보안 매니저2 **(신중)**: PG 2종 동시 통합 = 인증서·키 2종 관리 부담 +40%
- 마케팅팀장 **(찬성)**: 토스 브랜드 = 가입 컨버전 +18% 예상

### 결재 옵션
- A. 토스 주력 + KCP 자동 페일오버 (사장님 원안 정합)
- B. 토스 단일 (운영 단순, 장애 리스크 수용)
- C. 토스+KCP 동시 결제 (고객 선택 UI)

## 3. 도메인 A3 — 자동갱신 정책

### 사장님 영역

### PM 정직 권고

- 대안: 디폴트 ON + 결제 30일 전 이메일 사전 통지 + 1클릭 해지 UI
- 전제 의심: 베타 30곳은 자동갱신 OFF가 마찰 ↓

### 매니저 의견
- 법무팀장 **(찬성, 조건)**: 디폴트 ON 가능, 단 가입 시 명시적 동의 + 30일 사전 이메일 의무
- ERP 매니저 **(찬성)**: 더존·이카운트도 ON 디폴트, 업계 표준
- 보안 매니저1 **(신중)**: 결제 재시도 D+0/+3/+7 3회는 과도 → D+0/+5 2회 권장

### 결재 옵션
- A. 자동갱신 디폴트 ON + 재시도 D+0/+3/+7 3회 (사장님 원안)
- B. 자동갱신 디폴트 ON + 재시도 D+0/+5 2회 (보안 매니저1 안)
- C. 자동갱신 디폴트 OFF (베타 한정, 정식은 ON 전환)
