## §1 담당 절 — P0-1 `deploy-ncp-secrets.sh` 가 정본 이름을 못 보낸다

**지금**(`scripts/deploy-ncp-secrets.sh:42`)
```
if [[ "$line" =~ ^([A-Z_][A-Z0-9_]*)=(.+)$ ]]; then
```
🔴 **대문자만 받는다.** 코드가 읽는 정본 이름은 **섞인 대소문자**다 — `License__Pepper` · `Backoffice__BizNoPepper` · `Smtp__Host`.
🔴 **그리고 안 맞는 줄은 `if` 를 그냥 빠져나간다** — 에러도 경고도 없다. 「OK」만 몇 줄 찍히고 끝난다.
🔴 **이 스크립트를 무는 게이트는 레포 전체에 0건**이다(`grep -rln deploy-ncp-secrets` = 0).

**할 일**
1. 정규식을 `^([A-Za-z_][A-Za-z0-9_]*)=(.+)$` 로 넓힌다. 🟢 종전 줄은 **주석으로 남긴다**(#1)
2. 🔴 **건너뛴 줄을 모은다.** 빈 줄·`#` 주석은 정상 통과, **그 외에 안 맞는 줄이 1개라도 있으면 목록을 찍고 `exit 1`**(#15 — 조용히 넘기지 않는다)
3. 적재한 키 **개수를 찍는다**(「몇 개 넣었다」가 없으면 0개 넣고도 성공처럼 보인다)
4. 🔴 **값은 한 글자도 찍지 않는다** — 키 이름만

**덤으로 고칠 것** — 이 파일에 **금지어 3곳**이 있다(사장님 헌법: 「박제/박다/박았다/박힘」 일체 금지). 내가 이 파일을 여는 차수이므로 **이 파일 안에서만** 고친다. 🔴 **레포 전체 금지어 소거는 이 차수 밖**이다.

## §3 담당 절 — P0-4 🔴 **지시를 따르면 거짓 초록이 만들어진다**

**지금**(`CredentialsStatusController.cs`)
```
private CredentialCheck Probe(string envName, string configKey, string display)
    var env = Environment.GetEnvironmentVariable(envName);   // 화면이 지시하는 이름
    var cfg = _config[configKey];                            // 소비자가 실제로 읽는 키
    var v = !IsNullOrWhiteSpace(env) ? env : cfg;            // 🔴 둘 중 하나만 있으면 present
    ...  EnvName = envName                                   // 🔴 사람에게 보여주는 이름
```
화면은 `HITPAN_LICENSE_PEPPER` 를 넣으라 하고, 소비자 **11곳 / 8컨트롤러**는 `License:Pepper` 를 읽는다.
⇒ 🔴 **지시대로 넣으면 `env` 가 채워져 칸이 초록이 된다. 그런데 설치 경로는 그대로 500 이다.**
🟢 **정본 모양은 같은 파일에 이미 있다** — `ProbeSmtp("Smtp:Host", …)` 는 **설정키만** 받는다.

**할 일**
1. `Probe` 를 **설정키 1개**만 받게 바꾼다(`ProbeSmtp` 와 같은 모양). 🟢 종전 본문은 **주석으로 남긴다**(#1)
2. 화면에 보여줄 이름은 **설정키에서 기계적으로 만든다** — `License:Pepper` → `License__Pepper`. 🔴 **사람이 손으로 적은 이름을 쓰지 않는다**(그게 어긋남의 원인이었다)
3. 🔴 **`appsettings*.json` 무접촉**(#21) · 설정키 문자열은 **한 글자도 안 바꾼다**(소비자와 같아야 한다)

## 7-5 🔴 못 잰 것 (「됐다」고 말하지 않는다)

1. 🔴 **「닿는다」를 실물로 증명하지 못했다.** 게이트가 증명하는 것은 **「스크립트가 그 줄을 override 파일에 적는다」**까지다. 그 파일이 실제 서버에서 systemd 에 먹히는지는 **새 서버를 세워 봐야** 안다 ⇒ **사장님 손 7번 몫**
2. 🔴 **화면으로 안 쟀다.** `G-P0-4-*` 는 `Probe` 를 직접 불러 잰다. 화면이 그 값을 어떻게 그리는지는 **렌더 하네스가 0건**이라 여전히 못 잰다(별건 P2-2 · **3회차**)
3. 🔴 **운영 서버의 현재 override 파일은 안 봤다.** 이 차수는 **레포만** 고쳤다(#39)
4. 🟡 `ENV_SECRETS.md` 의 **`HITPAN_*` 이름들은 이 차수에서 다시 재지 않았다** — 「맞다」고 읽으면 안 된다. 문서에 그렇게 적었다
5. 🔴 **[4] 독립검증 0건** — 작성·구현·측정이 **전부 PM 한 사람**이다. SoD 가 깨져 있다
