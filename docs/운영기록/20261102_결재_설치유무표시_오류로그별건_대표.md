## 운영 읽기 결과 (읽기 전용 트랜잭션 · 1회 · 고객 값 0 · 변경 0 · #39)
- 🟢 대상 표 3개 존재 · 키 칸 문자 규칙 일치 · 고객 키 인덱스 있음. [1-V] F-1 의 운영 쪽 전제(표 없음 · 규칙 어긋남)는 해당 없다.
- 🟢 `is_locked_from_landing=1` · `bootstrap_at` 값 있는 행 0 — 코드 쓰기 0곳과 일치 · 지금 화면이 전 고객 「미설치」 인 까닭.
- 🟢 판정식 적용 시 「완료」 · 「설치 시작」 이 함께 나오고 어느 재료도 없는 행은 0. 건수는 공개 문서에 적지 않는다.
- 🟡 어느 고객이 어느 상태인지는 읽지 않았다. 판정식이 맞는지는 배포 뒤 대표 눈으로 대조한다.
