## 4. 무엇을 할 것인가 (범위)

### 해야 할 것
1. **1.2.41 시험 버전 게시** — 버전 차이를 만들어야 감지가 성립
2. **Windows Sandbox 에 1.2.40 설치** — 고객 PC 초기 상태 재현
3. **수신 전 구간 실측** — 감지 → 동의 팝업 → 백업 → 다운로드 → 서명검증 → 교체 → 재시작 → 버전확인
4. **끊긴 지점 기록** — 어디서 멈추는지가 이 작업의 진짜 산출물

### 하지 않을 것 (범위 밖)
- demo 운영 환경 조작 (헌법 #39)
- NCP 서버 설정 변경 (헌법 #29)
- 끊긴 지점 **즉석 봉합** — 발견은 기록만, 봉합은 별도 작업지시서

> ⚠️ **즉석 봉합 금지가 이 작업의 핵심 규율이다.** 7/20~23 두더지잡기가 그렇게 시작됐다.
