## 🔧 작업 단계

### Phase 1 — DDL 확장 + 해시 컬럼 추가 (30분)
```sql
ALTER TABLE partners
  MODIFY COLUMN biz_no VARCHAR(100) NULL,
  MODIFY COLUMN tel VARCHAR(100) NULL,
  MODIFY COLUMN fax VARCHAR(100) NULL,
  MODIFY COLUMN manager_tel VARCHAR(100) NULL,
  MODIFY COLUMN email VARCHAR(200) NULL,
  ADD COLUMN biz_no_hash CHAR(64) NULL AFTER biz_no,
  ADD INDEX idx_partners_biz_no_hash (biz_no_hash);
-- tenants, resellers, users, employees 동일 패턴
```

### Phase 2 — C# 마이그레이션 콘솔 유틸 작성 (1시간)

### Phase 3 — Entity Configuration 수정 (30분)
