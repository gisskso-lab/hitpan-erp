## 1. 🔴🔴 지금 **하면 안 되는 것** — 이것만 지켜라

### ① 서버에서 `scripts/deploy-ncp-secrets.sh` 를 손으로 돌리지 마라 (V-1)
- 그 적재기는 override 파일을 **먼저 비우고**, 비밀 파일에 모양 틀린 줄이 하나라도 있으면 `exit 1` 한다.
- `exit 1` 이 `chmod 600` · `chown root:root` · `systemctl daemon-reload` · `restart` **앞**이다.
- ⇒ **돌던 자격증명이 파괴되고**, 서비스는 메모리의 옛 값으로 계속 돌아 **당장 증상이 없다가 다음 재부팅에서 터진다.**
- 🔴 **이것은 작P0 이 만든 경로다.** 봉합 전에는 `exit 1` 이 없어 늘 chmod·restart 까지 갔다.
- 🟢 **지금 돌릴 이유도 없다** — 자격증명은 이미 서버에 있고 화면이 초록이다.
- 🟢 **자동 배포는 이 적재기를 부르지 않는다**(워크플로 등장 0회 · 레포 전체 자동 호출 경로 0건 — 실측). **배포는 막히지 않는다.**

### ② 토스 2칸을 초록으로 만들려고 값을 넣지 마라
베타는 결제가 없다. **빨강이 정상 상태**다. 값을 만들어 넣는 순간 거짓 초록이다.

### ③ 묵은 승인대기 배포 런을 승인하지 마라
현재 대기 런 **0건**. 뜨면 **반드시** 그 런의 SHA 와 `main` 의 **코드 차이**를 먼저 재라(`git diff --stat <sha> origin/main -- src/ installer/ .github/ scripts/`). 10/12 에 17시간 묵은 런이 승인돼 운영이 되돌려진 선례가 있다.

### ④ 그 외 상시 금지
`appsettings*.json` 수정 (#21) · 운영 직접 수술 (#39 — 사장님 손으로만) · `git add -A` · `HITPAN_GATE_SKIP_OK` · 자격증명 값·모양 기록(**가짜 값도 금지**) · 금지어 「박제·박다·박았다·박힘」 · 덮어쓰기 (#1 — 기존 줄은 주석으로 남긴다).

## 6. 🔴 전 세션이 밟은 함정 (같은 데 빠지지 마라)

1. 🔴 **`ProbeSmtp` 모양을 베끼고 소비자를 하나씩 확인하지 않아** 거짓 초록을 **거짓 빨강 4칸**으로 바꿨다. **정본 규칙: 칸은 소비자가 보는 자리를, 소비자와 같은 순서로 본다.** 🔴 그런데 **「없음」의 정의까지 맞춰야 한다**(V-2) — 그게 아직 안 됐다.
2. 🔴 **게이트가 소스를 정규식으로 긁으면 「변장한 글자 게이트」다.** 소비자 쪽 **주석 한 줄**만 남아도 영구 초록이 된다(T2). 음성 대조군이 성공해도 **운일 수 있다.**
3. 🔴 **환경에 끌리는 게이트는 게이트가 아니다.** 개발 PC 에 실제 환경변수가 있어 게이트가 빨개졌다. 🔴 **값을 비우는 것만으로는 부족하다 — 병렬 격리(collection)까지 넣어야 한다**(V-4).
4. 🔴 **「고쳤다」를 보고하기 전에 세라.** 「금지어 3곳 소거」가 **4곳**이었다(V-6).
5. 🔴 **같은 화면이 엔드포인트를 둘 부를 수 있다.** 한쪽만 고치고 끝낸 줄 알았다(V-5). **화면 파일에서 `http.Get` 을 전수 grep 하라.**
6. 🔴 **푸시는 원격 조회로 확인한다.** `git push --quiet` 가 조용히 실패한 적이 있다 — `git ls-remote` 로 확인.
7. 🔴 **머지 직전 PR 머리 SHA 를 다시 확인한다.** 10/11 에 API 가 5분간 옛 SHA 를 보고해 커밋 1개가 빠졌다.
8. 🔴 **이 환경의 `python` 은 스텁이다.** 파일 조작은 perl 또는 PowerShell. **고쳤으면 grep 으로 확인한 뒤** 돌려라 — 검증팀장이 이 함정에 걸려 **「13/13 통과」라는 거짓 측정**을 한 번 냈다.
9. 🔴 **Bash heredoc 이 긴 한글 문서에서 깨진다.** 문서는 Write 로 써라.
10. 🔴 **비밀스캔 「Scan secrets」 빨강 1개는 정상이다** — 새 브랜치 **첫 푸시**는 비교할 직전 커밋이 없어 **레포 역사 전체**를 스캔한다(역사에 116건). **PR 범위 스캔이 초록이면 내 작업은 깨끗하다.** 최근 40런 중 10/10 재현.
