> (이어서 · 10/6) "1. 백오피스에 cs기록 보관이나, cs기록을 통한 cs자동화 등의 cs관련 기능을 강화할것.
> 2. 개인정보 보호법, 보안 관련 한 법적분쟁이 생길 수 있는 이슈에 대해선 법무팀장, 보안상무의 피드백 필요"

- ⭐ **CS 강화 확정**: CS기록 보관 + CS기록을 통한 CS 자동화는 백오피스의 강화 대상(축소 설계 금지). 단 자동화의 지식원은 「챗봇 지식 직접 정의 · 외부 긁기 금지」(CS팀장 소관) · 본사 보유 필드는 보안·법무 한계선 안에서.
- ⭐ **법적 이슈 전담**: 개인정보보호법·보안 분쟁 소지는 **법무팀장 + 보안상무** 피드백을 받아야 설계 확정.

> (이어서 · 10/6) "사장이 미처 생각하지 못한 백오피스의 기능들에 대해 마음껏 피드백 하고 설계해줘"

- ⭐ **미인지 기능 설계 전권**: 하브루타가 찾은 미인지 항목 + 팀 제안 기능을 기능정의서에 **정식 기능으로 설계**한다(질문으로만 미루지 않음). 단 모든 제안 기능은 「제안」 표시 + 근거를 달고, 최종 채택은 사장님 보고 때 결재.

### 0-3. 산출물·결재 경로 (본오더 3~5항)
- 하브루타 토론(CS팀장 · ERP매니저 · 영업팀장 · 마케팅팀장) — 목적 = **사장님이 인지하지 못한 부분** 발굴 → **기능정의서**
- 산출물(전부 .md · `docs/설계/백오피스/` + 운영기록 링크): ① 사장님 요구사항정의서 ② 기능정의서 ③ DB명세서 ④ 아키텍처명세서
- 결재: PM 1차 → CTO·보안상무 2차 → **사장님 보고**
- 개발 착수부터는 기존 루틴 [2]설계 → [3]개발 ⟷ [3-V]·[4] 동시검증(#42 · WORKFLOW.md)
- 3시스템 연결(#35): ERP ↔ 랜딩 가입 시 영업정보 ↔ 백오피스가 한 흐름으로 이어지는 것이 1항 요구

> (이어서) "이게 계층관리의 정의임"

- ⭐⭐ **위 두 줄이 계층관리의 정의 전부다**(사장님 · 10/6) — 본사 안·대리점 안의 세부 계층을 PM·설계팀이 덧붙이지 않는다. 대리점 접근 범위 = 자기 영업현황·CS현황(정의에 없는 것을 대리점에 열지 않는다 · 필요하면 사장님께 여쭌다).
- ⭐⭐ **권한 두 갈래의 정의**(사장님 확정 · 10/6): **본사 = 마스터** — 모든 고객사 · 모든 대리점의 영업현황·CS현황을 보고 접근한다. **대리점 = 자기 것만** — 그 대리점에 해당하는 영업현황·CS현황만.
- ⭐⭐ **두 목적을 하나의 일관된 워크플로우로 잇는다**(따로 노는 두 줄기 아님) · **권한계층 = 본사 / 대리점 두 갈래**(사장님 확정 · 10/6).
- ⭐⭐ **백오피스 존재 이유 = 두 가지뿐**(사장님 확정 · 10/6): ① 본사·대리점의 **고객 구독관리 · 고객 CS관리 · 영업** ② 본사의 **대리점 실적 · 수수료 정산**. 이 둘에 닿지 않는 기능은 백오피스 범위가 아니다(넣으려면 사장님께 여쭌다).
- ⭐ **설계의 첫 축 = 백오피스 워크플로우 흐름**(사장님 지정). 7개 영역은 흐름 위에 얹는다 — 흐름이 서기 전에 화면·표·순위를 설계하지 않는다(ERP 6단계 워크플로우 #8·#20 과 같은 원리).
- 함께 열린 것: **S-2 백오피스가 대표 아이디·이메일을 받는 길**(결8 §4 · 사장님 10/5 「명심」 — 기억 메모 `project_backoffice_collects_owner_id_email`).
- 「등등」 = 위 7개가 전부가 아니다 ⇒ [1-V] 가 현재 백오피스에 이미 있는 영역을 전수로 세고, 7개 밖 영역은 **목록으로만** 올려 사장님께 넣을지 여쭌다(PM 이 범위를 정하지 않는다).
- 호출 명단(사장님 지정): **ERP 매니저 · 기술영업팀장 · CS팀장 강지원 · 마케팅팀장 · AI수석**. 설계 [2] 는 설계팀장 존, [1-V] 는 검증팀장 데이비드 박.

## 0-1. PM 이 아직 모르는 것 (설계 전에 사장님께 여쭐 후보 — [1-V] 사실을 본 뒤 확정)
- 「결재과금」 = 결제·과금(구독 결제 · 계정 과금 · 대리점 정산)으로 읽었다 ⚠️해석 — 「결재(승인 절차)」 뜻이 섞였는지.
- 「권한계층」 = 백오피스 사용자 계층(본사 오너 · 본사 직원 · 대리점 · 대리점 직원 …)으로 읽었다 ⚠️해석 — ERP 안 권한(#7·#38)과 섞지 않는다.
