## 1. 오더를 이렇게 이해했다 (명문화)
- 두 모드는 "덮어쓰기 = 초기화 후 이관 / 병합 = 있는 건 두고 보탬" 이고, 병합은 **두 번 돌려도 같은 값**이어야 한다. 지금은 계산서 21쌍이 실행마다 승자가 바뀐다(선행검증 §2-4) — 이걸 먼저 닫아야 병합이 선다.
- 속도·안정 = 1단계(마스터) 끝나면 ERP 를 쓰게 하고(5/16 사장님 문안 다이얼로그), 2단계는 끊겨도 **이어서**(체크포인트).
- 편리 = 경로 붙여넣기(있음) + **찾아보기**(서버측 탐색 · 브라우저는 PC 경로를 못 읽는다). 업로드는 Q2.
- 대사표 정답 칸은 사장님 확인대로 **ERP 화면 식을 레거시 데이터에** — 미리 계산해 보니 ⑤ 0 차 · ⑧ +1.48M · ⑨ +50K 로 전부 원인이 적힌다(선행검증 §2-6).
- DOCME 242,106행은 **(사원,날짜) 9,170묶음 = 일일보고서 9,167장**(연도 0000 3행 제외) · 작성자 매칭 99.85% · 새 표·메뉴 없음.
- **실측 근거**(헌법 #32): 선행검증서 §2 전항 — MDB 읽기 전용 직독 + `hitpan_e2e` + 코드 줄 번호.
