## §4 함정 — 이 트랙에서 밟을 것

1. 🔴 **메뉴 이동은 가드와 함께 옮긴다**(결-B). 가드를 두고 링크만 옮기면 직원 화면에 업데이트·되돌리기가 뜬다 — 권한 사고다.
2. 🔴 **업데이트 2종 메뉴에는 이미 게이트가 걸려 있다**(`src/HitPan.Tests/LocalSwapUi/LocalSwapUiGateTests.cs`). 자리를 옮기면 그 게이트부터 본다.
3. 🔴 **칸·주소를 바꿔 끼우지 말고 더한다**(#1). 작1 은 한 화면을 둘로 가르는 일이라 옛 주소 `/support/cs` 를 죽이지 않는다.
4. 🔴 **렌더 하네스가 0건이다.** 화면 칸이 갈라졌는지는 사람만 안다 — 작1 끝에 **사장님 실측 항목표**를 올린다.
5. 🔴 **CS 묶음만 돌리지 말고 전체 회귀를 돌린다.** 10/13 에 이웃 3건을 CI 가 잡았다.
6. 🔴 **마이그가 고객 DB 에 적용돼 있나를 먼저 잰다.** `origin` 칸이 없으면 본사공지사항 화면이 빈 채로 선다.
7. 🔴 **게시 때 새 마이그가 있으면 마이그 켜기**(작3 ⓑ). 안 켜면 워치독이 업데이트를 강제 중단한다(1.2.63 전례).
