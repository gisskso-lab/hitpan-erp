## §1. 절 A — §4-2 「CI 에서 실제로 돈 흔적」 (담당 [3] → [4])

### A-1. 전제 (선행검증서 §2)

- 🔴 **F-1**: `Build & Test` 는 `feat/20260920-rc-safe-path` 에서 **0회**. 트리거가 `develop/main` 전용이다.
- 🟢 **F-2**: CI 로그는 `Passed <FQN>.<시험명> [n ms]` 형태로 **시험 이름을 찍는다.**
- 🔴 **F-3**: `build` 잡 로그는 증거가 **아니다**(무필터 전수 → DB 없으면 `[SKIP]` 초록).

### A-2. 지시

1. **draft PR 을 연다** — base `main` · head `feat/20260920-rc-safe-path`.
   - 🔴 **제목·본문에 「머지 금지 사유」를 명시**한다. PR 은 **계측 장치**다.
   - 🔴 **draft 로 연다** — 초록이 떠도 실수로 못 누른다.
2. `Build & Test` 완료를 기다린다(과거 실측 4m51s~5m52s).
3. **로그를 내려받아 판정한다** — `gh run view <id> --log`.

### A-3. 판정 조건 (**4개 전부** 성립해야 닫힌다)

| 조건 | 재는 법 | 빠뜨리면 |
|---|---|---|
| **V-1** | `Build & Test` conclusion = **success** | — |
| **V-2** 🔴 | **`DB 게이트` 스텝 안**에 `Passed …RcLockRatioGateTests.…` **4줄** | `build` 잡에서 세면 SKIP 을 통과로 셈 (F-3) |
| **V-3** | 같은 스텝 `[SKIP]` **0건** (기존 가드 스텝 초록) | 돌았으나 건너뛴 것을 못 거름 |
| **V-4** 🔴 | **대조**: 같은 로그에 **옛 필터 게이트**(`RcSafePathGate…`)도 뜬다 | 「새 줄만 됐다」와 「필터 전체가 산다」를 못 가름 |

🔴 **`Passed` 를 센다. 이름을 세지 않는다** (9/21 에 낱말만 세고 두 번 틀림).
🔴 **회차를 숫자로 병기**한다 — 「4/4 초록」 같은 1회 관측 일반화 금지 (함정 §6-5).

### A-4. 빨간불이면

- V-1 실패(빌드·시험 깨짐) → **봉합 대상이 아니다.** 실패 목록을 **별건 A·B 기존 5건과 대조**해 「이번 PR 이 만든 것 0건」부터 가른다(함정 §6-9: 격리 실행 → 이전 커밋 대조).

## §3. 절 C — §4-3 C-C2 L5 실제 막힘 지속시간 (담당 [3] → 사장님 재보고)

### C-1. 사실관계

- 사장님이 **수용을 결재**하셨다. 그러나 CTO 가 **「수용의 재료가 없다」**고 지적했다.
- 🔴 **함정 §6-2**: 「여유 26배」는 **다른 두 양을 나눈 수**였다. 막힘 판정은 **오류번호 1205·1213** 으로만 정해지고 **소요 ms 는 판정에 안 쓰인다.** 3,000ms 는 **잠금 대기 상한**이지 수행시간 상한이 아니다.

### C-2. 지시

1. 시험 인스턴스를 **먼저 확인**한다(33306 안전 · 33406 STATEMENT) — ⚠️ **세션마다 꺼진다.**
2. **인위 25초가 아니라 실제 L5 트랜잭션이 잠금을 쥐고 있는 시간**을 잰다.
3. 🔴 **판정은 오류번호로 한다** — `1205`(lock wait timeout) · `1213`(deadlock). **ms 로 판정하지 않는다.**
4. 🔴 **비결정적 교착(1213)** 을 반드시 함께 본다 — 함정 §6-3: **PM 도 [4] 도 그 번호를 한 번도 안 꺼냈다.**
5. **회차를 숫자로 병기**한다(n회 중 m회). 1회 관측 일반화 금지.
6. 결과를 **사장님 재보고**로 올린다 — 수용을 뒤집자는 게 아니라 **재료를 채우는 것**이다.

### C-3. 이 절의 산출물

`docs/검증/선행/20260922_계측_CC2_L5_막힘지속_실측.md` (⚠️ 못 잰 축은 **⛔ 로 명시**)
