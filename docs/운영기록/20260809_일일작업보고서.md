### 3-1. 원인 — 닭과 달걀

오늘 이 게이트를 *"차단 → 경고 후 통과"* 로 고쳤는데,

> **새 규칙을 받으려면 옛 규칙을 통과해야 하는데,

### 3-2. PM 이 무엇을 놓쳤나

게시 전 게이트를 **로컬에서 전부 미리 돌렸다** — migsmoke·시드정합·컬럼·권한정합·빌드·테스트.
**전부 초록이었다.** 그런데 정작 중요한 하나를 안 봤다:

> ⚠️ **"지금 고객 PC 에 깔린 버전이 이 패키지를 어떻게 볼 것인가"**

**CI 게이트는 만드는 쪽을 검사한다. 이 결함은 받는 쪽에 있었다.**
빌드가 아무리 초록이어도 잡히지 않는 자리다.

⇒ 메모리에 *"고쳤다 ≠ 고객에게 갔다"* **4차 재발**로 기록.

## 4. 계정관리 전수 봉합 — ①~⑥

사장님이 *"60분 기다리기만 하기 뭐하니"* 하시며 여신 작업이다. 9화면 전수조사 결과:

> **끊긴 것은 경로가 아니라 데이터 계약이었다.**
> 화면·API·DB 는 다 있는데, 서로 다른 약속을 쓰고 있었다.

### 4-1. ① 권한이 안 먹던 진범 🔴

프론트가 메뉴 코드를 **하드코딩 15개**로 갖고 있는데 백엔드는 **20개**였고, **4개가 아예 달랐다.**

| 프론트 | 백엔드 |
|---|---|
| `ITEM_MASTER` | `ITEM` |
| `PARTNER_MASTER` | `PARTNER` |
| `PURCHASE_RECEIPT` | `PURCHASE` |
| `RETURN` | **없음** |

체크하고 저장하면 **"저장됐습니다"가 떴다.** 그런데 권한 조회는 `ITEM` 으로 하므로 **항상 0건**이었다.
즉 **권한 설정 화면이 그동안 아무 일도 하지 않았다.**

**재발 방지** — CI 게이트 `scripts/check-permission-menu-sync.sh` 신설.
프론트·백엔드 코드 집합을 비교해 다르면 빌드를 세운다.
**돌연변이 시험으로 실효 증명**: `ITEM` → `ITEM_MASTER` 로 되돌리자 exit=1 로 정확히 잡았다.

### 4-2. ② 실패를 "0건"으로 위장하던 것

조회가 **실패**했는데 화면은 *"데이터가 없습니다"* 라고 말했다. 5화면 + **빈 catch 24곳**.

`LoadFailedState` 공통 컴포넌트 신설 — **"못 불러왔다"(주황·재시도 버튼)** 와
**"0건이다"(회색)** 를 눈으로 구분한다.

### 4-3. ③ 설정이 조용히 초기화되던 P0 🔴

사용환경설정 조회가 실패하면 **하드코딩 기본값**을 진짜 설정처럼 보여줬다.
거기서 [저장]을 누르면 **27개 컬럼이 통째로 덮어써져** 단가 배율·여신 한도·마이너스 재고 정책이
전부 초기화됐다. **되돌릴 수 없다.**

⇒ 조회 실패 시 **화면을 아예 그리지 않는다.**

### 4-4. ⑤ 사장님 지적 3건

| 지적 | 진짜 원인 | 조치 |

## 5. 고리5 — DB 마이그 자동 적용 (사장님 승인 후 즉시 구현)

| 승인 조건 (사장님 문안 그대로) | 구현 |
|---|---|
| ERP 켜질 때 미적용 컬럼 자동 추가 | ✅ `Program.cs` 기동 시 `ApplyPendingAsync` |

| 실패하면 거기서 멈추고 무엇이 실패했는지 알림 | ✅ 실패 지점 정지 + `success=0` 기록 |
| 워치독 업데이트 전 자동 백업이 안전망 | ✅ 기존 백업 유지 |

|---|---|---|

| 2 | 재적용 | 🟢 DB-85 적용 · 55 → 56건 |
| 3 | 멱등 | 🟢 재기동해도 **0건 적용** · 중복 0 |

### 5-2. 1차 실패가 값졌다 — 안전 설계가 증명됐다

DB-02 에서 멈췄다(`Duplicate column name`). 개발 PC DB 가 clean DDL 시드 이전 것이라 생긴 일이다.
**그런데 그 덕분에 확인됐다** — 실패 지점에서 정지, `success=0` 기록,
**나머지 83건은 손대지 않음**. 설계대로였다.

### 5-3. 🔴 그 과정에서 PM 이 놓친 것 하나를 잡았다

### 9-1. 2번이 왜 중요한가

### 9-3. 3번 — 왜 반쪽인가

저장만 되고 출력에 안 찍히면 **여전히 반쪽**이다.
