# WS-20260515-07 — 방화벽 규칙 3개 자동 등록 (UDP 7844 + TCP 3306 + TCP 5257)

> **마감:** 5/18 23:59

## 1. 목적

설치 EXE가 관리자 권한으로 방화벽 규칙 3개 자동 등록. 사용자가 방화벽 알림 클릭할 필요 0 (헌법 #25 쉽게). 잘못된 클릭으로 통신 차단 가능성 0.

## 2. 등록 규칙 3개

| 포트 | 방향 | 프로토콜 | 프로세스 | 사유 |
|---|---|---|---|---|
| UDP 7844 | Outbound | UDP | cloudflared.exe | Cloudflare 터널 (QUIC) |
| TCP 3306 | Inbound (localhost only) | TCP | mysqld.exe | MariaDB 로컬 접속 |
| TCP 5257 | Inbound (localhost + LAN) | TCP | HitPan.API.exe | ERP API |

## 3. PowerShell 자동 등록

```powershell
# 1. cloudflared QUIC outbound
New-NetFirewallRule -DisplayName "HitPan cloudflared QUIC outbound" `
    -Direction Outbound -Protocol UDP -RemotePort 7844 `
    -Program "C:\cloudflared\cloudflared.exe" `
    -Action Allow -Profile Any

# 2. MariaDB localhost inbound
New-NetFirewallRule -DisplayName "HitPan MariaDB localhost inbound" `
    -Direction Inbound -Protocol TCP -LocalPort 3306 `
    -Program "C:\Program Files\MariaDB 11.4\bin\mysqld.exe" `
    -RemoteAddress LocalSubnet `
    -Action Allow -Profile Domain,Private

# 3. HitPan API inbound (LAN 공유 옵션 고려)
New-NetFirewallRule -DisplayName "HitPan ERP API inbound" `
    -Direction Inbound -Protocol TCP -LocalPort 5257 `
    -Program "C:\Program Files\HitPan\HitPan.API.exe" `
    -Action Allow -Profile Domain,Private
```

## 4. C# 통합 (설치 EXE)

```csharp
public static class FirewallRules {
    private static readonly (string Name, string Cmd)[] Rules = {
        ("HitPan cloudflared QUIC outbound",
         @"New-NetFirewallRule -DisplayName 'HitPan cloudflared QUIC outbound' " +
         @"-Direction Outbound -Protocol UDP -RemotePort 7844 " +
         @"-Program 'C:\cloudflared\cloudflared.exe' -Action Allow -Profile Any"),

        ("HitPan MariaDB localhost inbound",
         @"New-NetFirewallRule -DisplayName 'HitPan MariaDB localhost inbound' " +
         @"-Direction Inbound -Protocol TCP -LocalPort 3306 " +
         @"-Program 'C:\Program Files\MariaDB 11.4\bin\mysqld.exe' " +
         @"-RemoteAddress LocalSubnet -Action Allow -Profile Domain,Private"),

        ("HitPan ERP API inbound",
         @"New-NetFirewallRule -DisplayName 'HitPan ERP API inbound' " +
         @"-Direction Inbound -Protocol TCP -LocalPort 5257 " +
         @"-Program 'C:\Program Files\HitPan\HitPan.API.exe' " +
         @"-Action Allow -Profile Domain,Private"),
    };

    public static async Task ApplyAllAsync() {
        foreach (var (name, cmd) in Rules) {
            // 멱등성 — 기존 규칙 삭제 후 재생성
            var removeCmd = $"Remove-NetFirewallRule -DisplayName '{name}' -ErrorAction SilentlyContinue";
            await RunPowerShellAsync(removeCmd);
            await RunPowerShellAsync(cmd);
        }
    }

    private static async Task RunPowerShellAsync(string command) {
        var psi = new ProcessStartInfo("powershell.exe",
            $"-NoProfile -NonInteractive -ExecutionPolicy Bypass -Command \"{command}\"") {
            UseShellExecute = false,
            Verb = "runas",
        };
        using var proc = Process.Start(psi)!;
        await proc.WaitForExitAsync();
    }
}
```

## 5. 헌법 정합

| 헌법 | 정합 방식 |
|---|---|
| #25 쉽게 | 사용자 방화벽 클릭 0회 |
| #27 통신 무결성 | UDP 7844 (cloudflared) 보장 |
| #29 사전 승인제 | 설치 시점 1회 결재 = 봉합 권한 사전 등록 |
| #31 OS 보안 호환 | Defender Firewall + 제3자 방화벽 호환 |

## 6. 검증 게이트

| 게이트 | 통과 조건 |
|---|---|
| Get-NetFirewallRule | 3건 모두 Enabled |
| cloudflared 외부 통신 | UDP 7844 정상 |
| MariaDB localhost 접속 | TCP 3306 정상 |
| API 접속 | TCP 5257 정상 |
| 멱등성 | 재실행 시 중복 규칙 0건 |
| 제3자 방화벽 (NPKI·V3 등) | 별도 가이드 (WS-08과 연계) |

## 7. 제3자 방화벽 대응

V3 Lite, 알약, Norton 등은 자체 방화벽 보유. 본 작업지시서는 Windows Defender Firewall만 자동 등록. 제3자 방화벽은 WS-08 (백신 격리 감지) + WS-12 (1클릭 봉합 UI) 에서 사용자 가이드 제공.
