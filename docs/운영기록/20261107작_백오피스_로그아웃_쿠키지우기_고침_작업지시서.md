## §8 [HQA 관문 ②] 운영 백오피스 (배포 뒤)
### §8-1 무엇을 보나
- 로그인 없이 볼 수 있는 것만 HQA 가 직접: ① 로그인 화면 HTML 에 숨은 폼 `bo-signout-form` · 토큰 칸(값 길이 > 0 · 값은 적지 않음) 있음 = 배포본에 고침이 실렸다 ② 쿠키 없이 보호 주소 → 302.

### §8-2 허용 동작 규칙

- **허용**: 로그인 화면 열기 · 보호 주소 GET · 대표 본인 계정 로그인 · 로그아웃 · 뒤로 가기 · 새 탭 · 브라우저 쿠키 목록 보기.

## [3] 3회차 지시 — [4] 2회차 반려 뒤 (11/8 · PM 결재)
> 근거 = [작업리뷰서 2회차](../검증/백오피스/20261107_작업리뷰서_백오피스로그아웃.md) 「2회차」 절. 그 밖 칸(①가 · ①나1 · ①나2 · ② · ②b · ②c · D5 · D5x · D5y · L)은 F6 유무 둘 다 🟢.

### 무엇이 문제였나 (PM 원문 대조 · 받아쓰기 아님)
- `BackofficeAuthController.SignOutAsync` 의 「로그인 상태 아님」 갈래가 **무조건** `HttpContext.SignOutAsync` 를 부른다 → 응답에 인증 쿠키 지우기(`Set-Cookie: hitpan_bo=; expires=과거`)가 실린다.
- `Program.cs` 쿠키 설정 `o.Cookie.SameSite = SameSiteMode.Lax` → **다른 사이트**에서 올라온 POST 에는 브라우저가 인증 쿠키를 **안 싣는다**. 그래서 로그인한 사람이 외부 사이트의 숨은 폼에 걸리면 서버에는 「로그인 상태 아님」 으로 보인다.
- SameSite 는 **보내기만** 막고 **받기는 막지 않는다** → 브라우저는 그 응답의 지우기를 적용 → 로그인한 사람의 쿠키가 0 = **로그아웃 위조**. 1회차 · main 은 이 갈래가 없어 쿠키가 남았다 → **2회차가 새로 연 구멍**. 운영에는 2회차가 배포되지 않았다(운영 노출 0).

### 근본원인 (두 겹)
1. **PM 지시의 틀린 전제** — 2회차 지시 ① 에 PM 이 「쿠키 지우기 시도는 무해 · 다른 출처가 눌러도 잃을 것 0」 이라고 확인 없이 적었다. 「서버에 비로그인으로 보이는 요청」 = 「실제로 비로그인인 사람」 이라고 가정했는데, Lax 아래에서는 다른 사이트 요청이 **로그인한 사람도 비로그인으로 보이게** 만든다. 그 전제를 [3] 이 그대로 코드 주석에 옮겼다(「다른 출처가 눌러도 잃을 것 0」).
2. **게이트 빈칸** — D5 의 「다른 출처 POST 는 쿠키를 남김」 을 1회차는 **같은 사이트(포트만 다름)** 로만 쟀다. 같은 사이트 POST 에는 쿠키가 실리므로 이 갈래를 타지 않는다. 「다른 출처」 와 「다른 사이트」 를 한 칸으로 묶어 잰 것이 빈칸이었다.

### 봉합 방향 (PM 결재)
- 「로그인 상태 아님」 갈래의 `HttpContext.SignOutAsync` 는 **요청에 인증 쿠키가 실제로 실렸을 때만** 부른다. 쿠키 이름은 글자로 박지 말고 쿠키 인증 설정에서 읽는다(`IOptionsMonitor<CookieAuthenticationOptions>.Get(CookieAuthenticationDefaults.AuthenticationScheme).Cookie.Name`).
  - 쿠키가 실렸는데 로그인 상태가 아님 = 토큰 만료로 `OnValidatePrincipal` 이 거절했거나(이미 지움 · 두 번 지워도 무해) 풀 수 없는 쿠키 → 지우는 것이 맞다.
  - 쿠키가 안 실림 = 지울 것이 이 요청 안에 없다 → 지우기 응답 0 → 다른 사이트 POST 가 로그인한 사람의 쿠키를 지울 수 없다.
- 대안 「갈래에서 지우기를 아예 뺀다」 는 풀 수 없는 쿠키(키 바뀜 등)가 남는다 → 차선으로 기각.
- 쪼개진 쿠키(`ChunkingCookieManager` — 큰 쿠키는 `이름` + `이름C1…`): 기본 이름 칸이 늘 함께 간다고 **추정** → [3-V] 가 프레임워크 원문으로 확인한다.
- 코드 주석의 틀린 문장(「다른 출처가 눌러도 잃을 것 0」)은 #1 에 따라 지우지 말고 「⬛ 옛 주석(2회차) — 거짓으로 판명([4] 2회차 X)」 으로 표시하고 옆에 바른 이유를 적는다.
- 고칠 파일 = `BackofficeAuthController.cs` 한 곳 · 그 밖 diff 0 · 빈 catch 금지 · 옛 줄 주석 보존.

### D5 계약 문구 정정
- D5 「다른 출처 POST 는 쿠키를 남김」 은 이제부터 **같은 사이트 다른 출처**와 **다른 사이트** 두 칸으로 따로 잰다.
