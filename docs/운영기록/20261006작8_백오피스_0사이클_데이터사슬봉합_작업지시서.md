### 7-1. 안 선택 — ⓑ 두 파일 본문을 「ERP no-op」 으로 (1안)
- DB-39·DB-60 **파일·번호·이름은 그대로**(#41 지우지 않음), 본문만 「본사 전용 — ERP 에선 아무것도 안 한다」 주석 + `SELECT 1` 로.
- ⓑ 의 단점(「백오피스가 이 파일을 참조하나」)은 해소된 사실: 백오피스 DDL 진실원 = `installer/backoffice/*.sql` + SchemaMigrator(선행검증 A-⑤·C-⑤) — ERP 폴더의 두 파일은 백오피스 구축 경로가 아니다.
- 효과: 옛 DB 는 no-op 실행 → success=1 → **중단됐던 체인(DB-70~137)이 이어진다**. 기존 적용 DB 는 러너가 checksum 을 비교하지 않아(선행검증 §1 실측) 영향 0.
- 2안 ⓒ(러너 제외 규칙)는 제품 코드 수정 + 목록 관리 부담 — 1안이 막히면 재상정.
- ⚠️ **「배포된 마이그 본문 불변」 관행의 예외** — 위 근거(checksum 미비교 실측)로만 성립. 이 예외 자체가 결재 대상.
