## 0. 준비 — 계정 2개

메신저는 **계정 있는 사원끼리만** 된다(사장님 결재 2026-08-12).
지금 계정은 마스터 하나뿐이므로, 실측 전에 **직원 계정 2개**를 만들어야 한다.

```
설정 → 사원관리 → 직원 2명에게 계정 발급 (예: 김대리 · 박과장)
```

⚠️ 부서는 안 만들어도 된다. **1:1·단체는 부서와 무관하게 된다**(사장님: *"부서는 고객사가 설정할 일"*).
부서방만 부서를 만든 뒤에 생긴다.

## 1. 🔴 먼저 볼 것 — 한 번도 안 돌던 자리 3곳

코드리뷰가 잡은 결함이다. **여기가 열리면 봉합이 진짜다.**

| # | 어디서 | 눌러볼 것 | 되어야 하는 것 |
|---|---|---|---|
| **1-1** | HR → 휴직 관리 | 휴직 하나 **저장** | ✅ 저장됨 (전에는 100% 실패) |
| **1-2** | 메신저 → 📎 → **경비** | 목록이 뜨나 | ✅ 목록 (전에는 500) |
| **1-3** | 메신저 → 📎 → **업무보고서** | 목록이 뜨나 | ✅ 목록 (전에는 500) |

⇒ 하나라도 오류가 나면 **거기서 멈추고 알려주십시오.** 나머지는 볼 필요가 없습니다.

## 2. 메신저 — 사장님이 지시하신 것들

### 2-1. 대화 3종

| 볼 것 | 되어야 하는 것 |
|---|---|
| 새 대화 → **1:1** → 상대 고르기 | 방이 열리고 대화가 됨 |
| 새 대화 → **단체** → 여러 명 + 이름 | 방이 열림 |
| 새 대화 → **부서** (부서 0건일 때) | *"부서를 먼저 만들어 주세요"* 안내 — **오류가 아님** |

### 2-2. 🔴 읽음 — 사장님 지시

```
A 가 보냄 → B 가 대화방을 엶 → A 화면에 "읽음" 이 뜨나
```

| 방 | 표시 |
|---|---|
| 1:1 | **읽음** |
| 단체·부서 | **읽은 사람 수 숫자** (예: `2`) |

⚠️ 보낸 사람은 안 센다 — 아무도 안 읽었으면 **아무 표시도 없어야** 한다(`1` 이 뜨면 결함).

### 2-3. 🔴 문서 연결 — 사장님이 쓰신 문구 그대로

```
📎 → 연차신청서 고르기 → 전송
```

받은 쪽 화면에 이렇게 떠야 한다:

```
[결재]  "연차신청서" 를 전송하였습니다.
        클릭하시면 연차신청서 결재와 연결됩니다.
```

**눌렀을 때** → 그 문서 화면으로 **이동**해야 한다.

⚠️ 메신저에서 문서를 **만드는** 버튼은 없다. 그건 사장님이 자르신 범위다
(*"생성해서 만들고 결재까지 기능을 넣을 필요까진 없음"*).

### 2-4. 🔴 결재 결과가 신청자에게 돌아오나 — 이번 단계의 핵심

```
A(직원)  연차 신청 → 상신
B(결재자) 승인 또는 반려
   ↓
A 의 메신저에 메시지가 와야 한다
```

와야 하는 문구:

```
[결재]  "연차신청서" 가 승인되었습니다.
        클릭하시면 연차신청서 결재와 연결됩니다.
```

반려면 *"반려되었습니다."*

| 확인 | 되어야 하는 것 |
|---|---|
| 누가 보낸 것으로 뜨나 | **결재한 사람 이름**(봇 이름 아님) |
| 어느 방에 오나 | 결재자 ↔ 신청자 **1:1 방** (없으면 새로 열림) |
| 딱지 | `[결재]` — 사람이 쓴 말은 `[메시지]` |
| 알림도 같이 오나 | ❌ **메시지 하나만** (두 번 오면 결함) |

### 2-5. 파일

| 볼 것 | 되어야 하는 것 |
|---|---|
| 엑셀·이미지 보내기 | ✅ 감 |
| 받는 쪽에서 내려받기 | ✅ 열림 |
| **20MB 넘는 파일** | ⛔ *"파일은 20MB 까지 보낼 수 있습니다"* |
| **`.exe` 파일** | ⛔ *"프로그램 파일은 보낼 수 없습니다"* |
| `.exe` 를 `.xlsx` 로 **이름만 바꿔서** | ⛔ 그래도 막혀야 함 |

## 3. 🔴 권한 — 남의 것이 보이면 안 된다

| 시나리오 | 되어야 하는 것 |
|---|---|
| A 가 B·C 의 1:1 방 주소를 직접 침 | ⛔ 막힘 |
| **부모계정(사장)이** 남의 1:1 방 주소를 침 | ⛔ **막힘** (사장님이 *"본인 대화만 열람"* 을 고르심) |
| 일반 직원이 **남의 급여**를 첨부하려 함 | ⛔ 목록에 안 뜸 |
| 일반 직원이 📎 → 경비 | ⛔ **자기 경비만** (전에는 회사 전체가 보였음) |

---

## 4. 다른 단계도 함께

| 단계 | 볼 것 |
|---|---|
| 4 부서 | 부서 만들기 → 사원에 배정 |
| 5 연차 | 연차 부여 → **제안값이 뜨고, 고칠 수 있나** |
| 6 휴직 | §1-1 + 취소했을 때 **사원이 재직으로 돌아오나** |
| 7 경비 | 경비 신청 → 결재 |
| 8 급여 | 급여 등록 → **직원은 자기 것만 보이나** |

⚠️ **연차·급여 숫자는 우리가 판정하지 않는다.** 제안이 뜨고 담당자가 고치면 그게 정답이다
(사장님: *"고객사가 입력한 값만 우리는 처리해 주면 되는걸로"*).
