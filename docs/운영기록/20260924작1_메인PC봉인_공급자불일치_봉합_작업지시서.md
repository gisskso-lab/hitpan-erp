## §1 절A — 봉인/해제 공급자 + 키 분리

### §1-1 신규 파일

`src/HitPan.Application/Services/Security/MainPcSealService.cs` · `IMainPcSealService`

| 멤버 | 계약 |
|---|---|
| `byte[] Seal(byte[] raw)` | 갈래를 **재서** 고르고 그 공급자로 봉인 → 봉투를 씌워 반환 |
| `MainPcUnsealResult Unseal(byte[] envelope)` | 매직 확인 → 갈래 읽기 → **공급자를 명시해** 해제 |
| `bool IsPlatformKspUsable()` | 임시 키 이름으로 `CngKey.Create(..., MicrosoftPlatformCryptoProvider)` 를 **실제로 시도**하고 성공하면 즉시 삭제 |

`MainPcUnsealResult` = `Status` (`Ok` / `LegacyFormat` / `NotThisPc`) + `Key`(Ok 일 때만).
🔴 `Unseal` 은 **예외를 밖으로 던지지 않는다.** 상태로 답한다 — 지금 예외가 `DifferentPc` 로 위장되는 통로(`MainPcProofService.cs:137-146`)를 끊는다.

### §1-2 봉투 포맷

```
[0..3] 'H' 'P' 'M' '1'
[4]    갈래  'P'=Platform(TPM) · 'L'=DPAPI LocalMachine · 'U'=DPAPI CurrentUser
[5..]  본문  그 갈래가 만든 바이트 그대로
```

- 매직 불일치 · 길이 5 미만 → `LegacyFormat`. **해제를 시도하지 않는다**(TPM 접근 0회).
- 갈래 문자가 말하는 방법 **하나만** 쓴다. 실패해도 **다른 방법으로 폴백하지 않는다** → `NotThisPc`.

### §1-3 키 이름

- 🔴 생성자에 **키 이름을 주입할 수 있게** 둔다(기본값 = 위 상수). 게이트가 실물을 안 덮고 진짜 왕복을 도는 **유일한 통로**다.

## §3 절C · 절D — 출입증이 끊기는 자리

### §3-1 절C — 403 `main_pc_only` 1회 자동 재왕복 (주 봉합)

대상: `src/HitPan.Web/Services/HitPanApiAuthHandler.cs` — `:54` 의 **401 재시도 바로 옆**에 같은 모양으로 더한다.

- #15 — 빈 catch 금지. 최소 `LogDebug(ex, ...)` 한 줄.
- 🟢 이 절 하나가 **경주(C-3) · 30분 만료(C-5) · SPA 이동 중 만료**를 함께 덮는다.

### 🔴 PM 이 닫는다 — O-3 (TPM 없는 PC 의 봉인 갈래)

**결정: 봉인에 `U`(DPAPI CurrentUser) 갈래를 쓰지 않는다. `P` 또는 `L` 만이다.**

- **왜**: `U` 로 봉인하면 **지금 사고와 똑같은 모양**이 된다 — 그 순간엔 성공으로 보이고, 프로필이 바뀌는 **나중에 조용히 못 푼다.** API 는 SYSTEM 으로 돈다. 🔴 **조용히 나중에 터지는 경로를 새로 만들지 마라.**
- **왜 안전한가**: `L`(DPAPI LocalMachine)은 **TPM 이 없어도 된다.** 설계가 걱정한 *"TPM 없는 고객이 등록 자체를 못 한다"* 는 `L` 이 받는다. `U` 까지 내려가는 건 `L` 마저 실패하는 **비정상 상황**이다.
- **그때는**: 봉인 실패로 처리하고 **등록을 거절하되, 화면이 사유를 말한다.** 🚨 **막다른 방을 만들지 마라**(8/16 P0 전례) — 재시도 경로를 반드시 남긴다.
- 🔴 **게이트로 굳혀라**: `U` 갈래로 봉인이 만들어지지 않는지 묻는 게이트를 **G-23 에 한 줄 덧붙인다**(봉투 `[4]` 가 `U` 인 값은 **봉인 쪽에서 생성되지 않는다**). 해제 쪽은 옛 값 호환을 위해 `U` 를 **읽을 수만** 있게 둔다(#1).
