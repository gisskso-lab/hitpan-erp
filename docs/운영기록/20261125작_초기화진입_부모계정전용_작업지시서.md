## §1 [오더] 결재 원문 · 이해

> §144 대표(2026-11-25 16:4x) — 「진입문제 고치는 작업은 따로 세워.」
> §146 대표(17:0x) — Q1 **「초기화만」**: 초기화 한 곳 부모계정 전용(자료이관 덮어쓰기는 같은 서비스라 함께 닫힘) · 나머지 「관리자면 통과」 목록은 별건 등재 / Q2 **「막고 안내」**: 초기화 막고 대표 계정 확인 안내 · 테스트 환경에서 실제 행 수 잼
> §145 PM — Q3 메뉴 감춤(추천 · 설계 입력) · Q4 #38 어긋남은 이번과 분리 · 확인 문구 서버 검사는 같은 서비스라 함께 다룰지 설계가 안을 냄

- 이해: 「대표 계정」 = `users.is_parent = 1` 인 행(1V §2 · 헌법 #40 :262-265 「설치마법사에서 만든 로컬 계정」). account_type 은 자식 관리자도 `tenant_admin` 이라 가르지 못한다(1V §1 · #38 :210-215 와 코드 어긋남 — 고치지 않음 · Q4 별건).
- 안 하면: 관리자 역할 자식 계정이 메인 PC 에서 **자기 비번으로** 회사 장부 전체를 지운다(화면 · API · 서비스 3층 통과 · 6/23 첫 구현부터 · 1V §0).
- 대표 결재가 다시 필요한 자리 = Q1(안내 문구 뒤 실제 고치는 길) 하나만 후보(§13) — 나머지는 §146 원문 안.
