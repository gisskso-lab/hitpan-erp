## §5 함정 (오늘 실제로 밟았다)
- 🔴 **임시 색인 + commit-tree 는 BASE SHA 를 한 번 고정**해 `read-tree` 와 `-p` 에 같은 값을 쓴다 — 두 호출로 나눴더니 VS Code 자동 fetch 가 사이에 main 을 옮겨 #667 이 #666 을 되돌렸다(#670 복구). 커밋 직후 `git diff --stat <부모> <새 커밋>` 대조.
- 🔴 **가림 점검은 문자열 대조만으로 부족** — 비공개 원본을 풀어 쓴 문장은 걸리지 않는다. 공개 문서에 미봉합 결함의 성립 여부·찾을 범위를 쓰지 않는다(판정 등급만).
- 🔴 반증·검증 갈래는 **턴 상한**(25~60)에 자주 걸린다 — 도구 호출 수를 지시에 적고, 걸리면 「확인한 만큼 쓰고 미측정」으로 마무리시킨다.
- MySQL 은 사용자 폴더의 한글 경로를 데이터 폴더로 못 쓴다 — 영문 경로만.
- 격리 worktree 갈래는 원본 경로(`.claude/local_비공개/`)에 못 쓴다 — 산출물 경로를 worktree 안으로 받아 PM 이 옮긴다.
- GPT 회신 기산 = **main 머지 시각**(결재 #3 고침).
