### 3-1. 검증팀 반려 사유 (실측 재현됨)

| # | 결함 | 결과 |
|---|---|---|
| **A-1** | `Move-Item -Force` 가 폴더를 **대체하지 않고 안에 중첩**시킨다 → `watchdog.old\watchdog\HitPan.Watchdog.exe` | 롤백해도 EXE 가 제자리에 없음 = **영구 고립**. 예외도 안 나서 로그도 안 남음 |
| **A-2** | `watchdog` 폴더가 **없는 창(window)** 존재. 그때 전원 차단되면 `/SC ONCE` 는 이미 끝났고 **부팅 복구 코드가 레포에 0건** | **영구 고립** |
| **B-1** | 23:59 에 `+1분` = `00:00` → schtasks 가 **과거 시각**으로 등록. 그런데 **exit 0** | 침묵 실패 (영원히 안 돎) |
| **A-3** | `Stop-Service` 실패를 이중으로 삼키고 그대로 Move | A-1 유발 |

> **영구 고립 = 그 고객 PC 의 자동업데이트·자가복구 영구 종료.** 유일한 복구는 재설치인데
> 사장님이 폐기한 경로다(`feedback_no_overwrite_reinstall`, 7/15).
