### §5-3. Inno Setup `.iss` — 줄 맨 앞 `[` 는 **섹션 태그**로 읽힌다

두 번 깨졌다.
- `'[client]'` 문자열 → `Chr(91) + 'client' + Chr(93)` 로 회피
- `Format(...)` 인자 배열이 줄 맨 앞에서 `[` 로 시작 → **한 줄로 붙여** 회피

### §5-4. `cmd /C` 는 따옴표가 **2개 이상이면 첫·마지막을 벗긴다**

`1.2.78` 이 `exit 1` + **출력 0** 이었다. seed-parent 는 1을 내는 경로가 **없다**(0·2·3·4·5·6·10).
⇒ 출력 0 + 없는 코드 = **실행 자체가 안 됨.** `C:\Program Files` 공백에서 경로가 잘렸다.
**봉합**: 바깥을 한 겹 더 감싼다.

```pascal
'/C ""' + ExePath + '" seed-parent "' + InputFile + '" > "' + SeedLogFile + '" 2>&1"'
```
