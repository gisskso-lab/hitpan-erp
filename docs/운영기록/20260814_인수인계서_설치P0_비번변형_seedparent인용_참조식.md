## §5. 🔴 함정 — 다음 세션이 밟을 지뢰 (이 절이 이 문서의 값어치다)

### §5-1. 🔴🔥 **로그를 못 보면 추측하지 마라 — PM 이 오늘 5번 헛짚었다**

설치 실패 원인을 **다섯 번 연속으로 틀리게** 지목했다. 전부 검증팀·실측이 반증:

| # | PM 추측 | 반증 |
|---|---|---|
| 1 | EXE 가 8/4 로 낡았다 | `deploy-update.yml` 도 EXE 를 만든다 |
| 2 | `is_deleted` 컬럼 부재 | 출하 DDL 에 있다 |
| 3 | `local_company` 컬럼 불일치 | 16개 전부 있다 |
| 4 | `emp_name` 없음 | 있다 |
| 5 | MariaDB 미기동/타임아웃 | 기본 15초·재시도 0건·db-setup 성공 = DB 생존 |

**왜 이렇게 됐나 (구조적 이유)**: `seed-parent` 는 실패 이유를 **stderr 로 내는데**
설치 스크립트의 `Exec()` 가 그걸 **버렸다.** 로그에 종료코드만 남았다.
⇒ **볼 수 없으니 추측만 반복하게 된다.**

🔴 **교훈**: 원인이 안 보이면 **여섯 번째 추측 대신 "보이게 만드는 것"을 먼저 해라.**
(이 판단이 `1badba7` 로 이어졌고, 그게 진짜 결함을 드러냈다)

### §5-2. 🔴 **"고쳤다" ≠ "고객에게 갔다"** — [[project_fixed_vs_delivered_gap]] 재발

오늘 5차 사례가 나왔다: **CI 는 통과하는데 실제 컴파일이 깨졌다.**
`Installer Inno Setup Lint` 가 **pass** 인데 ISCC 실제 컴파일은 실패(#153·#155 두 판).
⇒ **린트 통과 = 컴파일 성공이 아니다.** `.iss` 는 게시 산출물이 나와야 확인된 것이다.

### §5-3. Inno Setup `.iss` — 줄 맨 앞 `[` 는 **섹션 태그**로 읽힌다

두 번 깨졌다.
- `'[client]'` 문자열 → `Chr(91) + 'client' + Chr(93)` 로 회피
- `Format(...)` 인자 배열이 줄 맨 앞에서 `[` 로 시작 → **한 줄로 붙여** 회피

### §5-4. `cmd /C` 는 따옴표가 **2개 이상이면 첫·마지막을 벗긴다**

`1.2.78` 이 `exit 1` + **출력 0** 이었다. seed-parent 는 1을 내는 경로가 **없다**(0·2·3·4·5·6·10).
⇒ 출력 0 + 없는 코드 = **실행 자체가 안 됨.** `C:\Program Files` 공백에서 경로가 잘렸다.
**봉합**: 바깥을 한 겹 더 감싼다.

```pascal
'/C ""' + ExePath + '" seed-parent "' + InputFile + '" > "' + SeedLogFile + '" 2>&1"'
```

### §5-5. 🔴 **경보기를 끄지 마라** — 2026-07-01 의 교훈

접속 확인 가드가 **있었는데** *"이 가드만 실패해 유일하게 설치를 막는다 ⇒ 과잉"* 이라며 차단에서 제외됐다.
🔴 **과잉이 아니라 진짜 결함을 정확히 잡고 있었다.** 원인까지 그때 주석에 적혀 있었다 — *"명령줄 -p 비번 해석 차이"*.
**알고도 원인을 고치는 대신 경보기를 껐다.**

그 결과: 비번이 어긋난 채 DB 초기화가 **"성공"** 으로 끝나고 → 부모계정 생성이 1045 로 죽어 →
**"시리얼·사업자번호·증표를 확인하세요"** 라는 **엉뚱한 메시지**. 고객이면 시리얼만 몇 번이고 다시 넣었을 것이다.
**불이 난 자리와 연기가 나는 자리가 달랐다.**

### §5-6. `sessionStorage` 는 **창마다 따로다**

메신저 팝업 빈 화면의 진범. 처음에 "팝업 차단"으로 오진했고 **사장님 스크린샷이 반증**(창은 떠 있었다).
`window.open` 새 창은 자기만의 **빈** sessionStorage 를 갖는다 ⇒ 토큰을 못 찾아 아무것도 안 그렸다.
**봉합**: `hitpanStorage_inheritFromOpener()` — Blazor 시작 **전에** opener 에서 물려받는다.
🔴 **localStorage 로 옮기지 마라.** 한 줄로 끝나지만 XSS 노출 창이 넓어진다.
