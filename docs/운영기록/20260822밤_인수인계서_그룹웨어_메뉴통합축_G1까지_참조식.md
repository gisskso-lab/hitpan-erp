## 1. 🔴 오늘 가장 중요한 것 — 축이 바뀌었다

### 1-1. 축 = **메뉴 통합(17→10) + 결재조회 일원화**

> 사장님: *"메뉴구성이자너 · **메뉴통합**"*

🔴 **PM 이 *"가장 중요한 축은 결재선 2중화"* 라 보고했고 사장님이 물리셨다.**

| | |
|---|---|
| 결재선·직권·전결 | 고객이 모르는 **내부 배선** = **수단** |
| **메뉴 통합** | 고객이 보는 것 = **목적** |

오늘 논의 전부가 *"메뉴를 합치자"* 에서 **파생된 질문**이었다.
⚠️ 상무님은 이미 *"나는 **순서**를 얘기했는데 사장님은 **축**을 바꾸셨다 — 급이 다른 얘기"* 로
   알아들었는데 **PM 이 못 알아들었다.**

### 1-2. 🔴 사장님 3원칙 (모든 판단의 잣대)

> **①** *"결재라인은 하나로 통합하되, **필터링으로 결재**하고 **창구만 구분**. 메뉴 최소화"*
> **②** *"**컬럼이 삭제되거나 기능이 없어지는게 아님. 메뉴에 녹아들어가게** 하는거지"*
> **③** *"**불필요하게 화면을 더 만들지 말고 이미 있는 화면으로 링크이동**"*

⇒ 라인 쪼개기·기능 빼기·메뉴 늘리기는 **전부 위반**. 필요하면 **필터 값·탭·링크**로 푼다.
