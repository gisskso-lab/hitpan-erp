## 1. 🔴 순서가 바뀌었다 — 작11 이 작9 앞으로

### 1-1. 왜

사장님 지시 7 *"판매확정·구매확정은 **암묵적인 결재기능**"* ⇒ 지시 9 *"ERP 결재 7종 모두 빼"*.
그 말이 성립하려면 **확정이 결재만큼 통제**돼야 하는데 — **실측 결과 통제가 없다.**

| 확정 엔드포인트 | 개별 권한 |
|---|---|
| `sales/deliveries/{id}/confirm` | **없음** |
| `sales/deliveries/bulk-confirm` | **없음** (일괄이라 영향 큼) |
| `purchase/receipts/{id}/confirm` | **없음** |
| `purchase/returns/{id}/confirm` | **없음** |
| `sales/returns/{id}/confirm` | `Authorize(SalesManager)` ← 유일 |

```
현재:  확정(통제 약함) + 결재(통제 있음)  → 결재가 뒷문을 막고 있다
작9후: 확정(통제 약함)                     → 막는 게 없다
```

⇒ **작9 를 미루는 게 아니라 작9 를 성립시키러 가는 것이다.**

### 1-2. 실측이 뒷받침한다 (검12)

- 대표 `DELIVERY` 권한 **전부 `false`** 인데 확정 4곳 **전부 400** — **403 이 0건**
- 반증: 없는 라우트 **405** ≠ 확정 **400** ⇒ 400 은 **진짜 확정 핸들러** 값
- 반증: 토큰 없이 **401** ⇒ *"다 통과"* 가 아니라 **"인증은 보는데 권한을 안 본다"**
