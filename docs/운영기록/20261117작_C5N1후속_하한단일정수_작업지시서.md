## §8 [K5 — 엔진 판 변경 PR 관문 문구 (이 PR 은 판 변경 0)]

> **P-4 엔진 판(digest) 변경 = 재측정 관문.** (A3 · K2) `trufflehog.yml` 엔진 digest 줄과 `scan.sh` digest 강제 줄은 **이 PR 머지 + 이 PR [4-X] 회신 CTO 대조 + 대표 결재 전까지 바꾸지 않는다.** 그 뒤에도 판 변경은 **별도 PR** · 자체시험 전부 초록 · **새 판 실제 Scan(깨끗 길) 잡 로그 판정 줄에서 `records=1` 이고 `chunks:` 가 한 번**(가짜 엔진 시험으로 갈음 금지) · 그 PR 의 [4-X]. 판 변경 PR 이 오면 PM 이 이 줄부터 본다. 자동 의존성 갱신 봇이 이 digest 를 올리는 PR 도 대상 · 자동 머지 금지.

- **`records=` 칸으로 판정 가능해지는 것**: 새 판이 `finished scanning` 줄을 몇 번 쓰는지를 **엔진 기록 원문 공개 없이 숫자로** 공개 판정(지금은 `-m1` 때문에 안 보임 · [1-V] M5 「반쪽」 → 기록 줄 수까지). 고친 뒤에는 깨끗 런이 초록이라는 것 자체가 「기록 줄 1 · 값 하나」 의 증명이고, 칸은 그것을 HQA 가 잡 로그로 독립 대조하게 해 준다.
- **여전히 못 하는 것(공개 한계)**: ① 찾음 길(종료 183)은 하한을 안 보므로 칸 · 확인 둘 다 없음 → K5 판정은 깨끗 런으로만 ② 둘째 기록 줄의 내용 ③ 정규식 밖 새 꼴(→ 빈 값 → 검사 오류로 드러남 · 깨끗으로는 안 샘).
