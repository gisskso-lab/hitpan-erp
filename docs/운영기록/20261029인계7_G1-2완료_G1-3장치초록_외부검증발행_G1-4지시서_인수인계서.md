## §5 함정 (오늘 실제로 밟았다)
- 🔴 **PR 이 main 과 충돌하면 `pull_request` 검사가 아예 안 돈다** — 런 6 이 「빨강」이 아니라 「없음」이었다. 다른 PR 머지 뒤엔 `gh pr view N --json mergeable` 부터.
- 🔴 **PR 가지에 푸시할 때마다 검사 한 벌이 돈다** — 문서만 고쳐도 런을 쓴다. 런 상한이 있으면 문서 기록은 다음 고침과 한 커밋으로 묶는다.
- 🔴 **장치가 죽으면 결과표가 통째로 사라졌다**(런 6) → 판정이 엉뚱한 이유(「돈 시험 0건」)로 빨강. 결과는 줄마다 즉시 기록.
- 🔴 **「통과」가 거짓이었다**(약관 H-D2 · 런 2~4) — 화면이 자리 잡기 전에 주소를 봤다. 검증팀장 재확인이 잡았다. 초록이 나와도 [4] 를 건너뛰지 않는다.
- 🔴 이 PC 에서 python 을 heredoc(stdin)으로 돌리면 한글이 깨져 실패한다 → `py -3 파일.py`(첫 줄 `# -*- coding: utf-8 -*-`) · 출력이 한글이면 `PYTHONIOENCODING=utf-8`.
- 🔴 `git -C 다른폴더 worktree add 상대경로` 는 그 폴더 **안**에 만든다(worktree 안 worktree) — 절대 경로로.
- 에이전트는 턴 한도로 자주 멈춘다(오늘 5회) — 「산출 문서를 먼저 만들고 채워라」를 지시에 넣으면 멈춰도 산출물이 남는다 · 15분 넘게 쉰 에이전트는 이어 부르지 말고 새로 띄워 산출물 주소만 넘긴다(토큰 규칙 P3).
