## 1. 점검 6건 (헌법·광고법 정합 점검)

### 1.1. 제24조의2 SLA 99.99% 공시
**광고법 정합 점검:**
- ✅ "본사 책임 영역"으로 한정 → 광고법 §3 (사실과 부합) 정합
- ✅ "보장" 단어 1회만 사용 (① 항) + 영역 즉시 정의 (② 항)
- ⚠️ **권고**: ① 항 "보장" → "약정" 또는 "목표" 검토 (법무 자문)
- ✅ 가용률 계산식 명시 (⑤ 항) = 부당광고법 §3 정합

**PM 의견**: 조항 자체는 정합. "보장" 표현은 법무 권고 받아 ① 항만 미세 조정.

### 1.2. 제24조의3 환불 조항
**전자상거래법 정합 점검:**
- ✅ 환불 기준 표 명시 (5단계)
- ✅ "익월 차감 또는 계좌 입금" 명시
- ⚠️ **권고**: 환불 청구 절차 명시 부족 → "자동 차감" vs "회원 청구 시" 명확화 필요
- ⚠️ **권고**: 환불 시한 명시 부족 → "발견일 + 30일 이내" 박제 검토

**PM 의견**: 환불 청구 절차 + 시한 보강 필요. 법무 의뢰 시 명시 의뢰.

### 1.3. 제24조의4 책임 분산
**민법·약관규제법 정합 점검:**
- ✅ 본사 책임 한정 명시
- ✅ 고객 책임 = 의무 제공 + 미준수 시 면책 (헌법 #24 정합)
- ✅ 제3자 책임 = 해당 제3자 약관 우선
- ⚠️ **권고**: 약관규제법 §7 (면책조항 제한) 정합 확인 필요 → "고의·중과실" 예외 박제 검토

**PM 의견**: 면책조항 제한 정합 확인 = 법무 핵심 검토 영역.

### 1.4. 제24조의5 비상 통신 수단 (Headscale)
**고지 의무 정합 점검:**
- ✅ 비상 활성화 시 백오피스 공지 명시
- ⚠️ **권고**: 비상 상황 정의 명확화 (Cloudflare 단순 장애 vs 정책 변경 구분)
- ⚠️ **권고**: 비상 활성화 → 자동 업데이트 = 고객 동의 절차 박제 검토

**PM 의견**: 비상 EXE 자동 업데이트 = 정보통신망법 고지 의무 확인 필요.

### 1.5. 마케팅 표현 가이드
**광고법 정합 점검:**
- ✅ 금지 표현 5종 박제 ("100%"·"절대"·"보장"·"무한"·"가장 안전한")
- ✅ 사용 가능 표현 6종 박제 (사실 기반)
- ⚠️ **권고**: "본사가 가진 게 없어서 털릴 게 없습니다" = 강한 표현, 법무 자문 권고

**PM 의견**: 셀링 카피 6종 (5순위 박제)와 정합. 법무 일괄 검토.

### 1.6. 적용 시점
**전자상거래법 §15-2 정합 점검:**
- ✅ 효력 발생 = 결재일 + 30일 (전자상거래법 정합)
- ✅ 기존 회원 통지 = 결재일 + 7일 (충분)
- ✅ 베타 5곳 첫 적용 = 6/15 (적용 시점 명확)

**PM 의견**: 적용 시점 절차 정합.
