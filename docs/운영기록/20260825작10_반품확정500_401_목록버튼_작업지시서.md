## 2. 🔴 원인 — 재현으로 확정한 것과, 아직 모르는 것

### [2번] 500 — **재현 성공**

로컬 DB 에 같은 조건을 만들어 실제로 돌렸다:

```
MySqlException: Unknown column 'is_loss' in 'SELECT'
```

`ConfirmSalesReturnAsync` 가 `sales_return_items.is_loss` 를 읽는데 **그 컬럼이 DB 에 없다.**
`is_loss` 는 작6 이 **DB-108** 로 추가한 컬럼이다.

**왜 500 인가** — `GlobalExceptionMiddleware` 는
`InvalidOperationException`→400, FK(1451·1452)→**409**, 나머지→**500** 으로 가른다.
컬럼 없음(1054)은 마지막 칸에 떨어진다.
🔴 **중간에 세웠던 FK 가설을 이걸로 버렸다** — FK 였다면 409 였을 것이고, 사장님이 받은 건 500 이다.

### [추가] 401 — **원인 확정**

`GET /api/auth/update-status-local` 은 **로그인 전**에 부른다(토큰이 없는 게 정상).
엔드포인트는 `[AllowAnonymous]` 인데, 그 **앞단 `TenantMiddleware`** 가 먼저 401 로 잘라낸다.
면제 목록에 `/api/auth/login`·`/api/auth/refresh` 만 있고 이 주소가 빠졌다.

### [1번] 목록에 확정 버튼 없음

작9 에서 **전표 화면에만** 넣었다. 목록(`SalesReturnList`)에는 안 넣었다. PM 누락이다.

### 🔴 아직 모르는 것 — DB-108 이 왜 안 들어갔나

1.3.10 은 `requiresMigration: true` 로 나갔고, 워치독은 신규 마이그가 있어도 **경고 후 통과**시키며
적용은 **HitPan.API 기동 시 `MigrationRunner`** 가 한다. 정상이라면 그때 들어갔어야 한다.

**추적할 수 없다** — `schema_migrations` 를 볼 수 없고(이 PC 는 운영기가 아니다),
`MigrationRunner` 는 SQL 폴더를 못 찾으면 **로그만 남기고 조용히 0건 처리**한다.

⇒ 이번 차수는 **원인 규명이 아니라 관측 가능성**을 만든다. 다음에 같은 일이 나면 **한 줄로 답이 나오게** 한다.

## 3. 작업 범위

### W1 — 확정 실패 시 "무엇이 없는지" 말한다 🔴 (사장님이 꼭 넣으라 하신 것)
- `ConfirmSalesReturnAsync`·`CancelSalesReturnAsync` 를 스키마 부재(1054)에 대해 **말이 되는 오류**로 바꾼다
- 컨트롤러가 그걸 **400 + 사유**로 돌려준다 — *"서버 오류"* 만 뜨고 끝나지 않게
- 🔴 **고객 화면에는 개발용어를 쓰지 않는다** — *"업데이트가 덜 적용되었습니다"* 로 안내

### W2 — 500 의 실제 원인 제거 (DB-108 강제 적용)
- 게시를 **`requiresMigration: true`** 로 내보내 미적용분을 밀어 넣는다
- `is_loss` 조회를 **컬럼이 없어도 죽지 않게** 방어(있으면 쓰고, 없으면 0=정상품 취급)
  🔴 이건 **로스 기능을 끄는 게 아니다.** 컬럼이 생기면 그대로 동작한다.
  마이그가 늦게 들어오는 구형 DB 에서도 **반품확정 자체는 되게** 하는 것이다(헌법 #20)

### W3 — 로그인 401
- `TenantMiddleware` 면제 목록에 `/api/auth/update-status-local` 추가
- 🔴 **면제 범위를 넓히지 않는다** — 이 주소 하나만. `/api/auth` 통째로 열면 `me`·`logout` 까지 열린다

### W4 — 목록에 「반품확정」
- `SalesReturnList` 에 확정 버튼. 권한은 작9 와 동일(`system_admin,tenant_admin,sales_manager`)
- draft 1건 선택 시에만 활성

### W5 — 게이트
- 확정 경로가 **스키마 부재를 사용자 말로 돌려주는지**
- 401 면제가 **그 주소만** 열렸는지
- 🔴 봉합 빼면 FAIL 하는지 **먼저 확인**
