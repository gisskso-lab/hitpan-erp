## §5. 함정 — 다음 세션이 밟을 지뢰
- 🔴 **계산서 봉합은 「빈 DB 에서만」 짝을 가른다.** 이미 이관한 DB 위 병합 재이관은 어긋난 짝만큼 흡수된다(병렬이슈 15 · 실물 표 사본으로 3경우 재현). **작지서 §5 의 66,631 은 리셋한 DB 기준**이다 — 조건 빼고 재면 오판한다.
- 🔴 **HTTP 로 경로 유무를 가르려 하지 마라.** 인증이 라우팅보다 먼저 서서 **없는 주소도 401** 이다. 401 을 통과로 읽으면 안 된다. 경로는 W13 리플렉션이 잰다.
- 🔴 **`iconv` 는 이 PC 에 없다.** `iconv … || echo 깨짐` 은 command-not-found 도 깨짐으로 센다 — 멀쩡한 memory 파일 3개를 "깨졌다" 로 오판할 뻔했다. 인코딩은 **Read 로 눈으로** 본다.
- 🔴 **한글을 셸에서 `perl -i -pe` 로 덧붙이지 마라** — 실제로 한 번 깨뜨렸다. heredoc 파일 + `awk` 로 **줄을 통째 교체**한다.
- ⚠️ `hitpan_e2e` 마스터 일부가 G-MH 시험값(`사용자가고친이름` 등)으로 남아 있다. 새 실측 전 **반드시 리셋**.
- ⚠️ 세션 튜닝 경고(`innodb_flush_log_at_trx_commit` 은 GLOBAL)는 **작21 부터 있던 것 · 회귀 아님**.
- 측정 도구에 `--mode`·`--phase`·`--job` 이 생겼다(기본값은 종전 동작). 스크립트는 scratchpad `run_baseline.sh`·`reset_e2e.sh`.
