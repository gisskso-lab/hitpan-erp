## 0. ⭐ 사장님 오더 (원문 그대로 — 이 문서의 원본)

> *"히트판erp에 직접 들어가서 인쇄양식 확인해보니 **못쓸 수준**이던데??"*
> *"**pdf로 그리는 엔진 좋아!!** … 하지만 양식이 못쓸정도로 너무 허접해."*
> *"양식지 기본셋팅이면 **이정도 디자인 퀄리티는 나와야** 하지 싶은데??"*

> *"**메일첨부용으로든, 실제 프린트 출력용으로든, pdf로 동일하게 가야지**"*

**이 아래 모든 내용은 위 오더를 명문화한 것이다.** 오더에 없던 요구를 넣지 않는다(#33).

## 1. 오더를 이렇게 이해했다

- **의중**: 세금계산서를 **거래처 경리가 받아 주는 종이**로 만들고, **메일과 종이가 글자 하나까지 같게** 한다.
- **안 하면**: B4 베타 1곳에서 **화면 사진 / 남의 서식 / 빈 종이**가 실제 거래처로 나간다. 법정 서식이라 **반송**된다.
- **실측 근거**: 선행검증서 전문(코드 0줄 · DB 0 · 빌드 0) · 설계문서 §1·§13.
