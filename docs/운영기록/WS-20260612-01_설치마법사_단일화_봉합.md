## 6/19 영역 출시 게이트 (4단계 흐름 100%)

깨끗한 Windows 10 64비트 VM 영역에서:

1. **랜딩페이지** → 계정정보 등록 → 설치마법사 다운로드 → 200 OK
2. **백오피스** → 계정정보 등록 → 시리얼 발송 → 메일 박힘
3. **EXE 클릭** → 시리얼 입력 → 설치 가도 → "성공" 표시 ≠ 거짓 표시
4. **브라우저 자동 열림** → `https://test-vm.hitpan.kr` → 200 OK → 로그인 화면

**검증 항목**:
- cloudflared 서비스 영역 Running (StopPending·Disabled 0건)
- 5분 자가 점검 PASS
- 백신 5종 예외 영역 정상 등록
- 방화벽 영역 4개 규칙 박힘
- registry.json 영역 정합
- 멀티 사업자 2번째 시리얼 영역 정합 가도 (포트 5357 충돌 0건)

**한 항목이라도 실패하면 베타1 출시 영역 보류** (헌법 #19 errors 0 + warnings 0 정합).
