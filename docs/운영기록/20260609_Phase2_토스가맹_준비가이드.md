## 사업자등록 후 (예정 8월 말) 박을 영역

### 1. 토스 가맹 신청
- 사이트: https://www.tosspayments.com/
- 필요 서류:
  - 사업자등록증
  - 통장 사본 (정산 계좌)
  - 대표자 신분증
- 심사 기간: 3~5 영업일

### 2. ClientKey + SecretKey 발급
- 토스 대시보드 → API 키 발급
- ClientKey: 클라이언트 (브라우저) 노출 가능
- SecretKey: 서버 전용 (절대 노출 금지, 헌법 #29)

### 3. NCP 백오피스 환경변수 박기
```bash
# /etc/systemd/system/hitpan-backoffice-api.service
Environment="HITPAN_TOSS_CLIENT_KEY=test_ck_xxxxx"   # 실키 발급 후 교체
Environment="HITPAN_TOSS_SECRET_KEY=test_sk_xxxxx"   # 실키 발급 후 교체
```

### 4. 시험 절차
1. 토스 결제창 호출: `GET /api/payments/toss/config` → ClientKey 응답 확인
2. 결제 진행: PaymentPage → 토스 SDK → 결제 성공
3. 서버 승인: `POST /api/payments/toss/confirm` → 200 응답 확인
4. DB 검증: `tenant_payments` 테이블 박힘 확인
5. 웹훅 시험: 토스 웹훅 시뮬레이션 → `POST /api/toss/webhook` → 200 응답

### 5. 결제 부활 영역
- 베타1에서 우회한 PaymentPage 코드 보존 (`project_beta1_no_payment` 메모리)
- 환경변수 박은 즉시 가입 동선에 결제 단계 자동 부활
- 코드 변경 0건
