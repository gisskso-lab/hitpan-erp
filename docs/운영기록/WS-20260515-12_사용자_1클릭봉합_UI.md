## 1. 목적

통신 사고 + 백신 격리 + 인증서 만료 등 어떤 사용자 영역 문제도 **1클릭 봉합**으로 해결. 헌법 #25 (쉽게) 현장 직원 시선 정공법.

> 사장님 격언: *"이 화면, 처음 보는 사람이 혼자 쓸 수 있냐?"*

## 2. 진단 → 봉합 5단계

```
① 화면 우상단 통신 상태 라이트 (Green/Yellow/Red)
   ↓ 클릭
② 자동 진단 결과 표시 (10초 이내)
   ↓
③ 문제 발견 시 봉합 옵션 제시
   ↓
④ 1클릭 봉합 (자동 또는 안내 매뉴얼)
   ↓
⑤ 복구 완료 토스트 + 자동 새로고침
```

## 3. UI 컴포넌트 명세

### 3-1. 통신 상태 라이트 (모든 페이지 우상단)

```razor
@* HitPan.Web/Shared/ConnectionStatusLight.razor *@
@inject ConnectionHealthService Health
@inject NavigationManager Nav

<MudTooltip Text="@_tooltip">
    <MudIconButton Icon="@_icon" Color="@_color" OnClick="OpenDiagnostic" />
</MudTooltip>

@code {
    private string _icon = Icons.Material.Filled.SignalCellular4Bar;
    private Color _color = Color.Success;
    private string _tooltip = "통신 정상";

    protected override void OnInitialized() {
        Health.StateChanged += OnStateChanged;
        OnStateChanged(Health.CurrentState);
    }

    void OnStateChanged(ConnectionState s) {
        InvokeAsync(() => {
            (_icon, _color, _tooltip) = s switch {
                ConnectionState.Healthy => (Icons.Material.Filled.SignalCellular4Bar, Color.Success, "통신 정상"),
                ConnectionState.Degraded => (Icons.Material.Filled.SignalCellularAlt2Bar, Color.Warning, "응답이 느립니다. 점검을 시작하려면 클릭하세요."),
                ConnectionState.Disconnected => (Icons.Material.Filled.SignalCellularConnectedNoInternet0Bar, Color.Error, "통신 끊김. 봉합을 시작하려면 클릭하세요."),
                _ => (Icons.Material.Filled.SignalCellularNull, Color.Default, "확인 중...")
            };
            StateHasChanged();
        });
    }

    void OpenDiagnostic() => Nav.NavigateTo("/security/diagnostic");
}
```

### 3-2. 진단 페이지

```razor
@* HitPan.Web/Pages/SecurityDiagnostic.razor *@
@page "/security/diagnostic"
@inject HttpClient Http

<MudContainer MaxWidth="MaxWidth.Small" Class="pt-8">
    <MudPaper Class="pa-6" Elevation="2">
        <MudText Typo="Typo.h4" Class="mb-4">통신 점검</MudText>

        @if (_diagnosing) {
            <MudProgressLinear Color="Color.Primary" Indeterminate="true" Class="my-4" />
            <MudText>점검 중입니다... (10초 이내)</MudText>
        } else {
            @foreach (var check in _checks) {
                <MudListItem Icon="@(check.Passed ? Icons.Material.Filled.CheckCircle : Icons.Material.Filled.Error)"
                             IconColor="@(check.Passed ? Color.Success : Color.Error)">
                    <MudText>@check.Name</MudText>
                    <MudText Typo="Typo.caption">@check.Message</MudText>
                </MudListItem>
            }

            @if (_checks.Any(c => !c.Passed)) {
                <MudDivider Class="my-4" />
                <MudButton Variant="Variant.Filled" Color="Color.Primary" Size="Size.Large"
                           FullWidth="true" OnClick="StartRecovery">
                    1클릭 봉합 시작
                </MudButton>
                <MudText Class="mt-3" Typo="Typo.caption" Align="Align.Center">
                    봉합이 안 될 경우 관리자에게 문의하세요 (제공된 매뉴얼 참조).
                </MudText>
            } else {
                <MudAlert Severity="Severity.Success" Class="mt-4">
                    모든 점검 통과. 안전하게 작업하세요.
                </MudAlert>
            }
        }
    </MudPaper>
</MudContainer>

@code {
    private bool _diagnosing = true;
    private List<DiagnosticCheck> _checks = new();

    protected override async Task OnInitializedAsync() {
        _checks = await Http.GetFromJsonAsync<List<DiagnosticCheck>>("/api/security/diagnostic") ?? new();
        _diagnosing = false;
    }

    async Task StartRecovery() {
        Navigation.NavigateTo("/security/recovery");
    }

    public sealed class DiagnosticCheck {
        public string Name { get; set; } = "";
        public string Message { get; set; } = "";
        public bool Passed { get; set; }
    }
}
```
