## §5 [구현 지시 — S-1 `scan.sh` 1층 새 모양]
**원칙**: 엔진 기록 글자는 작업 폴더 파일에만 둔다(`trap` 이 지움 · :68). 변수 · 출력에는 **숫자와 이 스크립트 고정 낱말만**. jq 출력도 고정 낱말(`obj` · `bad` · `true` · `false`)뿐.

**5-1 기록 줄 떼기** — `LC_ALL=C grep -a 'finished scanning' engine.log` → 작업 폴더 `rec.raw`. `records` = 그 파일 줄 수(지금 정의 그대로).

**5-2 판정 칸 — 전부 맞아야 1층 통과, 하나라도 어긋나면 「훑은 양 기록 모양 이상」 검사 오류**

| 칸 | 문법 확인 | 셈(숫자) | 통과 값 | 막는 꼴 |
|---|---|---|---|---|
| ⓐ 줄 수 | 기록 줄 정확히 하나 | `records` | `1` | 줄 둘 · 없음 |
| ⓑ 값 하나 · 객체 | 줄 전체 = JSON 값 정확히 하나 · 그 값이 객체 · `.msg` 가 글자 그대로 `finished scanning` | jq 출력 줄 수 `vals` · `obj` 줄 수 `objn` | `1` · `1` · **jq 종료 0** | `5 0` · `5␉0` · `5␍0` · 꼬리 글자 · 객체 둘 · 열쇠=값 꼴 · 옛 견본 꼴 · NUL · 다른 메시지 |
| ⓒ 열쇠 하나(해석 기준) | 흐름 해석(`--stream`)으로 **최상위** 경로 `["chunks"]` 잎 사건 수 — 같은 열쇠 둘은 일반 해석이 뒤 값만 남기므로 흐름 해석으로 센다 | `keyn` · 그중 정수 · `0 ≤ 값 ≤ 999999999` 인 것 `keyq` | `1` · `1` · **jq 종료 0** | 키 둘 · 역빗금 이스케이프 열쇠 · 배열 값 · 문자열 · null · 소수 · 넘침 · nan |
| ⓓ 열쇠 하나(글자 기준) | 줄 안 맨 글자 `chunks` 등장 수 | `t1` | `1` | 하위 열쇠 · 중첩 · 값 안 글자 |
| ⓔ 값 경계(글자 기준) | `"chunks":(0\|[123456789][0123456789]{0,8})[,}]` 등장 수 — 숫자 앞 = 콜론 바로 뒤 · 숫자 뒤 = `,` 또는 `}` 만(공백 · 탭 · CR 불허) | `t2` | `1` | 앞자리 0 · 부호 · 지수 · 10자리+ · 숫자 뒤 CR · 콜론 뒤 공백 |
| 값 | ⓔ 가 맞은 조각의 숫자만 → `chunks` | — | `^(0\|[123456789][0123456789]{0,8})$` (지금 정규식 유지) | 여러 줄 값 |

- jq 종료가 0 이 아니면 그 칸의 셈은 **빈 값** → 글자 비교에서 닫힘. 파이프 끝 상태로 지우지 말고 `if jq … > 파일; then 셈; fi` 꼴(흐름 해석은 오류 앞까지 사건을 내보내므로 종료 코드가 필수).
- ⓑ·ⓒ(해석)와 ⓓ·ⓔ(글자)는 **서로를 메운다**: 해석은 공백 · 이스케이프 · 중복을 보고, 글자는 jq 가 너그럽게 받는 앞자리 0 · `nan` · 지수 정규화를 본다. 한쪽만 지우면 S12 결정 행이 새야 한다(§7 V-A).
- 숫자 비교는 글자 비교(`!= "1"`)로 — 빈 값 · 깨진 값이 닫힘 쪽(앞 지시서 ⓐ 와 같은 꼴).
- jq 가 없으면 셈이 빈 값 → 검사 오류(닫힘). 지금 깨끗 길은 jq 를 안 불렀으므로 **깨끗 길의 새 의존**이다(C-5).
- 문구: `훑은 양 기록 모양 이상(기록 줄 R개 · 값 V · 객체 O · 조각 열쇠 K/Q · 글자 T1/T2 · 범위 커밋 C개)` — 앞 낱말 「훑은 양 기록 모양 이상」 은 그대로(S11 단언이 이 낱말을 본다).
- :140 `nvals` · :141 `tailbad` 은 ⓑ~ⓔ 로 대체되어 지운다 — 같은 미머지 PR 안 직전 커밋 줄의 교체이고 main 기준으로는 추가(#1 · §8).
- 2층 :185 `[ "$chunks" -gt 0 ] 2>/dev/null || scan_error …` **무변**(1층이 사라졌을 때의 예비).
