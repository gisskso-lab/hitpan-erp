### Step 5. 화면 확인 (예상)

| 영역 | 표시 |
|---|---|
| 4 KPI 카드 | healthy 0 / recovering 0 / down 0 / 미해결 emergency 0 |
| 월간 SLA | 100.0000% (데이터 없으면 기본값) |
| 환불 대상 | 0건 |
| Emergency 테이블 | "최근 24시간 emergency 없음." |

데이터가 0인 이유: 아직 워치독이 가동 안 됨 → ping 0건. W1 게이트 통과 후 워치독 등록되면 데이터 채워짐.
