## 1. 왜 지금 이 작업인가

### 1-1. 순위는 4번인데 왜 먼저 하는가

인수인계서 2차 §5 의 1순위는 **N-10 60분 실측**이다. 그런데 그것을 먼저 하지 않는다.

| | 사유 |
|---|---|
| 1순위(N-10 실측) | **사장님 손이 필요하다** — 백지환경 기동 + 신버전 게시 + 60분 대기 |
| 4순위(main 정렬) | **PM 이 지금 할 수 있다** + 🔴 **고객이 지금 겪고 있다** |

⇒ 순위를 뒤집은 것이 아니라, **1순위가 사장님 일정에 걸려 있는 동안 대기하지 않는다.**
그리고 **4순위는 1순위의 전제이기도 하다** — §1-3 참조.

### 1-2. 🔴 고객이 지금 겪고 있는 것

`ab566a4` 가 봉합한 것은 **사장님이 직접 겪으신 증상**이다.

> 사장님 실측 증언 (2026-08-07):
> *"1.2.53 에서 1.2.55 로 업데이트했을 때 **터널 오류가 잠깐 났었다.**
> 그리고 **새로고침 하니** 1.2.55 로 바뀌었다."*

**히트판을 만든 사장님조차 고장으로 읽으셨다.** 고객은 더더욱 그렇게 읽는다.
이 봉합이 main 에 없으므로, **지금 업데이트를 받는 고객은 그대로 겪는다.**

### 1-3. 🔴 이 작업이 1순위(N-10 실측)의 전제다

N-10 실측은 *"백지환경에 설치 → 신버전 게시 → 60분 대기 → 발견 확인"* 이다.
**그 "신버전"이 main 에서 빌드된다.** N-10 코드(`e3342b9`)가 main 에 없으면
**실측 대상 자체가 존재하지 않는다.**

⇒ 순서상 이것이 먼저다. 4순위라는 번호가 시간 순서를 뜻하지 않는다.
