## 2. 🔴 이번 세션이 뒤집은 것 — 다음 세션이 반드시 알아야 할 것

### 2-1. 🔴 인계2 의 "작9 P0-A 적용 권고" 는 **틀린 진단이었다**

인계2 에 *"NCP 디스크 2246MB · 패키지 회전 별건"* 이라 적어 다음 세션이 회전 패치를 짜게 만들어 뒀었다. **실제로 서버에 붙어보니 회전은 이미 돌고 있었다.**

```

  101M hitpan-1.3.22.zip     260M HitPan-ERP-Setup-1.3.22.exe
  101M hitpan-1.3.23.zip     260M HitPan-ERP-Setup-1.3.23.exe
```

**현행(1.3.23) + 직전(1.3.22) 2세대만 남아 있다.** 7/29 에 서버에서 손으로 넣은 회전본이 살아서 동작 중이다.

🔴 **PM 자책**: 레포본 `publish-update.sh:340` 에 회전이 있고 워크플로가 `.sh` 를 안 보낸다는 것까지는 맞게 조사했는데, 거기서 **"그러므로 서버엔 회전이 없다"** 고 건너뛰었다. **서버를 안 보고 워크플로 경고 숫자(2246MB)만 읽었다.** `ssh … ls /var/www/updates/packages` 한 줄이면 됐다.

⇒ **교훈: 레포에 없다 ≠ 서버에 없다.** 상주본은 따로 산다. 서버 상태는 서버에 물어라.

### 2-2. 🔴 「옛 업데이트 파일 삭제」로는 용량이 안 나온다

사장님 짐작(*"이전 업데이트 파일들 지우면 용량 나오잖아"*)은 **메커니즘은 맞으나 이 서버엔 해당분이 없다.** packages 는 이미 2세대뿐이라 **0 바이트**다.

**7.2GB 의 실제 정체** (전체 9977MB / 여유 2246MB / 77% 사용):

| 위치 | 크기 | 성격 |
|---|---|---|
| `/usr` | 3.8G | OS·런타임 — 못 건드림 |
| `/var/www/updates` | 720M | 🔴 현행+직전 — 보호 |
| `/var/lib` | 540M | MariaDB 등 — 못 건드림 |
| `/opt/hitpan/repo` | 260M | git 미러 — **B-4 서명 검증에 필요** |

⇒ **ERP 업데이트 파일은 전체의 10% 도 안 된다.** 나머지는 OS 와 살아있는 서비스다.

**검증**: API 빌드 **0/0** · Web 빌드 **0/0** · 삭제된 추적파일 **0개**.

`out-1323` 은 로컬 manifest sha256·크기(140MB)가 **서버 서빙본(105MB `d0fc786d…`)과 달랐다** — 서명 전 중간산출물이라 롤백용으로도 못 쓴다.

### 3-1. 🔴 지우려다 멈춘 것 — 다음 세션도 지우지 마라

- 🔴 **`db-backup-*` 504M** — **유일본이다.** `hitpan_erp` DB 가 **이 PC 에서 사라졌다**(현존: `hitpan_backoffice`·`hitpan_e2e`·`hitpan_trgtest`·`test`). 두 덤프 모두 정상(140테이블·`Dump completed`). **PM 이 처음엔 "지워도 되냐" 고 여쭀었는데, 조사해보니 여쭐 일이 아니었다.**

- 🔴 `installer-build`(308M)·`artifacts`(97M)·`tmp-build` — **git 추적파일이 각 2·10·4개 섞여 있다**

### 3-2. ⚠️ 기존 이상 (이번 세션 원인 아님)

## 4. NCP — 조사만 함 (🔴 사장님 지시 "냅둬")

**아무것도 삭제하지 않았다.** 서버는 조사 시작 시점 그대로다.

### 4-1. 회수 가능분 약 480M (미실행)

전부 `packages/` **밖**이라 회전 스크립트가 못 건드리던 것들:

| 대상 | 크기 | 근거 |
|---|---|---|
| `/root/btmp-evidence-20260730.bak` | 183M | 7/30 사고조사 잔재 · 그 건 종결 |
| `/var/hitpan/staging/web` | 119M | 배포 스테이징 · 배포 시 재생성 |
| `/root/hitpan-1.2.49.zip` | 98M | 옛 버전 |
| `/root/hitpan-1.2.48.zip` | 98M | 옛 버전 |

⇒ 실행 시 2246MB → 약 2726MB (게시 3회 → 3~4회)

`/opt/hitpan/*-bak-*`(8/16·8/18 백오피스 240M)도 후보였으나 **롤백 대상이라 제외**했다.

### 4-2. 🔴 착수 시 주의

- **삭제 명령이 권한 분류기에 차단됐다**(원격 파일 삭제). 우회하지 않았다 — 헌법 #29 가 막는 자리이고, **7/29 이 폴더 정리하다 대리점 404 사고**(`20260802_사고기록_대리점_설치실패_승인메일_404.md`)가 난 영역이다.
- 실행하려면 ①사장님 직접 실행용 스크립트(현행버전 보호 가드 + `--dry-run` 기본) ②Bash 권한 규칙 추가 중 택일.
- 🔴 **480M 는 게시 1회분이다. 근본 해법이 아니다.** 진짜 병목은 **10GB 디스크 자체**(`/usr` 3.8G + OS). 게시를 계속하려면 **디스크 증설**이 결국 필요하다 — **사장님 비용 판단 사항**.
