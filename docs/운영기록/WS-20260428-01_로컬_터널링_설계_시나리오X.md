### 3.2 단계 1 (베타 1개월) — 0원 운영

#### 3.2.1 Cloudflare 계정 준비
- 본사 Cloudflare 계정 1개 생성 (무료 플랜)
- Zero Trust 활성화 (50명까지 무료)
- 임시 도메인은 Cloudflare가 자동 발급: `*.cfargotunnel.com`

#### 3.2.2 named tunnel 발급 (베타 10곳용)
```bash
# 본사 어드민이 1회 실행 (각 베타 고객마다)
cloudflared tunnel create tenant-001
cloudflared tunnel create tenant-002
...
cloudflared tunnel create tenant-010

# 결과: 토큰 10개 발급 (각각 EXE 인스톨러에 박음)
```

#### 3.2.3 v1.0.7 EXE 인스톨러 (마커스 리 + 프론트 매니저 협업)
```
설치 단계:
1. HitPan ERP 설치 (기존 v1.0.6 흐름)
2. cloudflared.exe 자동 설치 (벤더 MSI 사용)
3. 본사가 발급한 토큰 박기
   cloudflared service install <TOKEN>
4. Windows 서비스 등록 → PC 부팅 시 자동 시작
5. 사용자가 받는 URL: https://tenant-001.cfargotunnel.com
   ※ 단계 2 진입 시 → https://tenant-001.hitpan.app 으로 자동 전환
```

#### 3.2.4 본사 발급 API (마일스톤 2 일부 선행)
```
POST /api/saas/tenant-tunnels
Body: { tenantName: "...", contactInfo: ... }
Response: { tunnelToken: "eyJ...", tunnelUrl: "tenant-001.cfargotunnel.com" }
```
- 본사 백오피스에서 호출 → 토큰 발급 → 인스톨러 빌드 시 박음
- ※ 백오피스 정식 구현은 마일스톤 3 — 본 작지서는 **수동 발급 방식**으로 시작
