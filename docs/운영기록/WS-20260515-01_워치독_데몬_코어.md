## 3. 8개 자가 진단 항목

| # | 항목 | 정상 기준 | 비정상 시 봉합 (WS 매핑) |
|---|---|---|---|
| 1 | Cloudflared 서비스 실행 중 | `Get-Service Cloudflared Status=Running` | `sc start` 자동 |
| 2 | Cloudflared 프로세스 정상 (좀비 0) | PID 활성 + StartTime < 24h | `taskkill /F` + `sc start` |
| 3 | localhost:5257 API 응답 | `GET /health → 200` | dotnet 서비스 재기동 |
| 4 | MariaDB 응답 | `SELECT 1` 200ms | `net start MySQL` (WS-02 협업) |
| 5 | Cloudflare 엣지 connector 활성 | `cloudflared tunnel info` 4 connections | TunnelSecret 재생성 (WS-03 협업) |
| 6 | demo.hitpan.kr 외부 200 OK | 외부 IP에서 5/5 200 | 위 1~5 봉합 후 재시도 |
| 7 | 자격증명 JSON 무결성 | 파일 크기 200~300B + 권한 사장님 한정 | DPAPI 재암호화 (WS-03 협업) |
| 8 | 토큰 secret 유효성 | cloudflared 로그 `Invalid tunnel secret` 0회 | `tunnel token --cred-file` 자동 (WS-03 협업) |

## 4. 자동 봉합 명령 매트릭스

```csharp
public enum Diagnosis {
    ServiceDown, ProcessZombie, ApiDown, MariaDbDown,
    ConnectorInactive, ExternalUnreachable, CredentialCorrupt, SecretInvalid,
    DefenderQuarantine, AntivirusQuarantine, FirewallBlocked,
    PhysicalDiskWarning, RansomwareSuspected
}

public interface IRemediationCommand {
    Task<RemediationResult> ExecuteAsync(CancellationToken ct);
    bool RequiresElevation { get; }
    bool RequiresUserConsent { get; } // 사장님 헌법 #29 정합
}
```

**원칙:**
- 모든 봉합은 멱등 (재실행 안전)
- 위험 봉합(파일 삭제·자격증명 갱신)은 사장님 사전 동의 캐싱 1회 후 자동
- 봉합 시도 3회 실패 → 본사 메타 ping에 에러 코드 전송 + 사용자 UI 알림

## 5. 본사 메타 ping (헌법 #22 정합)

- 30분마다 본사 backoffice 엔드포인트로 1줄 POST
- 본문 = `{ tenantId, watchdogVersion, lastDiagnosis, errorCode, timestamp }`
- **고객 업무 데이터 0건 포함** (절대원칙)
- HTTPS + Cloudflare WAF 통과
- 본사 측에서 5분 응답 없음 = "고객 PC 연결 끊김" 알림 (CS팀 능동 대응)
