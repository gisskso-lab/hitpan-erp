## §5. 함정 (오늘 새로)
- **`Agent isolation: worktree` 는 origin/main 에서 만든다** — 갈래 지시문에 「`git reset --hard <기능 브랜치 SHA>` 후 SHA 확인」 사전 결재를 넣었더니 매번 잡혔다. 작업 없이 멈춘 worktree 는 자동 삭제돼 **재개 불가**(새로 띄움).
- **TruffleHog 는 PR 커밋 이력 전부를 본다** — 시험의 더미 접속 문자열(`Password=` 조각)이 지운 뒤에도 빨강 → 이력 합치기(사장님 결재)로 닫음. 더미에 자격증명 모양 조각을 아예 넣지 마라.
- **시험마다 다른 DB 이름 + 연결 풀 켬 = CI MariaDB 151 연결 고갈** — 실패가 엉뚱한 게이트(자료이관·백업)에서 난다. 새 DB 게이트는 `Pooling=false`(봉합2·3).
- **「늘 허용」 한 자리가 메인PC 서버줄 거부까지 지웠다**(G-M8* 6건) — 바깥 판정을 바꿀 땐 안쪽 갈래의 거부 사유를 보존(`StaleServerRow`).
- **Git Bash `tar -cf "C:/…"` 실패 + `2>/dev/null`** 로 백업이 안 만들어진 채 지움 — `--force-local` · 크기 확인 뒤에만 삭제(메모리 ⑫).
- `pwsh` 없음 — `scripts/dev/*-brief.ps1` 은 PowerShell 도구에서 `& ./scripts/dev/build-brief.ps1 -Project src/HitPan.sln`.
- 서브에이전트는 `gh api …/logs` 가 권한 분류기에 거절될 수 있다 — PM 이 받아 scratchpad 에 두고 경로를 준다.
