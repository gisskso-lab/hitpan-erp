## §4. 미결·보류

| 안건 | 왜 보류 | 누가 |
|---|---|---|
| 🔴 `storage.js` `SESSION_KEYS` 무효 | **보안 판단**(XSS 노출 창)이라 별도 결재 필요 | 사장님 |
| 터널 `6-2-serviceinstall exit 1` | **미확정** — 재현으로 증명 안 했다 | PM |
| CI 속도 (CodeQL 경로필터) | PM 제안만, 미승인 | 사장님 |

**`SESSION_KEYS` 실측 요지**:
```js
const SESSION_KEYS = new Set(['access_token', 'refresh_token']);   // 접두어 없음
```
실제 키는 `hitpan_access_token`·`hitpan_refresh_token`(`AuthStorageKeys`).
⇒ `has()` 가 **항상 거짓**이라 **민감 토큰이 localStorage 로 간다.** 주석은 *"sessionStorage — XSS 노출 창 짧음"* 인데 **반대로 동작 중.**
8/14 에 넣은 `inheritFromOpener` 도 이 때문에 **작동한 적이 없다**(찾는 키가 없어 조용히 `false`).
⚠️ localStorage 는 같은 출처면 창끼리 공유되므로 **팝업 기능에는 지장 없다.**
