## 1. 오더를 이렇게 이해했다 (명문화)

- **사장님 의중**: 결재함은 **그룹웨어 업무만**. ERP 는 확정이 곧 승인이므로 결재를 또 태우면 중복이다.
  회계는 **사람이 시점을 정하되 금액은 시스템이 자동**으로 넘긴다.
- **안 하면 무슨 일이 나는가**:
  - 경비 결재를 승인해도 원본이 `pending` 고착 → **회계로 넘어갈 것 자체가 안 생긴다**(이미 출하)
  - 결재 3화면이 분산돼 사용자가 불편 (오더 5)
- **실측 근거** (헌법 #32 — 추측 금지): 설계문서 §2 참조. 요약:
  - `ApprovalService.cs:15-47` → 문서유형 **15종**
  - `ProcessAsync` 원본 반영 블록 → `leave`·`absence`·`overtime`·`report_*` 있음 / **`expense` 없음**
  - `ApprovalController.cs:106·119·132` → 필터 파라미터 **0개**
