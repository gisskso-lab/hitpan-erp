> **담당 매니저 리뷰:** 보안 매니저 (1차) + ERP 매니저 (2차)

## 1. 배경

형사영역 접근 사실을 **누구에게·언제** 알릴 것인가:
- 데이터 주체 본인 (직원 → 자기 정보 조회됨)
- tenant_admin
- 본사 보안팀
- 사장님

## 2. 선택지

### A안: 즉시 알림 (Real-time)
- 장점: 침해사고 즉시 인지
- 단점: 정상 업무에도 알림 폭주 → 무뎌짐

### B안: 일배치 (매일 09:00 요약)
- 장점: 노이즈 적음. 운영 부담 최소
- 단점: 24시간 지연 → 침해사고 늦게 인지

### C안: 단계별 (PM 추천)
- **즉시:** Critical 임계치 초과 (결재 #11 B안) → sms·전화
- **일배치:** 매일 09:00 본인·tenant_admin에게 어제 접근 내역 (정상 포함)
- **주배치:** 매주 월요일 09:00 본사 보안팀에게 통계
- **월배치:** 매월 1일 09:00 사장님에게 전체 trend

### D안: 본인만 즉시 + 나머지 일배치
- 장점: 데이터 주체 권리 강화. 개인정보보호법 정신 일치
- 단점: 본인에게 매번 알림 → 피로

## 3. 법령 근거

- **개인정보보호법 §20** 정보주체 이외로부터 수집한 개인정보 통지 (예외 있음)
- **개보법 §38** 권리행사 (열람 청구권)
- → 즉시 알림 의무 없음. 단 정보주체가 청구 시 응답 의무
