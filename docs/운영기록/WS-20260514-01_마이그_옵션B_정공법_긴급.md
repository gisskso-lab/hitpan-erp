## 3. 적용 범위

### 3.1 즉시 적용 (5/14 주간)
1. **테이블별 분리 트랜잭션** — 16개 테이블 각각 독립 tx
2. **청크 INSERT** — 테이블당 1,000~5,000건 단위 commit
3. **체크포인트** — `migration_checkpoints` 인프라 테이블 (W1 DDL 완료분 활용)
4. **멱등성** — `source_hash` 기준 중복 차단 (재시작 시 0건 INSERT)
5. **세션 변수 봉합 유지** — 5/14 새벽 옵션 A 봉합분(`SET SESSION ... innodb_lock_wait_timeout=600 등`) 보존

### 3.2 W3 정식 작업 (5/27~6/2, 마스터플랜대로)
- AIMD 동적 청크 조정 (배치 크기 자가 튜닝)
- `raw_data` AES-256 에러 적재 (`migration_errors`)
- 5클래스 분리 (Orchestrator/Reader/Mapper/CheckpointService/ErrorCollector)

> **5/14 긴급분은 W3 정식의 70%만 미리 박는다.** 코드 영구 구조는 W3 정식에서 5중 검증 후 확정.
