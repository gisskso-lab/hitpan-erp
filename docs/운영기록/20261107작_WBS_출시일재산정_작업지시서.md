## §1 [의중] 명문화

- **일정 픽스 = 이 WBS 의 결재다.** 10/27 기준선은 「조건부 수용」(§6 원문 2·3)이고, 대표 원문 5 「G0 에서 기준이 확정되고 WBS 가 나오면, 그때부터는 날짜를 고정하고 책임 있게 관리」.
- 결재된 WBS 는 그 뒤 **「계획 대비 ±n영업일」 보고의 기준선 판**이 된다 → 그래서 행마다 ID · 계획/실적 분리 · 판 번호가 있어야 한다(HQA Q3 · 11/7 보강 칸).
- 10/27 기준선(04/12 주)은 지우지 않는다 — **판 0** 으로 보존하고 새 판과의 편차를 남긴다(#1 · HQA Q3).
- 안 하면: 일정이 「30영업일」 가정 위에 남고, 밀려도 어느 행 때문인지 말할 수 없다.

## §4 [산정] 방법

1. **단위 = 봉합 묶음**(61_ §3 🔴): 같은 봉합에 묶이는 행은 1행. 묶음 판정 근거를 표 A 출처 칸에 적는다.
2. **건별 적산**: 표 B 칸을 더해 행 공수(하한~상한). 「G1 30영업일」(공동 문안 ⑤)은 쓰지 않는다 — 합과 나란히 적어 차이만 보인다.
3. **환산 근거**: S/M/L 일수 환산표는 없다(61 §3-1 🔶) → G1-2 · G1-3 · 막는 장치 · #691 의 **실적**(시작·머지 시각 · [4-X] 왕복 횟수)을 행 규모의 참고 기준으로 쓴다. 근거 없는 칸은 「미산정」.
4. **달력 = 공수 + 표 C 대기 + 공휴일**(61 §1 · 우주항공청 원문 미확인 = 선행 확인) — 결재 대기 2~3일 · 반려 1회 버퍼(단계마다 [4] 반려 1회 + 재검증)를 단계마다 둔다.
5. **사람 자원**: 61 §2 칸(PM 세션 · 갈래 물결 · 임원 · 검증팀장 · 법무 · 대표 1~2시간)을 채우고 **대표 실물이 몰린 행**을 표 C 에 표시한다.
6. **G5**: 차수 4 × (연속 14일 + N=10) · 차수 진입 서명 · 삼일절 · 5월 공휴일 겹침.
7. **임계 경로**: 표 A 의존 선행행으로 가장 긴 사슬을 계산해 한 줄로 쓰고, 사슬 위 행은 표 C 「임계 경로」에 🔴 + 「밀리면 출시일 +n」. 후보 = 61 §4(G1 → G2 이관 → G3 개발+측정 → **G4 외부 2곳** → G5 4차수).
8. **3날짜 산출** 후 표 D 판 1 줄 추가(판 0 대비 ±n영업일 · 사유 행 ID).
