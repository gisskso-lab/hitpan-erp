## 4. 구현 지시

- PM 직접 — 스크립트 한 번 (드라이런 → 대조 → 적용)
- 대상 표: 첫 머리칸이 「문서」 인 표만
- 자르는 규칙: 60자 넘는 칸만 · ` · ` ` — ` `. ` 같은 경계 우선 · 괄호가 안 닫히면 괄호 앞에서 · 끝에 `…`
- 「근거」 칸은 첫 주소(코드 표기 또는 링크) 하나만
- 본문 속 `|` 로 칸 수가 늘어난 줄 → 날짜 칸을 확인한 뒤 설명 칸으로 합쳐서 줄인다
- 파일마다 첫 문서 표 위에 안내 한 줄 + 이력 파일 링크
- 산출물: 개발명세서 → `docs/개발/erp/20260911_개발명세서_INDEX설명줄이기_2차.md`

## 5. 검증 방법

- 무손실: 파일마다 **첫 칸 문서 링크 목록 동일 (순서까지)** · 이력 파일 본문 = 원본 바이트 동일 (머리 6줄 제외)
- 표 모양: 문서 표 줄마다 칸 수 = 머리 칸 수 (표 렌더 깨짐 0)
- 상태 표식: 병렬이슈 상태 칸 맨 앞 표식이 원본과 같다
- [3-V] · [4] — 규모 S → 독립검증 1개가 두 관점 (매뉴얼 §2)
