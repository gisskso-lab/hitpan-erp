## 🔴 §2 쓰면 안 되는 것 — **이 차수 금지**

| | 금지 | 왜 |
|---|---|---|
| 1 | 🔴 **금액·요금 숫자** | 가격은 **미정**(「백오피스에서 설정 후 → 랜딩에서 적용」) |
| 2 | 🔴 **대리점 수수료율** | **본사가 대리점별로 자유롭게 설정**하는 값이다 — 밖에서 고정 숫자를 약속하지 않는다 |
| 3 | 🔴 **「각 단계에서 정확히 무엇이 막힌다」를 화면 단위로 단정** | 🔴 **조임 집행 코드가 0건**이다(§3). 화면에서 무엇이 어떻게 막히는지 **아직 없다** |
| 4 | 🔴 **「자동으로 잠깁니다」류 자동화 단정** | 집행 코드 0건 + **100% 자동화 없음**(반자동 원칙) |
| 5 | 🔴 **복구·연락 소요시간 숫자** | 재 보지 않았다 |

## 🔴 §3 가장 큰 쟁점 — **정책은 결재됐고 코드는 0건이다**

| | 실측 |
|---|---|
| 조임 집행 | 🔴 **코드 0건** — 조임 낱말 전수 0건(범위 `src/`·`*.bat`·`*.iss`·`*.ps1`·출하 DDL) |
| 제한 판정 | 🔴 ERP 가 `local_subscription.status` 를 **읽지 않는다**(`FROM local_subscription` 20건 중 status 읽기 0 · 대조군 작동) |
| 뜻 | 🔴 **오늘 기준으로는 미납이어도 ERP 가 막지 않는다.** B3⑦ 은 「조정」이 아니라 **「신설」** |

🔴 **그래서 [1-V] 에 물었다** — *"정책은 결재됐으나 코드가 0건인 상태에서 고객 안내문을 쓸 수 있는가."*

**PM 건의(판정은 [1-V]·CTO)**: **쓸 수 있다. 단 시제를 지킨다.**
- 🟢 쓴다 = *"요금이 밀리면 **이렇게 안내드립니다**"* (정책·약속 서술)
- 🔴 안 쓴다 = *"○일째 **자동으로 잠깁니다**"* (현재 동작 서술 — **지금 거짓**)
- 🟢 **내보내기 개방**은 정책이자 약속이라 **지금 써도 참**이다(사장님·검증팀 결재 축)
