## 3. 3축

### 축 A. 워치독 자가 보호
일반 사용자 권한으로는 종료 불가. 관리자 권한 종료도 5분 후 자동 재시작.

### 축 B. 관리자 권한 작업 전수 로그
모든 관리자 권한 액션을 SQL Server Event Log + DB 테이블에 저장 + 본사 알림 (메타만, PII 0).

### 축 C. BYOD (Bring Your Own Device) 차단
등록 안 된 PC는 ERP 접속 차단.

### 4-2. 자가 재시작 (관리자 강제 종료 후)

```csharp
// HitPanWatchdog.exe 종료 시 별도 보조 프로세스(Resurrector.exe)가 30초 뒤 재시작
public sealed class ResurrectorService : BackgroundService {
    protected override async Task ExecuteAsync(CancellationToken ct) {
        while (!ct.IsCancellationRequested) {
            try {
                var watchdog = Process.GetProcessesByName("HitPanWatchdog").FirstOrDefault();
                if (watchdog == null) {
                    _logger.LogWarning("[Resurrector] 워치독 종료 감지 — 30초 후 재시작");
                    await Task.Delay(TimeSpan.FromSeconds(30), ct);
                    using var sc = new ServiceController("HitPanWatchdog");
                    sc.Start();
                    sc.WaitForStatus(ServiceControllerStatus.Running, TimeSpan.FromSeconds(60));
                    _logger.LogInformation("[Resurrector] 워치독 재시작 완료");
                }
            } catch (Exception ex) {
                _logger.LogError(ex, "[Resurrector] 재시작 실패");
            }
            await Task.Delay(TimeSpan.FromSeconds(30), ct);
        }
    }
}
```

Resurrector.exe = 별도 EXE, 워치독과 상호 감시.

### 5-2. 미들웨어

```csharp
// HitPan.API/Middleware/AdminAuditMiddleware.cs
public sealed class AdminAuditMiddleware {
    private readonly RequestDelegate _next;
    private readonly IAdminAuditService _audit;

    public AdminAuditMiddleware(RequestDelegate next, IAdminAuditService audit) {
        _next = next;
        _audit = audit;
    }

    public async Task InvokeAsync(HttpContext context) {
        var endpoint = context.GetEndpoint();
        var attr = endpoint?.Metadata.GetMetadata<RequireAdminAttribute>();
        if (attr == null) {
            await _next(context);
            return;
        }

        var success = true;
        string? error = null;
        try {
            await _next(context);
            success = context.Response.StatusCode < 400;
        } catch (Exception ex) {
            success = false;
            error = ex.Message;
            throw;
        } finally {
            await _audit.LogAsync(new AdminAuditEntry {
                ActorUserId = context.User.FindFirst("user_id")?.Value,
                ActorRole = context.User.FindFirst(ClaimTypes.Role)?.Value ?? "",
                ActionCategory = attr.Category,
                ActionName = attr.Name,
                ActionTarget = context.Request.Path,
                Success = success,
                ErrorMessage = error,
                IpAddress = context.Connection.RemoteIpAddress?.ToString(),
                UserAgent = context.Request.Headers.UserAgent.ToString(),
            });
        }
    }
}

[AttributeUsage(AttributeTargets.Method)]
public sealed class RequireAdminAttribute : Attribute {
    public string Category { get; set; } = "config";
    public string Name { get; set; } = "";
}
```

## 6. 축 C — BYOD 차단 명세

### 6-1. 기기 등록 (헌법 #18 정합)

```sql
CREATE TABLE IF NOT EXISTS device_registrations (
    device_id VARCHAR(36) PRIMARY KEY,
    tenant_id VARCHAR(36) NOT NULL,
    device_name VARCHAR(100) NOT NULL,    -- "사장님 PC", "경리 PC" 등
    device_hardware_hash CHAR(64),         -- SHA256(motherboardId + cpuId + ...)
    public_key TEXT,                       -- 디바이스 키 (등록 시 생성)

    registered_at DATETIME(6),
    last_seen_at DATETIME(6),
    is_active TINYINT NOT NULL DEFAULT 1,
    UNIQUE KEY uq_device_hardware (tenant_id, device_hardware_hash)
);
```

### 6-2. 등록 절차

1. 새 PC에서 ERP 첫 접속 → 등록 대기 화면
2. 디바이스 하드웨어 해시 + 디바이스 키 생성
3. 사장님 또는 관리자가 등록 승인
4. 승인 후 ERP 접속 가능
