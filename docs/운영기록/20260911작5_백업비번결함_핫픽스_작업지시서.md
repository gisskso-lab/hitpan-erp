### 5-3. 구현 주의 (결함 재발 방지)
- 게이트와 코드가 **운영과 같은 연결 문자열 조립**(`InfrastructureExtensions.cs:55·65`, `User=…;Password=…`)을 거친 `IDbConnection` 을 써야 한다. 게이트가 `Pwd=` 형식 문자열을 따로 만들면 원인(열린 뒤 비번 빠짐)을 못 잰다.
- `TenantConfigReader` Application 사본은 db.conf 캐시 + 환경변수 폴백(`Common/TenantConfigReader.cs:18-26`). 게이트는 환경변수로 준다 · 테스트 출력 폴더에 db.conf 가 없음을 게이트 시작 시 확인.
- 부모(API) 프로세스 환경변수는 건드리지 않는다 — 자식 `ProcessStartInfo.Environment` 에만.

## §7 [게이트] — `BackupCredentialGate` (동작으로 잰다)

### 7-1. 환경
- **CI**: `build-and-test.yml` DB 게이트 잡 (ubuntu · `mariadb:11.4` 서비스 · `mariadb-client` · `HITPAN_REQUIRE_DB=true` → SKIP 금지 · `hitpan_e2e` 출하 DDL 적재). 게이트는 `HITPAN_DB_*` 를 `DB_HOST`·`DB_PORT`·`DB_NAME`·`DB_USER`·`DB_PASSWORD` 로 옮겨 준다.
- **Windows 격리 실측**(개발명세서 첨부 필수): 격리 MariaDB 11.4 인스턴스 · 3306 운영 인스턴스 금지(#39). 리눅스 CI 는 **숨은 콘솔 입력 대기·System32 경로의 모양을 재현하지 못한다** — 이 한계를 개발명세서에 적는다(조용한 축소 금지).
- DB 없는 로컬 실행에서 PASS 가 나오면 그것은 SKIP 이다 — 통과로 세지 않는다.
