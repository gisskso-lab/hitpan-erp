## §5. 함정 (오늘 새로)
- **TruffleHog PR 스캔은 PR 안 모든 커밋 이력을 읽는다** → 중간 커밋에 들어갔다 지운 문자열도 빨간불. 커밋 1개 새 PR 로 다시 받는다(강제 푸시·제외 목록 금지).
- **새 브랜치 push 스캔 = 전체 이력 스캔** → 늘 빨간불(주간 전수와 같은 탐지 수). 판정은 PR 스캔·main push 스캔으로.
- **빨간 체크 PR 을 `gh pr merge` 하면 권한 검사가 「CI 우회」 로 거부** — 우회 시도 금지.
- Git Bash 에서 `git show origin/main:<경로>` 는 `:` 가 변환돼 **0건처럼** 나온다 → `MSYS_NO_PATHCONV=1` + 따옴표.
- `deploy-update.yml` 입력 이름은 **`environment`** (feed 아님). 승인 요청은 Build 잡(약 7분 반) **끝난 뒤**에 간다 — 「곧 간다」 금지.
- GitHub Windows 러너 계정 = 기본 Administrator(RID 500) — 「현재 계정」 대조 시험은 러너에서 대조가 안 된다.
- `python` 은 Windows 스텁 — JSON 파싱은 `node -e`.
- 사장님이 PR 체크 완료 전에 머지할 수 있다 → **main CI 초록을 dispatch 전 반드시** 확인(I-3).
- 업데이트 팝업의 「자동 백업」 은 워치독 경로(db.conf 비번 직접)라 이번 결함과 무관 — 혼동 금지.
- 인계1 §5 함정(구현자 worktree · 옛 DLL · 로그 +9h · 하지 말 것 같은 문장에) 그대로 유효.
