## §1 [이해] 오더를 이렇게 이해했다
- 사장님 의중: [예] 뒤 고객이 **설명 없이** 끝까지 간다 — 덮개(꺼진 동안에도 유지) → 되돌린 판으로 켜지면 완료 [확인] → 첫 화면(메인 또는 로그인). **빈 화면 0 · 오류처럼 보이는 순간 0.**
- 안 하면: 오늘(10/5) 그대로 — 완료 안내 없음 · 옛 화면에 머묾 · F5 = 빈 화면(되돌린 판에 그 주소가 없다) ⇒ 고객은 고장으로 읽고 전화한다.
- 실측 근거(선행검증서 §2): 시작 뒤 기다림·새로불러오기 0(P1 · `LocalRollbackPage.razor:212-216`) · 1.3.49 에 `/data/rollback` 0건(M-5) · `api/app-version` 익명 401(M-1) · 세 번째 길은 502 를 실패 문구로 보임(🔴4 · 코드 판독) · 되돌린 판 ≥1.3.50 이면 완료 팝업 중복 가능(P6).
- 해석: 완료 안내는 **누르는 쪽 판(옛 화면)**이 띄운다. V = 서버가 준 되돌아갈 판이며, 살아난 판이 그와 같다고 확인한 뒤에만 쓴다.
