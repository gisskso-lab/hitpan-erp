## §4 ⬜ 사장님 손에 남은 것 (읽기 전용 · 값 안 본다)

```sql
SELECT status, COUNT(*) FROM tenants GROUP BY status;                      -- T-3 의 P0 여부
SELECT COUNT(*) AS n, MIN(attempted_at), MAX(attempted_at) FROM serial_verify_attempts;
SELECT result, COUNT(*) FROM serial_verify_attempts GROUP BY result;
SELECT COUNT(*) AS total, SUM(is_locked) AS locked FROM serial_verify_locks;
```
그리고 NCP 서버에서 **`df -h`** — 여유 + 🔴 **DB 볼륨과 `/var/www/updates` 가 같은 볼륨인가**(같으면 이 표가 자라 **업데이트 배포를 막는다** · 1.3.47 전례).
🔴 **이 숫자를 기다리느라 멈추지 않는다**(사장님 지시 「절차대로 봉합하고 진행해」). 들어오면 **긴급도만** 갱신한다.
