### 8-1. 사장님 결재 → PM 진행 → 본부장 인수 = 분 단위 사이클
- 14:30 진범 #1 commit 결재 (A)

- 15:05 PM 추천 (C→A→B) 결재
- ... 8회 결재 / 평균 37분

### 8-2. PM 추천 + 사장님 결재 분리 = 받아쓰기 차단
- PM이 옵션 3~4개 제시
- 사장님이 1개 선택 (또는 "PM 추천대로")
- **PM은 절대 단독 결정 안 함** (헌법 #29 정합)

### 8-3. 사장님 컨디션 우선
- PM 추천 시 항상 휴식 옵션 포함
- 사장님 보고는 1줄·예/아니오
- "사장님이 자야 PM이 살아남는다"

### 8-4. 헌법 31개 = PM 행동 규범 자동 작동
- PM이 외울 필요 없음
- 메모리 + CLAUDE.md 로 자동 로드
- 위반 시 즉시 인지 (예: WS-MIG-04 ALTER는 헌법 #29 → PM 자체 진행 차단)

### 8-5. 빠른 봉합 + 느린 결재
- 마이그 봉합 (코드 변경) = PM 자체 30분
- ALTER TABLE 결재 = 사장님 1회 결재 후 본부장 입회
- **속도와 안전의 절묘한 균형**
