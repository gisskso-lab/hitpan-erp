## §0 이 트랙의 정의 — 어디까지가 온보딩인가

> ## **"고객이 깔고 → 쓰기 시작하고 → 막혔을 때 답을 받는다."**
> 여기까지가 O 트랙이다. **파는 것은 K 트랙(마케팅자료)** 이고, 여기선 **이미 산 고객**을 다룬다.

| 들어가는 것 | 안 들어가는 것 (K 트랙) |
|---|---|
| 설치 안내서 · 7일 가이드 | 제품 소개서 · 제안서 |
| FAQ · 챗봇 지식 · CS 대본 | 가격표 · 랜딩 카피 |
| 장애 안내문 · 이관 안내문 | 대리점 판매 키트 |
| 온보딩 실전 검증 | 비교표 |

## §1 🔴 "병렬"은 "독립"이 아니다 — O 트랙이 기다리는 것

O 트랙 산출물의 **절반이 개발 산출물을 기다린다.** 안 기다리고 쓰면 **추측이 고객에게 나간다.**

| 못 쓰는 자료 | 기다리는 것 | 왜 |
|---|---|---|
| 설치 안내서 | 개발 **1-2** 백지 PC 설치 1대 | 실제 화면·실제 소요시간을 모르면 추측이다 |
| 화면이 들어간 모든 가이드 | 🔴 **결재 4 — 가상데이터 전용 테넌트** (캡처는 K 트랙 K1-2 가 찍는다) | 개발 PC 캡처 금지(#39) · 🔴 **기존 테넌트는 모회사 테스트 MDB = 실데이터**(#18·#22 · O-6) |
| CS 1차 응답 대본 | 개발 **1-3** CS 왕복 실물 1회 | 실제로 어떻게 도착하는지 모르고 못 쓴다 |
| "안 내면 어떻게 되나" 안내 | **결재 6·7** 4단계 조임 | 정책 없이 쓰면 **거짓말이 된다** |
| 메일로 보내는 모든 안내 | 개발 **0-1** 메일 발송 | 🔴 **메일이 안 가면 온보딩이 시작도 안 된다** |

## §4 O 트랙 ↔ 다른 트랙 의존 지도

```
개발 0-1 메일발송 ──────▶ O1-6 메일 문안 ────▶ O2-1 묶음
개발 1-2 백지설치 ──────▶ O1-1 설치 안내서 ──▶ O3-1 혼자 깔기(거든 0회)

결재 6·7 조임·내보내기 ─▶ O1-5 "안 내면" 안내
K 트랙 K1-2 화면캡처 ───▶ O1-2 7일 가이드 ───▶ O2-1 묶음
O2-6 지식 형식 ────────▶ 개발 4-7 챗봇 적재
```

🔴 **타임키퍼 임무**: 왼쪽이 늦으면 오른쪽도 늦는다. **당일 O 트랙 담당에게 알린다.**
