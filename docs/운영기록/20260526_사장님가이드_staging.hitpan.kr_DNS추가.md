## 🎯 Step 2: Cloudflared 터널에 staging 호스트 추가

### Cloudflare Zero Trust → Tunnels
1. 좌측 메뉴: **Zero Trust** → **Access** → **Tunnels**
2. 기존 터널 선택 (히트판 데모용 터널)
3. **Public Hostname** 탭 → **Add a public hostname**

### staging.hitpan.kr 추가
| 필드 | 값 |
|---|---|
| Subdomain | `staging` |
| Domain | `hitpan.kr` |
| Path | (비워둠) |
| Service Type | `HTTP` |
| URL | `localhost:5235` |

→ **Save hostname**

### api-staging.hitpan.kr 추가
| 필드 | 값 |
|---|---|
| Subdomain | `api-staging` |
| Domain | `hitpan.kr` |
| Path | (비워둠) |
| Service Type | `HTTP` |
| URL | `localhost:5258` |

→ **Save hostname**

## 🎯 Step 3: DNS 자동 등록 확인

- Cloudflared가 자동으로 CNAME 레코드 추가
- **DNS** 메뉴에서 확인:
  - `staging.hitpan.kr` → `<tunnel-id>.cfargotunnel.com` (Proxied 🟠)
  - `api-staging.hitpan.kr` → `<tunnel-id>.cfargotunnel.com` (Proxied 🟠)

---

## 🎯 Step 4: SSL 인증서 확인

- Cloudflare Universal SSL 자동 발급 (5~10분 소요)
- **SSL/TLS** → **Edge Certificates** → 신규 도메인 확인
- 발급 완료 시 https 접속 가능
