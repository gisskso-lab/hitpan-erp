### C-2 워터마크 SVG 생성 — 새 메서드 `TryBuildWatermarkSvg(...)`

🔴 **기존 함수에 얹지 않고 새로 짓는다**(§0 ㉡).

```
<svg xmlns='http://www.w3.org/2000/svg' xmlns:xlink='http://www.w3.org/1999/xlink' width='W' height='H'>
  <defs><filter id='s'><feColorMatrix type='saturate' values='{채도}'/></filter></defs>
  <g opacity='{명도}' filter='url(#s)'>
    <image x='0' y='0' width='W' height='H' xlink:href='data:image/{형식};base64,{로고}'/>
  </g>
</svg>
```

🔴 지킬 것:
- **`opacity` 는 `<g>` 에.** `<image>` 에 걸면 실측 ⓑ 로 **무시된다**
- **SVG 문자열이 깨지면 QuestPDF 가 예외를 던진다**(실측 ⓗ `Cannot decode the provided SVG image.`) ⇒ 문자열은 **우리가 전부 만들고**, 숫자는 **범위로 가둔 뒤** 불변문화권(`InvariantCulture`)으로 찍는다. 🔴 한국 로캘에서 소수점이 `,` 로 찍히면 SVG 가 깨져 **모든 양식이 500** 이 된다
- base64 외에 **고객 문자열을 SVG 안에 넣지 않는다**(파일명·경로 0건)
- 로고 바이트가 깨져도 **예외 0건 · 흰 종이**다(실측 ⓖ) — 그래도 **try 로 감싸고** `null` 을 돌려준다(#15 까닭 로그 한 줄)
- 수치 적용 순서 = 양식별 값이 **NULL 이면 공통값**, 공통도 없으면 제안값

### C-3 `print_background` 개방 — 축⒧-2 의 새 모양

`ResolveFormBackground`(`:1813`) — **인자 그대로**, 안의 조건만 넓힌다:

🔴 **그 한 줄의 주석을 지우지 말고 고쳐 적는다** — *"빼면 고객 종이에 그림이 또 찍힌다"* 는 경고는 **여전히 참**이다. 달라진 것은 **고객이 켠 경우에만 찍는다**는 것뿐이다. 끈 고객의 종이에 그림이 새면 **그게 사고다.**

## §E 갈래 E — 게이트 (C 뒤 · [4] 와 동시)

### E-1 🔴 축⒧-2 를 **지우지 않고 조건부로** 바꾼다

지금 축⒧-2 는 *"실인쇄에 그림이 안 깔리는 한 줄이 그대로다"* 를 잰다. [1-V] 지시: **「고객이 옵션을 꺼 두면 안 찍힌다」로 조건을 받는다. 지우는 것이 아니다.**

### E-2 신설 게이트 — 설계문서 §7 의 G-W1~G-W10 + 아래

| 게이트 | 재는 것 |
|---|---|
| G-W11 | 두 보관소(`FormBackgroundStore`·`CompanyImageStore`)의 울타리 축이 **각각** 동작하나 (복붙이 아니라 둘 다 사나) |
| G-W12 | 로캘이 `ko-KR` 일 때 SVG 소수점이 **`.` 로 찍히나** (C-2 — `,` 면 모든 양식 500) |
| G-W13 | `showBorder=1` 종이가 **봉합 전과 같나** (기존 고객 보호 · 대조군 = 봉합 전 바이트) |

### E-3 🔴 게이트를 짜는 사람이 지킬 것

- **대조군 없는 게이트는 「미측정」이다.** 켠 판·끈 판을 **둘 다** 재라
- **N/N 초록은 N 을 세지 말고 축을 세라.** 고정 입력 3줄짜리가 「늘 그렇다」를 단언하지 않게 하라
- **글자로 재는 축은 「어디 있나」를 못 잰다** — `opacity` 가 `<g>` 에 있나를 **글자로** 재면 `<image opacity>` 도 통과한다. **픽셀로 재라**
- 측정 방법은 이미 섰다: `Document.GenerateImages(...)` → PNG → **픽셀값 판독**(`scratchpad/opacityprobe` 가 본)
