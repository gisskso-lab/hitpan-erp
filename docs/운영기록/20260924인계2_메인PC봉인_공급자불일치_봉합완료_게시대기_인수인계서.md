## §1 무엇이었나 — 한 줄

**봉인은 TPM 금고(`MicrosoftPlatformCryptoProvider`), 해제는 소프트웨어 금고(1인자 `CngKey.Exists/Open`).**
같은 PC 인데 키를 못 찾는다 ⇒ **출입증이 발급된 적이 없다** ⇒ 자료관리 403 `main_pc_only`.

🔴 **등록은 실패한 적이 없다.** `mainpc-register` 는 200 이었다.
⚠️ 다만 **200 을 "등록 성공"의 증거로 읽지 마라** — `/api/devices` 라 `DeviceAuthMiddleware` 를 안 거친다.

### PM 동작 실측 (Software KSP 에만 키 생성)
```
Exists(name)           = True    ← UnsealKey:111 이 쓰는 1인자 오버로드
Exists(name, Software) = True
Exists(name, Platform) = False   ← SealKey:78 이 쓰는 공급자
```
⇒ **공급자별 키 공간 분리 확정.**
