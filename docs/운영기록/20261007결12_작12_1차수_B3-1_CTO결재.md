## §2 Z-2 — 🔴 **이미 올라갔다** · D-3(P1) 인증 없는 무한 쓰기 · TTL 0 · 🟡 **조건부 (면죄 논거 반려 · 즉시조치 1건)**

### ① 🔴 [4] 의 면죄 논거는 **성립하지 않는다**
[4] §14-3: 「봉합 전에도 성공 경로는 썼고 늘어나는 것은 실패 경로 2행」 — **비교 대상이 다르다.**

| | 봉합 전 | 지금 운영 |
|---|---|---|
| **유효 키** 1회 | 1행(감사) | 1행 + 리셋 UPDATE |
| **자격 없는 요청** 1회 | 🟢 **0행** (`:92` 즉시 return — [4] 자신의 기준선 1) | 🔴 **2행** (`serial_verify_attempts` 1 + `serial_verify_locks` UPSERT 1) |
| 잠긴 뒤에도 | — | 🔴 **매 요청 1행** (`:156`) |
| 지문을 매번 바꾸면 | — | 🔴 `uk_fingerprint` 가 안 걸려 **잠금 행 무한 증식** |

성공 경로의 쓰기는 **유효 라이선스 키라는 자격**을 요구한다. 실패 경로는 **아무 자격도 요구하지 않는다.** ⇒ 봉합이 만든 것은 쓰기량 증가가 아니라 **「인증 없는 쓰기 경로의 신설」**이다. **「봉합 전에도 썼다」는 면죄가 되지 않는다.**
보강: 백오피스 전역 rate limit **0건**([4] S-1 실측) · `machineFingerprint` 는 서명 0 · 검증은 `IsNullOrWhiteSpace` 하나(`:50`) ⇒ **비용 0 으로 무한 회전.** 정리 수단은 `TenantsAdminController.cs:240` 하나뿐이고 실패행은 `tenant_id` NULL 이라 안 지워지며 `serial_verify_locks` 는 정리 코드 **0 + `tenant_id` 칼럼도 없다.**

### ② 「며칠 안에 디스크가 어떻게 되나」 — ⚠️ **지금은 답할 수 없다. 재지 않았다**
- **정상 트래픽만이면**: 틀린 키를 넣는 사람은 설치 중 오타뿐이다 ⇒ 하루 수십~수백 행 수준. **몇 년이 걸려도 안 찬다.** 🟢
- **악의가 오면**: 상한은 **공격자의 대역폭뿐**이다(rate limit 0). 행당 hex 해시 2개(각 64자) + 인덱스 3개(DDL `:463-476`) ⇒ ⚠️**어림 수백 바이트/요청.** 초당 수백 요청이면 **하루 단위로 GB** 가 쌓인다.
- 🔴 **터지는 자리는 백오피스 DB 디스크(NCP)** 다. 작10 에서 **디스크 부족이 업데이트를 막은 전례**가 같은 모양이다([[project_update_blocked_disk_worktrees_20260929]]).
- ⚠️ **NCP 여유 용량 · DB 볼륨과 업데이트 webroot(`/var/www/updates`)가 같은 볼륨인지 재지 않았다**(#39 서버 무접촉).

### ③ ⇒ **즉시조치 1건 (쓰기 0 · 읽기만)** — §7 로 올린다
숫자 없이 「며칠」을 말하면 그게 다음 사람에게 사실이 된다. **읽기 1회로 끝난다.**

### ⇒ 판정 Z-2 = 🟡 **조건부 — 「봉합 전에도 썼다」 면죄 반려 · 되돌림 사유는 아님 · 즉시 계측 후 사장님 결재**

## §3 Z-3 — ⓒ 를 「보안 봉합」으로 내보내도 되나 · 🟡 **조건부 승인**

`InstallerBootstrapController.cs:347` — `string.Equals(req.Purpose, "tunnel-recovery", OrdinalIgnoreCase)` 일 때**만** 축소. 생략·오타·모르는 값은 **전체 응답**. ⇒ **공격자는 안 보내면 된다. 효과 0 은 사실이다.**(내가 코드로 확인)

**효과 0 인 것을 1차수에 넣은 것은 정당하다.** ⓒ 의 실질은 공격 방어가 아니라 **비밀값이 머무를 자리를 줄이는 것**이다 — 워치독이 받지 않으면 `bootstrap.token`·`tokenKey`·`tenant` 묶음 6개가 고객 PC 메모리·로그·`db.conf` 에 **남을 자리가 없다.** **#22 본사 데이터 최소주의의 정방향**이고, 기본값을 전체로 둔 결정(하위호환)도 옳다.

**「막았다」로 읽힐 위험** — 🟢 **문서는 차단됐다**: 개발명세서 §3 첫 줄 「공격자 대상 효과는 0 … 「막았다」로 쓰면 거짓」 · 작지서 §11-3 · 리뷰서 S-3. 🔴 **조건** — 1년 뒤 사람은 문서가 아니라 **커밋 메시지·게시 노트·보고**를 읽는다. 거기에도 같은 한 문장이 있어야 한다. 그리고 **「비밀값 2개 줄였다」가 아니라 「비밀값성 4항목 중 2개만」**이고, 못 뺀 `bootstrap.tokenKey` 는 코드 주석(`:173-174`)이 스스로 **「베타 = 전 고객 공용키」**라 적은 값이다 — **유효 키 1개를 가진 자가 전 고객 공용 서명키를 그대로 받는다.** 이 사실을 성과 보고에서 빼면 **반려**다 ⇒ §9 S-3.
