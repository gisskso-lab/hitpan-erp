## 4. 절대 검증 — 워크플로우 3흐름 무결성 (헌법 #20)

| 흐름 | 시나리오 | 기대값 |
|---|---|---|
| ① 매입 | 발주 → 매입 → 재고 반영 | 재고 ↑ 동일 tx |
| ② BOM | 완제품 생산 | 완제품 ↑ + 자재 ↓ 동일 tx |
| ③ 판매 | 견적 → 수주 → 거래명세서 → 세금계산서 | 재고 ↓ → 매출 ↑ |

한 단계라도 끊기면 P0 핫픽스 즉시 발진.
