## 3. ✅ D6-P0-02 봉합 완료 (2026-06-21, 사장님 A안 결재 → 봉합 → 2회 교차검증 통과)

> 통신 무결성 천장을 누르던 **유일한 P0**. 사장님 A안("토큰 기반 통일") 결재받아 봉합 완료. 베타 GO 차단 #1 해소(실측 1회 남음).

### 결함(봉합 전)
현재 터널은 **관리형(토큰 기반)** — 인스톨러가 `cloudflared service install {token}`으로 설치, 자가관리 자격증명 파일(`~/.cloudflared/{tunnelId}.json`, credFile)을 디스크에 안 만듦. 그런데 워치독 자가복구는 옛 자가관리 모델 전제였음:
- WS28C 재생성: `tunnel token --cred-file` — 관리형엔 credFile 없어 무의미·자해
- WS28D 재설치: `service install`을 토큰 없이 호출 → 관리형 터널 안 붙음

### 봉합 (A안 — 토큰 기반 통일, file:line)
1. **인스톨러** `HitPan-Universal.iss:952~` — db.conf에 `TUNNEL_TOKEN=` + G_TunnelToken 저장(종전엔 service install 인자로만 쓰고 버림). db.conf는 직후 icacls로 Administrators·SYSTEM만 읽기 ACL(헌법 #22).
2. **WS28D** `WS28D_ServiceReinstall.cs:47~` — db.conf의 TUNNEL_TOKEN으로 `service install {token}`. 토큰 부재(LOCAL·구버전)면 인자 없이 폴백+경고.
3. **WS28C** `WS28C_TunnelSecret.cs:99~` — 관리형(TUNNEL_TOKEN 존재+credFile 부재) 감지 시 자가관리 재생성 스킵, true 반환(D 위임). 토큰 없으면 종전 자가관리 경로 폴백(하위호환).

### 교차검증으로 추가 발견·봉합 (거짓봉합 직전 차단)
- **P1 (설계팀장 1차 발견)**: WS28C가 D에 위임해도, Worker의 D 게이트가 `!ServiceExists` 단독이라 "secret 무효화 + 서비스 생존"(=헌법 #28 5/15 demo 대표 다운 모드)에서 D가 호출 안 됨 → 토큰 재설치 발화 안 함. 자가복구 사각지대.
  - **봉합**: `WS28C.IsManagedTunnel()` 공개 헬퍼 추가 + `Worker.cs` 세 경로(정기·FullRecovery·PostReboot) D 게이트를 `!ServiceExists() || (secretInvalid && IsManagedTunnel())`로 확장. 정상 터널에선 secretInvalid=false라 미진입(자해 없음, CoolDown 추가 보호).
- **P2 (검증팀장)**: WS28D ExitCode 실패 로그가 cloudflared stderr/stdout 직접 출력 → 토큰 echo 이론적 노출면. **봉합**: tunnelToken을 `***REDACTED***`로 마스킹(`WS28D:84~`).
- **P3 (설계팀장 재검증)**: 이번에 "서비스 살아있을 때 D 강제" 경로를 열었더니, WS28D `sc.Start()`가 이미-Running 서비스에 호출→예외→복구 오기록. **봉합**: WS28C와 동일하게 Running이면 Stop→Start 가드 추가(`WS28D:95~`).

### 검증 상태
- 빌드 errors 0 + warnings 0 (헌법 #19) — 3회 재빌드 모두 통과
- 2회 교차검증(설계·검증팀장) — P1 봉합 확정, 새 회귀 0, 자해 0
- **남은 것 = 실측 1회**: 신규PC에서 "터널 강제 종료 → 5분 내 자가복구"(섹션 4 시나리오 5). 코드상 닫혔으나 실제 PC 검증해야 진짜 통과.

### 잔여 P3 (봉합 범위 밖, 비차단)
- `DbConfReader.cs:119~` Parse의 빈 catch(정적 메서드라 로거 없음) — 토큰 미로드 추적 불가. 헌법 #15 정합 위해 다음 점검에서 흔적 로그 추가 권고. 검증팀장 "차단 아님" 분류.

1. EXE 설치 → 부모계정 생성 → **로그인** (A-P0-1-REGRESSION 봉합 검증: 부모계정이 결재 화면 진입되나)

4. **같은 자재 쓰는 조립품 2라인 판매 확정** (B-1 BOM 검증)
5. 터널 강제 종료 → **워치독 자가복구 관찰** (D6-P0-02 검증: 5분 내 복구되나) ← D6-P0-02 봉합 후
