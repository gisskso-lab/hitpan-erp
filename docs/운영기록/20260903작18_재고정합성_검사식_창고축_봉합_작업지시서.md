## 1. 🔴 [1-V] 선행검증 결과 — 오더 범위가 줄었다

**사장님이 만들라고 하신 구조는 이미 서 있다.** 신설할 것이 없다.

| 오더 항목 | 판정 | 근거 |
|---|---|---|
| 마스터를 창고별로 | 🟢 **이미 있음** | `item_stock UNIQUE (tenant_id, item_id, warehouse_id)` |
| 원장도 창고별로 | 🟢 **이미 있음** | `stock_ledger.warehouse_id NOT NULL` |
| 반품 시 창고 자동세팅 | 🟢 **이미 돈다** | 반품 4건 전부 나간 창고로 복귀 (실측) |
| "안 맞을 일이 없다" | 🟢 **맞다** | 창고축 대조 3창고 전부 차이 0 |

**⇒ 이 작업의 실체는 「구조 신설」이 아니라 「검사식 1줄 봉합」이다.**

🔴 **범위를 임의로 넓히지 마라** — 창고 기능 재설계·화면 신설 **금지**.
사장님 오더의 목적은 *"재고가 맞게"* 인데, **재고는 이미 맞다.** 틀린 건 검사다.

## 2. 작업 범위

### W1. 🔴 게이트 **선행** 작성 (봉합보다 먼저)

**담당**: 검증팀 (🔴 **봉합자가 짜지 않는다** — SoD)

`item_stock` 창고별 행 vs `stock_ledger` 창고별 누적을 **창고를 포함해** 대조하는 게이트.

- [ ] 게이트를 짜고 **봉합 전에 돌려 🔴 FAIL(빨간불)을 확인한다**
      → 지금 검사가 3건을 뱉으므로 게이트도 FAIL 이 정상. **초록이면 그 게이트는 가짜다.**
- [ ] 대조군: 창고 합산 시 0건 / 창고 미포함 시 3건 — **둘 다 숫자로 재현**
- [ ] 🔴 **DB 게이트로 짠다** — `DbGateEnvironment` 승계 (작14). CI 에서 SKIP 되면 실패로 판정
- [ ] 짝지은 건수를 **반드시 함께 출력** (⚠️ 대조군 0인데 PASS 준 사고 재발 방지 · 선행검증서 §5 #6)

### W2. 검사식 봉합

**담당**: 백엔드 개발자 1명

**파일**: `src/HitPan.Application/Services/FinanceService.cs:561-573`

```sql
-- 현재 (창고를 안 본다)
LEFT JOIN stock_ledger l ON l.item_id = s.item_id AND l.tenant_id = s.tenant_id
GROUP BY s.item_id, s.current_qty

-- 봉합
LEFT JOIN stock_ledger l ON l.item_id = s.item_id AND l.tenant_id = s.tenant_id
                        AND l.warehouse_id = s.warehouse_id
GROUP BY s.item_id, s.warehouse_id, s.current_qty
```

- [ ] JOIN 에 `warehouse_id` 추가
- [ ] `GROUP BY` 에 `s.warehouse_id` 추가 (안 넣으면 창고별로 안 갈린다)
- [ ] 🔴 **다른 곳은 건드리지 않는다** — 같은 메서드의 다른 14개 검사 무접촉
- [ ] DDL 변경 **0건** (표 구조는 이미 옳다 — 마이그레이션 없음)

### W3. 매입 대칭 확인

**담당**: 백엔드 개발자 1명

- [ ] `CheckIntegrityAsync` 의 **나머지 14개 검사**에 같은 창고축 누락이 있는지 전수 확인
- [ ] ⚠️ **복붙 금지** — 있더라도 각 검사의 의미를 읽고 판단 (매입채무 ≠ 외상매출금 교훈)
- [ ] 발견 시 **이 지시서 범위에 포함할지 PM 에게 보고 후 결정** (임의 확장 금지)

### W4. 무력화 시험

**담당**: 검증팀 (🔴 봉합자 아닌 사람)

- [ ] 봉합한 `AND l.warehouse_id = s.warehouse_id` 를 **도로 빼면 게이트가 FAIL** 하는가
      → 빼도 통과하면 그 게이트는 가짜 (누적 22번)
- [ ] `GROUP BY` 의 `s.warehouse_id` 만 빼도 FAIL 하는가
- [ ] 🔴 **주석 처리가 아니라 실제로 지우고 돌린다** (이름만 남아 통과한 사고 있음)

### W5. 화면 확인 — "고쳤나" 가 아니라 "갔나"

**담당**: 검증팀

- [ ] `/accounting/integrity` 화면에서 **「확인 필요 1건」 → 「0건」** 으로 바뀌는가
- [ ] 🔴 **서버만 보고 판정하지 않는다** — 화면 스크린샷으로 확인 (작7 교훈)
- [ ] 나머지 14개 검사가 여전히 「정상」인가 (회귀 0)
