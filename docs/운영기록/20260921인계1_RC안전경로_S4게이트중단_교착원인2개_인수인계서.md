## §5. 함정 (이번에 새로)
1. **「좁아졌다」를 안 재고 썼다** — 설계 2판이 「잠금이 거래처 1건으로 좁아진다」고 적었고 PM 이 그대로 보고했다. [3-V] 실측은 회사 전체였다(1213 교착). **기대는 실측 전까지 사실이 아니다.**
2. **초록불이 감시의 증거가 아니다** — 반품 잠금절만 빼도 **전체 1,524 시험이 한 건도 안 깨졌다**([4] 전수). 게이트가 제품 문장을 **복제**하면 감시자가 0 이 된다 → 제품 상수를 쓰게 하라.
3. **재시도가 결함을 덮는다** — G-RC5 는 3회 되돌리고 성공해도 초록이었다(병렬이슈60). 「성공」이 아니라 **시도 횟수·교착 상대**를 재라.
4. **원인은 하나가 아닐 수 있다** — 인덱스로 잠금 범위를 좁혀도 교착이 남았다. 상대는 유니크 간극이었다(`SHOW ENGINE INNODB STATUS` 로 확인 · MariaDB 11.4 엔 `data_locks` 가 없다).
5. 서브에이전트 턴 한도(구현 60 · 검증 50 · 주심 25)로 **7번 멈췄다** — 착수문에 「N턴마다 결과 먼저 문서」·「대기는 포그라운드 블로킹」·「멈추기 전 커밋」을 넣어라. 5분 넘게 쉰 에이전트는 새로 띄운다(토큰 매뉴얼 §4-5 · 훅이 막는다).
6. 마이그 신설 시 **출하 DDL `schema_migrations` 시드**를 빠뜨리면 신규 설치 고객이 마이그를 다시 돈다 — 기존 게이트가 잡았다(`MigrationLocationGuardTests`).
7. Git Bash `sed -i` 는 CRLF 파일을 LF 로 바꿔 「수정됨」만 남긴다 — `git diff` 0 확인 후 checkout.
