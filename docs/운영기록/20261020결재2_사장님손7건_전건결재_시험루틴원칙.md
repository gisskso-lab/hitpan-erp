# 🔴 §2 별첨 = **시험 루틴 원칙** (신설 · 전 차수 적용)

> **"테스트용 PC 는 있지만, 모든 테스트는 실 사용 고객이 동일하게 사용하는 루틴·환경으로 시작한다."**

## 2-1 무엇이 바뀌나 — 축이 하나 늘었다

| | 종전 규범 | 🆕 오늘 더해진 것 |
|---|---|---|
| 축 | **환경** — 백지 PC + 지저분한 PC 둘 다 | 🔴 **루틴** — *들어가는 방법*도 고객과 같아야 한다 |
| 왜 필요한가 | 개발 PC 는 이미 다 깔려 있어 「되는 것처럼」 보인다 | 🔴 **환경만 백지여도 넣는 방법이 우리 방법이면**(빌드 복사·수동 배포·DB 수동 생성·키 손기입) **고객이 겪는 실패가 그 자리에서 전부 건너뛰어진다** |
| 위험 | — | 🔴 **시험용 PC 가 또 하나의 개발 PC 가 된다** |

## 2-2 🔴 시험용 PC 사용 규칙 — 이 순서를 벗어난 시험은 **무효**

| | 지킬 것 | 🔴 하면 무효 |
|---|---|---|
| 시작 | **랜딩에서 설치 파일 받기** → 실행 → **라이선스 키 1개 입력** | 레포 빌드 산출물 복사 · `dotnet run` · DB 수동 생성 · `appsettings` 손기입 |
| 올리기 | **자동 업데이트 경로**만 · Major 는 **팝업 Y/N** 그대로(#43) | 재설치 · 덮어쓰기 · 파일 교체 |
| 접속 | **터널 도메인**(`{고객사ID}.hitpan.kr`) | `localhost` 통과를 검증으로 적기 |
| 손 | 손을 댔으면 **그 손을 기록**한다 | 손 1번 들어갔는데 「고객 손 0번」으로 적기 ⇒ **판정 철회** |

## 2-3 적용 범위 — **전부**

통신 무결성 **17시나리오** · **B2 게이트 숫자 3개** · **EVF 6대 영역** · 화면 **캡처**(3번 환경) · 자료 이관 시험.
🔴 **시험 방법이 고객과 다르면, 숫자가 나와도 그 숫자는 우리 것일 뿐이다.**

🔴 **PM 자기점검**: 이 원칙은 내가 먼저 세웠어야 했다. 나는 안내서에 *"망가뜨려도 되는 윈도우 기계 1대"* 라고만 적었고 **그 기계를 어떻게 쓸지는 안 적었다.** 사장님이 그 빈 칸을 채우셨다.

| 연체 | 무엇이 일어나나 | 고객에게 하는 말 |
|---|---|---|
| **3일째** | 상득하게 **알림** | 「요금이 아직 확인되지 않았습니다」 |
| **7일째** | **경고** | 「○일 뒤 새로 적는 것이 제한됩니다」 |
| **14일째** | **잠금 — 읽기만 가능** | 「조회·내보내기는 계속 되십니다」 |

🟢 **결재 7(10/19 확정)과 정합** — 잠금까지 가도 **내보내기는 끝까지 개방**한다. 데이터 주권(#18·#22)과 같은 방향이다.
