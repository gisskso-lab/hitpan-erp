## §2 🔴 다음 사람이 밟을 함정 — 9건

1. 🔴 **`_ => "본사안내"` 를 지우지 마라.** 안 쓰이는 줄처럼 보이지만, 백오피스가 **7번째 값**을 더하는 순간 `switch` 식이 던지고 **수신 사이클이 죽어 같은 응답에 실린 본사 답변까지 못 내려온다**(10/12 사고와 같은 모양). 지워 보면 컴파일러도 `CS8509` 를 띄운다. G-W10-3 이 이 자리를 **실제 DB 에서** 돈다.
2. 🔴 **옛 행을 고쳐 적지 마라.** 낱말은 수신 때 본문에 **글자로 박혀** 저장된다. 이미 내려간 쪽지는 `[본사안내]` 그대로가 **정상**이다 — 고쳐 적으면 「이미 보낸 글의 종류를 다른 이름으로 덮어 적는」 거짓말이고 #1 위반이다. G-W10-4 가 막는다.
3. 🔴 **CI 의 Build 잡 초록을 증거로 쓰지 마라.** 그 잡은 **`HITPAN_GATE_SKIP_OK: 1`** 이다. DB 게이트의 판정은 **`DB 게이트 (Integrity — 실제 DB 실행)`** 잡뿐이다. 판별은 **소요시간** — DB 게이트가 **2초**면 돈 것이고 **1~3ms** 면 정적이거나 건너뛴 것이다.
4. 🔴 **낱말을 고치려면 기대값을 두 곳에서 함께 고쳐라** — `G-W10-7`(고정 규격표)와 **정본 문서**(10/13 백오피스 설계 §5-1 · 일정표 §1 결-A). G-W10-7 은 **일부러** 글자를 박아 뒀다.
5. 🔴 **배선 게이트와 내용 게이트는 다른 물건이다.** G-W10-1·2·5 는 기대값을 **과녁 자신**에서 가져오므로 **낱말 내용은 원리적으로 못 잰다**(실측: 낱말을 엉뚱한 말로 바꿔도 6/6 초록이었다). 내용을 보는 자리는 **G-W10-7 하나**다.
6. 🔴 **`CsPipelineRoundTripGate` 는 이 PC 에서 못 돌린다.** DB **2개**를 DROP/CREATE 하고, 로컬 `hitpan` 계정은 **실물 DB 이름**에만 권한이 있어서 쓰면 **실물을 지운다**(#39). 로컬 실측은 **`hitpan_trgtest` 하나만** 쓴다(9/27·10/7 선례).
   - 로컬 명령: `HITPAN_REQUIRE_DB=1 HITPAN_DB_USER=hitpan HITPAN_DB_PASS=<개발비번> HITPAN_W10_LABEL_DB=hitpan_trgtest dotnet test … --filter "FullyQualifiedName~ErpCsPurposeLabelGate"`
7. 🔴 **낱말 길이를 바꾸면 본문 자름이 바뀐다.** 본문 표시 상한이 **2000자**이고 머리글이 길어진 만큼 경계 근처 본문이 더 잘린다(최대 4자). 자를 때 경고가 남는다. **상한 변경은 별건 결재(결-B′).**
8. 🔴 **`Scan secrets` 가 빨개도 내 커밋이 아닐 수 있다.** 브랜치 **첫 밀기**는 `base` 가 없어 **이력 전체**를 훑는다(이번 20,331 chunks). PR 이벤트 **델타 스캔**이 진짜 판정이다(이번 **37 chunks · verified 0 · unverified 0**). 🚫 `exclude-paths` 로 빨간불을 지우지 마라.
9. 🔴 **`OWASP ZAP Baseline DAST` 는 `main` 에서 10/13부터 5회 연속 빨강**이다. 작2 전부터 그렇고 이 차수가 건드리지 않았다 — **별건**이다. 「작2 때문」이라 적지 마라.
