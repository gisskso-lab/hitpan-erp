## 2. 의중 확인 (결재 창 · 받은 그대로)
| 질문 | 답 |
|---|---|
| 평소 = 전체 · 고객 상세 화면에 있을 때만 그 고객사 · 나가면 다시 전체 — 맞나 | **「더 넓게」** — 고객 상세 말고도 **그 고객사를 보는 화면**에서는 그 고객사만 |
| 고객사 화면에서 표시줄 단계를 누르면 | **「그 고객사만 걸러진 CS 목록 (Recommended)」** — 고객A/S창구 목록이 그 고객사 + 그 단계로 걸러져 열림(숫자와 목록이 같아야 헷갈리지 않음) |
| 걸러졌다는 것을 글자로 | **「회사명 붙임 (Recommended)」** — 표시줄 앞에 회사명 · 왼쪽 메뉴의 빨간 CS 숫자는 언제나 전체 그대로 |

## 3. 지금 알고 있는 것 (PM 읽기 · 실행 0)
- 표시줄 = 백오피스 레이아웃 아래 띠 · 4단계(읽지 않음 · 처리되지 않음 · 처리 완료 · CS평가 완료) + 전체 · 세는 곳은 서버 한 곳 · 60초마다 다시 셈 · 누르면 고객A/S창구 그 단계로 이동 · 사이드바 빨간 숫자와 같은 값.
- 고객 상세 화면 = 고객 목록 → 고객사 클릭.

## 4. [1-V] 가 실측할 것
- 「그 고객사를 보는 화면」 전수(주소에 고객사가 들어가는 화면 · 고객사 하나를 다루는 화면) — 목록을 대표께 보여 드리고 확정.
- 세는 서버 길에 고객사 거름을 더할 수 있나 · 사이드바 숫자(전체)와 분리되나 · 대리점 화면 쪽 영향.
- 고객A/S창구 목록이 고객사 거름 + 단계 거름을 함께 받을 수 있나(주소 칸).
- 별건(상태 칸 안 펼쳐짐)과 같은 파일을 고치는지 · 순서.
