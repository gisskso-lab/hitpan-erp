## 4. ② SNS 노출 자동화 · 마케팅 자동화 관리 — 🟠 검토

> 사장님: *"필요할것 같아"* — **확정이 아니다.**

### 4-1. 두 가지가 섞여 있다

| | 무엇 | 성격 |
|---|---|---|
| **SNS 노출 자동화** | 콘텐츠를 SNS 에 자동으로 올리는 것 | 외부 연동 |
| **마케팅 자동화 관리 프로그램** | 그것을 관리하는 화면 | 우리가 만드는 것 |

**⇒ 착수 전 이 둘을 분리해서 판단해야 한다.**

### 4-2. ⚠️ 사장님 상황과 걸리는 부분 (정직하게)

| 제약 | 내용 |
|---|---|
| **사업자등록 = 베타 이후(8월 말)** | SNS 비즈니스 계정·광고 계정은 **사업자 정보를 요구하는 경우가 많다** ⚠️미확인 |
| **실업급여 수급 중** | 사업 활동으로 보일 수 있는 것에 주의 필요 |
| 광고비 | 자동화 도구는 만들 수 있으나 **노출에는 돈이 든다** |

> 🚫 헌법상 **PM 은 사업자 회원 가입·법인카드·유료 광고 계정을 권하지 않는다.**
> 위 ⚠️미확인 항목은 **단정하지 않는다** — 실제 가입 조건은 확인이 필요하다.

### 4-3. 착수 전 정할 것 (마케팅팀장)

| # | 항목 |
|---|---|
| 1 | **어느 SNS 인가** — 채널마다 조건·효과가 다르다 |
| 2 | **무엇을 올리나** — 올릴 콘텐츠가 있어야 자동화가 의미 있다 |
| 3 | 사업자등록 전에 **개인 명의로 가능한 범위** ⚠️미확인 |
| 4 | 자동화 도구를 **직접 만드나 / 있는 것을 쓰나** |
| 5 | **비용** — 도구·광고비 |

## 5. ③ AI 영상 제작 — 🟡 사장님 제안

> 사장님: *"제안함"* — 결정이 아니라 **아이디어를 올리신 것**이다.

### 5-1. 🔴 헌법 #23 이 정면으로 걸린다

> **외부 노출에 "AI·Claude·Cursor" 단어 금지**

**영상은 고객이 직접 보는 것**이다. 다음을 지켜야 한다:
- 영상 안에 제작 도구가 드러나면 안 된다
- 영상 설명·태그에도 마찬가지
- **워터마크가 박히는 도구는 쓸 수 없다**

### 5-2. 착수 전 확인할 것

| # | 항목 | 성격 |
|---|---|---|
| 1 | 도구의 **상업적 사용 허용** 여부 | ⚠️미확인 · 법무 검토 |
| 2 | **워터마크** 여부 | 헌법 #23 |
| 3 | 만들어진 영상의 **저작권 귀속** | ⚠️미확인 · 법무 검토 |
| 4 | **무엇을 보여줄 영상인가** | 마케팅팀장 |
| 5 | 실제 히트판 화면을 담나 | 담는다면 **고객 자료가 노출되면 안 된다** |

> 🔴 **5번 주의**: 데모 영상에 실제 거래처·금액이 찍히면 헌법 #18·#22 위반이다.
> 빈 데이터 또는 명백한 가짜 자료만 쓴다.

### 5-3. PM 소견 — 순서

**영상은 ①(랜딩 디자인)이 끝난 뒤가 낫다.**
화면이 바뀔 예정인데 영상을 먼저 만들면 **금방 옛것이 된다.**

⚠️ 이건 소견이지 결정이 아니다. 마케팅팀장 판단이 우선한다.

## 7. 순서 — 다른 과제와의 관계

```
[최우선] 베타 안전성 · 본사 워크스페이스 검증
             ↓
   ERP 화면 수정 ──▶ CS 챗봇
             ↓
   백오피스 (영업·CS 집합체)
             ↓
   ① 랜딩 디자인  ──▶  ③ AI 영상
             ↓
   ② SNS 자동화 (검토 후)
```

**왜 랜딩이 뒤인가** (PM 소견)
- 랜딩은 **파는 화면**이다. 팔 물건(ERP)이 먼저 탄탄해야 한다
- ⚠️ **단 §3-3 결함 4건은 예외다.** 가입이 안 되는 것은 디자인 문제가 아니라 **작동 문제**이므로,
  랜딩 순서와 무관하게 처리 판단이 필요하다

📌 **4대 과제 ④(요금 정책)와도 만난다** — 랜딩의 가격 화면이 그 결과를 보여준다.
