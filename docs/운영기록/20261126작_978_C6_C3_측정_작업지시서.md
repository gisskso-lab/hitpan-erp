- 대표로 **로그인 됨 + 「접속기기 확인」 열림** = 그 계정이 관리자 클레임(`tenant_admin`) + `is_parent = 1`. 로그인이 `is_active` · `is_deleted` 를 거르는지는 [4] 가 코드 한 줄로 확인해 기록(덧 :30 의 「살아 있는 대표 · tenant_admin」 네 조건 중 본인 몫).
- 「대표 수 정확히 1」 은 F-1 로 못 가림(1V T-2 :124) → F-2 「대표」 표시 개수로 보완. 사원과 연결 안 된 대표 계정은 F-2 에 안 보일 수 있음 → 0 이면 「대표 0명」 으로 판정하지 않고 멈춤.

### 2-3 측정 방법 = 사람 손 (저장소 `scripts/playwright-audit/` 꼴 읽은 결과)
- 원격 회사 대상 꼴(`verify-1335-return-20260903.js`)은 판정 규율이 맞으나(본문으로 가름 · 못 잰 것 UNKNOWN · 대조군 필수 :11-15) 계정 기본값을 파일 안에 두는 꼴이라 그대로 쓰면 자격증명 모양 규칙에 걸림 · CI 꼴(`ci/`)은 CI 안 127.0.0.1 시드 전용.

- 스크린샷: 접속 기기 · IP · 계정 이름이 찍히므로 **저장소에 올리지 않음** · 측정자 로컬 보관 · 기록 문서엔 파일 이름 + sha256 앞 16자만.
