## §1 무엇이 적발됐나 (값은 적지 않는다)

레포 자신의 제외목록 파일이 **의도적으로 남겨 둔 진탐 2건**이다.

| 자리 | 무엇 |
|---|---|
| `installer/install.bat` (51·85·92행) | 모든 고객 PC 에 **같은 DB 계정 비번**으로 MariaDB 계정을 만든다 |
| `scripts/backup-daily.ps1:7` | 환경변수가 없으면 하드코딩 값으로 떨어진다 |

`.github/trufflehog-exclude-paths.txt` 원문:

> *"이 둘은 **오탐이 아니라 진짜 문제**다. 제외하면 덮는 것이다. ⇒ 스캔은 계속 빨간 X 로 남는다. **그것이 의도다**. ⇒ 별건 작업지시서로 봉합한다."*

| | |

| 근거 (사장님) | **설치마법사가 안 돌 수도 있다** |

### 🔴 다음 사람에게 — **고치지 마라**
설치마법사는 **고객 PC 에서 혼자 끝까지 돌아야 한다**(원칙 #30 — 본사 의존 0 · 라이선스 키 하나만 입력).
비번을 PC 마다 다르게 만들면 **설치·업데이트·백업·워치독이 그 값을 서로 주고받아야** 하고, 그 통로가 지금 없다.
⇒ 🔴 **「보안상 당연히 고쳐야 한다」는 이유로 임의로 손대면 설치가 멈춘다.** 사장님 결재 없이 건드리지 않는다.

## §3 🔴 안 하는 것 (명시)

| | 왜 |
|---|---|
| `trufflehog-exclude-paths.txt` 에 **경로 추가 금지** | 사장님 결재는 **「비번을 유지한다」**이고 **「적발을 가린다」가 아니다.** 제외에 넣으면 그 파일에 **훗날 진짜 키가 들어가도 CI 가 못 잡는다**(그 파일 자신이 적어 둔 경고) |
| 빨간 X 를 없애려는 손질 금지 | 🔴 **스캔이 빨간 채로 남는 것이 설계다.** 다음 사람이 「빨강이니 뭔가 잘못됐다」로 읽지 않게 이 결재문을 남긴다 |
| 비번 값을 문서·커밋메시지에 적기 금지 | 누적 3회 지적된 자리 — **가짜 값도 잡힌다** |

## §4 🔴 남는 위험 (숨기지 않는다)

**한 고객사 PC 가 뚫리면 같은 자격증명으로 전 고객사 DB 계정이 열린다.**
이 위험은 이 결재로 **사라지지 않고 수용**된 것이다.

| 위험을 줄이는 조건 (지금 사실) | 상태 |
|---|---|
| DB 가 고객 PC **로컬**에만 있다(원칙 #22·#30 · 클라우드 이전 금지) | 🟢 |
| 본사가 고객 업무 데이터를 안 가진다(#18) ⇒ 한 PC 침해가 **본사·타 고객 데이터**로 번지는 경로는 아니다 | 🟢 |
| MariaDB 포트가 외부에 열려 있나 | ⚠️ **미측정** — 재지 않았다. 「막혀 있다」고 적지 않는다 |
| 같은 비번으로 **원격** 접속이 되나 | ⚠️ **미측정** |

🔴 ⚠️ 두 칸은 **다음 차수에 잴 거리**로 등재한다. 재기 전에는 *"로컬이라 안전하다"* 고 적지 않는다.
