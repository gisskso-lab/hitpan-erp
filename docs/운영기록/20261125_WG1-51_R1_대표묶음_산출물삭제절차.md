> 작성 2026-11-25 · PM 브라운킴 · 상태 🟢 진실원(R1 발사 전 조건 · [3-V] 2차 R-8)
> 근거: 대표 결재 §157(「올리고 바로 지움」 · 대안 B) · 법무 1줄 `../검증/외부/20261125_법무_R1_대표PDF묶음_1줄.md` · [3-V] 2차 `../검증/병렬이슈/20261125_3V_WG1-51_장치16차_대표묶음_보안상무.md`(R-8 · B-3 · N-6) · 결재 기록 §159 · §162

## 1. 무엇을 지키나
- 묶음(`bundle/` · PDF 20 + `00_읽어보기.txt`)은 결과표(`print-result.md` · `.json`)와 **한 산출물**(`ui-print-<잡 id>`)에 실린다(워크플로 0줄 · B-3).
- 공개 저장소라 올라가는 순간 로그인한 누구나 받을 수 있다 → **공개 시간 최소**(7일 → 수십 분).
- 결과표는 지우기 전에 기록 가지로 옮겨 남긴다.

## 2. 발사 전
1. R1 · main 짝 측정 가지 이름 · 머리 SHA 를 결재 기록에 적는다.
2. **재실행 금지**(같은 런 · 같은 가지) — 다시 돌리면 공개 묶음이 새로 생긴다(N-6). 다시 재야 하면 새 머리 · 새 결재.
3. PM 이 지울 권한을 미리 손으로 한 번 확인: `gh api repos/gisskso-lab/hitpan-erp/actions/artifacts --jq '.total_count'` 가 숫자로 나오는지.

## 3. 런 끝난 직후 (순서 그대로 · 한 번에)
1. 산출물 찾기: `gh api repos/gisskso-lab/hitpan-erp/actions/runs/<런 id>/artifacts --jq '.artifacts[] | "\(.id) \(.name) \(.size_in_bytes)"'` — `ui-print-*` 전부 적는다(시도 attempt 가 여럿이면 시도마다).
2. 받기: `gh run download <런 id> -R gisskso-lab/hitpan-erp -n <이름> -D <scratchpad>\r1_art\<이름>` — **저장소 밖 scratchpad** 에만.
3. 결과표 옮김: `print-result.md` · `print-result.json` 을 기록 가지 `docs/검증/외부/` 아래 R1 결과 파일로 복사 · 커밋(PDF · 묶음은 절대 커밋 금지).
4. [4] 검증팀장이 받은 사본으로 직접 대조(묶음 20 + 1 목록 · 첫 줄 바이트 · FontFamily 표 · 내장 글꼴 흐름 길이 ↔ 원본 크기(N-1) · 20장 눈 확인(N-3 실데이터 꼴 빈틈 메움)).
5. **대조 끝나는 즉시 삭제**: 1 에서 적은 id 마다 `gh api -X DELETE repos/gisskso-lab/hitpan-erp/actions/artifacts/<id>`.
6. 삭제 확인: 같은 id 로 `gh api repos/gisskso-lab/hitpan-erp/actions/artifacts/<id>` 가 **404** · 런 산출물 목록 0. 결과를 결재 기록에 적는다(id · 올라간 시각 · 지운 시각 · 공개 분).
7. 측정 가지 · 초안 PR 닫고 가지 지움(재실행 길 막음 · N-6).

## 4. 대표께 전달
- 받은 사본 중 `bundle/` 폴더만 대표께 직접 전달(공개 링크 0 · §12 :192). 전달 방법 · 시각은 결재 기록에.
- 대표 확인 끝나면(하루 안 · §135 ②) scratchpad 사본 지움.

## 5. 실패 때
- 삭제가 403 · 오류면: 그 자리에서 대표 보고(공개 지속 중) · 7일 보존 만료가 마지막 안전망.
- 무효 런(판정 0)이면 묶음 0장(장치 §161 Q-4) — 그래도 산출물은 1 ~ 6 대로 지운다.
