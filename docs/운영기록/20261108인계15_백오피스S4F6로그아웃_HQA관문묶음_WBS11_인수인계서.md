## §5 함정 (이번 창에서 겪은 것)
1. **레포 밖 폴더에서 `gh pr comment` → 조용히 안 올라감 · 빈 출력을 성공으로 보고(8건)** — HQA 가 「원문을 못 찾았다」 해서 드러났고 대표가 손으로 전달했다. 지연 게시 머리로 원문 그대로 다시 올림. 이제 늘 `-R` · URL 확인.
2. **감시 필터가 HQA 회신을 버렸다** — 「지연 게시」 글자를 빼는 필터가 그 글자를 인용한 HQA 글까지 뺐다. 필터는 머리 줄 꼴(`^## HQA`)로만 거른다.
3. **공개 게시(Release)는 자동 차단 장치가 대표 승인을 요구한다** — 묻고 나서 올렸다. 묶음 · 공개 산출물은 미리 결재 질문을 준비한다.
4. **에이전트 턴 상한(50)** — F6 2회차 측정이 중간에 멈춰 이어 받음. 측정 지시에 「파일 먼저 · 못 잰 칸은 미측정」.
5. **2회차 diff 가 [3-V] 를 안 거치고 [4] 로 갔다(로그아웃)** — 3회차 [3-V] 에서 2·3회차 함께 봄. 차수마다 [3-V] 를 [4] 와 같이 띄운다.
6. **wt-s4 sparse checkout 에 `docs/검증/외부` 가 없었다** — `MSYS_NO_PATHCONV=1 git sparse-checkout add`.
