## §5. 함정 — 이번 세션에서 실제로 밟은 것
- **PM 가설 「줄 끝(CRLF)」 이 틀렸다** — 실측 원인은 정렬 순서. 「진단도 실측 전엔 가설」 그대로. 가설로 고쳤으면 1건이 더 틀어졌다.
- **기대값 표를 PM 이 잘못 적었다**(가림 수 「줄면 빨강」) — 지우지 않고 사유 · 숫자를 붙여 정정 기록.
- PR 이 머지될 때마다 다른 열린 PR 의 INDEX 가 같은 자리에서 충돌 → 머지 요청 전 main 반영 확인.
- worktree 에서 `git push -q` 가 조용히 실패한 적이 있다 → 푸시 뒤 `git ls-remote` 로 원격 머리 확인.
- 표준 구현 에이전트의 자동 격리 worktree 가 거절됨 → 일반 에이전트 + 수동 worktree 경로 지시.
- 에이전트 50턴 한도 2회 · 쉬는 에이전트 다시 부르기는 토큰 규칙(P3)에 막힘 → 새 에이전트 + 산출물 주소만.
- 외부 실행 파일(actionlint) 내려받아 실행은 권한 밖 → 워크플로 문법은 리허설 런이 첫 확인.
- 판정 무관 점검(probe)이 판정 정보 일부를 공개 원자료로 올렸다(N2) → 점검 범위는 「존재 · 시간」 으로 좁힌다 · 발행 댓글에 공개.
- 공개 원자료에 쓰는 칸은 가림 규칙과 부딪힐 수 있다 → 판정 칸 스키마는 발행 전 고정(CTO).
