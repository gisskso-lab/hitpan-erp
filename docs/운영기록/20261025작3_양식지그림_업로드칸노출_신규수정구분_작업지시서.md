## §3 범위 — 못으로 고정한다

### 할 것

**절 가-1 · 업로드 칸을 항상 보이게 한다** (`FormTemplateEditorDialog.razor`)
- 업로드 묶음(안내문 + 「양식용지 그림 올리기」 단추 + 「그림 지우기」 + 올린 파일명)을 `@if (_form.PaperMode == "preprint")` **밖으로** 꺼낸다 — 항상 그려진다.
- `preprint` 일 때: **지금과 글자 하나 다르지 않다.**
- `plain` 일 때:
  - 「양식용지 그림 올리기」 단추는 **보이되 눌리지 않는다**(`Disabled`).
  - 그 옆에 **「양식용지로 바꾸기」** 단추 한 개 — 누르면 `_form.PaperMode = "preprint"` 로 바꾸고 안내를 띄운다. **저장은 하지 않는다**(저장은 「저장」 단추 몫).
  - 아래에 안내: *「이 양식은 「빈 A4 용지」로 되어 있어 그림을 올릴 수 없습니다. 위 「어떤 종이에 인쇄하나요?」를 「미리 인쇄된 양식용지」로 바꾸시면 올릴 수 있습니다.」*
  - 🔴 **예전에 올린 그림이 남아 있으면**(`BackgroundImageUrl` 이 비어 있지 않으면) 「그림 지우기」를 **보여 주고**, 참을 말한다: *「예전에 올린 그림이 남아 있습니다. 「빈 A4 용지」에서는 종이에 찍히지 않고 아래 미리보기에만 보입니다.」*
    — [1-V] ⒟ 비대칭(좌표는 버리는데 그림은 안 버린다)을 **서버를 안 건드리고** 고객이 지울 수 있게만 만든다.

**절 가-2 · 신규인지 수정인지 화면이 말하게 한다** (`FormTemplateEditorDialog.razor`)
- 창 맨 위에 글자를 띄운다 — `Template is null` 이면 **「새 양식 만들기」**, 아니면 **「양식 수정」**.
  🔴 `MudDialog` 제목이 실제로 그려지는지는 **⚠️미측정**이다(P3). 창 **안쪽**에 글자를 두면 그 미측정과 무관하게 참이 된다.
- `:372` 의 `_form.TemplateName = "신규 양식";` **미리채움을 없앤다** → 이름 칸은 빈 칸 + 흐린 안내글(`Placeholder`).
  🟢 비워 두고 저장하면 `:744` 가 *「양식 유형과 이름은 필수입니다.」*로 막는다 — **이미 있는 문**이라 새로 만들지 않는다.

**절 가-3 · 새 게이트 축 + 음성 대조군** (`FormPaperSizeAndBackgroundUploadGateTests.cs`)
- §1 의 적발(가-1 을 해도·되돌려도 초록) 때문에 **필수**다.
- 🔴 **주석과 문자열을 가린 뒤** 잰다 — 10/25 에 내 검사 도구가 `IndexOf("//")` 로 실코드를 손상시킨 사고가 있었다. 기존 `ReadCode`(주석 제거판)를 쓰고, `ReadSource`(원본)로는 재지 않는다.
