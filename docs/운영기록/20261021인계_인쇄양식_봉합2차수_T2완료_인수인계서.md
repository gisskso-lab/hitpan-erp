## §2 🔴🔴 오늘의 핵심 — **24/24 초록이 아무것도 안 지키고 있었다**

| | |
|---|---|
| 종전 판정식 | **「벌 머리 합계 == 2」 + 「각 쪽 ≤ 1」** |
| 왜 거짓인가 | `[1,0,1,0]`(2·4쪽이 **앞 벌의 꼬리 조각**)은 합계도 2, 각 쪽도 1 이하 ⇒ **두 단언을 다 통과**한다 |
| 더 나쁜 것 | `InlineData` 가 **1·3·30줄뿐** ⇒ **40줄을 아예 안 쟀다** |
| 🔴 결론 | **구멍은 「≤1」이 아니라 「0 을 허용한 것」이었다.** 내가 사장님께 보고한 **「가드 24/24」가 이 결함을 하나도 안 지켰다** |

🟢 **그래서 이번 차수는 게이트부터 고쳤다**(T-4). 제품은 **0줄**로 두고 **빨개지는 것을 성공 조건**으로 삼았다 ⇒ **15건 빨강**. 그다음에야 제품을 고쳤다(T-2) ⇒ **52/52 초록**.
🔴 **다음 사람에게: 재는 자가 틀린 채로 제품을 고치면, 고친 뒤의 초록도 거짓이다.**
