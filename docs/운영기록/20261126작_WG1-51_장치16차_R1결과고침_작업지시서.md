## §1 [오더] 원문 · 이해

> CTO §202-0 「묶음 = 장치 고침(닫힌 목록 Z-0 ~ Z-4) 뒤 · 다음 런 = 2런(R2 짝 + R3 합류 새 머리 · 남음 1)」
> CTO §202-4 「장치 16차 『R1 뒤 고침』 1벌 · 장치 파일 안만 · 워크플로 0줄 · 설계팀장 지시서 → PM 결재」
> CTO §198-3 R1-6 「은퇴 거리 2줄을 다음 장치 지시서 첫 거리로 올림」 · §198-6 「R1-6 지시서 때 [1-V] 로 글자 확인」
> 🆕 CTO §206-0 「Q1 ~ Q7 처리 · K4 = 이번 닫힌 목록에 Z-5 로 더함(조건 3 · 판정기 손 0 일 때만)」 · §206-2 「판정기를 런 전 글자(R1 계획 지시서 §7 :110 · 대표 §49)에 맞춤」

- 이 문서는 §202-4 표 다섯 줄의 글자를 개발 몫으로 옮긴 것이다. **고침 꼴 · 받아들임 글자를 넓히지 않는다.** 표에 없는 손질이 필요해 보이면 「확인 필요」 로 §14 에 적고 손대지 않는다.
- 안 하면: R2 · R3 에서 13 멈춤이 또 섬(R1-7 · CTO 다시) · K3 장이 다시 「못 잼」 → 묶음 0 · 격식 칸이 장치 공백으로 빨강 · M4 가 미측정으로 삼켜짐 · 고정 표가 YN1 로 또 불일치.
