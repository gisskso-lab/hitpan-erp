## 2. 🔴 가장 큰 것 — CI 에 DB 를 붙였다 (W1)

### 무엇이 무너져 있었나

```
build 잡      : dotnet test 1100개 전부      🔴 DB 없음
ddl-smoke 잡  : 스모크 1개                    ✅ MariaDB 있음
```

DB 게이트는 서버 미가용 시 `return` 으로 빠져나온다 — **xUnit 에게 그건 PASS 다.**
⇒ 진짜 게이트마저 한 번도 안 돌았고, *"1100개 통과"* 는 **글자검사만의 통과**였다.

### 봉합 — 판정 기준을 「어디서 도느냐」로 바꿨다

`DbGateEnvironment` 신설. 같은 `return` 이라도 자리를 가른다.

| 환경 | 동작 |
|---|---|
| 로컬 (DB 없음) | 종전대로 건너뜀 — **로컬 개발 안 깨짐** |
| `db-gate` 잡 (DB 약속) | **건너뛰는 것 자체가 실패** |

🔴 **`return` 을 무조건 `Assert` 로 바꾸지 않았다** — 그러면 DB 없는 로컬이 전부 깨진다.

### 🔴 1차 설계가 틀렸고 CI 가 잡았다 (그대로 기록한다)

처음엔 `CI` 환경변수로 판정했다. **GitHub Actions 는 모든 잡에 `CI=true` 를 준다.**
⇒ DB 를 안 띄우는 `build` 잡까지 DB 를 요구해 **애먼 곳이 56건 빨간불**이 됐다.

**정정**: 기준은 *"CI 인가"* 가 아니라 ***"DB 를 주기로 한 잡인가"*** 다.
그 약속이 `HITPAN_REQUIRE_DB` 이고 `db-gate` 잡만 주입한다.

### 실측 4종

| 조건 | 결과 |
|---|---|
| DB 약속 + DB 없음 | 🔴 **7/7 실패** — SKIP 탈출구가 실제로 닫혔다 |
| DB 약속 + DB 있음 | 🟢 93/93 통과 · **건너뜀 0** |
| `build` 조건(CI=true, DB 없음) | 🟢 1107 통과 · 건너뜀 0 |
| 로컬(약속 없음, DB 없음) | 🟢 통과 — 개발 안 깨짐 |

**CI 로그 실측**: `적재된 표 152개` · **`SKIP 없음 — 게이트가 실제로 돌았다`**

### ⚠️ 무는 범위 (조용한 축소 금지)

**업무 로직 게이트 13종**을 문다. 기기·승인 계열은 시험마다 `CREATE DATABASE` 를 하는
권한 축이라 **범위 밖**이고, **안 넣었다는 사실을 CI 로그에 찍는다.**
넣은 척하면 이번에 봉합한 사고를 형태만 바꿔 반복하는 것이다.
