# §1. 오늘 2차에 한 일

## 1-1. 🔴 메인PC 폐기 잠김 — 사장님 실측이 잡은 P0

> 사장님: *"메인PC가 폐기되는게 말이되?"*

### 무엇이 났나
메인PC(회사 서버)가 `revoked` 가 되자 **로그인 자체가 막혔고, 나갈 길이 전부 막혔다.**

| 시도 | 결과 |
|---|---|
| 다른 PC 로 로그인 | 같은 화면 — 풀 수 있는 건 대표계정뿐인데 그 대표가 못 들어감 |
| `localhost` 접속 | 안 됨 |
| 명령창 DB 수정 | 권한·비밀번호 벽 |
| **업데이트로 고치기** | 🔴 **팝업이 로그인 후에 떠서 도달 불가** |

⇒ **고치는 수단 자체가 잠겼다.**

### 진범
화면 자물쇠는 **앞으로 눌리는 것**만 막는다. **이미 `revoked` 인 기록**은 못 막는다.
⇒ 막는 자리를 **화면에만** 두고 로그인 검사에 두지 않은 것.

### 고침 — 사장님 지시대로 DB 를 마지막 방어선으로
> *"메인PC는 기기슬롯에서 **PK로 보호**해야해"*

**DB-89**: 트리거(폐기 되돌림) + 생성컬럼·UNIQUE(테넌트당 1대) + **이미 폐기된 것 되살리기**
로그인 검사도 메인PC 는 폐기 상태여도 통과. **일반 기기는 종전대로 막는다.**

# §2. 🔴 오늘 알게 된 중요한 사실 — DB 비밀번호는 고객사마다 다르다

`db.conf` 실측(Sandbox `T-001`):

```
DB_NAME=hitpan_erp_t001      ← 슬롯별
DB_USER=hitpan_t001          ← 슬롯별
DB_PASSWORD=(무작위 32자리)   ← 🔴 고객사마다 다름
```

| 문서에 적힌 것 | 실제 |
|---|---|
| CS 안내 기준: *"모든 고객사가 같습니다 `HITPAN2026!`"* | 🔴 **틀렸다** |
| `install.bat`: `Hitpan2025!` | 실제 설치본과 불일치 |

🔴 **CS 팀이 그 문서로 지원하면 `Access denied` 가 난다** — 오늘 PM 이 그대로 겪었다.
🟢 **다만 PI-03 의 위험은 낮아졌다** — *"공통 비번이라 한 곳 뚫리면 전부"* 가 아니다.
