## 3. W1 — CI 에 DB 잡 신설 🔴 최우선

### 왜 이게 1번인가

```
build 잡      : dotnet test 1100개 전부      🔴 DB 없음
ddl-smoke 잡  : 스모크 1개                    ✅ MariaDB 있음
```

DB 게이트 **101곳**이 서버 미가용 시 `return` 으로 빠져나온다 — **xUnit 에게 PASS 다.**

⇒ 🔴 **지금 게이트를 아무리 잘 짜도 전부 SKIP 된다. W3 이 무의미해진다.**

### 지시

| # | 내용 |
|---|---|
| 1 | **DB 를 물린 시험 잡을 신설**한다 — `ddl-smoke` 의 MariaDB 서비스 설비를 **복제** |
| 2 | 🔴 **`return` 을 `Assert` 로 바꾸는 것이 아니다** — 그러면 DB 없는 로컬 개발이 전부 깨진다. **CI 에서 DB 가 반드시 있게** 만드는 것이 이번 작업 |
| 3 | 🔴 **CI 환경에서는 SKIP 자체가 실패**가 되도록 판정한다 (환경변수 등으로 CI 여부 구분) |
| 4 | `TrialBalanceGateTests` 가 **실제 서비스를 실 DB 에 물려 부르는** 본보기 — 이 패턴을 기준으로 |

### 완료 판정 🔴

> **DB 게이트 하나를 일부러 깨뜨렸을 때 CI 가 빨간불이 되어야 한다.**

초록이면 W1 은 미완료다. **[SKIP] 이 로그에 찍히면 미완료다.**

## 6. W4 — 상태 한글 전환 (결재 7)

### 지시

| # | 내용 |
|---|---|
| 1 | 🔴 **DB enum 값은 건드리지 않는다.** 표시 계층에서만 한글 매핑 (결재 7 추가결정 ①) ⇒ 마이그 부담 0 |
| 2 | 대상: **판매라인** 모든 버튼 · 전표작성칸 · 목록 |
| 3 | **「분할출고」는 상태가 아니라 뱃지** — `판매완료 [분할출고]`. **컬럼 신설 없음** (추가결정 ②) |
| 4 | **마이너스 명세서는 같은 상태 + 부호로 구분** — 별도 상태 안 만듦 (추가결정 ③) |
| 5 | **취소 상태 유지** — 명세서는 3단(삭제/취소/마이너스) (추가결정 ④) |

### 상태 사전 (설계 §1-2 를 그대로 따른다)

```
수주완료 → 판매완료 → 판매확정 → 계산서발행 → 전자발행
              │          │                      │
            삭제        취소                반품완료 → 반품확정
```

⚠️ **매입라인은 이번에 안 바꾼다.** 매입·매출이 한동안 다른 어휘를 쓰는 것은 **의도된 과도기**다.

### 왜 봉합보다 먼저인가

**상태가 먼저 서야 버튼·목록을 한 번에 맞춘다.** 나중에 하면 두 번 고친다.

## 8. W6 — 마이너스 전표 사슬 + 반품하기 버튼 (결재 2·3·5)

### 8-1. 마이너스 전표

| # | 내용 |
|---|---|
| 1 | 반품 메뉴를 만들지 않는다. **마이너스 전표**로 처리 (결재 2) |
| 2 | 🔴 **사슬 근거 필수** — 근거 없는 마이너스는 장부를 못 읽게 만든다 |
| 3 | 🔴 **수주까지 전파** (결재 3) — 명세서 층에만 두면 **수주 잔량이 안 돌아와 P0-1 이 되살아난다** |
| 4 | 표기: 원전표 번호 + `R` · **원전표 바로 아래 배치** |

```
수주      1 + (−1) = 0
명세서    1 + (−1) = 0

목록:  명-001     1,000,000
       └ 명-001R  −1,000,000
```

### 8-2. 반품하기 버튼 2곳 (결재 5)

```
판매목록 그리드 ─ [반품하기]
거래명세서 작성 ─ [세금] [반품하기]
        ↓
같은 거래명세서 화면 — 수량·금액이 (−)로 전량 채워진 상태
  · 반품 안 할 품목은 줄을 지운다      · 수량 수정 가능
  · 이미 반품된 품목은 잔량만큼만      · 거기서 마이너스 계산서까지 끊는다
```

🔴 **새 화면 0개.** 새 화면은 새 진입점이고, 진입점이 늘면 **가드가 또 한쪽에만 붙는다**(P0-1 재발).

🟢 **잔량이 채워지므로 수량 상한이 자동으로 걸린다** — 막는 게 아니라 **넘을 경로가 사라진다.**
