## §5 함정 (오늘 겪은 것)
1. **증거보다 세게 적었다** — 대표 화면 1회로 「새 DB 연결 🟢」 를 적고 대표에게 정상으로 보고했다. HQA · CTO 가 잡았다.
2. **오류 패턴 0건 ≠ 오류 없음** — 배포 앞 구간도 0 이면 대조군이 없다.
3. **파일 판 ≠ 실행 중 적재 판.**
4. **표본 시험은 ssh 경로를 안 탔다** — 운영 첫 실행에서 멈춤이 나왔다. 1회차 원인은 추정이다. 「파일 저장 0」 도 틀렸다.
5. **지시 범위를 넘겼다** — K-4 만 지시받고 오류 로그까지 읽으려다 거부됐다. 운영 읽기는 대표 지시 범위 안에서만 된다. 거부되면 우회하지 않는다.
6. **`hp-implementer` 자동 격리는 거절된다** — 일반 에이전트 + 수동 작업 나무 · 커밋은 PM.
7. **게이트 초록의 한계** — 화면 코드를 되돌려도 14건이 초록이었다. 설치 표시는 대표 눈 대조가 마지막 관문이다. 시간 초과 시험도 처음엔 0건이었다.
8. **고객명 · 상태별 건수 · 캡처 공개 금지** — 대표 눈 대조 기록은 로컬에만 둔다.
9. **머지하면 배포 런이 게이트를 기다리지 않는다** — 머지 전 대기 런 0 확인 · 동승 변경 목록 · 대표 승인.
10. **HQA 회신은 감시만 믿지 말고 레포 전체 댓글을 잰다** — 회신이 #759 에 왔다. 마지막 읽은 id = 6579990991.

11. **게이트 자체를 고치는 PR 을 기계가 막지 못한다** — 승인 인원 · 코드 소유자 규칙이 없다. 필수 설정 재보고에 사람 대조를 함께 올린다.
