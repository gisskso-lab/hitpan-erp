## 4. 🔴 적용 후 확인 — 자식계정으로 해야 한다

## 5. 정직하게 — 이번에도 완전하지 않다

- **화면 실측 0건이다.** 검증은 빌드·시험·DB SQL 왕복까지다. §4 가 첫 실측이다.
- **⑥ 계층분리는 일부만 해소**됐다. 조회 3개를 열었을 뿐,
  "부모=전부 통과 / 자식=대부분 차단" 구조는 그대로다. 전수는 별건이다.
- **권한 체크박스 12개는 감춘 것이지 고친 게 아니다.** 실제 강제를 붙이는 것이 정답이고,
  그때 하나씩 다시 꺼낸다.
- **연차부여는 열지 않았다** — `employeeId` 를 쿼리로 그대로 받아, 열면 직원이 주소만 바꿔
  남의 연차를 본다. 권한 봉합이 아니라 자료 유출이 되므로 서버 범위 제한이 선행돼야 한다.
