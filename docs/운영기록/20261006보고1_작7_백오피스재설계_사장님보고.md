## §3. 함께 결재 주실 것
- **「제안」 F 행 채택**: 미인지 17건 + PM 제안 7건(F-3·F-4·F-7·F-9·F-23·F-24·F-26~F-31·F-35~F-42) — 기능정의서에 전부 「제안」 표시 · 채택된 것만 해당 사이클에 편입. F-4(대리점 내부 직원 계정)는 계층 정의 두 줄에 더하는 것이라 ⚠️별도 결재.
- **⓪사이클 확인 방식**: 화면 없는 데이터 사슬 봉합의 사장님 PC 확인 실물 = 고객사 상세의 연결 표시 1곳 vs 「게이트+되돌림 경로」 대체(아키 §4 주석).
