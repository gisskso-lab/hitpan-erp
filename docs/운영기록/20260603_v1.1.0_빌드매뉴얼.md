## 3. SHA256 + ZIP 박제

```powershell
# SHA256 박제
Get-ChildItem publish-output/v1.1.0/*.exe, publish-output/v1.1.0/*.msi `
    -Recurse | ForEach-Object {
    $hash = Get-FileHash $_.FullName -Algorithm SHA256
    "{0}  {1}" -f $hash.Hash, $_.Name
} | Out-File -Encoding utf8 publish-output/v1.1.0/SHA256_v1.1.0.txt

# Norton·McAfee ZIP (비밀번호 infected)
& "C:\Program Files\7-Zip\7z.exe" a -tzip -pinfected `
    publish-output/v1.1.0/HitPan_v1.1.0_for_AV_review.zip `
    publish-output/v1.1.0/api/HitPan.API.exe `

    publish-output/v1.1.0/cloudflared.exe `
```
