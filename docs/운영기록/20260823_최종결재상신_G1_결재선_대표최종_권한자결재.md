## 1. 🔴 이 작업의 핵심 — 사장님이 PM 권고를 정정하셨다

PM 은 Q2 에 *"권한자만"* 이라 권고했다. **그대로 짰으면 대표가 결재자 목록에서 사라진다.**

**근거** — `PermissionService.HasPermissionAsync` Layer 0:

```csharp
// Layer 0 — 부모계정(tenant_admin)은 항상 전권 (락아웃 방지)
if (userId == _currentTenant.UserId &&
    _currentTenant.AccountType == "tenant_admin")
{
    return true;
}
```

부모계정은 `user_permissions` 표를 **거치지 않는다.**
⇒ 권한자만 뽑으면 **대표는 그 표에 줄이 없어 안 잡힌다.**
⇒ 그런데 최종 결재 단계는 대표여야 한다.
⇒ **반드시 넣어야 할 사람을 못 고르는 화면** — G1 이 스스로와 충돌한다.

**값으로 증명했다**(글자검사 아님). 시험DB 에 4명 세우고 SQL 3변형 대조:

| 실험 | 결과 |
|---|---|
| 봉합 그대로 | 김대표 + 이결재 ✅ |
| 권한조건 제거 | **박무권(무권한자) 나타남** |
| **`is_parent` 갈래 제거 (= PM 권고)** | **김대표 사라짐** 🔴 |
| 계정상태 안 봄 | **최퇴사 나타남** |
