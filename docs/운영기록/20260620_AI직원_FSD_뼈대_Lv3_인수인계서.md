## 1. 사장님 비전 (절대 잊지 말 것 — 메모리 [[project_ai_employee_vision_20260620]] 정본)

### 1.1 핵심 명제
> "히트판의 모든 구현을 구현할 줄 아는 서브에이전트 같은 챗봇 AI가 먼저 되는 게 선행돼야 직원이 될 수 있어."
- = PM이 Claude Code로 히트판 코드를 자유자재로 다루듯, 챗봇도 히트판 안에서 모든 기능을 스스로 호출해야 직원.
- **하드코딩 명령별 분기 = 방향 틀림 → Tool Use 엔진으로 전환**(사장님 결재).

### 1.2 제품 정의 = "테슬라 FSD"
- 히트판 = 자동차(AI 없어도 수동 버튼으로 완전 동작). AI = FSD 옵션(켜면 자동, 안 켜도 차는 굴러감).
- 과금 = 고객 선택(BYOK 클로드 키). 키 넣으면 자동모드, 안 넣으면 수동 운전.
- 외부 마케팅: "AI·클로드·바이브코딩" 단어 금지(헌법 #23) → "자동 처리"·"스마트 모드". 한 줄 = "히트판의 FSD".

### 1.3 직무 개입 레벨 (FSD 단계, **베타 이후부터 확대**)
- Lv1 조회·분석 / Lv2 생성·작성(사람승인) / Lv3 워크플로우 연쇄 / Lv4 능동 제안 / Lv5 실시간 감시·보고 / Lv6 카톡방 직원.
- **현재 도달(정직 박제 — 부풀리기 금지 헌법 #32)**: ✅Lv1 ✅Lv2 ✅Lv3(코드 완성·경로 검증, 재고있는 데이터로 끝단 확인만 남음).
- 단계 확대는 **사장님 고민 영역**(자동/사람승인 경계, 금액 한도, 직무 차등, 법적 선). PM 섣불리 박제 금지.

### 1.4 추후 비전 (베타 이후, Tool 뼈대 위에 얹음)
- 능동 제안: "000사원 출근 안 함, 경위서 요청할까요?" / "미수 경과, 안내메일?" / "신규업체 개척, 마스터 등록?"
- 금융 감시(토스 API 후): 법인카드·계좌 사용내역 실시간 → 사장님 능동 보고 → 경비처리 자동반영.
- **카카오톡 미니앱 ↔ 히트판 ERP 웹서비스 연동**: 단톡방 직원. 같은 Tool Use 엔진(입구만 다름). 업무데이터는 고객 ERP 안에만(헌법 #18·#22).
- 정부 AI 육성 정책 명분(바우처·R&D·국산 SaaS) — 사장님 영역, PM은 기술로 뒷받침만.
