## 1. ✅ 완료 — ERP 계층제거 (커밋 85594a2)

### 왜 했나 (사장님 배경 — 계층의 "의미")
- ERP를 한 프로그램으로 두고 본사/대리점/고객사 로그인별 화면 분기하려던 옛 설계의 잔재.
- 보안 이유로 계층 관리는 백오피스로 이관, ERP는 순수 업무 플랫폼만:
  > **"고객사 하나라도 뚫리면 본사·다른 고객사까지 위험해진다."**
- 계층 = 본사·대리점·테넌트. 제거 후 ERP에 남은 것 = **부모계정(랜딩 최초가입) + 자식계정(부모가 생성) + 업무기능**.
- 헌법 #7(SaaS↔ERP 권한 혼용 금지)·#22(본사 데이터 최소주의)·#35(3시스템 분리) 정합.
