### [A] 메뉴 순서 — 지시대로

```
사원관리          ← 지시에 없던 2줄 중 하나. 맨 앞
결재관리
결재 설정
부서 관리
급여 관리
근태 관리
초과근무
연차신청          ← 이름 변경 (휴가·연차)
휴직신청          ← 이름 변경 (휴직 관리)
보고서관리        ← 이름 변경 (업무보고서)
경비처리          ← 이름 변경 (경비)
입사/퇴사         ← 지시에 없던 2줄 중 하나. 맨 뒤
```

🔴 **지시에 없던 2줄을 PM 이 판단해 배치했다.**
- **사원관리 맨 앞** — 직원계정 = 마스터 축(사장님 8/11: *"HR과 인사, 그룹웨어는 직원계정으로부터 모든 연결이 돼"*)
- **입사/퇴사 맨 뒤** — 입사→재직→퇴사 생애주기의 끝

⚠️ 다르게 원하시면 한 줄 옮기면 된다. **되돌리기 쉬운 결정**이라 멈추지 않고 진행했다.

### [B] 이름 4개 변경

| 전 | 후 | 왜 |
|---|---|---|
| 휴직 관리 | **휴직신청** | 직원이 신청하는 화면인데 이름이 "관리" 였다. 옆 [연차신청]과 짝이 맞는다 |
| 휴가·연차 | **연차신청** | 사장님이 순서표에 그렇게 적으셨다 |
| 업무보고서 | **보고서관리** | 사장님 지시 |
| 경비 | **경비처리** | 사장님이 순서표에 그렇게 적으셨다 |

🔴 **화면 제목은 「휴가·연차 관리」 그대로 뒀다.** 그 안에 전사 현황·휴가 일정 탭이
함께 있어 "신청" 만으로는 안이 설명되지 않는다.
**메뉴 이름은 직원이 찾는 말, 화면 제목은 그 안에 있는 것**을 가리킨다.

보고서가 **4종 → 5종**. 메뉴는 그대로 한 줄이고 **탭이 하나 늘었다.**

- [x] `WorkReportTypes.Business` (백엔드)

🔴 **다섯 곳을 다 채워야 한다.** 하나라도 빠지면:
- 사전에서 빠지면 → **결재 설정에 행이 안 떠서 켤 수 없고 ⇒ 상신이 조용히 죽는다** (8/21 휴직 P0 자리)
