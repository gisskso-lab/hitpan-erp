## §2. 챕터4 — 기기인증 · 모바일 QR (구현완료 · **실측 미완**)

### 사장님 설계 (원문 그대로)
- 메인기기슬롯 해결됨 → 남은 건 **사용PC슬롯 + 모바일슬롯**
- PC = **인증서 같은 인증키** / 모바일 = **QR 로 인증키**
- **로그인·접속은 되게** 하되 메뉴는 안 열림 → *"기기인증을 먼저 진행하세요."* + 인증버튼
- 한도초과 직원 → *"인증기기 한도초과. 관리자에게 문의하세요."*
- 대표계정에게 → *"비인증 PC에서 접속이 시도되었습니다. 슬롯1개를 추가하시겠습니까?"* (**슬롯 1개 = 만원**)
  - Y → 랜딩페이지 / N → *"등록기기를 변경하시겠습니까? or 기기차단을 하시겠습니까?"*
- **승인대기 — 대표에게 기기승인 권한**
- 기존 기기 = **(나) 이미 인증된 것으로 인정** — 아무도 안 막힌다
- **끄기 스위치 필수** — *"개발하면서 슬롯을 다 써서 테스트도 못하는 상황이 올수 있음"*
  주석: `//개발과정 속  테스트시 잠시 이 기능은 죽일 수 있음.//`

### 모바일 QR 5단계 (사장님 원문)
1. 등록기기 관리에 **[모바일기기 등록]** 버튼
2. 클릭 시 QR 생성 + *"스마트폰으로으로 QR코드를 찍어 주세요"*
3. 폰 촬영 → **"히트판 모바일기기등록"** 화면 → *"모바일 기기 등록을 하시겠습니까?"* Y/N
4. Y → 홈화면에 히트판ERP 아이콘 (아이폰·아이패드는 **별도 안내문구**)
5. 아이콘 터치 → 히트판 모바일웹

### 만든 것
| 구분 | 파일 |
|---|---|
| (E) 끄기 스위치 `DeviceApproval:Enabled` **기본 꺼짐** | `appsettings.json` · `TenantDeviceService.cs` |
| (B) 승인/거부 + 대기함 | `DeviceController.cs` · `DeviceManagePage` |
| (C) 슬롯 판매 Y/N 경로 | `DeviceManagePage` |
| (D) QR 토큰 발급·검증 + 등록화면 | `DeviceController.cs` · `Pages/Mobile/MobileDeviceRegisterPage.razor` |
| (D-2) 아이콘·PWA | `wwwroot/*.png` · `manifest.json` · `index.html` |
| QR 생성기 | `QrCodeGenerator.cs` (QRCoder + PNG 자체조립) |
| DDL | **DB-87** + clean DDL |

## §5. 운영 메모 — 다음 사람이 헤매지 않게

- **스쿼시 병합은 해시가 바뀐다.** main 반영 확인은 `git merge-base --is-ancestor` 가 아니라
  **`git diff <내커밋> origin/main -- <파일>` 이 비었는지**로 본다 (8/10 아침 4차 사고 계통)
- **워크플로 입력은 main 기준으로 읽힌다.** PR 브랜치에만 새 input 이 있으면 `gh workflow run` 이 **HTTP 422**.
  머지 후에 다시 부른다
- **1인 저장소**라 자기 PR 승인 불가. `--admin` 머지는 자동분류기가 막는다 → 사장님이 누르신다
- **게시 확인은 매니페스트로** — `curl -s https://updates.hitpan.kr/manifest.json`
- 🔴 **TruffleHog 빨간 X 를 "소음"으로 읽지 말 것 — 살아있는 P0 다.**
  PM 이 오늘 그렇게 오독했다가 워크플로를 열어보고 정정했다. `trufflehog.yml:68` 에 보안팀이 적어뒀다 —
  *"진탐(install.bat 의 고객 공통 DB 비번)은 제외하지 않았다. 그래서 계속 실패로 뜬다. **덮지 않는 것이 의도다.**"*
  실측: `origin/main:installer/install.bat` **5줄에 평문 상수**(값은 여기 안 적는다 — `git show` 로 직접 볼 것).
  **고객 공통 비번**이라 한 곳이 뚫리면 전 고객 DB 가 같은 열쇠로 열린다.
  ⚠️ PM 이 이 문서 초안에 **값을 그대로 옮겨 적었다가 스캔에 걸렸다** — 유출을 기록하려다 한 부 더 만들었다.
  **사고 기록에는 새는 자리를 적고, 새는 값은 적지 않는다.**
  ⇒ ✅ PR 게이트는 **`pull_request` 스캔**이 유효(새 유출 차단은 살아있다).
  ⇒ 🔴 할 일은 **스캔 끄기가 아니라 비번 제거**(고객사별 무작위 발급) — 보안상무 결재 사안. **끄면 '죽은 장치' 가 하나 더 생긴다**
