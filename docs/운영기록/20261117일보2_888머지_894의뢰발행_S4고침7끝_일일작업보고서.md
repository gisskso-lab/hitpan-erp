## 4. PM 잘못 · 함정 (재발 방지 · 상세 = 인계20 §5)
1. HQA 「조건부」 를 「최종 픽스」 처럼 다뤘다 — 조건 종결은 HQA 확인을 받아야 닫힌다. 내부 실측으로 닫은 칸은 「내부 실측」 이라고 쓴다.
2. 공개 전 3축 점검을 push 뒤에 한 번 했다 — 언제나 push 앞.
3. 추가 실측을 대표께 먼저 여쭙지 않았다 — 추가 측정 · 추가 라운드는 대표 지시가 있어야 연다.
4. 문서 PR 두 개를 나란히 열어 목차가 충돌했다 — 같은 목차를 건드리는 문서는 한 PR 로 묶는다.
5. 문서 머리 상태 줄이 첫 회차 판정에 멈춰 있었다 — 재검증 회차를 덧붙일 때 머리 「최종 상태」 줄과 목차도 같이 바꾼다.
