## §5. 함정 — 이번 세션에서 실제로 밟은 것
- **TruffleHog 로그의 스크립트 본문을 오류로 읽었다**: 「BASE == HEAD」 줄은 액션 스크립트 출력이었고, 실제 종료는 `exit code 183`(발견)이었다 → `##[error]` 줄과 종료 코드부터 본다. PR #854 에서 공개 정정했다.
- **classic protection API 404 ≠ 규칙 없음**: ruleset 이 따로 있다 → `gh api repos/…/rulesets` 와 `rules/branches/<b>` 를 같이 본다.
- **Git Bash heredoc 이 정규식 백슬래시를 먹는다** → 스크립트는 Write 도구로 파일을 만든 뒤 실행한다.
- **PR 감시 카운터에 내 댓글이 섞였다** → 작성자 머리(「## GPT」 · 「HQA ARGOS」 · 「PM 브라운킴 →」 제외)로 거른다.
- **푸시 전 3축 점검이 src 만 보면 문서 속 개인 경로를 놓친다**(CTO X-1 이 잡음) → 푸시 범위 전체(문서 포함 · 커밋 메시지 · 이력)를 본다.
- **hp-implementer 60턴 한도**: 묶음 같은 긴 일은 중간에 멈춘다 → 멈추면 `SendMessage` 로 「도구 5회 안에서 보고」를 받고, 결과는 PM 이 파일로 대조한다.
- **오라클 독립**: 지시문에 PM 손셈이 섞이면 「입력 노출」이 된다 → 지시문은 서면 기준만 주고, 보존본(`an6c_지시문_보존.md`)에 노출 여부를 적는다.
- **Edge 「16」은 창이 아니라 프로세스 수**였다. 측정 잔여 4개는 이미 죽은 기록(0MB)이다. 대표 창의 탭은 도구로 골라 닫지 못한다.
