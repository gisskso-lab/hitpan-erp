## 4. ⚠️ 오늘 마지막에 드러난 것 — 로그인 401 (미봉합)

사장님이 클라이언트 PC 에서 401 을 겪으셨다. **원인은 아이디 오타**였고 해결됐다.
**그러나 그 과정에서 구조 문제가 드러났다.**

`src/HitPan.Web/Services/AuthService.cs:64`
```csharp
ErrorMessage = err?.Message ?? "이메일 또는 비밀번호가 틀립니다"
```

**서버는 사유를 구별해 보내는데 화면이 전부 같은 문구로 덮는다.**

| 서버의 진짜 이유 | 화면 |
|---|---|
| 계정 없음 | "이메일 또는 비밀번호가 틀립니다" |
| 비밀번호 틀림 | 똑같이 |
| **기기 한도 초과** (`AuthController.cs:82`) | 똑같이 |
| 계정 비활성 / 5회 잠김 | 똑같이 |

🔴 **기기 한도 케이스가 위험하다** — 화면상 완전히 같은데 대응이 정반대다.
아이디 문제는 다시 치면 되지만, **기기 한도는 백 번 쳐도 안 되고 5번이면 15분 잠긴다.**
상담원이 화면만 보고는 절대 구별할 수 없다.

**참고**: 메인 PC 는 loopback 이라 **기기 검사를 건너뛴다**(`AuthController.cs:52-56`).
그래서 "메인은 되는데 클라이언트만 안 되는" 증상이 기기 슬롯일 때 정확히 이 모양이 된다.
