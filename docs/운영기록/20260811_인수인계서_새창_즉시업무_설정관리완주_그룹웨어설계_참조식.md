# §5. 운영 메모 — 헤매지 않게

- **스쿼시 병합은 해시가 바뀐다.** main 반영 확인은 `git merge-base` 가 아니라
  **`git diff <내커밋> origin/main -- <파일>` 이 비었는지**로 본다
- **워크플로 입력은 main 기준**이라 PR 브랜치에만 있는 input 은 **HTTP 422**. 머지 후 다시 부른다
- **1인 저장소** — 자기 PR 승인 불가, `--admin` 머지는 자동분류기가 막는다 → **사장님이 누르신다**
- 게시 확인 = `curl -s https://updates.hitpan.kr/manifest.json`
- 🔴 **TruffleHog 빨간 X 를 "소음" 으로 읽지 말 것** — `trufflehog.yml:68` 에 보안팀이
  *"진탐은 제외하지 않았다·덮지 않는 것이 의도"* 라 적어뒀다. **살아있는 P0**([PI-03](../검증/병렬이슈/20260811_PI-03_설치배치_고객공통_DB비번_평문.md))
- 🔴 **사고 기록에 유출 값을 복사하지 말 것** — PM 이 그러다 저장소에 값을 한 부 더 만들었다.
  **새는 자리를 적고 새는 값은 적지 않는다**
