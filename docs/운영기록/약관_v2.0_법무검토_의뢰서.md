## 2. 검토 요청 사항 6건

### 2.1. SLA 99.99% 공시 표현 (광고법 정합)
- 본사 책임 영역만 SLA 적용 = 명확한 한정 표현
- "100% 보장" 표현 금지 (헌법 #27 정합)
- "최선의 노력" 표현 vs "보장" 표현 법적 의미 차이
- **검토 의뢰**: 광고법 §3 (부당한 표시·광고 행위 금지) 위반 여부

### 2.2. 환불 조항 (전자상거래법 정합)
- SLA 미달 시 자동 환불 조항 (1개월 SLA × 5% 환산)
- 환불 신청 절차 (자동 vs 신청)
- 환불 한도 (월 사용료 100% 초과 금지)
- **검토 의뢰**: 전자상거래법 §17 (청약철회) + §18 (효과) 정합

### 2.3. 책임 한정 조항 (민법 정합)
- 고객 PC 사고 = 본사 책임 ×
- 통신사·전기·Cloudflare·PG 사고 = 본사 책임 ×
- 천재지변·전쟁·정부 명령 = 본사 책임 × (불가항력)
- **검토 의뢰**: 민법 §390 (채무불이행) + 약관규제법 §7 (면책조항의 제한) 정합

### 2.4. 본사 데이터 최소주의 명문화 (개인정보보호법 정합)
- 본사가 받는 데이터 = 메타정보만 (상태값·카운터·tenant_id_hash)
- 본사가 절대 받지 않는 데이터 = 업무 데이터 25개 (매출·매입·원장·거래처·직원·세금계산서 등)
- **검토 의뢰**: 개인정보보호법 §15 (수집·이용) + §17 (제3자 제공) 정합

### 2.5. 워치독 동작 고지 의무 (정보통신망법 정합)
- 워치독이 1분 주기 자가 진단 = 고지 의무 발생?
- 본사로 메타 ping 5분 주기 = 고지 의무 발생?
- 익명 telemetry = 개인정보 해당 여부
- **검토 의뢰**: 정보통신망법 §22 (개인정보 수집·이용 동의) 정합

### 2.6. 효력일 + 30일 사전 공지 의무
- 약관 변경 시 30일 전 공지 의무 (전자상거래법 §15-2)
- 공지 채널: 이메일 + 로그인 화면 + 홈페이지
- 효력일 산정 방법
- **검토 의뢰**: 전자상거래법 §15-2 (약관의 명시·교부) 정합
