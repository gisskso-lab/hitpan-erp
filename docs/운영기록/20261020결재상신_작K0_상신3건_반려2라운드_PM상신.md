## §1 올리는 것 — **3건**

### 🔴🔴 ⓒ (가장 급함) — **「본사가 받는 것」 전수 목록 1장**

**무엇을 결재받나**: 고객에게 *"본사가 무엇을 받아 갑니까"* 라고 물었을 때 **대답할 공식 목록**.

**왜 PM 이 못 정하나**
- 🔴 내가 1판에 **「직원·기기 여덟 칸뿐」**이라고 적었고 **그것이 거짓이었다.** 8칸은 **한 경로**의 칸 수다.
- 실측된 길이 **여섯 개**다 — 당기기(직원 5·기기 3) · 설치 지문(**컴퓨터 이름 + 윈도우 로그인 이름**) · **사업자번호** · **대표 아이디** · **문의 본문(자유글)** · 상주 점검 5분 메타 · 판 보고.
- 🔴 **설계 허용 목록과 코드가 안 맞는다** — 설계는 **7칸**, 코드 DTO 는 **8칸**(`EmployeeId` 가 목록 밖).
- 이건 **대외 문장 + 법무·광고법 + #18 유권해석**이 한 점에서 만나는 자리다.

**결재 주실 것**: ⓐ 전수 목록을 **공개 문서로 만들 것인가** (가/부) ⓑ **숫자로 말할 것인가**(「○칸」) **아니면 쓰임으로만 말할 것인가** ⓒ 설계 7칸 ↔ 코드 8칸 **어느 쪽으로 맞출 것인가**

**그동안 PM 조치**: K0-1·K0-2·O0-2 에서 **숫자를 전부 지웠다.** 쓰임으로만 적었고, **문의 본문은 본사가 읽는다**를 고객 글에 명시했다.
