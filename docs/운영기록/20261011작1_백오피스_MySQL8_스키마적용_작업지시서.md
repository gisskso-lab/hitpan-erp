## §0 한 줄

운영 백오피스(MySQL 8)가 `ALTER … IF NOT EXISTS` 를 거부해 적용기가 `11` 번에서 멈췄다.
**적용기 한 파일**을 MySQL 8 에서도 돌게 고치고, **MySQL 8 판 게이트**를 신설한다.

---

## §A 적용기 보정 — `SchemaMigrator.cs`

| 절 | 할 일 | 비고 |
|---|---|---|
| A-1 | `SELECT VERSION()` 1회로 서버 판 판정 (`MariaDB` 포함 여부) · **로그 한 줄** | 설계 §2-1 |
| A-2 | **MariaDB → 종전 경로 그대로** (배치 1회 실행) | #1 · 회귀 0 |
| A-3 | MySQL → 문장 단위 쪼개기 (문자열 `'` `"` `` ` `` · 주석 `--` `#` `/* */` 인식) | 설계 §2-2 |
| A-4 | `ALTER` 계열의 `IF NOT EXISTS` / `IF EXISTS` 토큰만 제거 | 🔴 `CREATE TABLE IF NOT EXISTS` 는 **보존** |
| A-5 | 오류 **1060·1061·1091·1826** 은 관용 + 건마다 로그 · **그 밖은 종전처럼 throw → 기동 중단** | #15·#19 · 1826 은 31번 FK(`IF NOT EXISTS` 없음) 재실행 덫 |
| A-6 | 파일 해시 멱등(`_schema_migrations`)·env 치환(`${VAR}`)은 **무변경** | 종전 동작 보존 |

**금지**: `installer/backoffice/*.sql` 수정 · 적용 조건(`HITPAN_BO_AUTO_MIGRATE`) 변경 · 적용기를 기본 on 으로 바꾸기.

## §B 게이트 — `BackofficeSchemaMysql8GateTests` 신설

| 게이트 | 판정 | DB |
|---|---|---|
| G-M8-1 | 빈 MySQL 8 DB 에 실물 적용기로 전 파일 적용 → 예외 0 | MySQL 8 |
| G-M8-2 | 표 9개 + 칸 10개 실재 (선행검증서 §4-2·§4-3 목록) | MySQL 8 |
| G-M8-3 | 이력표 비우고 2회차 적용 → 완주 (관용 경로 실제 통과) | MySQL 8 |
| G-M8-4 | 대조군 — `11` 번 원문을 종전 방식으로 보내면 **1064 거부** · 보정 경로로는 1064 사라짐 (같은 CI 실행 안에서 양쪽) | MySQL 8 |
| G-M8-5 | 쪼개기·벗기기 단위시험 + 음성 대조 | 없음 |

**규칙**: 로컬 DB 없음 = SKIP 이고, SKIP 은 통과가 아니다. CI 에서는 `DbGateEnvironment` 가 SKIP 을 막는다.
