## §5. 함정 (이번에 새로)

2. **「사유 있음」으로 넘긴 차이는 줄을 열어 봐야** — 작21·22 의 「레거시 내부 불일치」 판정이 틀렸다(PM 도 두 번 반복).
3. **PM 계산도 틀린다** — 미수 140,865,113(2월 이후 440줄 누락) · 「10행」(실제 12) · 「378행」(379). 숫자는 독립 계산으로.
4. **머지 충돌 해소에 python 쓰지 마라(스텁)** — 충돌 표시 줄이 커밋에 들어갔다(push 전 amend 로 제거). `sed '/^<<<<<<< /d…'` 후 `grep -c` 0 확인.
5. **무력화 시험 헛통과** — CRLF 로 치환 0건인데 PASS(H+C) · 스크립트 오류로 2회 헛실행(I). 치환 건수부터 확인.
6. **에이전트 턴 한도** — 구현 에이전트 대부분 60턴에 멈춤 → 「지금 상태 커밋 + 명세서 뼈대 먼저」를 착수 지시문에 넣어라. 한 갈래 파일 5개 이하로.
7. **계약(함수 시그니처) 불일치는 머지에서 드러난다** — D·E 는 트랜잭션 인자 없이 만들었고 이관 단계는 열린 트랜잭션 → I 가 오버로드로 봉합. 갈래 간 계약에 트랜잭션·로거·같은 DataTable 인스턴스까지 적어라.
8. **DOCFC 가 오래된 고객**(월마감 안 함)은 맞춤이 최신 거래를 0 으로 덮는다 → 신선도 가드 + R-C2 이월 계산.
