저장된 기억 *「게이트는 글자가 아니라 동작」* · *「N/N 초록은 N 을 세지 말고 축을 세라」* 가 **같은 날 두 번 재현**됐다.

### 2-1 🔴 봉합이 **글자**였던 것 — 마이그 (C-2)

넓히기 블록을 `DB-148` **안에** 넣었다. 적용기(`MigrationRunner`)는 **번호로 skip** 한다 —
`success=1` 인 `migration_id` 면 **파일을 읽지도 않는다** ⇒ 아침 판을 이미 돌린 DB 에 **영영 안 닿는다.**
⇒ **`DB-149` 신설** + 출하 DDL 시드(#36). 🟢 고객 DB 에는 그 칸이 **아직 없다**(`DB-148` 은 출하 전 · 1.3.66 에 없다).
저장된 기억 *「마이그 번호 겹치면 뒤 파일 skip」* 과 **같은 뿌리**.

### 2-2 🔴 「디스크 때문」이라고 **단정했다**

전체 묶음이 기준선보다 14건 많았고, `disk_low` 를 보고 **원인을 단정해 보고**했다.
CTO 가 같은 시험을 단독 실행해 **47/47 초록**을 받았다(그 사이 내가 worktree 를 거둬 여유가 늘었다).
🔴 **둘 다 참일 수 있다 — 단정이 틀렸다.** 판정은 **CI 의 DB 게이트(실제 DB · 초록)** 로 했다.

### 2-3 🔴 대조실험 잔재를 **레포에 남겼다** ([4] 3차 W-5)

보관소 울타리를 `if (false && …)` 로 끈 채 되돌리는 것을 잊었고 **검증이 찾아냈다.**
미커밋이라 커밋에는 안 들어갔지만 **그 상태로 잰 숫자가 내 보고에 섞였다.**
⇒ 되살리기와 복원은 **한 호흡에**, 복원 직후 **해시로 확인**.

### 2-4 🔴 도구가 **인코딩을 깨뜨렸다**

`perl -pi` 에 한글을 넣어 파일 51줄의 UTF-8 이 깨졌다(`git diff --stat` 이 102줄로 튀어 발견 · PowerShell 로 역변환).
`sed -i` 는 CRLF 를 LF 로 바꿨다(내용 동일 · 줄끝만 · `git checkout` 원복).
🔴 **한글은 편집 도구로만** 넣는다 — 저장된 기억 *「도구가 경로·인코딩을 바꾼다」* 그대로.

## §4 🔴🔴 고객 종이가 실제로 틀어지던 자리 셋

### ① 가로 양식에서 워터마크가 **통째로 사라졌다** (R-1 · P1)

로고는 **정사각**으로 깔리는데 크기를 「종이 **너비**」로 잡았다.
가로 용지(297×210)에서 **71% 만 넘으면** 높이가 종이를 넘고, QuestPDF 는 **예외도 로그도 없이 그림을 아예 뺀다**
(검증 실측: PDF 7.3KB · 래스터 **완전 백지**).
🔴 사장님 오더가 *"정중앙 **크게**"* 다 — **크게 하려고 숫자를 올리는 그 동작이 기능을 없앴다.**
⇒ **짧은 변** 기준(`ResolveWatermarkSideMm`) + `MaxWidth`·`MaxHeight` 둘 다.

### ② 「모든 양식 공통」이 **거짓이었다** (R-2 ≡ P1-2 · P1)

`show_watermark` 를 `NOT NULL DEFAULT 0` 으로 만들어 **「정하지 않았다」를 적을 칸이 없었다.**
- 공통을 켜도 **양식을 한 번이라도 저장한 고객에게 영영 안 닿는다**
- 공통만 켠 고객이 양식에서 **여백만 고쳐 저장해도 워터마크가 조용히 사라진다**

⇒ 칸을 지우지 않고 **`NULL` 허용으로 넓혔다**(#1·#37) · 판정을 **한 자리**로 · 화면을 **세 갈래**(공통 따름 / 이 양식만 켜기 / 이 양식만 끄기)로.

### ③ 새 보관소 240줄에 **게이트 0건** (R-3 · P1)

브라우저 파일을 디스크에 쓰고 지우는 코드였다. ⇒ **31건** 신설
(교차 테넌트 삭제 · **실제 링크로 테넌트 폴더 선점** · 네 형식 · 깨진 바이트 · 2MB · 고객 파일이름 미사용).

## §6 🔴 **종이 0회 — 열 차수 연속**

미리보기로는 **「그림이 종이에 찍히나」를 영영 못 잰다.** 이 차수도 못 쟀다.
R-1 은 PDF 바이트·픽셀로 잡았지만 **「프린터에서 로고가 글자를 덮나」는 아무도 안 봤다.**

### 사장님께 부탁할 실측 4건 (게시·적용 뒤)

1. **양식지를 넣고** → 「양식지 그림을 종이에도 인쇄」를 켜고 → **실제 프린터로** 뽑기
2. **워터마크를 켜고** 뽑기 — 로고가 **글자를 덮어 안 읽히지 않는지**(명도 0.12 · 채도 0.15 가 제안값)
3. **가로 양식**(거래명세서·현황표)에서 크기 **100%** 로 뽑기 — 🔴 이번 차수의 R-1 이 바로 거기 있었다
4. **격자를 끄고** 뽑기 — 품목이 **한 줄도 빠지지 않는지**
