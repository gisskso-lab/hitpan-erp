## 3. PM 해석 · 적용 (대표 원문을 넓히지 않는다)
- 실측은 **GitHub 의 Linux 서버**(개발 PC 아님)에서 돈다. HQA 는 **원자료 대조**로 관문 ① 판정을 한다 — 판정자는 여전히 HQA.
- 상신에 적은 대로 **측정 장치는 개발팀이 만든다 → 독립성이 깎인다는 점은 결재 때 이미 드러낸 조건**이다. 그래서 장치 · 기대값 · 판정 글자는 **발행 전 고정**하고 HQA 가 장치 원문까지 읽을 수 있게 공개한다.
- 「CI 추가라 별도 결재 필요」 — 이 결재는 **경로 선택**이다. 워크플로 설계 · 작업지시서는 루틴대로 [1-V] → [2] → PM 결재 → [3] ⟷ [3-V] ∥ [4] → [4-X] 를 밟는다. 전결 아님(11/13 전결은 끝났다).
- 고정 유지: 기능 머리 `16e88c01` · 시험 앱 `01161edb` · 판정 기대값(정본 §6). 기능 가지에 커밋하지 않는다.
- 11/13 결정(코덱스 없이 현행 유지)과 부딪히지 않는다 — 소통은 PR 댓글 · SHA 고정 링크 그대로.
