## §1 [장애 접수]
GitHub 기본 실행기(`ubuntu-latest`)가 Ubuntu 26.04.1 로 넘어갔다(#894 런 44247320987 실행기 정보). ui-browser.yml 세 잡이 `runs-on: ubuntu-latest` 라서 같이 넘어갔고, S7 브라우저 설치가 「Playwright does not support chromium on ubuntu26.04-x64」 로 3회 실패 → S8 건너뜀 → S9 판정이 키 틀 누락 36 FAIL 로 빨강. 같은 잡이 #894 옛 머리 `3382a52b`(11/17)에서는 성공했다 = 코드가 아니라 실행기 판이 바뀐 장애다. S4 측정 워크플로는 이미 `ubuntu-24.04` 로 고정되어 있다(PM 실측 :36 · :212 · main 미반영 가지).
