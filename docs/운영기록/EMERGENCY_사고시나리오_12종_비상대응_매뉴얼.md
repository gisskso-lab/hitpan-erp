## 1. 시나리오 12종

### 시나리오 1 — Windows Update 강제 재부팅 후 통신 다운
- **감지**: 워치독 WS-28-B emergency
- **진단**: cloudflared Service 종료 + TunnelSecret 무효화
- **봉합**: WS-28-C 자동 재발급 (3분) + 사장님 PC 자동 복구
- **본사 조치**: 자동 알림 수신 + CS 채널 사전 안내
- **등급**: 경증 (자동 봉합)

### 시나리오 2 — 백신 격리 (Norton·McAfee)
- **감지**: 사장님 PC 사용자 신고 + 백신 알림
- **진단**: 사전 화이트리스트 미등록 또는 등록 만료
- **봉합**: 1클릭 봉합 매뉴얼 (PDF) + 백신 예외 재등록
- **본사 조치**: 백신사 추가 false positive 메일 발송
- **등급**: 중증 (사용자 1클릭 + 본사 가도)

### 시나리오 3 — MariaDB 서비스 종료
- **감지**: 워치독 WS-28-I emergency (4 프로세스 감시)
- **진단**: 메모리 부족 또는 디스크 IO 실패
- **봉합**: WS-28-I 자동 재기동 (1분) + 사장님 PC 자동 복구
- **본사 조치**: 자동 알림 + emergency 박제
- **등급**: 경증 (자동 봉합)

### 시나리오 4 — 사장님 PC 디스크 가득
- **감지**: 워치독 WS-28-F cool down + 디스크 IO 실패 반복
- **진단**: MariaDB 로그 누적 또는 백업 누적
- **봉합**: 본사 CS 콜 + 디스크 청소 가이드 (사용자 가도)
- **본사 조치**: CS 챗봇 자동 가이드 + 콜센터 백업
- **등급**: 중증 (사용자 가도 + 본사 가도)

### 시나리오 5 — Cloudflare 정책 변경 또는 서비스 중단
- **감지**: Cloudflare 상태 페이지 + 본사 모니터링
- **진단**: Cloudflare 글로벌 장애 (제3자 책임)
- **봉합**: Headscale 비상 가도 (약관 §24의5 명시)
- **본사 조치**: 자동 EXE 업데이트 + 백오피스 공지
- **등급**: 치명 (사장님 결재 + 본사 비상 가도)

### 시나리오 6 — 사장님 PC 전원 차단
- **감지**: 본사 ping 5분 부재
- **진단**: 정전 또는 사장님 의도적 종료
- **봉합**: UPS 권장 가이드 (약관 §24의4) + 자동 시작 박제
- **본사 조치**: SLA 계산 시 고객 책임 영역 제외 (약관 §24의3 ③)
- **등급**: 경증 (사용자 책임 + 본사 안내)

### 시나리오 7 — SQL Injection 시도
- **감지**: 워치독 WS-28-G EventLog + ZAP 알림
- **진단**: 외부 공격자
- **봉합**: Bearer lockout (이미 박제) + 본사 IP 차단
- **본사 조치**: 보안 매니저 1·2 + 사장님 결재 + 법무 대응
- **등급**: 치명 (사장님 결재 + 본사 비상 가도)

### 시나리오 8 — 사장님 PC 랜섬웨어 감염
- **감지**: 백신 알림 + 워치독 emergency
- **진단**: 외부 공격 또는 직원 부주의
- **봉합**: 백업 즉시 복구 (사용자 가도) + 본사 CS 가이드
- **본사 조치**: 백업 매뉴얼 사전 박제 + CS 콜
- **등급**: 치명 (사용자 책임 영역, 본사 가르침 의무)

### 시나리오 9 — 워치독 자체 사망
- **감지**: Guardian 작업스케줄러 자동 부활
- **진단**: 워치독 프로세스 비정상 종료
- **봉합**: WS-28-H Guardian 자동 재실행 (5분) + 사장님 PC 자동 복구
- **본사 조치**: 자동 알림 + 5분 안 본부장 보고
- **등급**: 중증 (자동 봉합 + 본사 모니터링)

### 시나리오 10 — Bearer 토큰 lockout 후 정상 사용자 차단
- **감지**: 사장님 PC 사용자 신고 (인증 실패 반복)
- **진단**: Bearer 토큰 만료 또는 변조
- **봉합**: 본사 CS + 토큰 재발급 가이드
- **본사 조치**: 라이선스 키 재발급 + EXE 재설치 가이드
- **등급**: 중증 (사용자 가도 + 본사 가도)

### 시나리오 11 — 본사 백오피스 서버 다운 (SaaS 결제)
- **감지**: 사장님 PC 라이선스 갱신 실패
- **진단**: 본사 책임 영역 사고
- **봉합**: 본사 인프라 봉합 + SLA 99.99% 위반 시 약관 §24의3 환불
- **본사 조치**: 사장님 결재 + 본부장 + 백엔드 매니저 비상
- **등급**: 치명 (본사 책임 + 자동 환불 가도)

### 시나리오 12 — 4주 누계 사고 3건 이상
- **감지**: PM 누계 박제
- **진단**: 정식 출시 절대 게이트 NO-GO
- **봉합**: 사장님 결재 + 정식 출시 무기한 연기
- **본사 조치**: 재설계 가도
- **등급**: 치명 (정식 출시 연기 결재)
