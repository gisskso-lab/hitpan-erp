## §5. 🔴 함정 — 다음 세션이 밟을 지뢰 (이 절이 이 문서의 값어치)

### 5-1. 「고쳤나」가 아니라 「보이나·열리나」를 물어라 — **9차 재발**
작15 게이트 8개가 **전부 저장 경로만** 쟀다 ⇒ 9건 다 통과하고 **화면에서 반려**.
작16 도 목록만 고치고 **여는 문**을 안 만들어 또 반려.
⇒ **경로 전체를 세라**: 저장 → 조회 → 열기 → 확정 → 원장. 한 칸만 고치면 다음 칸에서 반려난다.
[[project_fixed_vs_delivered_gap]]

### 5-2. 🔴 내가 만든 게이트가 **두 번 가짜**였다
- `if (false && _isReturnMode)` 로 죽였는데 **통과** ⇒ 낱말만 셌다(체크리스트 ⑧)
- `Math.Abs` 지웠는데 **통과** ⇒ **다른 곳의 `Math.Abs` 가 대신 통과**시켰다(⑥)
⇒ **짜면 곧바로 봉합 빼고 FAIL 확인.** 통과하면 게이트가 가짜다.

### 5-3. 🔴 게이트가 내 봉합과 충돌하면 **지우기 전에 왜 있었는지 읽어라** (⑦ — 두 번 겪음)
- 8/31: `PurchaseReturnInReportsGateTests` 고정 **2600자 창**에 앵커가 밀려 FAIL
- 9/3: 내 G-2 의 `[^}]{0,400}` 창이 **중첩 if 때문에 첫 `}` 에서** 끊겨 FAIL
⇒ **둘 다 봉합이 틀린 게 아니라 자가 짧았다.** 창을 넓혔지 검사를 약화하지 않았다.
- 9/3: `MigrationLocationGuard` 가 **DB-116 미등록**을 잡음 ⇒ **진짜 결함이었다**(신규설치가 마이그 두 번 돌림).

### 5-4. 사장님 전제가 **DDL 상 반증돼도 우려는 정당할 수 있다**
*"반품테이블 자체가 매입반품"* → 표 4개 물리 분리·FK 반대 방향이라 **사실 아님**.
🟢 **그러나** ①코드가 `Purchase…` 이름을 뒤집어씀 ②**14차에 실제로 매출반품이 매입으로 저장된 사고**가 있었다.
⇒ **반증했으면 「왜 그렇게 보였나」까지 답하라.** 안 하면 결론이 나중에 다시 뒤집힌다.

### 5-5. 🔴 내가 **추정을 근거로 보고한 게 2건**
- *"음수가 양수로 둔갑했다"* → **틀림.** `Math.Abs`·클램프 **코드 전체 0건**, 서버 `[Range]` 가 저장을 거부한 것.
- *"레거시는 음수 방식이라 B안이 자연스럽다"* → **반대였다.** `IJ_IO='I'/'O'` **방향코드 = A안**.
⇒ **실측 한 줄이면 갈렸다.** 추정을 보고에 섞지 마라.

### 5-6. 게시 — `requiresMigration` 을 빼면 **기본값 false 로 나간다**
9/3 첫 게시 **실패**. 게이트가 막았다: *"새 마이그 1건인데 false 로 게시하려 한다 … 워치독이 고객 PC 에서 업데이트를 중단시킨다."*
⇒ **DB-NN 을 추가한 릴리스는 반드시 `-f requiresMigration=true`.** 게이트가 맞았고 내가 틀렸다.

### 5-7. `git add -A src` 가 **빌드 산출물 1130개**를 쓸어담았다
`installer/payload/**` 가 untracked 라 함께 스테이징 ⇒ push 가 **remote hung up** 으로 실패.
⇒ **바꾼 파일을 이름으로 지정해 add 하라.** 커밋 직후 `git show --name-only | wc -l` 로 개수 확인.

### 5-8. 실물 DB 는 **내 권한으로 못 본다**
`hitpan` 계정에 `hitpan_erp` **GRANT 는 있는데 DB 가 실재하지 않는다**. API 직접 호출은 **기기 인증**에 막힌다.
🟢 **되는 길 = Playwright 감사 스크립트**(§7) — 브라우저 경로라 기기 인증을 탄다.
⚠️ 시험용 `hitpan_e2e`·TEMPORARY 표는 **가짜다.** 보고할 때 반드시 구분.
