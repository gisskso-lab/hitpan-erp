## 2. 측정 계획 ([1-V] 몫 · 코드 변경 없이 먼저)
1. 실패 메시지의 MySQL 오류 번호 수집(1040 Too many connections · 2002/2013 · 1129 host blocked 등).
2. `db-gate` 잡 앞·뒤에 `SHOW GLOBAL VARIABLES LIKE 'max_connections'` · `SHOW GLOBAL STATUS` 의 `Max_used_connections`·`Threads_connected`·`Aborted_connects`·`Connection_errors_%` 를 찍는 단계 — **워크플로 수정은 [2] 결재 뒤**.
3. 대조군: 같은 SHA 에서 작5 게이트(`EmployeeAccountLinkGate`)를 GATES 에서 뺀 실행 1회(가설 ⓑ).
4. 첫 자료 = 작5 머지 SHA 의 main CI.

## 3. 하지 않는 것
- 시험을 재시도로 감싸 초록 만들기 금지(값 단언을 숨긴다 · 「게이트는 글자가 아니라 동작」).
- 작5 머지를 이 트랙으로 막지 않는다 — 결8 G-3 판정식으로 판단.
