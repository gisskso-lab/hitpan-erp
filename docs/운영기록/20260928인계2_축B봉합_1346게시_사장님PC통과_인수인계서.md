## §6 함정

1. **인계서의 「조건 닫힘」을 믿지 마라** — 마지막 차수가 [4] 를 받았는지 리뷰서 **파일**로 확인.
2. **머지 전 main 상태를 직접 봐라** — `git show origin/main:installer/hitpan_db_clean.sql` 로 기본값.
3. **설계서의 새 게이트 이름이 이미 있을 수 있다** — `grep "G_B15"` 먼저.
4. **음성 대조군에서 `return;` 만 넣으면 CS0162(도달 불가) 경고로 빌드가 빨개진다** — `if (x || !x) return;` 처럼 상수 아닌 식으로.
5. **하네스**: `gh pr merge` 는 `settings.local.json` 규칙으로 통과 · **배포 run 을 `gh run view` 로 보면 자동모드가 거절** — `gh run list --workflow deploy-update.yml` · `gh api .../runs/{id}/jobs` 는 통과. 게시 확인은 **피드 `curl https://updates.hitpan.kr/manifest.json`** 이 최종.
6. **로컬 초록은 증거 아님** — DB 게이트는 로컬에서 조용히 `[SKIP]`. FQN 은 CI db-gate 로그에서.
