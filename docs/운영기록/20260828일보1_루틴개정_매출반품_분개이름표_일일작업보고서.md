## 5. [4] 검증이 문서를 반려했다 (P2)

개발명세서 §4 가 명세서취소 `source_id` 를 `'{deliveryId}:cancel'` 로 적었는데 **틀렸다.**
`:cancel` 은 `MonthlySummaryGuard` 멱등키 얘기고, **회계 호출은 순수 `deliveryId`**.
⇒ 주석 읽고 **다른 서브시스템 규칙을 회계에 옮겨 적었다** = 받아쓰기.

코드는 안전(두 id 모두 GUID)하나 **근거가 틀렸으므로** 정정 + 한계 명시. → 봉합.
