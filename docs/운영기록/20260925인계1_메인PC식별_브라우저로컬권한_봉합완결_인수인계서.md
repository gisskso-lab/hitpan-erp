## §2 원인 — 다시 안 재도 된다 (확정)

**브라우저가 https 페이지 → 로컬(127.0.0.1) 요청에 「사용자 권한」을 묻기 시작했다.**
허용 전까지 요청은 **매달리는데**, 앱은 **1500ms 에 스스로 끊었다.**

```
새 브라우저로 처음 연다 → 권한 팝업이 뜬다 → 그동안 요청은 매달린다
   → 앱이 1500ms 에 포기        ⇒ "클라이언트 PC" 로 판정
   → 고객이 [허용] 을 눌러도 그 왕복은 이미 죽어 있다  ⇒ 화면이 안 바뀐다
   → 새로고침해야 비로소 열린다
```

🔴 **고객 눈에는 "허용했는데도 안 되는 고장"으로 보인다.**

### 대조실험 (변수 하나씩)

| 잰 것 | 결과 |
|---|---|
| curl 왕복 ①②③ (브라우저 없이) | 🟢 통과 — **서버·등록·봉인키 결백** |
| 새 프로필 **Edge** | 🔴 실패 1505·1515·1504ms ⇒ **브라우저 종류 축 반증** |
| `PrivateNetworkAccessSendPreflights` 끔 | 🔴 여전히 실패 ⇒ **서버 CORS 헤더로는 못 푼다** |
| **`LocalNetworkAccessChecks` 끔** | 🟢 OK 200 @11·6·5ms ← **범인** |
| `loopback_network` 권한 **한 줄만** 주입 | 🟢 OK 200 @42·5·5ms (없으면 FAIL @1506ms) |

🔴 **권한 이름 = `loopback_network`** · 저장 위치 = 브라우저 **프로필**
`%LOCALAPPDATA%\{Google\Chrome|Microsoft\Edge}\User Data\Default\Preferences`
→ `profile.content_settings.exceptions.loopback_network` · `setting:1` = 허용

**저장시각이 관찰과 일치한다** — Edge **9/23 01:31**(그날 실측) · Chrome **9/25 01:09**(사장님이 *"안 된다"* 하신 그 시각).

### 🔴 걸리는 시간 (실측 — 다음에 또 쓸 값)

| 상황 | 시간 |
|---|---|
| 히트판 **없는** PC (고객 클라이언트) | **1ms** — 연결 거부 |
| 권한 **거부**된 메인PC | **1~3ms** — 즉시 차단 |
| 권한 **있는** 메인PC | **5~42ms** |
| 권한 **팝업 대기 중** | **매달림** ← 시간제한에 걸리는 **유일한** 경우 |

## §6 🔴 내가 틀린 것 — 다음 사람이 반복하지 않게

### ① 9/23 "실물 실측 통과" 가 틀렸다

그날 Edge 에서 왕복이 돈 것은 **사람이 권한 팝업을 허용한 뒤**의 결과였다.
**그 손 한 번을 측정에 안 넣었다.**
> 브라우저를 안 바꿔본 것보다 **이쪽이 더 큰 누락**이다.
> 🔴 **한 번 통과한 경로에 사람 손이 몇 번 들어갔는지 세라.**

### ② 9/24 인계3 에 "브라우저 무관" 이라 적었다

같은 검증에서 `hitpan-mainpc-proof.js` 가 **브라우저 fetch 에 의존**한다는 걸
**직접 읽고 인용까지 해놓고** 반대 결론을 냈다. **열쇠 쪽만 보고 그것을 트리거하는 쪽을 안 셌다.**
⇒ 이 트랙에서 **축을 안 세고 결론 낸 것이 두 번째**다.

### ③ 실물 검증에서 측정 순서가 결과를 오염시켰다

한 페이지에서 **M-3(빈 포트)을 먼저** 쏘니 권한 상태가 바뀌어
M-1 이 **3023ms** 로 나왔고, 나는 그것을 *"실패"* 라고 보고했다.
**새 프로필로 다시 재니 20006ms — 통과였다.**
🔴 **권한이 걸린 축은 측정마다 프로필을 새로 판다.**

### ④ 원인 가설을 두 번 헛짚었다

`PrivateNetworkAccess`(preflight) → 대조실험에서 **기각**.
`1500ms 타임아웃 초과` → 첫 측정에서 6~27ms 로 **기각**.
🔴 **둘 다 "그럴듯했다."** 대조실험으로 하나씩 지우지 않았으면 엉뚱한 곳(서버 CORS 헤더)을 고쳤을 것이다.

## §7 🔴 함정 — 다음 사람이 밟기 쉬운 것

1. **`TIMEOUT_MS` 를 되돌리지 마라.** 주석이 이제 실측을 담고 있다. G-33 이 FAIL 로 잡는다.
2. **왕복을 복붙하지 마라.** `MainPcProofRunner` 한 곳이다. G-34 가 센다.
3. **재시도를 `ResolveAsync` 바깥에 넣지 마라.** G-27 계약이 깨진다.
4. **헤드리스로 재지 마라.** 이 축은 결과가 **정반대로** 나온다.
5. **한 프로필에서 여러 측정을 잇지 마라** (§6-③).
6. **`mainpc-proof` 의 `net::ERR_ABORTED` 는 차단이 아니다.** 앱이 스스로 끊은 것이다 — 원인이 정반대로 읽힌다.
7. **서버를 의심하기 전에 curl 로 왕복을 돌려라.** 브라우저를 빼면 서버 결백이 1분에 갈린다.
8. **게시 ≠ 적용.** 피드에 올라가도 고객이 **팝업 [예]** 를 눌러야 바뀐다 (#43).
9. **auto 모드에서는 운영 게시가 분류기에 막힌다.** 채팅 지시는 하네스 권한과 다른 층이다 —
   `settings.local.json` 규칙이 없으면 사장님이 직접 dispatch 하셔야 한다. 🔴 **권한 파일을 스스로 고쳐 열지 마라.**
