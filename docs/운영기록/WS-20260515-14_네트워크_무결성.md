## 1. 목적

고객 PC 네트워크 환경 다양성 (사무실 NAT·기업 Proxy·DNS 오염·ISP 장애) 대응. 어떤 환경에서도 cloudflared 터널이 정상 동작.

## 2. 3축

### 축 A. TCP keep-alive (긴 idle 끊김 방지)
방화벽·NAT가 idle 30분 후 끊는 환경 대응.

### 축 B. DNS fallback (DoH/DoT + 다중 resolver)
ISP DNS 장애·오염 시 Cloudflare/Google DNS-over-HTTPS 자동 전환.

### 축 C. Proxy 자동 감지 (WPAD·시스템 설정 + 인증)
기업 환경 PAC/HTTP_PROXY/NTLM 인증 Proxy 자동 통과.

    public async Task<IPAddress[]> ResolveAsync(string host, CancellationToken ct) {
        // 1. 시스템 DNS 시도
        try {
            return await Dns.GetHostAddressesAsync(host, ct);
        } catch { /* fallback */ }

        // 2. Cloudflare DoH
        try {
            return await DoHQueryAsync(host, "https://cloudflare-dns.com/dns-query", ct);
        } catch { /* fallback */ }

        // 3. Google DoH
        try {
            return await DoHQueryAsync(host, "https://dns.google/dns-query", ct);
        } catch {
            throw new Exception($"DNS 해석 전체 실패: {host}");
