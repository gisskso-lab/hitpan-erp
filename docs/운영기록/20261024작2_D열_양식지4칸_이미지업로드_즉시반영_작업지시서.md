## §2 절① 업로드 통로 — 합격선과 울타리

**받는 자리** `POST /api/form-templates/background` (`IFormFile`)
**넣는 자리** `%ProgramData%\HitPan\form-backgrounds\{tenant_id}\{새 이름}{확장자}`
**돌려주는 것** 작성기가 읽을 수 있는 **절대 경로 한 줄**

🔴 **쓰기 울타리 7중** — 읽기 울타리가 있다고 쓰기가 안전해지지 않는다

| # | 막는 것 | 왜 |
|---|---|---|
| 1 | `tenant_id` = **JWT 클레임에서만**(#2) | 파라미터로 받으면 즉시 반려 |
| 2 | 확장자 **5종만**(`.png`·`.jpg`·`.jpeg`·`.bmp`·`.webp`) | 작성기 허용과 **같은 목록을 쓴다**(두 벌 금지) |
| 3 | **20MB 상한** | 작성기 상한과 같은 값 |
| 4 | 🔴 **파일 이름을 고객에게서 받지 않는다** — 서버가 새 이름을 만든다 | `..\`·`:`·예약어·한글 깨짐·덮어쓰기를 **원천 차단** |
| 5 | 🔴 **저장 전에 그려 본다**(`Image.FromBinaryData`) | 못 그릴 바이트를 **보관소에 넣지 않는다**(R-2 를 입구로 당긴다) |
| 6 | 🔴 폴더가 없으면 **만든다** · 테넌트 폴더 **밖으로 못 나간다**(FullPath 비교 + 구분자) | R-4 를 쓰기 방향으로 |
| 7 | 🔴 **빈 catch 금지**(#15) · 실패는 **사람 말**로 돌려준다 | 「막았습니다」와 「못 올렸습니다」를 가른다 |

**합격선 ①** 🟢 실제 JPG 1장이 보관소에 **파일로 생긴다** · 🔴 확장자·크기·깨진 바이트 **각각 거절 1건**

## §3 절② 편집기 — 🔴 **「즉시」의 정의**

| 순서 | 무엇 | 🔴 규칙 |
|---|---|---|
| 1 | **파일 고르기** 단추 신설(`MudFileUpload`) | 🔴 **기존 URL 글자 칸을 지우지 않는다**(#1) — 더한다 |
| 2 | 올리면 서버가 경로를 돌려준다 | 실패하면 **그 자리에 사람 말로** 알린다 |
| 3 | 🟢 `_form.BackgroundImageUrl` 에 **그 경로를 넣는다** | 🔴 **저장하지 않는다** — 미리보기는 저장 전 값으로 그린다 |
| 4 | 🔴 **바로 미리보기를 다시 그린다**(`PreviewAsync()` 재호출) | **이것이 「즉시 반영」이다.** 고객이 단추를 두 번 누르게 하지 않는다 |
| 5 | 올린 그림을 **지우는 길**도 둔다 | 지우면 칸을 비우고 미리보기를 다시 그린다 |

**합격선 ②** 🟢 파일 고르기 → **다른 손짓 없이** 미리보기에 그 양식지가 깔려 보인다
🔴 **「저장했습니다」라고 말하지 않는다** — 저장은 저장 단추가 한다(`PrintSettingsPage` 거짓문구 사고 재발 금지)

## §4 절③ 작성기 4칸 — 칸마다 합격선

| 칸 | 무엇 | 🔴 주의 |
|---|---|---|
| `paper_size` | `A4`·`A5`·`Letter` → `page.Size(...)` **5곳** | 🔴 **모르는 값은 A4 로 떨어진다**(고객 종이가 안 나가는 일은 없다 · #20) |
| `orientation` | `landscape` 면 가로 | 🔴 세금계산서 여백 상한(`ClampTaxInvoiceMargin`)과 **부딪히지 않는지** 확인 |
| `show_company_seal` | 끄면 직인을 **안 찍는다** | 🔴 **배선만** — 직인 보관소가 없어 `seal_url` 은 늘 비어 있다(1-V §5-2). 🔴 **「직인이 나온다」고 적지 않는다** |
| `style_key` | 작성기까지 **전달** | 🔴 **배선만** — 4종 디자인 미확정(DDL 주석). 🔴 `basic` 외 값이 와도 **basic 으로 그린다** |

🔴 **세금계산서는 법정 서식이다** — 로고·테두리 손대지 않는다(D-5 · 법무팀장 결재 먼저).
**합격선 ③** 🟢 양식에서 A5·가로를 고르면 **미리보기와 인쇄 둘 다** 바뀐다(같은 통로라 자동) · 🟢 빌드 **0 errors · 0 warnings**(`-Project "src/HitPan.sln"`)

## §5 절④ 게이트 — 🔴 **N 을 세지 말고 축을 센다**

| 축 | 시험 | 음성 대조군 |
|---|---|---|
| A | 업로드가 **보관소 안에만** 쓴다 | 울타리 비교 줄을 빼면 **빨감** |
| B | 확장자·크기·깨진 바이트 **각각 거절** | 거절 줄을 빼면 **빨감** |
| C | 고객 파일 이름을 **쓰지 않는다** | 이름을 그대로 쓰면 **빨감** |
| D | `paper_size`·`orientation` 이 작성기에 **닿는다** | 전달 줄을 빼면 **빨감** |
| E | 모르는 값 → **A4·세로로 떨어진다** | 떨어뜨리는 줄을 빼면 **빨감** |
| F | 🔴 **칸을 손 목록으로 적지 않는다** — 양식 DTO 에서 **긁어서** 작성기 전달 여부를 본다 | 칸이 늘어 전달이 빠지면 **스스로 빨개진다** |

🔴 **F 가 핵심이다.** 10/24 G-1 은 손으로 적은 7종 목록이라 **분기를 빼도 42/42 초록**이었다. 같은 모양을 또 만들지 않는다.
🔴 **회귀 기준선** 실패 **157** 고정(DB 필요 게이트) — 새로 깨진 것 **0건**이어야 한다.
