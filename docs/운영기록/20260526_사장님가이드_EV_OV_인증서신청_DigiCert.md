## 🎯 Step 2: OV 인증서 먼저 신청 (24시간 발급)

### 제품 선택
- **OV Code Signing Certificate** (1년)
- 가격: 약 30만원 (파트너 별 ±5만원)

### 신청 절차
1. **장바구니 담기** → OV Code Signing 1년
2. **회사 정보 입력** (영문)
3. **법인 서류 업로드** (사업자등록증·등기부등본)
4. **결제** (신용카드)
5. **검증 통화 수신** (DigiCert가 회사 대표번호로 전화 → 신청자 확인)
6. **24시간 내 발급 이메일 수신**

### 발급 후 가도
- `.pfx` 파일 다운로드 + **비밀번호 안전 보관** (잃어버리면 재발급)
- PM에게 `.pfx` 파일 전달 → 빌드 파이프라인 등록

## 🎯 Step 3: EV 인증서 동시 신청 (5~10일 발급)

### 제품 선택
- **EV Code Signing Certificate** (3년)
- 가격: 약 60만원 (3년 일괄, 한국 파트너 기준)
- USB 토큰(eToken) 또는 HSM 클라우드 옵션 — **HSM 클라우드 권장** (분실 위험 0)

### 신청 절차
1. **장바구니 담기** → EV Code Signing 3년 + HSM 클라우드
2. **회사 정보 입력** (영문, OV와 동일)
3. **추가 서류 업로드**:
   - D&B 등록번호 (없으면 신청 시 자동 등록 5일 소요)
   - 또는 한국 법인등기부등본 영문 번역본 (공증 필요할 수 있음)
4. **결제** (신용카드)
5. **신원 검증 통화** (DigiCert가 사장님 직접 통화 → 영어 또는 한국 파트너 한국어)
6. **5~10일 발급 이메일 수신**

### 발급 후 가도
- HSM 클라우드 접속 정보 수신
- PM에게 클라우드 서명 설정 정보 전달 → CI/CD 파이프라인 통합
