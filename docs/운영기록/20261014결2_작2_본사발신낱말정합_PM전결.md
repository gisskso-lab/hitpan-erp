## §5 🔴 내가 낸 일 3건 — 적고 넘어간다

1. 🔴 **내 게이트에 구멍이 있었다**(C-3). 「게이트는 동어반복이면 안 된다」를 문서에 적어 놓고, 기대값을 **과녁 자신**에서 가져오는 게이트를 5건 만들었다. 낱말을 엉뚱한 말로 바꿔도 **전부 초록**이었다. **[4] 가 없었으면 못 잡았다.**
2. 🔴 **[1-V] P-10 을 틀리게 적었다**(C-2). `ls -d src/HitPan.Backoffice.*` 의 **점 한 글자**가 프로젝트를 숨겼고, 그 「없다」 위에 「어긋날 자리 0건」이라는 판정을 쌓았다. **도구가 세는 방식을 안 보고 결과를 사실로 적었다.**
3. 🔴 **INDEX 줄 하나를 덮어썼다.** awk 에 `next` 를 써서 삽입이 아니라 **교체**가 됐고 **일정표 줄이 사라졌다.** git 에서 되살리고 `numstat` 으로 **추가 1·삭제 0**을 확인했다. 「문서는 지우지 않는다」(#41)를 내가 어겼다 되돌렸다.

🔴 세 건 다 **내가 적은 규칙을 내가 어긴 것**이다. 2번은 「없다」를 적을 때 **세는 방식부터 적는다**로, 3번은 **INDEX 는 손댄 뒤 `numstat` 으로 삭제 0 을 확인한다**로 남긴다.
