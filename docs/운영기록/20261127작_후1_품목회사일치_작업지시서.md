## §3 [갈래 1] 출력 7자리 — 조각 더하기만

- **LEFT JOIN 유지**(INNER 면 줄이 사라져 합계 ≠ 줄 합 · 결함이 숨음) — HQA6 K1 과 같음. 다른 회사 품목 줄 = 행 · 금액 남고 품명 · 규격만 빈 칸.
- 상세행 칸 꼴인 까닭: 그 칸이 이미 WHERE 에서 `@TenantId` 로 묶여 있음 → #2. 견적만 칸이 없어 `@TenantId` 를 직접 씀(선례 `QuotationService.cs:137~139`).
- P1 에서 `qi.tenant_id` 꼴을 쓰면 칸 없음 오류 → 견적 종이가 안내문 종이로 떨어짐(:1424 catch) — **G-1 견적 시험이 이 실수를 잡음**(§5-1).
- 각 자리에 `// 종전:` 주석으로 옛 글자 남김(#1). FROM 글자(`FROM sales_order_items soi` 등)는 바꾸지 않음.
