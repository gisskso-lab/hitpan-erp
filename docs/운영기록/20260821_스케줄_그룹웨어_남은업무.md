> 상무님: *"사장님의 '전부 수동' 원칙은 **금액·복직일**에 대한 것이지,

## 3. ④ 메뉴 통합 + 결재 필터 — A안 확정

### 4-1. 결재창구 통합 (오더 1·15)
```
[전] 결재 대기 · 내가 보낸 결재 · 완료된 결재     메뉴 3개
[후] 결재관리 + 콤보2개                          메뉴 1개
[유지] 결재설정(/settings/approval)              ← A안: ON/OFF + 결재라인 한 화면
```

🔴 **지금 결재 3화면에 필터가 0개다** — API 가 파라미터를 아예 안 받는다.
⇒ **화면·API 양쪽 신규 작업**이다.

### 4-2. 🔴 상무님이 필터2 를 반증했다

사장님 안(보고서·휴가·휴직·경비신청·입사퇴사 5종)에 문제 2가지:
- 🔴 **초과근무가 빠졌다** — *"건수로는 결재함 1등이 될 물건"*
- 🔴 **영업·구매 7종이 통째로 빠졌다**(견적·수주·거래명세서·발주·매입·반품2)
  > *"결재 설정을 켠 고객은 결재함에 매입·매출이 쏟아지는데 **인사 문서만 필터가 있다.**"*
- ⚠️ **"입사퇴사" 는 결재 문서종류가 아니다** — 지금 넣으면 **항상 0건**

**상무님 대안(2단 필터)**:
```
필터2-A: 전체 / 인사·근태 / 영업 / 구매 / 경비
필터2-B: A 선택에 따라 좁혀짐
```
⇒ 🔴 **사장님 결재 필요** (오더 원안 변경)

### 4-3. 필터1 에 빠진 것
**`내가 반려한 것`** — *"반려는 **다시 올라올 것**이라 따로 봐야 한다"*(상무님)

### 4-4. 사원관리 필터 (오더 4)
전직원·부서별·직급별 + **재직/퇴사 축**을 여기 녹인다(지금 스위치를 필터로 승격).

### 4-5. ⚠️ 함께 볼 것
- 급여 메뉴 **되살리기** — 사장님 확인: 오더 15 에서 빠진 건 **실수**
- 상무님: 메뉴 순서가 **관리자 기준** — *"여는 사람 90%가 직원인데 직원 것이 4번째부터"*
- 상무님: 휴가 3형제 이름 정리 — **연차 신청(직원) / 휴가 승인(관리자) / 연차 규정(연 1~2회)**
- ⚠️ `GroupwareStage0GuardTests` 가 사이드바 주소를 단언 → **함께 갱신 필수**
- 🔴 내린 주소는 **리다이렉트로 살린다**(8/13 원칙 — 404 금지)
