# 【2】 업무 주의사항 — 반복해서 틀린 자리

## 🔴🔴 2-1. 이번 세션의 핵심 — **매입은 고쳤고 매출은 안 고쳤다**

작11 W1 의 정체가 이것이다. `PurchaseService.cs:726-747` 주석 **원문**:

> *"즉 **발주 1건으로 매입 2장을 만들 수 있었다(재고 2배 입고)**.
> 남은 방어는 `receiptItems.Count == 0` 뿐인데 그건 `received_qty` 가 제대로 올라갔을 때만 듣는다."*

**매출은 지금 그 봉합 전 상태 그대로였다.** 같은 사고, 같은 원리, 반대쪽 라인.

🔴 **교훈**: 한쪽 라인에서 사고가 나면 **반대쪽 라인에 같은 코드가 있는지 그 자리에서 확인하라.**
매입·매출은 거울이다. 한쪽만 고치면 **나머지 절반은 시한폭탄으로 남는다.**

⚠️ 단 **복사는 금지** — 사장님: *"매입을 매출에 맞춰서 하지 않잖아"*.
매입반품은 매입·미지급금, **매출반품은 매출·미수**를 건드린다. **대칭 이식이지 복붙이 아니다.**

## 🔴🔴 2-2. 게이트는 글자가 아니라 **동작** — 가짜 누적 **22번** (이번에 +1)

🔴 **G-4 가 가짜였다. 이번 세션에서 내가 잡았다.**
가드를 **`if (false && …)`** 로 죽이고 돌렸는데 **그대로 통과**했다 — 문자열이 파일에 남아 있어서다.
**체크리스트 ⑧ 에 이미 적혀 있던 함정에 그대로 빠졌다.**

⇒ *"조건이 살아서 던지는지"* 까지 보도록 고치니 **FAIL** 로 바뀌었다.
🔴 **짜고 곧바로 반증하지 않았으면 가짜 초록불이 그대로 나갔다.**

| # | 규칙 |
|---|---|
| ① | 짜면 **곧바로 봉합 빼고 FAIL 확인** |
| ② | **초록불이 어디서 오는지** 봐라 |
| ③ | **글자검사 금지** · ④ **반환값 판정 금지** |
| ⑥ | **낱말 하나로 검사 금지** (같은 이름이 정의·배선·주석에 다 산다) |
| ⑧ | 🔴 **`if (false && …)` 로 죽여도 통과하면 가짜** ← **이번에 또 걸림** |
| ⑩ | **대조군 필수** — G-1 은 *옛 가드는 통과시키고 새 가드는 막는* 대조군으로 짰다 |
| ⑮ | 🔴 **만드는 쪽만 재면 9건 다 통과하고도 반려난다** — 질문은 *"고쳤나"* 아닌 **"갔나"** |

## 🔴 2-3. 도구가 대상을 바꿔치기한다 — 누적 **6회**

이번 세션에서 **2건 추가**:

| # | 사고 | 결과 |
|---|---|---|
| ⑤ | 🔴🔴 **`mysql` 기본 charset 이 한글을 CP949 로 재서** 문자열 길이가 **25 → 20 → 17** 로 세 번 다르게 나왔다 | **작업지시서에 "ERROR 1406 오버플로" 라고 썼는데 그런 사고는 애초에 없었다.** 게이트가 FAIL 나서 잡음 |
| ⑥ | `perl -0pi` 가 **0건 치환하고도 exit 0** — 3번 조용히 아무것도 안 함 | 매번 바뀐 줄을 눈으로 봐서 잡음 → **Edit 도구로 전환**(실패하면 시끄럽게 실패) |

🔴 **길이는 내가 세지 말고 DB 에게 물어라.** 게이트를 그렇게 다시 짰다.

### 🔴🔴 W1 — 수주 1건으로 거래명세서가 **2장** 나왔다

유일한 방어가 `deliveryItems.Count == 0` 인데, 그게 의존하는 `delivered_qty` 는

⇒ **명세서를 만들고 확정 전(draft)에 다시 전환하면 그대로 통과.**
**둘 다 확정하면 재고 2배 출고.**

**매입은 이 사고를 이미 겪고 고쳤다**(`PurchaseService.cs:726-747`). **매출만 그 봉합을 못 받았다.**
⇒ 대칭 이식 + **기존 명세서 번호를 알려준다.**

### 🔴 W2 — 계산서 중복 가드가 **테넌트를 안 봤다**

(차변 매출 + 부가세예수금 / 대변 외상매출금)

### 🔴 그럼 진짜 구멍은 어디인가 — **읽는 쪽이다**

**쓰는 쪽은 맞고, 읽는 쪽이 매출반품을 안 본다.** 실측 대비:

| 파일 | `purchase_returns` | `sales_returns` |
|---|---|---|
| `FinanceService.cs` | **10회** | 🔴 **0회** |
| `ReportService.cs` | **26회** | 🔴 **7회** |
| `CollectionService.cs` | **1회** | 🔴 **0회** |

⇒ **분개는 쌓이는데 집계·조회가 그걸 안 센다.**
**영향**: 부가세 매출세액 과대계상 · 미수금 과대 · 손익 왜곡 — **결론은 인계5와 같고, 자리가 다르다.**

🔴 **이것이 "고쳤다 ≠ 갔다" 의 7차다.** 만드는 쪽만 보고 **읽는 쪽을 안 봤다.**

- **착수 전**: 사장님께 **범위 결재** (매입라인 밖)
- **주의**: 매입 코드 복사 금지 — **매출반품은 매출·미수**를 건드린다

## 🔴 P0-2 — 마이너스 전표 · 마이너스 계산서 (사장님 명시 오더)

**작8에서 매입에만 적용하고 매출·계산서로 못 옮긴 것이 내 누락이다.**
