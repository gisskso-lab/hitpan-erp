## §5 다음 사람이 바로 알아야 할 것

1. 🔴 **「돈다」고 쓰기 전에 실물 왕복 1회.** CI 초록은 **코드가 맞물린다**는 증거이고, **터널·운영이 맞물린다**는 증거가 아니다.
2. 🔴 **이 게이트는 로컬에서 돈다.** `HITPAN_W3_ERP_DB=test_w3_erp HITPAN_W3_BO_DB=test_w3_bo HITPAN_DB_USER=… HITPAN_DB_PASS=… HITPAN_REQUIRE_DB=true dotnet test --filter FullyQualifiedName~CsPipelineRoundTripGateTests`
   · 🔴 **DB 를 DROP 하는 게이트**라 이름에 `test`·`gate` 가 없으면 **지정을 거부**하고 무작위로 돈다.
   · 🔴 **클래스를 하나씩** 돌려라(override DB 가 하나인데 xUnit 이 클래스를 병렬로 돌려 서로 표를 DROP 한다 — 로컬 전용 함정).
3. 🔴 **음성 대조군을 쓸 때 「정말 두드렸나」를 함께 물어라.** 결과 0 에는 이유가 둘 있다 — **거부 / 미발송**. 재시도·백오프·잠금·레이트리밋이 있는 경로에서 음성 축을 **연달아** 쓰면 두 번째는 빈 대조군이 된다.
4. 🔴 **`DB-144` 자체를 도는 게이트는 0건이다.** 게이트는 ERP DB 를 **출하 DDL import** 로 세우므로 증명하는 건 「칸이 출하본에 있다」뿐이고, **기존 고객 전원이 지나가는 마이그 경로는 한 번도 안 돈다.** ERP `Migrations/SQL` 을 **실행**하는 게이트가 레포 전체에 **0건** — 트랙 하나가 필요하다([4] V-8ⓐ).
5. **변환표가 두 파일에 나뉘어 있다** — ERP 7모양 목록은 `CsRequestController`, 7→8 변환표는 `CsInboundController`. **한쪽만 늘어나면 새 모양이 조용히 400** 이 된다.
6. **`MaxAttempts` 도달 후 `terminal_reason='failed'`** 가 「유실 0」인지 **조용한 포기**인지 — 나는 판정하지 않았다. [4] 에 올려 뒀다.
7. 🔴 **선발신은 「전달 대기 큐」다.** 백오피스가 「보냈습니다」라고 말하지 않는다 — `delivered_at` 은 **ack 뒤에만** 채워진다.
8. **보관기한에 자동삭제는 없다**(폐기 후보만 보여주고 기본 무기한). 폐기는 **사유 필수 · 본문만 비움 · 감사기록 남김 · 행 보존**.
