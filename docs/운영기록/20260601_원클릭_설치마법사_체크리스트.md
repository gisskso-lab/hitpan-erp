## 0. 원클릭 설치 절대 원칙 (사장님 헌법 — 2026-06-01 강화)

> **결재 후 히트판ERP 다운로드 → EXE 실행 한 번 → 사용자 입력 0건 → 완료까지 자동**

- 🔴 **사용자 입력 = 0건** (라이선스 키도 입력 받지 않음 — EXE 파일명 또는 내장 매니페스트에 박제)
- 🔴 **다운로드 = 본사 백오피스 결재 후 자동 생성된 개인 EXE** (`HitPanSetup_{시리얼}.exe`)
- 🔴 **클릭 = 1번** (다운로드 폴더에서 더블클릭, UAC 1번이 끝)
- Cloudflare API 토큰·DB 비번·DNS 키는 **EXE에 절대 포함 금지** (헌법 #18·#22)
- 도메인 = `hitpan-{계정명}.kr` 또는 `{고객사}.hitpan.kr` 자동 생성
- 설치 완료 목표 = **10분 이내** (헌법 #26 목표·Timeout 분리)
- 백신 5종 + Defender + EDR 3종 환경에서 격리 0건 (헌법 #31)
- 워치독 동봉 + 자가 회복 (헌법 #28·#30)
- 5중 검증 통과 후 배포 (헌법 #23)

### 0.1 라이선스 키 박제 방식 (사용자 입력 0건 봉합)

**방식 A — 파일명 박제 (권장)**
```
HitPanSetup_HP-2606-A8K9X3F2-7C.exe
                ^^^^^^^^^^^^^^^^^ ← 시리얼이 파일명에 박제
```
- 본사 결제 결재 → 시리얼 발급 → `installer/build-installer.ps1` 시리얼 인자 받아 빌드 → 개인 EXE 생성 → 다운로드 링크 1회용 토큰
- Inno Setup `{srcexe}` 박제 활용 → 파일명에서 자동 추출
- 사용자가 파일명 변경해도 무관 — 내장 매니페스트와 교차검증

**방식 B — 내장 매니페스트 박제 (보강)**
- 빌드 시 `payload/license.dat` (서명된 JSON: `{ serial, issuedAt, signature }`)
- 본사 공개키로 서명 검증 → 변조 차단

→ **방식 A + B 동시 박제** (파일명 우선, 매니페스트 fallback)

### 1.1 사용자 입력 0건 봉합 박제

```iss
[Setup]

  Description: "히트판 ERP 자동 실행"; \
  Flags: shellexec postinstall nowait
```

→ 사용자 액션 = ① 다운로드 폴더에서 더블클릭 ② UAC "예" 클릭 → 끝

### 5.1 결재 → 다운로드 → 원클릭 흐름 박제

```
[랜딩] 결제 완료
   ↓
[백오피스] 시리얼 발급 + EXE 빌드 트리거
   ↓ /api/install/build-exe (시리얼 박제 EXE 생성)
[랜딩 /download] 1회용 토큰 다운로드 링크 전송
   ↓ (이메일 + 화면 안내)
[고객 PC] HitPanSetup_HP-2606-XXXX-XX.exe 다운로드
   ↓ 더블클릭 (사용자 액션 1회)
[UAC] "예" 클릭 (사용자 액션 2회 = 끝)
   ↓
[Inno Setup] 파일명에서 시리얼 자동 추출 → 13단계 자동 실행
   ↓
[바탕화면 바로가기 자동 생성] 🆕 사장님 결재
   ↓ HitPan_ERP.lnk → https://{고객사}.hitpan.kr/login (히트판 ICO)
[브라우저 자동 오픈] https://{고객사}.hitpan.kr/login
   ↓ (1회용 첫 로그인 토큰 자동 박제)
[ERP 첫 로그인 화면] 환영합니다, 사장님
   ↓ 로그인 1회 입력
[계정관리 > 회사정보] 🆕 사등 사진 자동 박제
   ↓ 랜딩에서 업로드한 사업자등록증 OCR 결과 자동 채움
[설정 > 구독결재관리] 🆕 자동갱신 박제
   ↓ 토스 빌링키 기반 매월 자동 결제
```

### 5.2 사장님 추가 결재 박제 (2026-06-01 강화)

#### 🆕 #1 바탕화면 바로가기 자동 생성
- Inno Setup `[Icons]` 섹션 박제
- 클릭 시 → `https://{고객사}.hitpan.kr/login` (시리얼 박제된 도메인)
- 히트판 ICO + 한글 표기 "히트판 ERP"

```iss
[Icons]
Name: "{commondesktop}\히트판 ERP"; \
  Filename: "https://{code:GetTenantDomain}.hitpan.kr/login"; \
  IconFilename: "{app}\Hitpan.ico"; \
  Comment: "히트판 ERP 첫 로그인 화면으로 이동"
```

#### 🆕 #2 사업자등록증 사진 → 계정관리 회사정보 자동 박제
- 랜딩 가입 시 업로드한 사업자등록증 OCR 결과를 `/api/install/complete` 응답에 박제
- 응답 페이로드:
  ```json
  {
    "tenant_id": "...",
    "biz_license_image_url": "https://hitpan.kr/storage/biz/{sha256}.jpg",
    "ocr_extracted": {
      "company_name": "...",
      "biz_no": "...",
      "ceo_name": "...",
      "address": "...",
      "business_type": "...",
      "business_item": "..."
    }
  }
  ```
- ERP 첫 부트 시 `tenant_profile` 테이블 자동 INSERT → **계정관리 > 회사정보**에 박제
- 사용자는 다시 입력할 필요 없음 (사장님 헌법 #25 "쉽게" 정합)
- 사등 이미지 = 본사 백오피스 zero-retention 정합 (검증 즉시 폐기 또는 ERP 로컬로만 이관, 헌법 #18·#22)

#### 🆕 #3 구독결제 자동갱신
- 랜딩 결제 단계에서 토스페이먼츠 **빌링키 발급** + 자동갱신 동의 박제
- 빌링키는 본사 백오피스 `subscriptions` 테이블에 박제 (헌법 #22 — 카드번호 평문 절대 미보관, 토스 보관)
- 매월 결제일 = 가입일 기준 (예: 6월 1일 가입 → 매월 1일 자동 결제)
- 결제 실패 시:
  - 7일 유예 (헌법 #25 "쉽게" 정합 — 고객 불편 최소)
  - 이메일·SMS 3회 안내 (D-1, D+1, D+3)
  - 7일 후 자동 일시정지 (cloudflared 비활성 → ERP 접속 차단)
  - 결제 갱신 즉시 자동 복구
- **빌링키 발급 흐름**:
  ```
  랜딩 /payment → 토스 SDK 결제창 → 빌링키 발급 → 본사 저장 → 첫 결제 즉시 진행
  ```
- 박제 위치:
  - 백오피스: 결제·환불 화면 (`/admin/billing`) — 빌링키 상태·다음 결제일·자동갱신 ON/OFF
  - ERP: **설정 > 구독결제관리** (`/settings/subscription-billing`) — 사장님 직접 결제수단 변경·해지 가능
