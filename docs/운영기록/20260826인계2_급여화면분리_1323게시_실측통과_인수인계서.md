### 🟢 "내 급여만" 은 서버가 이미 막고 있었다 (실측)

사장님 추가 지시(*"타인의 급여를 볼수없고, 내 급여만"*)를 **화면이 아니라 서버에서** 확인했다 — 감추는 것은 차단이 아니다.

```
// PayrollController.ResolveScopeAsync
if (await CanSeeOthersAsync()) return (true, requested);   // 권한자 → 전 직원
var me = CurrentEmployeeId();
return (true, me);                                          // 🔴 요청을 무시하고 본인으로 덮는다
```

⇒ 직원이 **주소창에 남의 id 를 넣어도 본인 것으로 덮인다.** 원복한 화면은 그대로 안전하다.

## 6. 🟡 남은 것 — 착수 금지 (사장님 *"지금 하지마 · 메모만 해놔"*)

### 그룹웨어 편집기능 제거

사장님: *"급여등록 버튼 삭제했음 좋겠음. **그룹웨어에선 조회기능만.**"*

🔴 **등록 버튼만 지우면 반쪽이다** — 조사 완료, `_canManage` 로 묶인 편집 진입점이 **4곳**:

| 위치 | 무엇 |
|---|---|
| `PayrollPage.razor:37-42` | **「급여 등록」 단추** |
| `PayrollPage.razor:71-73` | 빈 목록 안내문 *"[급여 등록] 으로 만드세요"* |
| `PayrollPage.razor:128-145` | 행 처리단추 — **수정 · 확정 · 지급완료** |
| `PayrollPage.razor:165~` | 편집 다이얼로그 본체(`OpenEditorAsync`) |

⚠️ **착수 전 여쭐 것** — *"조회기능만"* 의 범위:
- **좁게** = 등록·수정만 제거, 확정·지급완료 존치
- **넓게** = `_canManage` 블록 **전부 제거** (회계 화면에 다 있으므로 **기능 손실 0**)

⇒ **넓게가 유력**(회계에 전부 있고, 사장님 문구도 *"조회기능만"*). 그래도 **묻고 착수**.

⚠️ 착수 시 **게이트 확장 필수** — 현 게이트는 **발송**만 막고 **편집**은 안 막는다.
`OpenEditorAsync`·`급여 등록` 금지 검사 추가 + **대조군**(회계엔 있다).

### ⚠️ 별건 — NCP 디스크

게시 워크플로 경고: *"디스크 여유 **2246MB** — 게시 **2~3회분뿐**. 작9 P0-A(패키지 회전) 적용 권고"*
🔴 **2~3회 더 게시하면 막힌다.** 옛 패키지 회전을 별건으로 잡아야 한다.

### 🟡 미결 이월 — 매입목록↔반품목록 정합성 (1.3.21 반만통과)

사장님 사유: *"**매입목록과 반품목록 정합성이 안맞음**"*. **조사만 했고 착수 안 함**(사장님 지시로 회계급여 우선).

🔴 **필터가 실제로 다르다**(실측):

| 목록 | 필터 |
|---|---|
| 매입목록 `PurchaseService.cs:608` | `is_deleted=0 AND status <> 'canceled'` |
| 반품목록 `PurchaseService.cs:799` | `is_deleted=0` — **상태 필터 없음** |

⇒ **취소된 반품이 반품목록엔 뜨는데 매입목록엔 「반품」이 안 붙는다.**
⚠️ 같은 SQL 안에서 철자도 갈린다 — 608행 `'canceled'`(l1) vs 618행 `'cancelled'`(l2).

🔴 **착수 전 사장님께 증상 확정부터** — 어느 쪽으로 맞출지는 **업무 판단**이다:
- 취소된 반품을 **반품목록에서 빼는 것**이 맞는가
- 취소분도 **이력으로 남기고** 매입목록 표기만 맞추는 것이 맞는가

**추측 착수 금지** — 8/25 에 추측으로 다섯 번 틀린 자리다.

## 8. 게시 절차 (정본 — 다음 세션 그대로 쓸 것)

```
gh workflow run deploy-update.yml --ref main \
  -f version=1.3.NN -f channel=Major -f environment=production -f requiresMigration=false
```

- CI 가 **소스에서 재빌드**한다(SSOT — 로컬 zip 안 쓴다). 약 **8분**.
- `requiresMigration` = 이번 릴리스에 `Migrations/SQL/DB-NN_*.sql` **신규 추가**가 있으면 `true`.
  🔴 **애매하면 true**(false 인데 SQL 이 있으면 워치독이 업데이트를 **강제 중단**한다).
- 채널은 **Major 고정** — 선택지 없음(헌법 #43).
- 검증: `curl https://updates.hitpan.kr/manifest.json` + zip HTTP 확인.
