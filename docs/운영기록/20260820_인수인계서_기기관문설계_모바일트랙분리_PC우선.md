## 2. 이번 세션 사장님 결정 5건

### 2-1. 🟢 영구 차단 목록 = **불필요. 종결**
> 사장님: *"영구차단목록은 **두 개의 인증키로 메인PC에서 제어가 되니** 굳이 필요할까?"*

PM 동의. 폐기 기기가 대기 목록에 다시 뜨는 것은 **정상 동작**이고 대표가 승인 안 하면 못 쓴다.
목록을 따로 만들면 **차단목록 ↔ 폐기상태 진실원이 둘** 되어 어긋나는 날 다툰다. ⇒ **만들지 않는다.**
⚠️ 앞 세션 인수인계서 §3 의 "결재 대기 2건" 중 하나가 여기서 **종결**됐다. 되살리지 마라.

### 2-2. 🟢 기기 관문을 **로그인 앞**으로 옮긴다
> 사장님: *"최초화면에 '인증된 기기가 아닙니다' … **접속기기만 이 화면을 통과하고 로그인**"*

⇒ 설계서: [20260820_기기관문_로그인앞_이동_설계.md](../설계/보안/20260820_기기관문_로그인앞_이동_설계.md)

### 2-3. 🟢 폰의 입구는 **QR 하나**
> 사장님: *"모바일 등록을 위해 **QR을 받고 인증한 기기만 접속**되도록"*

### 2-4. 🟢 **2차 인증은 4자리로 끝** — 인증키 두 번 안 쓴다
> 사장님: *"2차 인증은 **숫자4자리 인증으로 끝**"*

🟢 새로 만들 것 없음 — `DeviceConfirmCode` 가 이미 그것이다(`device_id` 에서 **계산** · DB 컬럼 없음).
🔴 **"3차" 를 얹지 마라.** 사장님이 *"끝"* 이라고 못박은 자리다.

### 2-5. 🔴 **순서 = PC버전부터. 모바일은 나중에 몰아서**
> 사장님: *"**PC버젼부터. 모바일은 나중에 몰아서!!!**"*
