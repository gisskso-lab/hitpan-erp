# 작20260430-5 — 관리자 계정 화면 등록 (P0 보안)

## 🔴 우선순위
P0 (보안 격상)

## 발생 증상
- 사용자 추가 화면에 "관리자 계정 추가는 보안상 데이터베이스에서만 가능합니다" 안내문
- **고객사 대표(사장)는 DB 다룰 줄 모름** → 화면에서 등록 가능해야 함
- 본사가 DB 직접 다루도록 유도하면 헌법 #18 위반 + 본사 책임 분쟁 시 역공 가능 (법무팀장)

## 담당
- 메인: 보안 매니저 + 백엔드 매니저 (직접 처리)
- 검증: CTO + 법무팀장

## 작업 범위
1. 관리자 계정 화면 등록 흐름 설계:
   - 기존 platform_admin이 신규 admin 등록 시 → 2차 인증(OTP/이메일 토큰) 후 등록 허용
   - 또는 최초 1명은 가입 시 자동 admin, 추가는 어드민 패널에서 권한 위임
2. `tenant_admin` / `platform_admin` 권한 정책 검토 (절대원칙 #7: SaaS ↔ ERP 권한 혼용 금지)
3. 사용자 추가 화면에서 "역할 = 관리자" 선택 시 추가 검증 단계 표시
4. DB 직접 INSERT 안내문 제거

## 검증 보고서 양식
- 어드민이 화면에서 신규 admin 추가 → 정상 동작
- 권한 격리 확인: tenant_admin이 platform_admin 못 만드는지
- 보안 감사 로그 기록 (헌법 #18 v3 #G 보안감사로그)
- 고객 시선: 안내문 제거 + 직관적 흐름
