## 2. 🟢 덤으로 측정된 것 2개 — **못 잰 것 목록에서 지운다**

패널이 이제 **소비자가 읽는 자리를 그대로** 본다. 그러니 초록은 **「소비자가 실제로 그 값을 읽을 수 있다」**는 뜻이다.

| 확정 | 근거 |
|---|---|
| 🟢 **`NTS_API_KEY` 가 운영 서버에 있다** | 국세청 칸이 초록. 그 칸은 **env `NTS_API_KEY` 먼저 → 설정** 순서로 본다(`BizNoVerifyController:70` 과 동일) |
| 🟢 **`HITPAN_BOOTSTRAP_TOKEN_KEY` 가 운영 서버에 있다** | 부트스트랩 칸이 초록. 같은 순서(`InstallerBootstrapController:275` 와 동일) |
| 🟢 **백오피스 JWT 실제 키가 있다** | JWT(백오피스) 칸이 초록 · 🟢 그리고 `Program.cs:76` 이 **없으면 기동 중단**이므로 이중 확인 |

🔴 **한계**: 이것은 **「백오피스 프로세스가 그 값을 읽을 수 있다」**까지다. 기능이 끝까지 도는지(국세청 실호출 성공 · 설치 종단)는 **여전히 안 쟀다.**

## 3. 🟢🔴 이게 **B2② 전제를 흔든다** — 다음 차수 판단에 쓰라

[1-V] 는 B2② 를 *「`License:Pepper` 미설정 ⇒ `InstallerBootstrapController:81` throw → `:386` catch → **원클릭 설치 500**」* 으로 판정했다. 설치 경로가 요구하는 자격증명은 그것과 **부트스트랩 서명키**다.

| 설치 경로 요구 | 지금 |
|---|---|
| `License:Pepper` | 🟢 **초록**(10/18 사장님 `99-fix.conf` 로 닿게 됐다) |
| `Bootstrap:TokenKey` / `HITPAN_BOOTSTRAP_TOKEN_KEY` | 🟢 **초록**(오늘 확정) |

⇒ 🟢 **「자격증명이 없어서 설치가 1단계에서 500 난다」는 전제는 더 이상 참이 아닐 수 있다.**
🔴 **「아닐 수 있다」까지만 적는다** — 설치를 **한 번도 돌려 보지 않았다.** 종단 1회는 **사장님 손 7번(별 PC)** 몫이고, 그게 **B2② 를 가르는 유일한 측정**이다.
🔴 **이 줄을 「설치가 된다」로 읽지 마라.** 자격증명이 닿는 것과 설치가 끝나는 것은 다르다 — 그게 이 프로젝트의 「고쳤다 ≠ 갔다」 트랙이다.
