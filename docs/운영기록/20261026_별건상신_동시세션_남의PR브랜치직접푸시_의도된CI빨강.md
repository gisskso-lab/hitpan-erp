### 🔴 왜 별건인가 — 규칙에 **칸이 없다**

`WORKFLOW.md` 불변규칙 **#11**·**§7**(동시 세션)은 **같은 트리를 두 창이 쓸 때**를 다룬다.
🔴 **「남의 PR 브랜치에 얹지 않는다」는 칸이 없다.** 이번에 걸린 자리는 트리가 아니라 **원격 브랜치**다.

| 그대로 두면 | |
|---|---|
| 1 | **결재받은 SHA 와 머지되는 SHA 가 달라진다** ⇒ 사장님이 결재한 것과 다른 것이 머지된다 |
| 2 | **CI 가 다시 돈다** ⇒ 초록을 확인한 판이 초록이 아닌 판으로 바뀐다 |
| 3 | 🔴 **얹은 쪽이 그 PR 의 검증 규율을 모른다** — 이번엔 공개 전 3축 점검·표 렌더 확인을 안 거쳤다 |
| 4 | 오늘 머지 축에서 **두 번** 걸렸다(R-5 머지 대상 불일치 + 이 건) |

## §2 ⓑ push 판 `Scan secrets` — **의도된 빨강이 굳는다**

### 사실

| 실행 | 결과 |
|---|---|
| **pull_request** (PR 게이트) | 🟢 pass |
| **push** (새 브랜치 ⇒ base 없음 ⇒ **전체 이력** 스캔) | 🔴 fail · 미검증 **116** · **검증된 비밀 0** |

그 116 은 `.github/trufflehog-exclude-paths.txt` 가 적어 둔 **진탐**이다 — `installer/install.bat`(전 고객 공통 DB 비번) · `scripts/backup-daily.ps1:7`(하드코딩 폴백).
그 파일 원문: *"제외하면 덮는 것이다 ⇒ 스캔은 계속 빨간 X 로 남는다. **그것이 의도다**."*
🟢 그리고 그 비번은 **2026-10-26 사장님이 「유지」로 결재**하셨다([결재문](20261026_결재_설치마법사_공통DB비번_유지.md)).

### 🔴 무엇이 문제인가 — **빨강 자체가 아니다**

| 위험 | 왜 |
|---|---|
| 🔴 **「늘 빨강이니 무시」로 굳는다** | 새 브랜치를 밀 때마다 반복된다. 사람은 반복되는 빨강을 **안 본다** ⇒ **진짜 빨강이 섞여 들어오는 날 못 잡는다** |
| 거꾸로 | 다음 사람이 「빨강이니 뭔가 잘못됐다」로 읽고 **빨강을 없애려 손댄다**(= 적발을 가린다) |

🔴 이것은 메모리 수칙 **「게이트는 글자가 아니라 동작」**이 깨지는 모양이다. 게이트가 **늘 같은 소리를 내면** 그 게이트는 더 이상 측정기가 아니다.

### 🔵 제안 (결재거리)

| 길 | 내용 | 대가 |
|---|---|---|
| **길①** (권장) | **push 판 스캔의 기대값을 「알려진 N 건」으로 고정한다** — 그 N 을 넘으면 빨강, 같으면 초록. **새로 들어온 1건이 즉시 보인다** | 숫자 하나를 어디에 둘지 설계 필요 · 🔴 **N 을 세지 않고 적으면 오늘 내가 「161 은 전부 DB 게이트」로 틀린 것과 같은 사고** |
| 길② | push 판 스캔을 **PR 판만 남기고 끈다** | 🔴 PR 을 안 거치는 직접 푸시가 **안 잡힌다** |
| 길③ | 제외목록에 두 경로 추가 | 🔴 **불허** — 그 파일에 훗날 진짜 키가 들어가도 못 잡는다(사장님 결재는 「비번 유지」이고 「적발 가리기」가 아니다) |
| 길④ | 그대로 둔다 | 🔴 위 「굳는다」 위험 수용 |
