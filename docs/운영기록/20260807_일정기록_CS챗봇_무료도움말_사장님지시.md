## 0. 사장님 지시 원문 (가공 없음)

> **"cs챗봇구축은 AI API연결을 안하더라도 무료로 히트판erp 화면수정을 하며
> 나온 모든 자료를 수집해서 히트판의 기본적 기능에 대한 챗봇문의,
> 자연어를 통한 히트판의 도움말이 되는 역할까지는 해줘야 해.
> 그런 의미에서 AI수석과 cs팀장이 매우 중요해."**

---

## 1. 이 지시가 정한 것 — 세 가지

| # | 사장님이 못박은 것 | 뜻 |
|---|---|---|
| 1 | **API 연결 없이도 돌아야 한다** | 유료 API 가 전제가 아니다. **없어도 최소 기능은 성립** |
| 2 | **화면 수정하며 나온 모든 자료를 수집** | 별도로 지식을 만들지 않는다. **작업하며 저절로 쌓인다** |
| 3 | **자연어 도움말 역할까지** | 고객이 *"거래처 어디서 등록해요?"* 라고 물으면 답한다 |

### 1-1. 왜 "API 없이"가 중요한가 (PM 해석)

| 이유 | 내용 |
|---|---|
| **비용** | 고객 5~10곳 베타에 API 요금이 나가면 남는 게 없다 |
| **의존** | 외부 서비스가 죽으면 도움말도 죽는다. 히트판은 **고객 PC 에서 도는 것**이 원칙(헌법 #30) |
| **속도** | 지금 당장 만들 수 있다. API 계약·키 관리·비용 정책을 기다리지 않아도 된다 |

⇒ **API 는 나중에 얹는 것**이지, 없으면 아무것도 못 하는 구조로 만들면 안 된다.

## 3. 🔴 사장님 헌법 — 지식의 출처 (2026-06-19 확정)

> **"챗봇 지식은 히트판을 만든 사람이 직접 정의한다. 외부에서 긁어오지 않는다."**

이번 지시는 그 헌법을 **실행 방법까지** 정한 것이다:

> *"히트판erp 화면수정을 하며 나온 모든 자료를 수집해서"*

**화면을 고치는 사람이 곧 지식을 만드는 사람이다.** 별도 작업이 아니다.

[ERP 화면별 수정 일정](20260807_일정기록_ERP화면별_수정보완_9대영역_사장님지시.md) 에서

> *"챗봇 학습 자료로도 화면 단위가 깔끔하다"*

**우연이 아니라 같은 방향이었다.**

## 5. 착수 전 정할 것 (AI수석 · CS팀장)

| # | 항목 | 담당 |
|---|---|---|
| 1 | **API 없이 자연어를 어떻게 받는가** — 방식 결정 | AI수석 |
| 2 | **어디까지 답하고 어디서 사람에게 넘기나** | CS팀장 |
| 3 | 챗봇을 **어디에 붙이나** (ERP 안 / 랜딩 / 백오피스) | 공동 |
| 4 | 화면 수정 기록에서 **무엇을 어떤 형태로 뽑나** | 공동 |
| 5 | 지식을 **어디에 저장하나** (고객 PC 로컬 / 본사) | 🔴 헌법 #18·#22 |
| 6 | **모르는 질문**에 어떻게 답하나 | CS팀장 |

### 5-1. 1번이 이 작업의 핵심 난제다

*"자연어"* 와 *"API 없이"* 는 쉽게 충돌한다.

**PM 은 방식을 정하지 않는다** — AI수석 영역이다. 다만 판단 기준만 남긴다:
- 고객이 **정확한 단어를 몰라도** 찾아지는가 (*"거래처"* 를 *"업체"* 라고 쳐도)
- 고객 PC 에서 **추가 설치 없이** 도는가
- 지식이 늘어날 때 **다시 만들지 않아도** 되는가

### 5-2. 6번이 신뢰를 결정한다 (CS팀장 영역)

**모르는 것을 아는 척하면 챗봇 전체를 못 믿게 된다.**
*"제가 답할 수 있는 것은 여기까지입니다"* 를 어떻게 말할지가 중요하다.

⚠️ 8/07 에 우리가 직접 겪은 것 — 로그인 401 이 **모든 사유를 "비밀번호가 틀립니다"로 덮어**
사장님도 원인을 못 찾으셨다. **챗봇이 같은 실수를 하면 안 된다.**
