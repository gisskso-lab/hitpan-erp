## 1. 왜 지금 하는가 (실측 근거 · 헌법 #32)

설7 실측 — 확정 엔드포인트 **5개 중 4개에 개별 권한 검사가 없다.**

| 엔드포인트 | 무엇 | 개별 권한 |
|---|---|---|
| `POST /api/sales/deliveries/{id}/confirm` | 거래명세서 확정 | **없음** |
| `POST /api/sales/deliveries/bulk-confirm` | 거래명세서 **일괄** 확정 | **없음** |
| `POST /api/purchase/returns/{id}/confirm` | 매입반품 확정 | **없음** |
| `POST /api/purchase/receipts/{id}/confirm` | 매입 확정 | **없음** |
| `POST /api/sales/returns/{id}/confirm` | 판매반품 확정 | `Authorize(SalesManager)` |

### 1-1. 클래스 정책은 권한이 아니다

`Program.cs:335-343`:

```
SalesOnly     → system_admin, sales_manager, ★sales_user★, TenantAdmin, tenant_admin
SalesManager  → system_admin, sales_manager,               TenantAdmin, tenant_admin
PurchaseOnly  → system_admin, purchase_manager,            TenantAdmin, tenant_admin
```

**`sales_user` 가 `SalesOnly` 에는 있고 `SalesManager` 에는 없다.**
⇒ **`sales_user` 는 지금 거래명세서를 확정할 수 있고 판매반품만 못 한다.** 같은 확정인데 갈린다.

확정은 헌법 #6 에 따라 **원장이 움직이는 시점**이다.
