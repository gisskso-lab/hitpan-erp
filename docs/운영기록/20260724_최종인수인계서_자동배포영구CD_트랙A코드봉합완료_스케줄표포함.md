## 🔴🔴★ 최상단 결재벽 (사장님 못박음 2026-07-23밤 — 다음세션 클로드 필독)

**NCP sudo(인프라 조작)는 반드시 사장님 사전 결재 후에만 실행. 헌법 #29 절대.**
- PM은 PowerShell 로 NCP SSH 붙을 **능력은 됨**(deploy-ncp 키). 그러나 **능력 ≠ 권한.**
- "SSH 되니 결재 없이 NCP 실행" = 전임 PM(닥터스트레인지) 해고사고 재발. 절대 금지.
- NCP = 랜딩·백오피스·업뎃피드 도는 **운영 서버**(헌법 #39 직접수술 위험).
- 결재 후 실행 방식 2택: **A**(PM PowerShell SSH 직접) / **B**(PM 대본 → 사장님 복붙, 더 안전).
- dispatch(#4)=PM 트리거 → **사장님 GitHub 승인 버튼**. 백지실측(#5)=**사장님 Sandbox**.

## 0. 한 줄 상태

**사장님 "빌드→NCP 완전자동화(영구CD)" 지시 → SOP 완주(전수조사→회의→PRD→CTO결재→코드봉합→검증) → 트랙A NCP무관분 코드봉합 완료. 남은 건 사장님 NCP 결재 + 활성화 → 백지 UPDATE 사상 첫통과.**

근본문제(사장님 못박음): **"UPDATE 실측 0회 통과"** — 진범 절반 = 게시가 손작업(CI→NCP 전송 다리 부재). 자동화가 영구 제거.

## 3. 핵심 실측·판정 (다음세션 오판 방지)

- ✅ **CI 초록**: DDL스모크(MariaDB컨테이너)·Build(errors0+warnings0)·TruffleHog 전부 통과.
- ✅ **G-D 게이트 소멸**: `curl -I updates.hitpan.kr/manifest.json` → no-cache 이미 걸림. nginx 작업 불필요.
- ✅ **P0-검사 판정=(c)완전무관**: 치명결함 CF-1·CF-2(licenses/watchdog clean DDL 누락·비어있음)는 **백지 UPDATE 실측 안 막음.** 자동업뎃 경로는 HTTP피드+local_update_*+schema_migrations만 씀(clean DDL에 다 있음). **트랙A 바로 진행 가능.**
- ⭐ **webroot 실서빙 = `/var/www/updates`** (`.hitpan.kr` 아님. 작4 line8 오확인을 진실원+CTO nginx문서가 뒤집음). G-C 정정 대상.
- ⭐ **실측하려면 새버전 필수**: 현 SSOT 1.2.40(오늘 올림). 같은버전 감지0.

### 🔴 백지 실측 판독 오염 방지 (두더지잡기 재발차단)
1. "자동업뎃 됐는데 워치독 통신 안됨"을 실패로 **오판 금지.** 성패 판정 = `local_update_apply_status` 행 + `/health` 버전 + 교체된 HitPan.API.exe FileVersion.
2. MetaPing 400(별건)은 자동업뎃 성패 지표 **아님.** 본사 대시보드 버전 안떠도 "실패" 결론 금지.
3. 실측 중 로컬 `/watchdog/*` **호출 말 것**(CF로 500/401=정상 증상).
4. 1.2.40에 **새 마이그(DB-*.sql) 싣지 말 것**(교차검증 게이트 정상차단, 고리5 미구현).
