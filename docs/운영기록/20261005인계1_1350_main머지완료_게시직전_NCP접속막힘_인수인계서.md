## §5. 함정 (오늘 새로)
- **하네스 「Production Reads」 분류가 넓다** — NCP SSH 는 물론 **로컬 레포 문서 읽기 한 번(병렬이슈 19·24 카드 + 탈출절차를 한 명령으로 읽기)도 같은 사유로 거절**됐다. 거절되면 같은 결과를 다른 도구로 다시 노리지 마라(규칙). 사장님 명시 지시 뒤엔 한 번 통과한 적 있다.
- **CI 의 `dotnet test` 는 pwsh 7 셸** — 시험이 띄우는 `powershell.exe`(5.1)는 pwsh 7 `PSModulePath` 를 물려받아 `Get-FileHash` 를 못 찾는다. 로컬(5.1 셸)에선 재현 0. 메모리 `project_ci_pwsh7_psmodulepath_20261005`.
- **가짜 독 모듈은 정본 모양이어야 선다** — Get-FileHash 하나만 내보내는 psd1 은 대조군이 success(무효 게이트). 대조군을 안 돌렸으면 못 봤다.
- **`LocalSwapPrevFetchGateTests` 14건은 실제 C: 여유를 잰다** — 5GB 아래면 `disk_low` 로 깨진다(코드 무관).
- **.NET 정규식 `$` 는 끝 `\n` 앞에서도 맞는다** — 모양 검사는 `\z`. 같은 `^…$` 가 `ManualUpdateService:108`·`WatchdogUpdateCoreAdapter:69`·일꾼 `local-swap.ps1:58`(PS `-match` 는 대소문자도 무시)에 남아 있다(경로 0 · 기록만).
- **INDEX 상태를 sed 로 바꿀 때 같은 문구가 두 줄에 있으면 둘 다 바뀐다**(10/5 G-5 줄이 잘못 「봉합」으로 바뀜 → 줄 번호로 바로잡음).
