**삭제 조건 — 글자 말고 동작으로.** 한 디렉터리에 대해 넷이 전부 참일 때만 지운다.
1. `git -C <d> rev-parse --git-dir` 가 **그 디렉터리 하위**를 가리킨다(부모를 가리키면 고아 ⇒ git 판정 금지, 파일로 본다)
2. `git -C <d> status --porcelain` — **`-uno` 금지** — 출력 **0줄**
3. `git branch -r --contains $(git -C <d> rev-parse HEAD)` 출력 **1줄 이상**
4. 1개 지울 때마다 `df -h /c` 를 다시 찍어 **회수량을 실측 기록**(추정 금지)
위험 12개(origin 없음 6 + 미커밋 6)는 **보존**. 안 **다**(푸시 후 삭제)는 이번 차수 제외 — 비밀 스캔 설계가 선행인데 0.5일에 안 들어간다.
