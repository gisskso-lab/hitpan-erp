## §5. 함정 — 다음 세션이 밟을 지뢰
- **스쿼시 머지 후 파일 대조 완료**: `origin/main:2e57ad82` 에 LegacyMdbMapping·MdbReconciliationService·게이트·DB-118·도구·결1 실재, clean DDL `uq_payments_source` · 빌더 조립 · ForLog 8 · `'purchase'` 확인.
- **CodeQL 은 check-run 이 둘이다** — 「CodeQL Analyze」 success 만 보면 「CodeQL」(github-advanced-security, 새 경고 집계) failure 를 놓친다. 머지 전 `code-scanning/alerts?ref=refs/pull/N/merge` 로 severity 를 센다(병렬이슈 14).
- **perl 치환 문자열에 `${1}` 을 쓰면 글자로 들어간다**(`$to` 는 코드가 아니라 문자열) — 그 사고로 로그 템플릿이 통째로 사라진 채 빌드 0/0 이 났다. **정확 문자열 치환 + 결과 grep** 으로만. `git checkout -- 파일` 은 **인덱스**에서 복원한다 — HEAD 로 되돌리려면 `git restore --source=HEAD --staged --worktree`. git 이 checkout 하며 문서를 CRLF 로 바꾸므로 줄 패턴의 `$` 앵커는 줄끝을 뗀 뒤 비교한다.
- **재이관은 덮어쓰기 후**: 봉합 전 코드로 이관된 DB(예: 사장님 PC 실물) 위에 병합 재이관하면 옛 sales/purchase 행이 **다른 표에 남는다**. 작22 두 모드가 그 자리 — 그 전엔 실물 DB 에 돌리지 마라(#39 도 걸린다).
- **비번은 코드 주석에서 셸 변수로만**: `grep -m1 "사장님 MDB(비번 "` → env. 어떤 문서·로그에도 값 금지. 줄번호로 뽑지 마라(요약 줄이 54, 비번 줄이 55 — 한 줄 빗나갔었다).
- **perl -0pi 로 UTF-8 파일에 decoded 문자열을 끼우면 파일 전체 이중 인코딩** — rows 파일을 `<:raw` 로 읽어 바이트끼리. 백틱·따옴표 많은 perl 은 heredoc 도 깨진다 → **.pl 을 Write 로 쓰고 실행**.
- **게이트 기대값을 작지서에서 베끼면 작지서 오기를 지킨다**(W5 사고). 기대값은 그 값을 읽는 화면·식에서.
- **`dotnet test --no-build` 의 빈 출력**: 테스트 DLL 이 stale 이면 grep 이 아무것도 안 잡는다 — 초록으로 오해하지 마라.
- 15잡 병렬은 conn 발급이 24초에 걸쳐 늦어질 수 있다(병렬이슈 12) — 잡을 더 늘리면 `MaximumPoolSize=20`·`ConnectionTimeout=60` 부터.
