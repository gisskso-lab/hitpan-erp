## §5 🔴 내가 낸 일 5건

1. 🔴 **본체 게이트를 주석 한 줄에 열어 두고 「닫았다」고 적었다.** G-W12 쪽에만 주석 걷기를 걸고 **G-W10-8(본체)에는 안 걸었다.** 더 나쁜 것은 그 사실을 모른 채 코드 주석과 결재 문서에 「예외 0건으로 길을 닫았다」고 쓴 것이다. 🔴 **이 트랙에서 같은 함정을 다섯 번째** 밟았고, **그 경고를 내가 바로 옆 게이트에 직접 적어 뒀다.**
2. 🔴 **내 음성 대조군이 내 게이트를 뚫었다(NC-9).** 마이그를 **한 바퀴만** 돌리고 「새 마이그는 한 건도 못 들어온다」고 적었는데 초록이었다 — 새 칸은 출하본에 아직 없으니 1회차가 성공한다. 두 바퀴로 고쳤고, **그 봉합이 `DB-35` 를 새로 찾아냈다.**
3. 🔴 **통제 마이그를 과녁 뒤에 심어 놓고 「바로 앞에 선다」고 주석까지 적었다.** 러너 정렬은 같은 번호에서 **접미사 없는 쪽이 먼저**다. 실측이 잡았다(그 판은 빨강이었다). **주석은 코드가 아니다** — 내가 정렬 규칙을 글로 적고 그 글을 사실로 믿었다.
4. 🔴 **음성 대조군의 `git checkout` 이 커밋 안 한 봉합을 되돌렸다.** NC-8·NC-10 복원이 두 바퀴 봉합·`DB-35`·사전 시드를 **전부 지웠다.** `grep -c` 로 세어 알아내고 다시 넣었다. ⇒ 교훈: **대조군 도중에 생긴 봉합도 먼저 커밋한다.** 2차(C-1~C-7)에서는 **커밋 뒤에** 대조군을 돌렸다.
5. 🔴 **운영기록 INDEX 의 결3 줄을 덮어썼다.** 되돌리고(차이 0) 표 머리만 앵커로 잡아 다시 넣었다. 🟢 **작2 때 적어 둔 「손댄 뒤 `numstat` 으로 삭제 0 확인」이 이번엔 잡았다**(5건 전부 1/0).

🔴 1·3 은 같은 뿌리다 — **내가 적은 글을 측정으로 착각했다.** 2·4 는 **「돌려 보기 전에 적지 않는다」**를 한 바퀴 더 돌려야 했던 것이다.
