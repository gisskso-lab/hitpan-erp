## 0. 🔴 일정을 가르는 두 가지 원칙

### 0-1. 축이 먼저, 그 위에 얹는 것이 나중

> 축 = **메뉴 통합(17→10) + 결재조회 일원화**

결재선·직권·전결은 **축을 세우는 수단**이다. 다만 **수단이 없으면 축이 못 선다** —
1번에 결재를 모으는 만큼 결재선 구멍이 **더 아파지기** 때문이다(상무 판정).

### 0-2. 🔴 두 번 만지지 않는다

```
작9 이전에는 ERP 7종이 살아 있다
   ⇒ 지금 결재조회 필터를 만들면 견적서·발주서가 섞인다
   ⇒ 작9 후 필터를 다시 고쳐야 한다  ← 두 번 만짐
```

⇒ **작11 → 작9 → 결재조회 통합** 순서를 지킨다.
