## 1. 배경

결재 #8 cold storage 이전 채택 시 **저장 위치** 결정 필요. 헌법 #22 데이터 최소주의 + #18 v3 본사 차단 정신 적용.

## 2. 선택지

### A안: 사외 AWS S3 Glacier (암호화)
- 장점: 저장 비용 저렴 ($0.004/GB/월). 99.999999999% 내구성
- 단점: 클라우드 = **본사 접근 가능** → 헌법 #22 위반 위험. 국외 이전 통지 의무

### B안: 사외 NAVER Cloud Object Storage
- 장점: 국내 저장. 개인정보보호법 국외 이전 회피
- 단점: 본사 클라우드 → 헌법 #22 본사 보유 위반 동일

### C안: 고객사 내부 NAS (PM 추천)
- 장점: 헌법 #22 완벽 준수 (사장님 데이터는 사장님 것). 본사 접근 0
- 단점: 고객사 NAS 보유 의무. 베타 체험단 20곳 중 NAS 미보유 고객 다수 예상

### D안: 외부 감사인 cold storage (제3자 보관)
- 장점: 본사·고객사 모두 미보유. 침해사고 시 제3자 증거 능력 최강
- 단점: 비용 + 외부 감사인 계약 (회계법인 또는 보안전문업체)

## 3. 어벤져스 리뷰

| 매니저 | 의견 | 추천 |

| 법무팀장 | 침해사고 시 제3자 증거 능력은 D안 압도. 외부 감사인 계약 필요 | **D안** |
