## 0. 디자인 시스템

### 0.1 색상 (글래스모피즘 + 보라 그라데이션)
- Primary  : `#6366F1` (Indigo 500)
- Accent   : `#8B5CF6` (Violet 500)
- Gradient : `linear-gradient(135deg, #6366F1 0%, #8B5CF6 100%)`
- Background : `#FAFAFB` / 카드 `rgba(255,255,255,0.7)` + `backdrop-filter: blur(20px)`
- Text     : `#0F172A` (Slate 900) / Sub `#64748B` (Slate 500)
- Success  : `#10B981` / Warning `#F59E0B` / Danger `#EF4444`

### 0.2 폰트
- 본문 : **Pretendard Variable** (한국어 최적 + 가독성 1위)
- 코드 : JetBrains Mono
- 사이즈 : 12 / 14 / 16(본문) / 20 / 24 / 32 / 48(히어로) / 64(랜딩 카피)

### 0.3 그리드 & 반응형
- PC      : max-width 1280px, 12 columns, gutter 24
- Tablet  : 768~1023px, 8 columns
- Mobile  : ~767px, 4 columns

### 0.4 마이크로 인터랙션 영역
- 버튼 hover : translateY(-2px) + box-shadow 강화 (200ms)
- 카드 hover : scale(1.02) + 그라데이션 boundary glow
- 스크롤    : Intersection Observer로 fade-up 280ms
- CTA      : Primary 버튼 펄스 애니메이션 (2s 주기)

### 0.5 히트판 정신 (CLAUDE.md)
> "이 화면, 처음 보는 사람이 혼자 쓸 수 있냐?" — 모든 화면의 최종 통과 기준

- 스크롤 없이 첫 화면에서 셀링 포인트 100% 전달
- 모바일에서도 가입까지 3분 이내 완료
- 약관 동의·결제·다운로드 끊김 0
