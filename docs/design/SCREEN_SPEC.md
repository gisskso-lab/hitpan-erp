### 1-3. 공통 UI 원칙

- MudBlazor 컴포넌트 사용
- 히트판 ERP와 동일한 색상 시스템 (Primary: #1976D2)
- 테이블: MudDataGrid, 페이지네이션 기본 20건
- 상태 칩: MudChip (active=green, suspended=orange, terminated=red)
- 금액: 천 단위 콤마 포맷 (₩1,234,567)
- 날짜: yyyy-MM-dd 포맷

```
┌──────────────────────────────────────┐
│                                      │
│         [히트판 백오피스 로고]          │
│                                      │
│  이메일 [________________________]   │
│                                      │
│  비밀번호 [______________________]   │
│                                      │
│         [  로그인  ]                  │
│                                      │
│  ─── 또는 ───                        │
│                                      │

│                                      │
└──────────────────────────────────────┘
```

| 항목 | 내용 |
|------|------|
| 컴포넌트 | MudTextField (email, password), MudButton |

| 로그인 실패 | "이메일 또는 비밀번호가 올바르지 않습니다" (MudAlert, Severity=Error) |
| 성공 | account_type에 따라 자동 분기: platform_admin → /admin/dashboard, reseller_admin → /partner/dashboard |
