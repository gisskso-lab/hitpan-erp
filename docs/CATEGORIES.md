# 문서 분류 규칙 (사장님 확정 2026-07-28)

> **이 문서가 분류의 근거다.** 새 문서를 만들 때 여기서 카테고리를 찾고, 사장님께 저장 위치를 결재받는다.
> 감으로 고르지 않는다 — 아래 판정 순서를 기계적으로 따른다. (헌법 #41)
>
> 근거: 2026-07-28 실제로 635건을 분류하며 부딪힌 판단 지점에서 도출. 추측 아님.

## 0. 문서 = 폴더 (사장님 정의 2026-07-28 — 1:1 고정)

> **"앞으로 이렇게 정의함."** — 문서 종류가 곧 폴더다. 다르게 넣지 않는다.

| 문서 | 폴더 | 누가 쓰나 (작업 루틴) |
|---|---|---|
| **작업지시서** | `운영기록/` | **[1] 사장님 첫 오더를 문서화·명문화한 것** — 설계팀이 작성, PM 결재 |
| **선행검증서** ⭐ | `검증/선행/` | **[1-V] 검증팀장 데이비드 박** — 설계보다 먼저 (08-28 신설) |
| **설계문서** | `설계/{영역}/` | [2] 설계팀장 존 |
| **개발문서** (개발명세서) | `개발/{영역}/` | [3] 개발팀 (PM 지휘) |
| **동시병렬이슈문서** | `검증/병렬이슈/` | [3-V] 보안상무 안철수 |
| **검증문서** (작업리뷰서) | `검증/{영역}/` | [4] 검증팀장 데이비드 박 |

### ⭐ 작업지시서의 정의 (사장님 못박음)

> **작업지시서 = 사장님의 첫 오더를 문서화·명문화시킨 것.**

PM 이나 설계팀이 만들어내는 요구가 아니다. **사장님 오더가 원본**이고, 설계팀은 그것을 실행 가능한
형태로 옮겨 적는다. 그래서 작업지시서에 사장님 오더에 없던 내용이 들어가면 **월권**이다.
오더 범위를 벗어나는 것이 필요하면 **사장님께 다시 여쭙는다** (헌법 #33).

## 0-1. 그 밖의 문서 판정 순서 (위 5종이 아닐 때)

```
① 결재·기록·이력인가?              → 운영기록/  (인수인계·회의록·결재의견·약관)
② 잘못된 걸 찾는 것인가?            → 검증/
③ 어떻게 만들지 정하는 것인가?      → 설계/
④ 어떻게 만들었는지 남기는 것인가?  → 개발/
⑤ 고객이 읽는가?                   → CS/
⑥ 우리 팀의 규범인가?              → 헌법/
```

**둘 이상 걸리면 ①→⑥ 순서에서 먼저 걸리는 쪽.** 그래도 애매하면 **사장님께 여쭙는다** (헌법 #33).

## 4. 저장 시 의무 (헌법 #41)

문서를 만들 때 **한 번에** 다음을 한다:

1. **저장 위치를 사장님께 결재받는다** — 작업 단위로 묶어 1번
   > *"{위치}에 {문서명} 저장하고 진행합니다 — {한줄요약}. 진행할까요?"*
2. **틀을 쓴다** → [`_틀/`](_틀/)
3. **참조식으로 쓴다** — 다른 문서 내용 복사 금지, 주소만
4. **폴더 INDEX 에 한 줄 추가**
5. **대체한 옛 문서에 ⬛흡수 표시** ← 이걸 안 하면 문서가 다시 쌓인다

## 6. 📦 모든 문서는 보관·관리한다 (사장님 지시 2026-07-28)

### 삭제하지 않는다

문서는 **지우지 않는다.** 대체됐거나 폐기된 것도 **상태만 바꿔 남긴다.**

| 상태 | 뜻 | 읽어야 하나 |
|---|---|---|
| 🟢**진실원** | 현재 유효한 최신 | **이것부터 읽는다** |
| 🟡진행중 | 작업 중 | 관련 작업 시 |
| ⬛**흡수됨** | 새 문서가 대체함 (내용은 살아 있음) | 상세가 필요할 때만 |
| 🔴폐기 | 더 이상 유효하지 않음 | **읽지 마라** (근거 추적용으로만 보존) |

> **왜 안 지우나**: 지우면 "왜 그렇게 결정했나"를 추적할 수 없다. 같은 사고가 반복돼도 모른다.
> 실제 사례 — 오늘 7/24 진실원을 참조식으로 바꿀 때 **원본을 지우지 않고 `_원본상세_이력` 로 남겨**
> 하이브리드 정의·게시합의 전문이 보존됐다.

### 대체할 때 하는 일

새 문서가 옛 문서를 대체하면 **같은 작업에서** 다음을 한다:

1. 옛 문서 최상단에 **⬛흡수 표시** + "현재 진실원은 여기" 주소
2. 옛 문서에 **"언제 이걸 열어야 하나"** 안내 (상세가 필요한 경우를 적는다)
3. 폴더 INDEX 🟢진실원 절 갱신
4. 파일명에 `_이력` 등을 붙여도 좋다 (`20260724_…_원본상세_이력.md`)

### 관리 = INDEX 로 한다

| 관리 수단 | 무엇 |
|---|---|
| 폴더 `INDEX.md` | 최근 문서 + 🟢진실원 명시 |
| `INDEX_ALL.md` | 전체 목록 (큰 폴더만) — 옛 문서 찾을 때 |
| `docs/INDEX.md` | MASTER — 폴더 지도 |
| 담당자 | [`POLICY_폴더담당.md`](POLICY_폴더담당.md) — 그 폴더 문서를 누가 책임지나 |

**INDEX 에 없는 문서 = 관리되지 않는 문서**다. 만들면 반드시 등재한다.
