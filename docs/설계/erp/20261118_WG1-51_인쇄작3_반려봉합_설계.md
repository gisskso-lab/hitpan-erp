### §1-3 판독 — 「된다 / 안 된다」

- **대조군**: 같은 차림·같은 판독을 main `19518b03` 위에서 먼저 돌린다(갈래 Z). 기대 = ②③ 빨강. **main 에서 초록이 나온 항목은 그 측정이 대표의 실패를 못 잡는다는 뜻** → 그 항목은 「고침 0」 으로 넘기지 않고 멈춰 PM 보고 · 측정 재설계(진단도 실측 전엔 가설).
- ① 의 대조군 주의: 로고를 제대로 올린 main 은 **초록일 수 있다**(작2 [1-V] §1 — 판정 코드는 돌고 재료가 없었다). 그래서 ① 은 두 경우를 잰다 — (가) 로고 있음 + 켬 → 찍힘 ~~(나) 로고 없음 + 켬 → 대표가 켜는 자리·미리보기 자리에서 「로고가 없어 안 찍힌다」 를 본다. (가) 가 main 에서 초록이면 대표 실패 자리는 (나)이고, (나) 의 「된다」 정의는 **대표 확인 전 확정하지 않는다**(Q1).~~
- 정정(대표 11/18 Q1) — ① 은 두 경우를 **성격이 다른 두 기준**으로 나눈다.
  - **(가) 로고 있음 + 켬 = 반려 대상.** 대표가 본 실패는 「설정칸만 생기고 반영 0」. 대조군 규칙 그대로 — main 빨강 + 고친 판 초록 짝일 때만 초록. **(가) 가 main 에서 초록이면** 차림이 대표 화면 조건(설정 미리보기 길 · 전표 미리보기 길 · 로고를 올린 길)을 못 만든 것 → 「고침 0」 으로 넘기지 않고 멈춰 PM 보고 · 측정 재설계(대조군 규칙과 같음).
  - **(나) 로고 없음 + 켬 = 회귀 방지 기준 · 고침 대상 아님.** 대표 정의 = 「아무것도 안 보임 · 오류 0」. main 이 이미 「조용히 빠짐」(`PdfRenderService.cs:2435` → `:2605` · 로그 한 줄 · 화면 말 0)이면 **main 초록이 정답**이다. 그래서 (나) 는 짝 판정에 넣지 않고 「main 초록 · 고친 판 초록 · 둘 다 아무것도 안 보임」 을 따로 적는다 — 「main 초록 = 고친 것으로 치지 않음」 규칙과 부딪히지 않는다((나) 는 고친 것으로 세지 않고, 고친 판이 그 모양을 깨지 않았는지만 본다). main 에서 (나) 가 빨강(무엇이 보이거나 오류)이면 그때만 고침 대상으로 올리고 PM 보고.
