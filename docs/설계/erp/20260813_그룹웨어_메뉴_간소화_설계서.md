## 2. 병합안 — 22개 → 13개

### 2-1. 사원관리에 흡수 (사장님 지시 4)

```
[전] 사원관리 · HR직원현황 · 직급관리 · 부서관리 · 연차부여     5개
[후] 사원관리 (탭: 사원 / 연차)                              1개
```

**사장님 그림 그대로:**

```
사원 등록:  이름[홍길동]  부서[영업부 ▾ 또는 직접입력]  직급[과장 ▾ 또는 직접입력]
                                  ↓ 없는 이름이면
                          부서·직급이 자동으로 생긴다
```

🔴 **표는 그대로 둔다**(사장님 지시 5). `departments`·`positions` 는 살아 있다 —
**메신저 부서방**이 `dept_id` 로 묶이고, **결재선**이 직급으로 짜인다.
바뀌는 것은 **채우는 방법**이다:

| | 전 | 후 |
|---|---|---|
| 표 | `departments` · `positions` | **그대로** |
| 채우는 법 | 관리 메뉴에서 미리 만듦 | **사원 등록하며 자동 생성** |
| 메뉴 | 2개 | **0개** |

- **HR직원현황** → 사원관리 위에 요약카드 4개 + 검색으로 흡수(조회 전용이고 같은 API)
- **연차부여** → 사원관리 **"연차" 탭**. 🔴 화면을 통째로 옮긴다 —
  근속 계산·경고·조정사유·부여이력이 있는 373행짜리다. **줄여서 흡수하면 기능이 죽는다**

### 2-2. 휴가·연차 (사장님 지시 4번 항목)

```
[전] 휴가·연차 · 연차신청 · 휴가현황 · 휴가달력     4개
[후] 휴가·연차 (탭: 내 연차 / 전사 현황)          1개
```

넷이 **같은 API 하나**를 읽는다. 서버가 이미 `employeeId` 로 범위를 가르므로
한 화면에서 **고객사가 설정한 권한대로** 갈린다(사장님 지시 7 — *"고객이 설정한데로 계층분리"*).

- **휴가달력** → 없앤다. 대시보드 `UnifiedCalendar` 가 **이미 연차축(🔵)을 그린다**

### 2-3. 근태

```
[전] 근태관리 · 근태달력     2개
[후] 근태관리               1개
```

컬럼 7개가 글자까지 같고 **기본 날짜값 하나**만 다르다. 기간 버튼으로 흡수.

### 2-4. 경비

```
[전] 경비신청 · 경비현황     2개
[후] 경비                   1개
```

같은 API·같은 6컬럼 표. 신청 화면에 **건수·금액 카드 4개**만 얹으면 끝(합쳐도 ~130행).

### 2-5. 전자근로계약서

```
[전] 전자근로계약서 · 전자서명이력     2개
[후] 전자근로계약서 (탭: 계약서 / 서명이력)   1개
```

🔴 사장님은 *"숨겨도 될듯"* 하셨으나 **탭으로 남기기를 권한다.**
**서명 무효화가 거기서만 되고**, 되돌릴 수 없는 동작이라 흔적이 남아야 한다.
메뉴에서는 사라지므로 사장님 목적(메뉴 줄이기)은 달성된다.

### 2-6. 그대로 두는 것

| 화면 | 이유 |
|---|---|
| 결재 3개(대기·보낸·완료) | **대기만 승인 액션**이 있고 대상 집합이 서로 배타적 |
| 초과근무 · 휴직 · 급여 · 업무보고서 · 메신저 | 겹치는 화면 없음 |

## 7. 구현 결과 (2026-08-13 실측) — 설계와 달라진 곳

> 🔴 **설계서를 실측이 두 군데 정정했다.** 구현 전 사장님 결재를 받아 반영했다.

### 7-1. 정정 ① — 직급관리는 그룹웨어 것이 아니었다

설계 §2-1 은 사원관리가 **5개**를 흡수한다고 했으나, 실측하니 **직급 관리는
`/settings/positions`(설정 그룹)** 이고 시험 `직급화면은_메뉴에_한_곳만_있다` 가
그것이 사이드바에 **있을 것**을 단언하고 있었다(8/13 작성).

⇒ **사장님 결재: 설정에 그대로 둔다.** 그룹웨어에서 빼는 게 아니라 애초에 거기 없었다.

### 7-2. 정정 ② — 연차부여는 옮기지 않았다

`/employees`(사원관리)는 `Pages/Settings/EmployeePage.razor` 다. 연차부여 373행을
탭으로 넣으면 **설정 화면을 수술**하게 되고, 이번 작업 중 회귀 위험이 가장 크다.

⇒ **사장님 결재: 연차부여는 `/hr/annual-leave` 로 독립 유지.** 지킬것 #3(통째로 옮긴다)이
   자동 충족된다 — 아예 손대지 않았으므로.

### 7-3. 숫자 정정 — 22→13 이 아니라 **24→18**

설계서의 "22개" 는 그룹웨어 그룹에 들어와 있는 **설정 계열 2개**(결재 설정·직급 관리)를
세지 않은 값이다. 실제 사이드바 기준:

| | 전 | 후 |
|---|---|---|
| 그룹웨어 그룹 전체 | 24 | **18** |
| 그중 설정 계열 | 2 | 2 (안 건드림) |
| **그룹웨어 소관** | **22** | **16** |

13 이 아니라 16 인 이유는 위 정정 ①②(직급관리·연차부여 2개) 때문이다.
**합치기로 내린 6개는 설계서 그대로 전부 이행했다.**
