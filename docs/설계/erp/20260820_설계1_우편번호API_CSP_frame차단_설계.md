# [설계 1] 우편번호 찾기가 안 열린다 — CSP `frame-src` 누락

> **상태**: 🟡 설계 (코드 무접촉) · **결재 대기**: PM → 보안매니저 → CTO → 사장님
> **작성**: 2026-08-20 설계팀 · **근거**: 사장님 지시 *"업체관리 → 업체마스터 → 업체등록 → 우편번호(우편번호API 연결 끊어짐)"*
> **크기**: 🟢 **소** — 한 줄 · DDL 0 · 화면 0

---

## 1. 증상과 진범

**증상** — [업체등록] 에서 [우편번호 찾기] 를 눌러도 **창이 안 뜬다.**

**조사 결과 — 코드는 멀쩡하다.**

| 확인한 것 | 상태 |
|---|---|
| 스크립트 로딩 `index.html:105` | 🟢 있다 (`postcode.v2.js`) |
| interop `openDaumPostcode` `index.html:110` | 🟢 있다 |
| 버튼 `PartnerDetail.razor:65` → `SearchAddress():273` | 🟢 있다 |
| 콜백 `OnAddressSelected():280` | 🟢 있다 |

🔴 **진범 = CSP 헤더** (`src/HitPan.API/Program.cs:502-510`)

```
default-src 'self';
script-src ... https://t1.daumcdn.net ...   ← 스크립트는 허용됨
(frame-src 없음)                             ← 🔴 여기
```

카카오 우편번호 창은 **iframe 으로 뜬다.** `frame-src` 가 없으면 `default-src 'self'` 가 상속되어
**바깥 도메인 iframe 이 차단**된다. ⇒ 스크립트는 받아지고 버튼도 눌리는데 **틀만 안 뜨는** 증상이 된다.

⚠️ 6/17(1.2.13) *"CSP 3종 도메인 정합"* 봉합 때 **script-src 만 넣고 frame-src 를 빠뜨린 것**이다.

---

## 2. 🔴 왜 우리는 못 보고 사장님만 보셨나 (재발 방지 핵심)

```csharp
if (!isDevelopment) {   // ← CSP 는 여기 안에만 있다
    h["Content-Security-Policy"] = ...
}
```

⇒ **개발PC(Development)에서는 CSP 자체가 안 붙어 우편번호가 잘 열린다.**
   사장님 실사용 경로(터널·운영)에서만 끊긴다.

🔴 이것이 **`feedback_dev_pc_proves_nothing` · `feedback_verify_real_usage_path` 그 자리**다.
   *"개발PC에서 되는데요"* 는 이 건에서 **구조적으로 무의미**하다.
   ⇒ **검증은 반드시 `Production` 환경(CSP 켜진 상태)에서 한다.**

---

## 3. 고치는 방법

`Program.cs` CSP 에 `frame-src` 한 줄을 **추가**한다 (헌법 #1 — 기존 줄 수정 아닌 추가).

```
frame-src 'self' https://t1.daumcdn.net https://postcode.map.daum.net;
```

⚠️ **두 도메인이 필요할 수 있다** — 스크립트는 `t1.daumcdn.net` 에서 오지만
   iframe 내용은 `postcode.map.daum.net` 에서 오는 구조다. **실측으로 확정한다**(§5).
   🔴 브라우저 콘솔의 CSP 위반 메시지가 **차단된 정확한 도메인을 알려준다.** 그것을 근거로 적는다.
   ⚠️ 추측으로 도메인을 넓게 열지 마라(`https:` 전체 허용 금지 — 보안 후퇴).

---

## 4. 영향 범위 — 이 화면만이 아니다

`openDaumPostcode` 를 쓰는 곳 **전부**가 같이 죽어 있다:

| 화면 | 위치 |
|---|---|
| 업체등록 | `PartnerDetail.razor:65` |
| 사용자정보(기본사업장정보) | `Settings/UserInfoPage.razor:167` |

⇒ 사장님이 업체등록에서 발견하셨지만 **사업장정보에서도 안 열린다.**
   ⚠️ 사업장정보 쪽은 사업자등록증 OCR 로도 채워지는 경로가 있어(8/10 지시) **증상이 가려져 있었다.**

## 5. 검증 게이트 (SOP [7-V] 검증팀 몫)

| # | 게이트 | 방법 |
|---|---|---|
| G-1 | **봉합 빼면 FAIL** | `frame-src` 줄을 지우고 우편번호 창이 **안 뜨는 것**을 먼저 확인한다 (가짜 게이트 방지 — 누적 9번) |
| G-2 | 운영 환경 실측 | `Production` 으로 띄워 **CSP 켜진 상태**에서 연다. 🔴 개발PC(`Development`) 통과는 **인정 안 함** |
| G-3 | 두 화면 모두 | 업체등록 · 사업장정보 **둘 다** 연다 (§4) |
| G-4 | 콘솔 CSP 위반 0 | 브라우저 콘솔에 CSP 위반 메시지가 **남지 않아야** 한다 |
| G-5 | 선택 결과 반영 | 창에서 주소를 고르면 우편번호·주소 칸이 **채워지는지** (열리는 것 ≠ 값이 오는 것) |
| G-6 | 보안 후퇴 없음 | `frame-src` 외 다른 지시문이 **넓어지지 않았는지** diff 확인 (보안매니저) |
