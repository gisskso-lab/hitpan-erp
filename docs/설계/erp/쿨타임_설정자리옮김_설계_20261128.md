## §2 [자리] 후보 3 · 「처음 보는 대표가 찾나」

대표가 하려는 일 = 「직원이 퇴근 시각 뒤에도 PC 에 접속해 있으면 자동으로 로그아웃시키고 싶다」. 대표는 **설정관리**(대표만 보는 무리 · F4)를 먼저 연다고 본다 — 지금 그 무리에 「사용환경 설정」 이 안 보이므로 옛 자리를 아는 사람도 거기서 찾다 멈춘다.

| | 안 A — 설정관리 > 새 줄 「자동 로그아웃 설정」 | 안 B — 설정관리 > 「접속기기 확인」 화면 안 묶음 | 안 C — 그룹웨어 > 「근태 관리」 화면 안 관리자 묶음 |
|---|---|---|---|
| 주소 | `/settings/auto-logout`(새 화면) | `/settings/devices` | `/hr/attendance` |
| 처음 보는 대표가 찾나 | **높음** — 메뉴에 찾는 낱말이 그대로 보임 · 대표만 보는 무리 · 닫힌 「사용환경 설정」 이 있던 바로 그 자리 | 중 — 「로그인한 기기」 와 이어지지만 이름에 「로그아웃」 이 없음 · 들어가 봐야 앎 | 중 — 「퇴근」 과 이어지지만 직원도 보는 메뉴라 「설정」 을 기대 안 함 · 화면 안 묶음을 찾아야 함 |
| 권한 | 화면 `[Authorize(Roles=…tenant_admin…)]`(Settings.razor :4 와 같음) + 메뉴 `_isTenantAdmin` + 서버 `TenantAdminOnly` — 세 겹이 이미 있는 꼴 | 같음(그 화면도 설정관리) | 🔴 직원도 들어오는 화면 → 묶음만 감추는 화면 분기 새로 · 서버는 같음 |
| 바뀌는 화면 파일 | 새 1 + 메뉴 2(Sidebar · More) | 1(DeviceManagePage 덧붙임) | 1(HrAttendancePage 덧붙임 — 쿨타임 C-5 표시가 이미 들어간 화면) |
| 위험 | 낮음 — 새 화면 · 다른 화면 흐름 손 0 | 중 — 접속기기 화면(#10/5 슬롯 폐기 이력)에 저장 단추 섞임 · 「확인」 화면이 「설정」 화면이 됨 | 중상 — 근태(급여 근거) 화면에 설정 저장이 섞임 · 권한 분기 실수 = 직원이 끔 |
| 판정 | **추천** | 차선 | 비추천 |
