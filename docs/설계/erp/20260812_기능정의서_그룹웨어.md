## §2. 신규 화면 상세

### 2-1. 보고서 4종 (GW-030)

**공통 구조** — 4종이 같은 뼈대. 서식만 다르다.

```
┌ 보고서 목록 ─────────────────────────────┐
│ [기간 선택] [상태 필터] [+ 새 보고서]     │
├──────────────────────────────────────────┤
│ 날짜 │ 제목 │ 작성자 │ 결재상태 │ [보기] │
└──────────────────────────────────────────┘
```

| 항목 | 일일 | 주간 | 월간 | 경위서 |
|---|---|---|---|---|
| 기간 | 날짜 1일 | 주 시작~끝 | 연·월 | 발생일 |
| 필수 | 오늘 한 일 | 이번 주 실적·다음 주 계획 | 월 실적·차월 계획 | **발생경위·원인·재발방지** |
| 결재 | 팀장 | 팀장 | 팀장→대표 | **즉시 상신** |
| 특이 | 전일 자동 이월(선택) | 일일 자동 취합(선택) | 주간 자동 취합(선택) | 첨부 가능 |

**동작**
1. [+ 새 보고서] → 서식 입력 → **[임시저장]** / **[상신]**
2. 상신 시 **결재 문서 자동 생성**(기존 신청 패턴 재사용)
3. 결재선은 **문서종류별**로 설정된 것을 탄다
4. 🔴 **결재선이 없으면 상신 전에 알린다**(GW-023) — 조용한 실패 금지
5. 열람 권한: **본인** + **결재선에 포함된 사람** + 인사담당자

> 🔴 **개발 주의**: 문서종류 추가는 **DDL 변경 0**이지만, 코드 딕셔너리에 등록하지 않으면
> **결재 설정 화면에 안 뜨고 → 결재선을 못 걸고 → 결재가 영영 미생성**된다.
> (동일 계통 사고 전례가 코드 주석에 기록돼 있음)

### 2-2. 급여명세서 (GW-032) 🔴 법정

⛔ **범위 결재 전에는 착수 금지.** 명세서까지인가, 계산(4대보험·원천징수)까지인가.

**관리자 — 발급**
```
[대상 기간] [대상 직원 선택]
지급항목: 기본급 · 수당 · 상여 · 초과근무수당 ←(GW-012 집계 연동)
공제항목: 4대보험 · 소득세 · 기타
────────────────────────
지급계 · 공제계 · 실지급액
[임시저장] [결재 상신]
```

**직원 — 열람**
- 🔴 **본인 것만.** 다른 사람 것은 접근 자체가 차단
- 목록 → 상세 → 인쇄·PDF

**규칙**
- 🔴 급여액 **암호화**(헌법 #5) · 금액 **decimal**(#4)
- 결재 승인 시에만 **회계(인건비) 반영**(#6)
- 발급 이력 **보관**(법정 기간) · 수정 시 **이력**(8/11 결재 #7)
- 기준값 출처 = **근로계약서**(GW-003)

### 2-3. 사내 메신저 (GW-033)

🔴 **계정 있는 사원만**(사장님 결재). 계정 없으면 안내: *"메신저는 로그인 계정이 필요합니다."*

**단계별 — 이 순서로 짓는다**

| 단계 | 무엇 | 선행 |
|---|---|---|
| ① | **결재 알림**(GW-020) | 터널 WebSocket 실측 |
| ② | 1:1 · 전체 채팅 | ① |
| ③ | **부서방** | **부서 축 정리**(GW-040) |
| ④ | **채팅창에서 양식 작성 → 결재 상신** | ①②③ |

**팝업 별도 창** (사장님 지시)
```
ERP 화면                    [별도 창]
┌────────────────┐         ┌──────────────┐
│ 상단  🔔3  💬2 │ ←알림   │ 메신저        │
│                │         │ ┌─ 대화방 ──┐ │
│  (업무 화면)    │         │ │ 전체      │ │
│                │         │ │ 개발팀    │ │
└────────────────┘         │ └──────────┘ │
                           │ [+ 양식]      │
                           └──────────────┘
```

**④ 채팅창 양식 작성 — 사장님 지시의 핵심**
```
[+] 버튼 → 양식 선택
  · 휴가·연차 신청
  · 경위서
  · 일일/주간/월간 보고서
        ↓
  작은 입력 카드가 채팅창에 뜸
        ↓
  채우고 [전송]
        ↓
🔴 화면에서 신청한 것과 **완전히 동일한 결재 흐름**을 탄다
        ↓
  채팅에는 "휴가 신청을 올렸습니다 [보기]" 카드로 남음
```

> 🔴 **자연어 해석 아님**(사장님 결재). 양식을 불러 채우는 방식 — **고객 AI 토큰을 쓰지 않는다.**
> 참고: 기존 AI 도우미의 **승인 카드 UI** 가 시각적 원형으로 이미 있다.

**🔴 AI 챗봇과 분리 (헌법 #18·#22 — 보안 사유)**

| | AI 도우미 | 사내 메신저 |
|---|---|---|
| 아이콘 | 로봇 (기존 유지) | **사람·말풍선** |
| 위치 | 상단 바 (기존) | **별도 창** |
| 데이터 | **외부 전송 있음** | **고객사 PC 안에만** |

⇒ **UI 를 합치면 사내 대화가 외부로 나가는 경로가 생긴다. 절대 합치지 않는다.**

**알림 (인스타·페이스북처럼)**
- ERP 상단에 🔔(결재) · 💬(메시지) 뱃지, **실시간 갱신**
- 클릭 → 해당 결재/대화로 이동
- 읽음 처리
- 🔴 연결이 끊겨도 **폴백으로 최소 동작**(SignalR 자동 폴백)

## §3. 기존 화면 수정 상세

### 3-1. 🔴 "되는 척" 3건 — 최우선

| # | 화면 | 지금 | 고칠 것 |
|---|---|---|---|
| GW-050 | 전자근로계약서 | 급여 **항상 0원** | API 응답 이름과 화면 모델 일치 |
| GW-051 | 전자서명 이력 | 무효 건도 **"유효"** | 무효 상태 정확히 표시 + 무효 건엔 [무효화] 숨김 |
| GW-052 | 전자근로계약서 | **[무효화] 눌러도 스낵바만** | 실제 무효화 API 호출 **또는** 버튼 제거 |

> **되는 척하는 버튼은 없는 버튼보다 나쁘다.** 고객이 됐다고 믿는다.
> 고칠 수 없으면 **버튼을 없애는 것이 정직하다.**

### 3-2. 경비 신청 (GW-002·031)

```
[+ 경비 신청]
  일자 · 항목 · 금액 · 사용처 · 사유
  🆕 [영수증 첨부]  ← 이미지·PDF
        ↓ [상신]
  🆕 결재 문서 생성 ← 지금 없음
        ↓
  결재함 → 승인
        ↓
  🆕 회계(경비처리) 반영 ← 지금 끊김
```

**규칙**
- 🔴 **승인자 기록**(현재 우회 경로가 테넌트 ID를 넣음 — 반드시 정정)
- 월마감 이후 소급 **차단**
- 감사로그
- 영수증은 결재자가 **볼 수 있어야** 한다

### 3-3. 초과근무 3종 (GW-012)

```
신청: 일자 · [야근 / 초과근무 / 주말근무] · 시작~종료 · 사유
        ↓ 🆕 결재선을 탄다 (지금 미연동)
      승인
        ↓ 🆕 급여 계산 근거로 남는다 (GW-032 연동)
```

**🟢 토대**: 표·`overtime_type` 컬럼·화면·승인 API **이미 있음**. **메뉴 등재 + 3종 분리 + 결재 연동**이 전부.

### 3-4. 휴가·연차 (GW-004·053·054)

| 총 연차 **15일 하드코딩** | **DB 실값** + 입사일 기준 자동 산정 |

🔴 **연차 승인 → 차감은 이미 정합. 손대지 말 것.**

## §4. 공통 규칙 (전 화면)

### 4-1. 정직 규칙 🔴

| 상황 | 반드시 |
|---|---|
| 조회 실패 | **"불러오지 못했습니다"** — "데이터 0건"과 구분(GW-056) |
| 저장 실패 | **사유를 그대로** 보여준다 |
| 안 되는 기능 | 버튼을 **비활성** 또는 제거. 되는 척 금지 |
| 결재선 없음 | **알린다**(GW-023) |
| 권한 없음 | 안내 후 차단 |

### 4-2. 권한

| 대상 | 볼 수 있는 것 |
|---|---|
| 직원 | **본인 것** + 본인이 결재선에 포함된 것 |
| 결재자 | 결재선에 걸린 문서 |
| 인사담당자 | 전 직원 인사·근태·휴가 |
| 대표(부모계정) | 전부 + 급여 |

🔴 **급여명세서는 본인 + 대표 + 인사담당자만.** 다른 직원 것은 접근 차단.

### 4-3. 용어 (고객 노출 — 헌법 #23)

개발용어·영어 금지. **"승인 대기"**(pending ❌) · **"반려"**(reject ❌) · **"결재선"**(approval line ❌)
