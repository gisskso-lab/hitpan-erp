# 히트판 ERP 상세 PRD

> 작성일: 2026-05-06 | 상태: 확정

---

## 목적
고객사 직원이 매입·판매·재고·재무 업무를 처리하는 독립 운영 시스템.
인터넷 끊겨도 운영 가능. 본사로 업무 데이터 전송 없음.

---

## 설치 흐름 (원클릭 인스톨러)

```
[1] 이메일에서 EXE 다운로드 링크 클릭
[2] EXE 더블클릭
[3] 라이선스 키 입력 (유일한 입력)
[4] 인스톨러 자동 처리:
    ① 환경 체크
       - MariaDB 설치 여부 확인 → 없으면 설치 / 있으면 재사용
       - 닷넷 8 런타임 확인 → 없으면 설치
       - 포트 3306 충돌 확인 → 자동 해결
    ② 본사 API 호출 (라이선스 키로 인증)
       - credentials.json 수신
       - 고객사 도메인 수신 (hitpan-{계정명}.kr)
       - 초기 관리자 계정 수신
    ③ 설치 실행
       - DB 구축 (hitpan_erp 데이터베이스 + 테이블)
       - 히트판 API 배포 (c:\hitpan-api)
       - cloudflared Windows 서비스 등록
       - appsettings.json 자동 기입
    ④ 바로가기 생성
       - 바탕화면 바로가기 (.url 파일)
       - 엣지 즐겨찾기 자동 추가
       - 크롬 즐겨찾기 자동 추가
[5] 완료 → https://hitpan-{계정명}.kr 브라우저 자동 오픈
목표: 10분 이내 완료
```

## 첫 로그인 흐름

```
브라우저에서 hitpan-{계정명}.kr 접속
  ↓
로그인 화면
  ↓ (초기 관리자 계정으로 로그인)
약관 동의 화면 (미동의자 강제 이동)
  ↓ 필수 4개 동의 완료
대시보드
```

### 약관 동의 화면 요구사항
```
[필수] 서비스 이용약관          [전문 보기]
[필수] 개인정보 처리방침         [전문 보기]
[필수] 개인정보 처리 위탁        [전문 보기]
[필수] 만 14세 이상입니다
[선택] 마케팅 정보 수신

[전체 동의]

[동의하고 시작하기] ← 필수 4개 미체크 시 비활성
```
- 모든 사용자 적용 (대표·직원 구분 없음)
- 동의 일시·IP·약관 버전 DB 기록
- 약관 개정 시 재동의 요청
- 미동의 상태에서 다른 API 접근 시 미들웨어에서 차단

## 페이지별 핵심 요구사항

### /settings/company (일반정보설정)
- 회사명·대표자·사업자번호·주소·연락처
- 데이터 원본: 백오피스 tenants (조회 가능, 일부 수정 가능)
- 로고 업로드
- 세금계산서 발행 정보 설정

### /settings/users (직원계정관리)
- 직원 목록·등록·수정·비활성화
- 데이터 원본: ERP 로컬 DB (원본)
- 백오피스로 Pull됨 (5분 주기)
- 역할 배정: tenant_admin / 업무별 권한

### /settings/devices (기기관리)
- 등록 기기 목록·추가·삭제
- 데이터 원본: ERP 로컬 DB (원본)
- 백오피스로 Pull됨 (5분 주기)
- 요금제 기기 한도 표시

### /partners (거래처관리)
- 거래처 등록·수정·조회
- 매입처·매출처·혼합 구분
- 거래처별 원장 연동

### /items (상품관리)
- 상품 등록·수정·재고 연동
- 카테고리·단위·단가 관리
- 특별단가 설정

### /purchase/orders (발주)
- 발주서 작성 → 확정 → 매입 전환
- 발주 확정 전까지 재고 미반영
- 중복 발주 사전 차단

### /purchase/receipts (매입)
- 발주 기반 또는 직접 매입
- 확정 시 재고 즉시 반영
- journal_lines INSERT (UPDATE/DELETE 금지)

### /sales/deliveries (거래명세서)
- 견적·수주 기반 또는 직접 작성
- 확정 시 재고 즉시 차감
- 세금계산서 발행 연동

### /sales/tax-invoices (세금계산서)
- 거래명세서 기반 발행
- 홈택스 API 연동 (외주)
- 취소 시 역분개 자동 처리

## 백오피스 연동 (ERP 관점)

| 항목 | 방향 | 데이터 | 시점 |
|------|------|--------|------|
| 직원계정 | 백오피스가 Pull | 이름·이메일·직급·재직여부 | 5분 주기 |
| 등록기기 | 백오피스가 Pull | 기기ID·기기명·등록일 | 5분 주기 |
| 구독결제 변경 | ERP → 백오피스 Push | 결제 정보만 | 즉시 |
| 업무 데이터 | 전송 없음 | - | - |

### ERP가 제공하는 동기화 엔드포인트
```
GET /api/sync/employees
  인증: BACKOFFICE_SYNC_TOKEN (읽기 전용)
  응답: [{ name, email, position, isActive }]

GET /api/sync/devices
  인증: BACKOFFICE_SYNC_TOKEN (읽기 전용)
  응답: [{ deviceId, deviceName, registeredAt }]
```

## 워크플로우 무결성 원칙 (절대원칙 #20)

```
재고 변동은 반드시 이 3흐름으로만:
  ① 매입 확정 → 재고 증가
  ② BOM 생산 확정 → 완제품 증가 + 자재 감소 (동일 트랜잭션)
  ③ 거래명세서 확정 → 재고 감소

한 단계라도 끊기면 즉시 P0 핫픽스.
```

## 비기능 요구사항
- 처음 쓰는 직원이 설명서 없이 3분 안에 사용 가능
- 스크롤 없이 한 화면에서 핵심 정보 표시
- 모바일 사파리·크롬 지원
- 인터넷 끊겨도 ERP 운영 가능
- Enter키 → 다음 칸 이동
- 그리드 ↑↓ 키보드 행 이동
