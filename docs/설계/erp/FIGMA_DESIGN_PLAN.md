## 2. 랜딩 픽셀 디자인 (`Landing.figma`)

### L1 메인 (Home)
- Hero: 글래스모피즘 카드 + "한 화면씩 탄탄하게" + 1차 CTA "14일 무료 체험"
- Features: 6단계 워크플로우 시각화 (설정→마스터→매입→판매→현황→재무)
- Pricing: 3티어 카드 (29k/59k/100k) — 디폴트 영역
- 베타 모집: 선착순 카운터
- CTA: 하단 고정 "지금 시작"

### L2 가격 (Pricing)
- 3티어 카드 + 추천 배지 (STD에 "가장 인기")
- 기능 비교 매트릭스 (가로 스크롤 X, 한 화면 완결)
- FAQ 6건 (환불 / 자동갱신 / 해지 / trial / 데이터 / 결제)

### L3 베타 모집 (Beta)
- 선착순 30곳 카운터 (실시간)
- 베타 혜택 박스
- 신청 폼 짧게 (5필드)

### L4 가입 (Signup)
- 5단계 스텝퍼: 약관 → 계정 → 사업자정보 → 결제 → 완료
- 각 단계 한 화면 완결
- 진행률 표시

### L5 결제 (Payment)
- Mock 모드 표시 (7월 Toss 연결 전)
- Toss 카드 UI 미리보기
- 결제 수단 4종 (카드·계좌·간편·법인)
- 약관 동의 4건 (마지막 단계)

### L6 다운로드 (Download)
- 라이선스 키 표시 + 복사 버튼
- EXE 다운로드 큰 버튼
- 매뉴얼 PDF + 영상 + AI 챗봇 안내
- "10분 안에 설치 끝" 약속 카드

## 3. 백오피스 픽셀 디자인 (`Backoffice.figma`)

### B0 2FA 로그인
- 이메일/비밀번호 + OTP (Google Authenticator)
- 다크 모드 보라 계열 메인
- 본사 직원 강제 2FA (헌법 결재 #16)

### B1 사이드바 + 메인 영역
- 좌측 고정 사이드바 (collapse 가능)
- 7 영역 메뉴 + 활성 상태 표시
- 상단 검색 + 알림 + 프로필

### B2 Tenant (고객사 관리)
- 리스트 (필터: 상태·플랜·가입일)
- 상세 (메타정보만 — 헌법 #18·#22 정합)
- 업무 데이터 절대 표시 안 함

### B3 Subscription (구독)
- 플랜 변경 / trial / suspended / anonymized 라이프사이클 시각화
- 30일 유예 카운트다운
- 90일 익명화 큐

### B4 Payment (결제)
- 결제 이력 (Toss 1순위, 재시도 1/3/7일)
- 환불 처리 (7일 100% / 14일 50% / 30일 0%)
- SLA 영업일 3일 표시

### B5 Reseller (대리점)
- 대리점 리스트 + 수수료율 (디폴트 10%)
- 정산 익월 15일 캘린더
- 채널 KPI

### B6 Account (계정 관리)
- 본사 직원 계정
- 2FA 강제 표시
- 권한 매트릭스

### B7 Telemetry (텔레메트리)
- 5분 주기 heartbeat 시각화
- device_count / db_version / last_seen
- 업무 데이터 없음 (헌법 #22 정합 검증 배지)

### B8 Audit (감사)
- consent_audit_log
- 본사 직원 행동 로그
- 5년 보존

### 다크 모드 (보라 계열 메인)
- 백오피스 기본 다크
- Purple 600 → 900 그라데이션
- 카드 글래스모피즘 어두운 변형

## 5. 한 화면 완결 원칙 (사장님 헌법 정합)

모든 화면은 다음을 충족:
- 스크롤 없이 핵심 정보 노출
- 처음 보는 사람이 3분 안에 사용 가능
- 모달·드롭다운 깊이 2단계 이하
- 텍스트는 평이한 한국어
- 금액은 천단위 콤마 + 원 단위 명시
