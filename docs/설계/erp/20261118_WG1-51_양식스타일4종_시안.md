## §2 [4종 정의] 구현 가능한 값

> 열 너비 · 칸 순서 · 여백은 4종 공통(§1 그대로). 글자는 모두 #000. 표의 숫자 열은 오른쪽 정렬 그대로.

### §2-1 머리 배치 그림

| 키 | 머리 배치 |
|---|---|
| basic | 왼쪽 위 제목 → 그 아래 문서번호 · 일자 / 오른쪽 공급자 5줄 / 아래 회색 1pt 선 한 줄 |
| formal | **맨 위 가운데 제목**(글자 사이 넓게) → 그 아래 **이중선**(굵은 1.5pt + 1.5pt 띄고 + 가는 0.5pt) → 한 줄에 왼쪽 문서번호 · 일자 / 오른쪽 공급자 5줄 |
| simple | basic 과 같은 배치 · 제목 작게 · 아래 검정 0.75pt 선 |
| large | basic 과 같은 배치 · 글자 크게 · 아래 검정 1.5pt 선 |

### §2-2 값 표

| 항목 | 기본 `basic` | 격식 `formal` | 간결 `simple` | 큰글씨 `large` |
|---|---|---|---|---|

### §2-3 회색 사다리(4종이 쓰는 값 전부)

| 단계 | hex | 쓰는 자리 | 흑백 · 팩스 |
|---|---|---|---|
| 잉크 | #000000 | 글자 · 격식 선 · 간결 굵은 선 · 굵은 머리 선 | 안전 |
| 짙은 회색 | #424242 | 격식 본문 격자 | 안전 |
| 중간 회색 | #616161 · #757575 | 기본 머리 선 · 큰글씨 선 | 안전 |
| 옅은 선 | #9E9E9E · #BDBDBD | 간결 가로선 · 큰글씨 본문 선 · 기본 박스 선 | 대체로 남음(종이 실측으로 확인) |
| 바탕 면 | #E0E0E0 · #E6E6E6 · #EEEEEE · #F2F2F2 | 표 머리 배경 · 줄무늬 | 팩스에서 흰색으로 날아가도 **글자는 안 묻힘**(면 위 글자는 #000) |

`show_border=0` 규칙은 4종 모두 지금 그대로 — 선 0 · 면 끔 · 안쪽 +1pt. 스타일 값은 `show_border=1` 일 때만 산다.

## §3 [구현 메모] 결재 뒤 갈래 E ⑵ 가 쓸 것

### §3-1 갈림 — `ResolveStyleKey`
- 허용 목록 = `basic` · `formal` · `simple` · `large`(소문자 · 대소문자 무시 비교). 모르는 값 · 빈 값 → `basic` + 경고 한 줄 = **지금 동작 그대로**.
- 값 묶음 1개(예: 스타일 값 레코드)에 §2-2 표를 그대로 옮기고 4개 정적 인스턴스. `basic` 인스턴스는 §1 값과 **한 글자도 다르면 안 된다**(기존 고객 종이 보호 · 대조 시험).
- `ComposeHeader` · `ComposeBody` 에 그 묶음을 넘긴다 — 두 함수는 `static` 이다. 인자를 더하기 전 **부르는 자리 · 반사로 부르는 시험을 전부 grep**(헌법 #12 · 반사 게이트 함정 전례).
- 양식지 · 좌표 · 세금계산서 · 급여명세서 길은 **스타일을 읽지 않는다**(좌표 칸 넘침 방지 · 법정 서식) — §4 Q-C.
- DB: `form_templates.style_key varchar(20) DEFAULT 'basic'`(DB-90) 그대로 · DDL 변경 0. 출하 DDL 주석 「4종 확정 전까지 basic 단일」 갱신은 결재 뒤.

### §3-2 글꼴
- 본문은 4종 모두 맑은 고딕 = **새 의존 0**. 격식 제목만 §4 Q-A 에 따라:
  - (가) `Batang`(바탕 · Windows 한국어 보조 글꼴) — 파일 0 · 고객 PC 에 있는지 미확인
  - (나) Noto Serif KR Bold — **SIL Open Font License 1.1**(무료 · 상업 사용 · 내장 · 재배포 허용 · 글꼴 단독 판매만 금지) · 파일 1개 내장 + `FontManager.RegisterFont` + 라이선스 전문 동봉 · 설치본 크기 증가 · 공급망 점검 1건
  - (다) 맑은 고딕 굵게 + 자간 — 파일 0 · 격식 느낌은 이중선 · 가운데 배치가 맡음
- 미리보기 페이지는 맑은 고딕이 없는 기기에서 Noto Sans KR(OFL 1.1)로 대신 보인다 — 종이와 글자 모양이 조금 다를 수 있다.
