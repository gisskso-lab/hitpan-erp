## §1 [사실] F-1 설계 · 렌더 순서 · 고객 화면

### §1-1 F-1 설계가 세금계산서를 넣나

| 문서 · 줄 | 글자 | 읽음 |
|---|---|---|
| 설계 §7-3 :272 자료 모양 | 「새 `template_id` · **같은 `form_type`** · `paper_mode`='plain' · 칸 좌표 … 복사 · `print_background`=1」 | 종을 가리지 않음 |
| 설계 §7-3 :273 한 함수 | 「Y/N 의 Y 단추와 옮기기 단계가 **같은 함수**」 | 새로 올린 세금계산서 양식지의 Y 도 같은 결과 |
| 설계 §7-3 :274 대상 | `preprint` **그리고** `print_background`=1 **그리고** `is_active`=1 | 종 조건 0 → 세금계산서 포함 |
| 착수준비표 §1 :34 F-1 줄 | 세금계산서 글자 0 | 같음 |
| 설계 §0 :29 · 작업지시서 「하지 않는 것」 :89 | 「세금계산서·계산서 양식(법정 서식 · 결-K)」 | 법정 서식 **모양을 고치지 않는다**는 줄로 읽음 — Y 대상에서 뺀다는 뜻인지는 글자로 안 정해짐(**확인 필요**) |

⇒ **글자 없음 = 지금 설계대로 짜면 세금계산서 Y 를 만든다.**

### §1-2 `plain` 세금계산서에서 무엇이 먼저인가 (갈래 A 나무 `aacb6ac8`)

| 줄 | 하는 일 |
|---|---|
| `:100` | 저장값 `print_background` 를 떠 둠 |
| `:102` | `isPreprint` = `paper_mode == "preprint"` |
| `:142` | `bgImage` = 그림 읽기(종 상관없이 계산) |
| `:156~160` | `isYTemplate`(다섯 조건) · `useCoords` — **계산은 된다** |
| `:185` | `documentType == "tax_invoice" && !isPreprint` → 법정 작성기 — **`isYTemplate` 를 안 본다** |
| `:208~210` | `RenderTaxInvoiceDocument(자료, 회사, 부수, 절취선, 여백 4)` → 바로 돌려줌. 그림 · 좌표 인자 0 · 로고 · 격자 안 넘김(`:201` D-5) |

⇒ Y 판정이 계산되는 자리는 앞이지만 **갈림은 `:185` 가 먼저** — Y 세금계산서는 법정 작성기로 나간다.

### §1-3 고객 화면 결과

| 차림 | main(지금 고객) | F-1 그대로 짠 뒤 |
