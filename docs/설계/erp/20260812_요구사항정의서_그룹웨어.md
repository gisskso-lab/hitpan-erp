### GW-021 근태 ↔ 휴가 상호 인지

**현상**: 서로 모름. `attendance.status` 에 `'leave'` 값이 정의돼 있으나 **쓰는 코드 0**.
⇒ **휴가 낸 날이 근태에서 결근/무기록**으로 잡힘.
**요구**: 승인된 휴가일은 근태에 휴가로 표시. 사장님 결재 #5(*"안 찍은 날 = 정상출근, 예외만 체크"*)와 정합. **P1**

### GW-022 신청 사유 노출

**현상**: 사유가 **DB엔 저장되는데** 조회 SQL·DTO 에 누락 → 어느 화면에서도 못 봄(항상 "-").
**요구**: 신청 사유가 목록·상세에 보일 것. (같은 병을 `reject_reason` 은 이미 고쳤고 `reason` 만 남음) **P1**

### GW-023 결재선 없는 상신 처리

**현상**: 결재선이 0건이면 **아무 말 없이 무시**. 신청자는 올라간 줄 안다.
**요구**: 결재선이 없으면 **신청자에게 알린다**(관리자에게도). 조용한 실패 금지. **P1**

### GW-041 사원 ↔ 계정 양방향 연결

**현상**: 계정→사원은 자동 생성되는데, **사원→계정은 `user_id` 를 NULL 하드코딩.**
**요구**: 8/11 결재 #2 *"연결은 양방향"*. 사원 화면에서 계정 발급 경로 + **미발급자 표시**.
(참고: `HasUserAccount` 는 이미 계산되고 "계정 있음" 카운트만 표시 — **미발급자를 거르는 UI 가 없음**) **P1**

### GW-042 전자서명 축 정정

**현상**: 그룹웨어에서 **유일하게 `user_id` 기준.** 계정 없는 사원은 근로계약서에 **서명 불가**.
**요구**: 사원 기준으로 정정하되, **서명 행위 자체는 본인 확인이 필요**하므로 대체 수단(간편인증) 검토. **P1**
