```
U          L           BO          CF        EM
│          │           │           │         │
│ 가입신청 │           │           │         │
│─────────▶│           │           │         │
│          │ 본인확인  │           │         │
│          │ (PASS/카톡)│          │         │
│          │           │           │         │
│          │ 가입 Push │           │         │
│          │──────────▶│           │         │
│          │           │ tenant_id │         │
│          │           │ 발급      │         │
│          │           │ status=pending│     │
│          │           │           │         │
│          │           │ DNS·터널 발급 │     │
│          │           │──────────▶│         │
│          │           │ hitpan-{code}.kr    │
│          │           │◀──────────│         │
│          │           │           │         │
│          │           │ 가입 완료 이메일    │
│          │           │────────────────────▶│

│◀─────────│           │           │         │

```

**핵심 박제**

- Cloudflare API 토큰은 **본사 BO 서버에만** 존재. EXE·랜딩에 절대 포함 금지 (헌법 #29)
- DNS·터널 발급은 BO 백그라운드 작업으로 처리

## 2. 결제 시퀀스 (랜딩 → 토스 Mock → 백오피스 → 라이선스 발급)

```
U          L           BO          PG (Toss/Mock)
│          │           │           │
│ 결제 시작 │           │           │
│─────────▶│           │           │
│          │ 결제 요청 │           │
│          │──────────▶│           │
│          │           │ IPaymentProvider │
│          │           │ .RequestPaymentAsync│
│          │           │──────────▶│
│          │           │           │ 결제창
│          │◀──────────────────────│
│ PG 결제창│           │           │
│◀─────────│           │           │
│ 카드 결제 │           │           │
│────────────────────────────────▶ │
│          │           │           │ 승인
│          │           │ Webhook   │
│          │           │◀──────────│ (success/failed)
│          │           │           │
│          │           │ subscription.status = active
│          │           │ tenant.status = active
│          │           │ payment 저장
│          │           │ billing_key 저장 (자동결제)
│          │           │ invoice 생성
│          │           │           │
│          │           │ 라이선스 발급        │
│          │           │ (license_key, JWT) │
│          │           │           │
│          │ 완료 응답  │          │
│          │◀──────────│           │
│ 완료 화면 + EXE DL    │          │
│◀─────────│           │           │
```

**핵심 박제**
- 본사는 **카드번호·CVC·유효기간** 절대 보유 금지 (PCI-DSS)
- `billing_key`만 보관 → PG에 의존해 자동결제
- 어댑터 패턴: MVP는 MockPaymentAdapter, 베타 직전 TossPaymentsAdapter로 전환

## 3. ERP → 백오피스 텔레메트리 Pull (5분 주기)

```
ERP            BO
│              │
│ (5분 타이머)  │
│              │
│ heartbeat POST│
│─────────────▶│
│ { tenant_id, │
│   client_ver, │
│   db_ver,     │
│   os_ver,     │
│   watchdog_status, │
│   usage_counters }│
│              │
│              │ TenantHeartbeat 저장
│              │ UsageMetric upsert (today)
│              │
│              │ AlertRule 평가
│              │ (heartbeat_missing / error_spike)
│              │
│              │ (임계 초과 시) ops_manager에게 알림
│              │
│ 200 OK       │
│◀─────────────│
│              │
│ license 만료 D-7 등 │
│ 백오피스 → ERP 응답에 포함 │
│ (라이선스·구독 정보)│
```

**핵심 박제**
- ERP가 보내는 데이터 = **카운터·식별자·버전 메타만** (헌법 #18 v3)
- ❌ 매출 금액·거래처명·상품명·세금계산서 내용 일체 미포함
- ❌ 본사가 ERP에 Pull 요청 불가 (방향은 항상 ERP → BO)
- 본사가 ERP에 내려보내는 것 = 라이선스·구독·알림 메시지만

## 4. 해지 시퀀스 (ERP 안 본인 페이지 → 백오피스 → 환불 → 정지)

```
U(대표)    ERP         BO          PG          EM
│          │           │           │           │
│ 본인 페이지 진입     │           │           │
│─────────▶│           │           │           │
│          │ (대표 owner 인증 + PASS 본인확인) │
│          │           │           │           │
│ 해지 신청│           │           │           │
│─────────▶│           │           │           │
│          │ 해지 요청 │           │           │
│          │──────────▶│           │           │
│          │           │ cancel_requested_at = now
│          │           │ status = active (유지)
│          │           │ (이용 종료일까지)    │
│          │           │           │           │
│          │           │ (환불 정책 평가)    │
│          │           │ 일할 환불 / 전액 환불 / 없음 │
│          │           │           │           │
│          │           │ Refund.RequestAsync │
│          │           │──────────▶│           │
│          │           │           │ 환불 처리 │
│          │           │ Webhook   │           │
│          │           │◀──────────│           │
│          │           │           │           │
│          │           │ 해지·환불 안내 메일             │
│          │           │──────────────────────▶│
│          │           │           │           │
│          │ (이용 종료일 도래) ── 백오피스 배치    │
│          │           │ status = cancelled    │
│          │           │ subscription cancelled│
│          │           │ tenant suspended      │
│          │           │           │           │
│          │ 라이선스 만료 신호 (다음 ping)    │
│          │◀──────────│           │           │
│ ERP 잠금 화면        │           │           │
│◀─────────│           │           │           │
```

**핵심 박제**
- 즉시 차단 아님 → 이용 종료일까지 active 유지 (사장님 결재 D)
- ERP 데이터는 본사로 가지 않음 — 고객 PC에 그대로 보존 (헌법 #18 v3 / #22)
- 데이터 백업 책임 = 고객 (헌법 #24)

## 5. 대리점 영업 시퀀스 (대리점 → 백오피스 등록 → 수수료 계산)

```
R(대리점)  AD(본사)    BO          U(고객)    L          (월말)
│          │           │           │          │             │
│ 대리점 신청           │           │          │             │
│─────────▶│           │           │          │             │
│          │ 심사·계약 │           │          │             │
│          │──────────▶│           │          │             │
│          │           │ Reseller 등록        │             │
│          │           │ ResellerContract 저장│             │
│          │           │ 추천 코드 발급        │             │
│          │           │           │          │             │
│ 추천 코드 + 영업      │           │          │             │
│──────────────────────────────────▶│         │             │
│          │           │           │          │             │
│          │           │           │ 추천 코드로 가입│       │
│          │           │           │─────────▶│             │
│          │           │ 가입 Push │          │             │
│          │           │◀──────────────────────│             │
│          │           │ ResellerCustomer 매핑│             │
│          │           │ (mapping_source=landing_code)│      │
│          │           │           │          │             │
│          │           │ (이후 결제마다)        │             │
│          │           │ payment.tenant_id ↔ mapping 추적    │
│          │           │           │          │             │
│          │           │           │          │ (월말 배치) │
│          │           │ Commission 집계      │             │
│          │           │ = Σ(산하 결제) × rate│             │
│          │           │ status=pending       │             │
│          │           │           │          │             │
│          │ 검토·승인 │           │          │             │
│          │──────────▶│ status=approved      │             │
│          │           │           │          │             │
│          │           │ (익월 10일) 송금     │             │
│          │           │ status=paid           │             │
│ 정산 통보 │           │          │          │             │
│◀──────────────────────│           │          │             │
```

**핵심 박제**
- 대리점은 산하 고객사의 **매출·세금계산서 등 ERP 업무 데이터에 접근 불가** (헌법 #18 v3)
- 대리점이 보는 것 = 산하 고객사 메타정보 + 자기 수수료 집계만
- 본사는 송금 책임만, 자료 보관 책임은 대리점이 (헌법 #24)
