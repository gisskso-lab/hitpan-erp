## §0. 결론 한 줄

**"어느 주소로 열었나" 로는 메인PC 를 증명할 수 없다(8/10 결론이 옳다). 증명이 되는 선로는 "브라우저가 `127.0.0.1:{API_PORT}` 로 API 에 직접 붙는 순간" 하나뿐이고, 그 순간을 사장님이 막힌 도메인 화면의 버튼 한 번으로 지나가게 만든다(안 A · 로컬 되돌이 확인). 그 한 번의 증명으로 ① 자료관리 자리(10분짜리 증표)와 ② 신분 합류(1기계 = 1슬롯)를 따로 연다.**

## §2. 설계 원칙 — 「어느 주소로 열었나」가 아니라 「무엇이 증명하나」

### 2-1. 증명이 되는 선로는 하나뿐이다

서버는 자기가 메인PC 인 줄 안다(X1). 그 앞 브라우저가 **같은 컴퓨터**라는 것을 네트워크가 스스로 보증하는 선로는
**브라우저가 `http://127.0.0.1:{API_PORT}` 로 API 에 직접 붙는 TCP 연결** 하나다.

| 걸러야 할 것 | 어떻게 걸러지나 | 근거 |
|---|---|---|
| 터널(P1·P3·P4) | `CF-Connecting-IP` 가 붙는다 — 클라이언트가 못 뗀다 | 🟢 `MainPcOnlyAttribute.cs:41-43` 가 이미 이 헤더로 가른다 |
| 5234 프록시 경유(사내 PC·Host 위조) | 프록시가 Host 를 복사하지 않아 목적지 `localhost:{port}` 로 간다(`web-server.ps1:33`·`:91`·`:98`) ⇒ 브라우저 직결의 `127.0.0.1:{port}` 와 **Host 가 갈린다** | 🟡 Host 실제 값 ⬜ |
| 사내 다른 PC 가 직접 | 그 PC 의 127.0.0.1 은 그 PC 자신 · `hitpan-start.bat:79` 가 `0.0.0.0` 으로 띄워도 원격주소가 loopback 이 아니다 | 🟢 |
| DNS 리바인딩 | Host 가 공격자 도메인이 된다 | 🟡 |
| 그 주소에 화면이 있나 | API 가 자기 `wwwroot` 를 서빙한다(`Program.cs:580-597`·`:625-628`) · update zip 에 실린다(`deploy-update.yml:212-225`) | 🟢 |

⇒ **직결 로컬** = `Host ∈ {127.0.0.1:{API_PORT}, [::1]:{API_PORT}}` **AND** 원격 loopback **AND** `CF-Connecting-IP`·`X-Forwarded-For` 없음.

### 2-2. 🔴 그 선로를 사장님이 **실제로 지나게** 한다 — 8/19 안 B·C 폐기 사유 해소

8/19 안 B·C 는 *"브라우저가 스스로 loopback 주소로 가 주기"* 를 기대했거나 *"터널로 열린 경로에서 증표를 건넸다"* ⇒ **아무도 안 지났다**(8/19 §3-3·§3-5).

안 A 는 방향을 뒤집는다:
- **도메인 화면이 막힌 바로 그 자리**(자료관리 403 안내 · 대기 관문 합류 버튼)에 **[이 컴퓨터 확인]** 을 둔다.
- 버튼이 새 창으로 `http://127.0.0.1:{API_PORT}/local-proof?p={pairId}` 를 연다.
  - **메인PC 앞이면** 열리고 즉시 확인 → 창이 닫히고 → 도메인 탭이 확인됨을 받는다.
  - **다른 PC·폰이면** 그 기기 127.0.0.1 에 히트판이 없어 안 열린다 → 도메인 탭이 *"자료보관 컴퓨터 앞에서 눌러 주세요"*.
- **습관을 바꿀 필요가 없다** — 사장님은 계속 도메인으로 여시고, 필요할 때 버튼 한 번.
- **터널로는 비밀이 오가지 않는다** — 터널을 지나는 것은 대표 세션이 연 `pairId`(난수)와 *"확인됐나"* 조회뿐. **확인 자체는 직결 로컬에서만** 된다.

### 2-3. 두 질문을 가른다

| 질문 | 쓰는 곳 | 수명 |
|---|---|---|
| **Q-자리** — 지금 이 브라우저가 자료보관 컴퓨터 **앞에 있나** | `MainPcOnly`(찾아보기·덮어쓰기·초기화·백업) | **짧게**(권고 10분) — 필요할 때 다시 확인 |
| **Q-신분** — 이 브라우저는 **어느 기기 줄로 세나** | 슬롯·관문·기기 목록 | 길게(브라우저 저장소) |

🔴 **Q-자리를 저장된 비밀로 판정하지 않는다.** 저장소 복사 하나로 바깥에서 초기화가 열리면 안 된다 —
K 가 업무 API 에 수용한 *"그 PC 를 만질 수 있는 사람"* 수준(8/19 §3-10)을 **자료 삭제까지 넓히지 않는다.**
