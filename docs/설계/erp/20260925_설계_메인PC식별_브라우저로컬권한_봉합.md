## 1. 무엇을 고치나 (한 줄)

**브라우저가 "이 사이트가 당신 컴퓨터 안을 봐도 됩니까" 를 묻는 동안, 앱이 1500ms 에 포기해 버린다.**
→ ① **기다려준다** · ② **자료관리에 들어갈 때 한 번 더 돈다.**

## 2. 무엇을 안 고치나 (경계)

| 안 건드림 | 왜 |
|---|---|
| 서버 판정 (`MainPcOnlyAttribute` · `MainPcProofService` · 봉인키) | 🟢 선행검증 §2 — 결백이 실측으로 확인됨 |
| 왕복 3콜의 순서·의미 (①②③) | 9/22 결재된 설계. 흐름을 안 바꾼다 |
| **두 주소를 차례로 두드리는 것** | 사장님 결재 D-5. 동시 발사로 바꾸지 않는다 |
| 권한이 **거부된** 고객의 안내 문구 | ⚠️ **별건** — §7 |
| 팝업 자체를 없애는 길 | ⚠️ **별건 재설계** — 사장님이 봉합만 결재 |

## 3. 절① — 팝업이 떠 있는 동안 기다려준다

**대상**: `src/HitPan.Web/wwwroot/js/hitpan-mainpc-proof.js`

```
var TIMEOUT_MS = 1500;   →   10000
```

### 근거 — 지금 주석에 적힌 이유가 사실이 아니다

현재 주석: *"길게 잡으면 히트판이 없는 컴퓨터에서 로그인이 그만큼 느려진다"*

선행검증 §5 실측:

| 상황 | 실제 걸리는 시간 |
|---|---|
| 히트판 **없는** PC (= 고객 클라이언트) | **1ms** — 연결 거부. 즉시 |
| 권한 **거부**된 메인PC | **1~3ms** — 즉시 |
| 권한 **있는** 메인PC | **5~42ms** |
| 권한 **팝업 대기 중** | **매달림** ← 여기만 시간제한에 걸린다 |

⇒ **늘려서 느려지는 경우가 존재하지 않는다.** 기다리는 쪽은 오직 "메인PC인데 사람이 아직 안 누른" 경우다.

### 왜 10초인가

사람이 팝업을 **알아보고 누르는** 시간. 두 주소를 차례로 두드리므로 최악 20초이지만,
그 최악은 *"메인PC에서 사람이 20초간 팝업을 안 누른"* 경우뿐이고, 그때도 절②가 받아 준다.

🔴 **무한정 기다리지 않는다.** 시간제한을 없애면 사람이 팝업을 무시했을 때 회전자가 영원히 돈다
(선행검증에서 30초 넘게 매달리는 것을 실제로 관측했다 — §8 U-1).

## 4. 절② — 자료관리에 들어갈 때 조용히 한 번 더 돈다

**대상**: `src/HitPan.Web/Components/Common/MainPcOnly.razor`

### 지금 흐름

```
로그인 직후  MainPcGate 가 왕복 1회  → 실패하면 출입증 없음 (그것으로 끝)
자료관리 진입 MainPcOnly → api/devices/is-main-pc → 출입증이 없으니 403 → "이 컴퓨터가 아닙니다"
```

사용자가 그 사이 팝업을 **허용했어도** 다시 물어보는 자리가 없다.

### 바꿀 흐름

```
자료관리 진입 MainPcOnly
   → ① 먼저 묻는다 (지금 그대로)
   → 🔵 아니라고 나오면 **왕복을 한 번 돌고 다시 묻는다**  ← 더하는 것
   → 그래도 아니면 지금과 똑같이 "이 컴퓨터가 아닙니다"
```

### 🔴 게이트 G-27 을 깨뜨리지 않는 자리에 넣는다

`MainPcAccessState.ResolveAsync` 는 게이트가 **호출 횟수를 직접 세는** 자리다 —
*"막혔을 때 0회 · 통과했을 때 정확히 1회"*.

⇒ **`ResolveAsync` 바깥을 건드리지 않는다.** 재시도는 그것에 넘기는 `ask` **안에서** 끝낸다.
그러면 `ResolveAsync` 호출 횟수도, `OnAllowed` 호출 횟수도 **한 글자도 안 바뀐다.**

```
ask = async () => {
    if (서버가 그렇다고 하면) return true;        // 지금 경로 그대로
    if (왕복을 한 번 돌아 통과하지 못하면) return false;
    return 서버에 다시 묻는다;                     // 출입증이 생겼으니 이번엔 열린다
}
```

### 🔴 고리가 돌지 않게

| 막을 것 | 어떻게 |
|---|---|
| 재시도가 또 재시도를 부르는 것 | **한 번만.** 두 번째 실패는 그대로 실패로 둔다 |
| 클라이언트 PC 에서 매번 왕복이 도는 것 | 왕복 ②는 그 PC 에서 **1ms 에 실패**한다 — 비용이 없다 (선행검증 §5) |
| 화면이 오래 멈춘 것처럼 보이는 것 | 회전자는 이미 돌고 있다. 늘어나는 시간은 최악 20초이고, 그 경우는 §3 과 같다 |

## 5. 왕복 코드를 어디에 두나

지금 왕복(①②③)은 `MainPcGate.razor` 안의 **private 메서드**다. 절②가 같은 일을 해야 한다.

🔴 **복붙하지 않는다.** 코드 주석이 이미 경고하는 자리다 — *"규칙을 복붙하면 한쪽만 고쳐지는 날이 온다"*
(`MainPcOnlyAttribute.cs` · `DeviceController.cs` 둘 다 같은 경고를 달고 있다).

⇒ 왕복 한 바퀴를 **공용 서비스 한 곳**으로 옮기고, `MainPcGate` 와 `MainPcOnly` 가 **같은 것**을 부른다.

| 항목 | 지킬 것 |
|---|---|
| 기존 동작 | **한 글자도 안 바뀐다** — 판정 이름(`MainPcConfirmed`/`NotRegisteredYet`/`DifferentPc`/`ReRegisterRequired`/`NotProven`), 출입증 보관, 실패 시 조용함 전부 그대로 |
| 헌법 #1 | 옮기는 것이지 **덮어쓰는 것이 아니다.** `MainPcGate` 의 팝업 판정 로직은 그 자리에 그대로 남는다 |
| 헌법 #15 | 빈 catch 금지 — 지금의 `LogDebug` 흔적을 유지한다 |

## 6. 게이트 (⛔ 글자검사 금지 — 헌법 누적 25번)

| # | 무엇을 **동작으로** 재나 | 음성 대조군 |
|---|---|---|
| G-1 | 왕복 함수가 **한 곳**에만 있다 (복붙본이 생기면 FAIL) | 일부러 복붙본을 만들면 FAIL 이 뜨는가 |
| G-2 | `ask` 가 **한 번 실패하면 왕복을 1회** 돌고, **두 번째는 안 돈다** | 2회 돌게 고치면 FAIL |
| G-3 | `ResolveAsync` 호출 **1회**·`OnAllowed` **1회** — G-27 무회귀 | 기존 게이트 그대로 통과해야 한다 |
| G-4 | 시간제한이 **1500ms 가 아니다** + 클라이언트 PC 경로는 **여전히 즉시 끝난다** | 1500 으로 되돌리면 FAIL |

🔴 **브라우저 권한 정책 자체는 CI 에서 못 잰다** (러너에 실물 브라우저 정책이 없다).
⇒ 그 축은 **실물 실측**으로만 닫는다 — §8.

## 7. ⚠️ 별건으로 남기는 것 (사장님 결재 없이 착수 금지)

| # | 무엇 | 왜 별건인가 |
|---|---|---|
| B-1 | 권한을 **[차단]** 한 고객의 안내 | 지금 문구는 *"히트판이 설치된 그 컴퓨터에서 다시 열어 주세요"* 인데, 권한 거부는 **그 컴퓨터가 맞는데도** 같은 문구를 본다. 다만 차단과 클라이언트 PC 가 **둘 다 1~3ms 즉시실패**라 화면에서 구별할 방법을 아직 못 찾았다 (선행검증 §8 U-2) |
| B-2 | 팝업 자체가 안 뜨는 길 | 사장님 원칙 *"고객은 인증키가 도는지 모르게"* 는 이 봉합으로 **충족되지 않는다.** 재설계 사안 |
| B-3 | 이미 게시된 1.3.43·1.3.44 | 이 결함을 담은 채 나갔다. 재게시 여부는 사장님 판단 |

## 8. 실물로만 닫히는 것

```
[M-1] 권한 없는 새 프로필 Chrome 으로 로그인 → 팝업 [허용] → 자료관리가 열리는가
[M-2] 권한 없는 새 프로필 Edge 로 같은 것
[M-3] 클라이언트 PC(히트판 없음)에서 로그인이 느려지지 않는가 — 체감 지연 0
```

🔴 **헤드리스로 재면 결과가 뒤집힌다** (선행검증 §3). 반드시 화면 있는 실물 브라우저로 잰다.

## 9. 이 설계가 **안 고치는** 것을 다시 적는다

이 봉합 뒤에도 고객은 **팝업을 한 번 본다.** 달라지는 것은 —

| | 지금 | 봉합 뒤 |
|---|---|---|
| 팝업이 뜬다 | 🔴 뜬다 | 🔴 **여전히 뜬다** |
| 허용을 누르면 | 🔴 아무 일도 안 일어남 (이미 포기함) | 🟢 **그 자리에서 열린다** |
| 안 누르고 자료관리로 가면 | 🔴 "이 컴퓨터가 아닙니다" | 🟢 **한 번 더 물어본다** |
| 새로고침해야 하나 | 🔴 해야 한다 | 🟢 **필요 없다** |
