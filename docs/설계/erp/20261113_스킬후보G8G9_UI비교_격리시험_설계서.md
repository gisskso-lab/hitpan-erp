## §0 [카드] 결론 · 결정 · 다음 행동

- **추천 격리 = Windows 샌드박스(일회용).** 기능이 이 PC 에 **이미 켜져 있다**(11/13 실측) ⇒ 호스트 설정 변경 0 · 닫으면 안의 것이 전부 사라진다. 6/30 M4 시험 선례(대표 결재)도 있다. → §4
- **별도 OS 사용자는 비추천** — 같은 OS · 같은 망이라 호스트 DB(3306) · 실물 설치 폴더에 그대로 닿는다. 막으려면 호스트 방화벽까지 바꿔야 한다(#29 두 건). **VM(Hyper-V)은 불가** — 기능 꺼짐 · 켜려면 재부팅 · 디스크 20GB+ 가 없다. → §4
- 🔴 **지금 자원으로는 그대로 못 띄운다.** RAM 7.9G 중 여유 0.8G · C: 여유 10.7G(실측). ⇒ ① 시험 시간대 분리(편집기 · 브라우저 · PM 창을 닫은 시간에만) ② C: 여유 15G 이상 확보 뒤 착수(정리 = 삭제는 **대표 결재 뒤**). → §3
- 🔴 **호스트 DB 는 샌드박스 망에서 닿을 수 있다고 전제한다.** 매핑을 안 했다고 못 닿는 게 아니다. ⇒ 4겹 차단(반입 허용 목록 · 비밀값 검사 · 샌드박스 안 사설망 차단 · 착수 탐침 + 양성 대조) → 탐침이 닿으면 **시험 중단**. → §5
- **시험 3개 · 지표와 합격선은 실행 전에 고정**(제안값 → PM · 대표 확정):
  - **G8 루틴 스킬** — 사고 3종 재연 × 3안(기존 절차 · 작은 스크립트 · 스킬) × 3회 = 27회. 결정적 판독(기록 대역). 스크립트가 같거나 이기면 스킬이 아니라 **스크립트 채택**. → §6
  - **G9 탐색형** — 먼저 「기존 시험이 안 걷는 경로」가 실재하는지(환경 없이 읽기 전용). 0 이면 중단. 판정은 **같은 모델 아닌 사람/팀**(대표 지정). 미지정이면 G9 미실행. → §7
  - **UI 비교** — 랜딩 화면 1개(대표 지정) × 3안((a) 없음 (b) 공식 디자인 스킬 (c) 히트판 전용) × 2회. 블라인드 사람 판정 + 토큰 이탈 결정적 검사. → §8
- **대표 결정(11/13) 정합**: Codex 0 · 중계 프로그램 0. 샌드박스 안은 **고정 명령 목록을 차례로 돌리는 시작 스크립트**뿐이고, GPT · HQA 와는 현행 PR 댓글만 쓴다. → §11
- 규모 **M~L** · 시험 시간대 3회(회당 2~4시간 · 대표 손 회당 4동작) · 토큰 추정 5~10M(미측정). → §9

## §3 [자원] 실측과 산정

| 항목 | 11/13 실측 | 시험에 필요(추정) | 차이 · 대응 |
|---|---|---|---|
| RAM | 총 7.9G · 여유 0.8G · 상위 = 편집기 약 1.1G · 브라우저 약 1.1G · 기타 앱 | 샌드박스 3G 지정(동적) + 호스트 여유 0.5G | **2.7G 부족** → 시험 시간대에 편집기 · 브라우저 · 다른 앱 · PM 창을 닫는다(약 2.4~2.9G 회수 추정) |

| D: | 5G 중 여유 1.7G | — | 쓰지 않는다 |

- 실측 방법: OS 정보 · 논리 디스크 · 선택적 기능 상태 · 프로세스 메모리를 **읽기만** 했다(설정 변경 0).

## §4 [대안] 격리 방식 비교 · 추천

| | A 별도 OS 사용자 | **B Windows 샌드박스 (추천)** | C Hyper-V VM | D 본 프로필 + 시간대 분리만 |
|---|---|---|---|---|
| 디스크 | 프로필 + 도구 1~3G **영구**(계정 지울 때까지) | 임시 최대 약 4G · **닫으면 회수** + 캐시 1G | VM 디스크 20G+ → **여유 10.7G 로 불가** | 0 |
| RAM | 로그인 세션 추가 약 1G + 도구 | 지정 3G(동적) | 4G+ 고정 → 불가에 가깝다 | 0 |
| 격리 강도 | **약** — 같은 OS · 같은 망: 호스트 DB · 실물 설치 폴더(공용 읽기) · 로컬 서비스에 닿음 | **중~강** — 별도 커널 · 별도 파일시스템 · 망은 NAT(사설망 차단으로 보강 · §5) | 강 | **없음** — 사용자 범위 훅 · 설정 섞임 · 실물 DB 같은 자리 |
| 되돌림 | 계정 · 프로필 삭제 + 잔재 확인(전역 설치물 · 레지스트리) | **창 닫기 = 폐기** · 호스트엔 scratch 파일만 | VM 삭제 + 기능 끄기(재부팅) | 설정 복원 필요 |
| #29 영향 | 계정 생성 + DB 차단용 호스트 방화벽 규칙 = **2건** | **호스트 변경 0**(기능 이미 켜짐) · 실행만 대표 확인 | Hyper-V 켜기 · 가상 스위치 = 다수 + 재부팅 | 0 이지만 #39 위험 |
| Windows 사고 재현(G8) | 됨 | 됨 | 됨 | 됨 |
| 판정 | ❌ 격리 약함 · #29 두 건 | ✅ | ❌ 자원 불가 | ❌ 격리 아님 |

- 추천 근거[^1]: 자원 · 되돌림 · #29 세 축에서 B 가 유일하게 모두 통과한다. 단점 = 매 실행이 새 환경 ⇒ 도구 설치 · 로그인을 매번 다시 한다(캐시 매핑 · 시간대당 1회 실행으로 줄인다).
- WSL 은 리눅스라 G8 의 Windows 고유 사고(셸 경로 변환 · 한글 인코딩)를 재현 못 한다. 기능도 꺼져 있다 ⇒ 비교에서 뺐다.
- 클라우드(NCP)는 새 인프라 · 비용 · #29 이고 「3시스템 역할 분리」와 결이 다르다 ⇒ 뺐다.

[^1]: 선례 = 2026-06-30 M4 검증용 Windows 샌드박스(사장님 결재 · `tests/sandbox-m4/HitPan-M4.wsb`).

## §5 [차단] 실물 DB · 실물 ERP 차단 — 4겹 + 탐침

> 원칙: **「매핑 안 했다 = 못 닿는다」가 아니다.** 샌드박스는 NAT 망으로 호스트에 닿을 수 있다. 6/30 M4 설정 주석의 「3306 에 못 닿는다」는 매핑 안 함을 근거로 한 것이고 망 경로는 재지 않았다(가설로 둔다).

| 겹 | 장치 | 무엇을 막나 |
|---|---|---|
| 1 | **반입 허용 목록** — 레포 전체 복제 금지 · 고정 SHA 에서 필요한 경로만 내보낸 사본 | 접속 정보가 든 파일이 들어가는 것 |
| 2 | **반입 전 비밀값 검사** — 묶음 전체 검사 0건이어야 매핑 | 1겹 누락 |
| 3 | **샌드박스 안쪽 방화벽** — 시작 스크립트가 안쪽에서 사설망 · 링크로컬 대역 나가는 연결을 막는다(인터넷은 허용). 안쪽 규칙이라 호스트 설정 변경 아님 · 닫으면 사라짐 | 호스트 DB · 호스트 웹 · 같은 망 기기 |
| 4 | **착수 탐침** — 안에서 호스트 DB 포트 · 호스트 웹 포트로 연결 시도 → **실패해야 착수.** 양성 대조 = 같은 탐침을 호스트에서 루프백으로 돌려 「닿으면 잡는다」를 먼저 보인다 | 1~3겹이 실제로 동작하는지(게이트는 동작) |

- 탐침이 하나라도 닿으면 **그 자리에서 샌드박스를 닫고 중단** → PM 보고.
- 남는 위험(정직하게): 안쪽은 관리자 권한이라 에이전트가 3겹을 지울 수 있다 ⇒ 시작 스크립트가 시험 끝에 규칙 존재를 다시 기록하고, 판독에서 「규칙 사라짐 = 그 회 불합격」. 실물 ERP 의 공개 주소(터널)는 방화벽으로 못 막는다 ⇒ 접속 정보 반입 0(1 · 2겹) + 브라우저 방문 주소 기록에서 실물 도메인 0건을 판독 항목으로 둔다.
- 랜딩은 Development 설정으로만 띄운다 — 백오피스 API 주소가 샌드박스 안 루프백(없는 서비스)이라 실물 백오피스에 안 간다(`src/HitPan.Landing/Program.cs` 15~19줄 · `appsettings.json`).

## §6 [G8] 루틴 스킬화 — 체크리스트 호출기

- **과제 3종**(PR #854 G8 행의 사고 기록에서 · 대표가 바꿀 수 있음):
  - T1 레포 밖 폴더에서 PR 댓글 달기 — 레포 지정 누락(11/7 댓글 유실)
  - T2 커밋 상태를 SHA 로 조회 — 짧은 SHA 빈 값(11/3)

  - 예비 T4 커밋 제목 깨짐 — 3종에서 결론이 안 나면만
- **3안**:
  - (가) 기존 절차 = 해당 사고 기록 · WORKFLOW 해당 절 사본만 준다 — **대조군**
  - (나) 작은 스크립트 = 그 절차를 강제하는 래퍼
  - (다) 스킬 = 같은 절차를 부르는 체크리스트 호출기(정본 주소만 참조 · 새 규칙 0)
- 원격: **로컬 bare 저장소 + gh 기록 대역**(받은 인자 · 실행 폴더만 기록하고 아무 데도 안 올림) ⇒ 실제 GitHub 무접촉.
- 반복: 과제 3 × 안 3 × 3회 = **27회 · 매 회 새 세션** · 같은 사본 SHA · 같은 과제 문구 · 같은 모델 · 같은 도구 판.
- **판독(결정적 · 오라클)**: 대역 기록의 레포 지정 유무 · 조회 SHA 길이 40 · 커밋 파일 목록 = 지정 1건. 오라클 스크립트는 **검증팀장 측이 작성**하고 실행 전 해시를 고정한다(G6 원칙 · 입력 노출 목록 기록).
- 양성 대조: 일부러 어긴 기록 3벌을 오라클에 먼저 넣어 3벌 모두 「누락」으로 잡는지 본다. 못 잡으면 시험 안 한다.
- **지표**: ① 절차 누락 건수(주 지표) ② 토큰 ③ 수행 시간 ④ 새로 생긴 문서 · 중복 수.
- **합격선(제안 · 실행 전 PM · 대표 확정)**:
  - (다) 누락 ≤ (가) 누락의 1/2 **그리고** (다) < (나) ⇒ 스킬 후보 유지
  - (나) ≤ (다) ⇒ **스크립트 채택 쪽**(「스크립트가 본체」 합의)
  - 토큰 (다) ≤ (가) × 1.3
  - 승인 우회 · 실 원격 접촉 · 차단 규칙 삭제 1건 = 그 안 즉시 불합격
- **한계(정직하게)**: 짧은 새 세션은 긴 작업 중 망각을 다 재현 못 한다. 합의된 「재발률(직전 30일 대 시험 30일)」은 **실제 업무에 쓰는 측정**이라 격리 밖이다 ⇒ 이 시험 = 1단계 거르기. 2단계(실업무 30일)는 별도 결재.
- 기준선: 직전 기간 유형별 재발 건수를 **환경 없이** 사고 기록에서 먼저 센다(0단계).

## §7 [G9] 탐색형 — 「처음 보는 사람」 경로

- 합의된 제한: K35 · 결정적 시험 대체 아님 · 발견은 재현 시나리오로 승격 · **미포함 경로 실재 확인 먼저** · 탐색 쪽은 결함 후보와 재현 절차만 낸다(PASS/FAIL 안 냄).
- **0단계(환경 없이 · 읽기 전용)**: 대상 화면의 사용자 경로 목록 ↔ 기존 E2E · 시나리오가 걷는 경로 대조. **미포함 경로 0 ⇒ G9 중단**(불채택 사유 기록).
- **대상 화면**: 대표 지정(§13-④).
  - 가벼운 쪽 = 랜딩 — DB 없이 뜬다(실측)
  - ERP 화면이면 샌드박스 안 별도 DB(합성 데이터)가 필요 ⇒ 자원상 2단계로 미룬다
- 실행: 탐색형 브라우저 스킬이 「처음 보는 사람」으로 대표가 고른 과제 1개를 수행 · 2회.
- 대조군:
  - 같은 빌드에서 기존 결정적 시나리오(있으면)가 잡는 것과 겹치는지
  - 사본에만 **심은 결함 1건**(제안) — 찾으면 탐지력 확인 · 못 찾으면 「검출 0」을 해석할 수 없다
- **판정 주체 ≠ 같은 모델**. 후보 = 대표 · HQA · 외부 GPT팀(현행 PR 댓글 통로).
  - 지정 = 대표 결재(§13-⑤). **미지정이면 G9 실행 안 함**(6832751308)
- **지표**: ① 판정자가 확인한 새 결함 수 ② 오탐률 ③ 재현 시나리오로 승격된 수 ④ 토큰 · 시간.
- **합격선(제안)**:
  - 확인된 새 결함 ≥ 1 **그리고** 심은 결함 검출 **그리고** 오탐률 ≤ 50%
  - 검출 0 = 불채택(토론 기록 기준 · §14-③ 확인 필요)

## §8 [UI] 디자인 스킬 3안 비교 — 랜딩 화면 1개

- 합의된 제한: 상시 호출 아님 · 승인 과제에서만 · 3안 비교 뒤 채택 · 공식 디자인 스킬 = 랜딩 한정 비교 · ERP · 온보딩 · 반응형 = **히트판 전용** 우선.
- 대상: 랜딩 화면 **1개**(대표 지정 · §13-④). 과제 문구 1개를 PM 이 쓰고 대표가 확정한다.
- **3안**:
  - (a) 스킬 없음 — 대조군
  - (b) 공식 frontend-design
  - (c) 히트판 전용 UI 스킬 — **아직 없다** ⇒ 시험 전 제작(재료 = 디자인 토큰 파일 · DESIGN_PRINCIPLES · 「처음 보는 사람」 기준). 제작물은 샌드박스 사본 안에만 둔다
- 반복: 안당 2회 · 매 회 새 세션 · 같은 SHA.
- **지표**:
  1. 처음 쓰는 사람이 묻지 않고 끝낸 비율 — 대표 · HQA · **안 이름을 가린 블라인드**
  2. 토큰 이탈 수(정해진 색 · 글꼴 · 간격 밖 사용 건수 · 결정적 검사)
  3. 빌드 errors 0 · warnings 0(#19)
  4. 대상 밖 파일 변경 0
  5. 토큰 · 수정 횟수
- **합격선(제안)**:
  - (c) 무질문 완료율 ≥ (b) **그리고** 토큰 이탈 (c) < (a) · (b)
  - 3 · 4 위반 = 그 안 불합격
  - 「좋아 보인다」 같은 정성 결론 = 불합격(PRD §5)
- 산출물(화면 · 사본 diff)은 결과 폴더로만 나온다. **실제 랜딩 반영은 별도 작업 · 별도 결재.**
