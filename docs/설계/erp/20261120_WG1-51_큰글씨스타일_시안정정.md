## §1 [셈바탕] 글자 폭 · 칸 폭 — 실측과 규칙
- 글자 폭(em = 글자 크기 1pt 당) · 맑은 고딕 보통: `0`~`9` = 0.5508 · `,` `.` = 0.2188 · `-` = 0.4102 · 한글 음절 = 1.000 · 줄 높이 = (2229+495)/2048 = 1.330. 굵게: 숫자 0.5796 · 쉼표 0.2617(머리 글자에만 씀).
- 견본 글자 폭(em): `1,234,567,890` = `9,999,999,999` = **6.1641** · `123,456,789` = 5.3945 · `1,000,000.0` = **5.0625** · `999` = 1.6523 · `-1,234,567,890` = 6.5742 · 11자리 `12,345,678,901` = 6.7149.
- [4] F1 의 셈(부가세 9자리 59.3pt · 단가 10자리 67.8pt · 수량 55.7pt @11pt)과 이 실측이 소수 첫째 자리까지 같다 — 셈 바탕 일치.
- **칸 안 폭** = 칸 폭 − 좌우 안쪽 × 2. 안쪽은 `show_border=0` 이면 +1(`:767~769`) → 셈은 **테두리 끔(최악)** 으로 하고, 남는 폭 ≥ 1.0pt 를 둔다(선 굵기 반 0.375 · 반올림 흡수).
- 칸 폭 = A4 세로 595.28pt − 좌우 여백(기본 20mm = 56.69pt × 2) = **481.89pt**(본문 폭 W). 고정 칸 합이 W 를 넘으면 상대 칸이 0 아래 → 배치 엔진 동작 미측정 → §4 폭 모자람 규칙으로 막는다.
- 줄바꿈 판정 = 글자 폭 > 칸 안 폭. QuestPDF 는 칸 안 폭을 넘는 숫자 낱말을 접는다(E⑵ 명세 §3 「배치 엔진 기본 줄바꿈」). 그래서 「줄바꿈 0」 = 「글자 폭 ≤ 칸 안 폭」 하나로 정적 보장된다. 종이 확인 = M4.
