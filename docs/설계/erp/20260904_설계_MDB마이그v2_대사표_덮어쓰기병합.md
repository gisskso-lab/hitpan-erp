## 0. 사장님 오더 (2026-09-04 원문)

> 1. 히트판erp에서 마이그레이션 후 레거시 히트판에서 뽑는 값이랑 같은 값이 나와야 하고
> 2. 마이그레이션 속도도 굉장히 중요함.
> 3. 안정적으로 데이터 정합성, 무결성이 맞아야 함.
> 4. 마스터자료, 판매자료, 매입자료, 계산서, 회계, 재고, 등 모든 자료가 맞아야 함.
> 5. 히트판ERP에는 있고, 레거시에 없는 기능들은 NULL값으로 남겨둬야 하고,
> 6. 마이그레이션 옵션이 두개가 되어야 함. 1덮어쓰기, 2병합
> 7. 편리해야함. 폴더경로의 주소를 붙여넣기도 할수있게, 파일경로를 직접 찾을 수 있게.
> 8. 히트판ERP의 BOM은 레거시 히트판의 셋트조립과 동일한 기능을 함.

## 1. 대원칙 (바꾸지 않는 것)

1. **레거시 그대로** — 워크플로우·FK 정합이 안 맞아도 그대로 가져온다(5/14 사장님 결재). 수주·발주 소급 생성 금지(8/27). 반품은 레거시 모양(음수 라인) 그대로(Q5).
2. **확정 동작을 태우지 않는다** — 마이그는 매입확정·판매확정을 **호출하지 않고 결과를 직접 넣는다.** 태우면 재고·회계 이중 반영(8/27 §3). 원장은 DOCFB 직접 이관, 회계는 DOCF7 직접 이관 + `source_type='migration'` 격리.
3. **기존 70% 유지**(5/12 결재 1번) — 6,099줄을 새로 짜지 않는다. 고칠 자리는 선행검증서가 줄 번호로 짚었다(§4).
4. **반자동** — 병합 충돌은 시스템이 고르지 않는다. 제안값 → 사람이 확정(Q8).
5. **대사 없으면 완료가 아니다** — 「이관 완료」 대신 「대사 통과」 가 끝이다. 차이가 있으면 「차이 N건」 으로 끝난다.
6. **테스트 환경에서만 잰다**(#39) — `hitpan_e2e`. 실물 DB 는 읽기만.

## 2. 두 모드 — 덮어쓰기 / 병합

```
[모드 선택]
   ├─ ① 덮어쓰기 ─ 백업(강제) → DataResetService(6/23 화이트리스트, Q7) → 이관(전량 INSERT) → 대사
   └─ ② 병합   ─ 백업(강제) → 충돌 미리보기(마스터) → 사람이 확정 → 이관(키 기준 UPSERT/IGNORE) → 대사
```

| 구분 | ① 덮어쓰기 | ② 병합 |
|---|---|---|
| 쓰는 때 | 전환 첫 이관 · "ERP 에 넣은 게 다 틀렸다, 다시" | 레거시·ERP **병행 사용** 중 레거시 신규분 추가 이관(5/16 결정 8 "diff 마이그") |
| 마스터(업체·상품·사원·BOM) | 초기화 후 INSERT | 자연키(`migrated_source_hash`)로 짝 → **충돌표**(레거시 값 / ERP 값 / 선택) → 확정 후 반영. 기본값 = **ERP 값 보존, 빈칸만 채움**(Q8-A) |
| 거래(명세서·계산서·수금·전표·은행·카드·어음) | 초기화 후 INSERT | `source_id` UNIQUE 로 **있으면 skip, 없으면 INSERT**(현행 IGNORE 유지) — 거래는 덮지 않는다 |
| 원장(stock_ledger · journal_lines) | 초기화(스냅샷 교체 = #3 위반 아님, 6/29 결재 R6 논리) 후 INSERT | INSERT ONLY — skip/INSERT 만 |
| ERP 신규 거래(이관 후 ERP 에서 친 것) | **삭제됨** — 화면에 「ERP 거래 N건이 지워집니다」 명시 + 비번 재확인 | 보존 |
| 보존(두 모드 공통) | 회사정보 · 계정 · 약관동의 · 라이선스 · 기기 · 로그 · 설정 (DataReset 화이트리스트) | 동일 |
| 창고 | 이관 원장 = **MAIN**(Q9) | 동일 |

🔴 **병합의 첫 실행은 덮어쓰기와 같아야 한다** — 빈 DB 에 병합하면 결과가 덮어쓰기와 1행도 다르면 안 된다 (게이트 G-M1).

## 5. 흐름 · UI (오더 7)

```
[1] 원본 지정 ── ⓐ 경로 붙여넣기(현행)  ⓑ 찾아보기(서버측 탐색기: 드라이브→폴더, MDB 3개 있는 폴더에 ★)  ⓒ 업로드(zip/3파일, 다른 PC 접속용)

[3] 모드 ─── ① 덮어쓰기(경고: ERP 거래 N건 삭제 · 비번) / ② 병합(마스터 충돌표 → 확정)

        ↓

        ↓
[5-2] 2단계 거래 (백그라운드) ── PANDATA 14잡 병렬 + POTHER → 리빌드 → 진행카드(현행 SignalR)
        ↓
[6] 대사표 ── 9항목 ✅/❌ · 차이 목록 다운로드 · 「대사 통과」 또는 「차이 N건」
```

- 문구는 개발용어 0 (`feedback_no_dev_jargon_customer_facing`): "마이그레이션" 대신 화면은 **"기존 히트판 자료 가져오기"**(현행 제목 유지).

## 6. NULL 규칙 (오더 5)

| ERP 컬럼 성격 | 값 | 예 |
|---|---|---|
| nullable · 레거시에 없음 | **NULL** | `default_warehouse_id` · `category_id` · `supplier_default_id` · `employees.user_id`(8/11 결재: 계정 없음 허용) |
| NOT NULL DEFAULT · 레거시에 없음 | DDL 기본값 (NULL 불가) | `purchase_price 0` · `is_active 1` |
| NOT NULL · 기본값 없음 · 레거시에 없음 | 코드가 넣지 않는다 → **DDL 을 NULL 허용으로**(5/14 예외 ④) | 발견 시 DB-1xx 로 |
| 레거시에 있는데 ERP 에 자리 없음 | 버리지 않고 `memo` 또는 `legacy_*` 컬럼 (있는 것만) | `RT_SON/RT_KUM`(Q12) |
| 이관 행 식별 | `source_type='migration'` + `source_id` + `migrated_source_hash` (현행 유지) | 전 표 |

🔴 하드코딩 금지 목록(현행에서 걷어낼 것): `item_type='product'` 는 유지(레거시도 구분 없음) · `safety_stock 0` 은 DEFAULT 로 위임 · `status='confirmed'` 는 유지(레거시 = 확정본).

## 8. BOM = 셋트조립 (오더 8)

- 현행 매핑 유지: `DOCRT.(RT_PUM,RT_KU)` → `bom_headers.product_item_id` · `RT_RPUM/RT_RKU` → `bom_items.material_item_id` · `RT_UNIT` → `qty` · `RT_ABS` → `loss_rate` · `RT_GU` → `memo` · 자재 미등록 시 `MIG-AUTO-ITEM` 자동 등록(#78, 유지).
- `DOCFS.S_SET`(0/1/2/3): 셋트 여부·유형 플래그로 보임. **뜻 확인 후** `items.item_type`(현행 'product' 하드코딩) 또는 `memo` 에 반영(Q12).
- `RT_SON/RT_KUM`(구성 원가·금액): ERP `bom_items` 에 자리 없음 → Q12 (컬럼 추가 = DB-1xx · #1 추가만 / 또는 memo).
- 9/4 작20 창고결정 3단은 **이관 BOM 에도 그대로** 적용된다(마스터 기본창고 NULL → MAIN).

## 9. 속도 설계 (오더 2)

| 단계 | 설계 |
|---|---|
| 베이스라인 | **첫 실측**: `hitpan_e2e` + 이 MDB 3개 → 표별 초 기록(`migration_jobs.table_progress`) → 문서화. 기록 0건인 상태에서 목표를 말하지 않는다 |
| 1단계 분리 | 마스터 4표+COSTNO 를 별도 잡으로 → 완료 즉시 화면 열림(5/16 결재). 2단계는 백그라운드 잡 + 진행카드 |
| 병렬·BulkCopy | 현행 유지(14잡 `Task.WhenAll` · TEMPORARY stage → `INSERT IGNORE SELECT`). 5/14 사고 재발 방지: 표 단위 tx · 청크 |

| 중단·재개 | `migration_checkpoints` 를 **실제로 쓴다**(표 단위 완료 기록 → 재실행 시 완료 표 skip). 지금은 DDL 만 있고 코드 0 |
| 타임아웃 | 목표(10분)와 타임아웃(24h) 분리(#26) · 10/30/60분 Y/n 현행 유지 |
