# 랜딩페이지 상세 PRD

> 작성일: 2026-05-06 | 상태: 확정

---

## 목적
잠재 고객이 히트판을 발견하고 **가입 → 결제 → 설치**까지 끊김 없이 완료하는 단일 경로.

---

## 페이지 목록 및 흐름

```
/ (홈)
  ↓ "무료 체험 시작" 또는 "지금 구매"
/pricing (요금제 선택)
  ↓ 요금제 클릭
/signup (회원가입)
  ↓ 가입 완료
/signup/verify (이메일 인증)
  ↓ 인증 완료
/payment (결제)
  ↓ 결제 완료
/welcome (설치 준비 중)
  ↓ 이메일 수신 (라이선스 키 + 다운로드 링크)
/download (다운로드 안내)
```

---

## 페이지별 상세 요구사항

### / (홈)
- 히트판 핵심 가치 3줄 요약
- "설치 5분, 공유기 설정 없음" 셀링 포인트
- 무료 체험 CTA 버튼
- 요금제 간략 비교표
- 고객 후기 (베타 이후)
- 대리점 신청 링크

### /pricing (요금제 선택)
| 항목 | 베이직 | 스탠다드 | 프리미엄 |
|------|--------|---------|---------|
| 월 요금 | 29,000원 | 59,000원 | 100,000원 |
| 기기 수 | 1대 | 3대 | 무제한 |
| 사용자 수 | 3명 | 10명 | 무제한 |

- 요금제 클릭 → /signup 으로 이동 (선택 요금제 파라미터 전달)

### /signup (회원가입)
필수 입력:
- 이메일 (ID로 사용)
- 비밀번호 (8자 이상, 영문+숫자+특수문자)
- 회사명
- 대표자명
- 연락처

약관 동의 (가입 시):
- [필수] 서비스 이용약관
- [필수] 개인정보 처리방침
- [필수] 개인정보 처리 위탁
- [선택] 마케팅 정보 수신

계정명 자동 생성:
- 회사명 기반 → hitpan-{계정명}.kr 도메인으로 사용
- 중복 시 숫자 자동 부여

가입 완료 → 이메일 인증 링크 발송 → /signup/verify 이동

### /signup/verify (이메일 인증)
- "인증 이메일을 발송했습니다" 안내
- 재발송 버튼 (60초 쿨다운)
- 인증 링크 클릭 → /payment 이동

### /payment (결제)
- 선택한 요금제 표시
- 토스페이먼츠 결제창 호출
- 결제 성공 → 백오피스 프로비저닝 트리거 → /welcome 이동
- 결제 실패 → 오류 안내 + 재시도

### /welcome (설치 준비 중)
- "히트판 설치 환경을 준비하고 있습니다 (약 2분)"
- 진행 상태 표시 (DNS 생성 → 터널 발급 → 이메일 발송)
- 완료 시 → "이메일을 확인해주세요" 안내

### /download (다운로드 안내)
- 라이선스 키 표시 (이메일 링크로 진입)
- EXE 다운로드 버튼
- 설치 가이드 (3단계 이미지)
  1. EXE 실행
  2. 라이선스 키 입력
  3. 설치 완료 후 브라우저 자동 오픈

---

## 이메일 발송 목록

| 시점 | 제목 | 내용 |
|------|------|------|
| 가입 시 | 이메일 인증 | 인증 링크 |
| 결제 완료 | 히트판 설치 준비 완료 | 라이선스 키 + 다운로드 링크 |
| 설치 완료 | 히트판 시작 가이드 | 첫 사용 안내 |

---

## 프로비저닝 흐름 (결제 완료 후 백그라운드)

```
결제 완료 이벤트
  → 백오피스 프로비저닝 큐 적재
  → [비동기]
    ① Cloudflare API: hitpan-{계정명}.kr CNAME 생성
    ② cloudflared: 터널 생성 + credentials 발급
    ③ DB: 테넌트 슬롯 생성
    ④ 라이선스 키 생성 (UUID)
    ⑤ 이메일 발송
  목표: 2분 이내 완료
  실패 시: 재시도 3회 → 운영팀 알림
```

## 비기능 요구사항
- 가입부터 다운로드 링크 수신까지 5분 이내
- 모바일 반응형 필수 (사파리·크롬)
- SEO 최적화 (홈·요금제 페이지)
- 페이지 로딩 3초 이내
