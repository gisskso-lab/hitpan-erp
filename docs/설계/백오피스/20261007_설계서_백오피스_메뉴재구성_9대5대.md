## §1 [전제] 설계가 서 있는 실측 (전부 2026-10-07 존 직접 확인)

1. **실물 사이드바 = `Components/Layout/BackofficeSidebar.razor` 단 하나.**
   `BackofficeLayout.razor:5` · `PlatformLayout.razor:16` · `ResellerLayout.razor:5` 셋 다 `<BackofficeSidebar />`.
   `PlatformSidebar.razor`(124줄)·`ResellerSidebar.razor`(67줄)·`NavMenu.razor` 는 **참조 0건 = 죽은 파일 3개**(정본 §0 정정 블록과 일치).
2. 역할 축은 JWT 클레임 **`account_type`**(`BackofficeSidebar.razor:99-101`): `platform_admin`/`platform_owner`=본사 · 그 외(대리점 `reseller_admin`)=else 블록.
3. 🔴 지금 대리점(else 블록 `:68-75`)의 메뉴는 **한 줄뿐이고 링크가 `/admin/dashboard`(본사 경로)**.
4. 본사 화면 전부 `@layout PlatformLayout`. 대리점 실물 2화면(`ResellerCustomers`·`ResellerSettlement`)은 **`@layout` 줄이 없어** 기본 `MainLayout`(사이드바 없음)으로 뜬다 — 메뉴를 달려면 레이아웃 지정 1줄이 필요하다.

6. ⚠️미확인: 로그인 성공 후 이동 경로(코드에서 `NavigateTo` 미발견 — 게이트 실측 때 확인) · `platform_owner` 값 발급 길 0(정본 §0 — 본 설계는 노출 조건을 안 바꾼다, 별건).
