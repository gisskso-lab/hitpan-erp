## §1 [통과근거] 추적성 + 독립성 두 칸 (HQA 사전협의 #850 요청 6970488093 → 회신 6970680614 · 15:10 KST)
> 요청한 기준: **「표본을 만들고 판독한 코드 전부가 고정 해시로 식별되고, 그 기록이 원자료에 남아 HQA 가 사후 대조할 수 있다」**
> HQA 회신(원문): 「별건 A 선행안과 ①~④에 이견 없습니다. 해시 식별은 추적성의 근거입니다. 독립성 판정에는 HQA가 같은 원자료로 결과를 별도 대조할 수 있어야 하며, 설치 잡 분리 시에도 측정 잡으로 넘어오는 파일의 무결성을 확인해야 합니다. ⑤는 매 회차 동일 검출 경로를 확인할 수 있도록 포함하는 안에 동의합니다. 음성 시험 데이터와 본 표본은 구분해 주세요. 1바이트 시험의 v5 이관에 이견 없습니다. 합격 판정은 실측 증거 대조 후입니다.」
> → 통과 근거를 **§1-1 추적성(해시 식별)** 과 **§1-2 독립성(HQA 가 같은 원자료로 별도 재판독 · 대조)** 두 칸으로 나눈다. 둘 다 채워져야 통과 근거가 선다.

### §1-1 추적성 — 표본을 만들고 판독한 코드가 고정 해시로 식별되고 원자료에 기록된다

| 코드 | 고정 해시(어디에) | 원자료 기록(무엇) | HQA 사후 대조 |
|---|---|---|---|
| 장치 스크립트 전부(워크플로 · `tools/hqa-s4-measure/`) | 장치 커밋 SHA · v5 묶음 파일별 blob | run.json `device_commit` · `github_sha` · M0 `m0-assert.json` | 원자료 커밋 부모 사슬 = 장치 커밋 · 묶음 대조 |
| 판독 코드 4파일(`judge.js` · `rules.json` · `mask.js` · `hqa-gate.js`) | **워크플로 안 고정값**(판독 직전 단언 · §5-1) | run.json `judge_sha256` · `rules_sha256`(기록 시점) + `m7-pin.json` 참거짓(판독 직전) | 두 시점 모두 = v5 묶음 값 |
| 브라우저 몰기 코드(자동화 패키지 + 의존) | **잠금 파일 무결성 값**(장치 커밋 안 `pw/package-lock.json`) | `m3-npm-tree.json`(이름 · 판 · 받은 주소) · 잠금 일치 참거짓 · 스크립트 끔 참거짓 | 잠금 파일 = 장치 나무 · 받은 주소 = 공개 저장소 |
| 브라우저 · 시험 앱 | `expected-sums.txt`(바뀌지 않음) | `m1-bundle.json`(바뀌지 않음) | 기존 그대로 |
| 시스템 꾸러미(라이브러리 · 글꼴) | 고정 안 함 — **판 = 서명된 배포판 색인이 해시를 가짐** | `m2-installed.txt`(이번 설치로 생긴 이름 · 판 · 아키텍처 전부 · 의존 포함) · `m2-apt-history.txt` | 같은 이름 · 판의 공개 색인 해시 · 런 사이 판 차이 |
| 실행기 런타임(node · git · bash) | 이미지 판(run.json `runner`) | M3′ `m3g-guard.json` 「설치 앞뒤 같음」 참거짓 · 판 글자 | 이미지 판 · 앞뒤 같음 |

- 이 표의 칸 하나라도 원자료에 없으면 그 칸 = **미측정 = 합격 근거 0**(거짓 초록 금지).
- 시스템 꾸러미 행은 「고정 해시」 가 아니라 「판으로 식별 + 배포판 서명 색인」 이다 → HQA 가 이 행을 기준 충족으로 보는지 **확인 필요(§7 Q1)**.

### §1-2 독립성 — HQA 가 같은 원자료로 결과를 별도 재판독 · 대조한다 (v5 공개에 방법 · 입력 · 기대 출력을 미리 적는다)
| 칸 | 내용 |
|---|---|
| 방법 | 원자료 커밋을 받아 **패키지 설치 없는 환경**(node 기본 모듈만)에서 장치 커밋의 판독기로 다시 판독 → 장치가 낸 verdict 와 대조. 판독 코드 4파일은 외부 꾸러미를 부르지 않는다(S5 · `judge.js` 는 node 기본 모듈 + `mask.js` · `hqa-gate.js` 만) |
| 입력 | 원자료 커밋의 `samples.jsonl` · `withheld.json` / 장치 커밋의 판독 코드 4파일(sha256 = §1-1 고정값 · 먼저 대조) / 명령 = 워크플로 M7 단계와 같은 인자(`--rules` · `--samples` · `--out` · `--withheld`) |
| 기대 출력 | 재판독 verdict = 원자료 `verdict-device.json` 과 같음(sha256 같음 · 시각 같은 런마다 다른 칸이 있으면 그 칸 이름을 v5 공개에 미리 적고 나머지 전 칸 같음 — §7 Q9) · run.json 회차 줄 `verdict_sha256` 와도 같음 |
| 셈 | HQA 재판독 결과만 독립성 증거로 센다(CTO J1-2 · J2-ⓑ) · 개발 PC 결과 단독 = 참고 · 다르면 그 회차 판독 = 합격 근거 0 |
| 닫는 범위 · 못 닫는 범위 | 판독 영향 = 닫음. 표본 수집(브라우저 몰기)은 실행기에서만 일어나 재실행 불가 → §1-1 추적성(잠금 무결성 · 설치 기록 · M3′ 단언)으로 받친다 · 이 한계를 v5 공개에 그대로 적는다 |
| 음성 시험 데이터 | ⑤ 음성 시험 결과는 본 표본과 **폴더 · 이름으로 구분**(§5-5 ⓖ) · 판독기 입력에 들어갈 길 0 |
