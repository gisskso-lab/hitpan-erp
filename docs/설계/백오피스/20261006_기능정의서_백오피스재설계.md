## §1 [틀 — 8단계 + 주심 보충 2단계]
- 틀 = 사장님 채택 8단계(요구사항정의서 R-3). 모든 F 는 R-1 존재 이유 ①(구독·CS·영업) 또는 ②(실적·정산)에 닿는다.
- 주심(래리 Z1) 보충 2단계: **운영 관찰**(4단계 뒤) · **해지·미납·환불**(변경↔실적 사이). ERP 매니저는 별도 화면 반려 — 기존 화면에 얹자고 반론(회의록 §4) ⇒ 단계는 그릇으로 두되 **화면 형태는 쟁점-4** — 설계가 정하지 않는다.
- **공통 요구(🟢별건 결재 10/6 · 작7 §0)**: **백오피스 화면 각 데이터 시각화(차트)** — 현황(F-6·F-13·F-20)·순위(F-33)·정산(F-34)·건강판(F-36·F-37) 비고에 「시각화」 표시.
