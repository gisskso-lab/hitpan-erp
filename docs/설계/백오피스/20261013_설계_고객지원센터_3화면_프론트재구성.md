## §3 화면별 설계

### §3-0 세 화면이 공유하는 틀 (집안 관례 그대로 · CSS 신설 0건)

`BoPageHeader`(Title+Subtitle+Actions) → `BoFilterBar` → `div.bo-list-section`(머리+총건수) → `MudDataGrid`(Dense·Hover·`MudDataGridPager`) → 빈 상태 `BoEmptyStateCard`. 색·여백은 `design-tokens.css` 변수.

🔴 **이 차수의 본체 = 「세로로 쌓는다」를 「좌우로 나눈다」로 바꾸는 것.** 지금 `/admin/cs` 는 ①전화접수 패널 ②쪽지 패널(+보관기한) ③필터 ④목록 ⑤상세 ⑥백과사전 초안이 **한 줄로 아래로 쌓인다**. 행을 누르면 눈이 아래로 내려갔다가 다음 행을 보려고 다시 올라와야 한다.

**왜 읽기 쉬운가** — ① 고른 행과 상세가 **같은 눈높이**다(스크롤 왕복 0). ② 상단 토글 패널 2개가 사라져 **필터와 목록이 첫 화면 안에** 들어온다. ③ 상세의 주작업(읽기→답)이 위에서 아래 한 줄기고, 단추 11개는 접힌 「처리」 안으로 내린다.

**칼럼 8개 → 6개** (버리는 게 아니라 **옮긴다** — 정보 손실 0)

| | 칸 | 근거 |
|---|---|---|
| 남긴다 | 고객사 / 분류(2줄: 분류+7모양) / 접수 경로 / 상태 / 접수 / 답 | 6칸 모두 **상시 값이 있다** |
| 옮긴다 | **응대**(`handledVia`) → 상세 「처리」 | 세 값 중 하나이고 **완료로 넘기려고 채우는 입력칸**이다. 목록에선 거의 `-` 가 찍힌다(`HandledViaLabel` 의 `_ => "-"`). 읽을 정보가 아니라 **할 일** |
| 옮긴다 | **평가**(`rating`) → 상태 칸 안 작은 표식(★좋아요) | 고객이 매긴 뒤에만 값이 생긴다. 같은 사실을 **진행 단계 ④**와 **하단 띠**가 이미 센다 ⇒ 칼럼 하나를 상시 `-` 로 두지 않는다 |

**빈 상태** — `Title="접수된 A/S 가 없습니다"` / `Description="고객사 ERP 의 「CS 요청」 쪽지와, 직접 적어 넣은 A/S 가 이곳에 모입니다."` (🔴 `:254` 조사 오류 "CS 창구**이** 없습니다" 교정)

**왜 읽기 쉬운가** — ① 오늘 본문은 목록 셀 안에 `max-width:360px` 로 접혀 **행 높이가 들쭉날쭉**하다(`:165`). 셀을 **한 줄로 자르고** 전문을 오른쪽에서 읽으면 표가 가지런해진다. ② 자주 안 쓰는 보관기한·폐기 후보를 머리의 `[보관기한]` 다이얼로그로 내린다(오늘은 발신 패널 **안**에 섞여 있어 공지를 쓰려고 열면 설정이 함께 나온다). ③ 쓰기는 다이얼로그(R1) ⇒ 화면이 늘 「쌓인 것을 보는 자리」로 고정된다.

**칼럼** — 받는 고객사 / 종류 / 제목·내용(한 줄) / 쓴 때 / 상태. 상태 낱말은 **전달 대기 · 전달됨 · 취소됨 · 폐기됨** 넷 고정(§0-1 — 「폐기됨」은 서버가 이미 주는데 화면 모델이 안 받아 안 보였다. `OutboundRow` 에 `PurgedAt`·`PurgeReason` 2칸을 **더한다** · 서버 0줄).
🔴 **「보냈습니다」라고 쓰지 않는다** — Snackbar 는 「전달 대기함에 넣었습니다 — 수신 통로가 열리면 자동으로 나갑니다.」(기존 문구 유지 · `CsAdminController.cs:541-546` 과 같은 말).
**필터의 정직한 한계** — 서버 `GET api/admin/cs/outbound` 는 `?state=pending|delivered|canceled` 만 받고 **`purpose` 필터가 없으며 `LIMIT 200`**(`:583-585`) ⇒ ① 전달 상태는 **서버 필터** ② 종류는 **받아 온 200건 안에서만** 거른다 ⇒ 목록 머리에 **「최근 200건 중 N건」**이라고 적는다(R4). 서버 쿼리는 0줄 손대지 않는다.
**빈 상태** — 「아직 보낸 공지가 없습니다」 / 「「공지 쓰기」로 고객사에 보낼 공지를 적으면 이곳에 쌓입니다.」 · **실패 문구** 「공지 목록을 불러오지 못했습니다 — 잠시 뒤 「조회」를 다시 눌러 주세요.」 (그 밖은 R6)
