## 1. 목적

소프트웨어 통신 무결성을 넘어 **물리 하드웨어 사고**까지 대응. 디스크 손상·정전·메모리 비트 플립으로 인한 데이터 무결성 위협 사전 감지.

## 2. 3축

### 축 A. 디스크 SMART 모니터링
HDD/SSD 수명·온도·배드섹터 사전 감지.

### 축 B. UPS (무정전 전원장치)
정전 시 자동 셧다운 + 데이터 손실 0.

### 축 C. 메모리 ECC 또는 메모리 진단
비ECC 환경에서도 정기 진단 + 알림.

## 3. 축 A — 디스크 SMART 명세

### 3-1. PowerShell 자동 점검 (워치독 통합)

```powershell
# 매일 03:00 자동 실행
Get-PhysicalDisk | Select-Object FriendlyName, MediaType, HealthStatus, OperationalStatus
Get-StorageReliabilityCounter -PhysicalDisk (Get-PhysicalDisk) |
    Select-Object DeviceId, Wear, ReadErrorsTotal, WriteErrorsTotal, Temperature
```

### 3-2. C# 통합 (워치독 BackgroundService)

```csharp
public sealed class DiskHealthWorker : BackgroundService {
    protected override async Task ExecuteAsync(CancellationToken ct) {
        while (!ct.IsCancellationRequested) {
            try {
                await CheckDisksAsync(ct);
            } catch (Exception ex) {
                _logger.LogError(ex, "[Disk] SMART 점검 실패");
            }
            await Task.Delay(TimeSpan.FromHours(6), ct);  // 6시간 주기
        }
    }

    private async Task CheckDisksAsync(CancellationToken ct) {
        var psi = new ProcessStartInfo("powershell.exe",
            "-NoProfile -Command \"Get-PhysicalDisk | ConvertTo-Json\"") {
            UseShellExecute = false,
            RedirectStandardOutput = true,
            CreateNoWindow = true,
        };
        using var proc = Process.Start(psi)!;
        var json = await proc.StandardOutput.ReadToEndAsync(ct);
        await proc.WaitForExitAsync(ct);

        var disks = JsonSerializer.Deserialize<List<DiskInfo>>(json) ?? new();
        foreach (var d in disks) {
            if (d.HealthStatus != "Healthy") {
                _logger.LogError("[Disk] {Name} 비정상: {Health}/{Operational}",
                    d.FriendlyName, d.HealthStatus, d.OperationalStatus);
                await NotifyAdminAsync($"디스크 {d.FriendlyName} 상태 비정상", ct);
            }
        }
    }
}

public sealed class DiskInfo {
    public string FriendlyName { get; set; } = "";
    public string HealthStatus { get; set; } = "";
    public string OperationalStatus { get; set; } = "";
}
```

### 3-3. 임계치 알림

| 항목 | 임계 | 조치 |
|---|---|---|
| HealthStatus | Warning/Unhealthy | 즉시 알림 + 데이터 격리 백업 트리거 |
| Wear (SSD 수명) | 80% 이상 | 30일 내 교체 알림 |
| Temperature | 60°C 이상 | 환기/쿨링 점검 알림 |
| ReadErrors / WriteErrors | 0 초과 | 즉시 격리 백업 + 교체 권장 |

## 4. 축 B — UPS 명세

### 4-1. 권장 UPS 모델 (사장님 결재 후 구매)

| 모델 | 용량 | 백업 시간 | 가격 |
|---|---|---|---|
| APC Back-UPS 700 | 405W | 5분 | 15만원 |
| APC Back-UPS Pro 1000 | 600W | 12분 | 25만원 |
| EATON 5E 1100 | 660W | 10분 | 28만원 |

권장: **APC Back-UPS Pro 1000** (사장님 PC 환경)

### 4-2. UPS 연동 (PowerChute Personal Edition)

- APC 소프트웨어 PowerChute 설치
- 정전 감지 시:
  - 1분 후 사장님 알림 토스트
  - 5분 후 자동 mysqldump + 격리 백업 트리거
  - 8분 후 안전 셧다운 (Windows + MariaDB + cloudflared)

### 4-3. 자동 셧다운 스크립트

```powershell
# UPS-Shutdown.ps1 (PowerChute에서 호출)
# 1. 워치독에 정전 알림
Invoke-WebRequest -Uri "http://localhost:5257/api/system/power-loss" -Method POST -TimeoutSec 5

# 2. MariaDB 안전 종료
Stop-Service MariaDB -Force

# 3. cloudflared 종료
Stop-Service cloudflared -Force

# 4. Windows 셧다운
Stop-Computer -Force
```

## 5. 축 C — 메모리 진단

### 5-1. Windows Memory Diagnostic 정기 실행

```powershell
# 분기별 1회 (3개월) 자동 예약
schtasks /Create /TN "HitPan-Memory-Diagnostic" `
    /TR "mdsched.exe /scheduleboot" `
    /SC MONTHLY /MO 3 /D 1 /ST 03:00 /F
```

사용자에게 사전 알림 후 재부팅 시 진단.

### 5-2. ECC 메모리 권장 (서버급 PC)

사장님 PC가 워크스테이션급이면 ECC 메모리 권장:
- 비트 플립 자동 감지·정정
- DDR5 ECC 32GB: 약 50만원
- 결재 사항 (사장님 PC 업그레이드 시점에 검토)
