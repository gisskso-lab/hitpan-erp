## 3. 축 A — 코드 서명 명세

### 3-1. 인증서 조달

| 항목 | 내용 |
|---|---|
| 인증서 종류 | EV Code Signing Certificate |
| 발급기관 | DigiCert / Sectigo / GlobalSign (3 후보) |
| 비용 | 연 30~70만원 |
| 발급 기간 | 영업일 7~14일 |
| 저장 매체 | HSM USB 토큰 (FIPS 140-2 Level 2) |
| 결재 | 사장님 결재 필요 (회사 명의 + 사업자번호) |

**비EV (OV) 대비 EV 장점:**
- Defender SmartScreen 평판 즉시 부여 (OV는 일정 다운로드 수 누적 필요)
- Windows Update Driver 서명도 가능
- 백신 5종 신뢰도 즉시 상승

### 3-2. 빌드 파이프라인

```yaml
# GitHub Actions 또는 로컬 빌드 스크립트
steps:
  - name: Build HitPanWatchdog
    run: dotnet publish -c Release -r win-x64 --self-contained false /p:PublishSingleFile=true

  - name: Sign HitPanWatchdog.exe (EV cert)
    run: |
      signtool sign /fd SHA256 /tr http://timestamp.digicert.com /td SHA256 ^
        /n "HitPan ERP Co., Ltd." ^
        bin\Release\net8.0\win-x64\publish\HitPanWatchdog.exe

  - name: Verify signature
    run: signtool verify /pa /v bin\Release\net8.0\win-x64\publish\HitPanWatchdog.exe
```

## 4. 축 B — DPAPI 자격증명 보호 명세

### 4-1. 보호 대상

| 자격증명 | 현재 저장 위치 | 위험 |
|---|---|---|
| Cloudflare TunnelSecret | `C:\cloudflared\<tunnel-id>.json` | 평문 JSON (5/15 사고 시 노출 위험) |
| MariaDB root 비밀번호 | `appsettings.json` | 평문 |
| 본사 API 키 (워치독 메타 ping) | `HitPanWatchdog.exe.config` | 평문 |

### 4-2. DPAPI 변환

```csharp
using System.Security.Cryptography;
using System.Text;

public static class DpapiHelper {
    // 현재 사용자 키로 암호화 (machine 단위 격리)
    public static string Protect(string plaintext) {
        var data = Encoding.UTF8.GetBytes(plaintext);
        var encrypted = ProtectedData.Protect(
            data,
            optionalEntropy: null,
            scope: DataProtectionScope.LocalMachine);  // 머신 단위 (서비스 계정 호환)
        return Convert.ToBase64String(encrypted);
    }

    public static string Unprotect(string encryptedBase64) {
        var data = Convert.FromBase64String(encryptedBase64);
        var decrypted = ProtectedData.Unprotect(
            data,
            optionalEntropy: null,
            scope: DataProtectionScope.LocalMachine);
        return Encoding.UTF8.GetString(decrypted);
    }
}
```

### 4-3. 설치 EXE 통합

```csharp
// HitPanInstaller.exe — 설치 마지막 단계
public void EncryptCredentials() {
    // 1. Cloudflare TunnelSecret
    var credPath = $@"C:\cloudflared\{tunnelId}.json";
    var plainCred = File.ReadAllText(credPath);
    File.WriteAllText(
        $@"C:\ProgramData\HitPan\cloudflared.cred",
        DpapiHelper.Protect(plainCred));
    File.Delete(credPath);  // 원본 평문 삭제

    // 2. MariaDB 비밀번호
    var appsettingsPath = @"C:\Program Files\HitPan\appsettings.json";
    var json = File.ReadAllText(appsettingsPath);
    var node = JsonNode.Parse(json)!;
    var connStr = node["ConnectionStrings"]!["Default"]!.GetValue<string>();
    var encryptedConn = DpapiHelper.Protect(connStr);
    node["ConnectionStrings"]!["DefaultEncrypted"] = encryptedConn;
    node["ConnectionStrings"]!["Default"] = null;
    File.WriteAllText(appsettingsPath, node.ToJsonString());
}
```
