## 2. 처방안

### 2.1 표 행 클릭 → 라우팅
```
대시보드 외상·연체 Top 5
  거래처   | 미수금 | 0~30일 | ... | 연체
  서울상회 | 1,100  | 1,100  | ... | 정상   ← 이 행 클릭
                                      ↓
                          /finance/collections?partner={partnerId}
                                      ↓
                          수금·지급 메뉴 → 수금 탭 → 서울상회 행 미리 펼친 상태
```

- 임시 가정: `/finance/collections?partner={partnerId}` (수금) / `/finance/payments?partner={partnerId}` (지급)
- 외상·연체 Top 5는 미수금 = 수금 탭이 자연스러움
