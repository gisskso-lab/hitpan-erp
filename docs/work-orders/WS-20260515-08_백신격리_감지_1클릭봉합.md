## 1. 목적

WS-06/07이 자동 등록을 보장하더라도, 일부 백신(V3 Lite·알약·Norton 등)은 자체 차단 정책이 있어 격리/차단 발생 가능. 사용자 PC에서 격리 발생 시 워치독이 즉시 감지하고 사용자에게 **1클릭 봉합** 화면 표시.

## 2. 격리 감지 3축

### 축 A. 파일 존재 점검
워치독 EXE / cloudflared / MariaDB 핵심 파일이 사라지면 격리 의심.

```csharp
public sealed class QuarantineDetector {
    private static readonly string[] CriticalFiles = {
        @"C:\cloudflared\cloudflared.exe",
        @"C:\Program Files\MariaDB 11.4\bin\mysqld.exe",
        @"C:\Program Files\HitPan\HitPan.API.exe",
        @"C:\Program Files\HitPan\HitPanWatchdog.exe",
    };

    public List<string> DetectMissing() {
        return CriticalFiles.Where(f => !File.Exists(f)).ToList();
    }
}
```

### 축 B. 프로세스 점검
파일은 있지만 시작 직후 종료되면 차단 의심.

```csharp
public async Task<bool> ProcessHealthyAsync(string processName, CancellationToken ct) {
    var procs = Process.GetProcessesByName(processName);
    if (procs.Length == 0) return false;
    // 시작 직후 종료 패턴 감지 (5초 내 종료 시 차단 의심)
    var proc = procs[0];
    if (DateTime.Now - proc.StartTime < TimeSpan.FromSeconds(5)) {
        await Task.Delay(TimeSpan.FromSeconds(5), ct);
        return !proc.HasExited;
    }
    return true;
}
```

### 축 C. 백신 이벤트 로그 점검
Windows Event Log + 백신 벤더별 로그 폴더.

```csharp
public sealed class AntivirusLogScanner {
    // Windows Defender 격리 이벤트
    private const int DefenderQuarantineEventId = 1006;

    public async Task<List<QuarantineEvent>> ScanRecentAsync(TimeSpan window, CancellationToken ct) {
        var events = new List<QuarantineEvent>();
        var query = new EventLogQuery("Microsoft-Windows-Windows Defender/Operational",
            PathType.LogName, $"*[System[EventID={DefenderQuarantineEventId}]]");
        using var reader = new EventLogReader(query);
        EventRecord? rec;
        while ((rec = reader.ReadEvent()) != null) {
            if (rec.TimeCreated > DateTime.Now - window) {
                events.Add(new QuarantineEvent {
                    Vendor = "Defender",
                    Time = rec.TimeCreated ?? DateTime.Now,
                    Description = rec.FormatDescription(),
                });
            }
        }
        return events;
    }
}

public sealed class QuarantineEvent {
    public string Vendor { get; set; } = "";
    public DateTime Time { get; set; }
    public string Description { get; set; } = "";
}
```

## 3. 1클릭 봉합 화면 (Blazor)

```razor
@* HitPan.Web/Pages/SecurityRecovery.razor *@
@page "/security/recovery"
@inject IJSRuntime JS
@inject HttpClient Http

<MudCard Class="ma-4 pa-6" Elevation="3" Style="max-width:640px;margin:auto;">
    <MudText Typo="Typo.h5">백신이 히트판 통신을 차단했습니다</MudText>
    <MudText Class="my-3">
        @if (Quarantined.Count > 0) {
            <text>다음 파일이 격리되었습니다:</text>
            <ul>
                @foreach (var f in Quarantined) { <li>@f</li> }
            </ul>
        }
        아래 1클릭 봉합 버튼을 누르면 자동으로 백신 예외 등록 + 파일 복구를 시도합니다.
    </MudText>

    <MudButton Variant="Variant.Filled" Color="Color.Primary"
               OnClick="RecoverAsync" Disabled="@_busy">
        @if (_busy) { <MudProgressCircular Size="Size.Small" Indeterminate="true" /> }
        @(_busy ? "봉합 중..." : "1클릭 봉합 시작")
    </MudButton>

    <MudText Class="mt-4" Typo="Typo.caption">
        봉합이 안 될 경우 사용 중인 백신 (V3 Lite·알약·Norton 등) 의 격리/차단 목록에서
        'cloudflared.exe', 'mysqld.exe', 'HitPan*.exe' 를 복원 + 신뢰 추가 해주세요.
    </MudText>
</MudCard>

@code {
    private bool _busy;
    private List<string> Quarantined = new();

    protected override async Task OnInitializedAsync() {
        Quarantined = await Http.GetFromJsonAsync<List<string>>("/api/security/quarantine") ?? new();
    }

    async Task RecoverAsync() {
        _busy = true;
        try {
            // 1) Defender 예외 재등록 + 파일 복구 요청
            var res = await Http.PostAsync("/api/security/recovery/run", null);
            if (res.IsSuccessStatusCode) {
                await JS.InvokeVoidAsync("alert", "봉합 완료. 잠시 후 자동 새로고침됩니다.");
                await Task.Delay(3000);
                await JS.InvokeVoidAsync("location.reload");
            } else {
                await JS.InvokeVoidAsync("alert",
                    "자동 봉합 실패. 백신 화면에서 직접 복원해주세요.");
            }
        } finally { _busy = false; }
    }
}
```

## 4. 백신별 수동 봉합 매뉴얼 (UI 하단 링크)

### 4-1. V3 Lite (안랩)
1. V3 Lite 메인 → "격리실"
2. 격리된 cloudflared.exe / mysqld.exe / HitPan*.exe 선택
3. "복원" 클릭 → "복원 + 신뢰 추가" 선택

### 4-2. 알약 (이스트시큐리티)
1. 알약 메인 → "보호 결과" → "격리"
2. 동일 파일 선택 → "복원" → "이 파일을 신뢰합니다" 체크

### 4-3. 네이버 백신
1. 네이버 백신 트레이 아이콘 우클릭 → "격리실 보기"
2. 파일 복원 + "검사 제외" 등록

### 4-4. Norton
1. Norton 360 → "보안 기록"
2. "격리됨" 카테고리에서 파일 찾기
3. "옵션" → "이 파일 복원 및 제외"

### 4-5. McAfee
1. McAfee 보안 센터 → "PC 보안" → "격리된 항목"
2. 파일 선택 → "복원"
