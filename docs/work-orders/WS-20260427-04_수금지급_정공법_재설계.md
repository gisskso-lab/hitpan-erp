## 4. 기술 가이드

### 4.1 백엔드 — 신규 GET 엔드포인트 2개 (read-only)

#### 4.1.1 `GET /api/finance/receivables` (미수금 목록)
**응답** (거래처 단위 그룹 + 전표 펼침용):
```json
{
  "summary": [
    {
      "partnerId": "...",
      "partnerName": "서울상회",
      "outstanding": 1100,
      "aging0_30": 1100,
      "aging31_60": 0,
      "aging61_90": 0,
      "aging90Plus": 0,
      "isOverdue": false,
      "documentCount": 1
    }
  ],
  "documents": [
    {
      "partnerId": "...",
      "deliveryId": "...",
      "deliveryNo": "SD-20260426-002",
      "deliveryDate": "2026-04-26",
      "totalWithVat": 1100,
      "collected": 0,
      "outstanding": 1100,
      "agingBucket": "0_30"
    }
  ]
}
```

**SQL 핵심 (Dapper, INSERT ONLY 헌법 준수, read-only)**:
```sql
-- 전표별 미수 잔액 = (total + vat) - SUM(collections.amount)
SELECT
  sd.delivery_id,
  sd.delivery_no,
  sd.delivery_date,
  sd.partner_id,
  p.partner_name,
  (sd.total_amount + sd.vat_amount) AS total_with_vat,
  IFNULL(c.collected, 0) AS collected,
  (sd.total_amount + sd.vat_amount) - IFNULL(c.collected, 0) AS outstanding
FROM sales_deliveries sd
JOIN partners p ON p.partner_id = sd.partner_id
LEFT JOIN (
  SELECT ref_doc_id, SUM(amount) AS collected
  FROM collections
  WHERE is_active = 1 AND ref_doc_type = 'sales_delivery'
  GROUP BY ref_doc_id
) c ON c.ref_doc_id = sd.delivery_id
WHERE sd.tenant_id = @TenantId
  AND sd.status = 'confirmed'
  AND (sd.total_amount + sd.vat_amount) - IFNULL(c.collected, 0) > 0
ORDER BY sd.delivery_date ASC;
```

#### 4.1.2 `GET /api/finance/payables` (미지급금 목록)
대칭 구조 — `purchase_receipts` ↔ `payments`, `payment_type='purchase'` 필터.

```sql
SELECT
  pr.receipt_id,
  pr.receipt_no,
  pr.receipt_date,
  pr.partner_id,
  p.partner_name,
  (pr.total_amount + pr.vat_amount) AS total_with_vat,
  IFNULL(pay.paid, 0) AS paid,
  (pr.total_amount + pr.vat_amount) - IFNULL(pay.paid, 0) AS outstanding
FROM purchase_receipts pr
JOIN partners p ON p.partner_id = pr.partner_id
LEFT JOIN (
  SELECT ref_order_id, SUM(amount) AS paid
  FROM payments
  WHERE is_active = 1 AND payment_type = 'purchase'
  GROUP BY ref_order_id
) pay ON pay.ref_order_id = pr.receipt_id
WHERE pr.tenant_id = @TenantId
  AND pr.status = 'confirmed'
  AND (pr.total_amount + pr.vat_amount) - IFNULL(pay.paid, 0) > 0
ORDER BY pr.receipt_date ASC;
```

## 8. 미해결 확장 의문 (참고만, 본 작지서 범위 외)

### Q1. 회계 기표 자동 연동?
사장님 가드레일: "건드리지 않음". 본 작지서는 collections/payments INSERT까지만.
회계 자동 분개는 **별도 작지서** (회계 매니저 합류 후).

### Q2. 부분 수금 후 미수 0이 되면 자동 닫힘?
잔액 0이면 목록에서 자동 제외 (SQL의 `outstanding > 0` 필터). 별도 status 컬럼 추가 안 함.

### Q3. 한 거래처 미수 + 미지급 동시 표시?
이중 거래 거래처 — 별도 작지서. 본 작지서는 단방향만.

### Q4. 어음/카드 만기 관리?
결제수단별 만기일 추적은 **별도 작지서**. 본 작지서는 결제수단 기록까지만.

### Q5. 수금/지급 취소 (이미 박힌 행 무효화)?
soft delete(`is_active=0`) 정책 살아있음 — 사장님이 오늘 직접 시연으로 확인.
취소 화면은 **별도 작지서**.

### Q6. 결재함 연동?
지급 큰 금액은 결재 필요할 수 있음 — 결재 워크플로우 연동은 **별도 작지서**.
