## 3. 실측 시나리오 (각 백신 5건)

### 시나리오 1: 신규 설치
1. 깨끗한 Windows 11 + 백신 1종 설치 + 최신 정의 업데이트
2. HitPanInstaller.exe 다운로드 (signed EXE)
3. SmartScreen / 백신 경고 발생 여부 기록
4. 관리자 권한으로 설치
5. **통과 조건:** 격리 0건, 사용자 추가 클릭 0회

### 시나리오 2: 워치독 실시간 모니터링
1. 설치 완료 후 24시간 백신 실시간 모니터링 ON 상태로 방치
2. cloudflared / mysqld / HitPanWatchdog 격리/차단 여부 기록
3. 백신 알림 발생 횟수 기록
4. **통과 조건:** 24시간 격리 0건, 알림 0회

### 시나리오 3: 백신 풀스캔
1. 백신 풀스캔 실행 (수동 트리거)
2. HitPan 경로 4개 스캔 결과 확인
3. **통과 조건:** Threat detected 0건

### 시나리오 4: 격리 발생 시 1클릭 봉합
1. 백신 격리실에 cloudflared.exe 수동 격리 (인위적 시뮬)
2. WS-08 워치독 감지 → SecurityRecovery 페이지 자동 표시 확인
3. 1클릭 봉합 버튼 클릭
4. **통과 조건:** 5분 이내 자동 복구 90% 이상

### 시나리오 5: 백신 업데이트 후 재검증
1. 백신 정의 파일 강제 업데이트
2. 24시간 추가 모니터링
3. **통과 조건:** 업데이트 후에도 격리 0건
