# 작20260430-3 — 등록기기 관리 401 Unauthorized (P0 빠른 트랙)

## 🔴 우선순위
P0 (빠른 트랙)

## 발생 증상
- URL: `https://demo.hitpan.kr/settings/devices`
- 화면: "기기 목록 조회 실패: Response status code does not indicate success: 401 (Unauthorized)"
- 다른 API는 정상 → 등록기기관리 화면만 인증 토큰 헤더 누락

## 진범 추정 (데이비드 박)
- 프론트 단 HttpClient에서 Authorization 헤더 미부착
- 또는 인증 인터셉터가 이 화면에서 우회됨
- 백엔드 [Authorize] 정책 미스매치 가능성

## 담당
- 메인: 프론트 매니저 (DI 등록·HttpClient 패턴 직접 처리)
- 보조: 보안 매니저 (Authorization Policy 매핑)
- 검증: CTO

## 작업 범위
1. `src/HitPan.Web/Pages/Settings/Devices.razor` 또는 등록기기 화면 컴포넌트 grep
2. HttpClient 인스턴스 확인 — 다른 화면과 동일한 인증 인터셉터 적용 여부
3. 백엔드 컨트롤러 [Authorize] 정책 확인
4. 401 → 정상 200 응답 확인
5. **헌법 4조 검증 (DB→백엔드→프론트 끊김 0)**

## 검증 보고서 양식
- 프론트 진입 → 401 발생 X
- 등록 기기 목록 정상 표시 (0건이어도 빈 목록 정상 렌더)
- 캡처: 진입 화면 + 네트워크 탭 200 OK
