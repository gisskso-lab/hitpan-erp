# 작20260430-4 — 비밀번호 평문 노출 차단 (P0 보안)

## 🔴 우선순위
P0 (보안 격상 — 법무팀장·보안매니저 권고)

## 발생 증상
- 사용자(직원) 추가 화면에서 임시 비밀번호가 평문으로 입력란에 표시
- 어깨 너머 노출, 스크린샷 유출, 화면 캡처 자동백업 등 공격 벡터 다수
- **개인정보보호법 §29 안전조치 위반 가능성** (법무팀장)
- **베타 1주 안에 사고 보장** (안랩 40년 보안매니저)

## 담당
- 메인: 보안 매니저 (직접 처리)
- 보조: 프론트 매니저 (UI 변경)
- 검증: CTO + 법무팀장

## 작업 범위
1. 사용자 추가 화면 비밀번호 입력란 → `type="password"` + 토글 아이콘
2. 임시 비밀번호 화면 표시 정책 변경:
   - **A안:** 등록 시 임시 비밀번호 자동 생성 → 직원 이메일/SMS로 발송
   - **B안:** "비밀번호 재설정 링크" 토큰 이메일 발송 (표준 SaaS 패턴)
   - PM·보안 매니저 협의 후 결정 (B안 권장)
3. 어드민 화면에는 "발송 완료" 메시지만 표시 (비밀번호 자체 X)
4. 기존 테스트 데이터 영향 확인

## 검증 보고서 양식
- 화면: 비밀번호란 마스킹 (●●●●●)
- DB: 비밀번호 컬럼 BCrypt/Argon2 해시 확인 (평문 X)
- 이메일/SMS 발송 로그 확인 (헌법 #18 위반 없는지: 본사로 안 보냄)
- 고객 시선: 직원 등록 흐름 = 어드민이 이메일 입력만, 비밀번호는 직원이 직접 설정
