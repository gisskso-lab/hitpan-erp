## 작업 범위

### A. 디자인 토큰 (CSS 변수) 정의
```css
/* Typography */
--font-base: 16px;       /* 기존 14px → 16px */
--font-sm: 14px;
--font-lg: 18px;
--font-table: 15px;       /* 기존 13px → 15px */
--font-heading: 22px;     /* 기존 18px → 22px */
--font-button: 15px;
--line-height-base: 1.6;  /* 기존 1.4 → 1.6 */
--font-family: 'Pretendard', 'Noto Sans KR', sans-serif;

/* Spacing */
--spacing-xs: 4px;
--spacing-sm: 8px;
--spacing-md: 12px;       /* 기존 8px → 12px */
--spacing-lg: 16px;
--spacing-xl: 24px;

/* Visual */
--radius-sm: 6px;
--radius-md: 10px;
--shadow-card: 0 2px 8px rgba(0,0,0,0.06);
```
