# WS-20260515-06 — Windows Defender 예외 자동 등록 + SmartScreen 통과

## 1. 목적

Defender / 백신이 cloudflared·MariaDB·HitPan ERP 프로세스를 차단하지 않도록 설치 EXE가 관리자 권한으로 자동 등록. 헌법 #31 (백신 5종 격리 0) 핵심.

## 2. 예외 등록 대상 3종

| 프로세스 | 경로 | 사유 |
|---|---|---|
| cloudflared.exe | C:\cloudflared\cloudflared.exe | 외부 터널, Defender가 의심 |
| mysqld.exe | C:\Program Files\MariaDB 11.4\bin\mysqld.exe | DB 엔진 |
| HitPan.API.exe | C:\Program Files\HitPan\HitPan.API.exe | 자체 EXE |
| HitPanWatchdog.exe | C:\Program Files\HitPan\HitPanWatchdog.exe | 워치독 |
| dotnet.exe | C:\Program Files\dotnet\dotnet.exe | 일부 환경 |

## 3. 자동 등록 PowerShell (설치 EXE 통합)

```powershell
# HitPanInstaller.exe — 설치 마지막 단계 호출
Add-MpPreference -ExclusionProcess "C:\cloudflared\cloudflared.exe"
Add-MpPreference -ExclusionProcess "C:\Program Files\MariaDB 11.4\bin\mysqld.exe"
Add-MpPreference -ExclusionProcess "C:\Program Files\HitPan\HitPan.API.exe"
Add-MpPreference -ExclusionProcess "C:\Program Files\HitPan\HitPanWatchdog.exe"

Add-MpPreference -ExclusionPath "C:\cloudflared"
Add-MpPreference -ExclusionPath "C:\Program Files\MariaDB 11.4"
Add-MpPreference -ExclusionPath "C:\Program Files\HitPan"
Add-MpPreference -ExclusionPath "C:\HitPanBackup"
Add-MpPreference -ExclusionPath "C:\ProgramData\HitPan"
```

## 4. C# 통합 (설치 EXE)

```csharp
public static class DefenderExclusion {
    public static async Task ApplyAllAsync() {
        var processes = new[] {
            @"C:\cloudflared\cloudflared.exe",
            @"C:\Program Files\MariaDB 11.4\bin\mysqld.exe",
            @"C:\Program Files\HitPan\HitPan.API.exe",
            @"C:\Program Files\HitPan\HitPanWatchdog.exe",
        };
        var paths = new[] {
            @"C:\cloudflared",
            @"C:\Program Files\MariaDB 11.4",
            @"C:\Program Files\HitPan",
            @"C:\HitPanBackup",
            @"C:\ProgramData\HitPan",
        };

        foreach (var p in processes) {
            await RunPowerShellAsync($"Add-MpPreference -ExclusionProcess \"{p}\"");
        }
        foreach (var p in paths) {
            await RunPowerShellAsync($"Add-MpPreference -ExclusionPath \"{p}\"");
        }
    }

    private static async Task RunPowerShellAsync(string command) {
        var psi = new ProcessStartInfo("powershell.exe",
            $"-NoProfile -NonInteractive -ExecutionPolicy Bypass -Command \"{command}\"") {
            UseShellExecute = false,
            RedirectStandardOutput = true,
            RedirectStandardError = true,
            Verb = "runas",  // 관리자 권한 필수
        };
        using var proc = Process.Start(psi)!;
        await proc.WaitForExitAsync();
    }
}
```

## 5. SmartScreen 통과 (헌법 #31)

EV 코드 서명 (WS-03)이 EXE에 적용되어 있으면 SmartScreen 즉시 통과. 비EV (OV)는 일정 평판 누적 필요.

검증:
```powershell
Get-AuthenticodeSignature "C:\Program Files\HitPan\HitPan.API.exe"
# Status = Valid 확인
# SignerCertificate.Subject 에 "HitPan ERP Co., Ltd." 포함 확인
```

## 6. 검증 게이트 (헌법 #31)

| 게이트 | 통과 조건 |
|---|---|
| Get-MpPreference 확인 | ExclusionProcess 4건 + ExclusionPath 5건 |
| Defender Quarantine | 0건 (설치 후 24시간 모니터링) |
| SmartScreen 차단 | 0건 (다운로드 즉시 실행) |
| 검증 시 권한 | 관리자 권한 EXE만 (UAC 1회) |
| 헌법 #29 정합 | 설치 시점 1회 결재 = 봉합 권한 사전 등록 |
