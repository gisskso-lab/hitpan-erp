## 1. 목적

통신 무결성 사용자 인식 영역. 백엔드가 5분 이내 자동 복구하더라도 사용자에게 **상태를 친절하게 알려야** 함. 헌법 #25 (쉽게) + 헌법 #27 (통신 무결성) 동시 만족.

## 2. 사용자 시나리오

### Before (5/15 사고)
- 사용자가 화면에서 데이터 저장 시도
- API 503/Timeout
- 브라우저 에러 페이지 표시
- 사용자 = 본사 연락 → 사장님 패닉 → 7건 평행 봉합

### After (워치독 + 토스트)
- 사용자 화면에 **즉시** 토스트: "통신 점검 중입니다. 1분 후 자동 복구됩니다."
- 워치독 5분 자동 봉합 진행
- 복구 완료 시 토스트: "복구 완료. 안전하게 계속 작업하세요."
- 사용자 = 알아서 잠시 기다림. 본사 연락 0.

## 3. 구현 명세

### 3-1. 통신 상태 모니터링 (HitPan.Web)

```csharp
// HitPan.Web/Services/ConnectionHealthService.cs (신규)
public sealed class ConnectionHealthService : IDisposable {
    private readonly HttpClient _http;
    private readonly ILogger<ConnectionHealthService> _logger;
    private readonly Timer _timer;
    private ConnectionState _state = ConnectionState.Healthy;

    public event Action<ConnectionState>? StateChanged;

    public ConnectionHealthService(HttpClient http, ILogger<ConnectionHealthService> logger) {
        _http = http;
        _logger = logger;
        _timer = new Timer(CheckHealth, null, TimeSpan.FromSeconds(10), TimeSpan.FromSeconds(15));
    }

    private async void CheckHealth(object? state) {
        try {
            using var cts = new CancellationTokenSource(TimeSpan.FromSeconds(5));
            var res = await _http.GetAsync("/api/health", cts.Token);
            UpdateState(res.IsSuccessStatusCode ? ConnectionState.Healthy : ConnectionState.Degraded);
        } catch {
            UpdateState(ConnectionState.Disconnected);
        }
    }

    private void UpdateState(ConnectionState newState) {
        if (_state == newState) return;
        _state = newState;
        StateChanged?.Invoke(newState);
        _logger.LogInformation("[ConnHealth] 상태 변경: {State}", newState);
    }

    public void Dispose() => _timer.Dispose();
}

public enum ConnectionState { Healthy, Degraded, Disconnected, Recovering }
```

### 3-2. SignalR Hub (실시간 워치독 상태 수신)

```csharp
// HitPan.API/Hubs/WatchdogHub.cs (신규)
public sealed class WatchdogHub : Hub {
    // 워치독 EXE가 메타 ping 발송 시, 본사 API에서 SignalR로 모든 클라이언트에 broadcast
}

// HitPan.Web/Services/WatchdogClient.cs
public sealed class WatchdogClient {
    private readonly HubConnection _hub;

    public event Action<string>? OnRecoveryStarted;
    public event Action<string>? OnRecoveryComplete;

    public WatchdogClient(NavigationManager nav) {
        _hub = new HubConnectionBuilder()
            .WithUrl(nav.ToAbsoluteUri("/hubs/watchdog"))
            .WithAutomaticReconnect(new[] {
                TimeSpan.FromSeconds(2),
                TimeSpan.FromSeconds(5),
                TimeSpan.FromSeconds(10),
                TimeSpan.FromSeconds(30),
            })
            .Build();

        _hub.On<string>("RecoveryStarted", msg => OnRecoveryStarted?.Invoke(msg));
        _hub.On<string>("RecoveryComplete", msg => OnRecoveryComplete?.Invoke(msg));
    }

    public async Task StartAsync() => await _hub.StartAsync();
}
```

### 3-3. 토스트 컴포넌트 (MudBlazor)

```razor
@* HitPan.Web/Shared/ConnectionToast.razor *@
@inject ConnectionHealthService Health
@inject WatchdogClient Watchdog
@inject ISnackbar Snackbar

@code {
    protected override async Task OnInitializedAsync() {
        Health.StateChanged += OnHealthChanged;
        Watchdog.OnRecoveryStarted += OnRecoveryStarted;
        Watchdog.OnRecoveryComplete += OnRecoveryComplete;
        await Watchdog.StartAsync();
    }

    private void OnHealthChanged(ConnectionState state) {
        InvokeAsync(() => {
            switch (state) {
                case ConnectionState.Disconnected:
                    Snackbar.Add(
                        "통신 점검 중입니다. 잠시 기다리시면 자동 복구됩니다.",
                        Severity.Warning,
                        config => { config.RequireInteraction = true; config.HideTransitionDuration = 0; });
                    break;
                case ConnectionState.Healthy:
                    Snackbar.Clear();
                    Snackbar.Add("통신 정상", Severity.Success);
                    break;
            }
        });
    }

    private void OnRecoveryStarted(string msg) =>
        InvokeAsync(() => Snackbar.Add($"자동 복구 시작: {msg}", Severity.Info));

    private void OnRecoveryComplete(string msg) =>
        InvokeAsync(() => Snackbar.Add($"복구 완료: {msg}", Severity.Success));
}
```

## 4. UX 카피 (헌법 #25 쉽게)

| 상태 | 메시지 |
|---|---|
| Disconnected | "통신 점검 중입니다. 잠시 기다리시면 자동 복구됩니다." |
| Degraded | "응답이 느립니다. 자동 점검 중입니다." |
| RecoveryStarted | "자동 복구를 시작합니다. 1~5분 소요됩니다." |
| RecoveryComplete | "복구 완료. 안전하게 계속 작업하세요." |
| Healthy | "통신 정상" (3초 자동 닫힘) |

**금지 카피:**
- ❌ "에러가 발생했습니다" (불안 유발)
- ❌ "본사에 연락하세요" (사장님 부담)
- ❌ "TunnelSecret invalid" (기술 용어)
