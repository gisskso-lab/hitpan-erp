## 1. 목적

ERP 화면이 브라우저에서 안전하게 동작. MITM (중간자 공격) + XSS + Clickjacking + 쿠키 도용 + 도메인 위조 차단. 헌법 #27 (통신 무결성) 사용자 영역.

## 2. 5축 헤더 강제

### 축 A. HSTS (HTTP Strict Transport Security)
HTTP → HTTPS 자동 리다이렉트 + 브라우저 캐싱.

### 축 B. CSP (Content Security Policy)
XSS 차단 + 외부 스크립트 화이트리스트.

### 축 C. COOP / COEP (Cross-Origin Opener/Embedder)
SharedArrayBuffer 등 고급 격리.

### 축 D. CORS 화이트리스트
demo.hitpan.kr ↔ api.hitpan.app만 허용.

### 축 E. DNSSEC + CAA 레코드
도메인 변조 + 인증서 위조 방지.

## 3. ASP.NET Core 미들웨어 (HitPan.API)

```csharp
// Program.cs
app.UseSecurityHeaders(policies =>
    policies
        .AddStrictTransportSecurityMaxAgeIncludeSubDomains(maxAgeInSeconds: 60 * 60 * 24 * 365)  // 1년
        .AddContentSecurityPolicy(builder => {
            builder.AddDefaultSrc().Self();
            builder.AddScriptSrc().Self().UnsafeInline().UnsafeEval();  // Blazor WASM 필수
            builder.AddStyleSrc().Self().UnsafeInline();                 // MudBlazor 필수
            builder.AddImgSrc().Self().Data();
            builder.AddFontSrc().Self().Data();
            builder.AddConnectSrc().Self()
                .From("https://api.hitpan.app")
                .From("wss://api.hitpan.app");
            builder.AddFrameAncestors().None();
            builder.AddBaseUri().Self();
            builder.AddObjectSrc().None();
        })
        .AddCrossOriginOpenerPolicy(b => b.SameOrigin())
        .AddCrossOriginEmbedderPolicy(b => b.RequireCorp())
        .AddCrossOriginResourcePolicy(b => b.SameOrigin())
        .AddReferrerPolicy(b => b.StrictOriginWhenCrossOrigin())
        .AddXContentTypeOptionsNoSniff()
        .AddXFrameOptions(b => b.Deny())
        .RemoveServerHeader()
);

// CORS
builder.Services.AddCors(opt =>
    opt.AddPolicy("HitPan", p => p
        .WithOrigins("https://demo.hitpan.kr", "https://*.hitpan.kr")
        .SetIsOriginAllowedToAllowWildcardSubdomains()
        .AllowAnyHeader()
        .AllowAnyMethod()
        .AllowCredentials()));

app.UseCors("HitPan");
```

NuGet: `NetEscapades.AspNetCore.SecurityHeaders`

## 4. 쿠키 보안

```csharp
builder.Services.Configure<CookiePolicyOptions>(opt => {
    opt.MinimumSameSitePolicy = SameSiteMode.Strict;
    opt.HttpOnly = HttpOnlyPolicy.Always;
    opt.Secure = CookieSecurePolicy.Always;
});

builder.Services.AddAuthentication(JwtBearerDefaults.AuthenticationScheme)
    .AddCookie(opt => {
        opt.Cookie.HttpOnly = true;
        opt.Cookie.SecurePolicy = CookieSecurePolicy.Always;
        opt.Cookie.SameSite = SameSiteMode.Strict;
        opt.Cookie.Name = "__Host-HitPan.Auth";  // __Host- prefix = 추가 보호
    });
```
