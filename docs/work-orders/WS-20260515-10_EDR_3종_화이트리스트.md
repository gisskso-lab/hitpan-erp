## 1. 목적

기업 환경 (직원 10명+ 사장님) 에서 EDR (Endpoint Detection and Response) 도입 시 히트판 ERP 호환 가이드. 헌법 #31 (EDR 3종 호환) + 헌법 #18 (본사 데이터 0).

## 2. EDR 3종 대상

| EDR | 벤더 | 한국 시장 점유 |
|---|---|---|
| 안랩 EPP (Endpoint Protection Platform) | 안랩 | 30%+ |
| 한컴 시큐어 | 한컴 | 15% |
| Trend Micro Apex One | Trend Micro | 10% |

기업 직원 PC에 본사 IT 부서가 설치하는 경우가 많음. ERP 설치 후 차단 발생 시 본사 IT가 화이트리스트 등록해야 함.

## 4. EDR별 등록 절차

### 4-1. 안랩 EPP
1. 안랩 관리 콘솔 (V3 Manager 또는 EPP Cloud) 접속
2. **정책 관리** → **응용프로그램 제어** → **신뢰 프로세스**
3. 위 5개 프로세스 추가 + SHA-256 해시 (EV 서명서로 자동 검증)
4. **경로 예외** → 5개 경로 추가
5. **네트워크 정책** → 4개 도메인 추가
6. **정책 배포** → 대상 PC 그룹 선택 → 배포

### 4-2. 한컴 시큐어
1. 한컴 시큐어 관리자 페이지
2. **위협 관리** → **신뢰 응용프로그램**
3. 동일 항목 추가
4. **그룹 정책 적용**

### 4-3. Trend Micro Apex One
1. Apex One Web Console
2. **Agents** → **Agent Management** → **Settings**
3. **Behavior Monitoring** → **Approved List** 추가
4. **Firewall** → **Policies** → 도메인 추가
5. **Deploy**
