## 하지 않는 것 (설계 §2-ⓔ)

- 외부 지식 긁어오기 — 지식은 **CS팀장이 직접 정의**한다
- 자동 승격 — 사람 승인 없이 등재 **0건**
- 다른 테넌트 **티켓 원문**을 문서 근거로 저장
- 이 폴더의 파일을 진실원으로 두기 — 내보내기용 사본일 뿐이다
