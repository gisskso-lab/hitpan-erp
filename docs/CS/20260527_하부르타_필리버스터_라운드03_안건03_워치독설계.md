### Round 3.7 — PM 종합 — 5단계 구체 설계

**WS-28-A — TrustedInstaller 1074 감지 (Windows Update)**
```powershell
Get-WinEvent -FilterHashtable @{LogName='System'; ID=1074} -MaxEvents 1 |
  Where-Object { $_.Message -match 'TrustedInstaller' -and $_.TimeCreated -gt (Get-Date).AddMinutes(-10) }
```
→ 감지 시 재부팅 후 5분 자동 점검 플래그 박제

**WS-28-B — 재부팅 후 자동 점검 (5분)**
- 작업 스케줄러 `At system startup + 30초 delay`
- 4개 서비스 (MariaDB·API·Web·cloudflared) 시작 확인
- 외부 헬스체크 `https://demo.hitpan.kr/health` 200 확인

**WS-28-C — TunnelSecret 무효화 감지 + 자동 재발급**
- cloudflared 로그 `tail`: `Invalid tunnel secret` 패턴 감지
- 즉시 봉합:
  ```powershell
  Move-Item "C:\Users\$env:USERNAME\.cloudflared\$tunnelId.json" "$tunnelId.json.bak_$(Get-Date -Format yyyyMMddHHmmss)"
  cloudflared tunnel token --cred-file "$tunnelId.json" $tunnelId
  Restart-Service cloudflared
  ```

**WS-28-D — cloudflared 서비스 자동 재설치**
- Service 자체 삭제됨 감지 (`Get-Service cloudflared` 실패)
- 자동 재설치:
  ```powershell
  cloudflared service install
  Start-Service cloudflared
  ```

**WS-28-E — 외부 헬스체크 + 정상화**
- 1분 주기:
  ```powershell
  $code = (Invoke-WebRequest -Uri "https://demo.hitpan.kr/health" -TimeoutSec 10).StatusCode
  if ($code -ne 200) { $failCount++ } else { $failCount = 0 }
  if ($failCount -ge 3) { Trigger-FullRecovery }
  ```
