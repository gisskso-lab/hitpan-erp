## §1 왜 10장인가 — 선정 기준

화면은 **140개**(2026-10-20 실측 · `src/HitPan.Web/Pages`). 전부 찍을 수 없고, 찍어도 아무도 안 본다.
그래서 **두 트랙이 같이 쓰는 장**만 고른다.

| 기준 | 뜻 |
|---|---|
| ① **상담 한 번에 보여주는 장** | 영업이 실제로 넘기는 순서 |
| ② **처음 7일에 고객이 들어가는 장** | 온보딩 안내서가 그림을 필요로 하는 자리 |
| ③ **히트판만의 장** | 데이터 주권·자재명세서·원장처럼 설명이 필요한 자리 |

🔴 **①②를 동시에 만족하는 장을 먼저 고른다.** 한 장이 두 곳에서 쓰이면 찍을 장이 절반이 된다.

## §3 규격 — 전부 같게

| 항목 | 값 |
|---|---|
| 창 크기 | **1600 × 900** 고정 (이보다 크면 글자가 작아 보이고, 작으면 표가 잘린다) |
| 배율 | 100% (확대·축소 금지) |
| 형식 | PNG · 테두리 없음 · 그림자 없음 |
| 자르기 | 왼쪽 메뉴 **포함**(어디인지 알 수 있어야 한다) · 브라우저 주소줄 **제외** |
| 가림 | 가상 자료라도 **사람 이름 칸은 가상 이름**으로 채운다 |
| 파일명 | `hp-0N_화면이름.png` (예: `hp-06_BOM자재명세서.png`) — 번호는 §2 그대로 |
| 보관 | 한 폴더 · 같은 판에서 **한 번에** 찍는다(판이 섞이면 글자가 달라진다) |

## §4 🔴 찍을 때 지킬 것

| # | |
|---|---|
| 1 | 🔴 **가상 자료 전용 환경에서만.** 운영 고객 화면·개발 컴퓨터 화면은 **못 쓴다**(#39) |
| 2 | 🔴 **실제 거래처·금액·사람 이름 0건**(K-6) — 예시는 전부 가상 |
| 3 | 🔴 **같은 판에서 10장 한 번에** — 섞이면 메뉴 낱말이 장마다 달라진다 |
| 4 | 🔴 **고치지 않는다** — 화면에 없는 단추를 그려 넣거나 글자를 바꾸면, 고객이 그 화면을 찾는다 |
| 5 | 비어 있는 목록(0건 화면)은 **찍지 않는다** — 제품이 빈 것처럼 보인다 |
| 6 | 찍은 뒤 **O 트랙에 같은 폴더를 알려 준다**(두 번 찍지 않는다) |
