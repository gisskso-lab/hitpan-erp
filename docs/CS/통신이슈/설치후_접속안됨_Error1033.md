# 설치는 끝났는데 주소를 열면 화면이 안 나옵니다 (Error 1033)

| 기술 근거 | [네트워크 진단서 — 원인확정 실측완료](../../검증/20260730_네트워크진단서_터널1033_원인확정_실측완료.md) (네트워크 매니저 마이클) |

| 봉합 반영 버전 | **1.2.45 이상** — 이 버전 이후 설치본은 이 증상이 재발하지 않는다 |

## 0. ⚠️ CS 담당자가 먼저 알아야 할 것

**원인은 실측으로 확정됐다.** 추측이 아니다.

> **고객 컴퓨터에서 연결 프로그램(cloudflared)이 실행되지 않고 멈춰 있었다.**
> 오류가 나서 죽은 게 아니라 **조용히 정상 종료**돼 있었다. 그래서 아무 기록도 남지 않았다.

**중요 — 이 증상은 1.2.45 부터 설치 프로그램이 스스로 고친다.**

| 설치본 | 이 증상이 나나 | CS 대응 |
|---|---|---|
| **1.2.45 이상** | ❌ 거의 안 남 | 났다면 **다른 원인**이다. §7 로 간다 |
| 1.2.44 이하 | ⚠️ 날 수 있음 | **최신 버전으로 다시 설치**하면 해결 (§5) |

> 🔴 **옛 문서에서 바뀐 것**: 종전 안내는 *"고객이 스스로 고칠 수 없다 / 재설치해도 똑같다"* 였다.
> **실측 결과 그게 틀렸다.** 최신 설치본으로 다시 설치하면 **된다.**
> 옛 안내를 그대로 하면 고객을 헛되게 기다리게 한다.

## 1. 고객이 이렇게 말한다

고객이 쓰는 표현 그대로:

- "설치는 다 됐다는데 프로그램이 안 열려요"
- "주소를 치면 이상한 영어 화면이 나와요"
- "에러 1033 이라고 떠요"
- "설치 다 하고 인터넷 주소 눌렀는데 안 돼요"
- "회사 주소로 들어가면 오류가 나요"

## 2. 고객 화면에 보이는 것

```
Error 1033
Cloudflare Tunnel error
```

그 아래 영어 안내문이 길게 나온다. **고객은 이걸 읽지 못한다.** 당황해서 전화한다.

### 숫자로 갈라진다 — 이게 제일 빠른 판별법

| 화면 숫자 | 뜻 | 이 문서 건인가 |
|---|---|---|
| **1033** | 연결 프로그램이 아예 안 붙어 있다 | ✅ **이 문서** |
| **530** | 위와 같은 상태(다른 표기) | ✅ **이 문서** |
| 502 | 연결은 됐는데 프로그램이 꺼져 있다 | ❌ 다른 건 (ERP 미실행) |
| 404 · 500 | 화면·자료 문제 | ❌ 다른 건 |

> 💡 고객이 **"1033"** 또는 **"530"** 을 말하면 이 문서 건이다.

## 3. 첫 응대 (그대로 읽어도 되는 말)

> "네, 확인했습니다. 고객님 컴퓨터가 고장난 건 아니고
> **연결을 담당하는 부분이 멈춰 있는 상태**입니다.
> **최신 설치 파일로 한 번만 다시 설치하시면 해결됩니다.** 제가 안내해 드릴게요."

**핵심 3가지를 반드시 전달한다:**

1. **고객 잘못이 아니다** — 안심시킨다
2. **해결 방법이 있다** — "확인해보겠습니다" 로 끝내지 않는다
3. **얼마나 걸리는지** — 다운로드 + 설치 약 15분

### 이렇게 말하지 않는다 ❌

| 금지 | 왜 |
|---|---|
| "터널이 연결되지 않았습니다" | 개발용어. 고객이 못 알아듣는다 (헌법 #23) |
| "cloudflared 서비스가 죽었습니다" | 위와 같음 |
| "토큰을 못 받으셨네요" | 위와 같음 |
| "인터넷을 확인해보세요" | 인터넷 문제 아니다. 고객을 의심하는 말 |
| "원래 그럴 수 있어요" | 원래 그러면 안 되는 것이다 |
| "다시 설치해도 똑같습니다" | **옛 안내. 이제 틀렸다.** 최신본은 된다 |

## 4. 받아야 할 정보 (3개면 충분)

| # | 물어볼 것 | 고객에게 하는 말 |
|---|---|---|
| 1 | **회사명** | "가입하신 회사 이름 그대로 알려주세요" |
| 2 | **시리얼 키** | "가입하실 때 메일로 받으신 번호 알려주시겠어요?" |
| 3 | **설치한 날짜** | "언제쯤 설치하셨어요? 며칠쯤인지만요" |

> 3번을 묻는 이유: **1.2.45 이전에 설치했는지**를 가리기 위한 것이다.
> 7월 30일 이전 설치면 옛 버전이 거의 확실하고, 재설치로 해결된다.

## 5. 고객 안내 — 최신 버전으로 다시 설치 (해결책)

> "고객님, 저희 프로그램 최신 버전에서 이 부분이 개선되었습니다.
> 최신 파일로 한 번만 다시 설치하시면 정상 작동합니다.
> 지금 쓰시던 **자료는 그대로 유지**됩니다. 지워지지 않습니다."

**고객에게 알려주는 순서:**

1. `https://landing.hitpan.kr/download` 접속
2. **다운로드 버튼** 클릭 (파일 크기 약 270MB · 인터넷 속도에 따라 2~10분)
3. 내려받은 파일을 **오른쪽 클릭 → 관리자 권한으로 실행**
4. 시리얼 키 입력 (처음 설치할 때 넣었던 그 번호)
5. 안내대로 진행 → 완료

> ⚠️ **반드시 "관리자 권한으로 실행"** 을 강조한다. 이게 빠지면 또 실패한다.
> 고객이 "관리자 권한이 뭐예요?" 라고 하면:
> *"파일 위에서 마우스 오른쪽 버튼을 누르시면 목록이 나오는데,
> 거기 '관리자 권한으로 실행' 이라고 적힌 걸 눌러주세요."*

### 자료가 지워지지 않는다고 반드시 말한다

고객이 가장 무서워하는 건 재설치 = 자료 삭제다. **먼저 안심시킨다.**

> "거래처, 상품, 매입매출 자료 전부 그대로 있습니다. 프로그램만 새로 깔리는 겁니다."

## 6. 다시 설치한 뒤 확인 (고객과 함께)

> "설치가 끝나셨으면 회사 주소를 한 번 열어봐 주시겠어요?
> 로그인 화면이 나오면 정상입니다."

| 결과 | 다음 |
|---|---|
| ✅ 로그인 화면 나옴 | **해결.** §8 마무리 안내로 |
| ❌ 여전히 1033·530 | §7 로 (다른 원인) |
| ⚠️ 502 로 바뀜 | 연결은 됐다. ERP 실행 문제 → 별건으로 담당 이관 |

## 7. 다시 설치해도 안 되면 — 본사 이관

**1.2.45 이상으로 설치했는데도 1033 이면 원인이 다르다.** 가장 흔한 순서:

1. **백신이 연결 프로그램을 막았다** (가장 흔함)
2. 회사 방화벽이 외부 연결을 차단
3. 본사 쪽 설정 문제

**CS 가 원인을 판단하지 않는다.** 아래 형식으로 담당에게 넘긴다.

```
[통신이슈] Error 1033 — 최신본(1.2.45+) 재설치 후에도 미해결
· 회사명    :
· 시리얼    :
· 재설치 시각 :
· 설치본 버전 :
· 접속 주소 :
· 관리자 권한으로 실행했는지 : 예 / 아니오
· 쓰고 있는 백신 이름 :
· 고객 연락처 :
· 고객에게 안내한 내용 : ○시까지 재연락 약속
```

> 백신 이름을 묻는 이유: 실측에서 **백신 차단이 남은 유일한 원인**으로 좁혀졌다.
> 이 한 줄이 담당의 확인 시간을 크게 줄인다.

## 8. 마무리 안내 (해결된 뒤)

> "지금부터는 정상적으로 쓰실 수 있습니다.
> 앞으로 프로그램 개선이 있으면 **자동으로 업데이트**되니
> 고객님이 따로 설치하실 일은 없습니다. 불편을 드려 죄송합니다."

**앞으로 재설치가 없다는 것을 말해준다.** 고객은 "또 이래야 하나" 를 걱정한다.

## 9. 책임 경계 (헌법 #24)

| 영역 | 이번 건 | 고객에게 |
|---|---|---|
| **본사** | ✅ **본사 책임** — 설치 프로그램이 연결 시작을 끝까지 확인하지 않았다 | 명확히 사과한다. 최신본에서 개선됐다고 말한다 |
| 고객 | ❌ 해당 없음 | 고객 잘못이 아니라고 분명히 말한다 |
| 제3자(백신) | ⚠️ §7 인 경우만 | 확정 전에 백신 탓으로 돌리지 않는다 |

> **책임을 흐리지 않는다.** 본사 건이면 본사 건이라고 말한다.
> 고객은 원인을 궁금해하는 게 아니라 **언제 되는지**를 알고 싶다.

## 11. 무엇이 고쳐졌나 (CS 가 알아둘 배경)

고객에게 이걸 설명할 필요는 없다. **담당과 대화할 때 쓰는 배경 지식**이다.

| 봉합 | 무엇이 달라졌나 |
|---|---|
| P0-1 | 설치가 끝날 때 연결 프로그램이 **실제로 돌고 있는지 확인**한다. 안 돌면 경고를 띄운다 |
| P0-1 | 컴퓨터를 다시 켜도 연결 프로그램이 **자동으로 시작**된다 (종전엔 수동이었다) |
| P0-3 | 연결 정보가 낡아 실패하면 설치 중에 **새로 받아와 스스로 복구**한다 |
| P0-4 | 설치 후에도 연결 정보가 없어지면 감시 프로그램이 **스스로 다시 받아온다** |

> 요지: 종전에는 **"설치했는지"만 보고 "연결됐는지"를 안 봤다.** 그걸 보게 만든 것이다.
