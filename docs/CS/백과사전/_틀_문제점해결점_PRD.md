### 🔴 이 문서에 적지 않는 것

- 회사 이름 · 사람 이름 · 연락처 · 주소
- 주민번호 · 사업자번호 · 카드 · 계좌 **모양의 숫자** (승인 때 서버가 다시 검사해서 거부한다)

### 쓰는 순서 (반자동)

1. 티켓을 **완료**로 바꾼다 → `/admin/cs` 에서 **[백과사전 초안]** 을 누른다
2. 초안이 이 틀대로 떠오른다 (회사·담당자 칸은 **애초에 가져오지 않는다** — C-4)
3. 사람이 제목과 해결 순서를 적는다
4. **[승인 등재]** — 승인한 사람이 승인자로 남고, 그때서야 재사용 재료가 된다
   (승인 없이는 승인 판 **행 자체가 생기지 않는다** — DB 가 거절한다)
