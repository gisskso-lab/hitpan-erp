## 0. 사장님 요구사항 원문 (받아쓰기 아닌 의중 정리)
1. **단순 연동은 의미 없다.** 챗봇 사용법 문의는 익숙해지면 안 씀 / 히트판은 이미 반자동이라 단순 명령 메리트 없음.
2. **진짜 그림 = "AI가 하나의 직원이 되는 ERP."** 사무직 직원을 대체.
3. **AI 적용 2축**:
   - **기능적**: 사무직 직원을 대체하는 AI.
   - **기술적**: 본사 CS 워크스페이스 자동화 + 고객의 신속·편리한 CS 처리.
4. **"AI는 다 준비만, 실행은 항상 사람."** (책임·법적 리스크 차단)
5. **구독 정당화**: 메뉴로 되는 걸 말로 바꾼 수준이면 구독료 아까움. Claude라서 되는 것(추론·예측·발견·판단)이 있어야 함.
6. **비용 = 옵션형.** 히트판만 쓰려면 히트판만, AI 필요하면 클로드 연동(클로드ID 입력→토큰). 연동 고객만 AI 활성.
7. **CS 흐름**: 챗봇 1차 → 본사 도움 필요 판단 → 본사 CS 데이터 전송 → 아웃바운드 전화 → 애니서포트 원격.
8. **최종 법적검토는 법무팀장 게이트.**
