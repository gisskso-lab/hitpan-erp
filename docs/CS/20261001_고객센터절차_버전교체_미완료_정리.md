# 고객센터 절차 — 버전 교체가 끝까지 안 된 PC 정리

| 항목 | 내용 |
|---|---|
| 작성 | CS팀장 강지원 |
| 작성일 | 2026-10-01 |
| 상태 | 🟡 초안 — 이 안내가 나오는 판은 아직 고객에게 나가지 않았다(게시 판 번호 ⚠️미확정) |
| 대상 | 본사·대리점 상담원 (통화하면서 보는 문서) |

## 1. 이 문서를 언제 여나

고객이 **자료관리 › 「최신 버전 확인/업데이트」** 또는 **「이전 버전으로 되돌리기」** 화면에서 아래 문구 중 하나를 읽어 줄 때 연다.

| 번호 | 고객이 읽어 주는 문구 (화면 글자 그대로) | 급한 정도 |
|---|---|---|
| A | 「지난번 업데이트(또는 되돌리기) 도중 문제가 생겼습니다. 원래 버전으로 돌려 놓았는지 확인하지 못했습니다. 컴퓨터를 한 번 다시 켜 주세요. …」 | 🔴 높음 |
| A | 「버전을 바꾸던 도중 멈췄습니다. 원래 버전으로 돌려 놓았는지 확인하지 못했습니다. …」 | 🔴 높음 |
| B | 「이전 교체가 끝까지 되지 않았습니다. 고객센터로 연락 주세요.」 | 🟡 중간 |
| C | 「이전 자동 업데이트의 정리가 아직 끝나지 않았습니다. 다음 자동 업데이트가 끝나면 다시 쓰실 수 있습니다.」 | 🟢 낮음 |
| D | 「지난 교체에서 쓰던 프로그램 파일 일부를 아직 치우지 못했습니다. 다음 업데이트·되돌리기 때 먼저 치웁니다. 쓰시는 데는 지장 없습니다.」 | 🟢 낮음 |
| E | 「일부 첨부 파일을 아직 제자리로 옮기지 못했습니다. 파일은 지워지지 않고 보관돼 있으며, 다음 업데이트·되돌리기 때 먼저 옮깁니다.」 | 🟡 중간 |

- 문구 A 는 교체한 뒤 **24시간 동안만** 「지난 기록 · 날짜 시각」 줄로 보인다. 그 뒤에 전화한 고객은 A 없이 B 만 볼 수 있다 — **B 로 온 고객도 A 일 수 있다.**
- 이 두 메뉴는 **회사 자료가 들어 있는 컴퓨터(메인PC)에서 관리자 계정으로만** 열린다. 다른 컴퓨터에서 연 고객은 이 문서 대상이 아니다.
- 화면에 「이 버전의 히트판에는 아직 이 메뉴가 없습니다」가 나오면 이 문서 대상이 아니다(옛 판).

## 2. 먼저 꼭 알아 둘 것 (상담원만)

1. **고객 자료(거래·재고·장부·첨부·백업)는 이 일로 지워지지 않는다.** 버전 교체는 프로그램만 바꾸고 자료 창고에는 손대지 않게 만들어져 있다. 첨부 파일이 잠시 안 열려도 **지워진 것이 아니라 옮겨지지 못한 것**이다.
2. **고객 손으로 고칠 것은 없다.** 상담원이 할 일은 ① 확인 ② 안심시키기 ③ 기록 ④ 넘기기, 넷뿐이다.
3. **다시 누르게 하지 않는다.** 「최신 버전 확인/업데이트」·「이전 버전으로 되돌리기」의 [예]를 한 번 더 누르면, 정리에 성공하는 순간 **실제 교체가 이어서 시작되고 히트판이 멈춘다.** 그 판단은 본사가 한다.

## 3. 절대 하면 안 되는 것

| 하면 안 되는 것 | 이유 |
|---|---|
| 프로그램이 설치된 폴더를 열게 하기 · 그 안의 파일·폴더를 지우거나 옮기거나 이름 바꾸게 하기 | 남아 있는 폴더 안에 **옮기지 못한 첨부 파일**이 들어 있을 수 있다. 지우면 그때 진짜로 사라진다 |
| 명령창·관리 도구를 열게 하기 | 고객 PC 파일 수술 금지 원칙 |
| 자료(DB)를 백업본으로 되살리게 하기 · 자료를 지우게 하기 | 자료는 멀쩡하다. 되살리면 그 사이 입력한 자료가 사라진다 |
| 히트판을 지우고 다시 설치하게 하기 | 다시 설치는 정리 방법이 아니다 |
| [예]를 여러 번 누르게 하기 · 「이전 버전으로 되돌리기」를 해 보게 하기 | 2-3 참고. 교체가 겹치면 상황이 더 꼬인다 |
| 「고쳐졌습니다」·「다음 업데이트면 무조건 풀립니다」라고 약속하기 | 풀리는 길은 아직 실제로 확인되지 않았다(§8) |
| 원격으로 들어가 상담원이 직접 손대기 | 원격 조작이 필요하면 **본사 기술지원으로 넘기는 것까지가** 상담원 몫이다 |

## 4. 통화 절차 — 문구 A (도중에 멈춤 · 🔴)

### 4-1. 고객에게 할 말 (대본)

> 「화면에 나온 대로, 히트판 버전을 바꾸는 중에 끝까지 확인이 안 된 상태입니다.
>  **입력하신 자료는 지워지지 않습니다.** 먼저 그것부터 안심하셔도 됩니다.
>  지금 컴퓨터를 한 번 다시 켜 보겠습니다. 다른 직원분들 쓰시던 화면은 저장해 두시라고 한 번만 알려 주세요.」

> (다시 켠 뒤) 「히트판에 로그인해 보시고, 평소 쓰시던 화면 하나만 열어 봐 주시겠어요?
>  예를 들어 거래처 목록이나 오늘 거래 목록이요.」

### 4-2. 상담원이 확인할 것

| 순서 | 확인 | 결과에 따라 |
|---|---|---|
| 1 | 컴퓨터를 다시 켰나 | 아직이면 다시 켜기부터(4-1 대본) |
| 2 | 다시 켠 뒤 히트판 로그인이 되나 | **안 되면 → §7 로 바로 넘김(전화 · 급함)** |
| 3 | 평소 업무 화면이 열리고 목록이 보이나 | 안 보이거나 이상하면 → §7 로 넘김(급함) |
| 4 | 첨부 파일(채팅 첨부 등)이 안 열리는 것이 있나 | 있으면 기록만 · 「지워진 것이 아닙니다」 안내 |
| 5 | 두 메뉴 화면에 지금 무슨 문구가 보이나 | B 가 보이면 §5 도 함께 진행 |
| 6 | 바꾸는 도중에 컴퓨터를 끄셨거나 정전이 있었나 | 기록만 |

### 4-3. 마무리 대본

> 「지금처럼 화면이 잘 되면 업무는 계속 쓰셔도 됩니다. 쓰시다 이상한 점이 보이면 바로 연락 주세요.
>  다만 「최신 버전 확인/업데이트」와 「이전 버전으로 되돌리기」 두 메뉴는
>  저희가 확인을 마칠 때까지 **누르지 말아 주세요.** 본사 기술지원에서 확인해서 다시 연락드리겠습니다.」

- 2·3번에서 문제가 없어도 **§7 로 넘긴다**(급하지 않음 · 메일/기록). 이 상태는 저절로 끝났는지 상담원이 판단할 수 없다.

---

## 5. 통화 절차 — 문구 B (이전 교체가 끝까지 안 됨 · 🟡)

### 5-1. 고객에게 할 말 (대본)

> 「예전에 히트판 버전을 바꾸던 작업이 끝까지 정리되지 않은 상태라는 뜻입니다.
>  **입력하신 자료는 그대로 있습니다.** 업무 화면이 평소처럼 되는지만 같이 확인해 보겠습니다.」

### 5-2. 상담원이 확인할 것

| 순서 | 확인 | 결과에 따라 |
|---|---|---|
| 1 | 평소 업무 화면(목록·저장)이 되나 | 안 되면 → §7 로 넘김(급함) |
| 2 | 최근(하루 안) 문구 A 를 본 적이 있나 · 「지난 기록」 날짜 시각 | 있으면 §4 확인표도 진행 |
| 3 | 첨부 파일이 안 열리는 것이 있나 | 기록만 |
| 4 | 최근에 새 버전 안내 팝업이 떴나 · 눌렀나 | 기록만 |

### 5-3. 마무리 대본

> 「화면이 잘 되면 업무는 계속 쓰셔도 됩니다. 쓰시다 이상한 점이 보이면 바로 연락 주세요. 이 두 메뉴만 저희 확인이 끝날 때까지 쓰지 말아 주세요.
>  새 버전 안내가 뜨면 평소처럼 [예]를 누르셔도 됩니다. 본사 기술지원에서 확인해서 연락드리겠습니다.」

- 새 버전 안내 [예]로 이 상태가 풀리는지는 ⚠️미확정(§8). 「풀립니다」라고 말하지 않는다.
- 항상 **§7 로 넘긴다.** 이 상태는 저절로 안 풀리는 경우가 있다(같은 판이 계속되면 영구).

---

## 6. 통화 절차 — 문구 C · D · E (새 안내 3종)

### 6-1. 문구 C (이전 자동 업데이트의 정리가 남음 · 🟢)

> 「지난 자동 업데이트 뒤 정리가 조금 남아 있어서, 이 메뉴만 잠시 쓸 수 없는 상태입니다.
>  **업무와 자료에는 지장 없습니다.** 다음 자동 업데이트 안내가 오면 평소처럼 [예]를 누르시면 됩니다.」

- 상담원 할 일: 기록만. 업무가 되는지 한 번 확인.
- 새 버전이 오래 없으면 이 문구가 길게 남을 수 있다. **며칠째 계속되면 §7 로 넘긴다**(며칠이 기준인지 ⚠️미확정).

### 6-2. 문구 D (프로그램 파일 일부를 못 치움 · 🟢)

> 「지난번 교체는 끝났고, 쓰시던 옛 프로그램 파일 일부만 아직 안 치운 상태입니다.
>  **쓰시는 데 지장 없고, 자료도 그대로입니다.** 다음 업데이트 때 알아서 치웁니다.」

- 상담원 할 일: 기록만. 넘기지 않아도 된다.
- 이 문구는 교체 성공 줄 뒤에 붙어 **24시간만** 보인다. 사라졌다고 해결된 것은 아니다(다음 교체 때 치워진다).

### 6-3. 문구 E (첨부 파일 일부를 못 옮김 · 🟡)

> 「지난번 교체는 끝났는데, 첨부 파일 일부를 제자리로 아직 못 옮겼습니다.
>  **파일은 지워지지 않고 보관돼 있습니다.** 그래서 일부 첨부가 지금 화면에서 안 열릴 수 있습니다.」

- 상담원 할 일: 안 열리는 첨부가 실제로 있는지 확인 → 있으면 **§7 로 넘긴다**(급하지 않음).
- 🔴 「메뉴를 다시 눌러 보세요」라고 하지 않는다(§2-3). 누르면 옮기기 뒤에 실제 교체까지 이어진다.
- 되돌리기를 방금 한 PC 는 새 버전이 나올 때까지 「다음 교체」가 오지 않아, 그동안 첨부가 계속 안 열릴 수 있다. 이것만 정리하는 방법은 아직 없다(⚠️미확정 — 다음 차수).

## 7. 본사 기술지원으로 넘기기

### 7-1. 넘기는 곳

- 넘기는 곳·전화·메일·받는 시간은 [CS 대응 매뉴얼 §6-0](20260807_CS대응매뉴얼_배포_설치_통신_업데이트_원격지원.md) 을 따른다.
- **급함(전화)**: 다시 켠 뒤 로그인이 안 됨 · 업무 화면이 안 열림 · 목록이 비어 보임.
- **급하지 않음(메일/기록)**: 그 밖 전부.

### 7-2. 넘길 때 적을 것 (이관 기록)

| 칸 | 적을 내용 |
|---|---|
| 회사 | 회사 이름 · 접속 주소(○○.hitpan.kr) · 담당자 이름 · 연락처 |
| 문구 | 화면 문구 **글자 그대로**(§1 의 A~E 중 무엇인지) |
| 지난 기록 | 화면의 「지난 기록 · 월 일 시:분」 글자(있으면) |
| 무엇을 했나 | 「최신 버전 확인/업데이트」였나 「이전 버전으로 되돌리기」였나 · 언제 눌렀나 |
| 도중 사건 | 교체 중 컴퓨터를 껐나 · 정전이 있었나 |
| 다시 켜기 | 다시 켰나 · 그 뒤 로그인 됐나 |
| 업무 화면 | 평소 화면이 열리나 · 저장이 되나 |
| 첨부 | 안 열리는 첨부가 있나 · 어떤 화면의 첨부인가 |
| 새 버전 안내 | 최근에 떴나 · [예]를 눌렀나 |
| 고객에게 한 약속 | 「본사 확인 뒤 연락」 외에 한 말이 있으면 그대로 |

### 7-3. 고객에게 할 말 (넘길 때)

> 「본사 기술지원으로 내용을 넘겨 드렸습니다. 확인되는 대로 연락드리겠습니다.
>  그동안 업무는 평소처럼 쓰시고, 버전 바꾸는 두 메뉴만 쓰지 말아 주세요.
>  **입력하신 자료는 지워지지 않습니다.**」

## 8. ⚠️ 미확정 — 물어보면 「확인해서 알려드리겠습니다」

| 번호 | 아직 정해지지 않은 것 | 상담원이 하지 말 말 |
|---|---|---|
| 1 | 판이 섞인 채 켜진 히트판이 업무 화면에서 문제없이 도는지 — 실제 시험 전 | 「그냥 쓰셔도 아무 문제 없습니다」 단정 |
| 2 | 다음 자동 업데이트가 판을 맞춰 주고 문구 B 가 스스로 풀리는지 — 설계상 그렇게 되게 했지만 실제 확인 전 · 같은 판이 계속되면 안 풀린다 | 「다음 업데이트면 풀립니다」 약속 |
| 3 | 판이 그대로라 안 풀릴 때 본사가 고치는 판을 새로 내보낼지 — 본사 결정 사항 | 날짜 약속 |
| 4 | 남은 것만 정리하는 기능(첨부 옮기기만 따로) — 다음 차수 | 「정리 버튼이 있습니다」 |
| 5 | 교체 한가운데 끊긴 것을 다시 켤 때 저절로 되돌리는 기능 — 다음 차수 | 「다시 켜면 저절로 고쳐집니다」 |
| 6 | 문구 C 가 며칠 이상 계속되면 넘길지 기준 | 「며칠 기다리세요」 |
| 7 | 남은 옛 프로그램 파일이 차지하는 저장 공간 크기 — 미측정 | 「공간 문제 없습니다」 |
| 8 | 이 안내가 나오는 판 번호 · 게시 날짜 | 판 번호 안내 |

## 9. 본사 기술지원 참고 (상담원은 안 읽어도 된다)

> 고객에게 읽어 주지 않는다. 본사 기술지원이 이관 기록을 받았을 때 보는 요약이다.

| 문구 | 화면 속 뜻 | 정리 경로(설계 기준) |
|---|---|---|
| A | 끝 상태 `broken`(사유 `revert_failed`·`worker_interrupted`) — 원위치를 확인 못 한 채 켬 · 판이 섞였을 수 있음 | 다시 켜면 부팅 안전망이 서비스를 되살린다(설계 §4 S7) · 그 뒤는 B 와 같음 |
| B | `swap_interrupted` — 남은 `.rbk` + 모양 M2·M3·M4(설계 §15-0) | 워치독 업데이트로 판이 맞춰지고 기록과 달라지면 M5(잔재) → 다음 교체 S0 가 흡수. 판이 그대로면 그대로 잠김 → 수정판 게시 여부는 PM·사장님 결재 |
| C | `update_cleanup_pending` — 워치독 `.old` 남음 | 다음 워치독 업데이트가 치움. 우리가 지우는 안은 없음(사장님 결재 영역) |
| D | `success`/`refused` + `cleanup_pending` | 다음 교체 S0 가 치움 |
| E | `success`/`refused` + `carry_pending` — `api.rbk` 안 첨부 | 다음 교체 S0 가 싣고 치움. 되돌리기 직후 + 새 판 없음이면 정리 경로 없음(설계 §15-4 N-1 잔여) |

- 고객 PC 파일 손작업(`.rbk` 이름 바꾸기·지우기)은 **하지 않는다** — 헌법 #39·고객 PC 파일 수술 금지. 원격 조작이 필요하다고 판단되면 PM 보고 → 사장님 결재.
