## §1 🔴 먼저 — 분류는 우리가 새로 만드는 것이 아니다

8칸은 **이미 정해져 있다**(2026-10-08 사장님 결재). 이슈코드도 **백오피스가 발급**한다.
⇒ **이 문서가 8칸을 늘리거나 이름을 바꾸지 않는다.** 바꾸려면 백오피스 쪽 결재다.

| 칸 | 폴더 | 코드 | 여기 오는 문의 |
|---|---|---|---|
| 1 | **사용** | `USE-` | "어디서 하나요" · "이 숫자가 왜 이렇게 나오나요" · 쓰는 법 |
| 2 | **설정** | `SET-` | 회사 정보 · 직원 계정 · 권한 · 양식(인쇄) · 메일 설정 |
| 3 | **통신** | `NET-` | "안 열려요" · "서버 통신이 불안정합니다" · 밖에서 접속 |
| 4 | **데이터** | `DAT-` | 백업 · 복구 · 자료 옮겨오기 · 숫자가 안 맞는다 |
| 5 | **업데이트** | `UPD-` | 새 버전 · 업데이트 중 멈춤 · 되돌리기 |
| 6 | **기능오류** | `BUG-` | 눌렀는데 아무 일이 없다 · 오류 문구가 떴다 |
| 7 | **설치** | `INS-` | 처음 설치 · 재설치 · 자료 보관 컴퓨터 등록 |
| 8 | **기타** | `ETC-` | 요금 · 계약 · 위 어디에도 안 맞는 것 |

## §2 칸을 가르는 기준 — **한 문장**

> 🔴 **고객이 「무엇을 못 하고 있나」로 가른다. 원인으로 가르지 않는다.**

상담 받는 순간에는 **원인을 모른다.** 원인으로 가르려 하면 칸이 매번 바뀌고, 같은 문의가 두 칸에 쌓인다.

| 헷갈리는 짝 | 가르는 법 |
|---|---|
| 통신 ↔ 기능오류 | **화면이 열리나?** 안 열리면 **통신** · 열리는데 단추가 안 먹으면 **기능오류** |
| 데이터 ↔ 사용 | **숫자가 틀렸나, 못 찾나?** 틀렸으면 **데이터** · 어디 있는지 모르면 **사용** |
| 설치 ↔ 업데이트 | **처음인가, 쓰던 것인가?** 처음이면 **설치** · 쓰다 새 버전이면 **업데이트** |
| 설정 ↔ 사용 | **값을 넣는 화면인가?** 값을 정하는 일이면 **설정** |
| 무엇이든 ↔ 기타 | 🔴 **「기타」는 마지막이다.** 두 칸 사이에서 고민되면 **기타로 보내지 말고** 위 기준으로 하나 고른다 |

## §3 칸마다 — 첫 답 틀 (🔴 문구는 **O1-3** 에서 채운다)

각 칸은 **같은 네 줄 틀**을 쓴다. 상담 받는 사람이 **빠뜨리지 않게** 하기 위한 틀이다.

```
① 받았다고 알린다      — (문구: O1-3)
② 지금 업무가 되나 확인 — "지금 ○○ 은 되십니까?"  ← 🔴 이 한 줄을 항상 먼저
③ 그 자리에서 할 것     — 1~3단계 (고객이 혼자 할 수 있는 것만)
④ 안 되면 넘기는 곳     — {{고객센터_안내문}} 기준
```

| 칸 | ② 에서 꼭 물을 것 | ③ 에 들어갈 것 (출처) |
|---|---|---|
| 사용 `USE-` | 어느 화면인가 | 7일 안내 해당 날 → [O0-1](20261019_O0-1_온보딩7일설계도_초안.md) |
| 설정 `SET-` | 대표계정인가 직원계정인가 | [O0-4](20261019_O0-4_사원등록_권한설정_안내_초안.md) |
| 통신 `NET-` | 자료 보관 컴퓨터가 켜져 있나 | [O0-6 2번](20261019_O0-6_장애안내문_5종_초안.md) |
| 데이터 `DAT-` | 백업이 있나 / 옮겨온 자료인가 | [O0-3](20261019_O0-3_자료옮겨오기_안내문_초안.md) · [O0-6 4번](20261019_O0-6_장애안내문_5종_초안.md) |
| 업데이트 `UPD-` | 「업데이트 안내」 창을 눌렀나 | [O0-6 1번](20261019_O0-6_장애안내문_5종_초안.md) |
| 기능오류 `BUG-` | 🔴 **화면에 뜬 문구를 그대로** | 🔴 그 문구로 백과사전을 찾는다(§4) |
| 설치 `INS-` | 라이선스 키를 넣는 단계까지 갔나 | ⬜ **O1-1**(설치 안내서) 뒤 |
| 기타 `ETC-` | 요금·계약인지 | ⬜ 가격 확정 뒤 |

🔴 **②를 빼지 않는다.** 「되는 것이 무엇인지」를 먼저 세우면, 고객이 **전체가 멈춘 줄 알고 있던 상황**이 대부분 그 자리에서 풀린다.

## §4 🔴 고객은 **화면 문구를 그대로 말한다**

그래서 찾는 열쇠는 증상 설명이 아니라 **화면에 뜬 글자**다.

- *"서버 통신이 불안정합니다"* → `NET-`
- *"히트판 업데이트 중"* → `UPD-`
- *"백업 실패…"* → `DAT-`
- *"퇴사한 사원은 계정을 만들 수 없습니다"* → `SET-`

⬜ **숙제**: 고객에게 보이는 문구를 **전수로 모아** 칸마다 열쇠말로 붙인다. (지금은 위 네 개만 확인했다)
