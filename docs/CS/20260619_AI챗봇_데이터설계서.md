## 2. AI수석 3층 기억 구조 (사장님 통찰 — "멍청해지지도 까먹지도 않게")
> 두 낭떠러지 회피: ①다 기억(멍청·느림·비쌈) ②다 잊음(어제 한 일 까먹음). 정답=가운데(사람 기억).

| 층 | 무엇 | 위치 | 수명 |
|----|------|------|------|
| **장기 기억** | 까먹으면 안 되는 것(고객사 업종·자주 묻는 것·과거 해결법) | **파일 + DB 둘 다** | 영구 적립 |
| **단기 기억** | 이번 대화 흐름 | 컨텍스트(대화 중만) | 대화 끝나면 요약 후 비움 |
| **지식(RAG)** | 방대한 매뉴얼·깊은 케이스 | 로컬 sqlite-vec | 그때만 꺼냄 |

- **요약 = 망각 아니라 정제**: 대화 끝날 때 중요한 건 장기로 승격, 사소한 건 흘림.
- 효과: 1년 써도 안 느려지고 안 멍청해지고 BYOK 토큰 절약 + 어제 한 일은 기억.

### 2.1 신규 테이블 — ai_work_memory (장기 기억, 사장님 "인수인계 파일")
```sql
CREATE TABLE ai_work_memory (
    id              BIGINT AUTO_INCREMENT PRIMARY KEY,
    tenant_id       VARCHAR(50) NOT NULL,
    memory_type     ENUM('profile','faq_pattern','resolution','preference') NOT NULL,
    -- profile=고객사 특성 / faq_pattern=자주 묻는 것 / resolution=과거 해결법 / preference=선호
    summary         VARCHAR(1000) NOT NULL,       -- 압축 요약 (대화 통째 아님)
    importance      INT DEFAULT 50,               -- 0~100, 낮으면 정리(망각) 대상
    ref_count       INT DEFAULT 1,                -- 재참조 횟수(자주 쓰면 안 지움)
    last_used_at    DATETIME DEFAULT CURRENT_TIMESTAMP,
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_tenant_type (tenant_id, memory_type),
    INDEX idx_importance (importance DESC)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```
- **파일 미러**: `%LOCALAPPDATA%\HitPan\AiMemory\{tenant_id}_worklog.md` — 세션 시작 시 빠른 로드(파일), 백업·검색은 DB. 본사 0건(헌법 #22).
- 세션 종료 시 단기 대화 → 요약 → importance 매겨 적립. importance 낮고 ref_count 적은 건 주기적 정리(정제).

## 3. BYOK 키 입력·토큰 사용량 (사장님 지시 — 고객사 클로드 계정 입력 + 사용량 화면)
> 신규 테이블 안 만듦 — 실재 `local_subscription` 재활용 + ALTER 2개만.

### 3.1 local_subscription ALTER (실컬럼 위에 최소 추가)
```sql
ALTER TABLE local_subscription
    ADD COLUMN IF NOT EXISTS anthropic_key_saved_at  DATETIME NULL,   -- 키 저장 시각
    ADD COLUMN IF NOT EXISTS anthropic_key_verified_at DATETIME NULL; -- 연결확인 시각
```
- 키 저장: `anthropic_api_key_encrypted`(실재) + `IEncryptionService` AES-256. last4만 평문 표시용.
- ⚠️ 실DDL 전 `DESCRIBE local_subscription;` 의무 — 위 컬럼 실재 여부·중복 확인(헌법 #13).

### 3.2 사용량 = 기존 ai_usage_logs 그대로 (재설계 불요)
