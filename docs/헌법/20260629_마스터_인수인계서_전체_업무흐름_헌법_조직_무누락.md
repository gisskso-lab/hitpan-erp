## 4-1. ERP 6단계 워크플로우 (헌법 #8·#20)
```
①설정(사용자·사원·권한) → ②마스터(업체·상품·BOM·특별단가·원장)
→ ③매입(발주→매입/반품→재고) → ④판매(견적→수주→거래명세서→세금계산서)
→ ⑤현황(재고·매입·판매·계산서) → ⑥재무(회계·경비·경리)
```
재고는 3흐름으로만 변함: 매입확정 / BOM생산 / 판매확정. 원장 INSERT ONLY, confirmed에만 반영.
