## 2. 영역별 상세

### ① 작업지시서 보안 요구사항 명시 — `PULL_REQUEST_TEMPLATE.md`

PR 템플릿에 다음 필수 체크박스:
- [ ] 작업지시서 번호 (예: 작24)
- [ ] 보안 영향 평가 (Y/N)
- [ ] 헌법 절대원칙 25개 위반 여부 자가 점검
- [ ] tenant_id JWT 클레임에서만 사용 (헌법 #2)
- [ ] 본사 전송 업무 데이터 0건 (헌법 #18, #22)
- [ ] 빈 catch 없음 (헌법 #15)
- [ ] decimal 사용 (헌법 #4)

체크 누락 시 PR 자동 라벨링 `needs-template-fill` + reviewer assign 차단.

### ② 어벤져스 매니저 리뷰 — `CODEOWNERS`

```
# 보안 영역
src/**/Auth*           @security-manager-1 @security-manager-2
src/**/Tenant*         @security-manager-1
# DB 영역
src/**/Repositories/   @db-manager
**/*.sql               @db-manager
# 백엔드 영역
src/HitPan.API/        @backend-manager
# 프론트 영역
src/HitPan.Web/        @frontend-manager @web-designer
# 헌법·거버넌스 영역
docs/governance/       @pm
docs/design/           @pm @ai-chief
```

워크플로우 `01_review_gate.yml`은 PR에 절대원칙 25개 체크리스트 자동 코멘트 + 매니저 승인 1명 이상 필수.

### ③ 정적 분석 SAST 4종 — `02_sast.yml`

```yaml
name: SAST
on: [pull_request, push]
jobs:
  codeql:
    uses: github/codeql-action@v3
    with: { languages: 'csharp,javascript' }
  roslyn:
    runs: dotnet build /warnaserror   # 헌법 #19 정합
  trufflehog:
    runs: trufflehog --regex --entropy=True .
  snyk:
    runs: snyk test --severity-threshold=high
```

실패 정책: 4개 중 1개라도 HIGH 이상 발견 = merge 차단.

### ④ 동적 분석 DAST — `03_dast_nightly.yml`

OWASP ZAP Baseline + Full Scan. demo 환경 nightly. 베타 출시 D-7일부터 매일 실행. HIGH 1건 = 베타 차단.

### ⑤ 데이터 최소주의 (#22) 자동 스캔 — `04_data_minimalism.yml`

금기 컬럼 grep 룰셋:
```
금기 패턴 (본사 코드에 등장 시 차단):
- sales_amount, purchase_amount, invoice_amount
- customer_name, vendor_name, employee_name
- 매출_, 매입_, 거래처_, 직원_, 세금계산서_
- ledger_, journal_, stock_
```

`src/HitPan.Backoffice/**` 영역에서 위 패턴 발견 = merge 차단. 본사가 업무 데이터를 만지면 절대원칙 #18 위반.

### ⑥ 백신 호환성 (#31) — `05_av_compatibility.yml`

베타 출시 전 1회 + 매주 일요일 실행. 5종 백신 가상 환경 자동 설치 → EXE 격리 카운트 → 0이 아니면 차단:
- V3 Lite (안랩)
- 알약 (이스트시큐리티)
- 네이버 백신
- Norton
- McAfee

+ Defender 예외 자동 등록 검증 (cloudflared / MariaDB / dotnet).

### ⑦ 통신 무결성 (#27) — `06_comms_integrity.yml`

8대 영역 17 시나리오 nightly + Patch Tuesday 직후 자동 실행:
1. 인프라 (cloudflared·MariaDB·dotnet 재시작 자동복구)
2. 네트워크 (DNS·방화벽·UDP 7844)
3. 보안SW (Defender·백신 격리 후 복구)
4. 자격증명 (TunnelSecret 무효화 → 자동 재발급, 헌법 #28)
5. 물리 (UPS·디스크·ECC)
6. 인적 (관리자 실수 시나리오)
7. 응용 (워치독 5분 self-heal)
8. 외부 공격 (DDoS·Brute Force)

5분 이내 자동 복구 실패 = 베타 출시 차단.

## 3. 머지 차단 통합 정책

`branch protection rules` (main / develop):
- 필수 status check: 7영역 중 PR 트리거 5종 (①②③⑤ + Roslyn `/warnaserror`)
- 필수 review: CODEOWNERS 매니저 1명 + PM 1명
- 직접 push 금지
- force push 금지

베타 출시 게이트 (`release/beta-*` 브랜치):
- 7영역 모두 PASS 필수
- DAST·백신·통신 영역 24시간 이내 PASS 기록 필요
