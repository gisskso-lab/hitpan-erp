# 1클릭 격리 봉합 매뉴얼 (백신 6종)

> 헌법 #31 (OS 보안 도구 호환성) 정합
> 작성: 2026-06-01 (스켈레톤) / 실측 보강: 보안 매니저 2, ~2026-06-15
> 대상: 히트판 설치 EXE / cloudflared / MariaDB / .NET / 워치독 서비스

---

## 0. 원칙

- 본 매뉴얼은 **고객(또는 IT 담당자)이 화면을 보며 1분 안에 따라 할 수 있는** 정상 경로다.
- **강제 우회·탐지 회피 코드·자동 권한 상승 스크립트 절대 포함 금지** (악성코드 패턴).
- 백신 UI 변경 시 화면 캡처·버튼명을 보안 매니저 2가 즉시 갱신.
- 고객 PC 자가 회복 원칙 (헌법 #30) — 본사는 매뉴얼만 제공, 원격 조작 금지.

---

## 1. Windows Defender

1. 작업 표시줄 → Windows 보안 열기
2. 바이러스 및 위협 방지 → 보호 기록
3. 히트판 관련 항목 선택 → 작업 → **허용**
4. (선택) 바이러스 및 위협 방지 설정 → 제외 추가 → 폴더 → `C:\HitPan`

---

## 2. AhnLab V3 Lite

1. V3 Lite 메인 → 검사 기록 / 격리소
2. 격리된 히트판 파일 선택 → **복원**
3. 환경 설정 → 검사 예외 → 폴더 추가 → `C:\HitPan`

---

## 3. 알약 (ALYac)

1. 알약 메인 → 격리소
2. 히트판 항목 선택 → **복원**
3. 환경 설정 → 신뢰할 수 있는 항목 → 폴더 추가 → `C:\HitPan`

---

## 4. 네이버 백신

1. 네이버 백신 메인 → 격리실
2. 히트판 항목 선택 → **복원**
3. 환경 설정 → 검사 예외 → 폴더 등록 → `C:\HitPan`

---

## 5. Norton 360

1. Norton 메인 → 보안 → 기록
2. 격리 카테고리 → 히트판 항목 → **복원 및 제외**
3. 설정 → 안티바이러스 → 검사 제외 → 폴더 → `C:\HitPan`

---

## 6. McAfee Total Protection

1. McAfee 메인 → PC 보안 → 격리된 항목
2. 히트판 항목 선택 → **복원**
3. 설정 → 실시간 검사 → 제외 파일 추가 → `C:\HitPan`

---

## 7. 봉합 후 확인 (공통)

1. 히트판 ERP 바탕화면 아이콘 → 실행 → 로그인 화면 표시 확인
2. 작업 관리자 → 서비스 → `HitpanAPI`, `HitpanWatchdog`, `cloudflared` 3종 `Running` 확인
3. 외부 통신 테스트: 브라우저에서 `https://hitpan-{계정}.kr` 200 OK 확인
4. 실패 시 → 본사 CS (헌법 #24 가르침 의무 영역)

---

## 8. CS 회부 기준

- 1클릭 봉합 후에도 재격리 반복 → 본사 CS 회부
- 백신 신규 버전·시그니처로 인한 신규 탐지 → 보안 매니저 2가 24h 이내 매뉴얼 보강 + 사장님 보고
