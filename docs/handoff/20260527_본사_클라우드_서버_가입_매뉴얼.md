## 2. Step 1~10 사장님 직접 가도 (AWS Lightsail)

### Step 1. AWS 계정 가입 (30분)

1. 브라우저에서 **https://aws.amazon.com/ko/** 접속
2. 오른쪽 위 **"AWS 계정 생성"** 클릭
3. 입력:
   - **루트 사용자 이메일 주소**: gisskso@gmail.com (또는 hitpan@hitpan.kr 신규 권장)
   - **AWS 계정 이름**: hitpan-prod
4. **"이메일 주소 확인"** 클릭 → 이메일 OTP 6자리 입력
5. **루트 사용자 비밀번호** 설정 (16자 이상, 특수문자·숫자 포함)
6. **연락처 정보**:
   - 계정 유형: **비즈니스**
   - 회사명: 히트판
   - 전화번호: 사장님 직통
   - 주소: 사업장 주소
7. **결제 정보**:
   - 신용카드 입력 (BC·국민·삼성·현대 모두 가능)
   - ⚠️ **체크카드는 일부 차단** — 신용카드 권장
   - 본인 인증을 위해 $1 임시 결제 후 환불
8. **자격 증명 (전화 인증)**:
   - 휴대폰 SMS 또는 음성 OTP 수신
9. **AWS Support 플랜**:
   - **"기본 지원 - 무료"** 선택 (월 0원)
10. **콘솔 로그인** → 가입 완료

⏱️ **소요 시간**: 약 30분

---

### Step 2. Lightsail 인스턴스 생성 (10분)

1. AWS 콘솔에서 **상단 검색창에 "Lightsail"** 입력 → Lightsail 클릭
2. 오른쪽 위 **리전 선택**: **"Seoul (ap-northeast-2)"**
3. 가운데 **"인스턴스 생성"** 큰 버튼 클릭
4. **인스턴스 위치**: Seoul, Zone A (ap-northeast-2a)
5. **플랫폼 선택**: **Linux/Unix**
6. **블루프린트 선택**: **OS 전용 → Ubuntu 22.04 LTS**
7. **인스턴스 플랜 선택**:
   - **$10/월 — 2GB RAM, 2 vCPU, 60GB SSD, 3TB 전송**
   - (사장님 부담 시 $5/월도 가능하나 권장 X — 메모리 부족)
8. **인스턴스 식별**:
   - 이름: **hitpan-cloud-1**
9. 오른쪽 아래 **"인스턴스 생성"** 클릭
10. 1~2분 후 인스턴스 상태가 **"실행 중"** 으로 바뀌면 완료

⏱️ **소요 시간**: 약 10분

---

### Step 3. SSH 키 다운로드 (5분) — ⚠️ 사장님 직접 영역

1. Lightsail 메인 화면 오른쪽 위 **"계정"** 클릭 → **"SSH 키"** 탭
2. **"기본 키 다운로드"** 클릭
3. 파일명: `LightsailDefaultKey-ap-northeast-2.pem`
4. **저장 위치 (사장님 PC만)**:
   - 권장: `C:\Users\소순근\Documents\hitpan-keys\LightsailDefaultKey.pem`
   - ⚠️ **이 파일을 PM·서브에이전트·외부에 절대 공유 금지** (헌법 #29)
   - ⚠️ Dropbox·Google Drive·이메일 첨부 절대 금지
5. **백업**: USB 메모리에 1부 복사 (분실 시 인스턴스 재생성 필요)

> 🔒 **SSH 키 = 서버의 마스터 키.** 유출되면 누구든 서버 침입 가능. 사장님 PC만 보관.

⏱️ **소요 시간**: 약 5분

---

### Step 4. 고정 IP (Static IP) 발급 (3분)

1. Lightsail 메인 → **"네트워킹"** 탭
2. **"고정 IP 생성"** 클릭
3. **고정 IP 위치**: Seoul, Zone A
4. **인스턴스 연결**: **hitpan-cloud-1** 선택
5. **고정 IP 식별**: `hitpan-cloud-1-ip`
6. **"생성"** 클릭
7. 발급된 IP 메모 (예: `13.125.XXX.XXX`)

> 💡 **고정 IP는 인스턴스가 실행 중인 동안 무료.** 인스턴스 삭제 후 미연결 상태에서만 시간당 과금.

⏱️ **소요 시간**: 약 3분

---

### Step 5. 방화벽 규칙 (10분)

1. Lightsail → **인스턴스 hitpan-cloud-1 클릭** → **"네트워킹"** 탭
2. **IPv4 방화벽** 영역에서 **"규칙 추가"** 5번 반복:

| # | 애플리케이션 | 프로토콜 | 포트 | 제한 | 용도 |
|---|---|---|---|---|---|
| 1 | SSH | TCP | 22 | **사장님 집·사무실 IP만** | 서버 접속 |
| 2 | HTTP | TCP | 80 | 모든 IP | 랜딩페이지 |
| 3 | HTTPS | TCP | 443 | 모든 IP | 랜딩·백오피스 SSL |
| 4 | 사용자 지정 | TCP | 5234 | 모든 IP | Blazor Web (필요 시) |
| 5 | 사용자 지정 | TCP | 3306 | **본사 IP만 또는 차단** | MariaDB (외부 차단 권장) |

3. **⚠️ SSH 포트 22는 반드시 사장님 IP만 제한**
   - 사장님 집 IP 확인: https://www.whatismyip.com/
   - 사장님 사무실 IP 별도 추가
4. **포트 3306은 외부 차단 권장** — 백오피스 앱과 같은 서버에 있으므로 localhost로만 접근

⏱️ **소요 시간**: 약 10분

---

### Step 6. 1차 접속 확인 (5분)

1. Lightsail 인스턴스 화면 가운데 **"SSH로 연결"** 버튼 클릭 (브라우저 SSH)
2. 검은 화면에 명령어 입력:
   ```bash
   sudo apt update
   uname -a
   ```
3. Ubuntu 버전·커널 정보 출력되면 정상
4. **고급 (사장님 PC에서 직접 SSH)**:
   ```powershell
   # PowerShell (Windows)
   ssh -i "C:\Users\소순근\Documents\hitpan-keys\LightsailDefaultKey.pem" ubuntu@13.125.XXX.XXX
   ```

⏱️ **소요 시간**: 약 5분

---

### Step 7. 도메인 연결 (10분)

> 도메인 `hitpan.app` 또는 `hitpan.kr`을 사장님 Cloudflare 계정에서 관리한다고 가정.

1. **Cloudflare 대시보드** 로그인
2. 도메인 선택 → **DNS** 탭
3. **레코드 추가** 3건:

| Type | Name | Content | Proxy | TTL |
|---|---|---|---|---|
| A | `www` | 13.125.XXX.XXX | ✅ Proxied | Auto |
| A | `backoffice` | 13.125.XXX.XXX | ✅ Proxied | Auto |
| A | `beta` | 13.125.XXX.XXX | ✅ Proxied | Auto |

4. **저장**
5. 5분 후 브라우저에서 `https://www.hitpan.app` 접속 → Cloudflare 502 또는 기본 Nginx 페이지 나오면 정상

⏱️ **소요 시간**: 약 10분

### Step 8. 도커 설치 (15분, 서버에서 직접)

브라우저 SSH 또는 PowerShell SSH로 서버 접속 후 명령어 입력:

```bash
# 1. 시스템 업데이트
sudo apt update && sudo apt upgrade -y

# 2. Docker 설치
curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh

# 3. 현재 사용자에 도커 권한 부여
sudo usermod -aG docker ubuntu

# 4. Docker Compose 설치
sudo apt install docker-compose-plugin -y

# 5. 설치 확인
docker --version
docker compose version

# 6. 재로그인 (권한 적용)
exit
# → 다시 SSH 접속
```

⏱️ **소요 시간**: 약 15분

- 주 1회 사장님 PC로 다운로드 (수동, AES-256 암호화)
- ⚠️ **본사 백업이라도 고객 업무 데이터는 0건** (헌법 #22 v3 정합)

## 6. 문제 발생 시 (헬프데스크)

### 6.1 가입 단계 막힘
- AWS 한국 고객지원: 1644-0010 (한국어, 09:00~18:00)
- 24시간 챗봇: AWS 콘솔 우하단 ❓ 버튼

### 6.2 카드 결제 거부
- 해외결제 차단 해제 (카드사 콜센터)
- 또는 다른 카드로 재시도 (체크카드 X, 신용카드 권장)
- 또는 네이버 클라우드·카카오 클라우드로 변경 (별도 매뉴얼)

### 6.3 SSH 접속 실패
- 방화벽 22 포트 사장님 현재 IP 확인 (whatismyip.com)
- .pem 키 권한 (Linux/Mac만: `chmod 400 LightsailDefaultKey.pem`)
- PM에게 IP·증상만 공유 → PM이 진단 가이드 즉시 박제

### 6.4 도메인 연결 안 됨
- Cloudflare DNS 레코드 5분~24시간 전파 대기
- Cloudflare Proxy 끄고 직접 연결 테스트 후 다시 켜기
