### ✅ 1. CodeQL (GitHub Actions, 무료)

#### 가도 절차
1. `.github/workflows/codeql.yml` 생성
2. 언어 설정: `csharp`, `javascript`
3. 트리거: PR + push to develop
4. 결과: GitHub Security 탭 자동 게시

#### 설정 예시
```yaml
name: CodeQL Analysis
on:
  push:
    branches: [develop, main]
  pull_request:
    branches: [develop, main]
jobs:
  analyze:
    runs-on: ubuntu-latest
    permissions:
      security-events: write
    strategy:
      matrix:
        language: [csharp, javascript]
    steps:
      - uses: actions/checkout@v4
      - uses: github/codeql-action/init@v3
        with:
          languages: ${{ matrix.language }}
      - uses: github/codeql-action/autobuild@v3
      - uses: github/codeql-action/analyze@v3
```

#### 검증 기준
- ✅ PR 머지 전 CodeQL 통과 필수
- ✅ Critical·High 취약점 발견 시 머지 차단

#### 설정 예시
```xml
<Project>
  <PropertyGroup>
    <AnalysisMode>All</AnalysisMode>
    <AnalysisLevel>latest</AnalysisLevel>
    <TreatWarningsAsErrors>true</TreatWarningsAsErrors>
    <EnableNETAnalyzers>true</EnableNETAnalyzers>

  <ItemGroup>
    <PackageReference Include="Microsoft.CodeAnalysis.NetAnalyzers" Version="9.0.0" PrivateAssets="all" />
    <PackageReference Include="SecurityCodeScan.VS2019" Version="5.6.7" PrivateAssets="all" />
  </ItemGroup>
</Project>
```

#### 검증 기준
- ✅ 빌드 시 SAST 경고 0 (헌법 #19 정합)

### ✅ 3. TruffleHog (시크릿 스캔, 무료)

#### 가도 절차
1. `.github/workflows/trufflehog.yml` 생성
2. 전체 git 히스토리 스캔
3. PR 머지 전 시크릿 발견 시 차단
4. **기존 히스토리 1회 전수 스캔** (사장님 결재 필요할 수 있음)

#### 설정 예시
```yaml
name: TruffleHog Secret Scan
on:
  push:
  pull_request:
jobs:
  trufflehog:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0
      - uses: trufflesecurity/trufflehog@main
        with:
          path: ./
          base: ${{ github.event.repository.default_branch }}
          head: HEAD
          extra_args: --only-verified
```

#### 검증 기준
- ✅ AWS·Cloudflare·DigiCert·DB 비밀번호 노출 0
- ✅ 발견 시 즉시 키 회전 + 사장님 보고

#### 설정 예시
```yaml
name: OWASP ZAP Scan
on:
  schedule:
    - cron: '0 2 * * 0'  # 매주 일요일 02:00 KST

jobs:
  zap:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: zaproxy/action-baseline@v0.12.0
        with:
          target: 'https://staging.hitpan.kr'
```

#### 검증 기준
