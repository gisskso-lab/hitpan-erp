## 2. 5whys 분석

### Why 1 — 모바일 외부 접속이 왜 실패했나?
→ cloudflared 터널이 외부 트래픽을 로컬로 전달하지 못함.

### Why 2 — cloudflared가 왜 트래픽을 전달 못했나?
→ TunnelSecret 무효화 또는 cloudflared 프로세스 자체 중단 (5/15 사고 패턴 재현).

### Why 3 — 왜 TunnelSecret이 무효화/cloudflared가 중단됐나?
→ **(a) 5/27 Windows Update 강제 재부팅 누적 가능성** + **(b) cloudflared가 Windows Service로 등록되지 않고 콘솔 모드로 운영 중**이라 사장님 PC 재부팅 시 자동 시작되지 않음.

### Why 4 — 왜 cloudflared가 Service로 등록되지 않았나?
→ **헌법 #29 사장님 사전 승인 필요** + **5/15 사고 후 자동화 박제만 했고 정식 Service 등록은 사장님 결재 보류**.

### Why 5 — 왜 사장님 결재가 보류됐고 PM이 봉합 시 또 사고를 냈나?
→ **(a) 40h 하부르타 결과 박제 후에 cloudflared Service install (W1 게이트 6/3)로 박제** + **(b) PM이 5/27 봉합 중 `appsettings.Local.json`을 만들어 환경 변수 분기로 봉합 시도 → 헌법 #21 위반 (appsettings 절대 보호)**.

### **근본 원인 (Root Cause)**
**RC1 (인프라)**: cloudflared가 Windows Service가 아닌 콘솔 모드 운영 → 사장님 PC 재부팅 시 무인 복구 불가.
**RC2 (PM 사고)**: PM이 헌법 #21을 망각하고 appsettings 영역에 봉합 코드를 작성 → 사장님이 직접 정리.
**RC3 (워치독 부재)**: WS-28-A~I 9단계가 박제만 됐고 실제 동작 중인 워치독이 없음 → 자가복구 0.
