## C. 봉합 방안 (격리 발생 시)

### C-1. 백신별 예외 등록 자동화 (관리자 권한 + 설치 EXE 통합)

| 백신 | 자동 등록 방식 |
|---|---|
| V3 Lite | `ahnsd.exe` CLI + 레지스트리 `HKLM\SOFTWARE\AhnLab\V3` 예외 경로 추가 |
| 알약 | `alyac.exe /addex` CLI (관리자 권한) |
| 네이버 백신 | 레지스트리 `HKLM\SOFTWARE\NaverVaccine\Exclusions` 직접 등록 |
| Norton | `NIS.exe /addtrust` (SymCorpUI) — 수동 폴백 매뉴얼 동봉 |
| McAfee | `mcafee-cli.exe exclusion add` + ENS Web Control 예외 |
| Defender | `Add-MpPreference -ExclusionPath` PowerShell (관리자) |

### C-2. 설치 EXE EV 코드 서명

- **EV(Extended Validation) 코드 서명 인증서** 적용 시 SmartScreen 평판 즉시 신뢰
- 일반 OV 인증서는 평판 누적 1~3개월 소요 → 베타·정식 출시 모두 EV 필수
- 모델 파일(`.onnx`)도 별도 카탈로그(`.cat`) 서명

### C-3. 모델 파일 SHA-256 해시 검증 + 자동 격리 해제 워치독

- 워치독(Windows 서비스)이 1분 주기 모델 파일 무결성 점검
- 격리 감지 시 해당 백신 CLI로 자동 복원 + 본사 메타 ping (고객 데이터 0건, 헌법 #22)
- 3회 연속 실패 시 1클릭 봉합 가이드 토스트 알림
