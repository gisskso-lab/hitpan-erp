## 3. 콘솔 `<` 오류 봉합 — 완료 (재발 시 참고)

### 3-1. 진범 (Network 탭 실측으로 확정)
캘린더(`api/dashboard/unified-calendar`)가 `api-demo.hitpan.kr`로 호출되는데, **cloudflared 가 가끔 Web origin(demo.hitpan.kr 정적서버)으로 라우팅** → `Content-Type: text/html` + `Last-Modified: 5/20` 응답. `GetFromJsonAsync`가 그 `<`(HTML)를 파싱하다 `JsonException(ExpectedStartOfValueNotFound, <)` → 콘솔 `[HP15]`/캘린더 빨간 로그.

### 3-2. 봉합 (커밋 4acbf97·0acb299)
- `src/HitPan.Web/Services/UnifiedCalendarService.cs` — `GetJsonSafeAsync` 헬퍼: GetAsync 로 먼저 받아 **Content-Type 이 json 일 때만** 역직렬화. HTML/빈응답이면 조용히 null(기능 무손상).
- `src/HitPan.Web/Components/Common/TermsConsentBanner.razor` — `AuthProvider` 주입 + `CheckStatusAsync`에 미인증 가드.

### 3-3. ⚠️ 캐시 함정 (PM이 8번 헛다리 짚은 교훈)
- 봉합 후 사장님 일반 창에서 "오류 그대로"였던 건 **브라우저 캐시(옛 wasm)** 때문. `Clear site data`·Ctrl+Shift+R로도 안 지워질 때 있음 → **Network 탭 `Disable cache` 체크 + F5** 가 확실.
- **교훈: 브라우저 오류는 Console 스택이 아니라 Network 탭(Request URL·Content-Type)부터 봐라.** 시크릿 모드는 기기한도로 로그인 못 해 가짜 음성(오류 없어보임) 줌.
