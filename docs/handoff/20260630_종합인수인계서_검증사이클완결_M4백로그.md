## 3. slot빌더 봉합 검증 사이클 (완결) — 5단계로 거짓봉합 차단

```
작3(M2·M3) → 검증팀(구멍3) → 하브루타(절반씩맞음) → 작3v2 →
PM자가검증(R2과민발동 적발·보정) → 데이비드박(R1경계버그 적발·보정) →
임원단(DB권한·host/port 발견) → 전원하브루타(install.bat 증거로 P2확정·종결)
```

**최종 합의표:**
| 항목 | 등급 | 상태 |
|---|---|---|
| R1 경로 화이트리스트(경계버그 TrimEnd 보정) | 닫힘 | ✅ 완료 |
| R2 fail-closed(MYSQL_PWD·LASTEXITCODE·finally) | 진짜봉합 | ✅ 완료 |
| R3 사용자DB 화이트리스트 | 진짜봉합 | ✅ 완료(이 환경 정상abort 실측) |

**메타결론:** M4(별도 깨끗한 인스턴스)=1차 방어선, R3 SCHEMATA 가드=2차 보조 백스톱.
**결정타:** `installer/install.bat:85 GRANT ALL ON *.*` → hitpan 계정 전역권한 → SCHEMATA 권한필터링 미발동 → R3 정상 작동(fail-open 아님).
