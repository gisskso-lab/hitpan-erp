## 3. 워치독이 뭔지 비개발자 설명 (재박제)

### 3.1. 한 줄 정의
**"사장님 PC가 알아서 사고를 봉합하는 자동 복구 시스템"**

### 3.2. 9단계

| 단계 | 이름 | 무슨 일 | MTTR |
|---|---|---|---|
| WS-28-A | TrustedInstaller 감지 | Windows Update 강제 재부팅 사전 감지 | 즉시 |
| WS-28-B | 재부팅 후 점검 | 재부팅 후 5분 안 4 서비스 정상 시작 | 30초 |
| WS-28-C | TunnelSecret 봉합 | 통신 터널 인증 깨짐 → 자동 재발급 | 1분 |
| WS-28-D | Service 재설치 | cloudflared 사라짐 → 자동 재설치 | 2분 |
| WS-28-E | 외부 헬스 | 1분 주기 /health 200 확인 | 3분 |
| WS-28-F | Cool down | 봉합 5회/시간 초과 → 본사 즉시 알림 | 5분 |
| WS-28-G | Event Log | Windows EventLog + 익명 telemetry | 영구 |
| WS-28-H | 2층 Guardian | 워치독 죽으면 → 작업스케줄러가 살림 | 영구 |
| WS-28-I | 4 프로세스 감시 | MariaDB·cloudflared·API·Web 동시 감시 | 영구 |

**전체 MTTR = 3분 이하** (SLA 99.99% 정합).
