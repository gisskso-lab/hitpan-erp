### 진범 (2겹, 코드+DDL 실측 확정)
1. **(이미 봉합됨) FK 위반**: 과거 번들 DB에 users→tenants FK가 살아있어 tenants 비면 users INSERT가 ERROR 1452. → **현재 installer/hitpan_db_clean.sql에서 tenants 참조 위험 FK 18개 전원 비활성화 완료**(주석). 추가 작업 불필요. (fk_users_tenant: hitpan_db_clean.sql:3598)
2. **(진짜 살아있던 차단) 빌드게이트 숫자 불일치**: clean을 번들로 만들려면 build-installer.ps1 게이트3 통과 필요한데:
   - `$ExpectedTables=137`(build-installer.ps1:212) vs clean 실제 **121** → `-ne` 즉시 차단.
   - `$ExpectedTriggers=8`(:213) vs clean 실제 **3** → `-lt` 차단.
   - → clean은 멀쩡한데 게이트가 옛 숫자라 **빌드 영구 차단**. 이게 봉합 안 됐던 진짜 P0.

### 왜 121/3이 맞나 (실측)
- clean = 본사 HQ/대리점/플랫폼/랜딩 16테이블 제거판(헌법 #18·#22·#35). 제거16 = reseller_*(9)+platform/HQ(platforms·platform_admins·bo_permissions·backoffice_refresh_tokens·tenant_payments·commission_settlements)+landing(landing_signups·beta_signups).

## 4. 🟡 빌드가 막힌 이유 = 터널 토큰 (다음 세션 핵심)
**샌드박스 테스트하려면 게이트 봉합 반영된 새 EXE가 필요한데, 빌드를 못 돌렸다.**

**이유**: build-installer.ps1은 `-Token`(cloudflared 터널 토큰, eyJ로 시작)이 **필수 인자**(build-installer.ps1:20-21). 토큰 없거나 형식 틀리면 :41-44에서 즉시 중단. **빌드 자체가 토큰 없이 시작 불가.**

**토큰은 사장님 영역(헌법 #29)** — PM이 가짜 토큰 임의 생성 금지(인프라 조작 위반 + 가짜토큰 EXE는 터널 안 붙음).

**현재 dist/ EXE는 전부 게이트 수정 전 빌드**(최신 HitPan-Setup-test1.exe 6/18, 1.2.15 6/17). 9bbb242 반영 EXE 없음. 옛 EXE로 샌드박스 돌리면 P0 봉합 검증 안 됨.

**sandbox-test.wsb 주의**: installer/sandbox-test.wsb의 MappedFolder HostFolder 경로 한글이 깨져있음(`?뚯닚洹?`) → 그대로 쓰면 폴더 매핑 실패 가능. 경로 재작성 필요.
