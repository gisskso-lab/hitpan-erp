### 진범 (Network 탭 실측 확정 — 중요)
캘린더(`api/dashboard/unified-calendar`)가 `api-demo.hitpan.kr` 로 호출되는데, **cloudflared 터널/Cloudflare 가 그 경로를 가끔 Web origin(demo.hitpan.kr 정적서버)으로 잘못 라우팅** → `Content-Type: text/html` + `Last-Modified: 5/20`(정적파일) 응답. 종전 `GetFromJsonAsync` 가 그 `<`(HTML)를 파싱하다 `JsonException(ExpectedStartOfValueNotFound, <)` → 콘솔 빨간 로그.
- **인프라(터널 라우팅) 문제이나 코드로 방어**가 정공법(고객 PC마다 회선·환경 다름, 헌법 #27).
- 봉합 = GetAsync 로 먼저 받아 **Content-Type 이 json 일 때만** 역직렬화. HTML/빈응답이면 조용히 null(기능 무손상). 화면 캘린더는 원래도 정상 렌더였고 콘솔 로그만 제거됨.
