### 03:10 마이그 1분 절대 실측 (90초 윈도우)
실행 SQL (예시):
```sql
-- 1. 마이그 시작 timestamp 저장
SET @t_start := NOW(6);

-- 2. PYOJUN(15MB) + PANDATA(305MB) + POTHER(336MB) 마이그 트리거
CALL sp_run_full_migration_v2();  -- (DB매니저가 정확한 procedure 이름 확인 후 실행)

-- 3. 종료 timestamp + 소요 측정
SET @t_end := NOW(6);
SELECT TIMESTAMPDIFF(MICROSECOND, @t_start, @t_end) / 1000000 AS elapsed_seconds;
```

**성공 기준:** `elapsed_seconds <= 60` (헌법 #26 절대 원칙)

### 03:30 멱등성·무결성 검증 (30분)
```sql
-- 멱등성: 동일 마이그 재실행 후 dup 0 확인
SELECT COUNT(*) AS dup_count
FROM (
  SELECT source_hash, COUNT(*) AS c
  FROM migrated_transactions
  GROUP BY source_hash
  HAVING c > 1
) t;
-- 기대값: 0

-- FK orphan: 모든 외래키 정합성
SELECT COUNT(*) AS orphan_count
FROM stock_ledger sl
LEFT JOIN items i ON sl.item_id = i.id
WHERE i.id IS NULL;
-- 기대값: 0
```
