### 🔴 P0-1 — #80·#81 발주·수주 라인 품목 매핑 봉합 (5/22 09:00~14:00, 5h)

#### 진범
- DOCFA (발주 라인) 1,033개 중 833개 품목명이 items 마스터에 없음 → 라인 자체 누락
- DOCFO (수주 라인) 222개 중 154개 동일 결함

#### 봉합 방안 (옵션 G 결재 권고)
**옵션 G-1: 자동 가상 품목 생성** (사장님 결재 필요)
- 매핑 실패 품목명을 items에 `MIG-MISSING-{name}` 코드로 자동 INSERT
- 발주·수주 라인은 가상 품목으로 정상 적재
- 베타 안내문에 "26개 가상 품목 자동 등록" 박제

**옵션 G-2: 누락 라인을 staging에 보존 + 본 INSERT 스킵** (현재 코드)
- 영향: 발주서·수주서 PDF 일부 빈 칸 (베타 안내문 #2·#3 잔존)

#### 가도 코드 영역
- `MdbMigrationService.cs` 발주 라인 빌드 (line 4500~) + 수주 라인 빌드 (line 5200~)
- 품목 매핑 실패 catch → items 가상 등록 (UPSERT) → staging.item_id 매핑
- 멱등 키: `MIG-MISSING-{tenant}-{name_hash8}`

#### 검증 SQL
```sql
SELECT COUNT(*) FROM purchase_order_items WHERE item_id IN (SELECT item_id FROM items WHERE code LIKE 'MIG-MISSING-%');
SELECT COUNT(*) FROM sales_order_items WHERE item_id IN (SELECT item_id FROM items WHERE code LIKE 'MIG-MISSING-%');
```
