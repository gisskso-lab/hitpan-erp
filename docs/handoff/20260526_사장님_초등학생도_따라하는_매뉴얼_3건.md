# 🟢 1번 매뉴얼: Cloudflare DNS 추가 (5분, 무료)

> **목적**: 스테이징(테스트용) 도메인 2개 만들기
> **결과**: `staging.hitpan.kr` + `api-staging.hitpan.kr` 생성

## Step 1-1: Cloudflare 로그인
1. 크롬 브라우저 열기
2. 주소창에 입력: `https://dash.cloudflare.com`
3. 이메일 + 비밀번호 입력 후 **로그인** 클릭
   - ❓ 비밀번호 모르면: PM에게 물어보세요

## Step 1-2: 도메인 선택
1. 화면 가운데 `hitpan.kr` 클릭
   - 못 찾으면: 검색창에 `hitpan` 타이핑

## Step 1-3: Zero Trust 메뉴 들어가기
1. 왼쪽 메뉴 맨 아래 **Zero Trust** 클릭
2. 새 탭이 열립니다 (기다리세요 3초)
3. 왼쪽 메뉴 **Networks** → **Tunnels** 클릭

## Step 1-4: 터널 선택
1. 터널 목록에서 `hitpan-erp` 또는 비슷한 이름 클릭
2. 위쪽 **Public Hostname** 탭 클릭

## Step 1-5: 첫 번째 도메인 추가
1. **Add a public hostname** 버튼 클릭 (파란색)
2. 아래처럼 입력:
   ```
   Subdomain: staging
   Domain: hitpan.kr  (이미 선택됨)
   Path: (비워둠)
   Service Type: HTTP
   URL: localhost:5235
   ```
3. 맨 아래 **Save hostname** 버튼 클릭

## Step 1-6: 두 번째 도메인 추가
1. 다시 **Add a public hostname** 버튼 클릭
2. 아래처럼 입력:
   ```
   Subdomain: api-staging
   Domain: hitpan.kr  (이미 선택됨)
   Path: (비워둠)
   Service Type: HTTP
   URL: localhost:5258
   ```
3. **Save hostname** 버튼 클릭

## Step 1-7: 확인
- 목록에 `staging.hitpan.kr` + `api-staging.hitpan.kr` 두 개 보이면 ✅ 성공
- PM에게 카톡: *"DNS 2개 추가 완료"*

> 🚨 **에러나면**: 스크린샷 찍어서 PM에게 보내세요. 절대 혼자 지우지 마세요.

# 🟢 2번 매뉴얼: NPKI 신청 (30분, 무료)

> **목적**: 홈택스에서 전자세금계산서 테스트할 수 있는 개발자 인증서 받기
> **결과**: 5/29~5/31 사이 이메일로 테스트 인증서 PFX 파일 도착

## 준비물 (시작 전 책상에 올려놓기)
- [ ] 사업자등록증 사진 (휴대폰으로 찍어두기)
- [ ] 사업자등록번호 외워두기
- [ ] 휴대폰 (본인인증용)

## Step 2-1: 홈택스 접속
1. 크롬 브라우저 새 탭 열기
2. 주소창에 입력: `https://www.hometax.go.kr`
3. 메인 화면 뜨면 OK

## Step 2-2: 개발자센터 찾기
1. 화면 맨 아래로 스크롤 (마우스 휠 아래로)
2. 푸터(맨 아래)에서 **개발자센터** 글자 찾기
   - 없으면: 위쪽 검색창에 `개발자센터` 타이핑 후 엔터

## Step 2-3: 회원가입 / 로그인
1. **회원가입** 클릭 (이미 있으면 로그인)
2. **사업자** 선택
3. 사업자등록번호 입력
4. 휴대폰 본인인증 (문자 받으면 6자리 숫자 입력)

## Step 2-4: 개발용 인증서 신청
1. 로그인 후 **테스트베드** 또는 **개발용 인증서 발급** 메뉴 클릭
2. **신청서 작성** 클릭
3. 아래처럼 입력:
   ```
   회사명: 히트판
   사업자번호: (사장님 사업자번호)
   담당자명: 소순근
   담당자 이메일: gisskso@gmail.com
   담당자 휴대폰: (사장님 휴대폰)
   개발 목적: 히트판 ERP 전자세금계산서 자체 발행 시스템 개발
   사용 기간: 6개월
   ```

## Step 2-5: 사업자등록증 첨부
1. **파일 첨부** 버튼 클릭
2. 휴대폰에서 찍은 사업자등록증 사진 선택
   - 휴대폰에서 받기: 카카오톡 "나에게 보내기"로 사진 전송 → PC에서 다운로드
3. **업로드** 클릭

## Step 2-6: 제출
1. 모든 항목 입력 확인
2. **개인정보 동의** 체크박스 클릭
3. **신청** 버튼 클릭
4. 신청번호 화면 캡처 (Print Screen 키)

## Step 2-7: 대기
- 3~5일 후 이메일 도착 (5/29~5/31 사이)
- 이메일에 PFX 파일 + 비밀번호 첨부됨
- PM에게 카톡: *"NPKI 신청 완료, 신청번호 [숫자]"*

> 🚨 **에러나면**: 화면 그대로 두고 PM에게 카톡. 다시 시도하면 중복 신청됨.

# 🟢 3번 매뉴얼: EV/OV 인증서 신청 (30분, 90만원)

> **목적**: 설치 EXE에 도장 찍어서 Windows가 "안전한 프로그램"으로 인식하게 만들기
> **결과**:
> - OV (24시간 후): 임시 사용용 (30만원)
> - EV (5~10일 후): 정식 사용용 (60만원)

## 준비물
- [ ] 사업자등록증 PDF 또는 사진
- [ ] 법인등기부등본 (있으면, 없으면 생략 가능)
- [ ] 신용카드 (90만원 결제용)
- [ ] 휴대폰 (인증서 발급기관에서 통화 옴 — 영어 가능하면 좋음, 한국 파트너면 한국어)

## Step 3-1: 한국 파트너 사이트 접속
1. 크롬 새 탭
2. 주소창에 입력: `https://codesigning.co.kr`
   - 또는: `https://itrustchina.com` (둘 중 편한 곳)

## Step 3-2: 견적 문의 (선택사항, 가격 확인용)
1. **견적문의** 또는 **CONTACT** 메뉴 클릭
2. 아래처럼 입력:
   ```
   회사명: 히트판
   담당자: 소순근
   이메일: gisskso@gmail.com
   휴대폰: (사장님 휴대폰)
   문의 내용:
   - EV Code Signing Certificate 1년 (USB 토큰 포함)
   - OV Code Signing Certificate 1년 (임시 폴백용)
   - DigiCert 발급 희망
   - 빠른 발급 가능 여부
   ```
3. **전송** 클릭
4. 담당자가 30분~1시간 안에 전화 옴

## Step 3-3: OV 먼저 신청 (24시간 발급, 폴백용)
1. **OV Code Signing 신청** 버튼 클릭
2. 아래 입력:
   ```
   인증서 종류: Code Signing
   등급: OV (Organization Validation)
   기간: 1년
   발급기관: DigiCert
   가격: 약 30만원
   ```
3. 회사 정보 입력 (사업자등록증 정합)
4. 사업자등록증 PDF 업로드
5. **결제** 버튼 → 신용카드 결제 (30만원)
6. ✅ 완료. 24시간 내 발급

## Step 3-4: EV 추가 신청 (5~10일 발급, 정식)
1. **EV Code Signing 신청** 버튼 클릭
2. 아래 입력:
   ```
   인증서 종류: Code Signing
   등급: EV (Extended Validation)
   기간: 1년 또는 3년 (1년 권고)
   발급기관: DigiCert
   USB 토큰: 포함 (필수)
   가격: 약 60만원 (1년)
   ```
3. 회사 정보 입력
4. 사업자등록증 + 법인등기부등본 업로드
5. **결제** 버튼 → 신용카드 결제 (60만원)
6. ✅ 완료. 5~10일 내 USB 토큰 택배 도착

## Step 3-5: 신원 검증 통화 받기
- DigiCert 한국 파트너가 1~3일 안에 전화 옴
- 받으면:
  ```
  Q: "히트판 대표 소순근 본인 맞으시죠?"
  A: "네, 맞습니다"

  Q: "사업자번호 [숫자] 맞으시죠?"
  A: "네, 맞습니다"

  Q: "Code Signing 인증서 발급 신청하신 거 맞으시죠?"
  A: "네, 맞습니다. 히트판 ERP 설치 파일 서명용입니다"

  Q: "발급 후 이메일로 안내 드리겠습니다"
  A: "네, 감사합니다"
  ```
- 통화 시간: 약 3~5분

## Step 3-6: USB 토큰 수령 (EV만 해당)
1. 5~10일 후 택배로 USB 토큰 도착
2. **절대 잃어버리지 마세요** (재발급 60만원 추가)
3. 받으면 PM에게 카톡: *"EV USB 토큰 도착"*
4. PM이 빌드 서버에 등록함

## Step 3-7: 영수증 보관
- 90만원 결제 영수증 PDF 저장
- 경리 처리용

> 🚨 **결제 전 확인**: 가격이 30만 + 60만 = 90만원 맞는지 확인. 다르면 PM에게 카톡 먼저.

# 🚨 자주 묻는 질문 (FAQ)

## Q1. 1번(DNS)에서 메뉴를 못 찾겠어요
👉 화면 캡처해서 PM에게 카톡. 절대 아무 버튼 누르지 마세요.

## Q2. 2번(NPKI)에서 사업자등록증 사진이 흐릿해요
👉 다시 찍으세요. 글자가 또렷이 보여야 합니다. A4용지 위에 놓고 위에서 똑바로.

## Q3. 3번(EV)에서 90만원이 너무 비싸요
👉 정상 가격입니다. EV는 Windows SmartScreen 통과 필수. 안 사면 고객 PC에서 "위험한 파일" 경고 뜸.

## Q4. 통화가 영어로 와요
👉 한국 파트너(codesigning.co.kr / itrustchina.com)로 했으면 한국어. 영어로 오면 끊고 PM에게 카톡.

## Q5. 신용카드 결제 안 돼요
👉 한도 확인. 90만원이면 일시불 가능해야 함. 안 되면 다른 카드 시도. 그래도 안 되면 PM에게 카톡.

## Q6. USB 토큰 잃어버렸어요
👉 즉시 PM에게 카톡. 재발급 60만원 + 5~10일 추가 소요. (절대 잃어버리지 마세요)
