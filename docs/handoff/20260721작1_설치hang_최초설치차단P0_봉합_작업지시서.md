## 0. 실측으로 잡은 진범 (추측 아님 — 프로세스 관측)

백지 Windows Sandbox 에서 랜딩(`landing.hitpan.kr/download`) → **1.2.33 다운로드 성공 → 설치가 25분+ 무한 hang.**

**설치 로그 마지막 줄** (그 뒤 없음):
```
23:58:06.359  [재설치안전] 파일 복사 전 기존 실행 프로세스 정지 시작
```

**걸린 프로세스 관측** (죽였더니 새로 또 뜸 = 반복 hang 확정):
```
taskkill 1828 @23:58:11  → 25분 hang
(죽인 후) taskkill 6644 @00:30:11 → 또 hang
설치 본체 HitPan-ERP-Setup-1.2.33 (3372) = 살아서 자식 taskkill 반환 대기
```

### 진범 = [`StopRunningComponentsForReinstall`](../../installer/HitPan-Universal.iss#L1267) 의 `taskkill /F /IM` 무한 hang
- `taskkill /F /IM HitPan.API.exe`(L1284)·`HitPan.Watchdog.exe`(L1285)·`cloudflared.exe`(L1286) — 대상 없으면 즉시 반환해야 정상인데 **Windows Sandbox 에서 무한 대기**(taskkill /IM 의 프로세스 이미지 열거가 Sandbox 제약 계층에서 응답 못 받음 — 실측 중 `Get-CimInstance Win32_Process` 도 "액세스 거부" 나온 것과 동일 계층 문제).
- `Exec(..., ewWaitUntilTerminated)`(무한 대기)라 taskkill 이 안 끝나면 설치 전체가 영영 멈춤.
- `sc stop cloudflared`·`sc stop HitPanWatchdog` 은 **무죄 확정**(실측 `sc.exe query` = 1060 서비스 없음 → 즉시 반환).

### 근본 원인 = 재설치 방어 코드가 최초 설치(백지)에서 무조건 실행
[L1302](../../installer/HitPan-Universal.iss#L1302): `if CurStep = ssInstall then StopRunningComponentsForReinstall()` — **최초/재설치 구분 없이 무조건.** 백지엔 죽일 프로세스가 없는데도 종료 명령 8개+를 돌린다. 사장님 **"덮어 재설치는 존재하지 않는 경로"**([[feedback_no_overwrite_reinstall]], 헌법 #40 정신)와 정면 충돌 — 재설치용 코드가 **최초 설치를 죽인다.**

### ⚠️ 영향 범위 = 전 신규 고객 설치 차단 (P0)
고객이 랜딩에서 받아 설치하면 여기서 멈춘다. 자동업데이트(고리4)를 실측할 기회조차 안 온다. **오늘 고리4가 되는지 못 본 이유 = 이 앞단 설치 P0.**

## 1. 봉합 설계 (2축)

### 축 A [핵심] — 최초 설치면 정지 로직 통째 스킵
`{app}` 폴더에 **기존 설치 흔적**이 있을 때만 `StopRunningComponentsForReinstall` 실행. 백지면 스킵.
- 판정 기준 = `{app}\hitpan-keys.conf` 존재 여부(설치 완료 시 반드시 생성되는 파일, L1322). 있으면 재설치, 없으면 최초.
- 최초 설치엔 정지시킬 프로세스가 원천적으로 없으므로 스킵이 안전하고 정확(헌법 #40 정합).

### 축 B [방어깊이] — taskkill hang 자체를 원천 차단
재설치 경로에서도 taskkill /IM 이 hang 하면 안 된다. 두 방법 중 택(CTO 결정):
- **B-1 (권장)**: `taskkill /F /IM` → **PowerShell `Stop-Process -Name -Force`** 로 대체. /IM 의 이미지명 프로세스 스캔 hang 을 우회(Stop-Process 는 없으면 조용히 에러 반환, hang 없음).
- **B-2 (대안)**: 각 taskkill 을 `timeout` 으로 감싸거나 `ewWaitUntilTerminated` → 폴링+상한. Inno Exec 에 직접 타임아웃 없어 배선 복잡.
- `sc stop` 도 서비스 없을 때 즉시 반환이나(실측 확인), 방어깊이로 `sc.exe query` 선확인 후 stop 권장.

### 축 A·B 관계
- A 만으로 **오늘 실측 hang 은 100% 해소**(백지 = 스킵). B 는 재설치 고객(포맷·PC교체 후 재설치, 헌법 #40 유일 재설치 경로) 보호.
- 최소 봉합 = A. 정공법 완결 = A+B.
