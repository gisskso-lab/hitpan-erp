## 3. S1 착수 전 사장님 결재 영역 (헌법 #33)

다음 영역에서 사장님 결재 후 S1 가도:

1. **BYOK / 풀 2축 결정 확정** — 베타1은 본사 풀 단일? 또는 BYOK 우선 + 풀 폴백?
2. **모델 기본값** — `claude-opus-4-7` (품질) vs `claude-sonnet-4-7` (속도/비용) — 베타1 기본
3. **위험 Tool 범위** — `commit_*` / `cancel_*` 외 추가 영역 필요?
4. **베타1 Tool 범위** — 47개 컨트롤러 전수 vs 핵심 N개만 우선 (조회 + 매입 + 판매 + 재고)
5. **감사 로그 위치** — 고객 PC 로컬만 (헌법 #18·#22) vs 메타 통계만 본사 Push
