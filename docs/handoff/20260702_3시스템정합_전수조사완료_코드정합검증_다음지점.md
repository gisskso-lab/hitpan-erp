## 4. 🎯 다음 세션 첫 행동 (코드 정합검증)
정식 시리얼 경로의 **단계 간 API 입출력 계약이 코드상 이어지는지 필드 단위 대조**:
```
랜딩 → 백오피스: LandingSignupController(가입) / LandingPublicController license/claim 이 만드는 값
백오피스 → ERP: 부트스트랩 토큰 클레임(HMAC) + webhook(WebhookOutboundService.EmitSubscriptionChangedAsync)
ERP 수신: installer CallBootstrapApi / CompanyBootstrapController(bootstrap·create-parent) / webhook 수신 컨트롤러(있는지?)
```
- 핵심 대조점: ① 랜딩이 보내는 payload = 백오피스 기대값 = ERP 받는 값 필드 일치? ② **G5 웹훅 ERP 수신측이 실제 있는지**(백오피스는 EmitSubscriptionChanged 호출하나 ERP 수신 컨트롤러 미확인) ③ 시리얼 형식 일치(SerialIssueService `HP-YYMM-..` vs installer `HITP-XXXX-..` — 형식 2종 존재, 정합 확인 필요).
