## 5. 세금계산서 3계층 구조 (사장님 확정 설계)

```
거래명세서 확정 → 계산서 발행(내부 마킹) → 전자세금계산서 발행(국세청)
                                              ├─ 2계층: 즉시발행
                                              └─ 3계층: 예약발행(타이머 일괄)
```
- 계산서 발행과 전자발행은 **완전히 다른 버튼**
- 계산서 발행 상태가 **전자발행의 전제 조건**
- **이번 라운드는 계산서 발행 단계까지만** 우리가 구현
- 전자발행 단계는 자체개발/외주/시점 **미정** — 사장님 추후 결정
