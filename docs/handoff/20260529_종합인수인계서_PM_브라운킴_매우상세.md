## 3. 워치독이 뭔지 비개발자 설명

### 3.1. 비유
| 일상 | 워치독 |
|---|---|
| 🚗 자동차 자율 정비 | PC가 알아서 자기 봉합 |
| 🏥 병원 자가 진단 | 1분마다 4개 영역 점검 |
| 🚨 자동 소화기 | 사고 감지 → 즉시 진압 + 본사 알림 |
| 🏦 은행 무인 가동 | 24시간 365일, 사장님 손 0 |

### 3.2. 동작 9단계

| 단계 | 이름 | 무슨 일 하는지 | MTTR |
|---|---|---|---|
| WS-28-A | TrustedInstaller 감지 | Windows Update 강제 재부팅 사전 감지 | 즉시 |
| WS-28-B | 재부팅 후 점검 | 재부팅 후 5분 안 4 서비스 정상 시작 검증 | 30초 |
| WS-28-C | TunnelSecret 봉합 | 통신 터널 인증 깨짐 → 자동 재발급 | 1분 |
| WS-28-D | Service 재설치 | cloudflared 사라짐 → 자동 재설치 | 2분 |
| WS-28-E | 외부 헬스 | 1분 주기 /health 200 확인 | 3분 |
| WS-28-F | Cool down | 봉합 5회/시간 초과 → 본사 즉시 알림 | 5분 |
| WS-28-G | Event Log | Windows EventLog + 익명 telemetry | 영구 |
| WS-28-H | 2층 Guardian | 워치독 죽으면 → 작업스케줄러가 살림 | 영구 |
| WS-28-I | 4 프로세스 감시 | MariaDB·cloudflared·API·Web 동시 감시 | 영구 |

전체 MTTR(평균 복구 시간) = **3분 이하**. SLA 99.99% 정합 (월 다운타임 < 52분).

|---|---|---|
| 다운타임 | **6시간** | **10분 이내** |

## 14. 자주 묻는 질문 (FAQ)

### Q1. 워치독이 사장님 PC를 감시한다는 게 보안상 괜찮나?
**A**: 본사로 전송하는 데이터는 **상태값만** (healthy/recovering/down) + 봉합 카운터. 매출·거래처·직원 명단 일체 0건. 코드로 5중 검증해서 강제 차단. 헌법 #22 정합.

### Q2. 5/27 사고처럼 또 사고 날까봐 걱정.
**A**: 5/27 사고의 진짜 원인 3가지(콘솔 모드 + 워치독 부재 + PM 실수) 모두 6/3 사장님 1줄 결재로 영구 봉합. 워치독 가동 시 다운타임 6시간 → 10분 박제 (역시뮬).

### Q3. 7/14 정식 출시 못 지키면?
**A**: 사장님 격언 *"늦춰지면 어때. 확실하게 잡고가는게 중요하지"* 정합. 사고 1건 = 5주 연장. 8월·9월·10월도 가능. **약속한 99.99% 못 지키면 환불** 약관에 명문화.

### Q4. 본사가 사고 나면 SLA 책임?
**A**: 본사 책임 영역(SaaS 결제·인증·메타DB·모니터링·CS)만 SLA 99.99%. 고객 PC·통신사·전기·Cloudflare는 별도. 약관 §24의2 ③ ④ 명문화.

### Q5. 더존·이카운트 영업 어떻게 차별화?
**A**: "본사가 가진 게 없어서 털릴 게 없다" + "고객 PC가 알아서 자가 복구" + "못 지키면 돈 돌려드림". 쿠팡·SKT·KT 사고 시대 강력 셀링 포인트.

### Q6. AI로 만든 거 마케팅에 써도 돼?
**A**: 헌법 #23: **"AI", "Claude", "Cursor", "바이브코딩" 외부 자료 사용 금지**. 정통 ERP·풀스택 전문가팀 포지셔닝 유지.
