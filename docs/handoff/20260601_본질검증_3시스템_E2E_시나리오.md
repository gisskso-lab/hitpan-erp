6. 라이선스 키 자동 발급 + 안내 메일 발송
7. 메일 링크 클릭 → 다운로드 페이지 → 라이선스 키 검증 → EXE 다운로드

### 시나리오 2 — 백오피스 메타정보 조회 (헌법 #22 정합)

**목표**: 시나리오 1로 생성된 신규 계정이 백오피스에서 메타만 보이고, 업무 데이터는 0건임을 검증.

**단계**:
1. 백오피스 admin 로그인 (api/admin/auth/login)
2. `GET /api/admin/tenants` → 신규 가입 회사 1건 표시
3. `GET /api/admin/tenants/{id}` 상세 → 회사명·사업자번호·이메일·플랜·구독 상태만 표시
4. `GET /api/admin/licenses?tenantId={id}` → 발급 라이선스 1건
5. `GET /api/admin/subscriptions?tenantId={id}` → 구독 active + 결재 1건

**검증 포인트** (헌법 #22 위반 적발):
- ❌ 매출/매입/원장/거래처/직원/상품/재고/세금계산서 컬럼 0건 (있으면 즉시 P0 반려)
- ❌ 본사 DB에 고객사 업무 데이터 INSERT 트레이스 0건 (감사 로그 grep)
- ✅ 본사 DB 컬럼은 카운터·식별자·메타만

### 시나리오 3 — ERP 실업무 가도 검증 (대표 계정)

**목표**: 신규 대표 계정으로 6단계 워크플로우 끊김 없이 동작.

**단계** (6단계 워크플로우 순서):
1. 설정 → 사용자정보 → 사원관리 (대표 자신만) → 권한설정
2. 마스터 → 업체관리 1건 등록 → 상품관리 1건 등록 → BOM 1건 등록
3. 매입 → 발주 1건 → 매입 1건 → 재고 +N 확인
4. 판매 → 견적 → 수주 → 거래명세서 → 재고 -N 확인 → 세금계산서 1건
5. 현황 → 재고/매입/판매 모두 정합
6. 재무 → 경리·경비 표시 정합

**검증 포인트** (헌법 #20 워크플로우 끊김 0):
- 발주 → 매입 → 재고 증가 (한 화면 안 끊김)
- 거래명세서 → 세금계산서 자동 변환 가능
- 재고·매입·판매 현황 실시간 정합

### 시나리오 4 — 자식 계정 발급 + 권한 차단

**목표**: 대표 계정이 자식 계정 발급 후 권한별 화면 차단 동작.

**단계**:
1. 대표 로그인 → /users/permissions 접근 (TenantAdmin Policy 정합)
2. `POST /api/users/children` → 자식 계정 1건 발급 (Role=User, 매입만 권한 부여)
3. 자식 계정 로그아웃·로그인
4. 사이드바: 매입만 표시, 권한설정·사용자정보 미표시
5. 직접 URL `/users/permissions` 접근 → 403 차단
6. 대표 로그인 → `PUT /api/users/children/{id}/status` Suspended → 자식 로그인 차단
7. 부모 user_id 정합 (heritage_parent_user_id 컬럼 박제)

**검증 포인트** (헌법 #7·#11):
- SaaS↔ERP 권한 혼용 0
- PermissionPage 자식 계정 접근 0
- 부모↔자식 ID 분리 정합

### 시나리오 5 — 통신 차단 후 자가 회복 (헌법 #27·#28·#30)

**목표**: 신규 가입 계정 PC에서 cloudflared·인터넷·DB 차단 시 5분 이내 자가 회복.

**단계**:
1. 시나리오 1 완료된 PC에서 ERP 사용 중
2. cloudflared 서비스 강제 종료 (`sc stop cloudflared`)
3. 5분 이내 워치독 감지 → CommsRecoveryBanner 표시 → 자동 재시작 (관리자 권한 필요 시 1클릭 봉합)
4. Windows Update 강제 재부팅 시뮬레이션
5. 재부팅 후 5분 자동 점검 → cloudflared 자격증명 갱신 → 정상화
6. 백신 5종 (V3·알약·Norton·McAfee·Defender) 환경에서 격리 0 검증

**검증 포인트**:
- 본사 데이터 전송 0 (헌법 #22 — 워치독 ping 메타만)
