## 결함 D-1 — 멀티캘린더(시각화 선택 라디오) 사라짐

### 사장님 요구
대시보드에 **라디오 버튼**으로 4개 시각화를 선택 전환:
1. **멀티캘린더** (수정 직전 캘린더 기능: 미수·미지급·연차·월차 등 표시)
2. **매출·매입 추이**
3. **거래처 순위**
4. **외상 연체 순위**

### 실측 (현 상태)
- 5/26 결재로 `LeaveCalendar`(Dashboard.razor:124 주석 보존) → `UnifiedCalendar`(:125)로 교체.
- **라디오 전환 UI 자체가 없음.** 항상 UnifiedCalendar만 단독 렌더.
- 차트 옵션·데이터는 **고아 상태로 존재**: `_chartOptions`(:263, 월별추이), `_partnerChartOptions`(:285, 거래처TOP5), DTO `MonthlyTrend`(:518)·`TopPartners`(:525)·`PartnerAgingRow`(연체) — **렌더되는 곳 0건.**
- 즉 데이터·옵션 토대는 있고 **전환 UI + 차트 렌더 블록만 없음.**

### 영향
- UX 후퇴(사장님이 쓰던 멀티캘린더 기능 실종). 워크플로우 데이터 흐름엔 영향 없음(표시 계층).

## 결함 D-2~D-5 — 카드 클릭 라우팅 오결선 (4건)

| # | 카드 | 현재 이동(실측) | 요구 이동 |
|---|---|---|---|
| **D-2** | 오늘매출 (Hero, Dashboard.razor:31-34) | **클릭 핸들러 없음** | **오늘매출 목록** (오늘 날짜 필터) |
| **D-3** | 이번달매출 (KPI Hero, :93) | `/sales/summary` (집계) | **이번달매출 목록** (당월 필터) |
| **D-4** | 이번달매입 | **카드 자체 없음** (KPI는 재고·미수금만) | **카드 신설 → 이번달매입 목록** (당월 필터) |
| **D-5** | 미수금 (:109-113) | `/collections` | **미수금 목록** (미수금 잔액 목록) |

### 실측 라우트 후보 (작업지시서서 매니저가 페이지 기능 확인 후 확정)
- 매출목록: `/deliveries`(거래명세서=매출) 또는 `/sales/summary`(기간필터) — 사장님 "목록" 의도에 맞는 페이지 + 기간 프리필터(`?from=&to=`) 부착.
- 매입목록: `/purchases` 또는 `/purchases/summary` + 당월 필터.
- 미수금목록: `/collections`(수금) 또는 업체별원장(수불부) — "미수금 잔액 목록" 성격에 맞는 쪽.
- ※ 기존 GoToTransaction(:339)이 이미 `?from=&to=` 패턴 사용 — 동일 패턴 재사용 가능.

### 영향
- 사장님이 카드 누르면 엉뚱한 화면 → "동작 엉망" 직접 체감. 클릭=목록 직행이 ERP 기본 UX(헌법: 처음 보는 사람이 혼자 쓸 수 있냐).
