### 🚨 진범 #51 (NEW) — MDB 폴더 경로 입력 부담

#### 현재
```
사용자 입력: C:\HITWIN
```

#### 문제
- 일반 사장님(60대+)이 *"폴더 경로"* 개념 모름
- C:\ 시작이 익숙하지 않음 (D:\, E:\ 또는 바탕화면)
- 레거시 히트판 설치 폴더가 *"C:\HITWIN"*인지 사장님이 알아야 입력 가능
- 사장님 헌법 *"설명서 없이 처음 앉아서도 그냥 됐다"* 위반

#### 봉합 옵션
| 옵션 | 변경 | 효과 |
|---|---|---|
| **A** | 폴더 자동 탐지 (C:\HITWIN·D:\HITWIN·Desktop\HITWIN 등) | 사용자 입력 0 |
| **B** | "파일 선택" 다이얼로그 (Blazor JSInterop) | 사용자 1클릭 |
| **C** | 사장님 PC 부팅 시 HITWIN 위치 자동 등록 + 다음 마이그 시 1클릭 | 1회 등록 후 자동 |

#### PM 1차 추천: A + B 병행

### 🚨 진범 #52 (NEW) — 마이그 실패 시 안내 부재

#### 현재 코드
```csharp
else if (t.Status == "failed")
{
    <span style="color:var(--mud-palette-error)">@(t.ErrorMessage ?? "실패")</span>
}
```

#### 문제
- 카드에 "실패" 1단어만 표시
- 사장님이 *"왜 실패했는지·어떻게 해결할지"* 모름
- 사장님 헌법 *"처음 쓰는 직원이 물어보지 않고 해결할 수 있어야"* 위반

#### 봉합 옵션
- 실패 사유별 가이드 안내 (예: *"파트너 매핑 실패 — 사장님 자문 필요"*)
- *"해결 도구"* 버튼 (재시도·건너뛰기·도움말)
