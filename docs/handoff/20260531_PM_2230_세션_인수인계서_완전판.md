### Phase 7: 진범 #99 봉합 ⭐
**커밋**: 05f45d6 (1건)

**증상**:
```
GET /api/items/{itemId}/specs?activeOnly=true → 500
DataException: Error parsing column 0 (SpecId - Guid)
InvalidCastException: Object must implement IConvertible
```

**근본 원인 (DB 매니저 진단)**:
1. `DB-76_item_specs_seed.sql`이 MariaDB `UUID()` 함수로 시드 → row의 `spec_id`/`item_id`가 binary(16) 메타 힌트 박제 가능
2. MySqlConnector가 해당 컬럼을 `Guid` 타입으로 추론
3. Dapper가 `string` DTO에 매핑 시도 → InvalidCastException

**봉합 (`src/HitPan.Application/Services/ItemSpecService.cs:21-42`)**:
```csharp
const string sql = @"
    SELECT
        CAST(spec_id AS CHAR) AS SpecId,     -- ← Guid 회피
        CAST(item_id AS CHAR) AS ItemId,     -- ← Guid 회피
        spec_value AS SpecValue,
        is_default AS IsDefault,
        sort_order AS SortOrder,
        is_active AS IsActive,
        created_at AS CreatedAt
    FROM item_specs
    WHERE item_id = @ItemId AND is_active = 1
    ORDER BY sort_order, created_at";

await _uow.EnsureOpenAsync(); // ← BomService 패턴 정합
return await _uow.GetDbConnection().QueryAsync<ItemSpecDto>(sql, new { ItemId = itemId });
```

**4개 메서드 모두 `EnsureOpenAsync` 추가**.

**검증**:
```bash
curl http://localhost:5257/api/items/<itemId>/specs?activeOnly=true
# 200 OK, [{"specId":"...", "specValue":"유지보수1개월", "isDefault":true}]
```

**🚫 재발 방지 규칙 (헌법 후보)**:
> **MariaDB `UUID()` 함수로 시드한 char(36) 컬럼은 SELECT 시 반드시 `CAST(컬럼명 AS CHAR)` 명시.**
> 또는 시드 SQL에서 `UUID()` 대신 명시 UUID 문자열 사용.

protected override async Task OnInitializedAsync()

// 변경 후
private bool _loaded = false;

protected override async Task OnAfterRenderAsync(bool firstRender)
{
    if (firstRender && !_loaded)
    {
        var auth = await AuthState.GetAuthenticationStateAsync();

            await LoadMonthlyAsync();

        }
    }
