## 시연 2 — 랜딩 가입 → 백오피스 승인 → 시리얼 발급 (10분)

### 목표
랜딩페이지에서 신규 사업자가 가입 → 백오피스에서 본사가 승인 → 시리얼 자동 발급 → ERP webhook까지 한 흐름.

### 단계

**2-1. 랜딩 가입 신청** (가짜 사업자 차단도 함께 시험)

브라우저 다른 탭에서 https://landing.hitpan.kr 접속 → "가입 신청" 클릭

먼저 **가짜 사업자번호** `123-45-67890` 입력 → 차단되는지 확인 ✅

다음 **실제 활성 사업자번호** 입력 (사장님 보유 분 중 1개) → 다음 단계 진행:
- 회사명: `시연용 ${날짜}`
- 대표자명: 사장님 성함
- 이메일: 받을 수 있는 메일 주소
- 전화: 010-xxxx-xxxx
- 요금제: basic 선택
- 결제: 시연 모드 (테스트 결제 또는 무통장 선택)

**2-2. 백오피스 가입 신청 목록 확인**

https://back.hitpan.kr/admin/signups 진입
- 방금 가입한 건이 "승인 대기" 상태로 표시되는지 확인

**2-3. 승인 클릭**

해당 행의 **"승인"** 버튼 클릭

**2-4. 🔥 시리얼 키 즉시 메모**

승인 응답 화면에 시리얼이 **한 번만** 표시됩니다:

```
HITP-XXXX-XXXX-XXXX-XXXX
```

→ **반드시 즉시 복사**해서 메모장에 붙여놓으십시오. 화면 떠나면 다시 안 나옵니다.

**2-5. webhook 전송 확인** (PM이 함께 보겠습니다)

1분 내로 사장님 PC ERP의 `local_subscription` 테이블이 자동 UPSERT 됩니다.
- 사장님은 별도 동작 불필요
- PM이 SSH 로그·ERP DB로 동기화 확인

### 통과 기준
- 가짜 사업자번호 100% 차단
- 진짜 사업자번호 가입 OK
- 백오피스에 즉시 표시
- 승인 시 시리얼 발급 + webhook 즉시 디스패치

## 시연 3 — ERP 시리얼 인증 + 기기 등록 (10분)

### 목표
사장님이 ERP에 로그인 → 시리얼 입력 → "이 PC 등록?" → device_token 발급까지.

### 단계

**3-1.** 브라우저에서 https://demo.hitpan.kr 접속

**3-2.** 로그인
- 아이디: `tenant@hitpan.kr`
- 비밀번호: `Admin1234!`

**3-3.** 좌측 메뉴 → **계정관리 → 회사 정보** 클릭
(또는 주소창: https://demo.hitpan.kr/company)

**3-4.** 화면 우측 **"시리얼 인증"** 박스 확인

박스가 안 보이면 → 0-1 (ERP Web 재기동) 다시 실행 필요.

**3-5.** 시연 2에서 메모한 시리얼 입력
- 형식 예시: `HITP-MT25-J854-ZNXN-FNNN`
- "시리얼 인증" 버튼 클릭

**3-6.** 인증 성공 시 "이 PC를 등록하시겠습니까?" Y/N 박스 표시
- **"Y - 이 PC 등록"** 클릭

**3-7.** device_token 발급 완료 확인
- 화면 하단에 "기기 등록 완료" 메시지
- 기기 카운트 표시: `PC 1/5 등록됨`

**3-8. 잠금 시험 (선택)**

다른 시크릿 창 열어서 **잘못된 시리얼 5회** 입력:
- `HITP-WRNG-WRNG-WRNG-WRNG` 5회 시도
- 5회째 → "5회 실패. 60분 잠금" 메시지
- 잠금 해제는 본사 수동 (`POST /api/admin/serial-locks/{id}/unlock`)

### 통과 기준
- 시리얼 박스 정상 노출
- 인증 통과 → Y/N 박스 표시
- Y 클릭 → device_token 발급 + localStorage 저장
- 잘못된 시리얼 5회 → 60분 잠금
