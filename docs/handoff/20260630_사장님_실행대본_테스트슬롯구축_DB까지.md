## 4. 진짜 슬롯 구축 (DB까지)


### 이때 화면에서 사장님이 확인할 핵심 줄 (PM이 미리 예고)
| 단계 | 떠야 할 메시지 | 의미 |
|---|---|---|
| [G] | `DbName='hitpan_e2e' (운영 미터치 확인)` | 운영 보호 가드 통과 |
| [1] | `생성: C:\HitPanTest\...` | 격리 폴더 생성 |
| [2] | `clean DDL 확인: ...hitpan_db_clean.sql` | 출하 DDL 단일 진실원 사용 |
| [2] | **`테이블 수 검증 통과: 124 (>= 124)`** | ⭐핵심 — PM이 미리 124개 확인함 |
| [4] | `db.conf 작성 완료(PRIMARY_DOMAIN=e2e-comms.hitpan.kr...)` | 슬롯 설정 |
| [5] | `마커 작성 완료(ENV=TEST...)` | 실측 안전망 마커 |
| [6] | `cloudflared-test 서비스: ... → 등록 SKIP(B갈래 의존)` | ⭐정상 — 터널은 다음 단계 |
| DONE | `[완료] Build-TestSlot — ... 베이스 준비됨` | 초록색 = 성공 |

### ⭐ 가장 중요한 한 줄
**`테이블 수 검증 통과: 124`** — 이게 뜨면 DB슬롯이 정상으로 섰습니다.
(PM이 hitpan_db_clean.sql을 직접 세어 124개·schema_migrations 포함 확인했으므로, 정상이면 abort 없이 통과합니다.)

### [6]단계 SKIP은 정상입니다
`cloudflared-test ... 등록 SKIP`, `MariaDB-test ... 등록 SKIP` — **이건 오류 아닙니다.**
터널 토큰·서비스 격리 경로는 다음 결재 안건(헌법 #29 추가)이라 일부러 건너뜁니다.
