## 🗺️ 핵심축 전체 지도 (가입 → 정상작동)

```
[랜딩 NCP]  SignupPage.razor:477
   → POST api/landing/signup
[백오피스 NCP]  LandingSignupController:51
   → INSERT landing_signups + tenants(status=pending)
   → 이메일 발송
        ↓ (관리자 승인)
[백오피스 NCP]  SignupsAdminController:90
   → 시리얼 발급 HITP-XXXX(HMAC해시만 저장) + tenants active
   → CloudflareDomainService.IssueAsync → CNAME 생성 → tenant_domains
        ↓ (고객 설치)
[ERP 로컬]  LicenseSetupPage.razor:238
   → POST api/landing/license/claim
[백오피스 NCP]  LandingPublicController:143
   → 라이선스·사업자번호 해시 검증 → BootstrapToken 발급(HMAC, 10분)
        ↓
[ERP 로컬]  CompanyBootstrapController:42  POST api/setup/bootstrap
   → 토큰 서명검증(백오피스 URL 호출 0건) → local_company + local_subscription 저장
   → is_locked_from_landing=1
        ↓
[ERP 로컬]  CompanyBootstrapController:198  POST api/setup/create-parent
   → users+employees+warehouses+accounts 원자적 생성(트랜잭션)
   → 부모계정(tenant_admin, is_parent=1)
        ↓
[설치 부트스트랩]  BootstrapInstall.ps1:81 → POST back.hitpan.kr/api/installer/bootstrap
   → 터널 자동발급 → DNS target 갱신 → ingress 라우팅 → cloudflared service install {token}
        ↓
[ERP 로컬]  AuthController:35  POST api/auth/login
   → JWT(account_type=tenant_admin/tenant_user 둘뿐) → 약관동의 Y/N → 정상작동
        ↓
[업데이트]  Watchdog → updates.hitpan.kr/manifest.json → 채널분기 → 동의 Y/N → 백업 → (Velopack 미구현)
```
