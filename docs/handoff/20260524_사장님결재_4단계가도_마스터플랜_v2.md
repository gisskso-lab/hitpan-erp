## 📋 4단계 가도 정밀 정리

### 🎯 1단계 — 히트판 ERP 페이지 완성

#### 1-1) AI 챗봇 학습·완성
- 베타 30 안내문 v2 RAG 임베딩
- 잔존 §예외 3건 (#70·#71·#90) 안내 매뉴얼
- 고객 예상 질문 50건 답변
- BYOK 모드 + 풀(Pool) 모드 + 하이브리드 (사장님 5/12 결재)
- **담당**: AI수석 (단독)
- **예상 기간**: 5~7일

#### 1-2) 전자세금계산서 API 연동 (이세로 자동 연동)
- 거래명세서 → 세금계산서 자동 발행 + 이세로 전송
- 이세로 API 외주 vs 자체 결정 (사장님 5/12 보류 결재 재검토)
- 사용자 시점: 거래명세서 확정 시 → 자동 세금계산서 → 자동 이세로 전송
- 잔존 #71 21쌍도 이세로 기반 추후 봉합 가능성 검토
- **담당**: 백엔드 매니저 + 메이크빌 외주 협력
- **예상 기간**: 10~14일

#### 1-3) 히트판 ERP 6대 워크플로우 100% 완성
정밀 분해 (PM 5/24 진단):

| 워크플로우 | 현재 | 보완 영역 |
|---|---|---|
| #1 설정 | 95% | 양식설정 화면 마감 + 권한 그라뉼라 |
| #2 마스터 | 90% | 업체별·상품별 원장 화면 + BOM UI 정밀화 |
| #3 매입 | 85% | **반품 API + UI** (사장님 5/17 미구현 박제) |
| #4 판매 | 80% | **반품 API**·견적서 PDF 모바일 버그 봉합 |
| #5 현황 | 70% | 필터링·집계 화면 + 대시보드 |
| #6 재무 | 75% | 경비처리·세무 자동 전송 (1-2와 연동) |

- **담당**: 백엔드 매니저·프론트 매니저 풀가동
- **예상 기간**: 14~21일

#### 1-X) 모든 개발 문서 작성
- 6대 워크플로우 PRD 정합
- API 문서 (Swagger + Postman)
- DB ERD 최신화
- 운영 매뉴얼
- **담당**: PM + AI수석
- **예상 기간**: 5~7일 (1-3과 병렬)

**1단계 총 예상 기간**: 약 3~4주 (5/25~6/22)

### 🎯 2단계 — 백오피스 설계·개발

#### 2-1) PRD 재검토 + 작지서 (5/25~5/27)
- `docs/design/PRD_BACKOFFICE.md` (5/6 작성본) 재검토
- 사장님 요구: ① 고객사 생성·관리, ② 구독 결제 관리, ③ 대리점 결제·영업 실적·결제 관리
- 어벤져스 9자 회의 결재

#### 2-2) 백오피스 영역 7개 정의
| 영역 | 기능 |
|---|---|
| **고객사 관리** | 가입 고객 리스트·상세·활성/비활성·JIT CS 토큰 |
| **구독 결제 관리** | 월별 매출·결제 실패·환불·구독 변경·토스 webhook |
| **대리점 관리** | 등록·실적·MRR·수수료 정산·정산 영수증 |
| **CS 관리** | 챗봇 대화 이력·콜센터 티켓·원격 CS 로그 |
| **모니터링** | 워치독 17개 상태·통신 무결성·SLA 99.99% |
| **백업·DR** | E2E 암호화 백업·복구 (헌법 #22) |
| **권한·감사** | 본사 직원 권한·감사 로그 (헌법 #24) |

#### 2-3) 설계·개발 영역 6개
- ① 데이터 설계 (DB 매니저)
- ② 백엔드 설계 (백엔드 매니저)
- ③ 프론트 설계 (프론트 매니저 + 디자이너)
- ④ 보안 설계 (보안 매니저 1·2)
- ⑤ 일정·기능 정의 (PM + ERP 매니저)
- ⑥ 요구사항 정의 (PM + 마케팅·기술영업)

**2단계 총 예상 기간**: 약 3~4주 (6/22~7/20)
