## 5. 통합 우선순위 (한 줄 요약)

```
[지금] P0-검사(잠복사고가 백지실측 막나) ← B 검사 재개
   │
   ├─ 막음    → 트랙B(B-1·B-2) 선행 → 트랙A → 백지 UPDATE 첫통과
   └─ 안막음  → 트랙A 바로(A-1~A-7) → 백지 UPDATE 첫통과 / 트랙B는 별건 후순위
   │
   └─ 트랙C(MetaPing) = 병행, 목표 후. C-0 사장님 결정 대기.
```

**핵심**: 원래 목표(백지 UPDATE 첫통과)로 가는 최단경로 = 트랙A. 트랙B가 막는지만 P0-검사로 확정하면 길이 뚫린다.
