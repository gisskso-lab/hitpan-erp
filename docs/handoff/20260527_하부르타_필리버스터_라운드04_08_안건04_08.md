## 📋 안건 6 — TunnelSecret 자동 재발급

### Round 6.1 — 백엔드 매니저 제안

**박제 — 오늘 5/27 사고 사례:**
- cloudflared 죽인 후 재기동 시 `Invalid tunnel secret`
- 본 PM이 수동으로 token 재발급 + cred-file 백업 후 재발급 → 정상

**자동화:**
```powershell
# cloudflared 로그 tail
$log = "$env:USERPROFILE\.cloudflared\cloudflared.log"
Get-Content $log -Wait | ForEach-Object {
  if ($_ -match "Invalid tunnel secret") {
    $tunnelId = "e03a3b95-...."
    $credFile = "$env:USERPROFILE\.cloudflared\$tunnelId.json"
    Move-Item $credFile "$credFile.bak_$(Get-Date -Format yyyyMMddHHmmss)" -Force
    cloudflared tunnel token --cred-file $credFile $tunnelId
    Restart-Service cloudflared
    Write-EventLog -LogName Application -Source HitPanWatchdog -EntryType Warning -EventId 28003 -Message "TunnelSecret rotated, auto-regenerated"
  }
}
```

### Round 6.2 — 보안 매니저 2 추가

> *"자동 재발급 영역 = 정합. 단 무한 재발급 영역 방지 영역 필수.*
>
> *Cool down: 재발급 1회 / 1시간 영역. 초과 시 본사 알림 영역."*

### Round 6.3 — 합의

WS-28-C에 통합. 전원 동의.

### Round 8.1 — DB 매니저 제안

**메타 ping 구조:**
```json
{
  "tenant_id_hash": "sha256:abc...",
  "timestamp": "2026-05-27T12:00:00Z",

  "recent_recovery_count": 0,
```

**금지:**
