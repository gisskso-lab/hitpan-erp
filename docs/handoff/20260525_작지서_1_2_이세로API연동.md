## 🎯 4가지 핵심 흐름 (설계팀장 SAP 30년 표준)

### 1. 거래명세서 확정 → 세금계산서 자동 생성 (2모드, 설계팀장 SAP 30년)
- **일괄 모드**: 하루 1회 18:00 자동 일괄 발행 (헌법 #26 v3 Timeout 86400초 정합)
- **수동 즉시 모드**: 사용자가 거래명세서 화면에서 1클릭 즉시 발행
- 헌법 #20 끊김 0: 거래명세서 → 세금계산서 → 매출원장 → 세무 신고
- 금액 재계산 게이트 (P2-2 결재): SAP 표준 차단 (영업 수기 수정 즉시 차단)
- **즉시 자동 발행 폐기 사유**: 정정·취소 폭주 유발 (과거 LG SI 사고, 설계팀장 박제)

### 2. 세금계산서 → 이세로 자동 전송 (Timeout 3축 분리)
- **발행 Timeout 60초** (수동 즉시 모드)
- **조회 Timeout 10초** (실시간 상태 확인)
- **일괄 Timeout 86400초** (18:00 야간 배치, 헌법 #26 v3 정합)
- 실패 시 재시도 큐 + 사용자 알림 (DLQ 4중)

### 3. 이세로 → 신ERP 역방향 동기화
- 이세로 발행번호 + 승인번호 신ERP 저장
- 잔존 #71 21쌍도 이세로 승인번호로 추후 봉합 가능성 검토 (사장님 5/24 통찰)
- 세금계산서 ↔ 거래명세서 source_id 멱등 키 + 무결성 검증 게이트 (SAP VBRK→BSEG 패턴)

### 4. 세무사 자동 전송 — 2모드 단순화 (설계팀장 SAP DATEV 30년)
- **자동 모드**: 월말 자동 일괄 전송
- **수동 즉시 모드**: 사용자 1클릭 즉시 전송
- **3모드 폐기 사유**: 옵션 과다 = UX 실패 (헌법 #25 정합)
- **반자동 모드**: 6개월 운영 후 재검토
