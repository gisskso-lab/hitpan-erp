## 2. 작업 범위 (3블록)

### 블록 A — 코드 정리 (PM/개발팀, 인프라 0건)
- A-1. `build-installer.ps1:181` 주석의 옛 숫자 "137" → "121"로 정정(혼선 차단). **게이트 변수(:212 `121`)는 손대지 않음 — 이미 정확.**
- A-2. (확인만) 도메인 자동화 코드는 수정 0 — 이미 완비. 켜기만 하면 됨.

### 블록 B — CF 열쇠 주입 (🔴 사장님 입회하 PM, 헌법 #29)
- B-1. **사전 점검(읽기)**: hitpan.kr 이 Cloudflare 등록됐는지·Zone 활성·API 토큰 발급 가능 상태인지 확인. 가이드 `docs/operations/CLOUDFLARE_ENV_GUIDE_20260605.md`.
- B-2. **입회 주입**: 사장님이 화면 앞에 계신 상태에서, 가이드대로 `CLOUDFLARE_API_TOKEN`·`CLOUDFLARE_ZONE_ID`·`CLOUDFLARE_ACCOUNT_ID` 3개를 **Windows 사용자 환경변수**로 등록.
  - 토큰 자체는 **사장님이 Cloudflare 대시보드에서 생성**(PM은 토큰 발급 행위 안 함).
  - 환경변수 등록은 사장님 입회·승인 하에 1줄씩. PM 단독 조작 금지.
- B-3. **입회 재확인 의무**: B-1·B-2 각 단계 전 "지금 이 조작 진행해도 됩니까?" 사장님 확인. 입회 없는 단독 진행 = #29 위반.

### 블록 C — 첫 발급 → test 환경 묶음 (PM, B 완료 후)
- C-1. 자동화로 **test 서브도메인 1건 발급** — `domainAlias=test` 또는 결재된 명칭. 이게 통신무결성 test 도메인.
- C-2. test 슬롯 구축(작1 5-4): `hitpan_e2e` DB + `cloudflared-test`·`MariaDB-test` 서비스명 + 포트 15234/15257 + **`HITPAN_TEST_ENV.marker` 생성**(작2 화이트리스트 충족).
- C-3. 작2 봉합 스크립트 **반증 테스트**(데이비드 박 SoD) → 통과 후에만 실측.
