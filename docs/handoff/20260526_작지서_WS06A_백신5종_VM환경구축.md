### 옵션 A: Hyper-V (PM 권고)
- **장점**: Windows 10/11 Pro 기본 탑재, 무료, MS 표준
- **단점**: 사장님 PC가 Windows 10/11 Pro 필요
- **사양**: 메모리 32GB 권장 (각 VM 2GB × 15 = 30GB)

### 옵션 B: VirtualBox
- **장점**: 완전 무료, 크로스 플랫폼
- **단점**: 성능 Hyper-V 대비 약함

### 옵션 C: VMware Workstation Pro
- **장점**: 성능 최상, GUI 우수
- **단점**: 30만원/년 (사장님 추가 결재)

**PM 권고: Hyper-V** — 무료 + MS 표준 + 사장님 PC Windows 11 Pro 정합.
