## 📋 EV 인증서 신청 가이드 (사장님 직접 가도)

### Step 1: 공급사 선택 (PM 권고: DigiCert)

| 공급사 | 가격 | 발급 기간 | 평판 |
|---|---|---|---|
| **DigiCert EV** | 약 60~70만원/년 | 3~5일 | ★★★★★ (글로벌 표준) |
| Sectigo EV | 약 40~55만원/년 | 5~7일 | ★★★★ |
| GlobalSign EV | 약 60만원/년 | 5~7일 | ★★★★ |

**PM 권고: DigiCert** — Microsoft Defender SmartScreen 평판 가장 빠름.

### Step 2: 사장님 준비물
1. **사업자등록증** (히트판 ERP 사업자)
2. **법인 인감 또는 대표자 인감**
3. **신용카드** (60만원/년 결제용)
4. **회사 대표 연락처** (인증 전화)
5. **사업장 주소** (인증 우편물)

### Step 3: 신청 절차 (PM 가이드)
1. **DigiCert 한국 파트너 문의**: 02-XXX-XXXX (한국 영업)
   - 또는 [DigiCert 한국 공식 사이트](https://www.digicert.com/kr/)
2. **EV Code Signing 신청서** 작성 (PM이 사장님 정보 입력 영역 가이드)
3. **사업자등록증 + 인감 제출** (스캔 이메일 또는 우편)
4. **인증 전화** (DigiCert 직원이 사업자번호 + 대표자 확인)
5. **카드 결제 60만원**
6. **EV 인증서 USB 토큰 수령** (우편 3~5일)

### Step 4: 보안 매니저 2 가도 (수령 후)
- 인증서 토큰 → PM 안전 보관 (헌법 #29 정합)
- 설치 EXE 서명 + ONNX 모델 카탈로그 서명
- Day 3 게이트 5/30 최종 검증
