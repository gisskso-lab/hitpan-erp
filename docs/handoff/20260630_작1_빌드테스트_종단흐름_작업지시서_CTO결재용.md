## 3. 이번 작업 = 3블록 (결재 대상)

### 블록 A — 솔루션 전체 빌드 ✅ (이미 완료, 결재 불필요)
- 위 2번에서 완료. 산출물 없는 단순 컴파일 검증이라 읽기성으로 처리함.

### 블록 B — 종단 흐름 실측 (가입→시리얼→ERP로그인)
**대상 코드(전부 소스 실재 확인):**
- 랜딩 가입: `LandingSignupController` / `SignupsAdminController`
- 도메인 발급: `CloudflareDomainService` + `TenantDomainController` (Cloudflare API)
- 시리얼 발급: `ResellerSerialController` / `SerialVerifyController`
- 설치 부트스트랩: `InstallerBootstrapController`

**⚠️ 결재벽 — 어디까지 로컬 / 어디부터 헌법 #29:**

| 구간 | 실행 위치 | 결재 |
|---|---|---|
| 랜딩 가입 폼 → 백오피스 가입 INSERT | 로컬 빌드 기동 가능 | PM 가능 |
| **도메인 자동발급(Cloudflare API 호출)** | **실 DNS 레코드 생성 = 헌법 #29** | **사장님 손/입회** |
| 시리얼 발급 → 검증 | 로컬 빌드 기동 가능 | PM 가능 |
| 설치파일 다운 → ERP 부트스트랩 | **터널 발급 = 헌법 #29** | **사장님 손/입회** |
| ERP 로그인 → 정상작동 | 로컬 hitpan_e2e 슬롯에서 가능 | 슬롯 선 뒤 |

→ **순수 로컬 구간**은 PM이 빌드 기동·실측. **DNS·터널 발급 구간**은 사장님 #29 결재·입회 필수(전임 PM 해고 사유).

### 블록 C — 설치파일(EXE) 빌드

## 4. PM 권고 순서 (안전 — 두더지잡기 차단)

```
[1] 블록A 솔루션 빌드          ✅ 완료
[2] 블록B 순수 로컬 구간 실측   → PM 빌드 기동 (가입·시리얼 로컬)
[3] 블록B DNS·터널 구간        → 사장님 #29 결재·입회
[4] 블록C EXE 빌드            → 사장님 GO + 빈데이터 게이트 확인 후
```

**PM 의견**: B를 로컬 구간부터 검증해 흐름 무결성을 먼저 확인하고, DNS·터널·EXE는 사장님 손이 필요한 #29 구간이라 **묶어서 입회 결재**가 효율적. EXE는 종단 흐름이 로컬에서 검증된 뒤 마지막에.
