# NCP 인프라 설계도 (2026-06-06 토)

> 사장님 결재 받기 위한 설계 문서. 결재 후 NCP 화면 안내 모드로 구축.

---

## 1. 큰 그림 (사장님 운영 설계)

```
                       hitpan.kr (가비아 등록)
                              │
        ┌─────────────────────┼─────────────────────┐
        │                     │                     │
        ↓                     ↓                     ↓
{고객사ID}.hitpan.kr     landing.hitpan.kr     back.hitpan.kr
        │                     │                     │
        ↓                     ↓                     ↓
   고객사 PC 로컬          NCP 클라우드          NCP 클라우드
   cloudflared 터널        (랜딩페이지)          (백오피스)
        │
        ↓
   히트판 ERP
   (본사 데이터 0건)
```

오늘 NCP 인프라 작업 대상: **landing.hitpan.kr + back.hitpan.kr 한 서버** (랜딩 + 백오피스 한 NCP 서버에 같이)

ERP는 본 작업 범위 밖 (기존 고객사 PC + cloudflared 유지).

기존 `demo.hitpan.kr` 사장님 데모 ERP — 가비아 DNS 그대로 보존.
                   │
                   ↓
        ┌─────────────────────┐
        │     NCP 서버 (1대)    │
        │  - 백오피스 (.NET 8)  │
        │  - 랜딩 (.NET 8)      │
        │  - Nginx 리버스 프록시 │
        │  - SSL (Let's Encrypt) │
        └──────────┬──────────┘
                   │
                   ↓
        ┌─────────────────────┐
        │  NCP Cloud DB MySQL  │
        │  - hitpan_backoffice │
        │  - 자동 백업·HA       │
        └─────────────────────┘
```

## 2. NCP 자원 구성

### 서버 (Compute)
| 항목 | 값 | 이유 |
|---|---|---|
| 종류 | Server (VPC) | 가상 머신 |
| OS | Ubuntu 20.04 또는 22.04 | .NET 8 지원 + 무료 |
| 사양 | **Standard 2vCPU 4GB RAM** | 베타 20곳 수용 충분 |
| 디스크 | 50GB SSD | 코드 + 로그 + 임시 파일 |
| 공인 IP | 1개 (필수) | 외부 접속 |
| 리전 | 한국 (KR) | 국내 법령 정합 |

**예상 월 비용**: 4~6만원

### DB (Database)
| 항목 | 값 |
|---|---|
| 종류 | Cloud DB for MySQL |
| 엔진 | MySQL 8.0 (호환: MariaDB 11.4 사용 중 → 90% 호환) |
| 사양 | **micro 1vCPU 2GB RAM** (베타용) |
| 스토리지 | 10GB SSD |
| 백업 | 자동 (매일 1회, 7일 보존) |
| 다중 AZ | OFF (베타 동안, 정식 출시 시 ON) |

**예상 월 비용**: 2~3만원

### 네트워크 (Network)
| 항목 | 값 |
|---|---|
| VPC | 1개 (private 10.0.0.0/16) |
| Subnet | Public (서버용) + Private (DB용) |
| ACG (방화벽) | HTTP 80, HTTPS 443, SSH 22 |
| 공인 IP | 1개 |

**예상 월 비용**: 1~2만원

### **합계**: 월 7~11만원 (사장님 예산 알림 한도 10만원 안)

## 3. 도메인 연결 (가비아 DNS)

### 추가할 레코드 2개 (사장님 운영 설계 정합)
| 레코드 | 호스트 | 값 (Type) | TTL |
|---|---|---|---|
| 1 | `landing.hitpan.kr` | NCP 서버 공인 IP (A) | 600 |
| 2 | `back.hitpan.kr` | NCP 서버 공인 IP (A) | 600 |

### 기존 보존 (절대 건드림 금지)
- `demo.hitpan.kr` (ERP 사장님 데모)
- `api-demo.hitpan.kr` (API)
- 기타 사장님이 사용 중인 모든 서브도메인
- 메일 MX 레코드
- TXT 레코드 (인증용)

→ **추가만, 수정·삭제 0건**.

---

## 4. 보안 설정

### 서버 ACG (방화벽)
| 포트 | 용도 | 출처 |
|---|---|---|
| 22 (SSH) | PM 원격 작업 | 사장님 IP + PM IP만 |
| 80 (HTTP) | Let's Encrypt 인증서 발급 | 전체 |
| 443 (HTTPS) | 외부 접속 | 전체 |
| 3306 (MySQL) | 막음 (DB는 Private) | 차단 |

### DB ACG
- 서버 Private IP만 허용
- 외부 직접 접속 차단

### SSL
- Let's Encrypt 자동 발급·갱신 (90일마다)
- 무료, NCP 자동 통합

## 5. 배포 흐름 (월요일 작업 예정)

1. 백오피스 코드 빌드 (`HitPan.Backoffice` + `HitPan.Backoffice.API`)
2. NCP 서버에 SSH로 코드 업로드
3. systemd 서비스 등록 (자동 재시작)
4. Nginx 리버스 프록시 설정
5. SSL 자동 발급
6. 외부 접속 테스트

→ 오늘은 1~5단계까지의 **인프라 준비**. 코드 배포는 월요일.

## 6. 작업 순서 (오늘)

| # | 작업 | 사장님 | PM | 소요 |
|---|---|---|---|---|
| 1 | 본 설계도 결재 | 결재 | — | 1분 |
| 2 | NCP 서버 생성 | 화면 클릭 | 안내 | 10분 |
| 3 | NCP Cloud DB 생성 | 화면 클릭 | 안내 | 10분 |
| 4 | 공인 IP 발급 | 화면 클릭 | 안내 | 3분 |
| 5 | 서버에 공인 IP 연결 | 화면 클릭 | 안내 | 2분 |
| 6 | ACG (방화벽) 설정 | 화면 클릭 | 안내 | 5분 |
| 7 | 가비아 DNS 레코드 2개 추가 | 가비아 로그인 + 추가 | 안내 | 5분 |
| 8 | DNS 전파 확인 (ping) | — | PM | 30분 대기 |

**총 소요**: 약 1시간 (사장님 실제 클릭 시간 30~40분)

## 7. 위험 영역

| 위험 | 대비 |
|---|---|
| 가비아 DNS에서 기존 레코드 잘못 건드림 | 추가만, 수정·삭제 0건. 사장님 클릭 전 PM이 한 번 더 확인 |
| 공인 IP가 NCP에서 동적으로 바뀜 | **고정 IP (Public IP)** 발급, 영구 유지 |
| 비용 예상보다 폭주 | 예산 알림 50%/80%/99% 이미 설정 (오늘 토 완료) |
| 베타 끝나면 자원 정리 안 되면 비용 계속 | 정식 출시 후 자원 검토 일정 별도 |

## 9. 사장님 결재 후 첫 동작

NCP 콘솔 들어가셔서 **Menu → Compute → Server** 클릭 → **"+ 서버 생성"** 버튼.

→ PM이 화면별 안내 모드로 동행.
