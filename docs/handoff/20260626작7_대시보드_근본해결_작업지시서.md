## 1. 전수조사 결과 (받아쓰기 차단 — 어제 리스트 반증)

- 어제 리스트 "라우트 한 줄씩" + "GoToTransaction 이미 ?from=&to= 패턴" → **실측 반증**:
  목적지 페이지 4곳(`/deliveries`·`/sales/summary`·`/purchases`·`/collections`)이 **`[SupplyParameterFromQuery]` 0건 = 쿼리 미수신.**
  기존 `GoToTransaction`(Dashboard:346·350)조차 **보내기만 하고 받는 쪽 없음 = 반쪽 구현.**
- → 근본해결 = Dashboard 발신 + **목적지 페이지에 쿼리 수신·초기필터** 양쪽 수술.

## 2. 봉합 범위 (5건)

### D-1 멀티캘린더 라디오 (Dashboard.razor)
- `:125` UnifiedCalendar 단독 → 라디오 4선택(멀티캘린더/매출·매입추이/거래처순위/외상연체순위) + 선택별 렌더.
- 데이터·옵션 토대는 존재(_chartOptions·_partnerChartOptions·MonthlyTrend·TopPartners·PartnerAgingRow). 전환 UI + 차트 렌더 블록 신설.

### D-2 오늘매출 → 오늘 목록 (Dashboard Hero :31-34)
- 클릭 핸들러 신설 → `/deliveries?from={today}&to={today}`.

### D-3 이번달매출 → 당월 목록 (KPI Hero :93)
- `/sales/summary` → `/deliveries?from={monthStart}&to={today}` (목록 직행).

### D-4 이번달매입 카드 신설 → 당월 매입 목록 (KPI Hero :103-113)
- KPI 3장 → 4장 레이아웃. 새 카드 클릭 → `/purchases?from={monthStart}&to={today}`.

### D-5 미수금 → 미수금 목록 (KPI :109)
- `/collections` 유지(미수금 잔액 목록 성격 맞음) — 필터 불필요(전체 미수 목록).

### ★ 공통 — 목적지 페이지 쿼리 수신 (근본해결 핵심)
- `/deliveries`(DeliveryPage)·`/purchases`(PurchaseReceiptPage)에 `[SupplyParameterFromQuery] From/To` 추가 + 로드 시 기간 프리필터 적용.
- 기존 GoToTransaction(:346·350)도 이로써 정상 작동(반쪽 → 완결).
