## 2. ⚠️ 최우선 미결 — 운영 DB ALTER (사장님 결재 후에만, 헌법 #29)
**clean DDL 에 컬럼을 넣어도 운영 중 DB(hitpan_erp·demo 등)엔 자동 반영 안 됨.** 실측으로 발각:
- `hitpan_erp` 에 `item_special_prices.discount_rate`(17차)·`partner_special_prices.discount_rate`(19차) **둘 다 없음** → 그 화면에서 할인율 저장 시 "Unknown column" 500.
- 즉 **신규설치 고객 PC는 동작, 현재 demo/운영 DB는 동작 안 함.** 빌드0/0·스모크PASS 다 통과해도 못 잡음(스모크는 빈 DB만 봄).
- **필요 ALTER(사장님 결재 후 — PM 임의 실행 금지, 자동 분류기도 차단함=정상):**
  ```sql
  ALTER TABLE item_special_prices    ADD COLUMN IF NOT EXISTS discount_rate decimal(5,2) DEFAULT NULL;
  ALTER TABLE partner_special_prices ADD COLUMN IF NOT EXISTS discount_rate decimal(5,2) DEFAULT NULL;
  ```
- 더 큰 함의: **16~19차에 clean DDL 에 추가한 다른 컬럼/테이블도 운영 DB 미반영 가능.** 배포 전 운영 DB ↔ clean DDL 전체 diff 1회 필수.
- 상세: 메모리 [[project_clean_ddl_vs_live_db_gap_20260623]].
