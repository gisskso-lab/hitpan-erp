## 3. S20 Brute force — 진범 추가 박제 ❌

### 실측
```
S20 codes: 405,405,405,405,405,405,405,405,405,405
Allow: GET, HEAD
```

### 진단
- `POST https://demo.hitpan.kr/api/auth/login` → HTTP 405 Method Not Allowed
- 응답 헤더 `Allow: GET, HEAD` → 외부에서 GET·HEAD만 허용
- AuthController는 `[HttpPost("login")]`로 정상 박제됨 (소스 확인)
- **외부 모바일 로그인 자체가 불가** 상태

### 5월 27일 사고와 직결
- 5/27 사고 = 모바일 외부 접속 불가
- 사장님이 직접 봉합했지만 **POST 메서드는 여전히 막힌 상태**
- = 베타 발진 전 절대 봉합 필수

### 추정 근본 원인 (3가설)
1. **cloudflared config.yml ingress 규칙** — `/api/auth/*`가 service 라우팅 누락
2. **CORS 정책** — POST preflight OPTIONS만 통과하고 실제 POST는 reject
3. **API 측 OPTIONS 메서드 처리** — Cloudflare가 OPTIONS 응답 Allow 헤더 캐시 후 GET/HEAD만 노출

### 즉시 봉합 (사장님 결재 후, 헌법 #29)
1. **cloudflared config.yml 확인**:
   ```
   ingress:
     - hostname: demo.hitpan.kr
       service: http://localhost:5234   # Web만? API는?
   ```
   - API 별도 hostname (`api-demo.hitpan.kr`) 또는 path 분기 필요
2. **API CORS 설정 검증**:
   - `AllowAnyMethod()` 박제 확인
3. **로컬 직접 호출 검증**:
   - `localhost:5257/api/auth/login` POST가 정상이면 cloudflared가 진범
