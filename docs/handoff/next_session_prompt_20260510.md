## 핵심 문제 — BOM 등록 실패 원인

**Playwright 스크립트가 BOM 페이지 실제 동작을 제대로 파악하지 못했음.**

BOM 페이지(`/bom/new`) 실제 구조:
- 상단: 완제품명 MudAutocomplete (상품 검색 → 선택)
- BOM 이름 텍스트필드
- 자재 목록 테이블: `+ 자재 추가` 버튼으로 행 추가 → 각 행에 자재명 MudAutocomplete + 소요량 MudNumericField
- 저장 버튼

**실제 화면에서 BOM 등록을 직접 해보고 셀렉터를 맞춰야 함.**
다음 세션에서는 반드시 화면에서 직접 수동으로 BOM 1개를 등록해보고 Playwright 셀렉터를 검증할 것.
