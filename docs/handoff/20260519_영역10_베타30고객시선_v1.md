## 🚨 진범 #57 (NEW) — 마이그 도중 끊기면?

### 시나리오
```
김사장: 마이그 시작 (12분 예상)
김사장: 5분 후 다른 화면 클릭 → 사이드바 메뉴 누름
시스템: 마이그 화면 떠남 → 카드 17개 상태 사라짐
김사장: "어디까지 됐지?"
```

### 현재 코드 박제 (MdbMigration.razor)
- 마이그 도중 다른 화면 이동 가능
- 백엔드는 백그라운드로 계속 진행
- 그러나 사장님 시선에서는 *"상태 사라짐 = 실패"* 오해

### 봉합 옵션
- A) 마이그 도중 다른 화면 이동 차단 (모달)
- B) 사이드바에 *"마이그 진행 중 (12/17)"* 표시
- C) 마이그 화면 재진입 시 자동 SignalR 재구독 + 카드 상태 복원

#### PM 1차 추천: B + C 병행

## 🚨 진범 #58 (NEW) — 마이그 완료 후 화면에 데이터가 안 보이면?

### 시나리오
```
김사장: 마이그 완료. 거래처 화면 이동
시스템: 거래처 13,543건 표시
김사장: "내 단골 ㄱㄴㄷ 거래처 안 보여! 14,000개라 했는데?"

원인 분석:
- 사장님 ERP는 14,000개 거래처 + 일부 중복
- 마이그 후 13,543 = 중복 제거 결과 (정상)
- 그러나 사장님 시선: "457개 사라짐 = 실패"
```

### 봉합 안
- 마이그 결과 화면에 *"중복 제거 N건"* 별도 표시
- legacy_doc_no 별도 컬럼으로 추적 가능 표시
