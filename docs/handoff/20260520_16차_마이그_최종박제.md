## 🎯 #76 차/대 swap 결정적 검증 SQL

```sql
SELECT 'total', COUNT(*), SUM(debit_amount), SUM(credit_amount) FROM journal_lines
UNION ALL SELECT 'debit_only', COUNT(*), SUM(debit_amount), SUM(credit_amount)
  FROM journal_lines WHERE debit_amount > 0 AND credit_amount = 0
UNION ALL SELECT 'credit_only', COUNT(*), SUM(debit_amount), SUM(credit_amount)
  FROM journal_lines WHERE credit_amount > 0 AND debit_amount = 0;
```
