## ⚠️ 누락 가능 영역 (안내 4건)

### 1. 회계 분개 라인 13.3% 누락
- **현상**: 일부 전표의 분개 상세 라인이 조회되지 않을 수 있음
- **원인**: 레거시 30년 누적 데이터의 source_id 중복 (원본 결함)
- **영향**: ❌ 일별·월별·연간 **합계 보고서는 정확** (전표 헤더 기준)
- **권장 조치**: 베타 기간 동안 신규 분개는 100% 정상 입력. 과거 분개 누락이 운영에 영향이 있으면 본사 CS 문의

### 2. 발주서 라인 일부 빈 칸
- **현상**: 과거 발주서 PDF 조회 시 일부 품목 라인이 비어있을 수 있음
- **원인**: 레거시 발주서의 품목명이 상품 마스터에 등록되지 않은 케이스
- **영향**: ❌ 매입 처리·재고 반영은 정상 (매입 100% 정합)
- **권장 조치**: 신규 발주는 100% 정상. 과거 발주서는 조회용으로만 활용 권장

### 3. 수주서 라인 일부 빈 칸
- **현상**: 과거 수주서 PDF 조회 시 일부 품목 라인이 비어있을 수 있음
- **원인**: 발주서와 동일 (품목 매핑 결함)
- **영향**: ❌ 거래명세서·세금계산서·재고 차감은 정상 (판매 100% 정합)
- **권장 조치**: 신규 수주는 100% 정상

### 4. BOM 26개 누락
- **현상**: 레거시 BOM 31개 중 5개만 이관
- **원인**: 26개 BOM의 완제품이 상품 마스터에 없음 (테스트성 데이터 의심)
- **영향**: ⚠️ 누락 26개 완제품 생산 시 자재 자동 차감 안 됨
- **권장 조치**: BOM이 필요한 경우 **신규 BOM 등록** 또는 본사 CS 문의 (가상 상품 자동 생성 지원 검토 중)
