## 3. 회사 정보 일괄 치환 자동화 (PM 사전 박제)

### 3.1. PowerShell 자동화 스크립트
```powershell
# 5종 메일 본문 회사 정보 일괄 치환
$vendorDir = "C:\Users\소순근\Desktop\hitpan-erp\installer\docs\vendor_emails"
$companyInfo = @{
    "{{회사명}}"      = "주식회사 히트판"           # 사장님 박제 받음
    "{{사업자번호}}"  = "___-__-_____"             # 사장님 박제 받음
    "{{본사주소}}"    = "___"                       # 사장님 박제 받음
    "{{대표전화}}"    = "+82-___-____-____"        # 사장님 박제 받음
    "{{보안2직통}}"   = "+82-___-____-____"        # 보안 매니저 2 직통
    "{{회신메일}}"    = "security@hitpan.kr"       # 박제 완료
    "{{일반메일}}"    = "support@hitpan.kr"        # 박제 완료
}

Get-ChildItem -Path $vendorDir -Filter "0*.md" | ForEach-Object {
    $content = Get-Content $_.FullName -Raw -Encoding UTF8
    foreach ($key in $companyInfo.Keys) {
        $content = $content -replace [regex]::Escape($key), $companyInfo[$key]
    }
    $outPath = $_.FullName -replace "\.md$", "_발송본.md"
    $content | Set-Content $outPath -Encoding UTF8
    Write-Host "박제: $outPath"
}
```

## 4. SHA256 박제 명령 (6/3 빌드 후)

```powershell
# v1.1.0 빌드 후 SHA256 박제
Get-ChildItem publish-output\v1.1.0\*.exe, publish-output\v1.1.0\*.msi |
  ForEach-Object {
    $hash = Get-FileHash $_.FullName -Algorithm SHA256
    "{0}  {1}" -f $hash.Hash, $_.Name
  } | Out-File -Encoding utf8 publish-output\v1.1.0\SHA256_v1.1.0.txt
```
