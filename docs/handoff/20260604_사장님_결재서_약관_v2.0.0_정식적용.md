## 1. 약관 v2.0.0 — v1.0.0 대비 변경점

### 신설 4개 조항

| 조항 | 내용 | 영향 |
|---|---|---|
| §24의2 | SLA 99.99% (본사 책임 영역만) | 본사 가용률 보장 + 정의 |
| §24의3 | SLA 위반 시 환불 (5%/10%/30%/100%) | 회원 손실 보장 |
| §24의4 | 책임 분산 3축 (본사·고객·제3자) | 헌법 #24 명문화 |
| §24의5 | Headscale 비상 대기 | 헌법 #30 정합 |

### 정합 헌법
- #18 v3 본사 데이터 0
- #22 본사 데이터 최소주의
- #24 책임 분산 + 가르침 의무
- #27 통신 무결성 99.99%

## 2. 마케팅 카피 사용 가능 6종

회사 모든 외부 자료(웹페이지·영업 자료·약관·뉴스레터·SNS)에 사용 가능:

1. **"본사 책임 영역 가용률 99.99% (약관 명시)"**
2. **"본사가 보유한 고객 업무 데이터 = 0건"**
3. **"본사 사고로 인한 데이터 유출 = 구조적으로 불가능"**
4. **"Windows Update·백신·재부팅 자동 봉합"**
5. **"라이선스 키 1번, 다른 입력 0"**
6. **"클라우드 없는 ERP — 본사가 가진 게 없어서 털릴 게 없습니다"**
