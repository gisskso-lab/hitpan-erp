## 8. 진범 박제 (재발 방지)

### 진범 #99 — UUID() → Guid 매핑 (P0 봉합 완료)
- 위치: `src/HitPan.Application/Services/ItemSpecService.cs:21-42`
- 원인: MariaDB `UUID()` 함수가 MySqlConnector 메타에 Guid 타입 힌트 박제 → string DTO 충돌
- 봉합: SQL에 `CAST(컬럼명 AS CHAR)` 명시
- 재발 방지 규칙 (헌법 후보):
  > **MariaDB UUID() 함수로 시드한 char(36) 컬럼은 SELECT 시 반드시 `CAST(... AS CHAR)` 명시. 또는 시드 SQL에서 `UUID()` 대신 명시 UUID 문자열 사용.**

### 진범 #100 — WASM 부팅 직후 fetch 실패 (봉합 완료, 도구 한정 잔존)
- 위치: `src/HitPan.Web/Components/Common/UnifiedCalendar.razor`
- 원인: `OnInitializedAsync` 시점이 WASM 부팅 초기 → fetch 실패 가능
- 봉합: `OnAfterRenderAsync(firstRender)` 이동 + AuthenticationState 대기
- 재발 방지 규칙 (헌법 후보):
  > **WASM 컴포넌트에서 첫 HTTP 호출은 OnInitializedAsync 대신 OnAfterRenderAsync(firstRender) 시점 사용 + AuthenticationState 완료 대기.**
