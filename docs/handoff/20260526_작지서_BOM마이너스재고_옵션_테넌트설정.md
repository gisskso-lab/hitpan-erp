## 📋 가도 영역

### Step 1: DB 매니저 (5/26 09:00)

#### DDL 작지서
```sql
-- tenants 테이블에 옵션 컬럼 추가
ALTER TABLE tenants
ADD COLUMN allow_negative_stock TINYINT(1) NOT NULL DEFAULT 0
  COMMENT '마이너스 재고 허용 (1=도소매·선판매 후입고 / 0=제조·BOM 무결성)'
AFTER business_type;

-- 인덱스 (조회 최적화)
ALTER TABLE tenants
ADD INDEX idx_allow_negative_stock (allow_negative_stock);

-- 기존 데이터 마이그
-- 도소매 테넌트는 ON, 제조 테넌트는 OFF 기본값
UPDATE tenants
SET allow_negative_stock = 1
WHERE business_type IN ('retail', 'wholesale', 'distributor');

UPDATE tenants
SET allow_negative_stock = 0
WHERE business_type IN ('manufacturing', 'bom_production');
```

#### 검증 SQL
```sql
-- 적용 확인
DESCRIBE tenants;

-- 도소매 vs 제조 분포 확인
SELECT business_type, allow_negative_stock, COUNT(*) AS cnt
FROM tenants
GROUP BY business_type, allow_negative_stock;
```

#### DB 매니저 정합성 게이트
- ✅ DESCRIBE로 컬럼 존재 확인 (헌법 #13)
- ✅ ENGINE=InnoDB 정합 (헌법 #17, 기존 테이블이라 자동)
- ✅ Collation utf8mb4_unicode_ci 정합

##### 1. 거래명세서 발행 시 (`SalesOrderService.cs`)
```csharp
public async Task<Result> ConfirmSalesOrderAsync(int salesOrderId)
{
    var tenant = await _tenantService.GetCurrentTenantAsync();
    var items = await GetSalesOrderItemsAsync(salesOrderId);

    foreach (var item in items)
    {
        var currentStock = await _stockService.GetStockAsync(item.ProductId);
        var newStock = currentStock - item.Quantity;

        if (newStock < 0 && !tenant.AllowNegativeStock)
        {
            return Result.Fail($"재고 부족: {item.ProductName} (현재 {currentStock}, 요청 {item.Quantity})");
        }
    }

    // confirmed 시점에만 원장 INSERT (헌법 #6)
    await _stockLedgerService.InsertSalesLedgerAsync(salesOrderId);
    return Result.Ok();
}
```

##### 2. BOM 생산 시 (`BomProductionService.cs`)
```csharp
public async Task<Result> ConfirmProductionAsync(int productionId)
{
    var tenant = await _tenantService.GetCurrentTenantAsync();
    var bom = await GetBomAsync(productionId);

    // BOM 생산은 항상 마이너스 차단 (제조 무결성)
    // allow_negative_stock 무시 — BOM은 자재 부족 시 생산 불가 (헌법 #20 워크플로우)
    foreach (var material in bom.Materials)
    {
        var currentStock = await _stockService.GetStockAsync(material.ProductId);
        var requiredQty = material.QuantityPerUnit * bom.ProductionQuantity;

        if (currentStock < requiredQty)
        {
            return Result.Fail($"자재 부족: {material.ProductName} (필요 {requiredQty}, 보유 {currentStock})");
        }
    }

    // INSERT ONLY 원장 (헌법 #3)
    await _stockLedgerService.InsertBomLedgerAsync(productionId);
    return Result.Ok();
}
```

##### 3. 재고 조회 API (`StockController.cs`)
```csharp
[HttpGet("stock/{productId}")]
public async Task<IActionResult> GetStock(int productId)
{
    var stock = await _stockService.GetStockAsync(productId);
    var tenant = await _tenantService.GetCurrentTenantAsync();

    return Ok(new
    {
        productId,
        currentStock = stock,
        allowNegative = tenant.AllowNegativeStock,
        warning = stock < 0 ? "재고 마이너스 상태 (입고 대기)" : null
    });
}
```
