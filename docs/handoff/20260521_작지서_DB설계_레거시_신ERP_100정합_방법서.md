## 🎯 100% 정합 달성 방법 도출 영역

### 1. DB 매니저 분석 영역 (Oracle 30년 SI 패턴)

#### 1-1. #70 회계 분개 source_id 중복 3,667
- DOCF7 원본의 PK 정밀 분석: `RT_PUM + RT_KU + RT_SUN` 또는 `DT + EN + KCODE` 조합 유일성 검증
- 옵션 E: **OLEDB SELECT DISTINCT로 원본 단계 중복 제거** vs **원본 자체에 중복 존재 시 KCODE 세분화**
- 헌법 §3 정합 시 봉합 방법: **journal_lines 이력 테이블 분리** (분개 라인 변경 시 INSERT ONLY)

#### 1-2. #71 세금계산서 자기중복 21쌍
- DOCFT 원본 21쌍의 정밀 진단: (TX_NO, TX_SEQ, TX_PDT) 외 추가 컬럼으로 분리 가능 여부
- 옵션 F: **TX_BUY (거래처) 추가 suffix** vs **TX_REM (비고) hash 추가**

#### 1-3. #82 멱등 키 누락 4종 (bills·card·bom_*)
- 현재 ALTER로 source_id 추가 완료. **코드 환원 후 효과 검증** (24차)
- 통합 멱등 키 정책 수립 (모든 테이블 source_type + source_id + migrated_source_hash)

#### 1-4. #80·#81 발주·주문 라인 품목 매핑 실패
- DOCFA·DOCFO 원본 품목명이 items 마스터에 없는 케이스 분석
- 옵션 G: **자동 가상 품목 생성** (`MIG-MISSING-{name}`) vs **사용자 결재 후 매뉴얼 매핑**

### 2. 설계팀장 분석 영역 (SAP SE 30년 패턴)

#### 2-1. #78 BOM 16% 정합 → 100% 달성

- 헌법 #20 워크플로우 §20 BOM 생산 흐름 100% 보장 영역

#### 2-2. #83·#85 AS·명함 0행 매핑 미구현
