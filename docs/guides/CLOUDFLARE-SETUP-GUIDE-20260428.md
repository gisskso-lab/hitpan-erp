## STEP 1 — Cloudflare 계정 생성 (5분)

### 1.1 가입
1. https://dash.cloudflare.com/sign-up 접속
2. 이메일 + 비밀번호 입력
3. 이메일 인증 (받은 메일에서 링크 클릭)

### 1.2 무료 플랜 선택
- 가입 직후 플랜 선택 화면에서 **"Free Plan"** 선택
- 신용카드 정보 **요구 안 함** (무료 플랜은 카드 불필요)
- 만약 도메인 추가 화면이 뜨면 **"Skip for now"** 또는 **"Remind me later"** 클릭 (도메인은 단계 2에서 박음)

### 1.3 마커스 리 보조 안내
> 만약 가입 도중 "Verify your humanity" 캡차가 뜨면 그냥 풀어주세요. 이건 자동화 봇 차단 용도입니다.
> 이메일 인증 메일이 안 오면 스팸함 확인. 5분 후에도 안 오면 마커스 리에게 알려주세요.

---

## STEP 2 — Zero Trust 활성화 (5분)

### 2.1 Zero Trust 대시보드 진입
1. Cloudflare 대시보드 좌측 메뉴에서 **"Zero Trust"** 클릭
2. 또는 직접 접속: https://one.dash.cloudflare.com/

### 2.2 팀 이름 설정
- "Choose a team name" 화면에서 **`hitpan`** 입력
- 결과: 본사 Zero Trust URL이 `hitpan.cloudflareaccess.com` 으로 박힘
- ⚠️ 한 번 설정하면 변경 어려움 — `hitpan` 권장

### 2.3 Free Plan 선택
- 플랜 선택 화면에서 **"Free"** 클릭 (50명까지 무료)
- 카드 정보 요구하지만 **"Skip"** 또는 **"Add card later"** 가능
- 일부 경우 카드 등록 강제 — 그래도 무료 한도 안에서는 청구 안 됨 (마커스 리 모니터링)

⚠️ **마커스 리 약속**: Zero Trust Free 사용량을 매주 확인해서 50명 초과 위험 시 사장님께 즉시 보고. 청구서 한 장도 안 나오게 함.

## STEP 3 — Cloudflare Tunnel 첫 터널 생성 (10분, 시범 1개만)

### 3.1 Tunnel 메뉴 진입
1. Zero Trust 대시보드 → **"Networks"** → **"Tunnels"**
2. **"Create a tunnel"** 클릭

### 3.2 첫 터널 생성 (시범)
1. Tunnel type: **"Cloudflared"** 선택
2. Tunnel name: **`tenant-001`** 입력 (베타 첫 고객용)
3. **"Save tunnel"** 클릭

### 3.3 토큰 안전 보관 ⭐ 중요
1. 다음 화면에서 OS 선택 화면이 뜨면 **"Windows"** 선택
2. 아래에 표시되는 명령어:
   ```
   cloudflared.exe service install eyJh...(긴 토큰)...
   ```
3. **`eyJh...` 부분만 복사** → LastPass/Bitwarden/메모장에 저장
   - 라벨: `tenant-001 토큰`
   - **절대 Git에 커밋 금지** ⚠️
   - 종이에 적지 마세요 (사진 찍히면 유출)

4. **"Next"** 클릭 (실제 설치는 안 함, 토큰만 발급받는 게 목적)

### 3.4 Public Hostname 설정 (단계 1은 건너뛰기)
- 단계 1 (베타 0~1개월): 임시 도메인 사용 → **"I'll do this later"** 또는 **"Skip"**
- 단계 2 (`hitpan.app` 구매 후): 이 부분에서 hostname 박음
- 본 가이드는 단계 1만 다룸

### 3.5 결과 확인
- Tunnels 목록에 `tenant-001` 이 **"Inactive"** 또는 **"Healthy"** 로 표시됨
- 아직 cloudflared 클라이언트 미설치라 Inactive 정상

## ⚠️ 트러블슈팅

### Q1. "Add a payment method" 강제 — 카드 입력하라고 나옴
- 무료 한도 안에서는 청구 안 됨
- 그래도 부담스러우면 **"Skip / Remind me later"** 누르거나, 마커스 리에게 알려주세요
- 일부 신규 가입 시기에 따라 카드 강제됨 (정책 가변)

### Q2. 이메일 인증 메일이 안 와요
- 스팸함 확인
- 5분 후 재요청
- 그래도 안 오면 다른 이메일로 가입 (Gmail 권장 — Cloudflare가 잘 받아줌)

### Q3. Zero Trust 팀 이름 다른 거 박았어요
- 변경 가능하지만 번거로움 (Cloudflare Support 문의 필요)
- **이미 만든 거면 그대로 진행** — 변경 안 해도 작동
- 사장님이 박은 이름 알려주세요. 마커스 리가 인프라 문서에 박아둠.

### Q4. 캡차 무한 반복
- 다른 브라우저 시도 (Chrome → Edge / Firefox)
- VPN 켜져있으면 끄기

### Q5. "Verify your domain" 강제
- 단계 1에서는 도메인 미보유 → **"Skip"** 또는 **"I don't have a domain yet"** 클릭
- 단계 2 (도메인 구매 후) 다시 진행
