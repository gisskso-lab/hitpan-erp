## 6. 이 구조를 쓰는 원칙 (왜 이렇게 만들었나)

- **문서가 쌓일수록 AI가 멍청해진다** — 잡음이 신호를 덮고, 옛 문서를 최신으로 오판하기 때문.
- 그래서 **필요한 것만 읽는 구조**로 바꿨다. 매 세션 자동 로딩을 24,000 → 12,700 토큰으로 줄였다.
- **원문은 하나도 안 지웠다.** 위치만 옮기고, 필요할 때 찾아가게 했다.
- 새 문서를 만들 때 **대체된 옛 문서를 ⬛흡수로 표시**하는 게 핵심이다. 안 하면 다시 쌓인다.
