# 히트판 ERP 설치 매뉴얼

## 시작하기 전에

### 준비물
- 인터넷이 연결된 Windows 10/11 PC
- 관리자 권한 계정
- 가입 시 받은 시리얼 키 (이메일로 받으셨습니다)
- 약 10분의 시간

### PC 사양
| 항목 | 최소 | 권장 |
|---|---|---|
| OS | Windows 10 64bit | Windows 11 64bit |
| CPU | 듀얼코어 2GHz | 쿼드코어 2.5GHz |
| 메모리 | 4GB | 8GB |
| 디스크 여유 공간 | 10GB | 20GB |
| 네트워크 | 인터넷 연결 | 유선 + 무선 |

---

## 1단계 — 설치 파일 다운로드

1. 본사에서 안내드린 다운로드 링크를 클릭하세요.
2. `HitPan-ERP-Setup-1.x.x.exe` 파일이 다운로드됩니다.
3. 다운로드한 파일을 **바탕화면**에 저장하세요.

---

## 2단계 — 관리자 권한으로 실행

1. 다운로드한 `.exe` 파일을 **마우스 오른쪽 버튼** 클릭
2. "관리자 권한으로 실행" 선택
3. Windows에서 "이 앱이 디바이스를 변경할 수 있도록 허용하시겠습니까?" 묻는 창이 나오면 **예** 클릭

### 보안 경고가 나오는 경우

Windows Defender SmartScreen 경고가 나올 수 있습니다:
1. **추가 정보** 클릭
2. **실행** 버튼 클릭

(베타1 기간 동안만 해당, 정식 출시 시에는 자동 신뢰됩니다)

---

## 3단계 — 시리얼 키 입력

설치 마법사가 시작되면:

1. **환영** 화면에서 **다음** 클릭
2. **시리얼 키 입력** 화면이 나옵니다.
3. 이메일로 받은 시리얼 키를 정확히 입력하세요.
   - 예시: `HP-ABCD-1234-EFGH-5678`
   - 대소문자·하이픈 그대로 입력
4. **다음** 클릭

### 시리얼 키를 분실하셨다면
본사 고객센터로 문의해주세요. 가입 시 등록한 이메일로 재발송해드립니다.

---

## 4단계 — 자동 설치 (약 5~10분)

마법사가 다음을 자동으로 설치합니다:

- [x] 회사 정보 자동 확인
- [x] .NET 8 Runtime
- [x] MariaDB 11.4 (데이터베이스)
- [x] Cloudflare 터널 (외부 접속)
- [x] 워치독 서비스 (자동 복구)
- [x] 백신 예외 등록
- [x] 방화벽 규칙 등록

**설치 중 PC를 끄거나 재시작하지 마세요.**

---

## 5단계 — 설치 완료

설치가 완료되면:

1. **완료** 버튼 클릭
2. 자동으로 브라우저가 열립니다.
3. 본인의 ERP 주소가 나타납니다.
   - 예시: `mycompany.hitpan.kr`
4. 로그인 화면에서 가입 시 받은 부모계정으로 로그인

## 자주 묻는 질문

### Q1. 설치 도중 백신이 격리했어요
**A.** 다음 매뉴얼을 따라주세요:

1. 백신 프로그램 열기
2. "격리 항목" 메뉴 찾기
3. `cloudflared.exe` 또는 `HitPan` 관련 항목 **복원**
4. 백신의 "예외 설정"에 다음 폴더 추가:
   - `C:\HitPan`
   - `C:\Program Files\MariaDB 11.4`
   - `C:\Program Files\cloudflared`
5. 설치 마법사 재실행

### Q2. "시리얼 키가 올바르지 않습니다" 에러
**A.** 다음을 확인해주세요:
- 시리얼 키를 정확히 입력했는지 (대소문자·하이픈)
- 시리얼 키 양 끝에 공백이 없는지
- 본사에서 가입 승인이 완료되었는지 (이메일 확인)
- 인터넷 연결이 정상인지

### Q3. 설치가 중간에 멈췄어요
**A.**
1. 작업 관리자에서 설치 프로그램 강제 종료
2. PC 재시작
3. 설치 마법사 다시 실행
4. 같은 문제가 반복되면 본사 고객센터에 사고 화면 사진과 함께 문의

### Q4. ERP 주소에 접속이 안 돼요
**A.**
1. PC 재시작 후 다시 시도
2. 브라우저 캐시 삭제 (Ctrl+Shift+Delete)
3. 다른 브라우저로 시도 (Chrome 권장)
4. Windows 서비스에서 다음이 모두 **실행 중**인지 확인:
   - MariaDB
   - cloudflared
   - HitPan-Watchdog

### Q5. 자동 업데이트는 어떻게 되나요?
**A.** 자동 업데이트 안내문을 별도로 보내드렸습니다.
- 일반 업데이트: 매일 새벽 3시 자동
- 긴급 패치: 5분 안내 후 자동
- 큰 변경: 동의 후 영업시간 외 자동
