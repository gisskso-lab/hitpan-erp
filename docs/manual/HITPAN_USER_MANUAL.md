## 🚀 1. 시작하기

### 1.1 로그인

1. 웹브라우저(크롬·엣지)를 열고 **본인 회사 주소**로 접속합니다.
   - 예: `hitpan-회사명.kr`
2. 로그인 화면이 나오면:
   - **이메일**: 본인 회사 이메일 입력
   - **비밀번호**: 관리자에게 받은 비밀번호 입력
3. **[로그인]** 버튼 클릭

### 1.2 첫 화면 (대시보드)

로그인하면 가장 먼저 보이는 화면입니다.
- **오늘의 매출** — 위쪽에 큰 글씨로 표시
- **알림 카드** — 미수금, 발주 처리 대기, 결재 대기 등이 보입니다
- **빠른 메뉴** — 화면 아래쪽에 자주 쓰는 메뉴(홈/판매/수금/재고/전체메뉴)가 있습니다

### 1.3 사이드바 메뉴 구조

화면 왼쪽에 10개의 큰 그룹이 있습니다. 클릭하면 하위 메뉴가 펼쳐집니다.

| 그룹 | 무엇을 하는 곳인가 |
|---|---|
| **계정관리** | 사용자/사원/권한 설정 |
| **그룹웨어** | 전자결재, 연차신청, 공지사항 |
| **업체관리** | 거래처(고객·공급처) 등록 및 관리 |
| **상품관리** | 판매·매입할 상품과 BOM 등록 |
| **판매관리** | 견적·수주·거래명세서·세금계산서 |
| **매입관리** | 발주·매입·반품 |
| **계산서관리** | 세금계산서 발행·조회 |
| **재고관리** | 재고현황·수불부 |
| **회계관리** | 경비처리·손익현황·미수금 |
| **자료관리** | 데이터 백업·복구 |

> 💡 **팁**: 메뉴가 처음에는 다 닫혀 있습니다. 깔끔하게 보이려고 일부러 그렇게 했습니다. 필요한 그룹만 클릭해서 펼쳐 쓰세요.

## 🏢 2. 업체관리 — 거래처 등록

### 2.1 업체 마스터 등록

**언제 쓰나요?** — 새 거래처(고객사 또는 공급처)가 생겼을 때.

**순서:**

1. 사이드바에서 **[업체관리]** 클릭 → **[업체 마스터]** 클릭
2. 업체 목록이 나옵니다. 화면 위쪽 **[+ 업체 등록]** 버튼 클릭
3. 등록 폼이 열리면 다음 정보 입력:

| 필드 | 입력 내용 | 필수 여부 |
|---|---|---|
| 업체명 | 거래처 회사 이름 | ✅ 필수 |
| 업체코드 | 자동 생성됨 (수정 가능) | 선택 |
| 구분 | customer(고객) / supplier(공급처) | ✅ 필수 |
| 사업자번호 | 10자리 숫자 | 권장 |
| 대표자 | 대표자 성함 | 선택 |
| 업태/업종 | 사업자등록증 보고 입력 | 선택 |
| 전화/팩스 | 회사 연락처 | 선택 |
| 우편번호/주소 | 회사 주소 | 선택 |
| 담당자명/연락처 | 거래 담당자 정보 | 권장 |
| **단가등급** | A~E 등급 (A가 가장 싼 단가) | 권장 |
| **결제조건(일)** | 30일/60일 등 외상기간 | 권장 |
| **여신한도** | 최대 외상 가능 금액 | 권장 |
| 부가세 유형 | 과세/면세/영세율 | ✅ 필수 |
| 메모 | 자유 입력 | 선택 |

4. 입력 완료 후 **[저장]** 클릭

### 2.2 업체 특별단가

특정 업체에만 다른 단가를 적용할 때 씁니다.
예: A업체에는 드라이버 1,000원, B업체에는 1,200원으로 팔고 싶을 때.

### 2.3 업체별 원장

특정 업체의 거래 내역을 한 번에 보는 화면입니다.
매출·매입·수금·지급 모두 시간순으로 정렬되어 보입니다.

## 📦 3. 상품관리 — 상품과 BOM

### 3.1 상품 등록

**순서:**

1. **[상품관리]** → **[상품 마스터]** 클릭
2. **[+ 상품 등록]** 버튼 클릭
3. 입력 항목:

| 필드 | 입력 내용 |
|---|---|
| 상품명 | 상품 이름 (검색 키워드) |
| 상품코드 | 자동 생성 |
| 상품그룹 | 분류 (예: 공구, 자재, 부품) |
| **유형** | 완제품 / 반제품 / 자재 |
| 규격 | 사이즈·재질 등 |
| **단위** | EA, SET, BOX 등 |
| **판매단가** | 고객에게 파는 가격 |
| **매입단가** | 공급처에서 사오는 가격 |
| 표준단가 | 기준 단가 |
| 부가세 유형 | 과세/면세 |
| **안전재고** | 이 수량 이하 떨어지면 알림 |
| 자동발주 사용 | 안전재고 미만 시 자동으로 발주서 생성 |
| 기본 발주처 | 자동발주 시 어느 업체로 발주 |
| 기본 발주수량 | 자동발주 1회당 수량 |
| 자동 매입확정 | 자동발주 후 매입 자동 확정 여부 |
| 바코드 | 바코드 번호 |
| 기본 창고 | 어느 창고에 입고할지 |
| 메모 | 자유 입력 |

4. **[저장]** 클릭

### 3.2 BOM 등록 (제조·조립용)

**언제 쓰나요?** — 자재 여러 개로 완제품 하나를 만드는 회사일 때.
예: 드라이버 3개 + 렌치 2개 + 케이스 1개 → "공구세트 A" 완제품

**순서 (사장님 시연 기반):**

1. **[상품관리]** → **[BOM]** 클릭
2. **[+ BOM 등록]** 버튼 클릭
3. **완제품명 (새 상품)** 칸에 입력:
   - 기존 상품 검색해서 선택 가능
   - **새 상품 이름을 그냥 입력하면 → 상품마스터에 자동으로 등록됩니다** 💡
   - 예: "테스트 완제품" 입력 → 상품마스터에도 동시 생성
4. **BOM 이름** 입력 (예: "기본 공구세트 BOM")
5. **[+ 자재 추가]** 버튼 클릭 → 자재 행 1개 추가됨
6. 자재 행에서:
   - **자재명**: 검색해서 선택 (자동완성)
   - **단위**: 자동(EA) — 필요 시 변경
   - **소요량**: 완제품 1개 만드는 데 필요한 자재 수량
   - **로스율(%)**: 작업 중 버려지는 비율
7. 자재가 더 있으면 다시 **[+ 자재 추가]** 클릭 → 반복
8. **[저장]** 클릭

> ⚠️ **주의**: 로스율은 0~99% 사이로 입력하세요. 100% 이상은 비현실적입니다.

**BOM 상세 화면 버튼:**
- **[조립 실행]**: 자재 차감 + 완제품 입고 한 번에 처리
- **[조립 해체]**: 완제품을 다시 자재로 분해
- **[복사]**: 비슷한 BOM 빠르게 만들 때 사용
- **[삭제]**: BOM 삭제 (조심!)

## 🛒 4. 매입관리 — 발주부터 매입까지

### 4.1 워크플로우

```
발주 → 매입 → (필요 시) 반품
       ↓
   재고 자동 증가
```

### 4.2 발주서 작성

**순서:**

1. **[매입관리]** → **[발주 처리]** 클릭
2. **[추가]** 버튼 클릭 → 새 발주서 작성 화면
3. 헤더 입력:
   - **발주일자**: 오늘 날짜 자동
   - **거래처명**: 공급처 검색·선택
   - **발주메모**: 자유 입력
4. 품목 행 입력 (헤더 아래 표):
   - **품명**: 자재·상품 검색·선택
   - **규격, 단위**: 자동 채워짐
   - **수량**: 필요 수량
   - **단가**: 매입단가 자동 (수정 가능)
   - **금액**: 자동 계산
   - **부가세액**: 자동 계산
   - **비고**: 자유 입력
5. 품목이 더 있으면 행 추가
6. **[저장]** 클릭 → 발주서 작성 완료

**발주 상세 버튼:**
- **[발주서★]** / **[발주]** / **[매입]** / **[반품]**: 탭 전환
- **[매입확정]**: 발주서를 매입으로 전환 (재고 증가)
- **[복사]**: 같은 발주 빠르게 복제
- **[인쇄]** / **[PDF]** / **[이메일]**: 발주서 거래처에 전송

### 4.3 매입확정 (재고 반영)

발주만 한 상태에서는 재고가 안 늘어납니다.
**[매입확정]** 버튼을 눌러야 → 재고 자동 증가 + 매입 원장 INSERT.

> ⚠️ **주의**: 매입확정 후에는 수정·삭제가 어렵습니다. 신중하게 하세요.

### 4.4 반품

물건을 받았는데 불량이거나 잘못 받은 경우.
**[반품]** 탭에서 처리 → 재고 자동 감소.

## 💰 5. 판매관리 — 견적부터 세금계산서까지

### 5.1 워크플로우

```
견적 → 수주 → 거래명세서 → 세금계산서
                  ↓
             재고 자동 감소
```

### 5.2 거래명세서 작성

**순서:**

1. **[판매관리]** → **[거래명세서]** 클릭
2. **[추가]** 버튼 클릭
3. 헤더 입력:
   - **판매일자**: 오늘 날짜 자동
   - **거래처**: 고객 검색·선택
   - **메모**: 자유 입력
4. 품목 행 입력:
   - **품명**: 상품 검색·선택
   - **규격, 단위**: 자동
   - **수량**, **단가**: 입력 (단가는 업체별 특별단가 자동 적용)
   - **금액**, **부가세액**: 자동 계산
   - **비고**: 자유 입력
5. 품목 추가 반복
6. **[저장]** 클릭 → 거래명세서 발행 + 재고 자동 감소

**거래명세서 상세 버튼:**
- **[거래명세서★]** / **[세금계산서]**: 탭 전환
- **[세금]** 버튼: 거래명세서 → 세금계산서로 전환
- **[복사]**: 같은 내용 빠르게 복제 (정기 거래 편함)
- **[인쇄]** / **[PDF]** / **[이메일]**: 고객에게 전송

### 5.3 세금계산서 발행

거래명세서가 작성되어 있으면 **[세금]** 버튼 한 번으로 세금계산서가 만들어집니다.

발행 후:
- **[전자발행]** 버튼(녹색): 이세로/메이크빌 통해 국세청 전송 (베타에서는 준비 중)
- **상태 칩**: "계산서 발행" → "전자발행 완료"로 변경

## 📊 6. 재고관리

### 6.1 재고현황

**[재고관리]** → **[재고현황]** 클릭

화면에 보이는 정보:
| 컬럼 | 설명 |
|---|---|
| 품목명 | 상품 이름 |
| 수량 | 현재고 수량 |
| 안전재고 | 미리 설정한 안전재고 |
| 재고금액 | 현재고 × 매입단가 |

> 💡 안전재고보다 적게 떨어지면 화면에 빨간색 표시.

### 6.2 수불부 (입출고 이력)

**[재고관리]** → **[수불부]** 클릭

품목별 입고·출고 이력을 시간순으로 봅니다.
| 컬럼 | 설명 |
|---|---|
| 품목명 | 상품 |
| 입고수량 | 들어온 수량 |
| 출고수량 | 나간 수량 |
| 잔량 | 그 시점의 재고 |
| 입고금액/출고금액 | 시점별 금액 |

> ⚠️ 이 화면 데이터는 **삭제·수정 불가**(INSERT ONLY 원장). 잘못 들어가면 반대 거래로 상쇄해야 합니다.

## 💸 7. 회계관리

### 7.1 경비처리

회사에서 쓴 돈(주유비·식대·소모품 등) 입력.

1. **[회계관리]** → **[경비처리]**
2. **[추가]** 클릭
3. 항목·금액·증빙(영수증·카드매출전표 첨부) 입력
4. 저장 → 회계 원장에 자동 INSERT

### 7.2 손익현황

월별 매출·매입·이익을 한눈에 보여주는 화면.

### 7.3 미수금

고객별로 안 받은 돈(외상) 목록.
- 연체 일수 자동 계산
- 여신한도 초과 시 빨간색 표시

## 📨 8. 그룹웨어

### 8.1 전자결재

**[그룹웨어]** → **[전자결재]** 클릭

탭 구조:
- **결재 대기**: 내가 결재해야 할 문서
- **내가 보낸 결재**: 내가 기안한 문서 진행 상황
- **완료된 결재**: 종료된 결재

**기안 작성:**
1. **[기안 작성]** 버튼 클릭
2. 양식 선택 (지출결의서·휴가신청서 등)
3. 결재선 지정 (1차 → 2차 → 최종)
4. 내용 작성 → **[상신]**

### 8.2 연차신청

1. **[그룹웨어]** → **[연차신청]**
2. 연차 부여 일수, 사용 일수, 잔여 일수 표시
3. **[신청]** 버튼 → 시작일·종료일·유형(연차/반차/병가) 선택
4. 결재선 지정 → 상신

## 💾 9. 자료관리

### 9.1 자료 백업·복구

**[자료관리]** → **[자료 백업·복구]**

- **자동 백업**: 매일 새벽 자동 (설정 가능)
- **수동 백업**: 즉시 백업 파일 생성
- **복구**: 백업 파일 선택 → 복구

> ⚠️ **중요**: 복구는 현재 데이터를 덮어씁니다. 신중하게.

## 👤 10. 계정관리 (관리자만)

### 10.1 사원관리

**[계정관리]** → **[사원관리]**

| 컬럼 | 설명 |
|---|---|
| 사번 | 자동 생성 |
| 이름 | 사원 이름 |
| 부서 | 소속 부서 |

## ❓ 11. 자주 묻는 질문 (FAQ)

**Q1. 비밀번호 잊어버렸어요.**
→ 관리자에게 요청. 관리자가 [계정관리] → [사원관리]에서 비밀번호 초기화.

**Q2. 거래명세서 저장했는데 재고가 안 빠져요.**
→ 거래명세서가 "확정" 상태인지 확인. 임시저장(draft) 상태에서는 재고 안 빠짐.

**Q3. 발주했는데 재고가 안 늘어나요.**
→ 발주는 단순 주문 기록. **[매입확정]** 버튼을 눌러야 재고 증가.

**Q4. BOM 자재명에서 자재가 검색 안 돼요.**
→ 먼저 [상품관리]에서 자재가 등록되어 있어야 합니다. 등록 안 된 자재는 검색 안 됨.

**Q5. 세금계산서 전자발행이 안 돼요.**
→ 베타 버전에서는 이세로·메이크빌 API 연결 작업 진행 중. 정식 버전에서 활성화.

**Q6. 화면이 갑자기 안 나와요.**
→ 브라우저 새로고침(F5). 그래도 안 되면 로그아웃 후 재로그인.

**Q7. 모바일에서도 쓸 수 있나요?**
→ 향후 모바일 UX(아이폰 홈 화면 스타일) 출시 예정.
