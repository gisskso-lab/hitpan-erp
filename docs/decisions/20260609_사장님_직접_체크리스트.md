## P0-1. GitHub Secrets 박기 (10분)

GitHub `gisskso-lab/hitpan-erp` → Settings → Secrets and variables → Actions → New repository secret

| Secret 이름 | 값 | 영역 |
|---|---|---|
| `NCP_HOST` | NCP 서버 IP (back.hitpan.kr DNS 가리키는 영역) | NCP 자동 배포 |
| `NCP_USER` | NCP 배포용 SSH 계정명 | NCP 자동 배포 |
| `NCP_SSH_PRIVATE_KEY` | NCP 인증키 (PEM 전체 박기) | NCP 자동 배포 |

박은 후 검증:
- `develop` 브랜치 push → GitHub Actions `Deploy to NCP` 자동 가동
- 약 2~3분 후 back.hitpan.kr 자동 갱신 확인

## P0-2. Cloudflare 환경변수 박기 (15분)

NCP 백오피스 서버 SSH 접속 → `/etc/systemd/system/hitpan-backoffice-api.service`:

```ini
[Service]
Environment="CLOUDFLARE_API_TOKEN=xxxxx"
Environment="CLOUDFLARE_ZONE_ID=xxxxx"
Environment="CLOUDFLARE_ACCOUNT_ID=xxxxx"
```

박는 영역:
1. Cloudflare 대시보드 → My Profile → API Tokens → Create Token
2. 권한: `Zone:DNS:Edit` + `Account:Cloudflare Tunnel:Edit`
3. Zone: `hitpan.kr`만 박힘
4. 발급 후 토큰 → NCP 박힘

재기동:
```bash
sudo systemctl daemon-reload
sudo systemctl restart hitpan-backoffice-api
```

검증:
- 새 고객 가입 → 승인 → 시리얼 발급 → `InstallerBootstrap` 응답에 `tunnelToken` 박힘 확인
