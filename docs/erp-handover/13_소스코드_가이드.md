## 3. 빌드·실행 가이드

### 3.1 사전 준비
```powershell
# .NET 8 SDK
dotnet --version  # 8.0+ 또는 10.x

# MariaDB 11.4.10
mysql --version

# DB 생성
mysql -uroot -p -e "CREATE DATABASE hitpan_erp CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci"
mysql -uroot -p -e "CREATE USER 'hitpan'@'localhost' IDENTIFIED BY 'Hitpan2025!'; GRANT ALL ON hitpan_erp.* TO 'hitpan'@'localhost'"

# 마이그레이션 적용 (76개 SQL 순서대로)
for f in src/HitPan.API/Migrations/SQL/*.sql; do mysql -uhitpan -pHitpan2025! hitpan_erp < $f; done
```

```powershell
dotnet build src/HitPan.sln
# 기대: 0 errors / 0 warnings
```
