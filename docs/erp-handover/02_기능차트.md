## 4. 워크플로우 3흐름 (헌법 #20)

### 흐름 1. 매입
```
발주서 작성
  ↓ confirmed
매입명세서 발행 (입고)
  ↓ confirmed
stock_ledger INSERT (재고 증가)
  ↓
원장 (journal_lines INSERT)
```

### 흐름 2. BOM
```
BOM 헤더 + bom_items (자재 N건)
  ↓
생산 명령 (confirmed)
  ↓ 동일 트랜잭션
완제품 stock_ledger +N
자재 stock_ledger -N
```

### 흐름 3. 판매
```
견적서 → 수주서 → 거래명세서
                    ↓ confirmed
                    stock_ledger -N (재고 차감)
                    ↓
                    세금계산서 (메이크빌 ASP / 홈택스 외주)
                    ↓
                    매출 원장 + 경리 + 세무
```

**한 단계라도 끊기면 = 무결성 깨진 것 = 즉시 P0 핫픽스.**
