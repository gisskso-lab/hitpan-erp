## 2. 핵심 진범 박제

### 진범 #99 — UUID() → Guid 매핑 (2026-05-31) ⭐
**증상**: `GET /api/items/{itemId}/specs?activeOnly=true` 500

**Stack**:
```
DataException: Error parsing column 0 (SpecId - Guid)
  → InvalidCastException: Object must implement IConvertible
```

**근본 원인**:
- DB-76 시드 SQL이 MariaDB `UUID()` 함수로 spec_id 시드
- MySqlConnector가 해당 컬럼을 Guid 타입으로 추론
- Dapper가 string DTO에 매핑 시도 → 충돌

**봉합** (`ItemSpecService.cs:21-42`):
```sql
SELECT
    CAST(spec_id AS CHAR) AS SpecId,
    CAST(item_id AS CHAR) AS ItemId,
    ...
```

**재발 방지 (헌법 후보)**:
> MariaDB `UUID()` 함수로 시드한 char(36) 컬럼은 SELECT 시 반드시 `CAST(... AS CHAR)` 명시.

### 진범 #100 — WASM 부팅 직후 fetch 실패 (2026-05-31) ⭐
**증상**: 대시보드/양식정보설정 진입 시 콘솔
```
[UnifiedCalendarService.GetMonthlyAsync] HttpRequestException:
TypeError: Failed to fetch
```

**근본 원인**:
- `OnInitializedAsync`가 WASM 부팅 초기에 발사
- HttpClient handler 박제 전에 fetch 발사 → 실패

**봉합** (`UnifiedCalendar.razor`):
```csharp
protected override async Task OnAfterRenderAsync(bool firstRender)
{
    if (firstRender && !_loaded)
    {
        var auth = await AuthState.GetAuthenticationStateAsync();
        if (auth?.User?.Identity?.IsAuthenticated == true)
        {
            _loaded = true;
            await LoadMonthlyAsync();
            StateHasChanged();
        }
    }
}
```

**재발 방지 (헌법 후보)**:
> WASM 컴포넌트에서 첫 HTTP 호출은 `OnInitializedAsync` 대신 `OnAfterRenderAsync(firstRender)` 시점 사용 + `AuthenticationState` 완료 대기.
