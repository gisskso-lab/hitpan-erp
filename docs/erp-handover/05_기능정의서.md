## 1. 설정 (Stage 1, 16건)

### 1.1 회사정보 `/company`
| 항목 | 내용 |
|---|---|
| 입력 | 사업자번호·상호·대표·업종·주소·전화·이메일·로고 |
| 검증 | 사업자번호 체크섬, 이메일 형식 |
| 권한 | system_admin |
| 연결 | tenants 테이블 |

### 1.2 사용자정보 `/settings/user-info`
| 항목 | 내용 |
|---|---|
| 입력 | 이름·이메일·전화·비밀번호 변경 |
| 권한 | 본인 + system_admin |

### 1.3 사원관리 `/employees`
| 항목 | 내용 |
|---|---|
| 입력 | 사원번호·이름·이메일·부서·직책·입사일·역할 |
| 권한 | system_admin |
| 연결 | employees + users (2계층 헌법 #24) |

### 1.4 권한설정 `/users/permissions`
| 항목 | 내용 |
|---|---|
| 입력 | 사용자별 메뉴 권한 (CRUD) — 어드민 직접 설정 (헌법 #11) |
| 금지 | 업종·규모별 템플릿 제공 금지 |

### 1.5 직책관리 `/settings/positions`
- 직책 마스터 (대표·부장·과장·대리·사원 등)

### 1.6 결재라인 `/settings/approval-lines`
- 문서 유형별 결재 라인 (1~N단계)
- approval_lines + approval_line_steps

### 1.7 결재설정 `/settings/approval`
- 결재 정책 (자동 통과 / 부재 시 대결 등)

### 1.8 기기관리 `/settings/devices`
- 기기 등록 (헌법: 기기 기반 과금)
- 티어별 한도 (Light 1, Standard 3, Pro ∞)

### 1.9 이메일설정 `/settings/email`
- SMTP 설정 (서버·포트·계정·비밀번호 AES-256)
- 발송 이력 (email_send_history)

### 1.10 인쇄설정 `/print-settings`
- 프린터 선택, 용지 종류
- paper_mode: preprint(양식용지) / blank(순백지)

### 1.11 양식정보설정 `/settings/form-templates` ⭐ 신규 (2026-05-31)
- 8개 form_type: 견적·수주·거래명세·발주·매입·반품매입·반품매출·세금계산서
- preprint / blank 분기
- QuestPDF 좌표 박제

### 1.12 구독결제 `/settings/subscription-billing`
- 현재 티어, 다음 결제일
- 결제 수단 (토스페이먼츠)
- 청구서 이력 (billing_invoices)

### 1.13 데이터백업 `/data/backup`
- E2E 암호화 백업 (헌법 #22)
- 자동 스케줄 + 수동 실행
- 복원 (RestoreConfirmDialog)

### 1.14 로그 `/data/logs`
- 감사 로그 (audit_trail)
- API 요청 로그
- 로그인 시도

### 1.15 MDB마이그 `/settings/mdb-migration`
- 레거시 히트판 (Access MDB) 데이터 이관
- SignalR 진행률
- 헌법 #26 목표 10분 / Timeout 24시간

### 1.16 약관동의 `/terms` ⭐ 신규 (2026-05-31)
- 필수 4 (서비스·개인정보·구독·데이터소유권)
- 선택 1 (마케팅 수신)
- v2.0.0 버전 박제

## 2. 마스터 (Stage 2, 8건)

### 2.1 업체관리 `/partners`
- CRUD + 사업자번호 검증
- 매입처/매출처 구분 (partner_type)
- 연락처 (partner_contacts)

### 2.2 업체원장 `/partners/ledger`
- 거래처별 거래 내역 (매입·매출·수금·지급)
- 잔액 (partner_balance)

### 2.3 업체특별단가 `/partners/special-prices`
- 거래처-상품별 특별 단가
- 우선순위: 특별단가 > 상품 기본단가

### 2.4 상품관리 `/items`
- CRUD + 카테고리 (item_groups)
- 단위, 판매단가, 매입단가, 표준단가
- 안전재고, 자동발주

### 2.5 상품원장 `/items/ledger`
- 상품별 입출고 내역 (stock_ledger)

### 2.6 상품특별단가 `/items/special-prices`
- 상품-거래처별

### 2.7 BOM관리 `/bom`
- 헤더 (완제품) + 자재 (bom_items)
- 단가 캐시 (bom_cost_cache)

### 2.8 BOM신규 `/bom/new`
- 완제품 선택 + 자재 N건 + 수량 + 단가
