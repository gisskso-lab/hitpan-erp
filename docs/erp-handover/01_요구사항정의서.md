## 2. 비즈니스 요구사항

### 2.1 타겟 고객
- **1차**: 도소매 (가전·인테리어·식자재)
- **2차**: 제조 (소형 가공·BOM 단순)
- **3차**: 서비스 (유지보수·교육·컨설팅)

### 2.2 핵심 셀링 포인트
1. **로컬 PC DB + Cloudflare 터널** — 데이터 주권 사장님이, 본사는 메타정보만 (헌법 #22)
2. **원클릭 설치** — 라이선스 키 한 번이면 끝 (10분 이내)
3. **3분 안에 쓸 수 있는 UI** — 처음 보는 직원도 매뉴얼 없이 (사장님 헌법)
4. **모바일 + 데스크톱 통합** — 아이폰 홈 스타일 메뉴 (Phase 5)
5. **AI CS 챗봇** — "히트판에게 물어보세요" 24/7

### 2.3 가격 정책

## 3. 기능 요구사항 (6단계 워크플로우)

### Stage 1. 설정
- 회사정보 / 사용자정보 / 사원관리
- 권한설정 (어드민 직접, 헌법 #11)
- 직책 / 결재라인 / 결재설정
- 기기관리 / 이메일설정 / 인쇄설정
- 양식정보설정 (양식용지/순백지 분기, 헌법 #) — paper_mode
- 구독결제 / 데이터백업 / 로그 / MDB마이그
- 약관동의 (필수 4 + 선택 1)

### Stage 2. 마스터
- 업체관리 / 업체원장 / 업체특별단가
- 상품관리 / 상품원장 / 상품특별단가
- **BOM 관리** (자재 → 완제품 동일 트랜잭션, 헌법 #20)

### Stage 3. 매입 흐름 (헌법 #20)
```
발주 → 매입 → 재고 반영 → 원장 INSERT
       ↓
       반품 (역재고)
```

### Stage 4. 판매 흐름 (헌법 #20)
```
견적 → 수주 → 거래명세서 → 재고 차감 → 세금계산서
                                       ↓
                                       매출·경리·세무
```

### Stage 5. 재고
- 재고현황 / 재고원장 / 재고조정
- 재고이동 / 창고관리 / 창고분할

### Stage 6. 재무
- 회계 (분개·계정과목·월마감·손익·매입매출장·부가세·세무신고)
- 자금 (은행거래·카드결제·어음수표·출납장)
- 수금·지급
- 경비처리

### 부가
- 인사 (HR 사원·부서·근태·연차·초과근무·근로계약·서명이력)
- 결재 (대기·완료·발신)
- 대시보드 / 통합 캘린더

## 4. 비기능 요구사항

### 4.1 성능
- 단일 사용자 응답 < 2초
- 마이그 목표 시간: 10분 러프 (소형 표준, 헌법 #26)
- Timeout: 24시간 (대형 고객 가능성 보장)

### 4.2 보안 (5중 검증, 헌법 #23)
1. 작업지시서 보안 요구사항 명시
2. 어벤져스 매니저 리뷰 (절대원칙 25개)
3. SAST (CodeQL·Snyk·Roslyn·TruffleHog)
4. DAST (OWASP ZAP, 베타 출시 전 1회+)
5. 데이터 최소주의(#22) 검증

### 4.3 가용성 (헌법 #27)
- SLA 99.99% (연 다운타임 52분 이내)
- 통신 무결성 17개 워치독 시나리오 5분 자동 복구
- Windows Update 후 cloudflared 자동 복구 (헌법 #28)

### 4.4 호환성 (헌법 #31)
- Windows 10/11
- Defender + 백신 5종 (V3 Lite, 알약, 네이버, Norton, McAfee)
- EDR 3종 (안랩 EPP, 한컴, Trend Micro)
- 격리 0건 보장 (1클릭 봉합 매뉴얼 강제 제공)

### 4.5 코드 품질 (헌법 #19)
- 빌드 0 errors / 0 warnings
- 단위 테스트 100% PASS
- NuGet 보안 취약 패키지 0건

## 5. 데이터 요구사항

### 5.1 데이터 주권 (헌법 #22)
- **고객 PC**: 모든 업무 데이터 (매입/매출/원장/거래처/직원/세금계산서)
- **본사**: SaaS 결제·운영 메타정보만 (가입·결제·라이선스·텔레메트리·CS)
- 백업조차 E2E 암호화로 본사가 내용 모름

### 5.2 멀티테넌트 (헌법 #2)
- tenant_id는 JWT 클레임에서만
- 파라미터로 받는 코드 즉시 반려

### 5.3 원장 무결성 (헌법 #3)
- stock_ledger, journal_lines INSERT ONLY
- UPDATE/DELETE 금지
- 원장 반영은 confirmed 시점에만 (헌법 #6)

### 5.4 금액 정밀도 (헌법 #4)
- decimal 필수
- float/double 금지

### 5.5 암호화 (헌법 #5)
- 민감 컬럼 Value Converter (AES-256) 필수
- 미적용 PR 즉시 반려

## 6. 인터페이스 요구사항

### 6.1 외부 시스템
| 시스템 | 용도 | 책임 |
|---|---|---|
| Cloudflare | 터널·DNS | 본사 인프라 |
| MariaDB | 로컬 DB | 고객 PC |
| 토스페이먼츠 | SaaS 결제 | 본사 |
| 카카오/토스/금융인증/PASS | 전자서명 (간편인증 4종) | 제3자 |
| 메이크빌 | 전자세금계산서 ASP | 제3자 |
| 홈택스 API | 전자세금계산서 (외주 검토) | 제3자 |

### 6.2 API 패턴
- REST + JWT Bearer 토큰
- Refresh Token 회전
- Idempotency Key (POST 멱등성)
- 약관 미동의 시 미들웨어 차단

### 6.3 UI 패턴
- Blazor WebAssembly + MudBlazor
- 한 화면 완결 (스크롤 없이 핵심 정보)
- 모바일 우선 (아이폰 홈 스타일)
- WASM 첫 fetch는 OnAfterRenderAsync (진범 #100 봉합)
