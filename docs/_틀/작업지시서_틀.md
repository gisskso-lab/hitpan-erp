## AI수석 작성 지침 (이 틀을 쓰는 사람에게)

1. **"왜"를 추측으로 쓰지 마라.** 실측 명령과 결과를 근거로 적는다. 헌법 #32(받아쓰기 금지) 정합.
2. **"하지 않는 것"을 반드시 적어라.** 범위가 새는 사고의 90%는 이걸 안 적어서 난다.
3. **헌법 체크는 통합본 트리거 목차에서 기계적으로 뽑아라.** 감으로 고르지 말 것.
4. **검증 방법에 "확인함" 같은 말 금지.** 어떤 명령으로 무엇이 나오면 통과인지 적는다.
5. 못 채우는 칸이 있으면 → **그게 사장님께 여쭐 질문이다**(헌법 #33 단계 2).
